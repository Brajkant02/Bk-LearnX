BK LearnX v1.2 - Update Files Only

1. Is ZIP ko extract karein.
2. Extracted files/folders ko apne existing BK LearnX project ke root folder me copy karein.
3. Windows prompt aaye to "Replace the files in the destination" select karein.
4. Purani files ya project folder delete na karein.
5. VS Code terminal me chalayein:
   cd backend
   npm install
   npm start
6. Test ke baad GitHub par push karein:
   git add .
   git commit -m "Update BK LearnX to v1.2"
   git push origin main

Important: assets/shared/config.js me production backend URL set/check karein.
