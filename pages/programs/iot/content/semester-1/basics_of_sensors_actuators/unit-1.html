1. Introduction to Sensors

Sensor एक device या element है जो किसी physical quantity या environmental condition को detect/measure करके उससे संबंधित signal उत्पन्न करता है। Physical quantity जैसे temperature, pressure, light, humidity, force, displacement, motion आदि हो सकती है।

Simple Definition: Sensor वह device है जो physical quantity को detect करके उसे measurable signal में बदलने में सहायता करता है।

2. Sensor Characteristics

Sensor की performance को समझने के लिए उसकी कुछ important characteristics देखी जाती हैं। ये characteristics बताती हैं कि sensor input को कितनी अच्छी तरह detect और represent करता है।

CharacteristicBasic Meaning
Rangeजिस minimum से maximum input तक sensor operate/measure कर सकता है।
ResolutionInput में सबसे छोटा detectable change.
SensitivityInput change के प्रति output change की responsiveness.
AccuracyMeasured value का true/accepted value के कितना close होना।
RepeatabilitySame conditions में repeated measurements की consistency.
LinearityInput-output relationship का ideal straight-line relationship से deviation.
Response TimeInput change के बाद sensor output के required response तक पहुँचने में लगा समय।
Dead BandInput का वह region जिसमें change के बावजूद output में appreciable change नहीं होता।

3. Classification of Sensors

Sensors को उनके operating principle, output और power requirement आदि के आधार पर अलग-अलग categories में classify किया जा सकता है।

1. Active and Passive Sensors

TypeDescriptionExample
Active SensorMeasurement के कारण स्वयं electrical output generate कर सकता है और external excitation की आवश्यकता नहीं हो सकती।Thermocouple, piezoelectric sensor
Passive SensorExternal excitation के साथ अपनी resistance/capacitance/other electrical property में change करके measurement में सहायता करता है।RTD, thermistor, LDR

2. Analog and Digital Sensors

TypeDescription
Analog SensorContinuous या continuously varying output देता है।
Digital SensorDiscrete/digital form में output या data प्रदान करता है।

3. Contact and Non-contact Sensors

  • Contact: Measurement के लिए object के साथ physical contact कर सकता है।
  • Non-contact: बिना direct physical contact के quantity detect कर सकता है।

4. Based on Measured Quantity

Temperature, pressure, force, displacement, speed, acceleration, humidity, light, gas आदि को measure करने वाले sensors अलग categories में रखे जा सकते हैं।

4. Difference between Sensor, Transmitter and Transducer

TermMeaningExample / Role
SensorPhysical quantity को detect/measure करता है और corresponding response/signal देता है।Temperature sensor
Transducerएक form of energy/physical quantity को दूसरी form में convert करने वाला device/element.Thermocouple electrical output produce करता है।
TransmitterMeasured variable के signal को suitable standardized/conditioned signal में convert करके दूर स्थित receiving/control system तक भेजने के लिए उपयोग होता है।Industrial pressure transmitter
Conceptual Flow:
Physical Quantity → Sensing/Transduction → Signal Conditioning/Transmitter → Transmission → Controller/Display
Note: Practical instrumentation systems में sensor, transducer और transmitter की terminology application और manufacturer architecture के अनुसार overlap भी कर सकती है।

5. Primary Measuring Elements

Primary measuring element measurement system का वह initial sensing element है जो measurand के साथ directly interact करके उसके change को detect करता है। इसके response को आगे processing/transduction stages के लिए use किया जा सकता है।

Examples

  • Temperature measurement में sensing element.
  • Pressure measurement में diaphragm जैसे mechanical sensing elements.
  • Displacement measurement में mechanical sensing element.
Basic Measurement Chain: Measurand → Primary Sensing Element → Variable Conversion → Signal Conditioning → Transmission/Display

6. Sensor Selection & Characteristics

किसी application के लिए sensor चुनते समय केवल measured quantity देखना पर्याप्त नहीं होता। Operating conditions और required measurement performance भी देखनी होती है।

Selection में Important Factors

  • Required range
  • Required resolution
  • Required sensitivity
  • Required accuracy
  • Repeatability
  • Response time
  • Environmental conditions
  • Electrical/mechanical compatibility
  • Output signal और transmission requirements
  • Cost, reliability और maintenance requirements

7. Range

Range sensor द्वारा reliably measure किए जा सकने वाले input values की lower और upper limits को दर्शाता है।

Example: यदि temperature sensor की measurement range −20°C से 100°C है, तो −20°C lower limit और 100°C upper limit हैं।

Range को सामान्यतः Lower Range Value (LRV) और Upper Range Value (URV) से describe किया जा सकता है।

8. Resolution

Resolution input quantity में वह smallest change है जिसे sensor/system reliably distinguish या detect कर सकता है।

Example: यदि एक temperature instrument 0.1°C के change को distinguish कर सकता है, तो उसकी resolution लगभग 0.1°C हो सकती है।
Remember: छोटी resolution value का अर्थ अधिक छोटे changes को distinguish करने की capability हो सकती है, लेकिन resolution को accuracy के साथ confuse नहीं करना चाहिए।

9. Sensitivity

Sensitivity sensor के output में change और input में corresponding change के ratio को दर्शाती है।

Formula:
Sensitivity = Change in Output / Change in Input
S = ΔOutput / ΔInput
Example: यदि input 10 units बदलने पर output 2 V बदलता है, तो sensitivity = 2/10 = 0.2 V/unit.

10. Error

Error measured value और true/accepted reference value के बीच difference है।

Basic Formula:
Error = Measured Value − True/Reference Value
Absolute Error = |Measured Value − True Value|

Common Error Forms

  • Absolute Error: Actual difference in measurement units.
  • Relative Error: Error को reference/true value के relation में express किया जाता है।
  • Percentage Error: Relative error को percentage में express किया जाता है।
Percentage Error
= (Absolute Error / True Value) × 100

11. Repeatability

Repeatability बताती है कि same measurement conditions में same input को repeatedly measure करने पर sensor के readings कितनी consistent रहती हैं।

Example: यदि एक fixed temperature को बार-बार measure करने पर readings बहुत close आती हैं, तो sensor की repeatability अच्छी मानी जाती है।
Difference: Repeatability consistency से संबंधित है, जबकि accuracy true/accepted value के closeness से संबंधित है।

12. Linearity

Linearity sensor के actual input-output relationship और ideal straight-line relationship के बीच closeness/deviation को describe करती है।

Ideal linear sensor में input बढ़ने पर output predictable straight-line relationship के अनुसार change होता है।

Ideal:
Output = m × Input + c
Example: यदि 0, 10, 20, 30 units input पर output लगभग 0, 1, 2, 3 V मिलता है, तो relationship approximately linear है।

13. Accuracy

Accuracy measured value के true या accepted reference value के close होने की degree को दर्शाती है।

Example: यदि true temperature 50°C है और sensor 49.9°C दिखाता है, तो reading true value के काफी close है और accuracy अच्छी हो सकती है।
AccuracyRepeatability
True/accepted value के closeness से संबंधित।Repeated readings की consistency से संबंधित।

14. Impedance

Impedance किसी electrical component/system द्वारा alternating electrical signal के flow के विरुद्ध प्रस्तुत कुल opposition को दर्शाती है। इसे सामान्यतः Z से represent किया जाता है और इसकी unit Ohm (Ω) है।

Sensor को signal-conditioning या measurement circuit से connect करते समय sensor की electrical impedance important हो सकती है, क्योंकि loading effect measurement को प्रभावित कर सकता है।

Measurement Point: Sensor और measuring circuit की impedance compatibility signal accuracy और signal transfer के लिए important है।

15. Backlash

Backlash mechanical systems में direction बदलने पर lost motion या play के कारण input और output के बीच होने वाली discrepancy को दर्शाता है। यह gears, linkages और mechanical measuring mechanisms में विशेष रूप से देखा जा सकता है।

Example: किसी mechanical position mechanism को एक direction में move करने के बाद reverse direction में थोड़ा movement करने पर output तुरंत respond न करे, तो यह backlash के कारण हो सकता है।

16. Response Time

Response Time input में change होने के बाद sensor output को required final/steady response के specified level तक पहुँचने में लगने वाला समय है।

Example: यदि temperature अचानक बदलने पर sensor को stable reading देने में 2 seconds लगते हैं, तो application में response time लगभग 2 seconds के order का हो सकता है।

Fast-changing applications में fast response time वाला sensor अधिक suitable हो सकता है।

17. Dead Band

Dead Band input का वह range/region है जिसमें input change होने के बावजूद output में measurable या appreciable change नहीं होता।

Example: यदि किसी device में input में बहुत छोटा change output को प्रभावित नहीं करता और एक threshold पार करने के बाद response शुरू होता है, तो threshold के आसपास का insensitive region dead band हो सकता है।
Note: Dead band को resolution से confuse न करें। Resolution smallest distinguishable change से संबंधित है, जबकि dead band input region में response के absent/insignificant होने से संबंधित है।

18. Signal Transmission

Sensor से प्राप्त signal को processing, monitoring या control system तक पहुँचाना Signal Transmission का हिस्सा है। Industrial systems में signal को suitable form में condition और transmit किया जाता है ताकि distance पर भी reliable communication हो सके।

Basic Flow

  ↓
Transmission Medium
  ↓

Transmission Medium

  • Wired cable
  • Twisted pair
  • Coaxial cable
  • Optical fiber
  • Wireless/RF communication

19. Types of Signal

1. Analog Signal

Analog signal continuous form में vary करता है और measured quantity के साथ continuously change हो सकता है।

Temperature → Sensor → 0–10 V Analog Signal

2. Digital Signal

Digital signal discrete values/bits के रूप में information represent करता है।

Sensor → Digital Interface → Controller

3. Electrical Signal

Voltage या current के रूप में electrical signal transmission में उपयोग किया जा सकता है।

4. Pneumatic Signal

कुछ industrial instrumentation systems में pressure-based pneumatic signals का उपयोग किया जाता है।

5. Wireless Signal

Wireless sensors radio/wireless communication के माध्यम से data भेज सकते हैं।

Signal TypeGeneral ExampleUse
Analog Voltage0–10 VContinuous measurement
Analog Current4–20 mAIndustrial instrumentation
DigitalDigital data/bitsControllers and digital systems
PneumaticPressure signalIndustrial control environments
WirelessRF-based dataRemote sensing/IoT

  • Primary measuring element measurand के साथ initial/direct sensing interaction करता है।
  • Range minimum से maximum measurable input limits को दर्शाता है।
  • Resolution smallest detectable/distinguishable input change है।
  • Sensitivity = Change in Output / Change in Input.
  • Error measured value और true/reference value के बीच difference है।
  • Repeatability repeated measurements की consistency है।
  • Linearity actual response और ideal linear relationship के deviation से संबंधित है।
  • Accuracy true/reference value के closeness को दर्शाती है।
  • Impedance electrical signal के flow के विरुद्ध opposition से संबंधित है।
  • Backlash mechanical direction reversal में lost motion/play से संबंधित है।
  • Response time required sensor response तक पहुँचने में लगने वाला time है।
  • Dead band वह input region है जिसमें output में appreciable change नहीं होता।
  • Signals analog, digital, electrical, pneumatic या wireless forms में transmit हो सकते हैं।
