1. Web of Things (WoT) — Introduction

Web of Things (WoT) का मुख्य उद्देश्य Internet-connected devices और physical things को Web technologies के साथ accessible और interoperable बनाना है। WoT, existing Web concepts जैसे HTTP, URIs, REST और Web APIs का उपयोग करके connected things के साथ interaction को आसान बनाने की दिशा में काम करता है।

Exam Definition: Web of Things एक approach है जिसमें physical/IoT things को Web technologies और Web architecture के माध्यम से discover, access और interact किया जा सकता है।

सरल शब्दों में: IoT चीजों को connect करता है, जबकि WoT उन connected चीजों के interaction को Web के माध्यम से आसान बनाने पर focus करता है।

2. Web of Things versus Internet of Things

BasisInternet of Things (IoT)Web of Things (WoT)
Basic ideaPhysical devices/things को network और Internet से connect करना.Connected things को Web technologies और Web architecture से accessible/interoperable बनाना.
FocusConnectivity, sensing, communication और device ecosystem.Web-based interaction, discovery और application integration.
TechnologiesMQTT, CoAP, BLE, Zigbee, LoRaWAN आदि सहित अनेक IoT technologies.Web technologies जैसे HTTP, URI, REST और Web APIs का उपयोग किया जा सकता है.
AbstractionDevice/network details comparatively अधिक दिखाई दे सकते हैं.Web-oriented abstraction devices को applications के लिए easier बनाती है.
GoalThings को connect और communicate करना.Connected things को Web ecosystem में integrate और interact करना.
IoT: Thing → Network → Internet/Services

WoT: Thing → Web Interface/Description → Web Application
Remember: WoT को IoT का replacement नहीं समझना चाहिए। WoT, IoT ecosystem के ऊपर Web-based interaction और interoperability की layer/approach के रूप में समझा जा सकता है।

3. Two Pillars of the Web Architecture

Web Architecture को समझने के लिए syllabus में दिए गए Two Pillars को Web की मूल architectural ideas के रूप में समझना उपयोगी है। WoT इन्हीं Web principles का उपयोग connected things तक पहुंच बनाने के लिए करता है।

1. Identification / URI

Web पर resources की पहचान के लिए URI (Uniform Resource Identifier) का उपयोग होता है। WoT में किसी Thing या उसके resources/actions को identifiable Web resources के रूप में represent किया जा सकता है।

2. Interaction / Web Protocols

Web protocols और standard interaction mechanisms, जैसे HTTP, client और resource के बीच communication को define करते हैं। WoT इन्हें Things के interaction के लिए leverage कर सकता है।

Core idea: एक Web-based Thing को identify करने के लिए URI जैसी पहचान और उससे interact करने के लिए standard Web mechanisms दोनों महत्वपूर्ण हैं।

4. WoT में Web Architecture का उपयोग

Web Architecture की ताकत यह है कि applications को हर device के proprietary low-level communication mechanism को अलग-अलग समझने की आवश्यकता कम हो सकती है। WoT Web-based interface और descriptions के माध्यम से Things को application layer से connect करने में मदद करता है।

Thing/Sensor → WoT Interface & Description → Web/HTTP → Application
  • Identification: Thing/resources को unique Web-oriented identifiers से represent करना.
  • Representation: Thing की capabilities और interaction information को describe करना.
  • Interaction: Standard Web mechanisms से read/write/invoke जैसे operations support करना.
  • Integration: Web applications और services के साथ Things को जोड़ना.

5. Standardization for Web of Things

Standardization का उद्देश्य अलग-अलग vendors, platforms और devices के बीच common rules और interoperable mechanisms उपलब्ध कराना है। WoT में standardization important है क्योंकि IoT ecosystem में devices और protocols बहुत diverse हो सकते हैं।

Interoperability

Different devices और platforms के बीच common interaction संभव बनाना.

Reusability

Existing Web technologies और development patterns का reuse.

Discoverability

Things और उनकी capabilities को describe/discover करने में सहायता.

Scalability

बड़े और heterogeneous device ecosystem को manage करने में मदद.

Portability

Applications को particular vendor/device implementation से कम dependent बनाना.

Security

Communication, access और data protection के लिए standardized security considerations.

6. Platform Middleware for Web of Things

Platform Middleware वह intermediate software layer है जो underlying IoT devices/protocols और ऊपर की Web applications/services के बीच bridge का काम करती है।

इसका उद्देश्य hardware और network complexity को abstract करके application developers को common interfaces/services उपलब्ध कराना हो सकता है।

IoT Devices & Protocols → WoT Platform Middleware → Web APIs / Applications

Middleware के प्रमुख कार्य

  • Device Abstraction: Different devices की low-level details को hide करके common representation देना.
  • Protocol Adaptation: अलग communication technologies/protocols को application-friendly interfaces से connect करना.
  • Service Management: Device capabilities को services/resources के रूप में expose करना.
  • Data Handling: Device data को collect, transform और आगे applications तक पहुंचाने में मदद.
  • Discovery: Available Things/services को identify और discover करने में support.
  • Security Support: Authentication, authorization और secure communication जैसे mechanisms को support करना.

7. Platform Middleware का Working

WoT platform middleware को एक bridge की तरह समझा जा सकता है। नीचे basic working flow है:

Physical Thing
↓
Sensor / Actuator
↓
IoT Protocol / Local Network
↓
Platform Middleware
↓
Web Interface / API
↓
Web Application / User

Step 1: Sensor data generate करता है या actuator command receive करता है।

Step 2: Underlying IoT protocol/network device communication संभालता है।

Step 3: Middleware device-specific communication को abstract/adapt करता है।

Step 4: Thing की capabilities को Web-oriented interface/service के रूप में expose किया जा सकता है।

Step 5: Web application standard Web mechanisms के माध्यम से Thing से interact करती है।

8. IoT, WoT और Middleware का Relationship

Componentमुख्य भूमिका
IoTPhysical Things को sensing, actuation, communication और networking के माध्यम से connected ecosystem में लाना.
WoTConnected Things को Web technologies और Web-oriented interaction के माध्यम से applications के लिए accessible बनाना.
Platform MiddlewareUnderlying devices/protocols और Web applications के बीच abstraction, adaptation और service integration provide करना.
Easy Memory Trick: IoT = Connect Things → Middleware = Bridge/Abstract → WoT = Use Things through the Web.

9. Quick Revision

WoT

Web technologies के माध्यम से connected Things के interaction और integration की approach.

IoT vs WoT

IoT connectivity-focused ecosystem है; WoT Web-based interaction और interoperability पर focus करता है.

Web Pillar 1

Identification through URI/Web resource identification.

Web Pillar 2

Interaction through standard Web protocols/mechanisms such as HTTP.

Standardization

Interoperability, reusability, discoverability, scalability और security में सहायता.

Middleware

IoT devices/protocols और Web applications के बीच bridge और abstraction layer.

One-line flow: Things → IoT Connectivity → Middleware → Web Interface → Web Application.
