1. Arduino – Humidity Sensor

Humidity हवा में मौजूद water vapour की मात्रा को बताती है। Humidity sensor इस environmental condition को measure करता है। Arduino projects में DHT11/DHT22 जैसे sensor modules commonly used होते हैं।

Basic Working

Sensor humidity को sense करता है और module/digital interface के माध्यम से Arduino को reading देता है। Arduino उस reading को Serial Monitor पर दिखा सकता है या किसी output device को control कर सकता है।

Humidity
→
Humidity Sensor
→
Arduino
→
Display / Control

Example: DHT Sensor Reading

#include <DHT.h> #define DHTPIN 2 #define DHTTYPE DHT11 DHT dht(DHTPIN, DHTTYPE); void setup() { Serial.begin(9600); dht.begin(); } void loop() { float humidity = dht.readHumidity(); Serial.print("Humidity: "); Serial.print(humidity); Serial.println(" %"); delay(2000); }
Exam Point: Humidity sensor का main purpose environmental moisture/humidity को sense करना है। DHT-family modules temperature + humidity दोनों readings भी provide कर सकते हैं।

2. Arduino – Temperature Sensor

Temperature Sensor temperature को measure करने के लिए प्रयोग किया जाता है। Arduino के साथ LM35, TMP36 या digital temperature sensors जैसे अलग-अलग sensors use किए जा सकते हैं।

LM35 के साथ Basic Concept

LM35 एक analog temperature sensor है। यह temperature के अनुसार analog voltage देता है। Arduino का analogRead() उस voltage को ADC value में बदलकर पढ़ता है।

Arduino ADC reading → Sensor voltage → Temperature calculation

Example: LM35 with Arduino

const int sensorPin = A0; void setup() { Serial.begin(9600); } void loop() { int reading = analogRead(sensorPin); float voltage = reading * (5.0 / 1023.0); float temperatureC = voltage * 100.0; Serial.print("Temperature: "); Serial.print(temperatureC); Serial.println(" C"); delay(1000); }
Note: ऊपर का calculation typical 5V Arduino ADC reference और LM35 के approximately 10 mV/°C characteristic को assume करता है। Board/reference configuration बदलने पर calculation भी बदल सकती है।

3. Arduino – Water Detector / Sensor

Water Detector Sensor पानी या moisture की presence को detect करने के लिए प्रयोग किया जाता है। सामान्य water sensor module में conductive traces होते हैं। पानी traces के बीच conductivity बढ़ा सकता है, जिससे sensor output में बदलाव आता है।

Working Principle

Water touches sensor
→
Conductivity changes
→
Sensor output changes
→
Arduino detects

Example: Water Sensor + LED

const int waterPin = A0; const int ledPin = 13; void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); } void loop() { int value = analogRead(waterPin); Serial.print("Water Level/Value: "); Serial.println(value); if (value > 300) { digitalWrite(ledPin, HIGH); } else { digitalWrite(ledPin, LOW); } delay(500); }
Threshold: 300 केवल example threshold है। Actual sensor, water condition और circuit के अनुसार threshold experimentally/calibration से तय करना चाहिए।

4. Arduino – PIR Sensor

PIR (Passive Infrared) Sensor आसपास moving human/animal body से मिलने वाली infrared radiation में बदलाव को detect करता है। इसे motion detection के लिए widely used किया जाता है।

Working

PIR sensor स्वयं infrared signal transmit नहीं करता; इसलिए इसे Passive कहा जाता है। जब sensor के field of view में कोई warm object move करता है, तो infrared pattern में बदलाव होता है और sensor output बदल सकता है।

Human / Warm Object
→
PIR Sensor
→
HIGH/LOW Signal
→
Arduino

Example: Motion Activated LED

const int pirPin = 2; const int ledPin = 13; void setup() { pinMode(pirPin, INPUT); pinMode(ledPin, OUTPUT); Serial.begin(9600); } void loop() { int motion = digitalRead(pirPin); if (motion == HIGH) { digitalWrite(ledPin, HIGH); Serial.println("Motion detected"); } else { digitalWrite(ledPin, LOW); Serial.println("No motion"); } delay(200); }

Applications

  • Security alarm systems
  • Automatic lighting
  • Room occupancy detection
  • Energy-saving automation

5. Arduino – Ultrasonic Sensor

Ultrasonic Sensor high-frequency sound waves का उपयोग करके distance measure करता है। HC-SR04 इसका एक common educational module है।

Basic Pins

PinFunction
VCCPower supply
GNDGround
TRIGUltrasonic pulse initiate करने के लिए
ECHOReturned pulse का time बताता है

Working Principle

TRIG pulse
→
Ultrasonic wave
→
Object
→
Echo return

Arduino TRIG pin से pulse भेजता है। Sensor ultrasonic burst transmit करता है और reflected wave आने के बाद ECHO signal देता है। Arduino pulse duration से distance calculate कर सकता है।

Distance = (Time × Speed of Sound) / 2

/2 क्यों? क्योंकि sound wave object तक जाती है और फिर वापस sensor तक आती है; measured time round-trip time होता है।

Example: HC-SR04 Distance Measurement

const int trigPin = 9; const int echoPin = 10; void setup() { Serial.begin(9600); pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); } void loop() { digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); long duration = pulseIn(echoPin, HIGH); float distanceCm = duration * 0.0343 / 2; Serial.print("Distance: "); Serial.print(distanceCm); Serial.println(" cm"); delay(500); }
Exam Point: Ultrasonic sensor contact किए बिना object की दूरी measure कर सकता है, इसलिए इसे non-contact distance measurement में use किया जाता है।

6. Arduino – Connecting Switch (Magnetic Relay Switches)

Magnetic switch magnetic field की presence के आधार पर switching करता है। एक common example Reed Switch है। Reed switch में contacts magnetic field के कारण open/close हो सकते हैं।

Reed Switch Working

Magnet nearby
→
Reed Switch changes state
→
Arduino reads input
→
Action

Simple Connection Concept

Reed switch को Arduino digital input के साथ connect किया जा सकता है। Input को stable रखने के लिए internal pull-up resistor का उपयोग किया जा सकता है।

Example: Door Open/Close Detection

const int switchPin = 2; const int ledPin = 13; void setup() { pinMode(switchPin, INPUT_PULLUP); pinMode(ledPin, OUTPUT); Serial.begin(9600); } void loop() { int state = digitalRead(switchPin); if (state == LOW) { Serial.println("Magnet detected / Switch closed"); digitalWrite(ledPin, HIGH); } else { Serial.println("Switch open"); digitalWrite(ledPin, LOW); } delay(200); }
Terminology: “Magnetic switch” और “relay” एक ही component नहीं हैं। Reed switch magnetic field से contacts operate करता है; relay electrically controlled switch है जिसमें coil electromagnetic force से contacts operate करती है। यदि syllabus में “magnetic relay switches” लिखा है, तो practical component की exact type को identify करना जरूरी है।

Applications

  • Door/window open-close detection
  • Security systems
  • Position sensing
  • Magnetic presence detection

General Sensor Interfacing Steps

  1. Sensor का purpose और output type समझें।
  2. VCC और GND सही connect करें।
  3. Signal pin को सही Arduino pin से connect करें।
  4. Code में pinMode() या संबंधित sensor library setup करें।
  5. Sensor data को digitalRead(), analogRead(), pulseIn() या library function से read करें।
  6. Reading के आधार पर required action perform करें।
  7. Threshold/calibration को actual hardware के अनुसार test करें।
