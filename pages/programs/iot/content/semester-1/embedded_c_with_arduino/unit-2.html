2.1

Arduino Data Types

Data Type यह बताता है कि variable में किस प्रकार का data store किया जाएगा और उसे memory में किस प्रकार represent किया जाएगा। Arduino programming C/C++ आधारित होने के कारण विभिन्न standard data types उपलब्ध होते हैं।

Data TypeउपयोगExample
booleanTrue/False या logical state store करने के लिए। Arduino environment में इसका उपयोग commonly किया जाता है।boolean ledOn = true;
charएक character store करने के लिए।char grade = 'A';
byte0 से 255 तक unsigned integer value के लिए।byte level = 200;
intInteger values के लिए।int count = 25;
unsigned intNon-negative integer values के लिए।unsigned int count = 500;
longबड़ी integer values के लिए।long distance = 100000;
unsigned longबड़ी non-negative integer values के लिए; timing values में भी उपयोगी।unsigned long t = millis();
floatDecimal/floating-point values के लिए।float temp = 27.5;
doubleFloating-point values के लिए; exact size/precision board architecture पर depend कर सकती है।double value = 12.75;
StringText को convenient object form में store/process करने के लिए Arduino environment में उपलब्ध class।String name = "Arduino";
Exam Point: Embedded programming में data type का चुनाव memory usage और required range को ध्यान में रखकर करना चाहिए।

Type Conversion

int a = 10;
float b = 3.0;
float result = a / b;

जब अलग-अलग numeric types expression में आते हैं, C/C++ conversion rules के अनुसार values convert हो सकती हैं। सही result के लिए type और integer division का ध्यान रखना जरूरी है।

2.2

Variables और Constants

Variable क्या है?

Variable memory का एक named location है जिसमें program के दौरान बदलने वाली value store की जाती है।

int temperature = 25;
temperature = 30;

ऊपर temperature variable की value बाद में बदली गई है।

Variable Declaration और Initialization

int count;          // Declaration
count = 10;         // Assignment

int speed = 50;     // Declaration + Initialization

Constant

Constant ऐसी value है जिसे program के intended use में बदलना नहीं चाहिए। C/C++ में const keyword से read-only variable declare किया जा सकता है।

const int ledPin = 13;
const float PI = 3.14159;
VariableConstant
Value बदल सकती है।Declared value को program में बदलने से रोका जाता है।
Dynamic data के लिए उपयोगी।Fixed configuration values के लिए उपयोगी।
Example: sensor readingExample: pin number या fixed threshold

Scope का Concept

Scope बताता है कि variable को program के किस हिस्से में access किया जा सकता है। Local variable function/block के अंदर सीमित होता है, जबकि global variable सामान्यतः कई functions से accessible हो सकता है।

int ledPin = 13;  // Global

void setup() {
  int x = 10;     // Local to setup()
}

Operator एक symbol/keyword है जो values या variables पर कोई operation perform करता है।

1. Arithmetic Operators

Operatorकार्यExample

-Subtractiona-b

2. Relational Operators

==, !=, >, <, >=, <= comparisons के लिए उपयोग होते हैं और condition का result देते हैं।

3. Logical Operators

OperatorMeaning

=, +=, -=, *=, /=, %=

Example: Bitwise operations registers और hardware-level flags को manipulate करने में उपयोगी हो सकते हैं।
2.4

Control Statements

Control statements program के execution flow को control करते हैं। इनके द्वारा program conditions के आधार पर अलग-अलग statements execute कर सकता है।

if Statement

if (temperature > 30) {
  digitalWrite(13, HIGH);
}

if-else Statement

if (value > 500) {
  digitalWrite(13, HIGH);
} else {
  digitalWrite(13, LOW);
}

else-if Ladder

if (value < 300) {
  level = 1;
} else if (value < 700) {
  level = 2;
} else {
  level = 3;
}

Nested if

if (sensorOK) {
  if (value > 500) {
    digitalWrite(13, HIGH);
  }
}

switch-case

जब किसी expression की value के आधार पर कई fixed cases में से एक चुनना हो, तब switch उपयोगी है।

int mode = 2;

switch (mode) {
  case 1:
    Serial.println("Manual");
    break;
  case 2:
    Serial.println("Auto");
    break;
  default:
    Serial.println("Invalid");
}

break और continue

  • break loop या switch से बाहर निकलने के लिए।
  • continue current loop iteration के remaining statements को skip करके next iteration पर जाने के लिए।
2.5

Loops

Loop का उपयोग किसी statement/block को बार-बार execute करने के लिए किया जाता है। Arduino projects में loops बहुत महत्वपूर्ण हैं क्योंकि embedded program को repeated operations करने होते हैं।

1. for Loop

for (int i = 0; i < 5; i++) {
  Serial.println(i);
}

for loop तब उपयोगी है जब iterations की संख्या पहले से ज्ञात या controlled हो।

2. while Loop

int i = 0;

while (i < 5) {
  Serial.println(i);
  i++;
}

Condition true रहने तक statements execute होते हैं।

3. do-while Loop

int i = 0;

do {
  Serial.println(i);
  i++;
} while (i < 5);

do-while में body कम-से-कम एक बार execute होती है क्योंकि condition बाद में check होती है।

LoopCondition Checkमुख्य उपयोग
forIteration शुरू होने से पहलेKnown/repeat count
whileIteration शुरू होने से पहलेCondition-based repetition
do-whileBody के बादAt least one execution आवश्यक हो
Embedded Warning: Arduino में uncontrolled infinite loops या blocking delays project responsiveness को प्रभावित कर सकते हैं। Program flow carefully design करें।
2.6

Arrays

Array एक ही data type की multiple values को एक नाम के अंतर्गत store करने की सुविधा देता है। C/C++ में array indexing सामान्यतः 0 से शुरू होती है।

int marks[5] = {70, 80, 65, 90, 75};

Serial.println(marks[0]);  // 70
Serial.println(marks[3]);  // 90

Array Declaration

int values[5];
int numbers[] = {10, 20, 30, 40};

Array Traversal

int values[5] = {10,20,30,40,50};

for (int i = 0; i < 5; i++) {
  Serial.println(values[i]);
}

Two-Dimensional Array

int matrix[2][3] = {
  {1, 2, 3},
  {4, 5, 6}
};
ConceptExample
First elementarr[0]
Third elementarr[2]
Array size 5int arr[5]
Last index of size 54
Important: Array के valid index से बाहर access करने पर undefined/incorrect behavior हो सकता है।
2.7

Pointers

Pointer ऐसा variable है जो किसी अन्य object/variable के memory address को store करता है। Embedded C/C++ में pointers hardware-oriented programming और efficient data handling के लिए महत्वपूर्ण हैं।

int value = 25;
int *ptr = &value;

Serial.println(value);
Serial.println(*ptr);

यहाँ &value से value का address प्राप्त होता है और *ptr से pointer के माध्यम से stored value access की जाती है।

Pointer के मुख्य Operators

OperatorMeaning
&Address-of operator — variable का address देता है।
*Dereference operator — pointer द्वारा referenced value access करता है।

Pointer Example with Function

void changeValue(int *p) {
  *p = 100;
}

void setup() {
  int x = 20;
  changeValue(&x);
}

इस example में function को variable का address दिया गया, इसलिए function pointer के माध्यम से original variable की value बदल सकता है।

Safety: Invalid/uninitialized pointer को dereference करना dangerous है और unexpected behavior कर सकता है।
2.8

Strings

String text/characters की sequence होती है। Arduino programming में strings को मुख्यतः C-style character arrays या Arduino String class के रूप में handle किया जा सकता है।

1. C-style String

char name[] = "Arduino";

C-style string एक character array होता है जिसके अंत में null character '\0' होता है।

2. Arduino String Object

String name = "Arduino";
String message = "Hello " + name;

Serial.println(message);

Useful String Operations

String text = "Arduino";

text.length();
text.charAt(0);
text.substring(0, 4);
text.indexOf("du");
text.toUpperCase();
text.toLowerCase();
Method/Conceptकार्य
length()String की length प्राप्त करना।
charAt()किसी position का character प्राप्त करना।
substring()String का एक भाग निकालना।
indexOf()Character/text की position खोजना।
Embedded Point: छोटे memory वाले microcontrollers पर बहुत अधिक dynamic String operations memory fragmentation का कारण बन सकते हैं। Resource-constrained projects में fixed-size character buffers भी उपयोग किए जाते हैं।
2.9

Functions

Function program का reusable block है जो किसी specific task को perform करता है। Functions program को modular, readable और maintainable बनाते हैं।

Function के मुख्य भाग

Return Type → Function Name → Parameters ↓ Function Body ↓ return

Function without Parameter

void blinkLED() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

Function with Parameters

void setLED(int pin, int state) {
  digitalWrite(pin, state);
}

Function with Return Value

int addNumbers(int a, int b) {
  return a + b;
}

void setup() {
  int result = addNumbers(10, 20);
}

Function Prototype

Function को call करने से पहले उसका prototype declare किया जा सकता है।

int addNumbers(int a, int b);

void setup() {
  int x = addNumbers(5, 7);
}

int addNumbers(int a, int b) {
  return a + b;
}

Arduino special functions: setup() और loop() Arduino programming framework द्वारा defined structure का हिस्सा हैं। User-defined functions के अलावा इनका उपयोग लगभग हर basic Arduino sketch में होता है।

Integrated Example – Variables + Operators + Control + Loop + Array + Function

नीचे एक छोटा example कई programming basics को एक साथ demonstrate करता है।

int values[5] = {100, 200, 300, 400, 500};
const int ledPin = 13;

int calculateAverage() {
  long total = 0;

  for (int i = 0; i < 5; i++) {
    total += values[i];
  }

  return total / 5;
}

void setup() {
  pinMode(ledPin, OUTPUT);

  int average = calculateAverage();

  if (average > 250) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

void loop() {
}

Quick Revision – परीक्षा के लिए

  • Data Type: Data की type और representation define करता है।
  • Variable: ऐसी named storage location जिसकी value बदल सकती है।
  • Constant: Fixed/read-only value को represent करता है।
  • Operator: Data पर operation perform करता है।
  • if/else: Conditions के आधार पर execution control करता है।
  • switch: Multiple fixed cases में selection के लिए।
  • for: Controlled/repeated iterations के लिए।
  • while: Condition true रहने तक repetition।
  • do-while: Body कम-से-कम एक बार execute होती है।
  • Array: Same type की multiple values को एक नाम के अंतर्गत store करता है।
  • Pointer: Memory address store करता है।
  • String: Characters/text की sequence है।
  • Function: Reusable program block है।
  • setup(): Arduino sketch initialization के लिए सामान्यतः एक बार execute होता है।
  • loop(): Main program logic को repeatedly execute करता है।
