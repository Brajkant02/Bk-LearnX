5.1

Working with Serial Monitor

Serial Monitor Arduino IDE का एक tool है जिसका उपयोग Arduino board और computer के बीच serial communication के माध्यम से data भेजने और receive करने के लिए किया जाता है। यह debugging, sensor values देखने और user input test करने में बहुत उपयोगी है।

Serial Communication शुरू करना

void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.println("Hello Arduino");
  delay(1000);
}

Serial.begin(9600) serial communication की baud rate set करता है। Serial Monitor में वही baud rate select करनी चाहिए जो program में configured है।

Common Serial Functions

Functionकार्यExample
Serial.begin()Serial communication initialize करता है।Serial.begin(9600);
Serial.print()Data print करता है, सामान्यतः नई line के बिना।Serial.print(value);
Serial.println()Data print करके next line पर जाता है।Serial.println(value);
Serial.write()Serial stream पर bytes/data भेजने के लिए।Serial.write(65);
Serial.available()Receive buffer में available data check करने के लिए।Serial.available();
Serial.read()Available incoming byte को read करने के लिए।Serial.read();

Sensor Value Display

void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(A0);
  Serial.print("Sensor: ");
  Serial.println(value);
  delay(500);
}
Use: Serial Monitor physical LCD की तरह standalone display नहीं है; यह computer पर serial data देखने का development/debugging interface है।
5.2

Line Graph via Serial Monitor

Serial data को समय के साथ plot करके sensor values का line graph देखा जा सकता है। Arduino IDE के versions/features के अनुसार serial plotting interface का नाम या location अलग हो सकता है। कुछ environments में Serial Plotter feature उपलब्ध होता है।

Basic Sensor Plot Data

void setup() {
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(A0);
  Serial.println(sensorValue);
  delay(100);
}

हर line पर एक numeric value भेजने से plotting tool इन values को time sequence के रूप में visualize कर सकता है।

Multiple Values

void loop() {
  int sensor1 = analogRead(A0);
  int sensor2 = analogRead(A1);

  Serial.print(sensor1);
  Serial.print(" ");
  Serial.println(sensor2);

  delay(100);
}

Multiple series plot करने के लिए plotting tool द्वारा supported separator/format का उपयोग करना चाहिए। Arduino IDE के संबंधित version में supported Serial Plotter format verify करना useful है।

Sensor Value │ /\ │ /\ / \ /\ │ / \/ \_____ / \ └────────────────────────→ Time
Application: Temperature, light intensity, potentiometer या अन्य changing sensor readings को समय के साथ observe करने के लिए line graph useful है।
5.3

Interfacing an 8-bit LCD to Arduino

Character LCD एक electronic display है जो characters और simple text दिखा सकता है। Common 16×2 LCD में 2 rows और प्रत्येक row में 16 character positions होती हैं। 8-bit mode में LCD का data transfer आठ data lines के माध्यम से होता है।

8-bit Mode का Concept

LCD के data pins D0–D7 को Arduino के आठ digital pins से connect किया जाता है। इसके अलावा control pins RS और E उपयोग होते हैं। R/W pin को application के अनुसार control किया जा सकता है; write-only basic setup में इसे GND से connect करना common arrangement है।

Arduino 16×2 LCD -------- -------- Digital pins → D0 D1 D2 D3 D4 D5 D6 D7 Digital pin → RS Digital pin → E GND / control → R/W (write-only setup) Power → VSS / VDD Contrast → V0 Backlight → LED pins (module-specific)

मुख्य LCD Pins

Pin/Signalकार्य
VSSGround connection।
VDDLCD supply voltage, module specification के अनुसार।
V0 / VEEContrast adjustment के लिए।
RSRegister Select; command और data selection में उपयोग।
R/WRead/Write control।
EEnable signal; data/command transfer को latch करने में सहायता।
D0–D78-bit data bus।

Hardware Note: LCD module की exact voltage/backlight requirements model के अनुसार check करें। Arduino और LCD के grounds common रखना आवश्यक होता है।
5.4

8-bit LCD Connection और Architecture

8-bit interfacing में eight data lines के कारण अधिक Arduino GPIO pins की आवश्यकता होती है। इसका advantage simple full-byte data transfer है, जबकि disadvantage यह है कि 4-bit mode की तुलना में अधिक pins consume होती हैं।

Typical Example Connection

LCDArduino Example PinPurpose
RSD12Register selection
ED11Enable
D0–D7D10–D38-bit data bus
R/WGNDWrite-only configuration

ऊपर केवल एक example mapping दिया गया है; Arduino के available pins और project circuit के अनुसार mapping बदली जा सकती है। Code में वही mapping consistently define करनी होती है।

5.5

Fixed One-Line Static Message Display

Static message वह text है जो LCD पर fixed position पर display रहता है और continuously move नहीं करता। Arduino की LiquidCrystal library से character LCD को control करना आसान हो जाता है।

8-bit LiquidCrystal Example

#include <LiquidCrystal.h>

const int rs = 12;
const int en = 11;
const int d0 = 10;
const int d1 = 9;
const int d2 = 8;
const int d3 = 7;
const int d4 = 6;
const int d5 = 5;
const int d6 = 4;
const int d7 = 3;

LiquidCrystal lcd(rs, en, d0, d1, d2, d3, d4, d5, d6, d7);

void setup() {
  lcd.begin(16, 2);
  lcd.setCursor(0, 0);
  lcd.print("BK LearnX");
}

void loop() {
}

यहाँ lcd.begin(16,2) 16 columns और 2 rows वाले LCD को initialize करता है। setCursor() cursor position set करता है और print() message display करता है।

Expected display:

BK LearnX

5.6

Running Message Display

Running message में text display की position समय के साथ बदलती रहती है, जिससे message scrolling/moving दिखाई देता है। Arduino LiquidCrystal library में scrollDisplayLeft() और scrollDisplayRight() जैसे functions available हैं।

Simple Running Message

#include <LiquidCrystal.h>

LiquidCrystal lcd(12, 11, 10, 9, 8, 7, 6, 5, 4, 3);

void setup() {
  lcd.begin(16, 2);
  lcd.print("Welcome to BK LearnX");
}

void loop() {
  lcd.scrollDisplayLeft();
  delay(300);
}

हर iteration में display को left scroll किया जाता है। Delay scrolling की visible speed control करता है।

Alternative: Cursor Based Moving Text

#include <LiquidCrystal.h>

LiquidCrystal lcd(12,11,10,9,8,7,6,5,4,3);

void setup() {
  lcd.begin(16, 2);
}

void loop() {
  for (int pos = 15; pos >= 0; pos--) {
    lcd.clear();
    lcd.setCursor(pos, 0);
    lcd.print("HELLO");
    delay(200);
  }
}
Note: lcd.clear() को बहुत तेजी से repeatedly call करने पर display flicker हो सकता है। Better scrolling design में unnecessary clearing से बचना useful है।
5.7

Using the LCD Library of Arduino

LiquidCrystal library character LCD modules के साथ common interface operations को आसान बनाती है। इससे programmer को LCD के low-level command timing को manually manage करने की आवश्यकता कम होती है।

Library Include

#include <LiquidCrystal.h>

Object Creation – 8-bit Mode

LiquidCrystal lcd(rs, en, d0, d1, d2, d3, d4, d5, d6, d7);

Important Functions

Functionकार्यExample
lcd.begin(cols, rows)LCD dimensions/configuration initialize करना।lcd.begin(16,2);
lcd.print()Text/values display करना।lcd.print("Hello");
lcd.setCursor(col,row)Cursor की position set करना।lcd.setCursor(0,1);
lcd.clear()Display content clear करना।lcd.clear();
lcd.home()Cursor को home position पर ले जाना।lcd.home();
lcd.noDisplay()Display visibility off करना।lcd.noDisplay();
lcd.display()Display visibility on करना।lcd.display();
lcd.cursor()Cursor display करना।lcd.cursor();
lcd.noCursor()Cursor hide करना।lcd.noCursor();
lcd.blink()Cursor blink enable करना।lcd.blink();
lcd.noBlink()Cursor blinking disable करना।lcd.noBlink();
lcd.scrollDisplayLeft()Display content को left scroll करना।lcd.scrollDisplayLeft();
lcd.scrollDisplayRight()Display content को right scroll करना।lcd.scrollDisplayRight();

Arduino Sketch ↓ LiquidCrystal Library ↓ Control Signals + Data ↓ LCD Controller ↓ Character Display

Practical Examples

Example 1: Static Two-Line Message

#include <LiquidCrystal.h>

LiquidCrystal lcd(12,11,10,9,8,7,6,5,4,3);

void setup() {
  lcd.begin(16, 2);

  lcd.setCursor(0, 0);
  lcd.print("BK LearnX");

  lcd.setCursor(0, 1);
  lcd.print("Arduino Unit 5");
}

void loop() {
}

Example 2: Analog Value on LCD

#include <LiquidCrystal.h>

LiquidCrystal lcd(12,11,10,9,8,7,6,5,4,3);

void setup() {
  lcd.begin(16, 2);
}

void loop() {
  int value = analogRead(A0);

  lcd.setCursor(0, 0);
  lcd.print("Sensor:       ");
  lcd.setCursor(8, 0);
  lcd.print(value);

  delay(300);
}

यह example analog sensor value को LCD पर display करता है। पुराने characters हटाने के लिए पर्याप्त spaces या controlled update technique उपयोग की जा सकती है।

Example 3: Serial + LCD Together

#include <LiquidCrystal.h>

LiquidCrystal lcd(12,11,10,9,8,7,6,5,4,3);

void setup() {
  Serial.begin(9600);
  lcd.begin(16, 2);
}

void loop() {
  int value = analogRead(A0);

  Serial.println(value);

  lcd.setCursor(0, 0);
  lcd.print("Value: ");
  lcd.print(value);
  lcd.print("   ");

  delay(500);
}

एक ही sensor data को computer के Serial Monitor और physical LCD दोनों पर observe किया जा सकता है।

Quick Revision – परीक्षा के लिए

  • Serial Monitor: Arduino और computer के बीच serial data को देखने/भेजने का development tool।
  • Serial.begin(): Serial communication initialize करता है।
  • Serial.print()/println(): Data output करने के लिए।
  • Line Graph: Sensor values को time sequence में plot करके changing signal visualize किया जा सकता है।
  • 8-bit LCD: D0–D7 आठ data lines का उपयोग करता है।
  • RS: Command/data selection से संबंधित control signal।
  • R/W: LCD read/write control।
  • E: Enable control signal।
  • Static Message: Fixed position पर text display।
  • Running Message: Text को scrolling/moving form में display करना।
  • LiquidCrystal: Character LCD control को आसान बनाने वाली Arduino library।
  • lcd.begin(): LCD initialize/configure करता है।
  • lcd.setCursor(): Cursor position set करता है।
  • lcd.print(): Text/data display करता है।
  • lcd.clear(): Display content clear करता है।
One-Line Revision: Arduino Displays = Serial Monitor for computer-side output + Serial Plotting for trends + LCD interfacing for physical text display + LiquidCrystal library for easy LCD control.
