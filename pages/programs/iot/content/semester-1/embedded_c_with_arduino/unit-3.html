3.1

Pins Configured as INPUT

Arduino का digital pin external device से signal प्राप्त करने के लिए INPUT mode में configure किया जा सकता है। उदाहरण के लिए push button, switch या digital sensor का signal input pin पर पढ़ा जा सकता है।

Input mode में microcontroller pin की logic state को read करता है। सामान्य digital input में signal को HIGH या LOW के रूप में interpret किया जाता है।

Syntax

pinMode(pin, INPUT);

Example

const int buttonPin = 2;

void setup() {
  pinMode(buttonPin, INPUT);
}

void loop() {
  int state = digitalRead(buttonPin);
}

यहाँ pin 2 को input बनाया गया है और digitalRead() से उसकी current digital state पढ़ी जा सकती है।

महत्वपूर्ण: Floating input pin की state unpredictable हो सकती है। इसलिए button/switch circuits में suitable pull-up या pull-down arrangement उपयोग किया जाता है।
3.2

Pull-up Resistors

Pull-up resistor input pin को default HIGH logic level पर रखने के लिए उपयोग किया जाता है, जब external switch/signal उसे LOW की ओर नहीं खींच रहा हो। यह floating input की समस्या को कम करता है।

Internal Pull-up

Arduino में कई boards पर internal pull-up resistor को INPUT_PULLUP mode के माध्यम से enable किया जा सकता है। इससे external resistor की आवश्यकता कई simple button circuits में नहीं रहती।

const int buttonPin = 2;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
}

void loop() {
  int state = digitalRead(buttonPin);

  if (state == LOW) {
    // Button pressed
  }
}
Arduino Pin 2 ───── Button ───── GND | └── Internal Pull-up → HIGH when button is open Button OPEN → HIGH Button PRESSED → LOW
ध्यान दें: INPUT_PULLUP में logic अक्सर inverted होता है—button release पर HIGH और press पर LOW।

Pull-up क्यों आवश्यक है?

  • Input को defined default state देने के लिए।
  • Floating input से आने वाले random readings को कम करने के लिए।
  • Simple switches/buttons को reliable digital input बनाने के लिए।
3.3

Pins Configured as OUTPUT

जब Arduino pin से external component को digital control signal देना हो, तब pin को OUTPUT mode में configure किया जाता है। LED, suitable logic input या driver circuit जैसे applications में इसका उपयोग किया जाता है।

Syntax

pinMode(pin, OUTPUT);

Example

const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);

  digitalWrite(ledPin, LOW);
  delay(1000);
}

यह example output pin को HIGH और LOW करके LED को ON/OFF control करने की basic technique दिखाता है।

Electrical Safety: Arduino GPIO pin से केवल उसके specified current/voltage limits के भीतर load connect करें। Motor, relay coil या high-current device को direct GPIO से drive करने के बजाय suitable driver/transistor/MOSFET/module का उपयोग करें।
3.4

pinMode() Function

pinMode() Arduino का fundamental function है। इसका उपयोग किसी digital pin को INPUT, OUTPUT या supported boards पर अन्य supported mode में configure करने के लिए किया जाता है।

Syntax

pinMode(pin, mode);
ArgumentMeaningExample
pinजिस pin को configure करना है।13
modePin का operating mode।INPUT, OUTPUT, INPUT_PULLUP

Common Modes

ModeUse
INPUTExternal digital signal पढ़ने के लिए।
OUTPUTDigital output signal देने के लिए।
INPUT_PULLUPInternal pull-up enabled input के लिए, जहाँ board support करता है।
Remember: सामान्य digital pin को input/output के रूप में उपयोग करने से पहले उचित mode configure करना अच्छी practice है।
3.5

digitalWrite() Function

digitalWrite() digital output pin पर HIGH या LOW logic level set करने के लिए उपयोग होता है। यह तभी meaningful है जब pin को appropriate output mode में configure किया गया हो।

Syntax

digitalWrite(pin, value);
ValueMeaning
HIGHDigital HIGH state set करना।
LOWDigital LOW state set करना।

LED Example

const int led = 13;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  digitalWrite(led, HIGH);
  delay(500);
  digitalWrite(led, LOW);
  delay(500);
}

Button से LED Control

const int button = 2;
const int led = 13;

void setup() {
  pinMode(button, INPUT_PULLUP);
  pinMode(led, OUTPUT);
}

void loop() {
  if (digitalRead(button) == LOW) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }
}
3.6

analogRead() Function

analogRead() का उपयोग analog input pin से voltage level को ADC के माध्यम से digital numeric value के रूप में पढ़ने के लिए किया जाता है। यह sensors जैसे potentiometer, LDR और कुछ analog-output sensors के साथ बहुत उपयोगी है।

Syntax

int value = analogRead(pin);

Arduino Uno जैसे 10-bit ADC वाले board पर सामान्य reading range 0 से 1023 होती है। Reading का voltage interpretation reference voltage और board configuration पर depend करता है।

Example

const int sensorPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(sensorPin);

  Serial.println(value);
  delay(500);
}

Working Flow

Analog Sensor ↓ Analog Input Pin (A0) ↓ ADC ↓ Digital Numeric Value ↓ Program Processing ↓ Output / Decision
Important: analogRead() analog input reading के लिए है। यह digital HIGH/LOW reading के लिए नहीं है; digital state के लिए digitalRead() उपयोग किया जाता है।
3.7

Arduino Interrupts

Interrupt ऐसी mechanism है जिससे microcontroller किसी important external/internal event को detect करके वर्तमान normal execution flow को temporarily interrupt कर सकता है और एक special function, जिसे ISR (Interrupt Service Routine) कहा जाता है, execute कर सकता है। Event handling के बाद program सामान्य execution पर लौट सकता है।

Interrupt की आवश्यकता

यदि program लगातार किसी event को check करता रहे तो उसे polling कहते हैं। Interrupt approach में supported hardware event होने पर processor को event की सूचना मिलती है, जिससे fast event response संभव हो सकता है।

Normal Program ↓ Interrupt Event ↓ ISR executes ↓ Return to normal program

attachInterrupt()

Arduino framework में external interrupt को configure करने के लिए commonly attachInterrupt() function उपयोग किया जाता है।

attachInterrupt(digitalPinToInterrupt(pin), ISR, mode);
PartMeaning
digitalPinToInterrupt(pin)Pin को corresponding interrupt number में map करने का convenient तरीका।
ISRInterrupt आने पर execute होने वाला function।
modeकिस signal condition पर interrupt trigger हो: RISING, FALLING, CHANGE, या supported board पर LOW आदि।

Interrupt Example

const int ledPin = 13;
const int buttonPin = 2;

volatile bool eventDetected = false;

void handleInterrupt() {
  eventDetected = true;
}

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);

  attachInterrupt(
    digitalPinToInterrupt(buttonPin),
    handleInterrupt,
    FALLING
  );
}

void loop() {
  if (eventDetected) {
    eventDetected = false;
    digitalWrite(ledPin, !digitalRead(ledPin));
  }
}

इस example में button event interrupt trigger करता है। ISR केवल एक छोटा flag set करता है और main loop() actual processing करता है।

ISR में सावधानियाँ

  • ISR को छोटा और fast रखना चाहिए।
  • ISR के अंदर लंबे delay() या unnecessary processing से बचें।
  • Interrupt और main code के बीच shared variables के लिए volatile उपयोग किया जा सकता है।
  • Complex work को ISR के बजाय main loop में करने की बेहतर practice हो सकती है।
3.8

Practical Examples

Example 1: Push Button + LED

const int buttonPin = 2;
const int ledPin = 13;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(buttonPin);

  if (buttonState == LOW) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

Concept: Button = INPUT, internal pull-up = default HIGH, digitalRead() = input reading, digitalWrite() = LED control.

Example 2: Analog Sensor Threshold

const int sensorPin = A0;
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int sensorValue = analogRead(sensorPin);

  if (sensorValue > 600) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

यह example analog sensor reading को threshold के साथ compare करके digital output control करता है।

Example 3: Pin Mode Summary

pinMode(3, INPUT_PULLUP);
pinMode(13, OUTPUT);

3.10

Quick Revision – परीक्षा के लिए

  • INPUT: External signal पढ़ने के लिए pin mode।
  • OUTPUT: Digital control signal देने के लिए pin mode।
  • INPUT_PULLUP: Internal pull-up enable करके input को default HIGH रखने का convenient तरीका।
  • Pull-up resistor: Input को defined HIGH state की ओर रखता है।
  • pinMode(): Pin का operating mode configure करता है।
  • digitalWrite(): Digital output को HIGH/LOW set करता है।
  • analogRead(): Analog input को ADC द्वारा numeric value में पढ़ता है।
  • Interrupt: Important event पर normal execution को temporarily divert करके ISR execute करने की mechanism।
  • ISR: Interrupt event पर execute होने वाला छोटा handler function।
  • Polling: Program द्वारा repeatedly event/state check करना।
  • volatile: Interrupt/main code द्वारा shared variable के लिए compiler को value को हमेशा memory से observe करने की आवश्यकता बताने वाला qualifier।
One-Line Revision: Arduino I/O Programming = pinMode() से configuration + digitalRead()/analogRead() से input + digitalWrite() से digital output + Interrupts से event-driven response.
