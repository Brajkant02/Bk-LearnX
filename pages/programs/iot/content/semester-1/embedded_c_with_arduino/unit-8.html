Giving Input to the Controller

Introduction

Arduino में Input का अर्थ controller को किसी source से information या command देना है। Input serial communication, push buttons/keys और अन्य sensors से आ सकता है। Arduino input को process करके LED, buzzer, motor आदि output devices को control कर सकता है।

Input
→
Arduino Controller
→
Decision / Program
→
Output

इस unit में serial input तथा keys को input के रूप में लेकर LED और buzzer जैसे output devices को control करना समझाया गया है।

1. Using Serial Input

Serial Input में computer/serial device से Arduino को characters या data भेजा जाता है। Arduino का Serial interface इस data को receive करके program में use कर सकता है। Arduino IDE का Serial Monitor testing के लिए commonly उपयोग किया जाता है।

Important Serial Functions

Function Purpose
Serial.begin(9600) Serial communication की baud rate initialize करना
Serial.available() Receive buffer में available data की जानकारी देना
Serial.read() एक received byte/character read करना
Serial.print() Serial output भेजना
Serial.println() Serial output भेजकर new line देना

Example: Serial Character Read

void setup() { Serial.begin(9600); Serial.println("Send a key:"); } void loop() { if (Serial.available() > 0) { char key = Serial.read(); Serial.print("Received: "); Serial.println(key); } }
Concept: Serial.available() check करता है कि data receive हुआ है या नहीं, और फिर Serial.read() से received character पढ़ा जा सकता है।

2. Controlling LEDs with Keys

Keyboard/serial input में किसी specific key को command बनाकर Arduino LED को ON या OFF किया जा सकता है। उदाहरण के लिए 1 दबाने पर LED ON और 0 दबाने पर LED OFF।

Key '1' / '0'
→
Serial Input
→
Arduino
→
LED

Example

const int ledPin = 13; void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); Serial.println("Press 1 = ON, 0 = OFF"); } void loop() { if (Serial.available() > 0) { char key = Serial.read(); if (key == '1') { digitalWrite(ledPin, HIGH); Serial.println("LED ON"); } if (key == '0') { digitalWrite(ledPin, LOW); Serial.println("LED OFF"); } } }
Important: '1' और 1 अलग हैं। Serial Monitor से character read करने पर '1' जैसे character के साथ comparison किया जाता है।

3. Keys as Toggle Switch

Toggle का मतलब है एक ही key को बार-बार press करने पर output state बदलना। उदाहरण: पहली बार key दबाने पर LED ON, दूसरी बार उसी key को दबाने पर LED OFF, फिर ON और फिर OFF।

Toggle Logic

Key Press
→
Current State
→
Invert State
→
LED

Example: Serial Key as Toggle

const int ledPin = 13; bool ledState = false; void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); Serial.println("Press T to toggle LED"); } void loop() { if (Serial.available() > 0) { char key = Serial.read(); if (key == 'T' || key == 't') { ledState = !ledState; digitalWrite(ledPin, ledState); if (ledState) { Serial.println("LED ON"); } else { Serial.println("LED OFF"); } } } }
New State = NOT (Previous State)

यहाँ Boolean variable ledState output की current state store करता है। ! operator state को invert करता है।

4. Interfacing a Piezo Buzzer

Piezo Buzzer एक electronic sound-producing device है जो electrical signal मिलने पर sound उत्पन्न कर सकता है। Arduino के साथ इसे indication, alert और alarm applications में use किया जा सकता है।

Basic Connection Concept

Arduino Digital Pin
→
Piezo Buzzer
→
Sound

एक simple buzzer को suitable Arduino output pin से control किया जा सकता है। Exact module type के अनुसार active/passive buzzer की operation अलग हो सकती है।

Simple ON/OFF Example

const int buzzerPin = 8; void setup() { pinMode(buzzerPin, OUTPUT); } void loop() { digitalWrite(buzzerPin, HIGH); delay(500); digitalWrite(buzzerPin, LOW); delay(500); }

tone() Function

Passive piezo buzzer के साथ Arduino का tone() function specified frequency पर square-wave tone generate करने के लिए commonly used होता है।

const int buzzerPin = 8; void setup() { } void loop() { tone(buzzerPin, 1000); // 1000 Hz delay(500); noTone(buzzerPin); delay(500); }
Function Purpose
tone(pin, frequency) Specified pin पर tone generate करना
noTone(pin) उस pin पर generated tone stop करना

5. Using a Buzzer as an Alarm Unit

जब कोई predefined condition occur होती है, Arduino buzzer को activate करके alarm generate कर सकता है। Condition किसी key, sensor, switch या serial command से आ सकती है।

Alarm Working

Input / Condition
→
Arduino checks condition
→
Alarm ON
→
Buzzer Sound

Example: Key Controlled Alarm

const int buzzerPin = 8; void setup() { pinMode(buzzerPin, OUTPUT); Serial.begin(9600); Serial.println("Press A for alarm"); } void loop() { if (Serial.available() > 0) { char key = Serial.read(); if (key == 'A' || key == 'a') { tone(buzzerPin, 1500); delay(3000); noTone(buzzerPin); Serial.println("Alarm completed"); } } }

Alarm with Repeated Beeps

const int buzzerPin = 8; void alarm() { for (int i = 0; i < 5; i++) { tone(buzzerPin, 1500); delay(250); noTone(buzzerPin); delay(250); } } void setup() { pinMode(buzzerPin, OUTPUT); } void loop() { alarm(); delay(3000); }
Practical Note: High-power sirens/buzzers को Arduino GPIO pin से directly drive नहीं करना चाहिए। Required current के अनुसार transistor/MOSFET/driver और suitable external supply का उपयोग किया जा सकता है।

Integrated Example: Key → LED + Buzzer

Serial input को एक simple control panel की तरह use किया जा सकता है। L से LED toggle और A से alarm activate किया जा सकता है।

const int ledPin = 13; const int buzzerPin = 8; bool ledState = false; void setup() { pinMode(ledPin, OUTPUT); pinMode(buzzerPin, OUTPUT); Serial.begin(9600); Serial.println("L = Toggle LED"); Serial.println("A = Alarm"); } void loop() { if (Serial.available() > 0) { char key = Serial.read(); if (key == 'L' || key == 'l') { ledState = !ledState; digitalWrite(ledPin, ledState); } if (key == 'A' || key == 'a') { tone(buzzerPin, 1500); delay(1000); noTone(buzzerPin); } } }

Quick Revision

Question Short Answer
Serial Input क्या है? Serial communication के माध्यम से Arduino को data/command देना।
Serial.begin() का purpose? Serial communication initialize करना और baud rate set करना।
Serial.available()? Receive buffer में available data check करना।
Serial.read()? Received byte/character read करना।
LED को key से कैसे control कर सकते हैं? Received key को check करके digitalWrite() से LED ON/OFF कर सकते हैं।
Toggle switch क्या है? हर valid key press पर output state को ON ↔ OFF बदलना।
Piezo buzzer क्या करता है? Electrical signal से sound/alert generate करता है।
tone() का उपयोग? Specified frequency का tone generate करने के लिए।
noTone()? Generated tone को stop करने के लिए।
Buzzer alarm unit कैसे काम करता है? Condition detect होने पर Arduino buzzer को activate करता है।
