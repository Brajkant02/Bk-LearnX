1.1

Arduino का Overview

Arduino एक open-source electronics platform है, जिसका उपयोग sensors, LEDs, motors, displays और अन्य electronic components के साथ interactive तथा embedded projects बनाने के लिए किया जाता है। Arduino ecosystem में development boards, microcontrollers, programming environment और libraries शामिल होते हैं।

Programmer Arduino IDE में code लिखता है, उसे compile करता है और USB connection के माध्यम से board पर upload करता है। Board का microcontroller uploaded program के अनुसार input पढ़ता है, processing करता है और output devices को control करता है।

Exam Definition: Arduino एक open-source electronics prototyping platform है, जिसमें programmable microcontroller-based boards और programming environment की सहायता से electronic तथा embedded applications विकसित की जाती हैं।
Sensor Projects
Temperature, light, motion आदि sensors से data लेना।
Automation
Lights, fans, pumps आदि control करना।
Robotics
Sensors, motors और actuators के साथ projects।
IoT Prototypes
Connected-device projects के prototypes बनाना।

Arduino Installation

Arduino programming शुरू करने के लिए computer में Arduino IDE install किया जाता है। IDE code लिखने, compile करने और board पर upload करने का मुख्य environment है।

  1. Arduino IDE install करें।
  2. Board को data-capable USB cable से computer से connect करें।
  3. IDE में सही Board select करें।
  4. सही Port select करें।
  5. Sketch लिखें या example खोलें।
  6. Verify/Compile करें।
  7. Upload करें।
  8. Upload के बाद microcontroller program execute करेगा।
First Project: Arduino IDE के Blink example से LED blinking, board selection, compilation और upload की basic process समझी जा सकती है।
ध्यान दें: USB cable data transfer support करती हो। गलत board/port selection या improper wiring से upload या hardware operation में समस्या आ सकती है।

Arduino Architecture

INPUTS Sensors / Switches ↓ Digital / Analog Pins ↓ Microcontroller (CPU + Memory + Peripherals) ↓ Program Processing ↓ Digital / PWM / Communication Outputs ↓ LED / Display / Motor Driver / Actuator

Arduino architecture को hardware और software दोनों स्तरों पर समझा जा सकता है। Arduino Uno जैसे board में microcontroller मुख्य processing unit होता है। यह program instructions execute करता है और I/O peripherals के माध्यम से external devices से interaction करता है।

Popular classic Arduino Uno revision में ATmega328P microcontroller का उपयोग होता है। इसके साथ digital I/O, analog inputs, timers, serial communication और ADC जैसे features मिलते हैं।

1.7

Digital और Analog Ports / Pins का Concept

Digital Pin

Digital signal discrete logic states represent करता है। Arduino में digital pin को सामान्यतः HIGH या LOW के रूप में read/write किया जाता है।

pinMode(13, OUTPUT);
digitalWrite(13, HIGH);
delay(1000);
digitalWrite(13, LOW);

Analog Input

Real-world signals जैसे temperature या light sensor का voltage continuous हो सकता है। Arduino का ADC analog voltage को digital numeric representation में बदलता है।

int sensorValue = analogRead(A0);

Arduino Uno के 10-bit ADC में सामान्य reading range 0 से 1023 होती है, जो selected/reference voltage range को represent करती है।

PWM और Analog Output

महत्वपूर्ण: Uno का PWM वास्तविक continuous analog voltage output नहीं है। analogWrite() PWM waveform की duty cycle control करता है। True analog voltage के लिए suitable DAC/circuit की आवश्यकता हो सकती है।
DigitalAnalog InputPWM
HIGH/LOW logicADC के द्वारा analog voltage readingON/OFF pulses की duty cycle control
Switch/LED controlSensor measurementLED brightness जैसे applications

Arduino Interfacing Board से परिचित होना

Interfacing का अर्थ Arduino को external electronic components के साथ connect करके data लेना या output control करना है। Sensors physical world से input देते हैं और actuators/output devices Arduino के control के अनुसार action लेते हैं।

Input
Push button, potentiometer, LDR, temperature sensor आदि।
Output
LED, buzzer, display, relay module आदि।
Actuator
Motor, servo, pump आदि; suitable driver की जरूरत हो सकती है।
Communication
Serial, I²C, SPI जैसे interfaces से modules connect किए जा सकते हैं।

Basic LED Interfacing

Arduino Digital Pin ── Resistor ── LED ── GND

LED circuit में suitable current-limiting resistor लगाया जाता है। Motor जैसे higher-current load को Arduino GPIO से सीधे drive करने के बजाय suitable transistor/MOSFET/driver module का प्रयोग किया जाता है।

Sensor Interfacing Flow

  1. Sensor physical quantity को electrical signal में बदलता है।
  2. Arduino input pin signal receive करता है।
  3. Analog signal होने पर ADC उसे digital value में represent करता है।
  4. Program value process करता है।
  5. Arduino output या communication interface के माध्यम से action लेता है।

Introduction to Embedded C

Embedded C C programming concepts का उपयोग embedded systems के लिए software बनाने में किया जाता है। इसमें hardware resources, memory, timing और peripherals को ध्यान में रखकर program विकसित किया जाता है।

  • Hardware के close control की सुविधा
  • Variables, conditions, loops और functions
  • Microcontroller registers/peripherals के साथ काम
  • Limited memory और processing resources का ध्यान
  • Embedded और real-time applications में उपयोग

Arduino और C/C++

Arduino sketches सामान्यतः C/C++ आधारित Arduino programming environment में लिखे जाते हैं। Arduino framework कई hardware operations को आसान functions के रूप में उपलब्ध कराता है, जैसे pinMode(), digitalWrite(), digitalRead(), analogRead() और delay()।

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
FunctionPurpose
setup()Board start/reset होने के बाद सामान्यतः एक बार चलता है; initialization के लिए।
loop()Main application logic को repeatedly execute करता है।

Complete Working Example: LDR + LED

एक LDR से light level पढ़कर LED control करना digital और analog concepts का अच्छा example है।

  1. LDR circuit को A0 जैसे analog input से connect करें।
  2. LED को suitable resistor के साथ digital output pin से connect करें।
  3. analogRead(A0) से sensor value पढ़ें।
  4. Value को threshold से compare करें।
  5. Condition के अनुसार LED ON/OFF करें।
const int sensorPin = A0;
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int value = analogRead(sensorPin);

  if (value < 500) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}
यहाँ A0 = analog input, program में comparison = processing, और pin 13 = digital output है। वास्तविक LDR circuit में threshold और reading direction circuit arrangement पर depend कर सकती है।
