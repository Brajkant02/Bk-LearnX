4.1

Incorporating Arduino Time

Arduino projects में time का उपयोग बहुत महत्वपूर्ण है। किसी LED को निश्चित interval पर blink करना, sensor को periodic interval पर read करना, motor को कुछ समय तक चलाना, button event का timing measure करना या किसी task को बिना लगातार delay के schedule करना—इन सभी में timing functions उपयोगी होते हैं।

Arduino programming environment में basic timing के लिए मुख्य functions हैं: delay(), delayMicroseconds(), millis() और micros()।

Arduino Program ↓ Timing Requirement ↓ +-----------------------------+ | delay() | | delayMicroseconds() | | millis() | | micros() | +-----------------------------+ ↓ Timed Action / Measurement

4.2

delay() Function

delay() function program execution को दिए गए number of milliseconds तक रोकता है। यह beginners के लिए सबसे simple timing function है।

Syntax

delay(milliseconds);

Example

digitalWrite(13, HIGH);
delay(1000);

digitalWrite(13, LOW);
delay(1000);

यहाँ LED को HIGH करने के बाद program लगभग 1000 milliseconds (1 second) wait करता है, फिर LOW करता है और दोबारा 1 second wait करता है।

LED Blink Example

const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(500);

  digitalWrite(ledPin, LOW);
  delay(500);
}

delay() की विशेषता

  • Use करना बहुत आसान है।
  • Milliseconds में argument लिया जाता है।
  • Simple sequential timing के लिए उपयोगी है।
  • लेकिन delay के दौरान normal program flow effectively wait करता है, इसलिए दूसरे tasks की responsiveness प्रभावित हो सकती है।
Important: delay() को हर timing problem का solution नहीं मानना चाहिए। जब Arduino को simultaneously button, sensor, communication या अन्य tasks handle करने हों, तब millis() आधारित approach अधिक useful हो सकती है।
4.3

delayMicroseconds() Function

delayMicroseconds() program को दिए गए number of microseconds के लिए short delay देता है। यह बहुत छोटे timing intervals वाले applications में उपयोगी है।

Syntax

delayMicroseconds(microseconds);

Example

digitalWrite(8, HIGH);
delayMicroseconds(100);
digitalWrite(8, LOW);
delayMicroseconds(100);

ऊपर प्रत्येक state के बीच लगभग 100 microseconds का delay रखा गया है। Actual timing instruction execution और hardware characteristics से प्रभावित हो सकती है।

delay() और delayMicroseconds() में अंतर

ध्यान दें: बहुत छोटे delays में actual achievable precision processor clock, compiler-generated instructions और board architecture पर depend करती है।
4.4

millis() Function

millis() function board के running time का elapsed count milliseconds में देता है। इसका उपयोग यह पता लगाने के लिए किया जाता है कि program ने कितना time चलाया है।

Syntax

unsigned long currentTime = millis();

Arduino timing code में सामान्यतः unsigned long type उपयोग किया जाता है क्योंकि returned count समय के साथ बढ़ता रहता है।

Basic Example

unsigned long startTime;

void setup() {
  startTime = millis();
}

void loop() {
  unsigned long currentTime = millis();

  if (currentTime - startTime >= 5000) {
    // लगभग 5 seconds elapsed
  }
}

millis() से LED Blink — बिना blocking delay के

const int ledPin = 13;
unsigned long previousMillis = 0;
const unsigned long interval = 1000;
bool ledState = LOW;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  unsigned long currentMillis = millis();

  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;

    ledState = !ledState;
    digitalWrite(ledPin, ledState);
  }
}

इस technique में Arduino हर loop iteration में time check कर सकता है। इसलिए loop के बीच लंबा blocking wait नहीं लगाया जाता।

millis() Rollover

millis() का returned counter finite-size integer type में store होता है, इसलिए बहुत लंबे समय बाद यह rollover होकर फिर छोटे values से continue कर सकता है। सही elapsed-time comparison के लिए सामान्य pattern current - previous >= interval उपयोग करना rollover-safe design के लिए बेहतर है।

4.5

micros() Function

micros() program के start के बाद elapsed time का count microseconds में देता है। यह short-duration timing और performance measurement के लिए उपयोगी है।

Syntax

unsigned long currentTime = micros();

Execution Time Measure करना

unsigned long startTime = micros();

// Code to measure
int result = 10 * 20;

unsigned long elapsed = micros() - startTime;

यहाँ elapsed variable में measured section के execution time का approximate microsecond count प्राप्त किया जा सकता है। बहुत छोटे code sections के लिए measurement overhead और timer resolution को ध्यान में रखना चाहिए।

micros() आधारित Interval Example

unsigned long previousMicros = 0;
const unsigned long interval = 1000;

void loop() {
  unsigned long currentMicros = micros();

  if (currentMicros - previousMicros >= interval) {
    previousMicros = currentMicros;

    // timed task
  }
}
Important: micros() की resolution, rollover period और exact behavior board architecture पर depend कर सकते हैं। इसलिए high-precision timing requirement में specific board documentation और hardware timers को ध्यान में रखें।

4.7

Blocking और Non-Blocking Timing

Blocking Timing

Blocking timing में program किसी operation पर wait करता है और उस समय normal loop processing आगे नहीं बढ़ती। delay() इसका common example है।

digitalWrite(13, HIGH);
delay(5000);
digitalWrite(13, LOW);

यहाँ 5 seconds की waiting के दौरान उसी sequential flow में अगला statement तुरंत execute नहीं होता।

Non-Blocking Timing

Non-blocking approach में current time को repeatedly check करके यह तय किया जाता है कि interval पूरा हुआ या नहीं। millis() और micros() इस pattern के लिए उपयोगी हैं।

unsigned long previous = 0;
const unsigned long interval = 1000;

void loop() {
  unsigned long now = millis();

  if (now - previous >= interval) {
    previous = now;
    // Task
  }

  // Other tasks can continue here
}
Exam Point: जब एक Arduino project में multiple tasks को responsive रखना हो, तब elapsed-time based scheduling अक्सर simple delay-based code से बेहतर architecture देता है।
4.8

Practical Examples

Example 1: millis() से दो अलग Tasks

const int led1 = 13;
const int led2 = 12;

unsigned long t1 = 0;
unsigned long t2 = 0;

void setup() {
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
}

void loop() {
  unsigned long now = millis();

  if (now - t1 >= 500) {
    t1 = now;
    digitalWrite(led1, !digitalRead(led1));
  }

  if (now - t2 >= 1000) {
    t2 = now;
    digitalWrite(led2, !digitalRead(led2));
  }
}

यहाँ दोनों LEDs अलग-अलग intervals पर operate कर सकती हैं और कोई long blocking delay नहीं लगाया गया है।

Example 2: millis() से Sensor Sampling

const unsigned long sampleInterval = 2000;
unsigned long previous = 0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  unsigned long now = millis();

  if (now - previous >= sampleInterval) {
    previous = now;

    int value = analogRead(A0);
    Serial.println(value);
  }
}

इस example में sensor को लगभग हर 2 seconds पर read किया जाता है, जबकि loop के बीच program अन्य tasks भी कर सकता है।

Example 3: millis() से Elapsed Time

unsigned long start;

void setup() {
  Serial.begin(9600);
  start = millis();
}

void loop() {
  unsigned long elapsed = millis() - start;

  Serial.println(elapsed);
  delay(1000);
}
4.9

Quick Revision – परीक्षा के लिए

  • Arduino Time: Timed events, delays और elapsed-time measurement के लिए उपयोगी concept।
  • delay(): Milliseconds में blocking delay देता है।
  • delayMicroseconds(): Microseconds में short blocking delay देता है।
  • millis(): Program start के बाद elapsed time को milliseconds count के रूप में देता है।
  • micros(): Program start के बाद elapsed time को microseconds count के रूप में देता है।
  • Non-blocking timing: Current time और previous time के difference से interval check करना।
  • Common pattern: if (current - previous >= interval)
  • millis() और micros(): Returned counters finite-size होते हैं, इसलिए long-running programs में rollover को ध्यान में रखना चाहिए।
  • Time units: 1 second = 1000 milliseconds = 1,000,000 microseconds.
One-Line Revision: Arduino Timing = delay() for simple waits + delayMicroseconds() for short waits + millis()/micros() for elapsed-time based control and measurement.
