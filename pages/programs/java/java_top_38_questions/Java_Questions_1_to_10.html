Question 1: Explain the Fundamentals and Features of Object Oriented Programming (OOP).

Object Oriented Programming (OOP)

Object Oriented Programming (OOP) एक programming approach है, जिसमें program को functions के बजाय Objects और Classes के आधार पर organize किया जाता है। इसमें real-world entities जैसे Student, Employee, Car और Bank Account को objects के रूप में represent किया जाता है। प्रत्येक object के पास अपना data और उस data पर काम करने वाले methods होते हैं।

OOP का मुख्य उद्देश्य program को modular, reusable, secure और easy to maintain बनाना है। Java एक object-oriented programming language है और इसमें classes तथा objects का महत्वपूर्ण role होता है।

Fundamentals of OOP

OOP के मुख्य fundamentals निम्नलिखित हैं:

1. Class

Class एक blueprint या template होती है, जिसके आधार पर objects बनाए जाते हैं। इसमें data members (variables) और member functions (methods) define किए जाते हैं। Class यह बताती है कि उसके objects में कौन-सा data होगा और वे कौन-कौन से काम कर सकेंगे।

Example: Student एक class हो सकती है, जिसमें rollNumber, name और displayDetails() method define किया गया हो।

2. Object

Object, class का instance होता है। यह किसी real-world entity को represent करता है। Object के पास state, behaviour और identity होती है। State को variables, behaviour को methods और identity को object reference से access किया जा सकता है।

Example: यदि Student एक class है, तो Pankaj और Rahul उसके अलग-अलग objects हो सकते हैं। दोनों objects के data अलग हो सकते हैं।

3. Object Reference

Object Reference वह variable होता है जो किसी object को refer करता है। Java में object बनाने पर reference variable के माध्यम से उसके members को access किया जाता है। Reference variable object का actual data अपने अंदर store नहीं करता, बल्कि object को refer करता है।

Example: Student s1 = new Student(); में s1 reference variable है।

4. Abstraction

Abstraction का अर्थ है implementation की unnecessary details को hide करके केवल जरूरी features या functionality दिखाना। इससे user को यह जानने की आवश्यकता नहीं होती कि अंदर से काम कैसे हो रहा है, उसे केवल यह पता होना चाहिए कि feature का उपयोग कैसे करना है।

Example: हम ATM से पैसे निकालते समय केवल amount enter करते हैं। ATM के अंदर transaction process किस प्रकार execute होता है, यह user से hidden रहता है। Java में abstraction को abstract classes और interfaces से achieve किया जा सकता है।

5. Encapsulation

Encapsulation का अर्थ data और उस पर काम करने वाले methods को एक single unit यानी class में bind करना है। इसमें data को direct access से बचाने के लिए सामान्यतः variables को private रखा जाता है और उन्हें access करने के लिए public getter तथा setter methods दिए जाते हैं।

Example: BankAccount class में balance को private रखा जा सकता है और deposit() तथा getBalance() methods से नियंत्रित access दिया जा सकता है।

6. Inheritance

Inheritance वह mechanism है जिसमें एक class दूसरी class के accessible properties और methods को acquire कर सकती है। जिस class से features inherit किए जाते हैं उसे Parent/Superclass और जो class inherit करती है उसे Child/Subclass कहते हैं। इससे code reusability बढ़ती है।

Example: Vehicle parent class हो सकती है और Car उसकी child class हो सकती है। Car, Vehicle के common features को inherit कर सकती है।

7. Polymorphism

Polymorphism का अर्थ है “one name, many forms”. इसमें एक ही method name अलग-अलग situations में अलग behaviour दे सकता है। Java में method overloading compile-time polymorphism और method overriding runtime polymorphism का उदाहरण है।

Example: draw() method Circle के लिए circle और Rectangle के लिए rectangle draw कर सकता है, यदि दोनों classes इसे अपने अनुसार implement करें।

Simple Java Program Based on Class and Object

नीचे दिए गए program में Student class बनाई गई है। इसका object बनाकर name और roll number display किए गए हैं।

Java ProgramClass and Object
class Student {
    String name = "Amit";
    int rollNo = 101;

    void display() {
        System.out.println("Name: " + name);
        System.out.println("Roll No: " + rollNo);
    }

    public static void main(String[] args) {
        Student s1 = new Student();
        s1.display();
    }
}
Output

Roll No: 101

Advantages of OOP

  1. Code Reusability: Inheritance की मदद से existing code को दोबारा use किया जा सकता है।
  2. Data Security: Encapsulation और access modifiers data को controlled access देते हैं।
  3. Modularity: Program को अलग-अलग classes और objects में divide किया जा सकता है।
  4. Easy Maintenance: छोटे modules में program होने से errors find और update करना आसान होता है।
  5. Flexibility: Polymorphism की मदद से एक interface के अलग-अलग implementations बनाए जा सकते हैं।

Question 2: Explain the drawbacks of Procedural Programming and the need of OOP. Differentiate between POP and OOP.

Procedural Oriented Programming (POP)

Procedural Oriented Programming एक programming approach है जिसमें program को छोटे-छोटे procedures या functions में divide किया जाता है। इसमें मुख्य focus इस बात पर होता है कि किसी task को पूरा करने के लिए कौन-कौन से steps execute होंगे। C language इसका common example है।

Drawbacks of Procedural Programming

  1. Less Data Security: कई procedural programs में data को functions के बीच share किया जाता है, जिससे data पर control सीमित हो सकता है।
  2. Code Reusability की कमी: बड़े programs में existing code को reuse और extend करना comparatively कठिन हो सकता है।
  3. Maintenance Difficult: Program बड़ा होने पर functions और shared data के संबंध को समझना कठिन हो सकता है।
  4. Real-world Modeling कठिन: Real-world entities को data और behaviour सहित एक unit के रूप में represent करना आसान नहीं होता।
  5. Data और Functions अलग: POP में data और functions सामान्यतः अलग-अलग रहते हैं, इसलिए data handling पर अतिरिक्त ध्यान देना पड़ता है।

Need of Object Oriented Programming

Procedural programming की limitations को कम करने के लिए OOP approach उपयोगी है। OOP data और methods को classes में combine करती है। इससे program को real-world objects के अनुसार design करना, code reuse करना और data को controlled access देना आसान होता है।

Question 3: What is JVM? Explain its working and how Java is platform independent.

JVM (Java Virtual Machine)

JVM का full form Java Virtual Machine है। यह Java Runtime Environment (JRE) का एक important part है। JVM एक virtual machine है जो Java bytecode को execute करती है। Java source code को compiler compile करके bytecode में convert करता है और JVM उस bytecode को संबंधित system पर execute करती है।

JVM memory management, garbage collection, security और runtime execution जैसी responsibilities भी संभालती है। अलग-अलग operating systems के लिए JVM implementations उपलब्ध होती हैं।

Working of JVM

Java program की execution सामान्यतः निम्न steps में होती है:

  1. Source Code: Programmer Java source code को .java file में लिखता है।
  2. Compilation: Java compiler (javac) source code को compile करके bytecode बनाता है।
  3. Bytecode: Compiled bytecode सामान्यतः .class file में store होता है।
  4. Class Loader: JVM का Class Loader required class files को memory में load करता है।
  5. Bytecode Verification: Bytecode Verifier bytecode की validity और safety-related checks करता है।
  6. Execution Engine: Execution Engine bytecode execute करता है। यह interpreter और Just-In-Time (JIT) compiler का उपयोग कर सकता है।
  7. Output: Program execute होने के बाद required result प्राप्त होता है।

Why is Java Platform Independent?

Java को platform independent इसलिए कहा जाता है क्योंकि Java compiler source code को machine-specific native code के बजाय platform-neutral bytecode में convert करता है। यह bytecode किसी भी operating system पर उस system की compatible JVM के माध्यम से execute किया जा सकता है।

इस concept को “Write Once, Run Anywhere (WORA)” कहा जाता है। इसका अर्थ है कि एक बार bytecode generate हो जाने के बाद उसे अलग-अलग supported platforms पर compatible JVM के साथ चलाया जा सकता है।

Question 4: Explain Eclipse IDE, its features and the steps to develop, compile, run and debug a Java program.

Eclipse IDE

Eclipse IDE का full form Integrated Development Environment है। यह एक popular software development environment है जिसका उपयोग Java applications develop करने के लिए किया जाता है। Eclipse में programmer code लिख सकता है, project manage कर सकता है, program run कर सकता है और errors debug कर सकता है। Java development के लिए Eclipse में Java Development Tools (JDT) उपलब्ध होते हैं।

  2. Syntax Highlighting: Keywords, variables और strings को अलग-अलग colors में दिखाता है।

  5. Debugger: Breakpoints लगाकर program को step-by-step execute करने और variables inspect करने की सुविधा देता है।
  6. Project Management: एक workspace में multiple Java projects manage किए जा सकते हैं।
  7. Build and Run: Java program को compile/build और run करना आसान बनाता है।
  8. Plugin Support: Additional plugins के माध्यम से IDE की capabilities बढ़ाई जा सकती हैं।

Steps to Create a Java Program in Eclipse

  1. Install and Open Eclipse: System में Eclipse IDE install करके open करें।
  2. Select Workspace: Workspace folder select करें जहाँ projects store होंगे।

Question 5: Explain Java tokens and data types. Describe the primitive data types of Java.

Java Tokens

Java program की सबसे छोटी meaningful units को Tokens कहा जाता है। Java compiler source code को tokens के रूप में identify करता है। Java में मुख्य रूप से keywords, identifiers, literals, operators और separators (या punctuators) tokens के रूप में उपयोग होते हैं।

Types of Java Tokens

  1. Keywords: ये reserved words होते हैं जिनका Java में predefined meaning होता है। इन्हें सामान्य identifiers के रूप में use नहीं किया जा सकता। Examples: class, int, if, public, static.
  2. Identifiers: Classes, methods, variables और other program elements को दिए गए names identifiers कहलाते हैं। Examples: Student, total, display.
  3. Literals: Program में directly लिखी गई fixed values literals कहलाती हैं। Examples: 100, 3.14, 'A', "Java", true.
  4. Operators: ये values या variables पर operations perform करते हैं। Examples: +, -, *, ==, &&.
  5. Separators: ये program के अलग-अलग parts को separate करने के लिए उपयोग होते हैं। Examples: (), {}, [], ;, ,.

Data Types in Java

Data Type यह define करता है कि variable में किस प्रकार का data store किया जा सकता है। Java एक statically typed language है, इसलिए variable declare करते समय उसका data type specify करना होता है। Java data types को broadly दो categories में divide किया जाता है:

  1. Primitive Data Types: ये basic built-in data types हैं।
  2. Non-Primitive / Reference Types: इनमें classes, arrays, interfaces और अन्य reference types शामिल होते हैं।

Question 6: Differentiate between Type Conversion and Type Casting in Java.

Type Conversion

Type Conversion वह process है जिसमें एक data type की value को दूसरे compatible data type में automatically convert किया जाता है। Java में जब smaller compatible numeric type को larger numeric type में convert किया जाता है, तो इसे सामान्यतः Widening Conversion कहते हैं। इसमें programmer को explicit cast लिखने की जरूरत नहीं होती।

Example: int value को double variable में assign करना।

Java ProgramType Conversion
class ConversionExample {
    public static void main(String[] args) {
        int number = 25;
        double value = number;

        System.out.println("Integer: " + number);
        System.out.println("Double: " + value);
    }
}
Output
Integer: 25
Double: 25.0

Type Casting

Type Casting वह process है जिसमें programmer explicitly किसी value को दूसरे compatible data type में convert करता है। Narrowing Conversion में larger range वाले type को smaller range वाले type में convert किया जा सकता है। इसमें data loss या precision loss होने की संभावना रहती है।

Example: double value को int में convert करने के लिए cast operator (int) का उपयोग करना। Decimal part हट जाता है।

Java ProgramType Casting
class CastingExample {
    public static void main(String[] args) {
        double price = 99.75;
        int amount = (int) price;

        System.out.println("Double: " + price);
        System.out.println("Integer: " + amount);
    }
}
Output
Double: 99.75
Integer: 99

Type Conversion automatic होता है, जबकि Type Casting में programmer explicit cast operator का उपयोग करता है। Narrowing conversion करते समय possible data loss का ध्यान रखना चाहिए।

Question 10: Explain switch statement in Java and differentiate it from if-else statement.

switch Statement

Java में switch statement का उपयोग किसी expression की value के आधार पर multiple alternatives में से एक block select करने के लिए किया जाता है। यह तब useful होता है जब एक variable या expression की value को कई fixed cases के साथ compare करना हो।

Syntax of switch Statement

Java Syntaxswitch
switch (expression) {
    case value1:
        // statements
        break;
    case value2:
        // statements
        break;
    default:
        // default statements
}

Important Parts of switch

  1. switch: यह expression की value evaluate करता है।
  2. case: हर case एक possible matching value define करता है।
  3. break: Traditional switch statement में break current switch block से बाहर निकलता है। यदि break नहीं लिखा हो, तो control अगले case में fall through कर सकता है।
  4. default: कोई case match न होने पर default block execute होता है। यह optional होता है।

Example Program of switch Statement

Java ProgramDay Selection
class SwitchExample {
    public static void main(String[] args) {
        int day = 3;

        switch (day) {
            case 1:
                System.out.println("Monday");
                break;
            case 2:
                System.out.println("Tuesday");
                break;
            case 3:
                System.out.println("Wednesday");
                break;
            default:
                System.out.println("Invalid day");
        }
    }
}
Output
Wednesday

Working of switch Statement

  1. सबसे पहले switch expression evaluate होता है।
  2. उसकी value को available case labels से match किया जाता है।
  3. Matching case मिलने पर उससे statements execute होने लगते हैं।
  4. break मिलने पर switch statement terminate हो जाता है।
  5. यदि कोई case match नहीं होता और default मौजूद है, तो default block execute होता है।

Difference Between switch and if-else

Basisswitch Statementif-else Statement
1. Purposeएक expression की value को multiple case labels से match करता है।एक या अधिक boolean conditions check करता है।
2. ConditionsFixed case values के लिए convenient है।Range, relational और complex logical conditions के लिए suitable है।
3. Readabilityकई fixed choices होने पर code साफ दिखता है।Complex conditions में अधिक flexible और readable हो सकता है।
