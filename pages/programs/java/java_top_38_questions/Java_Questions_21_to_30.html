Question 21: Explain the accessibility of private, protected and public data members in inheritance.

Access Control in Inheritance

Java में access modifiers यह निर्धारित करते हैं कि किसी class के variables और methods को कहाँ से access किया जा सकता है। जब एक class दूसरी class को inherit करती है, तब superclass के members की accessibility उनके access modifier पर depend करती है।

1. Private Members

private members केवल उसी class के अंदर directly accessible होते हैं जिसमें वे declare किए गए हैं। Subclass उन्हें directly access नहीं कर सकती। हालांकि superclass के public या protected methods के माध्यम से private data को indirectly access किया जा सकता है।

2. Protected Members

protected members same package की classes में accessible होते हैं। इसके अलावा दूसरे package में मौजूद subclass भी protected members को inheritance के माध्यम से access कर सकती है, Java के protected access rules के अनुसार।

3. Public Members

public members को किसी भी package की दूसरी classes से access किया जा सकता है, यदि संबंधित class accessible हो। इसलिए inheritance में public members subclass में भी accessible रहते हैं।

4. Default (Package-Private) Members

यदि किसी member के साथ कोई access modifier नहीं लिखा जाता, तो उसे default या package-private access मिलता है। ऐसे members केवल उसी package की classes में accessible होते हैं। दूसरे package की subclass इन्हें directly access नहीं कर सकती।

Java Program Example

इस example में superclass के private, protected और public variables बनाए गए हैं। Subclass protected और public members को directly access करती है, जबकि private member को superclass के public method से access किया जाता है।

Java ProgramMember Accessibility
class Parent {
    private int privateData = 10;
    protected int protectedData = 20;
    public int publicData = 30;

    public int getPrivateData() {
        return privateData;
    }
}

class Child extends Parent {
    void display() {
        System.out.println("Private data: " + getPrivateData());
        System.out.println("Protected data: " + protectedData);
        System.out.println("Public data: " + publicData);
    }
}

class AccessDemo {
    public static void main(String[] args) {
        Child obj = new Child();
        obj.display();
    }
}
Output 
Private data: 10
Protected data: 20
Public data: 30

Conclusion

Inheritance में public और protected members subclass के लिए accessible होते हैं। Private members subclass में directly accessible नहीं होते, लेकिन superclass के methods के माध्यम से access किए जा सकते हैं। Access modifiers data security और controlled access प्रदान करते हैं।

Question 22: What is an Interface in Java? Explain how to define and implement an interface with a program.

Interface in Java

Interface Java में एक reference type है जो methods का contract define करता है। यह बताता है कि interface को implement करने वाली class को कौन-कौन से methods provide करने होंगे। Interface को interface keyword से declare किया जाता है और class इसे implements keyword से implement करती है।

Basic syllabus-level interface में methods सामान्यतः public और abstract होते हैं। Interface के variables implicitly public static final होते हैं, अर्थात वे constants होते हैं। Interface का object directly create नहीं किया जा सकता।

Defining an Interface

Interface बनाने का general syntax नीचे दिया गया है:

    void methodName();
}

Implementing an Interface

किसी class द्वारा interface implement करने पर class को उसके सभी abstract methods की implementation देनी होती है। Implement किए गए methods को public declare करना चाहिए।

  1. Interface abstraction प्रदान करता है और implementation details को अलग रखता है।
  2. अलग-अलग classes के लिए common contract define किया जा सकता है।
  3. Java में multiple inheritance of type को multiple interfaces implement करके support किया जाता है।
  4. Code को flexible और loosely coupled बनाने में मदद करता है।

Question 23: Differentiate between Class and Interface in Java.

Class

Class एक blueprint या template है जिसके आधार पर objects create किए जाते हैं। इसमें data members, constructors और methods हो सकते हैं। Class का object new keyword से बनाया जा सकता है।

Interface

Interface एक contract define करता है जिसे implementing class follow करती है। Basic interface में abstract methods declare किए जाते हैं। Interface का object directly create नहीं किया जा सकता।

Question 24: What is an Abstract Class in Java? Explain its characteristics with an example.

Abstract Class

Abstract class ऐसी class होती है जिसे abstract keyword से declare किया जाता है। इसका उपयोग common properties और behaviour को define करने के लिए किया जाता है। Abstract class का object directly create नहीं किया जा सकता। इसे दूसरी class extend करके use करती है।

Characteristics of Abstract Class

  1. Abstract class को declare करने के लिए abstract keyword का उपयोग होता है।
  2. इसका object directly create नहीं किया जा सकता।
  3. इसमें abstract methods और normal (concrete) methods दोनों हो सकते हैं।
  4. इसमें instance variables, static variables और constructors हो सकते हैं।
  5. Subclass abstract class को extend करती है और उसके abstract methods implement करती है, अन्यथा subclass भी abstract declare करनी होगी।
  6. Abstract class का उपयोग related classes के बीच common code share करने के लिए किया जाता है।

Abstract Method

Abstract method वह method है जिसकी केवल declaration होती है, body नहीं होती। इसे subclass में override करके implementation दी जाती है।

SyntaxAbstract Class and Method

    abstract void methodName();

    void display() {
        System.out.println("Concrete method");
    }
}

Question 26: What is Polymorphism in Java? Explain its types with examples.

Polymorphism

Polymorphism OOP का एक महत्वपूर्ण feature है। इसका अर्थ है “many forms” अर्थात एक ही name या reference का अलग-अलग situations में अलग behaviour होना। Java में polymorphism की मदद से program को flexible और reusable बनाया जा सकता है।

Types of Polymorphism

1. Compile-Time Polymorphism (Static Binding)

Compile-time polymorphism method overloading के द्वारा achieve किया जाता है। इसमें same class में same name के multiple methods होते हैं, लेकिन उनके parameter lists अलग होते हैं। Compiler arguments के आधार पर decide करता है कि कौन-सा method call होगा।

2. Run-Time Polymorphism (Dynamic Binding)

Run-time polymorphism method overriding के द्वारा achieve किया जाता है। इसमें subclass superclass के method को अपनी implementation के साथ redefine करती है। कौन-सा overridden method execute होगा, यह runtime पर actual object के आधार पर decide होता है।

  4. Method overloading से same operation के अलग input forms संभाले जा सकते हैं।

Question 27: Differentiate between Method Overloading and Method Overriding with examples.

Method Overloading

जब एक ही class में same name के दो या अधिक methods define किए जाते हैं, लेकिन उनके parameters की संख्या, type या order अलग होता है, तो इसे method overloading कहते हैं। यह compile-time polymorphism का example है। केवल return type बदलने से method overloading नहीं होती।

Method Overriding

जब subclass अपने superclass में पहले से मौजूद method को same signature के साथ अपनी implementation देकर redefine करती है, तो इसे method overriding कहते हैं। यह run-time polymorphism का example है। Overriding में return type compatible होना चाहिए और access level को कम restrictive नहीं किया जा सकता।

Difference Between Overloading and Overriding

Basis Method Overloading Method Overriding

Class एक ही class में हो सकती है; inheritance आवश्यक नहीं। Superclass और subclass का relation आवश्यक है।
Parameters Parameters की संख्या, type या order अलग होना चाहिए। Method signature समान होना चाहिए।

Return Type Return type अलग हो सकता है, लेकिन केवल return type बदलना पर्याप्त नहीं। Same या covariant return type होना चाहिए।

Question 28: Explain Constructor Overloading in Java. Differentiate between Constructor Overloading and Method Overloading.

Constructor Overloading

जब किसी class में एक से अधिक constructors define किए जाते हैं और प्रत्येक constructor की parameter list अलग होती है, तो इसे constructor overloading कहते हैं। इससे object को अलग-अलग प्रकार के initial values के साथ create किया जा सकता है।

Constructor का नाम class के नाम के समान होता है और इसका कोई return type नहीं होता। Constructor overloading compile-time polymorphism का एक example है।

Java Program

Java ProgramConstructor Overloading
class Student {
    int rollNo;
    String name;

    Student() {
        rollNo = 0;
        name = "Not Assigned";
    }

    Student(int r) {
        rollNo = r;
        name = "Unknown";
    }

    Student(int r, String n) {
        rollNo = r;
        name = n;
    }

    void display() {
        System.out.println(rollNo + " - " + name);
    }
}

class ConstructorDemo {
    public static void main(String[] args) {
        Student s1 = new Student();
        Student s2 = new Student(101);
        Student s3 = new Student(102, "Aman");

        s1.display();
        s2.display();
        s3.display();
    }
}
Output 
0 - Not Assigned
101 - Unknown
102 - Aman

Name सभी constructors का नाम class के नाम जैसा होता है। Overloaded methods का नाम same होता है।

Advantages

Question 29: Explain Upcasting and Downcasting in Java with examples. Differentiate between them.

Type Casting in Inheritance

Inheritance में superclass और subclass के objects/references के बीच reference conversion को casting कहा जाता है। Java में मुख्य रूप से Upcasting और Downcasting का उपयोग किया जाता है।

1. Upcasting

जब subclass type के reference को superclass type के reference में convert किया जाता है, तो इसे upcasting कहते हैं। यह automatically हो सकती है क्योंकि हर subclass object superclass का भी object होता है। Upcasting में superclass reference से केवल वही members access किए जा सकते हैं जो superclass में declared हों, लेकिन overridden instance method का execution actual object के आधार पर होता है।

2. Downcasting

जब superclass type के reference को subclass type में convert किया जाता है, तो इसे downcasting कहते हैं। इसे explicitly cast करना पड़ता है। Downcasting तभी valid है जब reference वास्तव में उस subclass के compatible object को refer कर रहा हो। गलत cast करने पर ClassCastException आ सकता है।

Java Program

Java ProgramUpcasting and Downcasting
class Animal {
    void eat() {
        System.out.println("Animal eats food");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

class CastingDemo {
    public static void main(String[] args) {
        Dog d = new Dog();

        // Upcasting
        Animal a = d;
        a.eat();

        // Safe downcasting
        if (a instanceof Dog) {
            Dog d2 = (Dog) a;
            d2.bark();
        }
    }
}
Output

Dog barks

Difference Between Upcasting and Downcasting

Basis Upcasting Downcasting
Conversion Subclass reference to superclass reference। Superclass reference to subclass reference।
Type Implicit/automatic हो सकती है। Explicit cast की आवश्यकता होती है।
Safety Valid inheritance relation में सामान्यतः safe है। गलत object type पर ClassCastException हो सकता है।
Access Superclass में declared members तक access। Subclass के additional members भी access कर सकते हैं।
Use Subclass objects को common superclass reference से handle करना। Subclass-specific behaviour/member access करना।

Question 30: What is Exception Handling in Java? Explain its importance, advantages and working.

Exception

Exception एक unwanted event या error condition है जो program के execution के दौरान उत्पन्न होती है और normal flow को disturb कर सकती है। उदाहरण के लिए zero से divide करना, invalid array index access करना या ऐसी file open करना जो उपलब्ध न हो।

Exception Handling

Java में exception handling एक mechanism है जिसकी मदद से runtime errors को handle किया जाता है ताकि program का normal flow जहाँ तक संभव हो जारी रह सके। Java में exception handling के लिए try, catch, finally, throw और throws keywords उपयोग किए जाते हैं। इन keywords का detailed use अगले questions में दिया गया है।

Why Exception Handling is Important?

  1. Prevents Abnormal Termination: Exception को handle करके program को अचानक terminate होने से बचाया जा सकता है।
  2. Maintains Normal Flow: Error situation के लिए alternate handling code provide किया जा सकता है।
  3. Error Separation: Main program logic और error-handling code को अलग रखा जा सकता है।
  4. Meaningful Messages: User को understandable error message दिखाया जा सकता है।
  5. Easy Debugging: Exception information से error का कारण identify करने में मदद मिलती है।

Advantages of Exception Handling

  • Program अधिक reliable और robust बनता है।
  • Runtime error को व्यवस्थित तरीके से handle किया जा सकता है।
  • एक ही try block से आने वाली अलग-अलग exceptions के लिए अलग catch blocks लिखे जा सकते हैं।
  • Finally block में cleanup tasks जैसे resources close करना किया जा सकता है।
  • Exception को call stack में आगे propagate भी किया जा सकता है।

Working of Exception Handling

जब कोई statement exception generate करती है, Java runtime उस point पर normal execution रोककर matching exception handler खोजता है। यदि matching catch block मिल जाता है, तो उसका code execute होता है। इसके बाद applicable finally block execute होता है और program आगे बढ़ सकता है। यदि handler नहीं मिलता, तो exception call stack में propagate होती है; अंत में uncaught रहने पर program terminate हो सकता है।

Simple Java Program

इस program में division के दौरान यदि denominator zero हो, तो ArithmeticException generate होती है। Catch block उस exception को handle करता है।

Java ProgramException Handling Overview
class ExceptionDemo {
    public static void main(String[] args) {
        int a = 10;
        int b = 0;

        try {
            int result = a / b;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }

        System.out.println("Program continues...");
    }
}
Output 
Cannot divide by zero
Program continues...

Types of Exceptions (Overview)

  1. Checked Exceptions: Compiler द्वारा compile time पर check की जाती हैं। उदाहरण: IOException, SQLException।
  2. Unchecked Exceptions: Runtime पर occur होती हैं और सामान्यतः RuntimeException की subclasses होती हैं। उदाहरण: ArithmeticException, NullPointerException, ArrayIndexOutOfBoundsException।

इस प्रकार exception handling Java program को unexpected runtime conditions के प्रति अधिक सुरक्षित और व्यवस्थित बनाती है।
