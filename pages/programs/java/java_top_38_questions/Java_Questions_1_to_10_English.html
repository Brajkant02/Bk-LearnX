Question 1: Explain the Fundamentals and Features of Object Oriented Programming (OOP).

Object Oriented Programming (OOP)

Object Oriented Programming (OOP) is a programming approach in which a program is organized around objects and classes rather than functions. Real-world entities such as students, employees, cars, and bank accounts are represented as objects. Each object has its own data and methods that operate on that data.

The main objective of OOP is to make programs modular, reusable, secure, and easy to maintain. Java is an object-oriented programming language in which classes and objects play an important role.

Fundamentals of OOP

The main fundamentals of OOP are described below:

1. Class

A class is a blueprint or template used to create objects. It defines data members (variables) and member functions (methods). A class specifies what data its objects will contain and what operations they can perform.

Example:Student can be a class containing rollNumber and name fields, along with a displayDetails() method.

2. Object

An object is an instance of a class. It represents a real-world entity and has state, behaviour, and identity. Its state is represented by variables, its behaviour by methods, and it is accessed through an object reference.

Example:If Student is a class, Pankaj and Rahul can be two different objects of that class. Each object can contain different data.

3. Object Reference

An object reference is a variable that refers to an object. In Java, after creating an object, its members are accessed through the reference variable. The reference variable does not store the object’s actual data; it refers to the object.

Example: Student s1 = new Student();Ins1is the reference variable.

4. Abstraction

Abstraction means hiding unnecessary implementation details and showing only the essential features or functionality. The user does not need to know how something works internally; they only need to know how to use the feature.

Example:For example, when withdrawing money from an ATM, we only enter the amount. The internal transaction process remains hidden from the user. In Java, abstraction can be achieved using abstract classes and interfaces.

5. Encapsulation

Encapsulation means binding data and the methods that operate on it into a single unit, namely a class. To prevent direct access to data, variables are generally declaredprivateand public getter and setter methods are provided to access them.

Example:For example, the balance in a BankAccount class can be declared private and controlled access can be provided through deposit() and getBalance() methods.

6. Inheritance

Inheritance is a mechanism through which one class can acquire the accessible properties and methods of another class. The class whose features are inherited is called the Parent or Superclass, while the class that inherits them is called the Child or Subclass. This increases code reusability.

Example:Vehicle can be a parent class and Car can be its child class. Car can inherit the common features of Vehicle.

7. Polymorphism

Polymorphism means “one name, many forms.” The same method name can exhibit different behaviour in different situations. In Java, method overloading is an example of compile-time polymorphism, while method overriding is an example of runtime polymorphism.

Example: draw()method can draw a circle for Circle and a rectangle for Rectangle if both classes implement it in their own way.

Advantages of OOP

  1. Code Reusability:Existing code can be reused with the help of inheritance.
  2. Data Security:Encapsulation and access modifiers provide controlled access to data.
  3. Modularity:A program can be divided into separate classes and objects.
  4. Easy Maintenance:Organizing a program into small modules makes errors easier to find and updates easier to perform.
  5. Flexibility:Polymorphism allows different implementations of a common interface.

Question 2: Explain the drawbacks of Procedural Programming and the need of OOP. Differentiate between POP and OOP.

Procedural Oriented Programming (POP)

Procedural Oriented Programming (POP) is a programming approach in which a program is divided into small procedures or functions. Its main focus is on the steps that must be executed to complete a task. The C language is a common example.

Drawbacks of Procedural Programming

  1. Less Data Security:In many procedural programs, data is shared among functions, which can limit control over that data.
  2. Limited Code Reusability:Reusing and extending existing code can be comparatively difficult in large programs.
  3. Maintenance Difficult:As a program grows, understanding the relationships between functions and shared data can become difficult.
  4. Difficulty in Real-World Modelling:Representing real-world entities as a single unit containing both data and behaviour is not straightforward.
  5. Data and Functions Are Separate:In POP, data and functions generally remain separate, so extra care is required when handling data.

Need of Object Oriented Programming

The OOP approach helps overcome several limitations of procedural programming. OOP combines data and methods into classes. This makes it easier to design programs around real-world objects, reuse code, and provide controlled access to data.

Difference Between POP and OOP

Basis POP OOP
1. Full Form Procedural Oriented Programming Object Oriented Programming
2. Main Focus Focuses on functions and procedures. Focuses on objects and classes.
3. Approach Generally follows a top-down approach. Generally follows a bottom-up approach.
4. Data and Functions Data and functions may remain separate. Data and methods are combined within a class.
5. Data Security Data-hiding facilities are limited. Encapsulation and access modifiers provide controlled access.
6. Reusability Code reusability is comparatively limited. Reusability can be achieved through inheritance and composition.
7. Suitable For Suitable for small, procedure-focused programs. Useful for organizing large and complex applications.
8. Examples C, Pascal Java, C++, C#

Conclusion

In POP, a program is organized around functions, whereas in OOP it is organized around objects and classes. Features such as encapsulation, inheritance, and polymorphism help OOP organize the development of large software applications.

Question 3: What is JVM? Explain its working and how Java is platform independent.

JVM (Java Virtual Machine)

The full form of JVMJava Virtual Machineis Java Virtual Machine. It is an important part of the Java Runtime Environment (JRE). The JVM is a virtual machine that executes Java bytecode. The Java compiler converts Java source code into bytecode, and the JVM executes that bytecode on the relevant system.

The JVM also handles responsibilities such as memory management, garbage collection, security, and runtime execution. JVM implementations are available for different operating systems.

Working of JVM

A Java program is generally executed through the following steps:

  1. Source Code:The programmer writes Java source code in a.java.java file.
  2. Compilation: Java compiler (javac) compiles the source code and generates bytecode.
  3. Bytecode:The compiled bytecode is generally stored in a.class.class file.
  4. Class Loader:The JVM Class Loader loads the required class files into memory.
  5. Bytecode Verification:The Bytecode Verifier checks the validity of the bytecode and performs safety-related checks.
  6. Execution Engine:The Execution Engine executes the bytecode. It may use an interpreter and a Just-In-Time (JIT) compiler.
  7. Output:The required result is obtained after the program has been executed.

Why is Java Platform Independent?

Java is called platform independent because the Java compiler converts source code into platform-neutral bytecode instead of machine-specific native code. This bytecode can be executed on any operating system through a compatible JVM for that system.

This concept is known as “Write Once, Run Anywhere (WORA).” It means that once bytecode has been generated, it can be run on different supported platforms using a compatible JVM.

  1. It executes Java bytecode.
  2. It helps run Java programs on different platforms.

  5. JIT compilation can improve execution performance.
Important:Java source code is not executed directly by the JVM. The compiler first converts it into bytecode, which is then executed by the JVM.

Question 5: Explain Java tokens and data types. Describe the primitive data types of Java.

Java Tokens

The smallest meaningful units of a Java program are called tokens. The Java compiler identifies source code as tokens. The main types of Java tokens are keywords, identifiers, literals, operators, and separators (or punctuators).

Types of Java Tokens

  1. Keywords:These are reserved words with predefined meanings in Java. They cannot be used as ordinary identifiers.Examples: class, int, if, public, static.
  2. Identifiers:Names given to classes, methods, variables, and other program elements are called identifiers.Examples: Student, total, display.
  3. Literals:Fixed values written directly in a program are called literals.Examples: 100, 3.14, 'A', "Java", true.
  4. Operators:They perform operations on values or variables.Examples: +, -, *, ==, &&.
  5. Separators:They are used to separate different parts of a program.Examples: (), {}, [], ;, ,.

Data Types in Java

A data type defines the kind of data that can be stored in a variable. Java is a statically typed language, so the data type must be specified when a variable is declared. Java data types are broadly divided into two categories:

  1. Primitive Data Types:These are the basic built-in data types.
  2. Non-Primitive / Reference Types:These include classes, arrays, interfaces, and other reference types.

Question 6: Differentiate between Type Conversion and Type Casting in Java.

Type Conversion

Type conversion is the process of automatically converting a value from one data type to another compatible data type. In Java, converting a smaller compatible numeric type to a larger numeric type is generally called widening conversion. The programmer does not need to write an explicit cast.

Example:Assigning an int value to a double variable.

Java ProgramType Conversion
class ConversionExample {
    public static void main(String[] args) {
        int number = 25;
        double value = number;

        System.out.println("Integer: " + number);
        System.out.println("Double: " + value);
    }
}
Output 
Integer: 25
Double: 25.0

Type Casting

Type casting is the process in which the programmer explicitly converts a value to another compatible data type. In narrowing conversion, a type with a larger range can be converted to a type with a smaller range. This may result in data or precision loss.

Example:The cast operator is used to convert a double value to int(int)The decimal part is discarded.

Java ProgramType Casting
class CastingExample {
    public static void main(String[] args) {
        double price = 99.75;
        int amount = (int) price;

        System.out.println("Double: " + price);
        System.out.println("Integer: " + amount);
    }
}
Output 
Double: 99.75
Integer: 99

Difference Between Type Conversion and Type Casting

Basis Type Conversion Type Casting
1. Meaning Automatic conversion from one compatible type to another. Explicit conversion performed by the programmer.
2. Control The compiler performs the conversion. The programmer writes a cast operator.
3. Operator No explicit cast operator is required. A cast operator such as (int)is used.
4. Direction Often used for widening conversions. Often used for narrowing conversions.
5. Data Loss Precision is not lost in ordinary numeric widening conversions. Data or precision may be lost.
6. Example double d = 10; int n = (int) 10.5;

Conclusion

Type conversion is automatic, whereas type casting uses an explicit cast operator written by the programmer. Possible data loss should be considered when performing narrowing conversions.

Question 10: Explain switch statement in Java and differentiate it from if-else statement.

switch Statement

In Java, theswitchswitch statement is used to select one block from multiple alternatives based on the value of an expression. It is useful when the value of a variable or expression must be compared with several fixed cases.

Syntax of switch Statement

Java Syntaxswitch
switch (expression) {
    case value1:
        // statements
        break;
    case value2:
        // statements
        break;
    default:
        // default statements
}

Important Parts of switch

  1. switch:It evaluates the value of the expression.
  2. case:Each case defines a possible matching value.
  3. break:In a traditional switch statement, break exits the current switch block. If break is omitted, control can fall through to the next case.
  4. default:The default block executes when no case matches. It is optional.

Example Program of switch Statement

Java ProgramDay Selection
class SwitchExample {
    public static void main(String[] args) {
        int day = 3;

        switch (day) {
            case 1:
                System.out.println("Monday");
                break;
            case 2:
                System.out.println("Tuesday");
                break;
            case 3:
                System.out.println("Wednesday");
                break;
            default:
                System.out.println("Invalid day");
        }
    }
}
Output 
Wednesday

Working of switch Statement

  1. First, the switch expression is evaluated.
  2. Its value is compared with the available case labels.
  3. When a matching case is found, its statements begin to execute.
  4. When break is encountered, the switch statement terminates.
  5. If no case matches and a default block is present, the default block is executed.

Difference Between switch and if-else

Basis switch Statement if-else Statement
1. Purpose Matches the value of an expression against multiple case labels. Checks one or more boolean conditions.
2. Conditions Convenient for fixed case values. Suitable for ranges, relational conditions, and complex logical conditions.
3. Readability Makes code clearer when there are many fixed choices. Can be more flexible and readable for complex conditions.
4. break In a traditional switch, break is used to prevent fall-through. A break statement is not required in if-else.
5. Default Case The default block is optional. The else block is optional.
6. Example Menu selection, day numbers, and fixed options. Age checks, marks ranges, and multiple conditions.

Advantages of switch Statement

  1. It makes handling multiple fixed choices easier.
  2. The code can be more organized than using many else-if conditions.
  3. It is useful in menu-driven programs.
  4. The default case can handle values that do not match any case.
