Question 11: Explain Arrays in Java. Write a Java program to multiply two 3×3 matrices.

Array in Java

Array Java में एक ऐसा data structure है जिसका उपयोग same data type के multiple values को एक single variable name के अंतर्गत store करने के लिए किया जाता है। Array में प्रत्येक element का एक index होता है। Java में array indexing zero से शुरू होती है, अर्थात पहले element का index 0 होता है।

Array का size create करते समय specify किया जाता है और एक बार create होने के बाद उसका length fixed रहता है। Java में arrays objects होते हैं और उन्हें new keyword की मदद से create किया जा सकता है।

Characteristics of Array

  1. Same Data Type: एक array में सामान्यतः एक ही declared type के elements store होते हैं।
  2. Fixed Length: Array create होने के बाद उसका size change नहीं किया जा सकता।
  3. Index Based Access: Elements को index number से access किया जाता है।
  4. Zero Based Indexing: First element का index 0 होता है।
  5. Memory: Array elements एक ही array object का हिस्सा होते हैं और index से access किए जाते हैं।

Types of Arrays in Java

1. One-Dimensional Array

One-dimensional array में elements एक sequence या list के रूप में store होते हैं। इसे एक index की मदद से access किया जाता है।

Declaration: int[] marks;

Creation: marks = new int[5];

2. Two-Dimensional Array

Two-dimensional array rows और columns के रूप में data store करता है। इसे matrix की तरह समझा जा सकता है और elements को दो indexes से access किया जाता है। Java में 2D array वास्तव में arrays का array होता है।

Declaration: int[][] matrix = new int[3][3];

Example of a 3 × 3 Array
matrix[0][0] matrix[0][1] matrix[0][2]
matrix[1][0] matrix[1][1] matrix[1][2]
matrix[2][0] matrix[2][1] matrix[2][2]

पहला index row को और दूसरा index column को represent करता है।

Advantages of Arrays

  1. एक ही नाम से कई values store की जा सकती हैं।
  2. Index की मदद से elements को आसानी से access किया जा सकता है।
  3. Loops के साथ array elements को process करना आसान होता है।
  4. Matrix और tabular data represent करने में उपयोगी है।

Java Program to Multiply Two 3×3 Matrices

Matrix multiplication में पहली matrix की row और दूसरी matrix के column के corresponding elements को multiply करके उनका sum निकाला जाता है। नीचे दिए गए program में दो 3×3 matrices multiply की गई हैं।

Java Program3×3 Matrix Multiplication
class MatrixMultiplication {
    public static void main(String[] args) {
        int[][] a = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        int[][] b = {
            {9, 8, 7},
            {6, 5, 4},
            {3, 2, 1}
        };

        int[][] result = new int[3][3];

        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                for (int k = 0; k < 3; k++) {
                    result[i][j] += a[i][k] * b[k][j];
                }
            }
        }

        System.out.println("Multiplication Result:");
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                System.out.print(result[i][j] + "\\t");
            }
            System.out.println();
        }
    }
}
Output 
Multiplication Result:
30    24    18
84    69    54
138   114   90

Explanation of Program

  1. दो integer 3×3 arrays a और b declare की गई हैं।
  2. result नाम की एक तीसरी 3×3 array बनाई गई है। इसके elements initially zero होते हैं।
  3. तीन nested loops का उपयोग row, column और multiplication के common index को traverse करने के लिए किया गया है।
  4. result[i][j] += a[i][k] * b[k][j] प्रत्येक result cell का sum calculate करता है।
  5. अंत में result matrix print की जाती है।

Question 12: Explain Scanner class for input/output in Java and describe Methods.

Scanner Class in Java

Scanner Java की एक predefined class है, जिसका उपयोग keyboard या किसी अन्य input source से data read करने के लिए किया जाता है। यह java.util package में उपलब्ध होती है। Scanner की मदद से int, float, double, String और अन्य types का input लिया जा सकता है।

import java.util.Scanner;

class ScannerExample {
    public static void main(String[] args) {

Question 14: What is a Constructor in Java? Explain its characteristics, purpose and types.

Constructor in Java

Constructor एक special member होता है जिसका उपयोग object create होने पर object को initialize करने के लिए किया जाता है। Constructor का नाम class के नाम के समान होता है और इसका कोई return type नहीं होता, void भी नहीं। Constructor को सामान्यतः new keyword के साथ object creation के समय call किया जाता है।

Characteristics of Constructor

  1. Constructor का नाम class के नाम के समान होता है।
  2. Constructor का कोई return type नहीं होता।
  3. Object create होने पर constructor invoke होता है।
  4. Constructor overloaded हो सकता है।
  5. Constructor inherit नहीं होता।
  6. यदि programmer कोई constructor declare नहीं करता, तो compiler default no-argument constructor provide करता है।

Purpose of Constructor

  • Object के instance variables को initial values देना।
  • Object create होते समय required initialization perform करना।
  • Object को valid initial state में लाना।

Types of Constructors

1. Default Constructor

यदि किसी class में programmer कोई constructor declare नहीं करता, तो Java compiler उस class के लिए default no-argument constructor provide करता है। यह fields को उनकी default values देता है। यदि programmer कोई भी constructor declare कर देता है, तो compiler automatic default constructor नहीं देता।

2. No-Argument Constructor

Programmer द्वारा बनाया गया ऐसा constructor जिसमें कोई parameter नहीं होता, no-argument constructor कहलाता है। इसे default constructor से अलग समझना चाहिए, क्योंकि यह explicitly programmer लिखता है।

3. Parameterized Constructor

जिस constructor में one or more parameters होते हैं, उसे parameterized constructor कहते हैं। इसका उपयोग object को अलग-अलग initial values देने के लिए किया जाता है।

Example Program of Constructors

Java ProgramConstructor Types
class Student {
    String name;
    int rollNo;

    // No-argument constructor
    Student() {
        name = "Not Assigned";
        rollNo = 0;
    }

    // Parameterized constructor
    Student(String n, int r) {
        name = n;
        rollNo = r;
    }

    void display() {
        System.out.println(name + " - " + rollNo);
    }

    public static void main(String[] args) {
        Student s1 = new Student();
        Student s2 = new Student("Amit", 101);

        s1.display();
        s2.display();
    }
}
Output 
Not Assigned - 0
Amit - 101

Basis Constructor Method
1. Purpose Object initialize करने के लिए। Specific task perform करने के लिए।
2. Name Class के नाम के समान होता है। कोई valid method name हो सकता है।
3. Return Type कोई return type नहीं होता। Return type declare करना आवश्यक है; void भी हो सकता है।
4. Invocation Object creation के समय invoke होता है। Method call के माध्यम से invoke होता है।
5. Inheritance Inherit नहीं होता। Accessible methods inherit हो सकते हैं और override भी हो सकते हैं।

Question 15: Explain Local, Instance and Static Variables. Differentiate between Static and Non-Static Methods.

Variables in Java

Variable एक named memory location या storage reference है जिसका उपयोग program में data represent करने के लिए किया जाता है। Java में variables को उनके declaration और usage के आधार पर local, instance और static variables में समझा जाता है।

1. Local Variable

Local variable किसी method, constructor या block के अंदर declare किया जाता है। इसका scope उसी method या block तक सीमित रहता है। Local variable को उपयोग करने से पहले initialize करना आवश्यक होता है, क्योंकि compiler इसे automatic default value नहीं देता।

2. Instance Variable

Instance variable class के अंदर लेकिन methods और constructors के बाहर declare किया जाता है और इसे static keyword नहीं दिया जाता। प्रत्येक object के पास instance variable की अपनी अलग copy होती है। यदि explicitly initialize न किया जाए, तो इसे default value मिलती है।

3. Static Variable

Static variable class के अंदर static keyword के साथ declare किया जाता है। इसकी एक shared copy class के सभी objects के लिए होती है। इसे class name के माध्यम से access करना बेहतर practice है।

Example Program of Variables

Java ProgramLocal, Instance and Static
class VariableExample {
    int instanceValue = 10;
    static int staticValue = 20;

    void show() {
        int localValue = 30;

        System.out.println("Instance: " + instanceValue);
        System.out.println("Static: " + staticValue);
        System.out.println("Local: " + localValue);
    }

    public static void main(String[] args) {
        VariableExample obj = new VariableExample();
        obj.show();
    }
}
Output 
Instance: 10

Static Method

Static method वह method है जिसे static keyword के साथ declare किया जाता है। यह class से belong करता है और इसे object बनाए बिना class name से call किया जा सकता है। Static method directly केवल static members को access कर सकता है; instance members को access करने के लिए object reference की आवश्यकता होती है।

Non-Static Method

Non-static method वह method है जिसे static keyword के बिना declare किया जाता है। यह object से belong करता है और सामान्यतः इसे call करने के लिए class का object आवश्यक होता है। यह static और instance दोनों members को access कर सकता है।

Question 16: What is a Package in Java? Explain how to create, access and import packages. Also explain CLASSPATH.

Package in Java

Package Java में related classes, interfaces और sub-packages को एक group में organize करने का तरीका है। Package का उपयोग name conflicts कम करने, code को व्यवस्थित रखने और access control में मदद करने के लिए किया जाता है। Java में built-in packages और user-defined packages दोनों होते हैं।

Types of Packages

1. Built-in Packages

ये Java API में पहले से available packages होते हैं। Examples: java.lang, java.util, java.io, java.net. java.lang package automatically import होता है।

2. User-Defined Packages

Programmer अपनी classes को organize करने के लिए स्वयं package create कर सकता है। इसे user-defined package कहते हैं।

Steps to Create a User-Defined Package

  1. Java source file की शुरुआत में package declaration लिखें।
  2. Package के अंदर class या interface declare करें।
  3. Source file को suitable folder structure में compile करें।
  4. दूसरी class में import statement लिखकर package member use करें या fully qualified name का उपयोग करें।

Example: Creating a Package

पहली file का नाम Message.java रखें:

}

Basis String StringBuffer

Question 19: Explain the different Access Specifiers in Java: private, public, protected and default.

Access Specifiers in Java

Access Specifiers या Access Modifiers Java में यह define करते हैं कि class के variables, methods और constructors को कहाँ से access किया जा सकता है। इनका उपयोग data hiding, encapsulation और controlled access के लिए किया जाता है। Java में चार access levels हैं: private, default (package-private), protected और public.

Types of Access Specifiers

1. private

private members को केवल उसी class के अंदर access किया जा सकता है जिसमें वे declare किए गए हैं। यह सबसे restrictive access level है और data hiding के लिए उपयोगी है।

2. default (Package-Private)

जब किसी member के साथ कोई access modifier नहीं लिखा जाता, तो उसे default या package-private access मिलता है। ऐसे members को उसी package की classes access कर सकती हैं, लेकिन दूसरे package की unrelated classes नहीं।

3. protected

protected members को same package की classes access कर सकती हैं। दूसरे package में ये members subclasses के माध्यम से access किए जा सकते हैं, inheritance rules के अधीन।

4. public

public members को accessible classes द्वारा किसी भी package से access किया जा सकता है, बशर्ते enclosing class भी accessible हो। यह सबसे open access level है।

Access Specifiers Comparison Table

Access Modifier Same Class Same Package Subclass in Other Package Other Package (Non-subclass)
private Yes No No No
default Yes Yes No No
protected Yes Yes Yes, through inheritance access rules No
public Yes Yes Yes Yes

Important Points

  1. Top-level classes केवल public या package-private हो सकती हैं; top-level class को private या protected declare नहीं किया जा सकता।
  2. Private members को सामान्यतः उसी class के methods के माध्यम से access किया जाता है।
  3. Protected का दूसरे package में access केवल subclass context में Java के access rules के अनुसार होता है।
  4. Access modifiers code security और maintainability में मदद करते हैं, लेकिन अपने आप encryption provide नहीं करते।

Question 20: What is Constructor Chaining in Java? Explain the order of constructor invocation with an example.

Constructor Chaining

Constructor Chaining वह process है जिसमें एक constructor से उसी class के दूसरे constructor या parent class के constructor को call किया जाता है। Java में same class के constructor को call करने के लिए this() और parent class के constructor को call करने के लिए super() का उपयोग किया जाता है।

Uses of Constructor Chaining

  1. Constructor initialization code को reuse करने में मदद करता है।
  2. Parent class के data को initialize करने की सुविधा देता है।
  3. Different constructors के बीच common initialization repeat करने की आवश्यकता कम करता है।

1. Constructor Chaining Using this()

this() का उपयोग same class के दूसरे constructor को call करने के लिए किया जाता है। इसे constructor की पहली statement होना चाहिए।

Java Programthis() Constructor Chaining
class Student {
    Student() {
        this("Unknown");
        System.out.println("No-argument constructor");
    }

    Student(String name) {
        System.out.println("Name: " + name);
    }

    public static void main(String[] args) {
        Student s = new Student();
    }
}
Output 
Name: Unknown
No-argument constructor

2. Constructor Chaining Using super()

super() का उपयोग child class constructor से parent class constructor call करने के लिए किया जाता है। यदि programmer constructor में explicit this() या super() call नहीं लिखता, तो compiler सामान्यतः accessible no-argument superclass constructor call insert करता है।

Child Constructor

Important Rules of Constructor Chaining

  1. this() और super() constructor में पहली statement होनी चाहिए।
  2. एक ही constructor में this() और super() दोनों को directly call नहीं किया जा सकता।
  3. this() same class के दूसरे constructor को call करता है।
  4. super() immediate parent class के constructor को call करता है।
  5. Constructor chaining की वजह से parent initialization child initialization से पहले होता है।

Difference Between this() and super()

Basis this() super()
1. Purpose Same class के दूसरे constructor को call करता है। Immediate parent class के constructor को call करता है।
2. Use Current class के constructors के बीच chaining। Parent और child class constructors के बीच chaining।
3. Position Constructor की first statement होना चाहिए। Constructor की first statement होना चाहिए।
4. Together एक constructor में super() के साथ directly use नहीं हो सकता। एक constructor में this() के साथ directly use नहीं हो सकता।
