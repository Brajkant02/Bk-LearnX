Question 11: Explain Arrays in Java. Write a Java program to multiply two 3×3 matrices.

Array in Java

An array in Java is a data structure used to store multiple values of the same data type under a single variable name. Each array element has an index. Array indexing in Java starts at zero, so the first element has index 0.

The size of an array is specified when it is created and remains fixed afterward. Arrays are objects in Java and can be created using the new keyword की मदद से create किया जा सकता है।

Characteristics of Array

  1. Same Data Type: An array generally stores elements of the same declared type.
  2. Fixed Length: The size of an array cannot be changed after it has been created.
  3. Index Based Access: Elements are accessed using their index numbers.
  4. Zero Based Indexing: The first element has index 0.
  5. Memory: Array elements belong to the same array object and are accessed by index.

Types of Arrays in Java

1. One-Dimensional Array

A one-dimensional array stores elements in a sequence or list and is accessed using a single index.

Declaration: int[] marks;

Creation: marks = new int[5];

2. Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It can be viewed as a matrix, and its elements are accessed using two indexes. In Java, a 2D array is actually an array of arrays.

Declaration: int[][] matrix = new int[3][3];

Example of a 3 × 3 Array
matrix[0][0] matrix[0][1] matrix[0][2]
matrix[1][0] matrix[1][1] matrix[1][2]
matrix[2][0] matrix[2][1] matrix[2][2]

The first index represents the row, and the second index represents the column.

Advantages of Arrays

  1. Multiple values can be stored under a single name.
  2. Elements can be accessed easily using indexes.
  3. Array elements can be processed easily using loops.
  4. Arrays are useful for representing matrices and tabular data.

Java Program to Multiply Two 3×3 Matrices

In matrix multiplication, corresponding elements of a row of the first matrix and a column of the second matrix are multiplied, and their products are added. The following program multiplies two 3×3 matrices.

Java Program3×3 Matrix Multiplication
class MatrixMultiplication {
    public static void main(String[] args) {
        int[][] a = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };

        int[][] b = {
            {9, 8, 7},
            {6, 5, 4},
            {3, 2, 1}
        };

        int[][] result = new int[3][3];

        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                for (int k = 0; k < 3; k++) {
                    result[i][j] += a[i][k] * b[k][j];
                }
            }
        }

        System.out.println("Multiplication Result:");
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                System.out.print(result[i][j] + "\\t");
            }
            System.out.println();
        }
    }
}
Output 
Multiplication Result:
30    24    18
84    69    54
138   114   90

  1. Two integer 3×3 arrays, a and b, are declared.
  2. result A third 3×3 array named
  3. Three nested loops are used to traverse the rows, columns, and common multiplication index.
  4. result[i][j] += a[i][k] * b[k][j] calculates the sum for each cell of the result matrix.
  5. Finally, the result matrix is printed.

Question 14: What is a Constructor in Java? Explain its characteristics, purpose and types.

Constructor in Java

A constructor is a special member used to initialize an object when it is created. A constructor has the same name as its class and has no return type, not even void. A constructor is generally called at the time of object creation using the new keyword.

Characteristics of Constructor

  1. A constructor has the same name as its class.
  2. A constructor has no return type.
  3. The constructor is invoked when an object is created.
  4. Constructors can be overloaded.
  5. Constructors are not inherited.
  6. If the programmer does not declare any constructor, the compiler provides a default no-argument constructor.

Purpose of Constructor

  • To assign initial values to an object's instance variables.
  • To perform the required initialization when an object is created.
  • To place the object in a valid initial state.

Types of Constructors

1. Default Constructor

If the programmer does not declare any constructor in a class, the Java compiler provides a default no-argument constructor for that class. It assigns default values to the fields. If the programmer declares any constructor, the compiler does not provide an automatic default constructor.

2. No-Argument Constructor

A constructor written by the programmer that has no parameters is called a no-argument constructor. It should be distinguished from a default constructor because it is explicitly written by the programmer.

3. Parameterized Constructor

A constructor with one or more parameters is called a parameterized constructor. It is used to initialize objects with different values.

Example Program of Constructors

Java ProgramConstructor Types
class Student {
    String name;
    int rollNo;

    // No-argument constructor
    Student() {
        name = "Not Assigned";
        rollNo = 0;
    }

    // Parameterized constructor
    Student(String n, int r) {
        name = n;
        rollNo = r;
    }

    void display() {
        System.out.println(name + " - " + rollNo);
    }

    public static void main(String[] args) {
        Student s1 = new Student();
        Student s2 = new Student("Amit", 101);

        s1.display();
        s2.display();
    }
}

Question 15: Explain Local, Instance and Static Variables. Differentiate between Static and Non-Static Methods.

Variables in Java

A variable is a named storage location used to represent data in a program. In Java, variables are commonly classified as local, instance, and static variables based on where and how they are declared.

1. Local Variable

A local variable is declared inside a method, constructor, or block. Its scope is limited to that method or block. A local variable must be initialized before it is used because the compiler does not assign it an automatic default value.

2. Instance Variable

An instance variable is declared inside a class but outside methods and constructors, and it is not declared with the static keyword. Each object has its own separate copy of an instance variable. If it is not explicitly initialized, it receives a default value.

3. Static Variable

A static variable is declared inside a class with the static keyword. A single shared copy is used by all objects of the class. Accessing it through the class name is considered better practice.

Question 16: What is a Package in Java? Explain how to create, access and import packages. Also explain CLASSPATH.

Package in Java

A package in Java is a way to organize related classes, interfaces, and sub-packages into a group. Packages help reduce name conflicts, organize code, and provide access control. Java has both built-in and user-defined packages.

Types of Packages

1. Built-in Packages

These packages are already available in the Java API. Examples: java.lang, java.util, java.io, and java.net. The java.lang package is imported automatically.

2. User-Defined Packages

A programmer can create a package to organize their own classes. This is called a user-defined package.

Steps to Create a User-Defined Package

  1. Write the package declaration at the beginning of the Java source file.
  2. Declare a class or interface inside the package.
  3. Compile the source file using a suitable folder structure.
  4. Use the package member by writing an import statement in another class, or use its fully qualified name.

Example: Creating a Package

Autoboxing in Java

Autoboxing is the process in which the Java compiler automatically converts a primitive data type value into an object of its corresponding wrapper class. For example, converting an int into an Integer is called autoboxing.

Each primitive type in Java has a corresponding wrapper class, such as Integer for int, Character for char, and Double for double.

Primitive Types and Wrapper Classes

Primitive Type Wrapper Class

short Short
int Integer
long Long

Example of Autoboxing

Java ProgramAutoboxing and Unboxing
class AutoboxingExample {
    public static void main(String[] args) {
        int number = 100;

        // Autoboxing: int to Integer
        Integer obj = number;

        // Unboxing: Integer to int
        int value = obj;

        System.out.println("Wrapper Object: " + obj);
        System.out.println("Primitive Value: " + value);
    }
}
Output 
Wrapper Object: 100
Primitive Value: 100

Unboxing

The process of automatically converting a wrapper class object into its corresponding primitive type is called unboxing. In the program above, int value = obj; is an example of unboxing.

String in Java

String is a Java class used to represent a sequence of characters. String objects are immutable, which means their contents cannot be changed after the object is created. If a modification operation is performed on a String, a new String object may be created.

Example: String name = "Java";

StringBuffer in Java

StringBuffer is a Java class used to create a mutable sequence of characters. Mutable means that the contents of the same object can be modified by appending, inserting, deleting, or replacing characters. StringBuffer methods are synchronized, so they provide thread-safe operations when the object is shared between multiple threads, unlike StringBuilder.

Example: StringBuffer text = new StringBuffer("Java");

Example Program of String and StringBuffer

Java ProgramString and StringBuffer
class StringExample {

        String s = "Hello";
        s.concat(" Java");

        System.out.println("String: " + s);

        StringBuffer sb = new StringBuffer("Hello");
        sb.append(" Java");

        System.out.println("StringBuffer: " + sb);
    }
}
Output 
String: Hello
StringBuffer: Hello Java

In the program above, because String is immutable, the original String does not change when the result of concat() is not assigned. In StringBuffer, append() modifies the contents of the same object.

Question 19: Explain the different Access Specifiers in Java: private, public, protected and default.

Access Specifiers in Java

Access specifiers, also called access modifiers, define where a class's variables, methods, and constructors can be accessed from. They are used for data hiding, encapsulation, and controlled access. Java has four access levels: private, default (package-private), protected, and public.

Types of Access Specifiers

1. private

private members can be accessed only within the class in which they are declared. This is the most restrictive access level and is useful for data hiding.

2. default (Package-Private)

When no access modifier is written for a member, it has default or package-private access. Such members can be accessed by classes in the same package, but not by unrelated classes in another package.

3. protected

protected members can be accessed by classes in the same package. In another package, these members can be accessed through subclasses, subject to Java's inheritance access rules.

4. public

public members can be accessed from any package by classes that can access the enclosing class. This is the most open access level.

private Yes No No No
default Yes Yes No No
protected Yes Yes Yes, through inheritance access rules No
public Yes Yes Yes Yes

        System.out.println("Default: " + b);

Important Points

  1. Top-level classes can be declared only as public or package-private; a top-level class cannot be declared private or protected.
  2. Private members are generally accessed through methods of the same class.
  3. Access to protected members from another package is allowed only in a subclass context, according to Java's access rules.
  4. Access modifiers help with code security and maintainability, but they do not provide encryption by themselves.

Question 20: What is Constructor Chaining in Java? Explain the order of constructor invocation with an example.

Constructor Chaining

Constructor chaining is the process of calling another constructor of the same class or a constructor of the parent class from a constructor. In Java, this() is used to call another constructor in the same class, and super() is used to call a parent class constructor.

Uses of Constructor Chaining

  1. It helps reuse constructor initialization code.
  2. It allows parent class data to be initialized.
  3. It reduces the need to repeat common initialization code across different constructors.

1. Constructor Chaining Using this()

this() is used to call another constructor in the same class. It must be the first statement in the constructor.

    Student(String name) {
        System.out.println("Name: " + name);
    }

        Student s = new Student();
    }
}

super() is used to call a parent class constructor from a child class constructor. If the programmer does not explicitly write a this() or super() call in a constructor, the compiler generally inserts a call to the accessible no-argument superclass constructor.

When an object of a child class is created in an inheritance hierarchy, constructor execution begins with the parent class and proceeds down to the child class. If the inheritance chain has multiple levels, the constructor of the highest superclass executes first, followed by the constructors of the classes below it.

Important Rules of Constructor Chaining

  1. this() and super() must be the first statement in a constructor.
  2. this() and super() cannot both be called directly in the same constructor.
  3. this() calls another constructor in the same class.
  4. super() calls the constructor of the immediate parent class.
  5. Constructor chaining ensures that parent initialization occurs before child initialization.
