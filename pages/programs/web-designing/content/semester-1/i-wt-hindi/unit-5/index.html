JQuery Concept

jQuery एक fast, small और feature-rich JavaScript library है। इसका main purpose JavaScript को आसान बनाना है। JavaScript में DOM selection, event handling, animations और AJAX जैसे tasks के लिए कई lines code लिखना पड़ता है, लेकिन jQuery में वही काम कम code में किया जा सकता है।

jQuery का slogan है: Write less, do more. इसका मतलब है कि कम code लिखकर ज्यादा काम किया जा सकता है। jQuery especially DOM manipulation, HTML element selection, CSS change, event handling, hide/show, fade, slide effects और AJAX operations के लिए popular रही है।

Modern JavaScript में कई features directly available हो गए हैं, इसलिए new projects में pure JavaScript या frameworks जैसे React, Vue आदि भी use होते हैं। फिर भी syllabus और पुराने web projects में jQuery important है क्योंकि बहुत सारी websites और plugins आज भी jQuery पर based हैं।

Why jQuery Was Created

  • JavaScript DOM manipulation को easy बनाने के लिए।
  • Different browsers के behavior को handle करने के लिए।
  • Animations और effects को simple बनाने के लिए।
  • Event handling को short और readable बनाने के लिए।
  • AJAX operations को आसान बनाने के लिए।

JavaScript vs jQuery Example

Same काम JavaScript और jQuery में compare करके देखें।

// JavaScript
document.getElementById("heading").style.color = "blue";
// jQuery
$("#heading").css("color", "blue");

Basic jQuery Syntax

$(selector).action();
Part Meaning
$ jQuery का short symbol है।
selector HTML element select करता है।
action() Selected element पर काम perform करता है।

Example

$("#box").hide();

यह code id="box" वाले element को hide कर देगा।

Real Life Example:
अगर webpage पर “Show Answer” button click करने पर answer smoothly open हो, तो यह jQuery effects से आसानी से बनाया जा सकता है।
Remember:
jQuery JavaScript की library है, अलग programming language नहीं। यह JavaScript code को short और आसान बनाती है।

Adding JQuery to Web Page

jQuery use करने से पहले उसे web page में add करना जरूरी होता है। HTML page में jQuery add करने के दो common methods हैं: CDN link के through और local downloaded file के through। CDN method beginner और quick testing के लिए easy होता है, जबकि local file method offline या controlled project setup के लिए useful होता है।

Adding jQuery Using CDN

CDN का full form Content Delivery Network है। इसमें jQuery file internet server से load होती है।

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

Complete CDN Example

<!DOCTYPE html>
<html>
<head>
  <title>jQuery Example</title>
</head>
<body>

  <h1 id="heading">Hello jQuery</h1>

  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

  <script>
    $("#heading").css("color", "blue");
  </script>

</body>
</html>
Output:
Heading blue color में show होगी।

Adding jQuery Using Local File

Local method में jQuery file download करके project folder में रखी जाती है और HTML में link की जाती है।

<script src="jquery-min.js"></script>

Correct Script Order

jQuery code लिखने से पहले jQuery library load होनी चाहिए। अगर jQuery library के पहले jQuery code लिख दिया गया, तो $ is not defined error आ सकता है।

<!-- Correct order -->
<script src="jquery-min.js"></script>
<script src="script.js"></script>

Document Ready Function

jQuery code को तब run करना चाहिए जब HTML document पूरी तरह load हो जाए। इसके लिए document ready function use किया जाता है।

$(document).ready(function() {
  $("p").css("color", "green");
});

Short Form of Document Ready

$(function() {
  $("p").hide();
});

CDN vs Local jQuery

Basis CDN Local File
Source Internet server से load होती है। Project folder से load होती है।
Internet Need Internet required हो सकता है। Offline भी work कर सकती है।
Setup Easy और quick। File download करनी पड़ती है।
Use Testing और online projects। Offline lab/practical और controlled projects।

Common Mistakes

  • jQuery library include करना भूल जाना।
  • jQuery code library load होने से पहले लिख देना।
  • CDN link गलत लिखना।
  • Local file का path गलत देना।
Remember:
jQuery code run करने से पहले jQuery library page में load होना जरूरी है।

JQuery Selectors

jQuery selectors का use HTML elements को select करने के लिए किया जाता है। jQuery selectors CSS selectors जैसे ही होते हैं। jQuery में selected elements पर actions perform किए जाते हैं, जैसे hide, show, css change, text change, value read आदि।

jQuery selector syntax में dollar sign $ और parentheses का use होता है। Selector quotes के अंदर लिखा जाता है।

Basic Syntax

$(selector).action();

Element Selector

Element selector tag name से elements select करता है।

$("p").hide();

यह सभी paragraphs को hide कर देगा।

ID Selector

ID selector unique element select करता है। CSS की तरह jQuery में भी ID selector # से लिखा जाता है।

$("#heading").css("color", "red");

Class Selector

Class selector same class वाले elements select करता है। Class selector dot . से लिखा जाता है।

$("box").hide();

Universal Selector

Universal selector सभी elements को select करता है।

$("*").css("font-family", "Arial");

Grouping Selector

Multiple selectors को एक साथ select किया जा सकता है।

$("h1-p.note").css("color", "blue");

Attribute Selector

Attribute selector किसी specific attribute वाले elements select करता है।
