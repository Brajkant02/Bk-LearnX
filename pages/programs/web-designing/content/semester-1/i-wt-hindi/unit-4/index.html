JavaScript Introduction

JavaScript एक popular programming तथा scripting language है जिसका मुख्य उपयोग Web Pages को Dynamic, Interactive तथा Functional बनाने के लिए किया जाता है। केवल HTML से किसी Web Page की structure तैयार की जाती है और CSS से उसका design तथा appearance बनाया जाता है, जबकि JavaScript की सहायता से उस Web Page में Logic, Interaction और Dynamic Behaviour जोड़ा जाता है।

उदाहरण के लिए किसी Website पर जब User किसी Button पर Click करता है और उसके बाद कोई message दिखाई देता है, किसी Form को Submit करने पर validation होती है, Menu Open या Close होता है, Image बदलती है या किसी Element का content dynamically update होता है, तो इन कार्यों में JavaScript महत्वपूर्ण भूमिका निभा सकती है।

JavaScript को मुख्य रूप से Client-Side पर Browser में execute किया जाता है, लेकिन आधुनिक समय में इसका उपयोग Server-Side development में भी किया जाता है। Node.js जैसे runtime environment की सहायता से JavaScript को Server पर भी run किया जा सकता है। इस प्रकार JavaScript का उपयोग केवल छोटे Web Page interactions तक सीमित नहीं है, बल्कि इसका उपयोग complete Web Applications बनाने में भी किया जाता है।

JavaScript एक Dynamically Typed language है। इसका अर्थ है कि Variable declare करते समय सामान्यतः उसका Data Type अलग से लिखना आवश्यक नहीं होता। Variable में रखी गई Value के आधार पर Runtime पर उसका type निर्धारित किया जाता है।

Why JavaScript is Used?

किसी सामान्य Static Web Page में Information पहले से निर्धारित होती है। User केवल उस Information को देख सकता है। JavaScript की सहायता से Website User के Actions के अनुसार Response दे सकती है। इसलिए modern Websites तथा Web Applications में JavaScript का बहुत महत्वपूर्ण स्थान है।

  • Web Pages को Interactive बनाने के लिए JavaScript का उपयोग किया जाता है।
  • User के Click, Mouse Movement, Keyboard Input तथा अन्य Events को Handle किया जा सकता है।
  • HTML Elements को dynamically Change किया जा सकता है।
  • Form Data को Validate किया जा सकता है।
  • Dynamic Content को Web Page पर Display किया जा सकता है।
  • Browser में Calculations तथा Logical Operations किए जा सकते हैं।
  • Web Applications में User Interaction को Control किया जा सकता है।

History of JavaScript

JavaScript को Brendan Eich ने 1995 में develop किया था। शुरुआत में इसका नाम LiveScript था, जिसे बाद में JavaScript नाम दिया गया। समय के साथ JavaScript में अनेक नए Features तथा Improvements जोड़े गए और यह Modern Web Development की एक प्रमुख language बन गई।

JavaScript के standardization के लिए ECMAScript standard का उपयोग किया जाता है। Modern JavaScript में let, const, Classes, Arrow Functions तथा अन्य features जैसे improvements शामिल हैं।

Basic Structure of JavaScript

JavaScript Code को HTML Document के अंदर <script> tag के बीच लिखा जा सकता है। Browser इस script को पढ़कर JavaScript Code को execute करता है। 

<script>

    console.log("Hello World");

</script>

ऊपर दिए गए Example में console.log() का उपयोग Browser के Developer Console में message display करने के लिए किया गया है। JavaScript को HTML Document में include करने के लिए <script> tag महत्वपूर्ण होता है।

First JavaScript Program

<!DOCTYPE html>
<html>

<head>
    <title>JavaScript Example</title>
</head>

<body>

    <h1>My First JavaScript Program</h1>

    <script>
        console.log("Hello World");
    </script>

</body>

</html>

इस Program में HTML का उपयोग Web Page की basic structure बनाने के लिए किया गया है तथा <script> tag के अंदर JavaScript Code लिखा गया है। जब Browser इस HTML File को Open करता है, तो JavaScript Code execute होता है और "Hello World" message Browser Console में दिखाई देता है।

JavaScript and CSS

CSS का मुख्य कार्य Web Page की Presentation और Styling करना है। JavaScript आवश्यकता के अनुसार CSS Properties को भी dynamically change कर सकती है। उदाहरण के लिए Button Click होने पर किसी Element का background, size, visibility या अन्य styling बदलना संभव है।

Client-Side JavaScript

जब JavaScript Code सीधे User के Web Browser में execute होता है, तो इसे Client-Side JavaScript कहा जाता है। इसका उपयोग User Interface, Form Validation, Events, DOM Manipulation तथा Interactive Web Pages के लिए किया जाता है।

उदाहरण के लिए यदि किसी Registration Form में User ने required field खाली छोड़ दी है और Website तुरंत "Please enter your name" message दिखाती है, तो यह Client-Side JavaScript का उदाहरण हो सकता है।

Server-Side JavaScript

जब JavaScript Code Server पर execute होता है, तो इसे Server-Side JavaScript कहा जाता है। इसका उपयोग Database से Data प्राप्त करने, Files के साथ काम करने, Server Requests Process करने तथा Web Application के Backend को develop करने के लिए किया जा सकता है।

Node.js JavaScript को Server-Side environment में run करने के लिए एक लोकप्रिय runtime environment है।

Variables in JavaScript

Variable एक named memory location या identifier है जिसका उपयोग Program में किसी Value को Store करने के लिए किया जाता है। JavaScript में Variables का उपयोग Number, String, Boolean, Object तथा अन्य प्रकार की Values को Store करने के लिए किया जाता है।

उदाहरण के लिए यदि हमें किसी Student का Name, Age तथा Marks Program में Store करना है, तो हम इन Values को Variables में रख सकते हैं। बाद में Program के किसी भी आवश्यक भाग में इन Variables का उपयोग करके उनकी Value को Read, Calculate या Modify किया जा सकता है।

Variable Declaration in JavaScript

JavaScript में Variable declare करने के लिए मुख्य रूप से var, let और const keywords का उपयोग किया जाता है।

Keyword Basic Meaning Reassignment
var Traditional तरीके से Variable declare करता है। Allowed
let Block-scoped Variable declare करता है। Allowed
const ऐसा Binding declare करता है जिसे Reassign नहीं किया जा सकता। Not Allowed

1. var Keyword

var JavaScript में Variable declare करने का traditional तरीका है। पुराने JavaScript Programs में इसका व्यापक उपयोग किया जाता था। var से declare किया गया Variable function-scoped होता है। 

var name = "Brajkant";
var age = 23;

console.log(name);
console.log(age);

ऊपर दिए गए Example में name Variable में String Value और age Variable में Number Value Store की गई है।

2. let Keyword

let Modern JavaScript में Variable Declaration के लिए widely used keyword है। यह Block Scope follow करता है। इसका उपयोग तब किया जाता है जब Variable की Value को Program के दौरान बाद में Change किया जा सकता हो। 

let marks = 70;

marks = 85;

console.log(marks);

यहाँ पहले marks की Value 70 है और बाद में उसे 85 कर दिया गया। इसलिए let ऐसे Variables के लिए उपयोगी है जिनकी Value को Reassign करना हो।

3. const Keyword

const का उपयोग ऐसे Variable Binding के लिए किया जाता है जिसे बाद में Reassign नहीं करना होता। const Variable को Declaration के समय Value देना आवश्यक होता है। 

const pi = 3.14159;

console.log(pi);

यदि किसी const Variable को बाद में नई Value Assign करने का प्रयास किया जाता है, तो Error प्राप्त होता है। 

const country = "India";

country = "Nepal";

ऊपर दिए गए Example में country को दोबारा नई Value Assign करने का प्रयास किया गया है, इसलिए यह valid reassignment नहीं है।

Variable Declaration और Initialization

Variable Declaration का अर्थ है Variable को create करना, जबकि Initialization का अर्थ है Variable को पहली Value देना। 

let age;        // Declaration

age = 23;       // Initialization

Declaration और Initialization एक ही Statement में भी की जा सकती है। 

let age = 23;

Rules for Naming Variables

JavaScript में Variable का नाम रखते समय कुछ Rules को follow करना आवश्यक होता है।

  1. Variable Name में Letters, Digits, Underscore तथा Dollar Sign का उपयोग किया जा सकता है।
  2. Variable Name किसी Digit से Start नहीं हो सकता।
  3. Variable Name में Space का उपयोग नहीं किया जाता।
  4. JavaScript Keywords को Variable Name के रूप में उपयोग नहीं किया जा सकता।
  5. JavaScript Variable Names Case-Sensitive होते हैं।
  6. Meaningful Variable Names का उपयोग करना बेहतर होता है।

Valid Variable Names

let name;
let studentName;
let age23;
let _marks;
let $price;

Invalid Variable Names

let 123name;       // Invalid

let student name;  // Invalid

let my-name;       // Invalid

let let;           // Invalid

Case Sensitivity

JavaScript Case-Sensitive language है। इसका अर्थ है कि Uppercase और Lowercase Letters को अलग-अलग माना जाता है। 

let name = "Rahul";

let Name = "Amit";

console.log(name);
console.log(Name);

यहाँ name और Name दो अलग-अलग Variables हैं क्योंकि दोनों की Capitalization अलग है।

Changing Variable Values

let तथा var से declare किए गए Variables की Value को आवश्यकता के अनुसार बदला जा सकता है। 

let city = "Kanpur";

city = "Lucknow";

console.log(city);

इस Example में पहले city की Value "Kanpur" थी। बाद में उसे "Lucknow" से Replace कर दिया गया।

Multiple Variables

एक Program में अनेक Variables declare किए जा सकते हैं। प्रत्येक Variable का अपना अलग Name और Value हो सकती है। 

let studentName = "Amit";
let age = 21;

console.log(studentName);

Variables with Different Data

ऊपर के Example में अलग-अलग Variables में String, Number तथा Boolean Values Store की गई हैं। JavaScript में Variable Declaration के समय सामान्यतः Data Type अलग से लिखना आवश्यक नहीं होता।

Scope of Variables

Scope यह निर्धारित करता है कि किसी Variable को Program के किस भाग में Access किया जा सकता है। JavaScript में var और let/const के Scope Rules अलग होते हैं।

Function Scope

var Function Scope follow करता है। इसका अर्थ है कि Function के अंदर declare किया गया var Variable सामान्यतः उसी Function के Scope में उपलब्ध होता है।

Block Scope

let और const Block Scope follow करते हैं। Block सामान्यतः { } braces के अंदर का Code Area होता है। 

if (true) {

    let message = "Hello";

    console.log(message);

}

ऊपर के Example में message Variable केवल उस Block के अंदर Access किया जा सकता है।

var, let और const में Difference

Basis var let const
Scope Function Scope Block Scope Block Scope
Reassign Yes Yes No
Redeclare in Same Scope Allowed Not Allowed Not Allowed
Modern Usage Mostly Legacy Code Common Common

Best Practices for Variables

  • Variable का Name meaningful रखें।
  • जहाँ Value Reassign करनी हो वहाँ let का उपयोग करें।
  • जहाँ Reassignment नहीं चाहिए वहाँ const का उपयोग करें।
  • Variable Names में consistent naming convention follow करें।
  • Unnecessary Global Variables बनाने से बचें।

Real Life Example

let productName = "Laptop";

let price = 50000;

let quantity = 2;

let total = price * quantity;

console.log(productName);

console.log(total);

इस Example में productName Product का Name, price उसकी Price, quantity खरीदे गए Products की संख्या और total Total Price को Store करता है। इस प्रकार Variables का उपयोग किसी E-Commerce Application में Product तथा Payment से संबंधित Data को temporarily process करने के लिए किया जा सकता है।

Exam Summary:
JavaScript में Variables का उपयोग Data को Store करने के लिए किया जाता है। Variable Declaration के लिए मुख्य keywords var, let और const हैं। var Function Scope follow करता है, जबकि let और const Block Scope follow करते हैं। let Variable को Reassign किया जा सकता है, जबकि const Binding को Reassign नहीं किया जा सकता। JavaScript में Variable Names Case-Sensitive होते हैं।

Data Types in JavaScript

Data Type यह बताता है कि किसी Variable में किस प्रकार का Data Store किया गया है। JavaScript में अलग-अलग प्रकार के Data को Store और Process करने के लिए विभिन्न Data Types का उपयोग किया जाता है। उदाहरण के लिए किसी Variable में Student का Name Store करना हो तो String का उपयोग किया जा सकता है, जबकि Age या Marks के लिए Number का उपयोग किया जाता है।

JavaScript एक Dynamically Typed Language है। इसका अर्थ है कि Variable को Declare करते समय सामान्यतः उसका Data Type अलग से Specify करने की आवश्यकता नहीं होती। JavaScript Runtime पर Variable में मौजूद Value के आधार पर उसके Data Type को निर्धारित करती है।

Exam Point:
Data Type किसी Variable में Store होने वाले Data के प्रकार को निर्धारित करता है। JavaScript में Data Types को मुख्य रूप से Primitive और Non-Primitive Categories में समझा जाता है।

Definition of Data Type

Definition:
"Data Type किसी Data या Value की प्रकृति को बताता है और यह निर्धारित करता है कि उस Data को Program में किस प्रकार Store तथा Process किया जाएगा।"

Primitive Data Types

Primitive Data Types basic या fundamental values को represent करते हैं। ये किसी single value को represent करते हैं और JavaScript में commonly used Data Types हैं।

1. String

String का उपयोग Text या Characters को Store करने के लिए किया जाता है। String को Single Quotes, Double Quotes या Template Literals में लिखा जा सकता है। 

let name = "Brajkant";

let city = 'Kanpur';

let message = `Welcome to JavaScript`;

ऊपर दिए गए सभी Examples में Text Data को String के रूप में Store किया गया है।

String Example

let studentName = "Rahul";

console.log(studentName);

यहाँ studentName Variable में "Rahul" एक String Value है।

2. Number

Number Data Type का उपयोग Numerical Values को Store करने के लिए किया जाता है। JavaScript में सामान्य Number values में Integer तथा Decimal दोनों प्रकार की Values को represent किया जा सकता है। 

let age = 23;

let marks = 85.5;

let price = 49999;

यहाँ age, marks और price सभी Number Values हैं।

Special Number Values

JavaScript में Number के साथ कुछ special values भी मिलती हैं, जैसे NaN तथा Infinity। 

console.log(10 / 0);

console.log("Hello" * 5);

3. Boolean

Boolean Data Type केवल दो Values को represent करता है: true और false। इसका उपयोग Conditions तथा Logical Decisions में बहुत अधिक किया जाता है। 

let isStudent = true;

let isLoggedIn = false;

उदाहरण के लिए किसी Website में यह Check करना हो कि User Login है या नहीं, तो Boolean Value का उपयोग किया जा सकता है।

4. Undefined

जब किसी Variable को Declare किया गया हो लेकिन उसे कोई Value Assign न की गई हो, तो उस Variable की Value सामान्यतः undefined होती है। 

let username;

console.log(username);

यहाँ username Variable Declare किया गया है, लेकिन उसमें कोई Value Assign नहीं की गई, इसलिए इसकी Value undefined होगी।

5. Null

null का उपयोग जानबूझकर किसी Variable में "कोई Value नहीं है" या "empty value" represent करने के लिए किया जाता है। यह undefined से अलग concept है। 

let selectedProduct = null;

console.log(selectedProduct);

यहाँ Developer ने जानबूझकर selectedProduct को null Value दी है।

undefined और null में Difference

Basis undefined null
Meaning Value अभी Assign नहीं हुई। जानबूझकर Empty Value दी गई।
Assignment Normally Value Assign नहीं की गई होती है। Developer explicitly null assign करता है।

6. BigInt

BigInt Data Type का उपयोग बहुत बड़े Integer Values को represent करने के लिए किया जाता है, जिन्हें सामान्य Number representation की safe integer range से बाहर होने पर exact रूप से represent करना आवश्यक हो। 

let largeNumber = 123456789012345678901234567890n;

console.log(largeNumber);

BigInt Number के अंत में n लगाकर लिखा जाता है।

7. Symbol

Symbol एक unique और immutable primitive value होती है। इसका उपयोग अक्सर Object के अंदर unique property keys बनाने के लिए किया जाता है। 

let id = Symbol("studentId");

console.log(id);

प्रत्येक Symbol अपने आप में unique होता है। इसलिए दो अलग-अलग Symbols में समान description होने पर भी वे अलग Values माने जाते हैं।

Non-Primitive Data Types

Non-Primitive Data Types का उपयोग Complex Data तथा Multiple Values को represent करने के लिए किया जाता है। JavaScript में Object तथा उसके विभिन्न forms इसका प्रमुख उदाहरण हैं।

1. Object

Object एक ऐसा Data Structure है जिसमें Data को Key-Value Pairs के रूप में Store किया जा सकता है। इसका उपयोग किसी Real-World Entity की कई related properties को एक साथ Store करने के लिए किया जाता है। 

let student = {

    name: "Amit",

    age: 21,

    course: "PGDCA"

};

console.log(student.name);

यहाँ student Object में name, age और course तीन Properties हैं।

2. Array

Array का उपयोग एक ही Variable में Multiple Values को Store करने के लिए किया जाता है। Array में अलग-अलग Values को Index के माध्यम से Access किया जा सकता है। JavaScript में Array का Index सामान्यतः 0 से Start होता है। 

let subjects = [
    "HTML",
    "CSS",
    "JavaScript",
    "Python"
];

console.log(subjects[0]);

ऊपर दिए गए Example में subjects Array में चार Values हैं। subjects[0] से पहली Value प्राप्त की जा सकती है।

3. Function

JavaScript में Function एक reusable block of code है जिसका उपयोग किसी specific task को perform करने के लिए किया जाता है। Function को अलग-अलग situations में Call करके Code को बार-बार लिखने से बचा जा सकता है। 

function greet() {

    console.log("Hello JavaScript");

}

greet();

यहाँ greet() एक Function है जिसे Call करने पर उसका अंदर लिखा Code execute होता है।

let status = true;

Operators in JavaScript

Operator एक special symbol या keyword होता है जिसका उपयोग JavaScript में किसी Value या Variable पर कोई operation perform करने के लिए किया जाता है। Operators की सहायता से हम Mathematical Calculation, Value Assignment, Comparison, Logical Decision तथा अन्य Operations perform कर सकते हैं।

उदाहरण के लिए यदि दो Variables में 20 और 10 Store हैं, तो + Operator की सहायता से दोनों Values को Add किया जा सकता है। इसी प्रकार > Operator का उपयोग यह Check करने के लिए किया जा सकता है कि एक Value दूसरी Value से बड़ी है या नहीं।

Exam Point:
JavaScript Operators का उपयोग Variables तथा Values पर विभिन्न प्रकार के Operations perform करने के लिए किया जाता है। Operators को मुख्य रूप से Arithmetic, Assignment, Comparison, Logical, Bitwise, Ternary तथा अन्य Operators में समझा जाता है।

Logical Operators का उपयोग दो या अधिक Conditions को Combine करने के लिए किया जाता है। इनका उपयोग विशेष रूप से if-else तथा अन्य Conditional Statements में किया जाता है।

Operator Name Meaning

Logical AND

let age = 25;

Logical NOT

let isLoggedIn = false;

6. String Operators

JavaScript में + Operator का उपयोग Strings को Concatenate अर्थात Join करने के लिए भी किया जा सकता है।

7. Ternary Operator

Ternary Operator एक short form of if-else है। इसमें तीन operands होते हैं: Condition, True Value और False Value।

यदि Condition true है तो पहला result मिलेगा, अन्यथा दूसरा result मिलेगा।

8. typeof Operator

typeof एक Unary Operator है जिसका उपयोग किसी Value या Variable के Data Type की जानकारी प्राप्त करने के लिए किया जाता है। 

let name = "Rahul";

let age = 21;

console.log(typeof age);

पहले Statement का result string और दूसरे का number होगा।

9. Increment and Decrement Operators

Increment Operator (++) किसी Value को 1 से बढ़ाता है, जबकि Decrement Operator (--) किसी Value को 1 से घटाता है। 

let count = 5;

count++;

console.log(count);

count--;

console.log(count);

पहले Output में 6 और उसके बाद 5 प्राप्त होगा।

Operator Precedence

जब किसी Expression में एक से अधिक Operators का उपयोग किया जाता है, तो JavaScript एक निश्चित order के अनुसार Operations perform करती है। इसे Operator Precedence कहा जाता है। 

let result = 10 + 5 * 2;

console.log(result);

यहाँ Multiplication की precedence Addition से अधिक होने के कारण पहले 5 * 2 calculate होगा और फिर 10 add होगा। इसलिए result 20 होगा।

किसी Expression में Order को स्पष्ट रखने के लिए Parentheses ( ) का उपयोग किया जा सकता है। 

let result = (10 + 5) * 2;

console.log(result);

यहाँ पहले Parentheses के अंदर की calculation होगी, इसलिए result 30 होगा।

Control Flow - if-else Statement

Control Flow का अर्थ है Program में Statements के Execute होने का Order अर्थात Code किस क्रम में चलेगा। JavaScript में Control Flow का उपयोग यह निर्धारित करने के लिए किया जाता है कि किसी Condition के आधार पर कौन-सा Code Execute होगा।

सामान्यतः JavaScript Program की Statements एक के बाद एक Sequential Order में Execute होती हैं। लेकिन जब हमें किसी Condition के आधार पर अलग-अलग Decision लेना हो, तब Conditional Statements का उपयोग किया जाता है। if और if-else JavaScript की सबसे basic Conditional Statements हैं।

Exam Point:
Control Flow का उपयोग Program के Execution को Control करने के लिए किया जाता है। if-else Statement का उपयोग Condition के आधार पर अलग-अलग Code Blocks को Execute करने के लिए किया जाता है।

Definition of if Statement

Definition:
"if Statement एक Conditional Statement है जो दी गई Condition के true होने पर संबंधित Code Block को Execute करती है।"

1. if Statement

if Statement का उपयोग तब किया जाता है जब हमें केवल एक Condition Check करनी हो। यदि Condition true होती है, तो if Block के अंदर लिखा Code Execute होता है। यदि Condition false होती है, तो if Block का Code Execute नहीं होता।

Syntax

if (condition) {

    // Code to be executed

}

Example

let age = 20;

if (age >= 18) {

    console.log("You are eligible.");

}

यहाँ age >= 18 Condition Check की गई है। क्योंकि age की Value 20 है और 20, 18 से बड़ी है, इसलिए Condition true होगी और message Console में दिखाई देगा।

Flow of if Statement

if Statement Flow

Start
↓
Condition Check
↓
Condition True?
↙         ↘
Yes         No
↓           ↓
Execute Code    Skip Code
↘           ↙
End

2. if-else Statement

जब हमें Condition के आधार पर दो अलग-अलग possibilities में से एक को Execute करना हो, तब if-else Statement का उपयोग किया जाता है। यदि Condition true होती है तो if Block Execute होता है, जबकि Condition false होने पर else Block Execute होता है।

Syntax

if (condition) {

    // Code when condition is true

}
else {

    // Code when condition is false

}

Example

let age = 16;

if (age >= 18) {

    console.log("Eligible to vote.");

}
else {

    console.log("Not eligible to vote.");

}

यहाँ age की Value 16 है। Condition age >= 18 false होगी, इसलिए else Block Execute होगा।

if और if-else में Difference

Basis if if-else
Conditions एक Condition Check करता है। True और False दोनों Cases Handle करता है।
False Condition Code Skip हो जाता है। else Block Execute होता है।
Use Single Decision Two-Way Decision

3. if-else if-else Statement

जब किसी Program में दो से अधिक Conditions को Check करना हो, तब if-else if-else Statement का उपयोग किया जाता है। इसमें Conditions को एक के बाद एक Check किया जाता है। जो पहली Condition true होती है, उसका Code Block Execute होता है।

Syntax

if (condition1) {

    // Code

}
else if (condition2) {

    // Code

}
else if (condition3) {

    // Code

}
else {

    // Default Code

}

Example - Marks and Grade

let marks = 85;

if (marks >= 90) {

    console.log("Grade A+");

}
else if (marks >= 80) {

    console.log("Grade A");

}
else if (marks >= 70) {

    console.log("Grade B");

}
else if (marks >= 60) {

    console.log("Grade C");

}
else {

    console.log("Needs Improvement");

}

यदि marks 85 हैं, तो पहली Condition false होगी, दूसरी Condition true होगी और "Grade A" Display होगा। इसके बाद बाकी Conditions Check नहीं की जाएँगी।

Nested if Statement

जब एक if Statement के अंदर दूसरी if Statement लिखी जाती है, तो उसे Nested if कहा जाता है। इसका उपयोग तब किया जाता है जब एक Condition के true होने के बाद दूसरी related Condition Check करनी हो। 

let age = 22;

let hasID = true;

if (age >= 18) {

    if (hasID) {

        console.log("Entry Allowed.");

    }

}

इस Example में पहले Age Check होती है। यदि Age 18 या उससे अधिक है, तभी दूसरी Condition hasID Check की जाती है। दोनों Conditions true होने पर Entry Allow की जाती है।

OR Operator में कम से कम एक Condition true होने पर if Block Execute हो सकता है।

for Loop in JavaScript

for loop JavaScript में एक महत्वपूर्ण Looping Statement है जिसका उपयोग किसी Code Block को बार-बार Execute करने के लिए किया जाता है। जब हमें यह पता हो कि किसी Code को कितनी बार Execute करना है, तब for loop बहुत उपयोगी होता है।

उदाहरण के लिए यदि हमें 1 से 10 तक Numbers को Display करना हो, किसी Array के सभी Elements को Access करना हो या किसी Task को निश्चित संख्या में Repeat करना हो, तो for loop का उपयोग किया जा सकता है।

Exam Point:
for loop का उपयोग किसी Code Block को एक निश्चित संख्या या किसी Condition के आधार पर बार-बार Execute करने के लिए किया जाता है।

Definition of for Loop

Definition:
"for loop एक looping control statement है जिसका उपयोग किसी Code Block को बार-बार Execute करने के लिए किया जाता है, जब Loop की Initial Condition, Testing Condition तथा Update Expression को पहले से Define किया जा सके।"

Syntax of for Loop

for (initialization; condition; update) {

    // Code to be executed

}

for loop में तीन मुख्य Parts होते हैं:

  1. Initialization
  2. Condition
  3. Update

Parts of for Loop

1. Initialization

Initialization में Loop Variable को Initial Value दी जाती है। यह सामान्यतः Loop के Start में केवल एक बार Execute होती है। 

let i = 1;

यहाँ i Loop Variable है और इसकी Initial Value 1 रखी गई है।

2. Condition

Condition यह निर्धारित करती है कि Loop को Continue करना है या Stop करना है। जब तक Condition true रहती है, Loop का Code Execute होता रहता है। Condition false होने पर Loop समाप्त हो जाता है। 

i <= 5

3. Update

Update Expression Loop Variable की Value को Change करता है। सामान्यतः इसमें Increment या Decrement Operator का उपयोग किया जाता है। 

i++

Simple Example of for Loop

for (let i = 1; i <= 5; i++) {

    console.log(i);

}

इसका Output होगा:

2
3
4
5

यहाँ Loop Variable i की शुरुआत 1 से होती है। प्रत्येक Iteration में Condition Check होती है और i++ के कारण उसकी Value 1 से बढ़ती जाती है। जब i की Value 6 हो जाती है, तो Condition i <= 5 false हो जाती है और Loop समाप्त हो जाता है।

Nested for Loop

जब एक for loop के अंदर दूसरा for loop लिखा जाता है, तो उसे Nested for Loop कहा जाता है। इसका उपयोग Tables, Patterns तथा Multi-Dimensional Data को Process करने में किया जा सकता है।

break Statement with for Loop

break Statement का उपयोग Loop को Condition पूरी होने से पहले ही Stop करने के लिए किया जाता है। 

for (let i = 1; i <= 10; i++) {

    if (i === 5) {

        break;

    }

    console.log(i);

}

यहाँ i की Value 5 होते ही break Execute होगा और Loop समाप्त हो जाएगा। इसलिए 1 से 4 तक Values Display होंगी।

continue Statement with for Loop

continue Statement का उपयोग Current Iteration को Skip करने के लिए किया जाता है। Loop पूरी तरह समाप्त नहीं होता, बल्कि अगली Iteration पर चला जाता है। 

for (let i = 1; i <= 5; i++) {

    if (i === 3) {

        continue;

    }

    console.log(i);

}

यहाँ 3 की Iteration Skip हो जाएगी और Output में 1, 2, 4 और 5 प्राप्त होंगे।

while Loop in JavaScript

while loop JavaScript का एक महत्वपूर्ण Looping Statement है जिसका उपयोग किसी Code Block को बार-बार Execute करने के लिए किया जाता है। इसमें Code तब तक Execute होता है जब तक दी गई Condition true रहती है।

3. External JavaScript

Large Web Applications में External JavaScript का उपयोग अधिक किया जाता है क्योंकि इससे HTML और JavaScript Code अलग-अलग Files में Organized रहता है।

Using JavaScript in Head

लेकिन यदि Script को Document Parse होने से पहले Load कराया जाता है, तो कुछ situations में DOM Elements अभी available नहीं होते। ऐसी स्थिति में defer उपयोगी होता है।

defer Attribute

defer Attribute External JavaScript को HTML Parsing के साथ Download करने की अनुमति देता है, लेकिन Script को HTML Document Parse होने के बाद Execute करता है। 

<script src="script.js" defer></script>

यदि JavaScript को DOM Elements के साथ काम करना है, तो defer एक उपयोगी तरीका हो सकता है।

async Attribute

async Attribute External Script को Asynchronously Load और Execute करने की अनुमति देता है। Script Download होने के बाद वह Execute हो सकता है, इसलिए उसके Execution का Timing HTML Parsing के साथ अलग हो सकता है। 

<script src="script.js" async></script>

async उन Scripts के लिए useful हो सकता है जो दूसरे Scripts या DOM Parsing के Order पर निर्भर नहीं हैं।

JavaScript Objects

Object JavaScript का एक महत्वपूर्ण Data Structure है, जिसका उपयोग Related Data तथा Functionality को एक ही Structure में Store करने के लिए किया जाता है। JavaScript Object में Data को Key-Value Pair के रूप में Store किया जाता है। प्रत्येक Key किसी Property को Represent करती है और उसके साथ संबंधित Value Store होती है। :contentReference[oaicite:1]{index=1}

उदाहरण के लिए किसी Student की Information जैसे Name, Age, Course और Roll Number को अलग-अलग Variables में Store करने के बजाय एक Object में Group किया जा सकता है। इसी प्रकार E-Commerce Website में किसी Product की Name, Price, Category और Stock जैसी Information एक ही Object में Store की जा सकती है।

JavaScript Objects Dynamic और Mutable होते हैं। इसका अर्थ है कि किसी Object में Runtime पर नई Properties Add की जा सकती हैं, Existing Properties को Modify किया जा सकता है और आवश्यकता होने पर Properties को Delete भी किया जा सकता है। :contentReference[oaicite:2]{index=2}

Exam Point:
JavaScript Object Related Data को Key-Value Pairs के रूप में Store करता है। Object की प्रत्येक Key एक Property को Represent करती है और Property की Value किसी भी suitable Data Type की हो सकती है।

Creating JavaScript Object

JavaScript में Object बनाने के कई तरीके हैं। सबसे सामान्य और सरल तरीका Object Literal है। इसके अलावा new Object() Constructor का भी उपयोग किया जा सकता है। :contentReference[oaicite:3]{index=3}

1. Object Literal

Object Literal JavaScript में Object Create करने का सबसे simple और commonly used तरीका है। इसमें Curly Braces { } के अंदर Key-Value Pairs Define किए जाते हैं।

Document Object Model (DOM) Web Development में JavaScript का एक बहुत महत्वपूर्ण Concept है। DOM की सहायता से JavaScript किसी HTML Document के Elements को Access, Select, Modify, Create और Delete कर सकता है। इसी के कारण एक Static HTML Web Page को Dynamic और Interactive Web Page में बदला जा सकता है।

JavaScript इस DOM Tree के माध्यम से HTML Elements और उनकी Properties को Access कर सकता है तथा उनके Content, Style और Attributes में बदलाव कर सकता है। इसलिए DOM JavaScript और HTML Document के बीच एक महत्वपूर्ण Interface का कार्य करता है।

2. getElementsByClassName()

Using Class

Using Tag

इस Example में Button पर Click होने पर greet() Function Execute होगा।

Passing Parameters through Events

Event के समय Function को Parameters भी Pass किए जा सकते हैं। इससे Function को Dynamic Information उपलब्ध कराई जा सकती है। 

<button onclick="showMessage('Welcome')">

    Click Me

</button>

<script>

function showMessage(message) {

    alert(message);

}

</script>

यहाँ "Welcome" Function को Argument के रूप में Pass किया गया है।

Passing this Keyword

HTML Event में this Keyword का उपयोग Current HTML Element को Function में Pass करने के लिए किया जा सकता है। 

<button onclick="changeText(this)">

    Click Me

</button>

<script>

function changeText(button) {

    button.textContent = "Clicked";

}

</script>

यहाँ this Current Button Element को button Parameter में Pass करता है। Function उस Button का Text Change कर देता है।

Using addEventListener()

Modern JavaScript में Event Handle करने के लिए addEventListener() Method का उपयोग करना एक महत्वपूर्ण तरीका है। इसमें HTML में Event Attribute लिखने के बजाय JavaScript से Event Listener Attach किया जाता है। 

<button id="btn">

    Click Me

</button>

<script>

let button = document.getElementById("btn");

button.addEventListener("click", function() {

    alert("Button Clicked");

});

</script>

यहाँ पहले Button को DOM की सहायता से Select किया गया। इसके बाद addEventListener() के माध्यम से उसके साथ click Event Attach किया गया।

Calling Named Function with addEventListener()

Anonymous Function की जगह एक अलग Named Function भी Event Handler के रूप में दिया जा सकता है। 

<button id="btn">

    Click Me

</button>

<script>

function showMessage() {

    alert("Hello JavaScript");

}

let button = document.getElementById("btn");

button.addEventListener("click", showMessage);

</script>
Important:
addEventListener("click", showMessage) में Function को तुरंत Call नहीं किया जाता। इसलिए यहाँ showMessage लिखा जाता है, जबकि showMessage() लिखने से Function उसी समय Execute हो जाएगा।

Event Object

JavaScript Event होने पर Browser एक Event Object उपलब्ध करा सकता है। इसमें Event से संबंधित Information होती है, जैसे Event Type, Target Element, Mouse Position और Keyboard Key आदि। 

document.getElementById("btn")
.addEventListener("click", function(event) {

    console.log(event);

});

यहाँ event Parameter Event की Information को Represent करता है।

event.target

event.target उस HTML Element को Represent करता है जिस पर Event हुआ है। 

document.getElementById("btn")
.addEventListener("click", function(event) {

    console.log(event.target);

});

preventDefault()

कुछ HTML Elements के साथ Browser का अपना Default Behaviour होता है। preventDefault() Method का उपयोग उस Default Behaviour को रोकने के लिए किया जा सकता है। 

document.getElementById("link")
.addEventListener("click", function(event) {

    event.preventDefault();

    console.log("Default Action Prevented");

});

Multiple Event Listeners

एक ही Element पर अलग-अलग Events के लिए Multiple Event Listeners लगाए जा सकते हैं। 

let button = document.getElementById("btn");

button.addEventListener("click", function() {

    console.log("Clicked");

});

button.addEventListener("mouseover", function() {

    console.log("Mouse Over");

});

Keyboard Event Example

let input = document.getElementById("username");

input.addEventListener("keydown", function(event) {

    console.log("Key: " + event.key);

});

यहाँ User द्वारा Press की गई Keyboard Key की जानकारी event.key से प्राप्त की जा सकती है।

Mouse Event Example

let box = document.getElementById("box");

box.addEventListener("mouseover", function() {

    box.style.backgroundColor = "lightblue";

});

box.addEventListener("mouseout", function() {

    box.style.backgroundColor = "white";

});

Mouse Box के ऊपर आने पर उसका Background Color Change होगा और Mouse बाहर जाने पर Color वापस Change हो जाएगा।

Form Validation using Events

JavaScript Events का एक महत्वपूर्ण उपयोग Form Validation है। Form Submit होने से पहले User द्वारा Enter की गई Information को Check किया जा सकता है। 

<form id="loginForm">

    <input type="text" id="username"
           placeholder="Enter Username">

    <button type="submit">

        Login

    </button>

</form>

<script>

let form = document.getElementById("loginForm");

form.addEventListener("submit", function(event) {

    let username =
        document.getElementById("username").value;

    if (username === "") {

        event.preventDefault();

        alert("Username is required");

    }

});

</script>

इस Example में यदि Username Empty है, तो Form Submission को रोक दिया जाएगा और User को Error Message दिखाई देगा।

Events in E-Commerce Website

E-Commerce Website में HTML Events का उपयोग बहुत अधिक किया जाता है। Product को Cart में Add करना, Quantity Change करना, Search Input लेना, Login Form Validate करना, Menu Open करना और Checkout Process को Control करना Events की सहायता से किया जा सकता है। 

function addToCart(productName) {

    alert(productName + " added to cart");

}

<button onclick="addToCart('Laptop')">

    Add to Cart

</button>

यहाँ Button पर Click करने पर addToCart() Function Call होता है और Product का Name Parameter के रूप में Pass किया जाता है।

Advantages of Event Handling

  1. Interactive Web Pages
    User Actions के अनुसार Web Page Response करता है।
  2. Better User Experience
    User को Immediate Feedback दिया जा सकता है।
  3. Form Validation
    Form Submit होने से पहले User Input को Validate किया जा सकता है।
  4. Dynamic Content
    Events के आधार पर Page का Content Dynamically Change किया जा सकता है।
  5. Application Control
    Buttons, Forms, Menus और अन्य UI Components को Control किया जा सकता है।

Common Mistakes in Event Handling

  • Event Name गलत लिखना।
  • Function Name की Spelling गलत करना।
  • Function को Call करना भूल जाना।
  • addEventListener() में Function को गलत तरीके से Call करना।
  • DOM Element Select करने से पहले Script Execute कर देना।
  • Form Event में preventDefault() की आवश्यकता होने पर उसे न लगाना।
Exam Summary:
HTML Events वे Actions हैं जो User या Browser द्वारा किसी HTML Element पर Perform किए जाते हैं। जैसे click, dblclick, mouseover, mouseout, keydown, keyup, input, change, submit और load। JavaScript इन Events को Handle करके आवश्यक Function को Execute कर सकता है। Event को HTML Attribute जैसे onclick के माध्यम से Handle किया जा सकता है या JavaScript के addEventListener() Method का उपयोग किया जा सकता है। Function को Event के साथ Call करते समय Parameters भी Pass किए जा सकते हैं। Event Object Event से संबंधित Information देता है, जबकि event.target उस Element को Represent करता है जिस पर Event हुआ है। Form Submission जैसे Default Browser Behaviour को रोकने के लिए preventDefault() Method का उपयोग किया जा सकता है। Event Handling JavaScript की सहायता से Interactive और Dynamic Web Applications बनाने का महत्वपूर्ण हिस्सा है।
