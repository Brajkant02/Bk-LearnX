Introduction to Relational Constraints

Relational Constraints वे rules हैं जो database data को valid, accurate और consistent बनाए रखते हैं। Constraints गलत, duplicate या incomplete data को prevent करती हैं।

Domain Constraint

Domain Constraint define करती है कि किसी attribute में किस type और range की values store हो सकती हैं।

Examples

  • Age integer और positive हो।
  • Email text format में हो।
  • Marks 0 से 100 के बीच हों।
  • Gender predefined values में हो।
Marks INT CHECK (Marks BETWEEN 0 AND 100)

Tuple Uniqueness Constraint

Relation में duplicate tuples नहीं होने चाहिए। प्रत्येक row किसी unique real-world record को represent करे। Primary key और candidate keys tuple uniqueness enforce करने में help करती हैं।

Example:
दो students का Student_ID same नहीं हो सकता।

Key Constraints

Super Key

Attributes का कोई भी set जो tuple को uniquely identify करे।

Candidate Key

Minimal super key।

Primary Key

Selected candidate key।

Alternate Key

Candidate key जो primary key select नहीं हुई।

Foreign Key

एक relation का attribute जो दूसरे relation की primary key refer करता है।

Integrity Constraints

Integrity constraints database consistency maintain करती हैं। Main types entity integrity और referential integrity हैं।

ConstraintPurpose
Entity IntegrityPrimary key null नहीं हो सकती।
Referential IntegrityForeign key valid referenced value रखे।
Domain IntegrityValues valid domain से हों।
User-defined IntegrityBusiness-specific rules।

Entity Integrity Constraint

Entity Integrity के अनुसार primary key की value null नहीं हो सकती, क्योंकि primary key प्रत्येक tuple को uniquely identify करती है।

Example

Student_ID INT PRIMARY KEY

Student_ID missing होने पर student record uniquely identify नहीं होगा।

Referential Integrity Constraint

Referential Integrity ensure करती है कि foreign key की value referenced table की primary key में exist करे या allowed होने पर null हो।

Image Placeholder: Referential Integrity between Tables

Example

DEPARTMENT(Dept_ID, Dept_Name)
STUDENT(Student_ID, Name, Dept_ID)

STUDENT.Dept_ID में वही value होनी चाहिए जो DEPARTMENT.Dept_ID में मौजूद हो।

Referential Actions

Referenced row update या delete होने पर DBMS different actions perform कर सकता है।

ActionMeaning
CASCADERelated child rows भी update/delete हों।
SET NULLForeign key null हो जाए।
SET DEFAULTDefault value set हो।
RESTRICT / NO ACTIONReferenced row change prevent हो।
