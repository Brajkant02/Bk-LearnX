Introduction to Database Security

Database Security उन techniques, policies और mechanisms का collection है जिनका उद्देश्य database को unauthorized access, data theft, data modification और cyber attacks से सुरक्षित रखना है.

Authorization

Authorization यह निर्धारित करती है कि कौन-सा user database में कौन-सा operation कर सकता है। Authentication user की पहचान verify करती है जबकि Authorization permissions तय करती है.

PrivilegePurpose
SELECTData पढ़ना
INSERTNew record जोड़ना
UPDATEData बदलना
DELETERecord हटाना
CREATEDatabase objects बनाना
GRANT SELECT ON student TO teacher;
REVOKE DELETE ON student FROM teacher;

Views and Security

View एक virtual table है जो केवल आवश्यक data users को दिखाती है। Sensitive columns या rows को hide करके security बढ़ाई जा सकती है.

CREATE VIEW student_public AS
SELECT student_id,name
FROM student;

Security Constraints

Security constraints database access को control करने वाले rules हैं.

  • Strong Password Policy
  • Role Based Access Control (RBAC)
  • Least Privilege Principle
  • User Authentication
  • Audit Logs
  • Regular Backup
Professional Tip: User को केवल उतनी permissions दें जितनी उसके कार्य के लिए आवश्यक हों.

Encryption

Encryption plaintext data को ciphertext में convert करती है ताकि unauthorized person उसे पढ़ न सके.

Types of Encryption
