Introduction to PL/SQL

PL/SQL का full form Procedural Language/Structured Query Language है। यह SQL के साथ procedural programming features जैसे variables, conditions, loops, functions, procedures और exception handling provide करती है। इसका उपयोग database server पर business logic execute करने के लिए किया जाता है।

Why PL/SQL is Needed

  • Multiple SQL statements को एक block में execute करना।
  • Conditions और loops use करना।
  • Reusable functions और procedures create करना।
  • Database operations को secure और centralized बनाना।
  • Errors को exception handling के through manage करना।
Remember:
SQL declarative language है, जबकि PL/SQL SQL के साथ procedural programming capabilities add करती है।

Features and Advantages of PL/SQL

  • Block-structured programming।
  • SQL statements का direct support।
  • Variables, constants और data types।
  • Conditional और iterative statements।
  • Functions और stored procedures।
  • Triggers और cursors।
  • Exception handling।
  • Server-side execution के कारण network traffic कम।
  • Code reuse और modularity।
  • Database security improve होती है।

Structure of a PL/SQL Block

PL/SQL program को blocks में लिखा जाता है। एक block में optional declaration section, mandatory executable section और optional exception section हो सकते हैं।

DECLARE
    -- Variables and constants

BEGIN
    -- Executable statements

EXCEPTION
    -- Error handling statements

END;
/

IF Control Statement

Simple IF

IF marks >= 40 THEN
    DBMS_OUTPUT.PUT_LINE('Pass');
END IF;

IF-ELSE

IF marks >= 40 THEN
    DBMS_OUTPUT.PUT_LINE('Pass');
ELSE
    DBMS_OUTPUT.PUT_LINE('Fail');
END IF;

IF-ELSIF-ELSE

IF marks >= 75 THEN
    grade := 'A';
ELSIF marks >= 60 THEN
    grade := 'B';
ELSIF marks >= 40 THEN
    grade := 'C';
ELSE
    grade := 'F';
END IF;

CASE Statement

CASE grade

    WHEN 'B' THEN message := 'Very Good';
    WHEN 'C' THEN message := 'Good';
    ELSE message := 'Needs Improvement';
END CASE;

Basic LOOP Statement

DECLARE
    counter NUMBER := 1;
BEGIN
    LOOP
        DBMS_OUTPUT.PUT_LINE(counter);
        counter := counter + 1;
        EXIT WHEN counter > 5;
    END LOOP;
END;
/

Basic LOOP तब तक चलता है जब तक EXIT condition true नहीं होती।

WHILE LOOP

DECLARE
    counter NUMBER := 1;
BEGIN
    WHILE counter <= 5 LOOP
        DBMS_OUTPUT.PUT_LINE(counter);
        counter := counter + 1;
    END LOOP;
END;
/

WHILE loop execution से पहले condition check करता है।

FOR LOOP

BEGIN
    FOR counter IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE(counter);
    END LOOP;
END;
/

Reverse FOR Loop

FOR counter IN REVERSE 1..5 LOOP
    DBMS_OUTPUT.PUT_LINE(counter);
END LOOP;

EXIT and CONTINUE

EXIT

Loop को immediately terminate करता है।

CONTINUE

Current iteration skip करके next iteration start करता है।

FOR i IN 1..10 LOOP
    CONTINUE WHEN MOD(i,2)=0;
    DBMS_OUTPUT.PUT_LINE(i);
END LOOP;
Remember:
IF decision लेने के लिए और LOOP repeated execution के लिए use होता है।

Basic Exception Handling

Exception runtime error या unusual condition होती है। PL/SQL exception section errors को gracefully handle करता है।

DECLARE
    result NUMBER;
BEGIN
    result := 10 / 0;
EXCEPTION
    WHEN ZERO_DIVIDE THEN
        DBMS_OUTPUT.PUT_LINE('Division by zero is not allowed');
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('Unexpected error');
END;
/
Warning:
WHEN OTHERS useful है, लेकिन real applications में specific exceptions को पहले handle करना चाहिए।
