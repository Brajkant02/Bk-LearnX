Creating Database and Tables

CREATE DATABASE college;
USE college;

CREATE TABLE student (
  student_id INT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(120) UNIQUE,
  marks INT CHECK (marks BETWEEN 0 AND 100),
  city VARCHAR(50) DEFAULT 'Kanpur'
);

UPDATE Command

SET marks = 85
WHERE student_id = 2;

Foreign Key Example

CREATE TABLE department (
  dept_id INT PRIMARY KEY,
  dept_name VARCHAR(100)
);

CREATE TABLE student (
  student_id INT PRIMARY KEY,
  name VARCHAR(100),
  dept_id INT,
  FOREIGN KEY (dept_id)
  REFERENCES department(dept_id)
);

Views

View virtual table होती है जो query result पर based होती है।

CREATE VIEW high_marks AS
SELECT student_id, name, marks
FROM student
WHERE marks >= 80;

Advantages

  • Security improve
  • Complex query simplify
  • Reusable query
  • User-specific data view

Indexes

Index data search speed improve करता है, लेकिन insert/update cost बढ़ा सकता है।

CREATE INDEX idx_student_name
ON student(name);
Remember:
हर column पर index बनाना सही नहीं; frequently searched columns पर use करें।
