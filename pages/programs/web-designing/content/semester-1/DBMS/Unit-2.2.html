Entity and Entity Set

Entity real-world object, person, place, event या concept होता है जिसे uniquely identify किया जा सके।

Entity Set same type की entities का collection होता है।

Example

  • Student एक entity है।
  • All students का collection Student Entity Set है।

Super Key

Super Key one or more attributes का set होता है जो entity को uniquely identify कर सकता है। इसमें unnecessary attributes भी included हो सकते हैं।

Example

Student table में Student_ID और Student_ID + Name दोनों super keys हो सकते हैं।

Candidate Key

Candidate Key minimal super key होती है। इसमें कोई unnecessary attribute नहीं होता।

Example

Student_ID और Email दोनों candidate keys हो सकते हैं, यदि दोनों unique हैं।

Primary Key

Primary Key candidate keys में से selected key होती है जो entity को uniquely identify करती है। इसकी value unique और non-null होती है।

Example

Student_ID को primary key select किया जा सकता है।

Unique Key

Unique Key attribute की values को unique बनाती है। कुछ DBMS में unique key null value allow कर सकती है, जबकि primary key null नहीं होती।

Participation Constraint

Participation constraint बताती है कि entity relationship में mandatory participate करती है या optional।

Total Participation

हर entity को relationship में participate करना आवश्यक है। इसे double line से show किया जाता है।

Partial Participation

कुछ entities participate कर सकती हैं और कुछ नहीं। इसे single line से show किया जाता है।

Weak Entity Set

Weak Entity Set अपनी complete primary key नहीं रखता और strong entity पर depend करता है। इसे identify करने के लिए owner entity की key और partial key use होती है।

Example

Employee का Dependent entity weak हो सकता है।
