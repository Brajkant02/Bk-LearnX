PL/SQL

1. Introduction to PL/SQL

PL/SQL का full form Procedural Language/Structured Query Language है। यह SQL को procedural programming features के साथ combine करता है। इसके माध्यम से SQL statements के साथ variables, conditions, loops, functions, procedures, cursors, triggers और exception handling जैसे programming constructs का उपयोग किया जा सकता है। citeturn0search0turn0search4

PL/SQL विशेष रूप से Oracle database environment से closely associated है। यह database के अंदर procedural logic execute करने और reusable database programs बनाने के लिए use होता है। PL/SQL programs blocks में organized होते हैं और blocks nested भी हो सकते हैं। citeturn0search5

SQL और PL/SQL में अंतर

SQL PL/SQL
मुख्यतः declarative/query language है। SQL के ऊपर procedural programming features provide करता है।
Individual SQL statements execute करता है। एक block में multiple SQL statements और programming logic रख सकता है।
IF/LOOP जैसे procedural constructs मूल SQL का हिस्सा नहीं हैं। IF, CASE, loops आदि support करता है।
Query/data manipulation पर focus। Database-side business logic और reusable programs पर focus।

PL/SQL की प्रमुख विशेषताएँ

  • Block Structure: Program logical blocks में organized होता है।
  • Procedural Constructs: Decision making और iteration support करता है।
  • SQL Integration: SQL queries और DML statements को procedural code में use किया जा सकता है।
  • Reusability: Functions, procedures, triggers आदि database में reusable program units बन सकते हैं।
  • Exception Handling: Runtime errors को handle करने के लिए exception section available है।
  • Cursors: Query result set को row-by-row process करने में सहायता करते हैं।
  • Reduced Network Traffic: Multiple statements को database side पर block के रूप में execute करने से communication overhead कम हो सकता है।
Exam Definition: PL/SQL is a procedural extension of SQL that combines SQL data manipulation with procedural programming constructs for database programming.

2. PL/SQL Block Structure

PL/SQL का basic unit एक block है। सामान्य PL/SQL block में declaration, executable और exception-handling parts हो सकते हैं। Declaration और exception sections optional हैं, जबकि executable section BEGIN ... END के बीच लिखा जाता है। citeturn0search0turn0search2

DECLARE Declaration Section ↓ BEGIN Executable Section ↓ EXCEPTION Exception Handling Section END;

Basic Example

DECLARE v_name VARCHAR2(50) := 'Amit'; BEGIN DBMS_OUTPUT.PUT_LINE('Student: ' || v_name); EXCEPTION WHEN OTHERS THEN DBMS_OUTPUT.PUT_LINE('An error occurred'); END; /

Three Main Sections

Section Purpose
DECLARE Variables, constants, cursors और local declarations define करने के लिए।
BEGIN ... END Executable statements और main program logic के लिए।
EXCEPTION Errors/exceptions handle करने के लिए।
Note: DECLARE और EXCEPTION sections optional हो सकते हैं, लेकिन PL/SQL block का executable part BEGIN और END के बीच रहता है। citeturn0search5

3. User Defined Functions

User Defined Function (UDF) programmer द्वारा create किया गया reusable PL/SQL program unit है जो किसी specific task को perform करता है और एक value return करता है। Functions calculations या value-generation के लिए विशेष रूप से useful हैं। citeturn0search6

Function के मुख्य भाग

  • Function Name: Function की पहचान।
  • Parameters: Input values receive करने के लिए optional parameters।
  • RETURN Type: Function किस data type की value return करेगी।
  • Function Body: Actual logic।
  • RETURN Statement: Result वापस करने के लिए required।

Syntax

CREATE OR REPLACE FUNCTION function_name ( parameter_name IN datatype ) RETURN return_datatype IS -- declarations BEGIN -- statements RETURN value; EXCEPTION -- exception handling END function_name; /

Example: Square Function

CREATE OR REPLACE FUNCTION square_num ( p_num IN NUMBER ) RETURN NUMBER IS BEGIN RETURN p_num * p_num; END square_num; /

Calling the Function

SELECT square_num(5) AS Result FROM dual;

Expected result: 25

Another Example: Employee Bonus

CREATE OR REPLACE FUNCTION calculate_bonus ( p_salary IN NUMBER ) RETURN NUMBER IS BEGIN RETURN p_salary * 0.10; END calculate_bonus; /
SELECT calculate_bonus(50000) AS Bonus FROM dual;

Expected result: 5000

Advantages of Functions

  • Code reusability बढ़ती है।
  • Complex calculation को एक reusable unit में रखा जा सकता है।
  • Application code को simpler बनाया जा सकता है।
  • Same calculation को multiple places पर reuse किया जा सकता है।
  • Database-side logic centralized हो सकती है।
One-Line Rule: Function performs a task and must return a value. citeturn0search6turn0search7

4. Control of Flow Statements in PL/SQL

Control flow यह determine करता है कि PL/SQL program में statements किस order में execute होंगे। PL/SQL में decision-making और looping constructs available हैं। GFG के PL/SQL tutorial में IF/THEN, CASE और loop-based control flow को प्रमुख concepts के रूप में cover किया गया है। citeturn0search4

A. IF-THEN

Condition true होने पर statements execute होते हैं।

DECLARE v_marks NUMBER := 75; BEGIN IF v_marks >= 40 THEN DBMS_OUTPUT.PUT_LINE('Pass'); END IF; END; /

B. IF-THEN-ELSE

DECLARE v_marks NUMBER := 35; BEGIN IF v_marks >= 40 THEN DBMS_OUTPUT.PUT_LINE('Pass'); ELSE DBMS_OUTPUT.PUT_LINE('Fail'); END IF; END; /

C. ELSIF

DECLARE v_marks NUMBER := 82; BEGIN IF v_marks >= 75 THEN DBMS_OUTPUT.PUT_LINE('Distinction'); ELSIF v_marks >= 60 THEN DBMS_OUTPUT.PUT_LINE('First Division'); ELSIF v_marks >= 40 THEN DBMS_OUTPUT.PUT_LINE('Pass'); ELSE DBMS_OUTPUT.PUT_LINE('Fail'); END IF; END; /

D. CASE Statement

DECLARE v_grade CHAR(1) := 'A'; BEGIN CASE v_grade WHEN 'A' THEN DBMS_OUTPUT.PUT_LINE('Excellent'); WHEN 'B' THEN DBMS_OUTPUT.PUT_LINE('Good'); WHEN 'C' THEN DBMS_OUTPUT.PUT_LINE('Average'); ELSE DBMS_OUTPUT.PUT_LINE('Needs Improvement'); END CASE; END; /

E. Simple LOOP

DECLARE i NUMBER := 1; BEGIN LOOP DBMS_OUTPUT.PUT_LINE(i); i := i + 1; EXIT WHEN i > 5; END LOOP; END; /

F. WHILE LOOP

DECLARE i NUMBER := 1; BEGIN WHILE i <= 5 LOOP DBMS_OUTPUT.PUT_LINE(i); i :=i + 1; END LOOP; END; /

G. FOR LOOP

BEGIN FOR i IN 1..5 LOOP DBMS_OUTPUT.PUT_LINE(i); END LOOP; END; /
Control Structure Use
IF Condition based decision
ELSIF Multiple conditions
CASE Multiple alternatives/choices
LOOP Repeated execution
WHILE LOOP Condition-based repetition
FOR LOOP Known range/iteration count के लिए convenient loop
EXIT Loop से बाहर निकलने के लिए

5. Procedures / Stored Procedures

Procedure एक reusable named PL/SQL program unit है जो किसी specific task या business logic को perform करता है। जब procedure database में stored होता है तो उसे stored procedure कहा जाता है। Procedures database में logic encapsulate करने और repeated execution के लिए useful हैं। citeturn0search3turn0search8

Procedure के मुख्य parts

  • Procedure Header: Name और optional parameters define करता है।
  • Procedure Body: Actual executable logic contain करता है।
  • Parameters: IN, OUT और IN OUT modes के साथ values pass/return की जा सकती हैं।

Parameter Modes

Mode Purpose
IN Caller से value procedure में pass करता है।
OUT Procedure से value caller को return करने के लिए।
IN OUT Value procedure में आती भी है और modified होकर वापस भी जा सकती है।

Syntax

CREATE OR REPLACE PROCEDURE procedure_name ( p_parameter IN datatype ) IS BEGIN -- procedure logic END procedure_name; /

Example

CREATE OR REPLACE PROCEDURE show_student ( p_id IN NUMBER ) IS v_name VARCHAR2(50); BEGIN SELECT Name INTO v_name FROM Student WHERE StudentID = p_id; DBMS_OUTPUT.PUT_LINE('Student: ' || v_name); END show_student; /

Calling Procedure

EXEC show_student(101);

OUT Parameter Example

CREATE OR REPLACE PROCEDURE get_square ( p_num IN NUMBER, p_result OUT NUMBER ) IS BEGIN p_result := p_num * p_num; END; /
Function vs Procedure: Function must return a value, जबकि procedure मुख्यतः एक task/action perform करने के लिए होती है और function की तरह mandatory RETURN value नहीं होती। citeturn0search6turn0search7

Advantages of Stored Procedures

  • Code reusability।
  • Business logic centralization।
  • Repeated SQL code को avoid करना।
  • Applications और database के बीच standardized interface provide करना।
  • Complex database operations को एक call में encapsulate करना।

6. Transactions in PL/SQL

Transaction database operations का logical unit है। इसमें एक या अधिक operations हो सकते हैं जिन्हें collectively complete या undo किया जाता है। Transaction management database consistency और reliability के लिए important है।

Important Transaction Commands

Command Purpose
COMMIT Current transaction के changes permanently save करता है।
ROLLBACK Uncommitted changes को undo करता है।
SAVEPOINT Transaction के अंदर intermediate point create करता है।
ROLLBACK TO SAVEPOINT Specific savepoint तक changes undo करता है।

GFG के transaction reference में COMMIT, ROLLBACK और SAVEPOINT को transaction control के प्रमुख commands बताया गया है। citeturn0search1

COMMIT Example

UPDATE Employee SET Salary = Salary + 5000 WHERE EmpID = 101; COMMIT;

ROLLBACK Example

UPDATE Employee SET Salary = Salary + 5000 WHERE EmpID = 101; ROLLBACK;

ROLLBACK के बाद uncommitted change undo हो जाता है।

SAVEPOINT Example

UPDATE Employee SET Salary = Salary + 1000 WHERE EmpID = 101; SAVEPOINT sp1; UPDATE Employee SET Salary = Salary + 2000 WHERE EmpID = 102; ROLLBACK TO sp1; COMMIT;
Transaction Start ↓ SQL Operations ↓ SAVEPOINT (optional) ↓ Success? ─── YES → COMMIT │ NO ↓ ROLLBACK

7. Triggers

Trigger एक stored database program/block है जो किसी specified database event के होने पर automatically execute होता है। Trigger को user सामान्य procedure की तरह manually call नहीं करता; triggering event होने पर database engine उसे fire करता है। citeturn0search2turn0search14

Common Trigger Events

  • INSERT
  • UPDATE
  • DELETE

Trigger Timing

Timing Meaning
BEFORE Event operation से पहले trigger action execute होता है।
AFTER Event operation के बाद trigger action execute होता है।

Row-Level Trigger

यदि trigger प्रत्येक affected row के लिए execute होना है, तो FOR EACH ROW का उपयोग किया जा सकता है। GFG trigger material में statement-level और row-level triggers दोनों concepts covered हैं। citeturn0search2turn0search4

Example: Audit Trigger

CREATE OR REPLACE TRIGGER trg_student_insert AFTER INSERT ON Student FOR EACH ROW BEGIN DBMS_OUTPUT.PUT_LINE('New student inserted: ' || :NEW.StudentID); END; /

:NEW और :OLD

Row-level DML triggers में :NEW और :OLD pseudorecord values current/new और previous/old row values को reference करने के लिए use किए जा सकते हैं। citeturn0search1

Operation :OLD :NEW
INSERT Generally available नहीं New row values
UPDATE Old values New values
DELETE Old values Generally available नहीं

Uses of Triggers

  • Auditing और change tracking।
  • Complex business rules enforce करना।
  • Automatic actions perform करना।
  • Database changes पर related logic execute करना।
  • कुछ integrity/security requirements implement करना।
Remember: Procedure = explicitly invoked; Trigger = event के response में automatically invoked. citeturn0search14

8. Cursors

Cursor PL/SQL में query के result set को access और process करने का mechanism है। इसे query result के context area की ओर pointer की तरह समझ सकते हैं। Cursor का उपयोग result set की rows को one-by-one process करने के लिए किया जा सकता है। citeturn0search15

Why Cursors?

Normal SQL statement कई rows पर एक साथ operate कर सकता है, लेकिन कुछ procedural logic में हमें प्रत्येक row को individually process करना होता है। ऐसे cases में cursor useful होता है।

Cursor के Main Steps

DECLARE Cursor ↓ OPEN Cursor ↓ FETCH Row ↓ Process Row ↓ Repeat ↓ CLOSE Cursor

GFG के अनुसार cursor के basic actions Declare, Open और Fetch हैं; processing के बाद cursor close किया जाता है। citeturn0search15

Types of Cursors

Type Explanation
Implicit Cursor Oracle/PLSQL engine द्वारा automatically created for certain SQL statements।
Explicit Cursor Programmer द्वारा declare किया जाता है जब result set को explicitly control करना हो।

Explicit Cursor Example

DECLARE CURSOR c_students IS SELECT StudentID, Name FROM Student; v_id Student.StudentID%TYPE; v_name Student.Name%TYPE; BEGIN OPEN c_students; LOOP FETCH c_students INTO v_id, v_name; EXIT WHEN c_students%NOTFOUND; DBMS_OUTPUT.PUT_LINE( v_id || ' - ' || v_name ); END LOOP; CLOSE c_students; END; /

Cursor Attributes

Attribute Meaning
%FOUND Latest FETCH/operation ने row पाया या नहीं।
%NOTFOUND Latest FETCH में row नहीं मिली।
%ROWCOUNT अब तक processed/fetched rows की count।
%ISOPEN Cursor open है या नहीं।
Easy Memory: Cursor = Query result को row-by-row process करने का mechanism.

9. GRANT Command

GRANT command database objects पर users/roles को privileges देने के लिए use होती है। यह database security और access control का important part है। GFG के SQL command reference में GRANT को DCL command के रूप में बताया गया है। citeturn0search11turn0search12

Common Privileges

  • SELECT
  • INSERT
  • UPDATE
  • DELETE
  • EXECUTE

Syntax

GRANT privilege ON object TO user_or_role;

Example

GRANT SELECT ON Student TO user1;

अब user1 को Student object पर SELECT privilege दिया जा सकता है।

Multiple Privileges

GRANT SELECT, INSERT, UPDATE ON Student TO user1;
GRANT = Permission देना.

10. REVOKE Command

REVOKE पहले दिए गए privileges को वापस लेने के लिए use होता है। यह भी Data Control Language (DCL) से associated command है। citeturn0search11turn0search12

Syntax

REVOKE privilege ON object FROM user_or_role;

Example

REVOKE INSERT ON Student FROM user1;

Multiple Privileges

REVOKE SELECT, UPDATE ON Student FROM user1;
GRANT REVOKE
Permission देता है। Permission वापस लेता है।
DCL DCL
GRANT SELECT ON Student TO user1; REVOKE SELECT ON Student FROM user1;
GRANT = Give privilege | REVOKE = Remove privilege

11. Function vs Procedure vs Trigger

Feature Function Procedure Trigger
Purpose Value/result calculate करना Specific task/business logic execute करना Event के response में automatic action
Invocation Call/query expression से Explicitly call किया जाता है Event होने पर automatically fire
Return Must return a value Mandatory single return value नहीं Return value concept नहीं
Parameters Parameters हो सकते हैं IN/OUT/IN OUT parameters हो सकते हैं Normal procedure-style parameters नहीं
Typical use Calculation Reusable database operation Audit, automatic validation/action

GFG के references में function को value-returning reusable block, procedure को reusable task-oriented block और trigger को event-driven automatic database program के रूप में distinguish किया गया है। citeturn0search6turn0search8turn0search14

12. Complete PL/SQL Workflow

नीचे syllabus के major concepts को एक logical workflow में connect करके समझें:

SQL Data ↓ PL/SQL Block ↓ Variables + Control Flow ↓ Functions / Procedures ↓ Cursors → Row-by-Row Processing ↓ Transactions → COMMIT / ROLLBACK ↓ Triggers → Automatic Event Response ↓ GRANT / REVOKE → Access Control

Mini Integrated Example

DECLARE v_count NUMBER; BEGIN SELECT COUNT(*) INTO v_count FROM Student; IF v_count > 0 THEN DBMS_OUTPUT.PUT_LINE( 'Total Students = ' || v_count ); ELSE DBMS_OUTPUT.PUT_LINE( 'No students found' ); END IF; END; /

इस example में PL/SQL block, variable, SELECT INTO और IF-ELSE control flow एक साथ use हुए हैं। इसी प्रकार आगे functions, procedures, cursors और triggers को reusable database programs के रूप में organize किया जा सकता है।
