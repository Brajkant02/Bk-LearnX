Moodle Introduction

Moodle एक open-source Learning Management System है जिसका use online courses, activities, assignments, quizzes, grades और learners manage करने के लिए किया जाता है।

Moodle Installation

Requirements

  • Web server
  • PHP
  • Database
  • Moodle data directory

Steps

  1. Moodle package obtain करें।
  2. Files web server पर place करें।
  3. Database create करें।
  4. Moodle data directory create करें।
  5. Browser installer run करें।
  6. Admin account और site settings configure करें।

  • Backup protection

  • Secure file permissions
Remember:
Moodle security केवल server की नहीं, roles, plugins और user practices की भी responsibility है।

Performance
