Unit 2: Basic Python Syntax

इस chapter में Python syntax, comments, strings, numeric data types, conversion, input-output और formatting को beginner-friendly examples के साथ समझाया गया है।

Basic Syntax

किसी भी programming language में syntax का मतलब code लिखने के rules से होता है। जैसे English में sentence बनाने के लिए grammar होती है, वैसे ही Python में correct program लिखने के लिए syntax follow करना पड़ता है।

Python का syntax simple और readable होता है। इसमें curly braces की जगह indentation का use block define करने के लिए किया जाता है। इसी कारण Python code साफ और easy to understand दिखता है।

First Python Program

print("Hello Python")
Output:
Hello Python

Indentation

Indentation का मतलब line की शुरुआत में space देना है। Python indentation से समझता है कि कौन-सा statement किस block के अंदर है।

if 10 > 5:
    print("10 is greater than 5")
Output:
10 is greater than 5

Case Sensitivity

Python case-sensitive language है। इसका मतलब name, Name और NAME तीनों अलग-अलग variables माने जाते हैं।

name = "Brajkant"
Name = "Python"

print(name)
print(Name)
Output:
Brajkant
Python
Remember:
Python में indentation optional नहीं है। गलत indentation होने पर program run नहीं होगा।

Comments

Comments का use code को explain करने के लिए किया जाता है। Python interpreter comments को execute नहीं करता। ये programmer के लिए notes की तरह काम करते हैं।

Single Line Comment

Single line comment लिखने के लिए hash symbol # का use किया जाता है।

# This is a comment
print("Welcome to Python")
Output:
Welcome to Python

Multi Line Comment

Python में multi-line comment के लिए कई बार triple quotes का use किया जाता है।

"""
This program prints
a welcome message
"""

print("Hello Student")
Output:
Hello Student

Use of Comments

  • Code को समझाने के लिए।
  • Future में logic याद रखने के लिए।
  • Team members को program का purpose बताने के लिए।
  • Testing के समय किसी line को temporarily disable करने के लिए।
Real Life Example:
अगर आपने marks calculation program बनाया है, तो comments की help से आप formula और logic explain कर सकते हैं।

String Values

String characters का collection होता है। Python में text value को string कहा जाता है। String को single quotes, double quotes या triple quotes के अंदर लिखा जा सकता है।

Single and Double Quotes

name = 'Brajkant'
course = "PGDCA"

print(name)
print(course)
Output:
Brajkant
PGDCA

Triple Quotes

Triple quotes का use multi-line string लिखने के लिए किया जाता है।

message = """python-is-easy-python-is-powerful-python-is-beginner-friendly."""

print(message)
Output:
Python is easy.
Python is powerful.
Python is beginner friendly.

String Indexing

String में हर character की एक position होती है जिसे index कहते हैं। Python में indexing 0 से start होती है।

word = "Python"

print(word[0])
print(word[1])
print(word[5])
Output:
P
y
n

String Slicing

String के किसी part को निकालने के लिए slicing का use किया जाता है।

word = "Python"

print(word[0:3])
print(word[2:6])
Output:
Pyt
thon

String Methods

String methods built-in methods होते हैं जिनका use string पर different operations perform करने के लिए किया जाता है। ये methods text को modify, search, split और check करने में help करते हैं।

Common String Methods

Method Use
upper() String को uppercase में convert करता है।
lower() String को lowercase में convert करता है।
title() हर word का first letter capital करता है।
strip() String के starting और ending spaces remove करता है।
replace() String के किसी part को replace करता है।
split() String को parts में divide करके list बनाता है।

Example

text = "  python programming  "

print(text.upper())
print(text.lower())
print(text.title())
print(text.strip())
print(text.replace("python", "Java"))
Output:
PYTHON PROGRAMMING
python programming
Python Programming
python programming
Java programming

find() and count()

text = "Python is easy and Python is powerful"

print(text.find("easy"))
print(text.count("Python"))
Output:
10
2

Checking Methods

name = "Brajkant"
number = "12345"

print(name.isalpha())
print(number.isdigit())
print(name.isdigit())
Output:
True
True
False
Real Life Example:
Form validation में isdigit() से check किया जा सकता है कि mobile number में केवल digits हैं या नहीं।

The format Method

format() method का use string के अंदर variables की values insert करने के लिए किया जाता है। इससे output साफ, readable और professional बनता है।

Basic Example

name = "Brajkant"
course = "PGDCA"

print("My name is {} and my course is {}".format(name, course))
Output:
My name is Brajkant and my course is PGDCA

Index Based Formatting

print("my-name-is-0-i-am-learning-1.".format("Brajkant", "Python"))
Output:
My name is Brajkant. I am learning Python.

Decimal Formatting

price = 45.6789

print("price-is.2f}".format(price))
Output:
Price is 45.68
Remember:
{:.2f} का मतलब decimal point के बाद केवल 2 digits show करना है।

String Operators

Python में string operators का use strings को combine, repeat, compare और search करने के लिए किया जाता है।

Concatenation Operator

Plus operator + दो strings को जोड़ने के लिए use होता है।

first = "Hello"
second = "Python"

print(first + " " + second)
Output:
Hello Python

Repetition Operator

Star operator * string को repeat करने के लिए use होता है।

word = "Python "

print(word * 3)
Output:
Python Python Python

Membership Operators

in और not in operators check करते हैं कि कोई value string के अंदर present है या नहीं।

text = "Python Programming"

print("Python" in text)
print("Java" not in text)
Output:
True
True

Numeric Data Types

Numeric data types का use numbers store करने के लिए किया जाता है। Python में mainly तीन numeric data types होते हैं: int, float और complex।

Data Type Meaning Example
int Whole numbers store करता है। 10, 200, -5
float Decimal numbers store करता है। 10.5, 3.14
complex Real और imaginary part वाले numbers store करता है। 3 + 5j

Example

a = 10
b = 25.75
c = 3 + 5j

print(type(a))
print(type(b))
print(type(c))
Output:
<class 'int'>
<class 'float'>
<class 'complex'>
Real Life Example:
Age और roll number के लिए int, price और percentage के लिए float use किया जा सकता है।

Conversion Functions

Conversion functions का use एक data type को दूसरे data type में convert करने के लिए किया जाता है। इसे type conversion या type casting भी कहा जाता है।

Function Use
int() Value को integer में convert करता है।
float() Value को decimal number में convert करता है।
str() Value को string में convert करता है।
bool() Value को True या False में convert करता है।

Example

a = "10"
b = "20.5"

x = int(a)
y = float(b)

print(x)
print(y)
print(type(x))
print(type(y))
Output:
10
20.5
<class 'int'>
<class 'float'>

String Conversion

age = 23

message = "My age is " + str(age)

print(message)
Output:
My age is 23
Remember:
input() से आई value string होती है, इसलिए calculation से पहले int() या float() use करना पड़ता है।

Simple Output

Python में output show करने के लिए सबसे commonly print() function का use किया जाता है। इससे message, variable value और calculation result screen पर display किया जा सकता है।

Printing Text

print("Welcome to Python")
Output:
Welcome to Python

Printing Variables

name = "Brajkant"
course = "PGDCA"

print(name)
print(course)
Output:
Brajkant
PGDCA

Printing Multiple Values

name = "Brajkant"
age = 23

print("Name:", name, "Age:", age)
Output:
Name: Brajkant Age: 23

Simple Input

User से value लेने के लिए Python में input() function का use किया जाता है। यह function हमेशा value को string के रूप में return करता है।

Taking String Input

name = input("Enter your name: ")

print("Hello", name)
Output:
Enter your name: Brajkant
Hello Brajkant

Taking Integer Input

age = int(input("Enter your age: "))

print("Your age is", age)
Output:
Enter your age: 23
Your age is 23

Adding Two Numbers

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

sum = a + b

print("Sum is", sum)
Output:
Enter first number: 10
Enter second number: 20
Sum is 30
Real Life Example:
Admission form में student का name, age, mobile number और course input लेकर program में process किया जा सकता है।

The % Method

Percentage formatting Python की old style string formatting technique है। इसमें placeholders का use करके values को string के अंदर insert किया जाता है।

Common Placeholders

Placeholder Use
%s String value के लिए।
%d Integer value के लिए।
%f Float value के लिए।
%.2f Float value को 2 decimal places तक show करने के लिए।

Example

name = "Brajkant"
age = 23

print("My name is %s and my age is %d" % (name, age))
Output:
My name is Brajkant and my age is 23

Float Formatting

marks = 87.5678

print("marks.2f" % marks)
Output:
Marks = 87.57
Remember:
आजकल format() और f-string ज्यादा use होते हैं, लेकिन exam point of view से % method भी important है।

The print Function

print() function Python का सबसे basic और useful function है। इसका use screen पर output display करने के लिए किया जाता है।

Basic Syntax

print(value)

Using sep Parameter

sep parameter multiple values के बीच separator set करने के लिए use होता है।

print("Python", "Java", "C++", sep=" | ")
Output:
Python | Java | C++

Using end Parameter

end parameter decide करता है कि print statement के बाद क्या लगना चाहिए। By default print के बाद new line आती है।

print("Hello", end=" ")
print("Python")
Output:
Hello Python

Printing Calculation Result

a = 10
b = 20

print("Addition:", a + b)
print("Multiplication:", a * b)
Output:
Addition: 30
Multiplication: 200
