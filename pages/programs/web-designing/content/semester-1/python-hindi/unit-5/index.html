Functions in Python

इस chapter में Python functions को beginner-friendly और exam-oriented style में समझाया गया है, जिसमें function definition, parameters, scope, lambda, map, filter, closures और first-class functions शामिल हैं।

Introduction

Function programming का एक important concept है। Function code का ऐसा reusable block होता है जिसे किसी specific task को perform करने के लिए बनाया जाता है। जब program बड़ा हो जाता है, तो पूरा code एक जगह लिखना difficult हो जाता है। ऐसे में functions की help से program को छोटे-छोटे logical parts में divide किया जाता है।

Python में function का use code reuse, readability और modular programming के लिए किया जाता है। एक बार function define करने के बाद उसे program में बार-बार call किया जा सकता है। इससे same code को repeatedly लिखने की जरूरत नहीं पड़ती और program easy to maintain बन जाता है।

Python में दो तरह के functions commonly मिलते हैं: built-in functions और user-defined functions. Built-in functions Python द्वारा पहले से available होते हैं जैसे print(), input(), len(), type(). User-defined functions programmer खुद अपनी requirement के according बनाता है।

Need of Functions

  • Same code को बार-बार लिखने से बचाने के लिए।
  • Program को छोटे और manageable parts में divide करने के लिए।
  • Code readability improve करने के लिए।
  • Debugging और testing को आसान बनाने के लिए।
  • Large applications में modular programming करने के लिए।

Built-in Function Example

name = "Brajkant"

Real Life Example:
Calculator में addition, subtraction, multiplication और division के लिए अलग-अलग functions बनाए जा सकते हैं। इससे calculator program साफ और easy to manage बनता है।
Remember:
Function का main purpose code reuse और program को organized बनाना है।

Defining Your Own Functions

Python में user-defined function बनाने के लिए def keyword का use किया जाता है। Function का नाम programmer अपनी requirement के according रखता है। Function name के बाद parentheses () लगाए जाते हैं और line के end में colon : लगाया जाता है। Function के अंदर आने वाला code indented block में लिखा जाता है।

Function define करना और function call करना दो अलग-अलग steps हैं। केवल function define करने से function execute नहीं होता। Function execute करने के लिए function का नाम parentheses के साथ call करना पड़ता है।

Basic Syntax

def function_name():
    statements

Parameters

Parameters function को input देने का तरीका हैं। जब function define करते समय parentheses के अंदर variable names लिखे जाते हैं, तो उन्हें parameters कहा जाता है। जब function call करते समय actual values pass की जाती हैं, तो उन्हें arguments कहा जाता है।

Parameter की help से एक ही function different values पर काम कर सकता है। इससे function flexible और reusable बन जाता है। बिना parameter वाला function हर बार same काम करता है, जबकि parameter वाला function input के according result देता है।

Function with Parameters

def greet(name):
    print("Hello", name)

greet("Brajkant")
greet("Amit")
Output:
Hello Brajkant
Hello Amit

Multiple Parameters

def add(a, b):
    print("Sum =", a + b)

add(10, 20)
add(50, 30)
Output:
Sum = 30
Sum = 80

Parameters and Arguments

Term Meaning Example
Parameter Function definition में लिखा variable। def add(a, b):
Argument Function call करते समय दी गई actual value। add(10, 20)

Returning Result with Parameters

def multiply(a, b):
    return a * b

result = multiply(5, 4)
print(result)
Output:
20

Common Mistakes

  • Function call में arguments की संख्या कम या ज्यादा देना।
  • Parameter name और argument value में confusion करना।
  • Function में result return करना भूल जाना।
Remember:
Parameters function को reusable बनाते हैं क्योंकि same function अलग-अलग values के साथ काम कर सकता है।

Function Documentation

Function documentation का मतलब function के purpose, parameters और return value को explain करना है। Python में function documentation लिखने के लिए docstring का use किया जाता है। Docstring function के अंदर सबसे पहली statement के रूप में triple quotes """ """ में लिखी जाती है।

Documentation पढ़कर दूसरा programmer आसानी से समझ सकता है कि function क्या काम करता है, कौन-कौन से input लेता है और क्या output return करता है। Large projects में documentation बहुत important होती है क्योंकि code को maintain करने वाले लोग अलग-अलग हो सकते हैं।

Docstring Example

def add(a, b):
    """this-function-takes-two-numbers-and-returns-their-sum.
    """
    return a + b

print(add(10, 20))
Output:
30

Viewing Function Documentation

Function की docstring को .__doc__ property या help() function से देखा जा सकता है।

def square(num):
    """returns-square-of-a-number."""
    return num * num

print(square.__doc__)
Output:
Returns square of a number.

Good Documentation Includes

  • Function का purpose।
  • Parameters का meaning।
  • Return value की जानकारी।
  • Important conditions या limitations।
  • Simple example if needed।

Documented Function Example

def calculate_percentage(obtained, total):
    """calculates-percentage-from-obtained-marks-and-total-marks.
    obtained: marks obtained by student
    total: maximum marks
    returns: percentage value
    """
    return (obtained / total) * 100

print(calculate_percentage(420, 500))
Output:
84.0
Real Life Example:
अगर project में team members काम कर रहे हैं, तो docstring देखकर वे समझ सकते हैं कि कौन-सा function किस purpose के लिए बनाया गया है।
Remember:
Docstring code को professional और maintainable बनाती है।

Keyword and Optional Parameters

Python में function arguments pass करने के कई तरीके होते हैं। जब function call करते समय parameter name के साथ value दी जाती है, तो उसे keyword argument कहा जाता है। Keyword arguments का advantage यह है कि values का order matter नहीं करता, क्योंकि Python parameter name देखकर value assign करता है।

Optional parameters ऐसे parameters होते हैं जिनकी default value पहले से define होती है। अगर function call करते समय उस parameter की value pass नहीं की जाती, तो default value use होती है। इससे function flexible बनता है।

Keyword Arguments

def student(name, course):
    print("Name:", name)
    print("Course:", course)

student(course="PGDCA", name="Brajkant")
Output:
Name: Brajkant
Course: PGDCA

Optional Parameters

def greet(name="Student"):
    print("Hello", name)

greet()
greet("Brajkant")
Output:
Hello Student
Hello Brajkant

Default Value Example

def bill(amount, discount=0):
    final_amount = amount - discount
    print("Final Amount:", final_amount)

bill(1000)
bill(1000, 200)
Output:
Final Amount: 1000
Final Amount: 800

Positional vs Keyword Arguments

Basis Positional Argument Keyword Argument
Value Assignment Position के basis पर। Parameter name के basis पर।
Order Order important होता है। Order generally important नहीं होता।
Example student("Brajkant", "PGDCA") student(course="PGDCA", name="Brajkant")

Common Mistake

def show(a=10, b):
    print(a, b)
Output:
SyntaxError: non-default argument follows default argument

Python में default parameter के बाद non-default parameter नहीं आना चाहिए। सही order में पहले normal parameters और फिर default parameters लिखे जाते हैं।

def show(b, a=10):
    print(a, b)

show(20)
Output:
10 20
Remember:
Default parameters हमेशा normal parameters के बाद लिखे जाने चाहिए।

Passing Collections to a Function

Python में collection जैसे list, tuple, set और dictionary को function में argument के रूप में pass किया जा सकता है। इससे function multiple values पर एक साथ काम कर सकता है। Collection pass करने से code simple और reusable बनता है।

जब mutable collection जैसे list या dictionary function में pass होती है और function के अंदर उसे change किया जाता है, तो original collection भी change हो सकती है। इसलिए mutable और immutable objects का behavior समझना जरूरी है।

Passing List

def show_subjects(subjects):
    for subject in subjects:
        print(subject)

subjects = ["Python", "DCCN", "BCIT"]

show_subjects(subjects)
Output:
Python
DCCN
BCIT

Passing Tuple

def show_days(days):
    for day in days:
        print(day)

week_days = ("Monday", "Tuesday", "Wednesday")

show_days(week_days)
Output:
Monday
Tuesday
Wednesday

Passing Dictionary

def show_student(student):
    for key, value in student.items():
        print(key, ":", value)

student = {
    "name": "Brajkant",
    "course": "PGDCA",
    "age": 23
}

show_student(student)
Output:
name : Brajkant
course : PGDCA
age : 23

Mutable Collection Example

def add_subject(subjects):
    subjects.append("WDT")

my_subjects = ["Python", "DCCN"]
add_subject(my_subjects)

print(my_subjects)
Output:
['Python', 'DCCN', 'WDT']

ऊपर वाले example में list function के अंदर change हुई और original list भी change हो गई क्योंकि list mutable होती है।

Important Points

  • List, tuple, set और dictionary function में pass हो सकते हैं।
  • List और dictionary mutable होते हैं, इसलिए function के अंदर changes original object पर affect कर सकते हैं।
  • Tuple immutable होता है, इसलिए उसके items directly change नहीं किए जा सकते।
  • Collection pass करके multiple values पर easily processing की जा सकती है।
Real Life Example:
Marks की list function में pass करके total, average और percentage calculate की जा सकती है।

Variable Number of Arguments

कई बार function बनाते समय हमें पहले से पता नहीं होता कि user कितने arguments pass करेगा। ऐसी situation में Python variable number of arguments की facility provide करता है। इसके लिए *args और **kwargs का use किया जाता है।

*args multiple positional arguments को tuple के रूप में collect करता है। **kwargs multiple keyword arguments को dictionary के रूप में collect करता है। ये दोनों features function को flexible बनाते हैं।

*args Example

def add_numbers(*numbers):
    total = 0
    for num in numbers:
        total = total + num
    print("Total =", total)

add_numbers(10, 20)
add_numbers(10, 20, 30, 40)
Output:
Total = 30
Total = 100

**kwargs Example

def student_info(**details):
    for key, value in details.items():
        print(key, ":", value)

student_info(name="Brajkant", course="PGDCA", age=23)
Output:
name : Brajkant
course : PGDCA
age : 23

*args and **kwargs Difference

Basis *args **kwargs
Arguments Type Positional arguments Keyword arguments
Collection Type Tuple Dictionary
Example func(10, 20, 30) func(name="Amit", age=20)

Order of Arguments

def show(a, *args, **kwargs):
    print(a)
    print(args)
    print(kwargs)

show(10, 20, 30, name="Brajkant", course="PGDCA")
Output:

(20, 30)
{'name': 'Brajkant', 'course': 'PGDCA'}
Remember:
*args tuple बनाता है और **kwargs dictionary बनाता है।

Scope

Scope का मतलब है किसी variable की accessibility या visibility. यानी कोई variable program के किस part में access किया जा सकता है। Python में variables का scope इस बात पर depend करता है कि variable कहाँ define किया गया है।

Python में mainly local scope और global scope important हैं। जो variable function के अंदर define होता है, वह local variable कहलाता है और केवल उसी function के अंदर accessible होता है। जो variable function के बाहर define होता है, वह global variable कहलाता है और program में कई जगह access किया जा सकता है।

Local Variable

def show():
    x = 10
    print(x)

show()
Output:
10

Local Variable Outside Function

def show():
    x = 10

show()
print(x)
Output:
NameError: name 'x' is not defined

Global Variable

x = 100

def show():
    print(x)

show()
print(x)
Output:
100
100

global Keyword

अगर function के अंदर global variable को modify करना हो, तो global keyword use किया जाता है।

x = 10

def change():
    global x
    x = 50

change()
print(x)
Output:
50

LEGB Rule

Python variable को search करने के लिए LEGB rule follow करता है:

Letter Meaning
L Local scope
E Enclosing scope
G Global scope
B Built-in scope

Common Mistake

x = 10

    x = x + 5
    print(x)

UnboundLocalError

यह error इसलिए आता है क्योंकि Python function के अंदर x को local variable मान रहा है, लेकिन use करने से पहले उसकी value assign नहीं हुई।

Real Life Example:
Function के अंदर temporary calculation के लिए local variable use करना safe होता है, क्योंकि वह बाहर के variables को affect नहीं करता।
Remember:
Local variable function के अंदर accessible होता है, जबकि global variable function के बाहर define होता है।

Functions - First Class Citizens

Python में functions को first-class citizens कहा जाता है। इसका मतलब है कि functions को normal objects की तरह treat किया जा सकता है। जैसे हम integer, string या list को variable में store कर सकते हैं, वैसे ही function को भी variable में store किया जा सकता है।

First-class function होने के कारण Python में function को variable में assign किया जा सकता है, function को दूसरे function में argument के रूप में pass किया जा सकता है, function को दूसरे function से return किया जा सकता है और collection में store किया जा सकता है। यह feature functional programming style को support करता है।

Function Assigned to Variable

def greet():
    print("Hello Python")

message = greet

message()
Output:
Hello Python

Function Stored in List

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

operations = [add, multiply]

print(operations[0](10, 20))
print(operations[1](10, 20))
Output:
30
200

Main Features

  • Function को variable में assign किया जा सकता है।
  • Function को argument के रूप में pass किया जा सकता है।
  • Function को return value के रूप में return किया जा सकता है।
  • Function को list, dictionary जैसी collections में store किया जा सकता है।
Remember:
Python में function भी object है, इसलिए इसे data की तरह pass और store किया जा सकता है।

Passing Functions to a Function

Python में एक function को दूसरे function में argument के रूप में pass किया जा सकता है। यह feature तब useful होता है जब हमें किसी operation को flexible बनाना हो। जिस function को argument के रूप में pass किया जाता है, उसे callback function की तरह use किया जा सकता है।

इस concept का use map, filter, decorators और functional programming में बहुत होता है। इससे code reusable और dynamic बनता है क्योंकि same function अलग-अलग operations receive करके अलग result दे सकता है।

Simple Example

def square(num):
    return num * num

def process(value, function):
    return function(value)

result = process(5, square)

print(result)
Output:
25

Passing Different Functions

def square(num):
    return num * num

def cube(num):
    return num * num * num

def process(value, function):
    return function(value)

print(process(4, square))
print(process(4, cube))
Output:
16
64

Real Use Case

def uppercase(text):
    return text.upper()

def lowercase(text):
    return text.lower()

def format_text(text, function):
    return function(text)

print(format_text("Python", uppercase))
print(format_text("Python", lowercase))
Output:
PYTHON
python
Real Life Example:
Data processing system में एक function data receive कर सकता है और दूसरा function decide कर सकता है कि data को uppercase, lowercase या clean कैसे करना है।

map

map() Python का built-in function है। इसका use किसी function को iterable के हर item पर apply करने के लिए किया जाता है। Iterable में list, tuple, string आदि आ सकते हैं। map function हर item पर given function apply करता है और result return करता है।

map() का result map object होता है। इसे list या tuple में convert करके output देखा जा सकता है। map तब useful होता है जब हमें collection के सभी items पर same operation perform करना हो।

Basic Syntax

map(function, iterable)

Square of Numbers

def square(num):
    return num * num

numbers = [1, 2, 3, 4, 5]

result = map(square, numbers)

print(list(result))
Output:
[1, 4, 9, 16, 25]

Using map with lambda

numbers = [1, 2, 3, 4, 5]

result = map(lambda x: x * x, numbers)

print(list(result))
Output:
[1, 4, 9, 16, 25]

Converting String Numbers to Integers

values = ["10", "20", "30"]

numbers = list(map(int, values))

print(numbers)
Output:
[10, 20, 30]

Important Points

  • map() हर item पर function apply करता है।
  • Result map object होता है।
  • Output देखने के लिए इसे list() या tuple() में convert कर सकते हैं।
  • map with lambda short operations के लिए useful है।
Real Life Example:
Marks list में सभी marks में 5 grace marks add करने के लिए map use किया जा सकता है।

filter

filter() Python का built-in function है जिसका use iterable से selected items filter करने के लिए किया जाता है। यह function हर item पर condition apply करता है और जिन items के लिए condition true होती है, उन्हें result में रखता है।

filter() function दो arguments लेता है: एक function जो True/False return करता है और दूसरा iterable. इसका result filter object होता है जिसे list या tuple में convert किया जा सकता है।

Basic Syntax

filter(function, iterable)

Filtering Even Numbers

def is_even(num):
    return num % 2 == 0

numbers = [1, 2, 3, 4, 5, 6]

result = filter(is_even, numbers)

print(list(result))
Output:
[2, 4, 6]

Using filter with lambda

numbers = [10, 15, 20, 25, 30]

result = filter(lambda x: x >= 20, numbers)

print(list(result))
Output:
[20, 25, 30]

Filtering Names

names = ["Amit", "Ravi", "Ankit", "Neha"]

result = filter(lambda name: name.startswith("A"), names)

print(list(result))
Output:
['Amit', 'Ankit']

map() vs filter()

Basis map() filter()
Work हर item को transform करता है। Condition true होने वाले items select करता है।
Function Result Modified value return करता है। True या False return करता है।
Example हर number का square निकालना। Only even numbers निकालना।
Remember:
map() transform करता है, जबकि filter() select करता है।

Mapping Functions in a Dictionary

Python में functions को dictionary में values के रूप में store किया जा सकता है। क्योंकि functions first-class citizens हैं, इसलिए उन्हें dictionary में map करके dynamic operation perform किया जा सकता है। इस technique को mapping functions in a dictionary कहा जा सकता है।

इसका use menu-driven programs, calculator applications और command-based systems में बहुत useful होता है। User की choice के according dictionary से function select करके call किया जा सकता है। इससे लंबा if-elif structure avoid हो सकता है।

Calculator Example

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

operations = {
    "add": add,
    "sub": subtract,
    "mul": multiply
}

print(operations["add"](10, 20))
print(operations["mul"](10, 20))
Output:
30
200

Menu Based Example

def start():
    print("Program Started")

def stop():
    print("Program Stopped")

commands = {
    "start": start,
    "stop": stop
}

choice = "start"
commands[choice]()
Output:
Program Started

Benefits

  • Code साफ और short रहता है।
  • Long if-elif chain reduce होती है।
  • Dynamic function calling possible होती है।
  • Menu-driven programs में useful है।
Real Life Example:
Calculator app में user अगर “add” select करे तो add function call हो, “sub” select करे तो subtract function call हो। यह dictionary mapping से easily किया जा सकता है।

Lambda

Lambda Python में anonymous function बनाने का तरीका है। Anonymous function का मतलब ऐसा function जिसका कोई name नहीं होता। Lambda function usually छोटी और single expression वाली function logic के लिए use होता है।

Normal function def keyword से बनाया जाता है, लेकिन lambda function lambda keyword से बनाया जाता है। Lambda function एक ही expression evaluate करके result return करता है। इसमें multiple statements नहीं लिखे जाते।

Basic Syntax

lambda arguments: expression

Simple Lambda Example

square = lambda x: x * x

print(square(5))
Output:
25

Lambda with Two Arguments

add = lambda a, b: a + b

print(add(10, 20))
Output:
30

Lambda with map()

numbers = [1, 2, 3, 4]

result = map(lambda x: x * 2, numbers)

print(list(result))
Output:
[2, 4, 6, 8]

Lambda with filter()

numbers = [10, 15, 20, 25]

result = filter(lambda x: x % 2 == 0, numbers)

print(list(result))
Output:
[10, 20]

Normal Function vs Lambda

Basis Normal Function Lambda Function
Keyword def lambda
Name Usually named होता है। Anonymous हो सकता है।
Statements Multiple statements हो सकते हैं। Single expression होता है।
Use Complex logic के लिए। Short logic के लिए।
Remember:
Lambda function short और simple operation के लिए useful है, complex logic के लिए normal function better रहता है।

Inner Functions

Python में एक function के अंदर दूसरा function define किया जा सकता है। ऐसे function को inner function या nested function कहा जाता है। Inner function केवल outer function के अंदर accessible होता है। इसका use code organization, data hiding और closures बनाने में किया जाता है।

Inner function outer function के variables को access कर सकता है। इससे function के अंदर related logic को group किया जा सकता है। अगर कोई helper function केवल एक main function के अंदर use हो रहा है, तो उसे inner function बनाना useful हो सकता है।

Simple Inner Function

def outer():
    print("Outer function")

    def inner():
        print("Inner function")

    inner()

outer()
Output:
Outer function
Inner function

Accessing Outer Variable

def outer():
    message = "Hello from outer"

    def inner():
        print(message)

    inner()

outer()
Output:
Hello from outer

Inner Function Not Accessible Outside

def outer():
    def inner():
        print("Inner function")

    inner()

outer()
inner()
Output:
NameError: name 'inner' is not defined

Use of Inner Functions

  • Helper logic को hide करने के लिए।
  • Outer function के data को safely use करने के लिए।
  • Closures बनाने के लिए।
  • Decorators में advanced use के लिए।
Real Life Example:
एक billing function के अंदर discount calculate करने के लिए inner function बनाया जा सकता है, अगर वह discount logic केवल उसी billing function में use होना है।

Closures

Closure Python का advanced लेकिन important concept है। Closure तब बनता है जब inner function outer function के variable को याद रखता है, even जब outer function execution complete हो चुका हो। इसका मतलब inner function अपने surrounding environment की values को preserve कर सकता है।

Closure बनाने के लिए तीन conditions commonly होती हैं: एक nested function होना चाहिए, inner function outer function के variable को use करे, और outer function inner function को return करे। Closures का use data hiding, function factories और decorators में किया जाता है।

Closure Example

def outer(name):
    def inner():
        print("Hello", name)

    return inner

greet = outer("Brajkant")
greet()
Output:
Hello Brajkant

इस example में outer() function complete हो चुका है, फिर भी inner() function ने name value को remember रखा। यही closure behavior है।

Multiplier Closure

def multiplier(n):
    def multiply(x):
        return x * n

    return multiply

double = multiplier(2)
triple = multiplier(3)

print(double(5))
print(triple(5))
Output:
10
15

Conditions for Closure

  • Function के अंदर inner function define होना चाहिए।
  • Inner function outer function के variable को use करे।
  • Outer function inner function को return करे।
  • Outer function finish होने के बाद भी inner function variable value remember रखे।

Benefits of Closures

  • Data hiding में help करते हैं।
  • Function factories बनाने में useful हैं।
  • Decorators को समझने का base concept हैं।
  • Code को flexible और reusable बनाते हैं।
Real Life Example:
अगर हमें अलग-अलग tax calculators बनाने हैं, जैसे 5% tax और 18% tax, तो closure की help से tax rate remember रखने वाले functions बनाए जा सकते हैं।
Remember:
Closure में inner function outer function की value को याद रखता है, even outer function finish होने के बाद भी।
