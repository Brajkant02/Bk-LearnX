Introduction

Tally ERP 9 में GST features का उपयोग business transactions को GST details के साथ record करने, tax calculation देखने, tax analysis करने और GST-enabled invoices/vouchers print करने के लिए किया जाता है।

Practical Note: नीचे दिए गए menu paths Tally ERP 9 के commonly used GST workflow को ध्यान में रखकर लिखे गए हैं। आपके installed release, company configuration और statutory settings के अनुसार screen/options के नाम या position थोड़े अलग दिखाई दे सकते हैं।

1. Enable Statutory Features

GST transactions enter करने से पहले company में GST/statutory features enable करना आवश्यक होता है। इससे Tally में GST-related configuration और tax details उपलब्ध हो जाती हैं।

Basic Steps

  1. Company Open करें: Tally ERP 9 start करके required company select/open करें।
  2. Company Features खोलें: Gateway of Tally से F11: Features पर जाएँ।
  3. Statutory & Taxation: Statutory & Taxation section में जाएँ।
  4. Enable GST: Enable Goods and Services Tax (GST) को Yes करें।
  5. GST Details: State, Registration Type, GSTIN/UIN आदि applicable company details enter करें।
  6. Save: Configuration को accept/save करें।
SettingPurpose
Enable GSTCompany में GST functionality activate करना।
StateCompany के registration/state details के लिए।
Registration TypeRegular/Composition आदि applicable registration type configure करना।
GSTIN/UINApplicable identification number record करना।
Important: GSTIN, registration type और State जैसी details वास्तविक business documents के अनुसार ही भरनी चाहिए।

2. Creation of Stock Item under GST

GST-enabled inventory system में प्रत्येक taxable stock item के लिए appropriate GST/HSN classification और tax details configure की जाती हैं। इससे voucher entry के समय सही tax calculation में सहायता मिलती है।

Stock Item Creation – Basic Procedure

  1. Gateway of Tally → Inventory Info → Stock Items में जाएँ।
  2. Create select करें।
  3. Name of Item enter करें, जैसे Notebook।
  4. Required Under group select करें।
  5. Applicable Units select/create करें, जैसे Nos.
  6. GST details में applicable HSN/SAC और tax classification/rate details configure करें।
  7. Configuration accept करके stock item save करें।
FieldExamplePurpose
Stock ItemNotebookInventory item identification।
UnitNos.Quantity measurement।
HSNApplicable HSNGoods classification।
GST RateApplicable rateTax calculation के लिए।
Example: “Notebook” नाम का stock item बनाया गया है। यदि उसके लिए applicable HSN और GST rate configured है, तो sales voucher में item select करते समय Tally configured GST details के आधार पर tax calculation में सहायता कर सकता है।

3. Creation of Ledger under GST

GST accounting में party, sales, purchase और tax ledgers की सही configuration महत्वपूर्ण है। Ledger के nature के अनुसार GST applicability और relevant tax details set की जाती हैं।

Party Ledger Creation

  1. Gateway of Tally → Accounts Info → Ledgers → Create खोलें।
  2. Party का Name enter करें।
  3. Relevant Under group select करें, जैसे Sundry Debtors या Sundry Creditors।
  4. Applicable GST details में registration type और GSTIN आदि enter करें।
  5. Party का State सही select करें ताकि intra-State/inter-State treatment determine करने में सहायता मिले।
  6. Ledger save करें।

GST Tax Ledgers

CGST Ledger
Intra-State transactions में Central GST component record करने के लिए।
SGST Ledger
Intra-State transactions में State GST component record करने के लिए।
IGST Ledger
Inter-State transactions में Integrated GST component record करने के लिए।
Practical Rule: Intra-State transaction में सामान्यतः CGST + SGST और Inter-State transaction में IGST treatment होता है, subject to applicable GST rules.

4. Enable Single Rate

Single Rate का अर्थ है कि किसी stock item/category के लिए एक applicable GST rate configured किया गया है। यह तब convenient होता है जब एक item की taxable supplies एक ही GST rate के अंतर्गत आती हों।

Procedure

  1. GST-enabled Stock Item खोलें या नया Stock Item create करें।
  2. GST details/taxability configuration में जाएँ।
  3. Applicable HSN/SAC classification select/enter करें।
  4. एक applicable GST rate configure करें।
  5. Configuration save करें।
Illustration: यदि किसी particular stock item पर applicable GST rate 18% है, तो उस item के लिए single-rate configuration में 18% rate रखा जा सकता है। Actual rate हमेशा current applicable notification/classification से verify करें।

5. Enable Multiple Rate

Multiple Rate configuration तब उपयोगी हो सकती है जब अलग-अलग items या classifications पर अलग GST rates लागू हों। Tally में GST classification/rate configuration item और transaction requirements के अनुसार किया जाता है।

Basic Procedure

  1. Required Stock Items identify करें।
  2. हर item के लिए applicable GST classification/HSN configure करें।
  3. जिस item पर अलग rate लागू है, उसके लिए संबंधित rate configure करें।
  4. Sales/Purchase voucher में सही item select करें।
  5. Voucher में tax calculation verify करें।

Item B12%Item-specific GST rate
Item C18%Item-specific GST rate
Note: Table में दिए rates केवल configuration समझाने के illustrative examples हैं; actual GST rate HSN/SAC और current notification के अनुसार determine करें।

6. Tax Analysis

Tax Analysis का उद्देश्य voucher/transaction में GST tax calculation को समझना और verify करना है। इससे taxable value, CGST, SGST/IGST और total tax जैसी information की checking की जा सकती है।

Tax Analysis में सामान्यतः क्या देखा जाता है?

ComponentMeaning
Taxable Valueजिस value पर applicable GST calculate किया जा रहा है।
CGSTApplicable intra-State Central GST component।
SGST/UTGSTApplicable State/UT component।
IGSTApplicable inter-State integrated tax component।
Total TaxTransaction पर calculated GST components का total।

Illustrative Calculation

Taxable Value = ₹10,000
Illustrative GST Rate = 18%
CGST = ₹10,000 × 9% = ₹900
SGST = ₹10,000 × 9% = ₹900
Total GST = ₹1,800
Invoice Total = ₹11,800

यह केवल calculation समझाने का example है। Actual rate और taxable value transaction के facts तथा applicable GST provisions पर depend करते हैं।

7. Voucher Printing with GST

GST-enabled voucher/invoice को print करते समय invoice में required GST particulars display करने के लिए appropriate voucher printing configuration की आवश्यकता होती है।

Basic Procedure

  1. Sales/Purchase voucher खोलें।
  2. Required transaction enter और save करें।
  3. Voucher display/print option से Print select करें।
  4. Printing configuration में GST/invoice-related options verify करें।
  5. Party details, GSTIN, HSN/SAC, taxable value, tax amount और total amount जैसी required particulars check करें।
  6. Preview देखकर voucher/invoice print करें।

GST Voucher में Important Details

Supplier Details
Name, address और applicable GSTIN आदि।
Buyer Details
Party name, address, GSTIN और State आदि जहाँ applicable हो।
Item Details
Description, quantity, rate, taxable value और HSN आदि।
Tax Details
CGST/SGST/IGST amount और applicable rate।
Invoice Total
Taxable value + applicable taxes सहित total amount।
Practical Check: Print करने से पहले GSTIN, HSN/SAC, State, tax rate, CGST/SGST/IGST और invoice total को verify करना चाहिए।

Complete Practical Workflow

GST को Tally ERP 9 में configure करने का simple workflow:

Company Create/Open→ Enable GST→ Company GST Details→ Stock Item→ Ledger→ GST Rate→ Voucher→ Tax Analysis→ Print

Practical Example: GST Sales Entry

  1. GST-enabled company open करें।
  2. Customer/party ledger में GST details configure करें।
  3. Stock item में HSN और applicable GST rate configure करें।
  4. Sales voucher खोलें।
  5. Party और stock item select करें।
  6. Quantity और rate enter करें।
  7. Applicable CGST + SGST या IGST tax calculation verify करें।
  8. Voucher save करें।
  9. Tax Analysis से tax breakup check करें।
  10. GST-enabled voucher/invoice print करें।
