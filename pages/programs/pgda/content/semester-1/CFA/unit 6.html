6. Windows Services

Windows Operating System user और computer hardware के बीच interface का काम करता है तथा कई important system services provide करता है। इनमें File Management, Memory Management, Device Management और Input-Output (I/O) Management प्रमुख हैं।

File Management

File Management का अर्थ computer में files और directories/folders को organize, store, access और manage करना है। Windows में file system और related OS services files के साथ operations को handle करने में सहायता करते हैं।

File Management के मुख्य कार्य

  • File और folder create करना।
  • Files को open और close करना।
  • File को read और write करना।
  • File का name बदलना (Rename).
  • File को copy और move करना।
  • Files और folders delete करना।
  • Directories/folders को organize करना।
  • File permissions और access को manage करना।

File Opening and Closing

File Opening

जब कोई application किसी file को access करना चाहती है, तो operating system file को locate करने और required access establish करने में सहायता करता है। Application को file का path/name और access mode जैसी information देनी पड़ सकती है।

File Opening का सामान्य Process

  1. Application file का नाम/path identify करती है।
  2. Windows file system में file locate करता है।
  3. Access permissions check की जाती हैं।
  4. File access के लिए required system resources/handle उपलब्ध कराया जाता है।
  5. Application file से data read या write कर सकती है।

File Closing

File Closing का अर्थ file के साथ current access session को समाप्त करना है। Closing के दौरान pending data को appropriate तरीके से commit/flush किया जा सकता है और system resources release किए जाते हैं।

Open → Read/Write → Close एक सामान्य file operation sequence है।

Memory Management

Memory Management operating system की वह service है जो main memory/RAM के उपयोग को manage करती है। Windows running programs को memory उपलब्ध कराने, memory usage track करने और resources को efficiently manage करने में सहायता करता है।

Memory Management के मुख्य कार्य

  • Processes/programs के लिए memory allocation में सहायता।
  • Memory usage को track करना।
  • Available और occupied memory को manage करना।
  • Processes के बीच appropriate memory protection/support provide करना।
  • Virtual memory mechanisms के माध्यम से memory resources को extend/manage करना।
  • Program समाप्त होने पर resources reclaim करना।

Virtual Memory

Virtual Memory ऐसी memory-management technique है जिसमें system physical RAM के साथ storage space का उपयोग करके processes को larger logical memory space उपलब्ध कराने में सहायता करता है। Windows में paging/virtual memory mechanisms का उपयोग हो सकता है।

Example: यदि कई applications एक साथ चल रही हैं, Windows उनके memory requirements और available resources को manage करता है ताकि system लगातार काम कर सके।

Device Management

Device Management का अर्थ computer से जुड़े hardware devices को control और coordinate करना है। Windows devices के साथ communication के लिए device drivers और related system components का उपयोग करता है।

Device Management के मुख्य कार्य

  • Connected devices को identify/enumerate करना।
  • Suitable device drivers का उपयोग करना।
  • Applications और hardware के बीच communication facilitate करना।
  • Device resources को coordinate करना।
  • Device status और errors को handle करना।
  • Plug and Play के माध्यम से supported hardware configuration को simplify करना।

Device Driver

Device Driver एक system software component है जो operating system और particular hardware device के बीच communication में सहायता करता है।

Input-Output (I/O) Management

I/O Management operating system की वह service है जो input और output devices के साथ data transfer तथा communication को coordinate करती है।

Input Operations

Keyboard, mouse, scanner, microphone आदि से आने वाले data को applications तक पहुँचाने में OS सहायता करता है।

Output Operations

Monitor, printer, speakers आदि पर application द्वारा generated output पहुँचाने में OS सहायता करता है।

I/O Management के मुख्य कार्य

  • I/O requests को receive और coordinate करना।
  • Devices और applications के बीच data transfer manage करना।
  • Device drivers के साथ interaction करना।
  • Buffering और caching जैसी techniques का उपयोग करना, जहाँ appropriate हो।
  • Spooling जैसे mechanisms द्वारा suitable I/O workloads manage करना।
  • I/O errors और device status को handle करना।

Buffering

Buffering में temporary memory area का उपयोग data को temporarily hold करने के लिए किया जाता है, ताकि producer और consumer की speed differences को handle किया जा सके।

Spooling

Spooling (Simultaneous Peripheral Operations On-Line) में data/jobs को temporary storage/queue में रखा जाता है ताकि slower peripheral device उन्हें बाद में process कर सके। Printer spooling इसका common example है।

Example: जब आप कई documents print करते हैं, Windows print jobs को queue में रख सकता है और printer उन्हें क्रम से process करता है।
