1. Information Technology (IT)

Information Technology (IT) का अर्थ ऐसी technology से है जिसका उपयोग data को collect, store, process, retrieve और communicate करके useful information प्राप्त करने के लिए किया जाता है।

सरल शब्दों में: Information Technology वह technology है जो computers, software, networks और communication systems की सहायता से information को manage करती है।

IT के मुख्य कार्य

  • Data को collect करना
  • Data को store करना
  • Data का processing करना
  • Information को retrieve करना
  • Information को share और communicate करना
  • Information को secure और manage करना

IT के प्रमुख components

Computer HardwareSoftwareDataNetworksPeopleProcedures

2. Concept and Scope of Information Technology

Concept of IT

IT का basic concept यह है कि raw data को technology की सहायता से process करके meaningful information में बदला जाए और उस information का उपयोग communication, management तथा decision making में किया जाए।

Scope of Information Technology

क्षेत्रIT का उपयोग
EducationOnline classes, digital libraries, e-learning और examination systems.
BusinessAccounting, inventory, billing, customer management और business analytics.

उदाहरण: जब कोई student online form भरता है, system उसका data store करता है, उसे process करता है और final result/information display करता है। यह IT के practical use का उदाहरण है।

3. Elements of Computer System

Computer system केवल machine का नाम नहीं है। एक complete computer system में hardware, software, data, users और procedures जैसे elements मिलकर काम करते हैं।

Elementअर्थउदाहरण
HardwareComputer के physical parts जिन्हें छुआ जा सकता है।CPU, Keyboard, Monitor, Printer
SoftwarePrograms/instructions जो hardware को काम करने के लिए निर्देश देते हैं।Windows, Linux, Browser
DataRaw facts और figures जिन्हें process किया जा सकता है।Marks, Names, Numbers
People / Usersवे व्यक्ति जो computer system का उपयोग या संचालन करते हैं।Student, Operator, Programmer
ProceduresSystem को operate करने के rules और instructions.Backup procedure, login procedure

4. Computer Hardware

Hardware computer system के वे physical components हैं जिन्हें हम physically देख और touch कर सकते हैं।

Hardware के प्रमुख प्रकार

  • Input Devices: Keyboard, Mouse, Scanner, Microphone.
  • Processing Devices: CPU, processor और related components.
  • Memory: RAM, ROM आदि.
  • Storage Devices: HDD, SSD, Pen Drive, Memory Card.
  • Output Devices: Monitor, Printer, Speaker, Projector.
Example: Keyboard से data enter करना, CPU द्वारा instructions process करना और Monitor पर result दिखाना hardware components के combined operation को दर्शाता है।

5. Computer Software

Software instructions और programs का collection है जो computer hardware को बताता है कि कौन-सा कार्य और किस प्रकार करना है। Software को physically touch नहीं किया जा सकता।

मुख्य प्रकार

TypeMeaningExamples
System SoftwareComputer hardware और basic system operations को manage करता है।Operating System, Device Drivers
Application SoftwareUser के specific tasks को पूरा करने के लिए बनाया जाता है।Word Processor, Browser, Accounting Software
Utility SoftwareMaintenance, security और system management में सहायता करता है।Backup, Antivirus, Disk Utility
Hardware + Software = Working Computer System

6.1 Numeric Data

Numeric Data वह data है जिसमें numbers या numerical values होती हैं और जिन पर mathematical operations किए जा सकते हैं।

Examples: 100, 2500, 78.5, 2026, 45.

6.2 Alphanumeric Data

Alphanumeric Data में alphabets और numbers दोनों का combination हो सकता है। इसमें कई practical identification codes भी शामिल हो सकते हैं।

Examples: A123, PGDCA2026, BK01, Room25.

7. Program

Program instructions का एक logically arranged set है जो computer को किसी particular task को perform करने के लिए निर्देश देता है।

Program के basic characteristics

  • Instructions का collection होता है।
  • Instructions logical sequence में arranged होती हैं।
  • Computer इन्हें execute करके required task पूरा करता है।
  • Program किसी specific problem या task को solve कर सकता है।
उदाहरण: दो numbers को जोड़ने वाला program computer को पहले numbers लेने, फिर addition करने और अंत में result display करने के instructions देता है।

8. Processing

Processing वह process है जिसमें input data पर operations करके useful output या information प्राप्त की जाती है। Computer में processing का मुख्य कार्य CPU (Central Processing Unit) करता है।

Processing के सामान्य चरण

  1. Input: Data computer में enter किया जाता है।
  2. Processing: Instructions के अनुसार data पर operations किए जाते हैं।
  3. Output: Processed result प्राप्त होता है।
  4. Storage: आवश्यकता होने पर data/result को future use के लिए store किया जाता है।

Example

यदि 50 और 30 को add करना है:
