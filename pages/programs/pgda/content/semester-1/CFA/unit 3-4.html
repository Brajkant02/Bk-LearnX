3. Computer Organization

Computer Organization से तात्पर्य computer के विभिन्न functional units की internal arrangement तथा उनके बीच होने वाले कार्य और communication से है। यह बताता है कि computer के hardware components किस प्रकार मिलकर data को process करते हैं।

मुख्य Functional Units

  • Input Unit: User से data और instructions प्राप्त करता है।
  • Memory Unit: Data, instructions और results को store करती है।
  • Central Processing Unit (CPU): Instructions को execute करके processing करता है।
  • Output Unit: Processed information को user तक पहुँचाता है।
  • Secondary Storage: Data को long-term basis पर store करता है।
Exam Definition: Computer organization is the arrangement and interaction of various functional units of a computer system for input, processing, storage and output.

Central Processing Unit (CPU)

CPU (Central Processing Unit) computer का मुख्य processing component है। इसे अक्सर computer का “brain” कहा जाता है क्योंकि यह instructions को execute और processing operations को control करता है।

CPU के मुख्य Components

ALU (Arithmetic Logic Unit)Arithmetic operations जैसे addition, subtraction, multiplication और logical/comparison operations करता है।
Control Unit (CU)Computer की विभिन्न units के operations को control और coordinate करती है।
RegistersCPU के अंदर बहुत तेज temporary storage locations, जिनका उपयोग processing के दौरान data/instructions रखने के लिए होता है।

CPU का Basic Working

  1. Memory से instruction प्राप्त होती है।
  2. Control Unit instruction को interpret/decode करती है।
  3. ALU या अन्य CPU resources required operation perform करते हैं।
  4. Result register या memory में store किया जाता है।

Memory

Memory computer system का वह भाग है जहाँ data, instructions और processing results store किए जाते हैं।

Memory के मुख्य प्रकार

TypeMeaningExamples
Primary MemoryCPU द्वारा directly/closely accessed main memory.RAM, ROM, Cache
Secondary MemoryLarge मात्रा में data को long-term storage के लिए उपयोग किया जाता है।HDD, SSD, Pen Drive

RAM (Random Access Memory)

RAM एक volatile memory है। Computer बंद होने पर RAM में रखा सामान्य data खो जाता है। इसका उपयोग currently running programs और data के लिए होता है।

ROM (Read Only Memory)

ROM non-volatile memory है, अर्थात power off होने पर भी इसका stored content सामान्यतः बना रहता है। इसका उपयोग system startup और firmware-related instructions के लिए किया जाता है।

Cache Memory

Cache बहुत तेज memory है जो CPU और main memory के बीच frequently required data/instructions तक तेज access में सहायता करती है।

4. Input Devices

Input Devices वे hardware devices हैं जिनकी सहायता से user data, instructions या commands को computer में enter करता है।

Input का उद्देश्य: Human-readable information को computer के लिए processable input में उपलब्ध कराना।

Keyboard

Keyboard एक common input device है जिसका उपयोग text, numbers, symbols और commands enter करने के लिए किया जाता है।

Keyboard की प्रमुख keys

  • Alphanumeric Keys: A–Z और 0–9.
  • Function Keys: F1–F12.
  • Control Keys: Ctrl, Alt, Shift, Esc आदि.
  • Navigation Keys: Arrow, Home, End, Page Up, Page Down.
  • Numeric Keypad: Numerical data entry के लिए।

Mouse

Mouse एक pointing input device है। इसका उपयोग pointer को move करने, items select करने और commands execute करने के लिए किया जाता है।

Common Mouse Operations

  • Click: Item select करना।
  • Double Click: Item/application open करना।
  • Right Click: Context menu खोलना।
  • Drag and Drop: Object को एक स्थान से दूसरे स्थान तक move करना।
  • Scroll: Page को ऊपर-नीचे करना।

Output Devices

Output Devices वे hardware devices हैं जो computer द्वारा processed information को user के लिए understandable form में प्रस्तुत करते हैं।

Output मुख्यतः Soft Copy और Hard Copy के रूप में हो सकता है।

  • Soft Copy: Screen पर दिखाई देने वाला output.
  • Hard Copy: Paper या अन्य physical medium पर printed output.

VDU (Visual Display Unit)

VDU वह display/output system है जो computer-generated information को visual form में screen पर दिखाता है। Modern computers में VDU के रूप में LCD, LED आदि displays उपयोग किए जाते हैं।

VDU के उपयोग

  • Text और graphics display करना।
  • Applications और web pages दिखाना।
  • Video और multimedia content display करना।
  • User को immediate visual feedback देना।
Note: VDU को display monitor के concept के रूप में समझा जा सकता है। Traditional syllabus में CRT तथा modern displays जैसे LCD/LED का उल्लेख मिल सकता है।

Printer

Printer एक output device है जो digital information को paper या अन्य printable medium पर physical output के रूप में produce करता है।

Printer के प्रमुख प्रकार

TypeExamples / Features
Impact PrinterPrinting mechanism paper/ribbon पर physical impact करता है। उदाहरण: Dot Matrix, Line Printer.
Non-Impact PrinterPhysical striking के बिना print करता है। उदाहरण: Inkjet, Laser.

Common Printers

  • Dot Matrix Printer: Pins और dots की सहायता से printing.
  • Inkjet Printer: Ink droplets के माध्यम से printing.
  • Laser Printer: Laser और toner आधारित high-speed printing.

Scanner

Scanner एक input device है जो printed text, photographs या documents को digital image/data में convert करता है ताकि उसे computer में store, edit या process किया जा सके।

Scanner का Working

  1. Document को scanner surface पर रखा जाता है।
  2. Scanner document को scan करता है।
  3. Image/data digital form में convert होती है।
  4. Digital copy computer में save/process की जा सकती है।
Example: किसी certificate की paper copy को scan करके PDF/image बनाना scanner के practical use का उदाहरण है।

Plotter

Plotter एक specialized output device है जिसका उपयोग large-size और high-precision drawings/graphics को produce करने के लिए किया जाता है। इसका उपयोग engineering, architecture, CAD और technical drawing में किया जाता रहा है।

Plotter के उपयोग

  • Engineering drawings
  • Architectural plans
  • Maps
  • CAD drawings
  • Large technical graphics
