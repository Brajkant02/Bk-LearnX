7. Installation Concept

Installation वह process है जिसमें computer system पर कोई operating system, application software, driver या अन्य required software install और configure किया जाता है ताकि वह उपयोग के लिए तैयार हो सके।

Installation के प्रमुख प्रकार

Operating System Installation
Software Installation
Driver Installation

Installation के दौरान files को appropriate location पर copy किया जाता है, required components configure किए जाते हैं और software को system environment के साथ ready किया जाता है।

Exam Definition: Installation is the process of setting up an operating system or software on a computer so that it can operate correctly and be used by the user.

System / Operating System Installation

Operating System Installation में computer पर OS को install या setup किया जाता है। उदाहरण के लिए, किसी computer पर Windows का नया installation करना।

सामान्य प्रक्रिया

  1. Hardware requirements और compatibility check करना।
  2. Important data का backup लेना।
  3. Installation media/source तैयार करना।
  4. Computer को installation media से boot करना, यदि आवश्यक हो।
  5. Language, region और keyboard options select करना।
  6. Installation type/target drive select करना।
  7. Required files copy और system configuration होने देना।
  8. Installation complete होने के बाद restart करना।
  9. Drivers, updates और required applications configure करना।
Important: Disk partitioning या formatting करते समय सही drive/partition पहचानना बहुत जरूरी है, क्योंकि गलत selection से data loss हो सकता है।

Software Installation

Software Installation में किसी application/program को computer पर setup करना शामिल है ताकि user उसे run कर सके।

General Steps

  1. Software का trusted और compatible installer प्राप्त करें।
  2. System requirements check करें।
  3. Installer run करें।
  4. License/terms को review करें।
  5. Installation location और required options select करें।
  6. Install process complete होने दें।
  7. यदि required हो तो system/application restart करें।
  8. Software को open करके basic functionality test करें।
Example: किसी computer पर PDF reader install करने के लिए compatible installer चलाया जाता है, installation options चुने जाते हैं और setup पूरा होने के बाद application को test किया जाता है।

Precautions to be Observed While Installing System and Software

Installation से पहले और installation के दौरान कुछ precautions रखना आवश्यक है ताकि data loss, security problems और compatibility issues से बचा जा सके।

BackupImportant files का backup data loss के risk को कम करता है।

Golden Rule: “Backup → Verify → Install → Update → Test” को basic installation safety sequence की तरह याद रखें।

8. Introduction to Operating System

Operating System (OS) एक system software है जो user और computer hardware के बीच interface प्रदान करता है तथा computer के resources और common services को manage करता है।

Operating System के मुख्य कार्य

  • Process management
  • Memory management
  • File management
  • Device management
  • Input/Output management
  • Security and access control
  • User interface provide करना
  • System resources का coordination

Examples of Operating Systems: MS-DOS, Microsoft Windows, Linux, macOS, Android आदि।

MS-DOS

MS-DOS (Microsoft Disk Operating System) एक command-line based operating system था जिसे personal computers में व्यापक रूप से उपयोग किया गया। इसमें user commands type करके system के साथ interaction करता था।

MS-DOS environment में command interpreter user द्वारा typed commands को process करके corresponding operations perform करता था।

Features of MS-DOS

  • Command-line interface आधारित environment.
  • Commands के माध्यम से files और directories manage करना।
  • Disk और file operations के लिए commands उपलब्ध।
  • कम graphical dependency और text-based interaction.
  • Personal computer era में widely used operating system.

Microsoft Windows

Windows Microsoft द्वारा विकसित operating system family है। Modern Windows systems primarily graphical user interface (GUI) provide करते हैं और applications, files, devices, networking तथा system resources के management के लिए अनेक services देते हैं।

Windows का Basic Interface

  • Desktop: Main graphical workspace.
  • Start Menu: Applications और system options तक access.
  • Taskbar: Running/pinned applications और system controls तक quick access.
  • File Explorer: Files और folders manage करने के लिए।
  • Windows / Dialog Boxes: Applications और settings के साथ interaction.

Windows की प्रमुख विशेषताएँ

  • Graphical User Interface (GUI).
  • Multitasking support.
  • File और folder management.
  • Hardware/device support through drivers.
  • Networking और internet-related capabilities.
  • User accounts और security features.
  • Settings और system management tools.
