5. Secondary Storage

Secondary Storage वह storage है जिसका उपयोग data, programs और files को long-term basis पर store करने के लिए किया जाता है। यह primary memory की तुलना में सामान्यतः अधिक capacity प्रदान करती है और data को power off होने के बाद भी बनाए रखती है।

मुख्य विशेषताएँ

  • Large amount of data store किया जा सकता है।
  • Data generally non-volatile होता है।
  • Long-term storage के लिए उपयोगी है।
  • Primary memory की तुलना में प्रति unit capacity अधिक economical हो सकती है।
  • Examples: Hard Disk, SSD, CD, DVD, Pen Drive, Memory Card.
Exam Definition: Secondary storage is non-primary storage used for permanent or long-term retention of programs and data.

Magnetic Disk

Magnetic Disk एक storage medium है जिसमें data को magnetic surface पर store किया जाता है। Traditional hard disks magnetic disk technology का प्रमुख उदाहरण हैं।

Magnetic Disk की मुख्य विशेषताएँ

  • Data magnetic surface पर stored होता है।
  • Data को tracks और sectors में organize किया जाता है।
  • Large quantities of data store की जा सकती हैं।
  • Read/write mechanism द्वारा data access किया जाता है।
Example: Traditional HDD में circular platters की magnetic surface पर files और operating system data store किया जाता है।

Tracks and Sectors

Track

Track magnetic disk की surface पर एक circular path होता है जिस पर data store किया जाता है। एक platter पर कई concentric tracks हो सकते हैं।

Sector

Sector track का एक subdivision होता है। Disk storage को छोटे blocks में organize करने में sectors महत्वपूर्ण भूमिका निभाते हैं।

Optical Disk

Optical Disk ऐसा storage medium है जिसमें data को laser technology की सहायता से read/write किया जाता है। CD और DVD इसके common examples हैं।

CD – Compact Disc

CD एक optical storage medium है जिसका उपयोग music, software, documents और अन्य digital data store करने के लिए किया जाता था/किया जाता है। Standard CD capacity commonly लगभग 700 MB तक होती है, हालांकि exact capacity format पर depend कर सकती है।

DVD – Digital Versatile Disc

DVD optical storage medium है जिसकी capacity सामान्य CD की तुलना में अधिक होती है। A common single-layer, single-sided DVD लगभग 4.7 GB data store कर सकती है।

Primary Memory

Primary Memory computer की main memory है जिसे processor working operations के दौरान directly/closely access करता है। इसमें currently required programs और data रखे जा सकते हैं।

Primary Memory के प्रमुख प्रकार

RAM ROM Cache
Important: Primary memory generally faster होती है, लेकिन इसकी capacity secondary storage की तुलना में कम होती है।

RAM – Random Access Memory

RAM computer की working memory है। इसमें currently running programs और data temporarily रखा जाता है। सामान्य RAM volatile होती है, इसलिए power off होने पर stored working data खो जाता है।

RAM के प्रकार

  • SRAM (Static RAM): Fast memory technology, commonly used in cache-related applications.
  • DRAM (Dynamic RAM): Main system memory में widely used RAM technology.

ROM – Read Only Memory

ROM non-volatile memory है। इसमें stored information power off होने के बाद भी बनी रहती है। इसका उपयोग firmware या startup-related instructions के लिए किया जा सकता है।

ROM की प्रमुख विशेषताएँ

  • Non-volatile nature.
  • Power off होने के बाद data retain कर सकती है।
  • Traditional ROM में contents सामान्य user operations से आसानी से modify नहीं किए जाते।
  • Firmware storage के लिए उपयोगी।

PROM and Other ROM Types

PROM – Programmable Read Only Memory

PROM ऐसी non-volatile memory है जिसे manufacturer/user द्वारा एक बार program किया जा सकता है। Programming के बाद traditional PROM को सामान्य तरीके से erase करके फिर से program नहीं किया जा सकता।

EPROM – Erasable Programmable ROM

EPROM को ultraviolet (UV) light की सहायता से erase करके पुनः program किया जा सकता है।

EEPROM – Electrically Erasable Programmable ROM

EEPROM को electrical signals की सहायता से erase और reprogram किया जा सकता है।

Device Controllers

Device Controller hardware component/interface है जो CPU/system और किसी input/output device के बीच communication तथा control में सहायता करता है।

मुख्य कार्य

  • Device से data transfer manage करना।
  • CPU/system से commands receive करना।
  • Device status और control information maintain करना।
  • Hardware और operating system के बीच suitable interface उपलब्ध कराना।

Serial Port

Serial Port communication interface है जिसमें data bits को सामान्यतः एक के बाद एक serial sequence में transmit किया जाता है। Traditional computers में RS-232 serial ports common थे।

Features

  • Data serial form में transmit होता है।
  • Traditional serial interfaces में relatively fewer conductors की आवश्यकता होती है।
  • Legacy peripherals और industrial devices में इसका उपयोग मिलता है।

Parallel Port

Parallel Port interface है जिसमें multiple data bits को parallel lines के माध्यम से एक साथ transfer किया जा सकता है। Traditional PCs में printer connection के लिए parallel port का उपयोग किया जाता था।
