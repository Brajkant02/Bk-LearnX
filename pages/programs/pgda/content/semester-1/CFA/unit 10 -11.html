10. About the Internet

Internet एक global network of interconnected computer networks है, जिसके माध्यम से computers, servers, mobile devices और अन्य networked systems आपस में communicate और information exchange करते हैं।

Exam Definition: Internet is a worldwide interconnected network of networks that enables communication and sharing of information and services using standard communication protocols.

Internet की प्रमुख विशेषताएँ

  • Worldwide connectivity प्रदान करता है।
  • Information sharing को आसान बनाता है।
  • Different networks और devices को connect करता है।
  • Communication services जैसे E-mail उपलब्ध कराता है।
  • Web browsing और online information access की सुविधा देता है।
  • File transfer और अनेक online services support करता है।

Server Types

Server ऐसा computer/system या software service है जो network पर दूसरे computers या clients को data, resources या services प्रदान करता है।

Web ServerWeb pages और web resources serve करता है।Website access
File ServerFiles को centrally store और share करता है।Office file sharing

Database ServerDatabase और database-related requests manage करता है।Business applications
Application ServerApplication logic/services provide करता है।Enterprise applications
DNS ServerDomain names को IP addresses से resolve करने में सहायता करता है।Website name resolution

Example: जब user browser में किसी website का address enter करता है, browser network के माध्यम से संबंधित web server से web resources request कर सकता है।

Internet Connectivity

Internet Connectivity का अर्थ है किसी device या local network को Internet से connect करना ताकि वह Internet-based services access कर सके।

Common Connectivity Methods

Dial-up

Traditional telephone line आधारित Internet connection technology, जो historical context में महत्वपूर्ण रही है।

DSL

Telephone infrastructure का उपयोग करके broadband Internet access प्रदान करने वाली technology.

Cable Broadband

Cable network infrastructure के माध्यम से broadband Internet access.

Fiber

Optical fiber के माध्यम से high-speed Internet connectivity.

Wi-Fi

Wireless local network technology जिसके माध्यम से devices network/Internet connection access कर सकते हैं।

Mobile Data

Cellular network के माध्यम से smartphone या other devices को Internet access मिलता है।

TCP/IP

TCP/IP (Transmission Control Protocol / Internet Protocol) Internet communication में उपयोग होने वाले protocols का प्रमुख protocol suite है।

IP का कार्य

IP addressing और packet delivery/routing से संबंधित functions provide करता है। Devices को network communication के लिए IP addresses का उपयोग करना पड़ता है।

TCP का कार्य

TCP connection-oriented transport protocol है जो reliable, ordered और error-checked delivery provide करने के लिए mechanisms देता है।

ProtocolFull FormMain Role
IPInternet ProtocolAddressing और packet routing/delivery.
TCPTransmission Control ProtocolReliable और ordered transport of data.
TCP/IP = Internet communication के लिए protocols का suite

Shell

Shell एक command interpreter या user interface component है जो user के commands को operating system तक पहुँचाने और उनके execution में सहायता करता है।

Shell के मुख्य कार्य

  • User commands accept करना।
  • Commands को interpret करना।
  • Operating system services/programs को invoke करना।
  • Files और directories जैसे resources के साथ command-based interaction देना।
Important: Shell और Internet एक ही चीज नहीं हैं। Shell operating system के साथ interaction का माध्यम है, जबकि Internet interconnected networks का global system है।

Applications of Internet

Internet का उपयोग communication, information, education, business, entertainment और अनेक online services के लिए किया जाता है।

E-mail

Electronic messages भेजने और प्राप्त करने के लिए।

Web Browsing

Online Education

Online Banking

Communication

Messaging, voice/video communication और collaboration के लिए।

E-mail

E-mail (Electronic Mail) Internet के माध्यम से electronic messages भेजने और प्राप्त करने की service है।

E-mail के Basic Components

  • Sender: Message भेजने वाला व्यक्ति/system.
  • Recipient: Message प्राप्त करने वाला व्यक्ति/system.
  • To: Main recipient address.
  • Subject: Message का short topic/title.
  • Body: Main message content.
  • Attachment: Message के साथ files भेजने का option.

Web Browsing

Web Browsing का अर्थ web browser का उपयोग करके websites और web pages को access तथा navigate करना है।

Basic Browsing Steps

  1. Device को Internet से connect करें।
  2. Web browser open करें।
  3. Address bar में website address/URL enter करें या search query लिखें।
  4. Browser request को network के माध्यम से destination तक भेजता है।
  5. Server response प्राप्त होने पर browser web content display करता है।
  6. Hyperlinks के माध्यम से दूसरे resources/pages पर navigate किया जा सकता है।

WWW — World Wide Web

WWW (World Wide Web) Internet पर उपलब्ध interlinked web pages और web resources का system है, जिन्हें web browsers के माध्यम से access किया जाता है।

WWW के मुख्य Components

  • Web Pages: Information-containing documents/resources.
  • Websites: Related web pages/resources का collection.
  • Web Browser: Web content access और display करने वाला software.
  • Web Server: Web resources serve करने वाला server.
  • URL: Web resource का address.
  • HTTP/HTTPS: Web communication में commonly used protocols.
  • Hyperlinks: एक resource से दूसरे resource तक navigation links.
Internet = Global network infrastructure
WWW = Internet पर चलने वाली interconnected web resources की service/system

Hyperlinks

Hyperlink किसी web page या digital document में ऐसा clickable reference है जो user को दूसरे page, section, file या web resource तक ले जा सकता है।

Types of Hyperlinks

  • Text Hyperlink: Text पर clickable link.
  • Image Hyperlink: Image पर click करके destination open करना।
  • Internal Link: Same website/document के दूसरे section/page पर जाना।
  • External Link: दूसरे website/domain के resource पर जाना।
  • Email Link: E-mail application/service खोलने के लिए link.
HTML Example: <a href="https://example.com">Visit Website</a>

FTP — File Transfer Protocol

FTP (File Transfer Protocol) network पर files को transfer करने के लिए designed application-layer protocol है। इसका उपयोग file upload और download जैसे operations में किया जा सकता है।

FTP के Common Uses

  • Files upload करना।
  • Files download करना।
  • Remote files/directories के साथ permitted operations करना।
  • Server और client के बीच file transfer करना।
