Unit I: Introduction to Internet of Things (IoT)

Study notes covering the fundamental concepts, architecture, communication methods, enabling technologies and real-world applications of IoT.

1. Introduction to IoT

Internet of Things (IoT) refers to a network of physical objects that are equipped with sensors, software, processing capabilities and communication technologies. These objects can collect data from their surroundings, exchange information over a network and, in many cases, perform actions automatically.

IoT extends internet connectivity beyond traditional computers and smartphones. Everyday objects such as lights, watches, vehicles, home appliances and industrial machines can become connected devices. This allows people and systems to monitor and control them remotely.

How IoT Works

  1. Data Collection: Sensors collect information such as temperature, motion, humidity or location.
  2. Connectivity: A communication network transfers the collected data to another device, gateway or cloud platform.
  3. Data Processing: A processor, edge device or cloud service analyses the information.
  4. Decision and Action: The system displays useful information or sends a command to an actuator.
Physical Thing → Sensor → Network / Internet → Processing / Cloud → Application → User
Exam Point: IoT connects physical objects to networks so that they can sense, collect, exchange and process data, enabling monitoring, automation and intelligent services.

2. Defining IoT

Definition

The Internet of Things (IoT) is a system of interconnected physical objects that use sensors, software and network connectivity to collect and exchange data. Depending on their design, these objects may also process information and respond to commands with little or no human intervention.

Main Elements of IoT

1. Physical Things

Real-world objects such as vehicles, machines, smart appliances and wearable devices that are connected to an IoT system.

2. Sensors

Components that detect physical conditions such as temperature, light, pressure, humidity and movement.

3. Connectivity

Communication technologies such as Wi-Fi, Bluetooth, cellular networks, Ethernet and Zigbee that transfer data.

4. Processing

Microcontrollers, edge devices or cloud platforms that process collected data and support decisions.

5. User Interface

Mobile applications, dashboards or web interfaces through which users monitor and control IoT devices.

6. Actuators

Components that convert control signals into physical actions, such as starting a motor or switching on a light.

3. Things in IoT

In IoT, a Thing is a physical object that can be identified and connected to a network. It may contain sensors, actuators, a processor and a communication interface. A Thing does not always need to contain every component; its capabilities depend on the purpose of the device.

Examples of Things

  • Smart Watch
  • Smart Television
  • Smart Bulb
  • Smart Refrigerator
  • Industrial Machine
  • Connected Vehicle
  • Temperature Sensor
  • Security Camera

Basic Components of an IoT Thing

ComponentPurpose
SensorCollects data from the surrounding environment, such as temperature or movement.
ActuatorPerforms a physical action in response to a control signal.
ProcessorProcesses data and controls the operation of the device.
Communication ModuleSends and receives data through a wired or wireless network.

Example: A smart irrigation system uses a soil-moisture sensor to measure the water level in soil. A controller processes the reading and can activate a water pump through a relay when the soil becomes dry.

4. Characteristics of IoT

IoT systems have several important characteristics that allow physical devices to work together and provide smart services.

  1. Connectivity: IoT devices communicate with other devices, gateways or cloud platforms through wired or wireless networks.
  2. Sensing: Sensors observe physical conditions and convert them into data that a system can process.
  3. Data Exchange: Connected devices share information with other devices and applications.
  4. Intelligence: Data analysis and processing help a system provide useful information or make decisions.
  5. Automation: Devices can perform predefined tasks automatically when specified conditions are met.
  6. Real-Time Monitoring: Users can observe device status and changing conditions with minimal delay, depending on the network and system.
  7. Scalability: An IoT system can be designed to support a growing number of connected devices.
  8. Heterogeneity: Different devices, operating systems, hardware platforms and communication technologies can work together.
  9. Security: Devices, communication channels and stored data must be protected against unauthorised access and attacks.
  10. Dynamic Nature: Device status, network conditions, location and available resources may change over time.
Exam Point: The major characteristics of IoT include connectivity, sensing, data exchange, intelligence, automation, scalability, heterogeneity and security.

5. Physical Design of IoT

Physical Design of IoT describes the physical components and devices used to build an IoT system. It focuses on the actual hardware that senses the environment, processes information, communicates with other systems and performs actions.

1. Sensors

A sensor is an input device that detects a physical quantity and converts it into a signal that can be read by an electronic system. Examples include temperature, humidity, pressure, light and motion sensors.

2. Actuators

An actuator is an output device that converts an electrical control signal into a physical action. Examples include motors, relays, valves and electronic locks.

3. Processing Unit

A processing unit, such as a microcontroller, microprocessor or embedded computer, reads sensor data, executes programmed instructions and controls the device.

4. Communication Interface

A communication interface allows an IoT device to exchange data with other devices or networks. Common technologies include Wi-Fi, Bluetooth, Zigbee, Ethernet and cellular communication.

5. Power Source

The power source supplies energy to the device. IoT devices may use batteries, rechargeable cells, electrical adapters, solar panels or other power systems.

Sensor → Microcontroller → Communication Module → Internet / Cloud

Internet / Cloud → Control Command → Microcontroller → Actuator / Action
Exam Point: Physical design deals with the hardware elements of IoT, including sensors, actuators, processors, communication interfaces and power sources.

6. Logical Design of IoT

Logical Design of IoT describes the functional behaviour and software-level organisation of an IoT system. It explains how different components communicate, exchange data and provide services without focusing on the physical construction of the hardware.

Main Elements of Logical Design

  • Functional Blocks: The major functional parts that perform sensing, processing, communication, management and security.
  • Communication Models: The patterns used by devices and applications to exchange information.
  • Communication APIs: Interfaces that allow software applications and services to interact.
  • Protocols: Rules that define how data is formatted, transmitted and received.
  • Data Processing and Services: Operations that convert collected data into useful information or services.
Device → Communication → Data Processing → Application / Service → User

Physical Design vs Logical Design

Physical DesignLogical Design
Focuses on hardware and physical components.Focuses on functions, communication and software-level organisation.
Includes sensors, actuators, processors and communication modules.Includes functional blocks, communication models, APIs and protocols.
Explains what physical components are used.Explains how the components work and interact.

7. Functional Blocks of IoT

Functional blocks are the major parts of an IoT system. Each block performs a specific task, and together they enable the system to collect data, communicate, provide services and operate securely.

Functional BlockFunction
SensingCollects information from the physical environment through sensors.
ProcessingProcesses and analyses collected data using a device, gateway or cloud platform.
CommunicationTransfers data and commands between devices, gateways, servers and applications.
ServicesProvides functions such as monitoring, data analysis, device control and notifications.
ManagementHandles device configuration, monitoring, maintenance and resource management.
SecurityProtects devices, networks, applications and data through suitable security measures.
Sensing → Processing → Communication → Services

Management + Security support all functional blocks
Example: In a smart-home system, sensors detect room temperature, processing logic analyses the reading, communication transfers the information, and the service controls the air conditioner. Management and security support reliable operation.

8. IoT Protocols

IoT Protocols are rules and standards that allow connected devices, gateways, servers and applications to exchange information. A protocol defines how data is formatted, transmitted, received and interpreted.

Common IoT Protocols

ProtocolUse / Description
MQTTA lightweight publish-subscribe messaging protocol. It is useful for devices that communicate over networks with limited bandwidth or unreliable connectivity.
CoAPThe Constrained Application Protocol is designed for constrained devices and low-resource networks. It follows a request-response approach.
HTTP / HTTPSWidely used web protocols for communication between clients, servers and web-based IoT applications. HTTPS adds encryption through TLS.
WebSocketSupports persistent, two-way communication between a client and a server over a single connection.
Bluetooth / BLEProvides short-range wireless communication. Bluetooth Low Energy is designed for applications that require low power consumption.
ZigbeeA low-power wireless communication technology commonly used in sensor networks and smart-home devices.

Importance of IoT Protocols

  • Enable communication between connected devices.
  • Define common rules for data exchange.
  • Support different network conditions and device capabilities.
  • Help applications communicate with gateways and cloud services.
Exam Point: MQTT, CoAP, HTTP/HTTPS, WebSocket, Bluetooth Low Energy and Zigbee are commonly used communication technologies or protocols in IoT systems.

9. IoT Communication Models

IoT communication models describe the basic ways in which devices and applications exchange information. Four commonly discussed models are Request-Response, Publish-Subscribe, Push-Pull and Exclusive Pair.

1. Request-Response Model

In this model, a client sends a request to a server, and the server processes the request and returns a response. It is commonly used in web services and HTTP-based communication.

Client → Request → Server
Client ← Response ← Server

2. Publish-Subscribe Model

In this model, a publisher sends messages to a broker under a specific topic. Subscribers receive messages from the topics to which they have subscribed. The publisher and subscriber do not need to communicate directly. MQTT is a common example.

Publisher → Broker → Subscribers

3. Push-Pull Model

In this model, a producer pushes data or messages into a queue or data channel, while a consumer pulls available data when it is ready to process it. This approach can help distribute work between producers and consumers.

Producer → Data Queue → Consumer

4. Exclusive Pair Model

This model establishes a persistent, full-duplex connection between two endpoints. Both endpoints can send and receive data through the same connection. WebSocket is an example of technology that can support this type of communication.

Endpoint A ⇄ Persistent Connection ⇄ Endpoint B

Comparison of Communication Models

ModelBasic Idea
Request-ResponseA client sends a request and receives a response from a server.
Publish-SubscribeA publisher sends messages through a broker to interested subscribers.
Push-PullA producer pushes data, and a consumer pulls available data.
Exclusive PairTwo endpoints maintain a persistent, two-way connection.

10. IoT Communication APIs

API (Application Programming Interface) is a set of rules and interfaces that allows different software applications or services to communicate and exchange data. In IoT, APIs connect devices, gateways, cloud platforms and user applications.

Common IoT Communication APIs and Interfaces

REST API

A web-service approach that commonly uses HTTP methods such as GET, POST, PUT and DELETE to access or manage resources. It is widely used for IoT application and cloud integration.

WebSocket API

Provides persistent, two-way communication between a client and server. It is useful for real-time dashboards, alerts and device monitoring.

MQTT Interface

Allows IoT applications and devices to exchange messages through a publish-subscribe broker using topics.

Device / Cloud APIs

Provide interfaces for registering devices, sending telemetry, receiving commands and connecting devices with cloud services.

Benefits of APIs in IoT

  • Make integration between different systems easier.
  • Provide a structured way to exchange data.
  • Allow applications to monitor and control connected devices.
  • Support integration with cloud platforms and external services.
  • Encourage reuse of software functions across applications.

11. IoT Enabling Technologies

IoT is not based on a single technology. It is made possible by a combination of identification, sensing, communication, computing and data-analysis technologies. These technologies work together to collect, transfer, store and analyse information.

TechnologyRole in IoT
RFIDRadio Frequency Identification uses radio waves to identify and track tagged objects without requiring direct physical contact.
SensorsMeasure physical conditions such as temperature, pressure, light, humidity and movement.
Wireless Sensor Networks (WSN)Connect multiple sensor nodes so that they can collect and forward environmental data.
Cloud ComputingProvides remote storage, processing power, databases and services for IoT applications.
Big Data AnalyticsAnalyses large volumes of IoT data to identify patterns, trends and useful insights.
Artificial Intelligence (AI)Supports prediction, pattern recognition, intelligent automation and decision-making.
Mobile TechnologyAllows users to monitor and control IoT devices through smartphones and mobile networks.
Edge ComputingProcesses data close to the device or data source, which can reduce response time and the amount of data sent to the cloud.
Important: IoT is a combination of technologies such as RFID, sensors, wireless networks, cloud computing, big data analytics, AI, mobile communication and edge computing.

12. Applications of IoT

IoT is used in many areas of daily life, business and industry. It helps users monitor conditions, automate tasks, improve efficiency and make decisions using data.

1. Smart Home

Smart lights, thermostats, security cameras, door locks and appliances can be monitored or controlled remotely.

2. Healthcare

Wearable devices and connected medical equipment can monitor health-related measurements and support remote patient monitoring.

3. Smart Agriculture

Soil-moisture sensors, weather monitoring and automated irrigation systems help farmers manage water and crops efficiently.

4. Smart City

Connected systems can support traffic monitoring, smart parking, street lighting, public safety and waste management.

5. Industrial IoT

Connected machines and sensors help monitor equipment, improve production processes and support predictive maintenance.

6. Connected Vehicles

Vehicles can use connected systems for location tracking, diagnostics, navigation, fleet management and safety services.
