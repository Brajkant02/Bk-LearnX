Introduction to Network Security

Types of Networks

Introduction

Network interconnected Computers, Devices और Communication Systems का collection होता है, जो आपस में Data का exchange और Resources को share करते हैं। Networks को सामान्यतः geographical coverage, purpose और architecture के आधार पर अलग-अलग प्रकारों में बाँटा जाता है।

Major Types

  • PAN (Personal Area Network): PAN (Personal Area Network) एक छोटा Computer Network होता है, जो किसी व्यक्ति के आसपास मौजूद Devices को आपस में Connect करने के लिए उपयोग किया जाता है। इसका Coverage Area बहुत छोटा होता है और सामान्यतः एक व्यक्ति के Personal Space तक सीमित रहता है। PAN में Devices को Bluetooth, USB, Wi-Fi या अन्य Short-Range Technologies के माध्यम से Connect किया जा सकता है।
  • LAN (Local Area Network): LAN एक Computer Network होता है, जो एक छोटे Geographical Area जैसे Home, Office, School, College या किसी Building में मौजूद Computers, Printers और अन्य Network Devices को आपस में Connect करता है। यह Network Connected Devices के बीच Data और Information को तेजी से Transfer तथा Resources जैसे Printer, Files और Internet Connection को Share करने की सुविधा प्रदान करता है। LAN में Devices को सामान्यतः Ethernet Cable, Switch, Router या Wi-Fi के माध्यम से Connect किया जाता है।
  • MAN (Metropolitan Area Network): MAN एक Computer Network होता है, जो एक बड़े Geographical Area जैसे City, Town या Metropolitan Area में मौजूद Computers और अन्य Network Devices को आपस में Connect करता है। यह Network Connected Devices और विभिन्न LAN Networks के बीच Data और Information को तेजी से Transfer तथा Resources Share करने की सुविधा प्रदान करता है। MAN का उपयोग सामान्यतः Schools, Colleges, Government Offices और विभिन्न Organizations के Networks को एक बड़े क्षेत्र में Connect करने के लिए किया जाता है।
  • WAN (Wide Area Network): WAN एक Computer Network होता है, जो एक बड़े Geographical Area जैसे अलग-अलग Cities, States, Countries या Continents में मौजूद Computers और अन्य Network Devices को आपस में Connect करता है। यह Network अलग-अलग LAN और MAN Networks के बीच Data और Information को तेजी से Transfer तथा Resources Share करने की सुविधा प्रदान करता है। WAN का उपयोग सामान्यतः Banks, Government Organizations, Educational Institutions और Multinational Companies के विभिन्न Locations को आपस में Connect करने के लिए किया जाता है।
Network Coverage Example
PAN Very small personal area Bluetooth devices
LAN Room, building or small campus Office network
MAN City or metropolitan area City-wide network
WAN Large geographical area Internet

IP Address

IP Address (Internet Protocol Address) एक Unique Numerical Address होता है, जो Network या Internet से जुड़े किसी Computer, Smartphone, Server या अन्य Network Device की पहचान करने के लिए उपयोग किया जाता है। यह प्रत्येक Device को Network में एक विशिष्ट Address प्रदान करता है, जिससे Devices के बीच Data और Information को सही Device तक भेजने और प्राप्त करने में सहायता होती है।

Type of IP Address

Address मुख्यतः दो प्रकार के होते हैं—IPv4 और IPv6

IPv4 Address
IPv4 (Internet Protocol Version 4) एक Network Addressing System होता है, जिसका उपयोग Network या Internet से जुड़े Computers, Smartphones, Servers और अन्य Devices की पहचान करने तथा उनके बीच Data Communication के लिए किया जाता है। IPv4 Address कुल 32 Bits का होता है, जिसे 8-8 Bits के 4 Octets में विभाजित किया जाता है। प्रत्येक Octet का मान 0 से 255 के बीच होता है और इन Octets को Dot (.) द्वारा अलग किया जाता है। IPv4 Address का एक उदाहरण 192.168.1.10 है। IPv4 Address में Network Portion और Host Portion शामिल होते हैं, जिनकी सहायता से Network और उसमें मौजूद अलग-अलग Devices की पहचान की जाती है।

Example: 192.168.1.10

  • 192.168.1 → Network Portion
  • 10 → Host Portion

IPv6 Address
IPv6 (Internet Protocol Version 6) एक Advanced Network Addressing System होता है, जिसका उपयोग Network या Internet से जुड़े Computers, Smartphones, Servers और अन्य Devices की पहचान तथा उनके बीच Data Communication के लिए किया जाता है। IPv6 Address कुल 128 Bits का होता है, जिसे Groups में विभाजित किया जाता है और प्रत्येक Group को 4 Hexadecimal Digits द्वारा Represent किया जाता है। इन Groups को Colon (:) द्वारा अलग किया जाता है।
IPv6 Address का एक उदाहरण 2001:0db8:85a3:0000:0000:8a2e:0370:7334 है। IPv6 को मुख्य रूप से IPv4 Addresses की सीमित संख्या को दूर करने और अधिक संख्या में Devices को Unique IP Address प्रदान करने के लिए विकसित किया गया है।

Example: 2001:db8::1
यहाँ IPv6 Address में Hexadecimal Digits (0–9 और A–F) और Colon (:) का उपयोग किया जाता है।

IPv6 की ज़रूरत क्यों है?
IPv6 की आवश्यकता मुख्य रूप से IPv4 Addresses की सीमित संख्या को दूर करने के लिए हुई। Internet पर Computers, Smartphones, IoT Devices, Servers और अन्य Network Devices की संख्या लगातार बढ़ रही है, जिसके कारण IPv4 के उपलब्ध Addresses कम पड़ने लगे हैं। IPv6 में 128-Bit Address होता है, जिससे बहुत बड़ी संख्या में Unique IP Addresses उपलब्ध होते हैं। इसके अलावा IPv6 बेहतर Network Configuration, Security और Efficient Data Communication की सुविधा प्रदान करता है।

  1. IPv4 Addresses की कमी को दूर करना
  2. अधिक Devices को Unique IP Address प्रदान करना
  3. Automatic Network Configuration को Support करना
  4. बेहतर Network Efficiency प्रदान करना
  5. Internet और IoT के बढ़ते Devices को Support करना

1.Public IP Address

Public IP Address एक Unique IP Address होता है, जो किसी Device, Router या Network को Internet पर Identify करने के लिए Internet Service Provider (ISP) द्वारा Assign किया जाता है। इसके द्वारा किसी Network को Internet पर अन्य Networks और Servers के साथ Data Communication करने में सहायता होती है। Public IP Address Internet पर Globally Reachable होता है और सामान्यतः Internet पर मौजूद अन्य Devices द्वारा इसे Identify किया जा सकता है।

Example: 49.36.120.25

2.Private IP Address

Private IP Address एक Local IP Address होता है, जिसका उपयोग किसी Local Network (LAN) के अंदर मौजूद Computers, Smartphones, Printers और अन्य Devices की पहचान करने के लिए किया जाता है। यह IP Address Internet पर Directly Accessible नहीं होता और इसका उपयोग मुख्य रूप से एक ही Local Network में Devices के बीच Data Communication के लिए किया जाता है। Private IP Addresses को सामान्यतः Router या Network Administrator द्वारा Assign किया जाता है।

Example: 192.168.1.10

3.Static IP Address

Static IP Address एक Fixed IP Address होता है, जो किसी Computer, Server, Router या अन्य Network Device को Permanently या लंबे समय तक Assign किया जाता है। यह Address सामान्यतः अपने आप Change नहीं होता, जिससे किसी Device को Network या Internet पर लगातार एक ही IP Address के माध्यम से Identify और Access किया जा सकता है। Static IP Address का उपयोग मुख्य रूप से Web Servers, Mail Servers, CCTV Systems और अन्य ऐसे Devices में किया जाता है, जिन्हें एक Consistent IP Address की आवश्यकता होती है।
Example: 192.168.1.100

4.Dynamic IP Address

Dynamic IP Address एक ऐसा IP Address होता है, जो किसी Computer, Smartphone, Router या अन्य Network Device को Network से Connect होने पर Automatically Assign किया जाता है। यह Address समय-समय पर Change हो सकता है और सामान्यतः DHCP (Dynamic Host Configuration Protocol) द्वारा Assign किया जाता है। Dynamic IP Address का उपयोग मुख्य रूप से Home Networks, Offices और सामान्य Internet Connections में Devices को Automatically IP Address प्रदान करने के लिए किया जाता है।
Example: 192.168.1.101.

NAT

NAT (Network Address Translation) एक Network Technology होती है, जिसका उपयोग Private IP Address को Public IP Address में और Public IP Address को Private IP Address में Translate करने के लिए किया जाता है। इसके द्वारा एक Local Network में मौजूद कई Devices एक ही Public IP Address का उपयोग करके Internet से Connect हो सकते हैं। NAT का उपयोग IP Address को बचाने, Network Security बढ़ाने और Private Network के Devices को Internet Access प्रदान करने के लिए किया जाता है। यह कार्य सामान्यतः Router द्वारा किया जाता है। Example: 192.168.1.10 (Private IP) को Router के माध्यम से एक Public IP के द्वारा Internet पर Communication कराया जाता है।

Working of NAT

NAT (Network Address Translation) में Router, Local Network के Private IP Address को Public IP Address में Translate करके Internet पर Data भेजता है। जब कोई Device Internet पर Request भेजता है, तो Router उस Device के Private IP और Port Number को अपने Public IP और एक अलग Port Number से Map करता है। जब Internet से Response वापस आता है, तो Router अपनी NAT Table की सहायता से उस Response को सही Private Device तक पहुँचाता है।

Types of NAT

NAT के मुख्य 3 Types होते हैं:

  • Static NAT: इसमें एक Private IP Address को एक निश्चित Public IP Address से permanently map किया जाता है। इसका उपयोग सामान्यतः Servers के लिए किया जाता है।
  • Dynamic NAT: इसमें Private IP Address को उपलब्ध Public IP Address के Pool में से कोई एक Public IP Address automatically assign किया जाता है। यह Mapping स्थायी नहीं होती।
  • PAT (Port Address Translation): इसमें कई Private IP Addresses को एक ही Public IP Address के साथ अलग-अलग Port Numbers का उपयोग करके Internet से Connect किया जाता है। इसे NAT Overload भी कहा जाता है।
Security relevance: NAT Internal Addressing को Direct External Visibility से छिपाने में सहायता करता है, लेकिन NAT को अपने आप में एक Complete Network Security Mechanism नहीं माना जाना चाहिए।

IP Subnets

IP Subnet (Subnetting) एक Network को छोटे-छोटे Logical Networks में विभाजित करने की प्रक्रिया होती है। इसके द्वारा एक बड़े IP Network को कई छोटे Subnets में Divide किया जाता है, जिससे IP Addresses का बेहतर उपयोग, Network Management और Network Performance को improve करने में सहायता मिलती है। प्रत्येक Subnet का अपना Network Address और Host Address Range होता है। Subnetting में Subnet Mask या CIDR Notation का उपयोग किया जाता है।
Example:
192.168.1.0/24 को छोटे Subnets में Divide करके अलग-अलग Networks बनाए जा सकते हैं।

Purpose of Subnetting

  • Network Divisionb: बड़े IP Network को छोटे-छोटे Subnets में Divide करना।
  • Efficient IP Usage: Available IP Addresses का बेहतर उपयोग करना।
  • Network Performance: Network Traffic को अलग-अलग Segments में बाँटकर Performance Improve करना।
  • Network Management: Network को Manage और Maintain करना आसान बनाना।
  • Security: अलग-अलग Network Segments बनाकर Security को Improve करना।
  • Troubleshooting: Network Problems को Identify और Troubleshoot करना आसान बनाना।

Subnet Mask and CIDR

Subnet Mask
Subnet Mask एक 32-Bit Address होता है, जिसका उपयोग IPv4 Network में Network Portion और Host Portion को Identify करने के लिए किया जाता है। यह निर्धारित करता है कि IP Address का कौन-सा भाग Network को और कौन-सा भाग Host Devices को Represent करता है।
Example: 255.255.255.0
CIDR (Classless Inter-Domain Routing):
CIDR एक IP Addressing Method है, जिसमें IP Address के साथ Prefix Length का उपयोग करके Network Portion को Represent किया जाता है। CIDR में / के बाद दी गई संख्या Network Bits को दर्शाती है।
Example: 192.168.1.0/24 - यहाँ /24 का अर्थ है कि पहले 24 Bits Network Portion के लिए हैं।

DHCP Server

DHCP (Dynamic Host Configuration Protocol) एक Network Protocol होता है, जिसका उपयोग Network से जुड़े Computers, Smartphones और अन्य Devices को Automatically IP Address तथा अन्य Network Configuration प्रदान करने के लिए किया जाता है। DHCP की सहायता से IP Address, Subnet Mask, Default Gateway और DNS Server जैसी जानकारी Automatically Assign की जाती है। इससे प्रत्येक Device में Network Settings को Manually Configure करने की आवश्यकता कम हो जाती है।

DHCP Process

Step-1: DHCP Discover
Client Network से Connect होने पर DHCP Server को खोजने के लिए DHCP Discover Message Broadcast करता है।

Step-2: DHCP Offer
DHCP Server Client को एक Available IP Address और अन्य Network Configuration जैसे Subnet Mask, Default Gateway और DNS Server Offer करता है।

Step-3: DHCP Request
Client प्राप्त Offers में से एक IP Address को Select करके DHCP Request Message भेजता है और उस IP Address को Request करता है।

Step-4: DHCP Acknowledge (ACK)
DHCP Server Client की Request को Confirm करके DHCP ACK Message भेजता है। इसके बाद Client को IP Address और Network Configuration प्राप्त हो जाती है और वह Network Communication कर सकता है।

Advantages of DHCP

  • Automatic IP Address Assignment:
    DHCP Network से जुड़े Computers, Smartphones और अन्य Devices को Automatically IP Address Assign करता है, जिससे Manual Configuration की आवश्यकता कम हो जाती है।
  • Reduces Manual Configuration:
    प्रत्येक Device में IP Address, Subnet Mask, Default Gateway और DNS Server जैसी Network Settings को Manually Enter करने की आवश्यकता नहीं होती।
  • Efficient IP Address Management:
    DHCP Available IP Address Pool को Efficiently Manage करता है और आवश्यकता के अनुसार Devices को IP Addresses Assign करता है।
  • Prevents IP Address Conflicts:
    DHCP प्रत्येक Device को उचित IP Address प्रदान करता है, जिससे एक ही IP Address कई Devices को मिलने से होने वाले IP Conflict की संभावना कम होती है।
  • Easy Network Management:
    Network Administrator के लिए बड़ी संख्या में Devices की Network Configuration को Centralized तरीके से Manage करना आसान हो जाता है।
  • Automatic Network Configuration:
    DHCP केवल IP Address ही नहीं, बल्कि Subnet Mask, Default Gateway और DNS Server जैसी आवश्यक Network Information भी Automatically Provide कर सकता है।
Security Point: Unauthorized या Rogue DHCP Services गलत Network Configuration प्रदान कर सकती हैं और Clients को अनचाहे Gateway या DNS Servers की ओर Redirect कर सकती हैं।

Ports

Port एक Logical Communication Endpoint होता है, जिसका उपयोग Network में किसी Device पर चल रही अलग-अलग Applications या Services की पहचान करने और उनके बीच Data Communication को Manage करने के लिए किया जाता है। प्रत्येक Network Service सामान्यतः एक Specific Port Number का उपयोग करती है, जिससे Data को सही Application या Service तक पहुँचाया जा सके। Port Numbers 0 से 65535 तक होते हैं।

Port Categories

  • Well-known ports(0-1023):
    इन Ports को सामान्यतः Standard और Common Network Services तथा Protocols के लिए Reserve किया जाता है।
    • Example: HTTP – 80, HTTPS – 443, FTP – 21, SSH – 22
  • Registered ports(1024-49151):
    इन Ports का उपयोग विभिन्न Applications और Services द्वारा किया जाता है। इन्हें Software Developers या Organizations द्वारा Register किया जा सकता है।
    • Example: MySQL – 3306, PostgreSQL – 5432
  • Dynamic/private ports(49152-65535):
    इन Ports का उपयोग सामान्यतः Temporary या Client-side Connections के लिए किया जाता है। इन्हें Applications आवश्यकता के अनुसार Dynamically Use कर सकती हैं।

DNS

DNS (Domain Name System) एक Network System होता है, जिसका उपयोग Domain Name को उसके संबंधित IP Address में Translate करने के लिए किया जाता है। इसके द्वारा Users को कठिन IP Addresses याद रखने के बजाय आसान Domain Names जैसे google.com या youtube.com का उपयोग करके Websites और Internet Services तक पहुँचने में सहायता मिलती है। DNS सामान्यतः Domain Name और IP Address के बीच Mapping को Maintain करता है और सही Server का IP Address Find करने में सहायता करता है।
Example: google.com → 142.250.x.x → Google Server

Why DNS is Required

DNS की आवश्यकता मुख्य रूप से निम्न कारणों से होती है:

  • Easy Website Access:
    DNS के द्वारा Users आसानी से Domain Name जैसे google.com का उपयोग करके Website Access कर सकते हैं।
  • IP Address को याद रखने की आवश्यकता कम:
    Users को अलग-अलग Websites के Numerical IP Addresses याद रखने की जरूरत नहीं होती।
  • Domain Name Resolution:
    DNS Domain Name को संबंधित IP Address में Resolve करता है, जिससे सही Server तक Request पहुँचती है।
  • Faster Access:
    DNS में Caching की सहायता से पहले से Resolve किए गए Domain Names का IP Address जल्दी प्राप्त किया जा सकता है।
  • Scalability:
    DNS बड़े Internet पर करोड़ों Domains और Servers को Manage करने में सहायता करता है।
  • Load Distribution:
    DNS का उपयोग एक Domain की Requests को अलग-अलग Servers या IP Addresses की ओर Direct करने के लिए भी किया जा सकता है।

Common DNS Records

DNS Records Purpose
A Record Domain Name को IPv4 Address से Map करता है।
AAAA Record Domain Name को IPv6 Address से Map करता है।
CNAME Record एक Domain Name को दूसरे Domain Name (Canonical Name) का Alias बनाता है।
MX Record Domain के लिए Mail Server को Specify करता है।
NS Record Domain के लिए Authoritative Name Server को Specify करता है।
TXT Record Domain से संबंधित Text Information और Verification/Security Data को Store करता है।
PTR Record IP Address को Domain Name में Resolve करता है। इसे Reverse DNS Lookup में उपयोग किया जाता है।
SOA Record Domain की Authoritative Information जैसे Primary Name Server और Zone-related details को Define करता है।

Proxy Servers

Proxy Server एक Intermediate Server होता है, जो Client और Internet या Destination Server के बीच Gateway की तरह कार्य करता है। जब कोई Client Internet पर Request भेजता है, तो यह Request पहले Proxy Server के पास जाती है और Proxy Server उस Request को Destination Server तक Forward करता है। इसी प्रकार Server से प्राप्त Response को Proxy Server वापस Client तक भेजता है।
Proxy Server का उपयोग Security, Privacy, Access Control, Content Filtering और Web Caching जैसे कार्यों के लिए किया जाता है।

Example:
Client → Proxy Server → Internet Server
Internet Server → Proxy Server → Client

Uses of Proxy Servers

  • Security: Proxy Server Client और Internet के बीच एक Intermediate Layer प्रदान करके Network Security को Improve करने में सहायता करता है।
  • Privacy: Proxy Server के माध्यम से Destination Server को Client का Direct IP Address दिखाई नहीं देता, जिससे कुछ हद तक Privacy बढ़ सकती है।
  • Access Control: Organizations में Proxy Server का उपयोग Users के Internet Access को Control और Manage करने के लिए किया जाता है।
  • Content Filtering: Proxy Server के द्वारा कुछ Websites, Content या Web Traffic को Block या Filter किया जा सकता है।
  • Web Caching: Frequently Access की जाने वाली Web Content को Cache में Store करके बाद की Requests को तेजी से Serve किया जा सकता है।
  • Monitoring: Organizations Proxy Server की सहायता से Internet Traffic और User Requests को Monitor और Log कर सकती हैं।
  • Bandwidth Management: Proxy Server के द्वारा Bandwidth Usage को Control और Optimize करने में सहायता मिल सकती है।
  • Accessing Restricted Resources: कुछ Network Environments में Proxy Server का उपयोग Restricted या Controlled Resources तक Access प्रदान करने के लिए किया जाता है।
Note: Proxy Policy Enforcement और Network Traffic की Visibility प्रदान कर सकता है, लेकिन इसकी Effectiveness सही Configuration और Handle किए जा रहे Traffic के Type पर निर्भर करती है।

Virtual Private Networks(VPN)

VPN (Virtual Private Network) एक Network Technology है, जो Internet जैसे Public Network के माध्यम से दो या अधिक Devices या Networks के बीच एक Secure और Encrypted Connection स्थापित करती है। VPN के द्वारा User का Data Traffic Encrypt किया जाता है और एक VPN Tunnel के माध्यम से भेजा जाता है, जिससे Data को Unauthorized Access से Protect करने में सहायता मिलती है।
VPN का उपयोग मुख्य रूप से Secure Remote Access, Privacy, Data Protection और Remote Networks को Connect करने के लिए किया जाता है।

Uses of VPN

  • Secure Remote Access: VPN के द्वारा Users किसी Organization के Private Network को Internet के माध्यम से Securely Access कर सकते हैं।
  • Data Encryption: VPN Data Traffic को Encrypt करता है, जिससे Data को Unauthorized Users द्वारा पढ़ना कठिन हो जाता है।
  • Privacy: VPN User और Internet के बीच एक Intermediate Connection प्रदान करता है, जिससे User का Original IP Address Destination Services से Hide हो सकता है।
  • Secure Public Wi-Fi: Public Wi-Fi जैसे Cafes, Airports और Hotels में VPN Data Communication को अधिक Secure बनाने में सहायता कर सकता है।
  • Remote Office Connectivity: VPN की सहायता से अलग-अलग Offices और Networks को Secure तरीके से Connect किया जा सकता है।
  • Protetion of Sensitive Data: VPN का उपयोग Login Credentials, Business Data और अन्य Sensitive Information को सुरक्षित तरीके से Transfer करने के लिए किया जा सकता है।
  • Bypass Network Restrictions: कुछ Organizations में VPN का उपयोग Authorized Users को Restricted Internal Resources तक Secure Access देने के लिए किया जाता है।

VPN Flow

Client / Network → VPN Tunnel → VPN Gateway → Protected Network / Internet

DNS Server

DNS Server (Domain Name System Server) एक ऐसा Server होता है, जो Domain Names को उनके संबंधित IP Addresses में Resolve करने का कार्य करता है। जब कोई User Browser में किसी Website का Domain Name जैसे google.com Enter करता है, तो DNS Server उस Domain Name का संबंधित IP Address Find करता है और Browser को प्रदान करता है। इसके बाद Browser उस IP Address की सहायता से संबंधित Web Server से Connection स्थापित करता है।


DNS Server का मुख्य उद्देश्य Domain Name Resolution करना और Users को आसान Domain Names के माध्यम से Internet Services Access करने में सहायता करना है।

Basic Resolution Process

User ↓ Domain Name (google.com) ↓ DNS Resolver ↓ DNS Server ↓ IP Address ↓ Web Server ↓ Website

1.User Request:
User Browser में Domain Name जैसे google.com Enter करता है।

2.DNS Query:
Device का DNS Resolver उस Domain Name के IP Address को Find करने के लिए DNS Query भेजता है।

3.DNS Server Search:
DNS Resolver आवश्यक DNS Servers से Information प्राप्त करता है और Domain का IP Address Find करता है।

4.IP Address Response:
DNS Server Domain Name के संबंधित IP Address को Resolver को Return करता है।

5.Connection to Server:
Browser प्राप्त IP Address का उपयोग करके संबंधित Web Server से Connection Establish करता है।

Security Considerations

  • DNS Spoofing:
    Attacker गलत DNS Response देकर User को Fake या Malicious Website पर Redirect कर सकता है।
  • DNS Cache Poisoning:
    DNS Cache में गलत IP Address Store करके Users को Unauthorized Websites की ओर Redirect किया जा सकता है।
  • DNSSEC:
    DNS Security Extensions (DNSSEC) DNS Responses की Authenticity और Integrity Verify करने में सहायता करता है।
  • Secure DNS Communication:
    DNS Queries को Protect करने के लिए DoH (DNS over HTTPS) और DoT (DNS over TLS) जैसी Technologies का उपयोग किया जा सकता है।
  • DNS Server Protection:
    DNS Servers को Unauthorized Access से Protect करने के लिए Access Control, Firewall और Regular Updates का उपयोग किया जाना चाहिए।
  • Monitoring and Logging:
    DNS Queries और Responses की Monitoring और Logging करके Suspicious या Malicious Activities को Identify करने में सहायता मिलती है।

OSI and TCP/IP Model

OSI Model

OSI (Open Systems Interconnection) Model एक Conceptual Networking Model है, जिसे ISO (International Organization for Standardization) द्वारा विकसित किया गया है। इसका उपयोग Network Communication की प्रक्रिया को 7 अलग-अलग Layers में Divide करके समझने के लिए किया जाता है। प्रत्येक Layer Network Communication में एक Specific Function perform करती है और अपने नीचे तथा ऊपर वाली Layer के साथ मिलकर काम करती है।

7 Layer of OSI Model

1. Application Layer
Application Layer OSI Model की 7th और सबसे ऊपर वाली Layer होती है। यह सीधे End User और Network Services के बीच Interface के रूप में कार्य करती है। इसका मुख्य उद्देश्य User Applications को Network Services प्रदान करना है, ताकि User Network के माध्यम से विभिन्न Services जैसे Web Browsing, Email, File Transfer और Remote Access का उपयोग कर सके।

Common Protocals:

  • HTTP / HTTPS – Web Browsing
  • FTP – File Transfer
  • SMTP – Email Sending
  • DNS – Domain Name Resolution
  • SSH – Secure Remote Access

2. Presentation Layer
Presentation Layer OSI Model की 6th Layer होती है, जिसका मुख्य कार्य Data को एक ऐसे Format में Convert करना है जिसे Receiving Device आसानी से Understand और Process कर सके। यह Layer Data Translation, Encryption/Decryption और Compression/Decompression जैसे कार्य करती है।

3. Session Layer
Session Layer OSI Model की 5th Layer होती है, जिसका मुख्य कार्य दो Devices या Applications के बीच Communication Session को Establish, Manage और Terminate करना होता है। यह Layer Communication के दौरान Session को Maintain और Synchronize करने में सहायता करती है, ताकि Data Exchange व्यवस्थित तरीके से हो सके।

4. Transport Layer
Transport Layer OSI Model की 4th Layer होती है, जिसका मुख्य कार्य दो Devices के बीच End-to-End Data Delivery सुनिश्चित करना होता है। यह बड़े Data को छोटे Segments में Divide करती है और Receiving Device पर उन्हें सही क्रम में Reassemble करने में सहायता करती है। यह Layer Error Control, Flow Control और Reliable Data Transmission जैसी Services प्रदान करती है।

5. Network Layer
Network Layer OSI Model की 3rd Layer होती है, जिसका मुख्य कार्य Data Packets को एक Network से दूसरे Network तक Source से Destination पहुँचाना होता है। यह Layer Logical Addressing (IP Address) और Routing का उपयोग करके Data के लिए उचित Path निर्धारित करती है।

6. Data Link Layer
Data Link Layer OSI Model की 2nd Layer होती है, जिसका मुख्य कार्य एक ही Network में Connected Devices के बीच Reliable Data Transfer प्रदान करना होता है। यह Network Layer से प्राप्त Packets को Frames में Convert करती है और MAC Address की सहायता से Data को सही Device तक पहुँचाने में सहायता करती है।

7. Physical Layer
Physical Layer OSI Model की 1st और सबसे नीचे वाली Layer होती है। इसका मुख्य कार्य Data को Bits (0 और 1) के रूप में Physical Medium के माध्यम से एक Device से दूसरे Device तक Transmit और Receive करना होता है। यह Layer Electrical, Optical या Radio Signals का उपयोग करके Data Communication करती है।

TCP/IP Model

TCP/IP (Transmission Control Protocol/Internet Protocol) Model एक Networking Model है, जिसका उपयोग Network और Internet पर Data Communication को समझने और Implement करने के लिए किया जाता है। इसमें Network Communication की पूरी प्रक्रिया को 4 Layers में Divide किया गया है। प्रत्येक Layer Network Communication में अलग-अलग Functions perform करती है और Protocols का उपयोग करके Data को Source से Destination तक पहुँचाने में सहायता करती है।

4 Layers of TCP/IP Model

Layer Function Example
4. Application User Applications को Network Services प्रदान करना। HTTP, HTTPS, DNS, FTP, SMTP
3. Transport End-to-End Communication, Reliability, Flow Control और Error Control। TCP, UDP
2. Internet IP Addressing और Routing के द्वारा Packets को Destination तक पहुँचाना। IPv4, IPv6, ICMP
1. Network Access Data को Physical Network Medium पर Frames/Signals के रूप में Transfer करना। Ethernet, Wi-Fi, ARP

OSI vs TCP/IP

OSI TCP/IP
OSI का Full Form Open Systems Interconnection है। TCP/IP का Full Form Transmission Control Protocol/Internet Protocol है।
इसे ISO द्वारा Develop किया गया है। इसे ARPA/DARPA के Internet Architecture के रूप में Develop किया गया।
इसमें 7 Layers होती हैं। इसमें सामान्यतः 4 Layers होती हैं।
OSI एक Reference/Conceptual Model है। TCP/IP एक Protocol Suite और Practical Networking Model है।
इसमें Session और Presentation की अलग-अलग Layers होती हैं। TCP/IP में Session और Presentation Functions को Application Layer में शामिल किया जाता है।
इसमें Data Link और Physical की अलग-अलग Layers होती हैं। TCP/IP में दोनों को सामान्यतः Network Access Layer में Combine किया जाता है।
OSI Model मुख्य रूप से Networking Concepts को समझाने और Standardization के लिए उपयोगी है। TCP/IP Model का उपयोग Internet और Real-World Networks में व्यापक रूप से किया जाता है।
OSI Model में Protocols को Model से अलग समझा जाता है। TCP/IP Model अपने नाम के अनुसार TCP, IP और अन्य Protocols के साथ closely associated है।

12. TCP vs. UDP

TCP और UDP दोनों Transport Layer Protocols हैं, लेकिन दोनों की Communication Characteristics अलग-अलग होती हैं।

Feature TCP UDP
Connection Connection-oriented Connectionless
Reliability Provides reliable delivery mechanisms No built-in guarantee of delivery
Ordering Maintains ordered byte-stream delivery No delivery-order guarantee
Overhead Higher Lower
Typical use Web, file transfer, reliable application communication DNS queries, streaming and latency-sensitive applications depending on design
Exam Point: TCP emphasizes reliable, ordered communication; UDP emphasizes a simpler datagram service with lower protocol overhead.

13. Routers

Definition

Router एक Layer 3 Networking Device होता है, जो अलग-अलग IP Networks के बीच Packets को forward करता है। यह Routing Information का उपयोग करके appropriate next hop या interface select करता है।

Functions

  • Connects different networks.
  • Forwards IP packets.
  • Maintains or uses routing information.
  • Can provide services such as NAT, depending on the device.
  • Can participate in network segmentation and security policy enforcement when supported.

14. Switches

Definition

Network Switch सामान्यतः एक Layer 2 Device होता है, जो MAC Address Information का उपयोग करके Ethernet Frames को forward करता है। Managed Switch में VLAN Configuration और Monitoring जैसी additional facilities भी हो सकती हैं।

Functions

  • Connects devices within a local network.
  • Learns MAC addresses and builds a forwarding table.
  • Forwards frames to appropriate ports.
  • Supports segmentation features such as VLANs on managed models.

15. Endpoint Solutions

Definition

Endpoint वह Device होता है जो Network में participate करता है, जैसे Desktop Computer, Laptop या Server। Endpoint Security Solutions इन Devices को Malware, Unauthorized Activity और अन्य Security Threats से protect करने के लिए उपयोग किए जाते हैं।

Common Endpoint Security Controls

  • Anti-malware and endpoint protection.
  • Host-based firewall.
  • Application control.
  • Patch and update management.
  • Device and access control.
  • Security monitoring and logging.
Security Principle: Network security is stronger when both network-level controls and endpoint-level controls are used together.

16. Access Directory

Directory Services Users, Computers, Groups और अन्य Network Resources की information को centrally store और manage करने का तरीका provide करती हैं। Enterprise Environment में Directory-based Access Management का उपयोग Users को authenticate करने और authorization policies apply करने के लिए किया जा सकता है।

Access Management

  • Authentication: Verifies who a user or device is.
  • Authorization: Determines what an authenticated identity is allowed to do.
  • Account management: Maintains user and group information.
  • Policy enforcement: Applies organizational security rules.

17. TOR Network

Definition

Tor (The Onion Router) एक Network है जिसे multiple relays के through Traffic route करके privacy improve करने के लिए design किया गया है। इसका design किसी single point के लिए User Activity को final destination से directly link करना अधिक difficult बनाता है।

Basic Concept

User → Tor Entry Relay → Intermediate Relay(s) → Exit Relay → Destination

Security and Privacy Considerations

Tor can be used for legitimate privacy and research purposes, but the anonymity properties can also be abused. Organizations may therefore monitor and manage Tor-related traffic according to their security policies.

18. Networking Devices (Layer 1, 2, 3)

Layer Common Device Primary Role
Layer 1 – Physical Hub, repeater, cables/media Transmission of physical signals/bits
Layer 2 – Data Link Switch, bridge Frame forwarding using link-layer information
Layer 3 – Network Router Packet forwarding between IP networks

Importance in Security

Understanding the layer at which a device primarily operates helps in selecting appropriate security controls. For example, MAC-based controls are associated with Layer 2 while IP routing and many network-layer policies operate at Layer 3.

19. Different Types of Network Layer Attacks

Introduction

Network Attacks Communication, Addressing, Routing, Services या Network Devices की weaknesses का misuse करने का प्रयास करते हैं। ऐसे attacks Confidentiality, Integrity या Availability को target कर सकते हैं।

Common Attack Categories

  • DoS/DDoS: Attempts to make a service or network resource unavailable by overwhelming it or exhausting resources.
  • IP spoofing: Uses a forged source IP address in network traffic.
  • ARP spoofing/poisoning: Manipulates ARP information in local IPv4 networks to associate an attacker's MAC address with another IP address.
  • DNS attacks: Can include manipulation, abuse or disruption of name resolution.
  • Scanning: Attempts to identify reachable hosts, services or ports.
  • Man-in-the-middle attacks: An attacker attempts to position themselves between communicating parties to observe or manipulate traffic.
  • Routing attacks: Attempt to manipulate or disrupt routing information or forwarding behavior.
Protection: Segmentation, access controls, secure protocols, monitoring, firewalls and IDS/IPS can help reduce the risk or impact of network attacks.

20. Firewall

Definition

Firewall एक security control होता है, जो defined Rules या Policies के अनुसार Network Traffic को monitor और control करता है। इसे Hardware, Software या दोनों के combination के रूप में implement किया जा सकता है।

Basic Working

Incoming / Outgoing Traffic → Firewall Policy Check → Allow / Deny / Log → Destination

Functions

  • Controls inbound and outbound traffic.
  • Enforces access-control rules.
  • Restricts unwanted services or connections.
  • Can provide logging and alerts.
  • Can separate trusted and untrusted network zones.

21. ACL

Definition

ACL (Access Control List) Rules का एक collection होता है, जो यह specify करता है कि कौन-सा Traffic या Access permit किया जाएगा और कौन-सा deny किया जाएगा। ACL का उपयोग Routers, Switches, Firewalls और अन्य Network Security Systems पर किया जा सकता है।

Common Matching Criteria

  • Source IP address.
  • Destination IP address.
  • Protocol.
  • Source or destination port.
  • Direction or interface, depending on the device.
Exam Point: ACLs implement policy through ordered rules. A correct rule order and a clear default behavior are important for predictable results.

22. Packet Filtering

Packet Filtering एक Firewall या Security Mechanism होता है जिसमें Packets को defined criteria के आधार पर examine किया जाता है और फिर उन्हें permit या deny किया जाता है। इसके लिए Source Address, Destination Address, Protocol और Ports जैसे criteria उपयोग किए जाते हैं।

Advantages

  • Simple and comparatively fast.
  • Useful for controlling known network services.
  • Can reduce unwanted traffic before it reaches protected systems.

Limitations

  • Basic filtering has limited awareness of application context.
  • Complex rule sets can become difficult to manage.
  • It should be combined with other security controls where appropriate.

23. DMZ

Definition

DMZ (Demilitarized Zone) एक Network Segment होता है, जिसे Publicly Reachable Services को Organization के Internal Network से isolate करने के लिए बनाया जाता है। Web Servers जैसी Public-facing Systems को DMZ में रखा जा सकता है, जिससे Internal Network का direct exposure कम करने में सहायता मिलती है।

Basic Architecture

Internet → Firewall → DMZ (Public Services) → Internal Firewall/Policy → Internal Network

Benefits

  • Provides network segmentation.
  • Limits direct exposure of internal systems.
  • Allows security policies to differ between public services and internal resources.

24. Alerts and Audit Trails

Alerts

Alert एक notification होता है, जो तब generate होता है जब Security Device या Monitoring System किसी ऐसे event को detect करता है जो configured condition या threat indicator से match करता है। Alerts के द्वारा Administrator को important security events की जानकारी प्राप्त होती है।

Audit Trails

Audit Trail Security-related Activities का record होता है, जैसे Authentication Attempts, Configuration Changes, Access Events और Network Events। Logs को Troubleshooting, Monitoring और Incident Investigation के समय review किया जा सकता है।

Importance

  • Helps identify suspicious activity.
  • Supports incident investigation.
  • Assists troubleshooting.
  • Provides accountability and historical records.
  • Supports security monitoring and compliance requirements where applicable.

25. IDS, IPS and Its Types & Setup

IDS – Intrusion Detection System

IDS (Intrusion Detection System) Network या System Activity को monitor करता है और जब known malicious patterns, abnormal behavior या configured policies से match करने वाली activity detect होती है, तब Alert generate करता है। IDS मुख्य रूप से Detection और Alerting का काम करता है।

IPS – Intrusion Prevention System

IPS (Intrusion Prevention System) Detection के साथ preventive action भी perform करता है। Configuration और Security Policy के अनुसार यह suspicious Traffic को block या drop कर सकता है।

Feature IDS IPS
Primary purpose Detect and alert Detect and prevent
Typical action Generate alerts/logs Block, drop or otherwise prevent according to policy
Deployment consideration Can monitor traffic without being inline Often deployed inline for prevention

Types of IDS/IPS Detection

1. Signature-Based

Signature-based detection compares observed activity with known patterns or signatures of previously identified threats. It can be effective for known threats but may not detect new attacks for which no suitable signature exists.

2. Anomaly-Based

Anomaly-based detection identifies activity that deviates from an established or expected baseline. It can help identify previously unknown behavior, but unusual legitimate activity may also generate false positives.

3. Policy-Based

Policy-based detection checks activity against explicitly defined organizational security policies. It can identify violations of configured rules and acceptable-use requirements.

4. Honeypot-Based

A honeypot is a deliberately controlled system or resource designed to attract or observe unauthorized activity. Honeypot-based security monitoring can provide information about attack techniques and suspicious behavior without exposing ordinary production resources.

Basic IDS/IPS Setup

Network Traffic ↓ Traffic Capture / Monitoring Point ↓ IDS/IPS Detection Engine ↓ Signature / Anomaly / Policy Analysis ↓ Alert + Log ↓ IPS Policy Action (when enabled) ↓ Security Administrator / Monitoring System

General Setup Steps

  1. Identify the network segment and assets that need monitoring.
  2. Choose an appropriate IDS/IPS deployment point.
  3. Configure network interfaces and management access securely.
  4. Define detection signatures, policies and relevant thresholds.
  5. Configure alerting and logging.
  6. Test detection using authorized and controlled test traffic.
  7. Review alerts and tune rules to reduce unnecessary false positives.
  8. Maintain signatures, software and security policies.
Important: IDS/IPS configuration should be tested carefully. Incorrect rules may generate excessive alerts or, in the case of prevention controls, block legitimate traffic.

Conclusion

Network security depends on both strong networking fundamentals and appropriate security controls. Understanding IP addressing, subnetting, DNS, ports, routers and switches helps a student understand how network communication takes place. Firewalls, ACLs, DMZs, endpoint controls, logging, IDS and IPS then provide mechanisms for controlling, monitoring, detecting and responding to suspicious network activity.
