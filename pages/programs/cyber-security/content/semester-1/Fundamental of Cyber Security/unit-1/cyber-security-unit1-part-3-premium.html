Cloud

Cloud internet के माध्यम से storage, servers, databases और software provide करता है। Security concerns में privacy, access control और misconfiguration शामिल हैं।

Software

Software programs और instructions का collection है। Trusted installation, updates और secure configuration जरूरी हैं।

Domain

Domain website का human-readable address है। Domain ownership, DNS security और phishing prevention important हैं।
