Cyber Security Unit-1 - Part 4

Viruses, worms, Trojan, bombs, trapdoors, spoofing, e-mail/macro viruses, malicious software और network/DoS attacks.

Virus

Virus file या program से attach होकर execute होने पर spread करता है।

Worm

Worm self-replicating malware है जो network के through independently spread कर सकता है।

Trojan Horse

Trojan useful software जैसा दिखता है लेकिन malicious function perform करता है।

Logic Bomb

Logic bomb specific date या condition पूरी होने पर activate होता है।

Trapdoor / Backdoor

Trapdoor normal authentication bypass करने वाला hidden access path है।

Spoofing

Spoofing trusted identity, address या source को fake दिखाने की technique है।

  • Email spoofing
  • IP spoofing
  • Website spoofing
  • DNS spoofing

E-mail Viruses

E-mail viruses malicious attachments या links से spread होते हैं। Sender verify करें और unknown attachment न खोलें।

Macro Viruses

Macro viruses documents और spreadsheets में embedded macros का misuse करते हैं।

Safety: Unknown document में macros enable न करें।

Malicious Software

Malicious software में virus, worm, Trojan, ransomware, spyware, rootkit, adware और bots शामिल हैं।

Protection Measures

  • Regular updates
  • Strong passwords and MFA
  • Firewall and anti-malware
  • Backups
  • Phishing awareness
  • Least privilege
  • Monitoring
Remember: Prevention, detection, response और recovery चारों जरूरी हैं।
