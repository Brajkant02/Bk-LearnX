System Hacking Concepts

Gaining Access

Gaining Access वह stage है जहाँ attacker किसी weakness, stolen credential या misconfiguration का misuse करके system में entry प्राप्त करने की कोशिश करता है।

Common Causes

  • Weak passwords
  • Default credentials
  • Unpatched software
  • Phishing
  • Misconfigured services
  • Excessive permissions

Defensive Measures

  • MFA enable करें।
  • Strong password policy use करें।
  • Unused services disable करें।
  • Regular patching करें।
  • Login attempts monitor करें।

Password Cracking Concepts

Password Cracking passwords को guess, recover या break करने की attempt है। Security study में इसका उद्देश्य weak password practices के risks समझना है।

ConceptMeaning
Brute ForceMany possible combinations try करना
Dictionary AttackCommon words/password lists try करना
Credential StuffingLeaked credentials reuse करना
Password SprayingFew common passwords many accounts पर try करना

Protection

  • Long passphrases
  • MFA
  • Account lockout/rate limiting
  • Password hashing
  • Unique passwords

Vulnerability Exploitation

Vulnerability system, software या configuration की weakness है। Exploitation उस weakness का misuse है।

Examples of Weaknesses

  • Outdated software
  • Weak input validation
  • Insecure permissions
  • Open unnecessary ports
  • Default configuration

Defensive Cycle

  1. Assets identify करें।
  2. Vulnerability scan करें।
  3. Risk prioritize करें।
  4. Patch या mitigate करें।
  5. Retest करें।

Escalating Privileges

Privilege Escalation low-level access से higher permissions प्राप्त करने की unauthorized attempt है।

TypeMeaning
Vertical EscalationUser से administrator-level access
Horizontal EscalationSame-level दूसरे user के data/access तक पहुँचना

Protection

  • Least privilege principle
  • Role-based access control
  • Patch management
  • Privilege review
  • Administrative account separation

Hiding Files and Concealment

Attackers unauthorized files, tools या data को hidden locations, misleading names या altered attributes के माध्यम से conceal कर सकते हैं। Defensive security में hidden files और unusual changes detect करना important है।

Detection Measures

  • File integrity monitoring
  • Hidden file review
  • Endpoint detection tools
  • Unusual process monitoring
  • Known-good baseline comparison

Clearing or Tampering with Logs

Security logs user activity, login attempts, system events और errors record करते हैं। Attackers traces hide करने के लिए logs delete या alter करने की कोशिश कर सकते हैं।

Protection

  • Centralized logging
  • Remote log storage
  • Write-protected audit logs
  • Regular log backup
  • Alerting on log deletion
  • Time synchronization
Remember:
Logs incident investigation के लिए critical evidence होते हैं।

Application Security Practices

  • Secure coding standards
  • Input validation
  • Authentication and session security
  • Error handling without sensitive disclosure
  • Dependency updates
  • Code review
  • Security testing
  • Secrets को source code में store न करना
