Backups

Backup important data की duplicate copy है जो data loss, hardware failure, malware या accidental deletion के बाद recovery में help करती है।

Image Placeholder: Backup and Recovery Strategy

Backup Types

TypeMeaning
Full BackupComplete data copy
Incremental BackupLast backup के बाद changes
Differential BackupLast full backup के बाद changes

3-2-1 Rule

  • 3 copies of data
  • 2 different storage media
  • 1 copy offsite/offline

Archival Storage

Archival Storage old but important data को long-term retention के लिए सुरक्षित रखना है। Archived data daily use में नहीं होता, लेकिन legal, historical या business requirement के कारण preserve किया जाता है।

Considerations

  • Retention period
  • Encryption
  • Access control
  • Format compatibility
  • Integrity checks
  • Geographical redundancy

Secure Disposal of Data

Data disposal का उद्देश्य expired या unnecessary data को इस प्रकार remove करना है कि उसे recover न किया जा सके।

Methods

  • Secure deletion
  • Cryptographic erasure
  • Disk wiping
  • Physical destruction
  • Paper shredding
Common Mistake:
Normal delete command अक्सर data को permanently erase नहीं करती।

Access Control Security

Access Control यह तय करता है कि कौन user किस resource पर कौन-सा action perform कर सकता है।

Basic Process

Identification
     ↓
Authentication
     ↓
Authorization
     ↓
Accounting / Auditing

Access Control Models

ModelMeaning
DACOwner permissions control करता है
MACCentral policy और classification-based control
RBACRole के आधार पर permissions
ABACAttributes और conditions के आधार पर access

Least Privilege and Account Security

  • User को minimum required permissions दें।
  • Shared accounts avoid करें।
  • MFA use करें।
  • Inactive accounts disable करें।
  • Privileged accounts monitor करें।
  • Access reviews regularly करें।
  • Strong password policy लागू करें।
Remember:
Access control का उद्देश्य सही user को सही resource पर सही समय पर सही permission देना है।
