NetBIOS Enumeration

NetBIOS legacy Windows networking में naming और resource-sharing services से संबंधित technology है। Misconfigured environments में system names, workgroups या shared resources जैसी information expose हो सकती है।

Image Placeholder: NetBIOS Name and Share Exposure

Security Risks

  • System names exposure
  • Workgroup/domain information disclosure
  • Shared resource visibility
  • Legacy protocol risk

NetBIOS Security Countermeasures

  • NetBIOS को जहाँ required न हो disable करें।
  • File sharing को trusted networks तक restrict करें।
  • Firewall पर legacy ports block/restrict करें।
  • Strong authentication use करें।
  • Anonymous access disable करें।
  • Shared folders और permissions audit करें।

Directory and Account Exposure

Usernames, groups और directory structures का exposure password attacks और social engineering risk बढ़ा सकता है।

Protection

  • Generic error messages use करें।
  • Account discovery prevent करें।
  • Inactive accounts disable करें।
  • MFA लागू करें।
  • Directory permissions review करें।

Enumeration Detection and Logging

Useful Monitoring

  • Repeated account queries

  • Legacy protocol traffic
  • Unexpected directory queries

Centralized logs और alerting suspicious enumeration behavior detect करने में help करते हैं।

Legal and Ethical Considerations

  • Written authorization लें।
  • Defined scope follow करें।
  • Production disruption avoid करें।
  • Sensitive data securely handle करें।
  • Findings responsible तरीके से report करें।
  • Evidence और logs preserve करें।

Unit-5 Security Checklist

  • Public footprint reviewed
  • Employee oversharing awareness provided
  • DNS and domain records audited
  • External assets inventoried
  • Unnecessary services disabled
  • Network diagram updated
  • Legacy protocols restricted
  • Shared resources reviewed
  • Logs centralized
  • Authorized retesting completed
