Scanning Concept

Scanning authorized security assessment में systems, hosts, services और network characteristics identify करने की process है। इसका purpose security exposure understand करना और vulnerabilities reduce करना है।

Host Discovery

Host discovery का उद्देश्य authorized network में active systems identify करना है। Security teams asset inventory और monitoring coverage verify करने के लिए इसका use करती हैं।

Defensive Benefits

  • Unknown devices identify करना
  • Inactive assets remove करना
  • Monitoring coverage improve करना
  • Network segmentation verify करना

Service Discovery

Service discovery से यह समझा जाता है कि authorized systems पर कौन-सी network services available हैं।

Security Review Points

  • Unnecessary services बंद हैं या नहीं
  • Default ports/services exposed हैं या नहीं
  • Service versions supported हैं या नहीं
  • Access restrictions configured हैं या नहीं

Operating System Discovery

OS discovery का उद्देश्य network behavior और system responses के आधार पर operating system family का अनुमान लगाना है। Defensive teams इससे outdated platforms और patching requirements identify करती हैं।

Security Use:
Unsupported operating systems को identify करके upgrade plan बनाना चाहिए।

Scanning beyond IDS and Firewall - Defensive View

Attackers detection avoid करने की कोशिश कर सकते हैं। इसलिए defenders को केवल firewall पर depend नहीं करना चाहिए। Layered monitoring और behavioral analysis जरूरी है।

Defensive Controls

  • IDS/IPS tuning
  • Rate-limit and anomaly detection
  • Centralized logs
  • Endpoint detection
  • Network segmentation
  • Regular authorized assessments
Important:
Detection bypass techniques का प्रयोग unauthorized systems पर करना illegal और unsafe है।
