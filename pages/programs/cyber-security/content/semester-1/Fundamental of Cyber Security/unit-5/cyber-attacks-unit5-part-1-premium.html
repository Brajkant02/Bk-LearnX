General Procedure Adopted for Cyber Attacks

Cyber attacks को समझने के लिए security professionals attacker के सामान्य stages का अध्ययन करते हैं। इनमें reconnaissance, scanning, enumeration, exploitation, privilege escalation और evidence concealment जैसे phases शामिल हो सकते हैं।

Reconnaissance

Reconnaissance target organization, people, systems और public digital footprint के बारे में information collect करने की initial stage है।

Types

TypeMeaning
Passive ReconnaissancePublic sources से information collect करना, target systems से direct interaction नहीं।
Active ReconnaissanceAuthorized environment में target infrastructure से limited interaction करके details verify करना।

Footprinting Concepts and Methodology

Footprinting organization की internet presence, domains, public documents, technologies, employees और exposed services का high-level profile तैयार करने की process है।

Methodology

  1. Scope और authorization define करें।
  2. Public sources identify करें।
  3. Organization-related information collect करें।
  4. Information validate और classify करें।
  5. Security exposure assess करें।
  6. Countermeasures recommend करें।

Footprinting using Search Engines

Search engines public web pages, indexed files, news, cached content और exposed references identify करने में useful होते हैं। Defensive audit में organization यह verify करती है कि sensitive information accidentally public तो नहीं है।

Defensive Checks

  • Publicly indexed documents review करना
  • Old or duplicate pages identify करना
  • Sensitive contact details exposure देखना
  • Search results में fake brand pages identify करना

Footprinting using Web Services

Public web services और internet databases domain reputation, certificate transparency, website technologies और public metadata जैसी information provide कर सकते हैं।

Security Value

  • External attack surface understanding
  • Expired certificates identify करना
  • Unknown public subdomains review करना
  • Brand impersonation detect करना

Social Networking Sites

Social networking sites पर employees, job roles, technologies, office locations और business activities से संबंधित information मिल सकती है। Attackers इसे social engineering के लिए misuse कर सकते हैं।

Countermeasures

  • Employees को oversharing awareness दें।
  • Public profile privacy review करें।
  • Internal projects publicly disclose न करें।
  • Unknown connection requests verify करें।

Website Footprinting

Website footprinting में public pages, contact forms, technology indicators, privacy policies, subdomains और exposed metadata का defensive review किया जाता है।

Website Owner Checklist

  • Sensitive comments हटाएं।
  • Default pages disable करें।
  • Directory listing बंद रखें।
  • Security headers configure करें।
  • Old files remove करें।

Email Footprinting

Email addresses, public contact patterns और exposed email formats attackers को phishing campaigns तैयार करने में help कर सकते हैं।

Protection

  • Public contact forms use करें।
  • Email addresses unnecessary pages पर publish न करें।
  • Spam filtering और MFA use करें।
  • Phishing simulations और awareness training conduct करें।

WHOIS Footprinting

WHOIS-style domain registration records domain ownership, registrar और administrative metadata के बारे में public information दे सकते हैं। Privacy protection और accurate records security तथा compliance के लिए important हैं।

DNS Footprinting

DNS domain names को IP addresses और services से map करता है। Defensive review में organization अपने public DNS records की accuracy और unnecessary exposure check करती है।

Image Placeholder: Domain Name to DNS Records

Countermeasures

  • Unused DNS records remove करें।
  • Zone transfer restrict करें।
  • DNS changes monitor करें।
  • DNSSEC जहाँ suitable हो use करें।

Network Footprinting

Network footprinting का उद्देश्य authorized scope में internet-facing network ranges, gateways और publicly exposed infrastructure को map करना है।

Defensive Purpose

  • Unknown assets identify करना
  • Public exposure verify करना
  • Asset inventory update करना
  • Security monitoring improve करना

Footprinting by Social Engineering

Social engineering में attacker human trust, urgency या authority का misuse करके information प्राप्त करने की कोशिश करता है।

Common Warning Signs

  • Urgent confidential request
  • Password या OTP मांगना
  • Unknown caller claiming authority
  • Unexpected attachment or link
  • Policy bypass request
Remember:
Information security में human verification process technical controls जितना ही important है।

  • Public information exposure minimize करें।
  • Employee security awareness बढ़ाएं।
  • Domain और certificate monitoring करें।
  • Search engine indexing review करें।
  • DNS records और subdomains audit करें।
  • External attack surface inventory maintain करें।
  • Fake social accounts और phishing domains monitor करें।
