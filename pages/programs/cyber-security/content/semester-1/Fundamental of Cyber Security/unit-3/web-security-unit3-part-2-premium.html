Overview of N-Tier Web Applications

N-Tier Architecture application को multiple logical layers में divide करती है। Commonly presentation, application/business और data tiers होते हैं।

Image Placeholder: Presentation, Business and Data Tiers

TierPurpose

Security Benefit

Layers separate होने से access control, monitoring और security policies better लागू की जा सकती हैं।

HTTP browser और web server के बीच communication protocol है। यह request-response model पर काम करता है।

Client Request → Web Server
Web Server Response → Client

Common Methods

  • POST

HTTPS

Reading HTML Source

HTML source page की structure, links, forms, scripts और metadata दिखाता है। Security study में source inspection से exposed comments, hidden fields, insecure references और client-side logic identify की जा सकती है।

Image Placeholder: Browser View Source

Security Considerations

  • Secrets source code में न रखें।
  • Comments में sensitive information avoid करें।
  • Client-side checks पर depend न करें।
  • Hidden fields को trusted data न मानें।
