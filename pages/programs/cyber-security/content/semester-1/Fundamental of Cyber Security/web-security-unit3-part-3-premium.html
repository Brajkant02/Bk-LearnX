Applet Security

Applet browser या applet viewer में run होने वाला Java program था। Traditional applets sandbox restrictions के अंदर execute होते थे ताकि local system resources पर direct access limited रहे।

Image Placeholder: Applet Sandbox Model

Security Restrictions

  • Local files पर restricted access
  • System commands पर restrictions
  • Limited network access
  • Signed applets के लिए additional trust
Historical Note:
Java applets modern browsers में practically obsolete हैं, लेकिन syllabus में sandbox security concept समझने के लिए important हैं।

Servlet Security

Servlet server-side Java component है जो web requests process करता है। Servlet security authentication, authorization, session management और input handling पर depend करती है।

Security Practices

  • Input validation
  • Parameterized database queries
  • Secure session cookies
  • Role-based access
  • HTTPS use
  • Error details hide करना
  • File upload validation

Session and Cookie Security

Secure Cookie Attributes

  • Secure
  • HttpOnly
  • SameSite
  • Short expiry

Session Practices

  • Login के बाद session ID rotate करें।
  • Logout पर session invalidate करें।
  • Inactive sessions expire करें।
  • Session ID URL में expose न करें।

Symmetric Encryption

Symmetric Encryption में encryption और decryption के लिए same secret key use होती है।

Image Placeholder: Same Key Encryption and Decryption

Advantages

  • Fast
  • Large data के लिए efficient
  • Lower computational cost

Limitation

Secret key securely share करना difficult हो सकता है।

Asymmetric Encryption

Asymmetric Encryption public key और private key pair use करती है।

Hybrid Encryption in HTTPS

HTTPS typically hybrid approach use करती है: asymmetric cryptography secure key exchange/authentication के लिए और symmetric encryption actual session data के लिए।

Web Security Checklist

  • Security testing performed
