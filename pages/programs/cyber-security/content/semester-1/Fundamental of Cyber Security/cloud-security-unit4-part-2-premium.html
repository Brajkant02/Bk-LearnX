Infrastructure as a Service (IaaS)

IaaS virtual servers, storage, network और computing infrastructure service के रूप में provide करता है। User operating system और applications manage करता है, जबकि provider physical hardware manage करता है।

Image Placeholder: IaaS Responsibility Model

Uses

  • Virtual machines
  • Storage
  • Backup systems
  • Development environments
  • Disaster recovery

Platform as a Service (PaaS)

PaaS application development और deployment के लिए runtime, frameworks, databases और development tools provide करता है।

Advantages

  • Fast development
  • Infrastructure management कम
  • Built-in scalability
  • Development tools available

Software as a Service (SaaS)

SaaS complete software application internet के माध्यम से provide करता है। User browser या app से software use करता है।

Examples of Use

  • Email
  • CRM
  • Online office tools
  • Learning management systems
  • Project management tools

IaaS vs PaaS vs SaaS

BasisIaaSPaaSSaaS
User ControlsOS, apps, dataApps and dataMostly usage/configuration
Provider ControlsHardware and virtualizationInfrastructure and platformComplete stack
Best ForIT infrastructureDevelopersEnd users

Virtualization and Virtual Machines

Virtualization single physical machine पर multiple virtual machines create करने की technology है। प्रत्येक VM अपना operating system और applications चला सकती है।

Image Placeholder: Physical Host and Multiple VMs

Components

  • Host machine
  • Hypervisor
  • Guest operating systems
  • Virtual CPU, memory and storage

Virtual Machine Provisioning

VM Provisioning new virtual machine को create, configure और resources assign करने की process है।

Steps

  1. VM template select करें।
  2. CPU, RAM और storage assign करें।
  3. Network configure करें।
  4. Operating system deploy करें।
  5. Security policies apply करें।
  6. Monitoring enable करें।

Virtual Machine Migration Services

VM Migration virtual machine को one host से another host पर move करने की process है।

TypeMeaning
Cold MigrationVM shutdown करके move करना
Live MigrationRunning VM को minimal interruption के साथ move करना
Storage MigrationVM disk files को new storage पर move करना

Benefits

  • Load balancing
  • Hardware maintenance
  • Fault avoidance
  • Resource optimization
