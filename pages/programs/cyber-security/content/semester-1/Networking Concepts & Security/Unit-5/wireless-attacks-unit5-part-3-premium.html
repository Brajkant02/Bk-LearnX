Attacks on WEP - Defensive Overview

WEP weak encryption design, short initialization vectors और outdated key handling के कारण insecure माना जाता है।

Countermeasure

WEP को पूरी तरह disable करके WPA2 या WPA3 use करें।

Attacks on WPA - Defensive Overview

WPA ने WEP से security improve की, लेकिन legacy configurations और weak passwords risk बन सकते हैं।

Protection

  • Strong passphrase
  • Modern hardware
  • WPA2/WPA3 migration
  • WPS disable

Attacks on WPA2 - Defensive Overview

WPA2 strong है, लेकिन weak passwords, outdated firmware, poor enterprise configuration और protocol implementation issues risk create कर सकते हैं।

Protection

  • Strong unique passwords
  • AES-based configuration
  • Firmware updates
  • Enterprise authentication
  • Management-frame protection

Bluetooth Security

Bluetooth short-range communication technology है। Threats में unauthorized pairing, tracking, data exposure और weak legacy modes शामिल हो सकते हैं।

Fluxion Framework - Defensive Overview

Fluxion wireless social-engineering attacks से जुड़ा framework माना जाता है। Course perspective में इसका उद्देश्य fake access point, credential phishing और user-awareness risks समझना है।

Not Included: Credential capture, fake portal setup या attack execution instructions नहीं दिए गए हैं।

Detection of Wireless Attacks

  • Duplicate SSID alerts
  • Unexpected deauthentication spikes
  • Rogue access point detection
  • New MAC address monitoring
  • Channel and signal anomalies
  • Authentication failure trends
