Packet Sniffing

Wireless packet sniffing radio traffic capture और analysis की process है। Administrators इसका use troubleshooting और security monitoring के लिए करते हैं।

Protection

  • Strong encryption
  • VPN on untrusted Wi-Fi
  • HTTPS
  • Wireless IDS

ARP Replay Attack - Concept

ARP replay attacks historically weak wireless encryption environments में repeated traffic का misuse करके security weaknesses exploit करने से जुड़ी रही हैं।

Not Included: Attack execution steps intentionally नहीं दिए गए हैं।

Protection

  • WEP हटाएं
  • WPA2/WPA3 use करें
  • Network monitoring
  • Client isolation

Fake Authentication Attack

Fake authentication में unauthorized client legitimate device की तरह associate होने की कोशिश करता है।

Protection

  • Enterprise authentication
  • Certificate-based access
  • 802.1X
  • Wireless IDS/IPS

Deauthentication Attack

Deauthentication attack clients को access point से disconnect करने की कोशिश करता है।

Protection

  • Protected Management Frames
  • WPA3
  • Wireless intrusion detection
  • Signal anomaly monitoring

Fake Hotspots

Fake hotspot legitimate public Wi-Fi जैसा दिखाई देता है और users को connect करने के लिए trick करता है।

Protection

  • Network name verify करें
  • Auto-connect disable करें
  • VPN use करें
  • Sensitive logins avoid करें
  • HTTPS certificate warnings ignore न करें

Evil Twin Attack

Evil Twin legitimate access point की copy जैसा fake wireless network है।

Detection Signs

Wireless Threat Countermeasures

  • WPA3/WPA2-Enterprise
  • Protected Management Frames
  • Wireless IDS/IPS
  • Rogue AP detection
  • Guest isolation
  • Regular surveys
  • User awareness
