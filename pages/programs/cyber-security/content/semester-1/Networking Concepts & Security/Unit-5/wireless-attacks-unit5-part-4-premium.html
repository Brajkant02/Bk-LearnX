Wireless Attacks Unit-V - Part 4

Wireless hardening, monitoring, incident response, implementation checklist और best practices.

Wireless Network Hardening

  • WPA3 या WPA2-AES use करें
  • Strong admin password रखें
  • WPS disable करें
  • Default SSID/admin credentials बदलें
  • Firmware update करें
  • Guest network isolate करें
  • Management access restrict करें

Enterprise Wireless Security

Enterprise networks में centralized authentication, certificates और user-based access control use किया जाता है।

Controls

  • 802.1X
  • RADIUS
  • Certificate-based authentication
  • VLAN assignment
  • Central logging

Wireless IDS/IPS

Wireless IDS/IPS rogue APs, unusual traffic, deauthentication spikes और policy violations detect कर सकती है।

User Awareness

  • Unknown Wi-Fi join न करें
  • Auto-connect बंद रखें
  • Certificate warnings ignore न करें
  • VPN use करें
  • Fake login pages पहचानें
  • Bluetooth discoverability limit करें

Wireless Incident Response

  1. Suspicious AP identify करें
  2. Affected clients isolate करें
  3. Logs and captures preserve करें
  4. Rogue device locate करें
  5. Credentials reset करें
  6. Configuration fix करें
  7. Post-incident review करें

Wireless Security Audit Checklist

  • Encryption standard reviewed
  • WPS disabled
  • Admin access restricted
  • Guest network isolated
  • Rogue AP detection enabled
  • Firmware current
  • Bluetooth policy defined
  • Wireless logs centralized
  • Incident plan tested

Best Practices

  • Obsolete protocols remove करें
  • Strong authentication use करें
  • Regular wireless surveys करें
  • Monitoring and alerts रखें
  • User training दें
  • Physical AP security maintain करें
  • Configuration backups रखें
Professional Tip: Wireless security radio coverage, encryption, authentication, device security और user behavior—सभी पर depend करती है।
