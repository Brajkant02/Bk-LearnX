Network Attacks Part-1 - Enumeration Techniques

SMTP, SNMP, IPsec, VoIP, RPC, Telnet, FTP, TFTP, SMB, IPv6 और BGP.

Enumeration Overview

Authorized assessment में services से structured information identify करना।

Authorized Use Only

SMTP Enumeration

Mail server exposure, relay settings और user-disclosure behavior review किया जाता है।

  • Open relay disable
  • TLS
  • Rate limiting
  • Logging

SNMP Enumeration

Weak community strings और excessive read access sensitive information expose कर सकते हैं।

  • SNMPv3
  • Default strings हटाएं
  • Management access restrict करें

IPsec Enumeration

Gateway exposure, authentication policies और supported proposals review किए जाते हैं।

VoIP Enumeration

SIP domains, extensions exposure और banners का review।

RPC Enumeration

Unnecessary RPC exposure attack surface बढ़ाता है।

Telnet Enumeration

Telnet plaintext protocol है; SSH prefer करना चाहिए।

FTP Enumeration

Anonymous access, plaintext credentials और directory exposure review की जाती है।

TFTP Enumeration

TFTP में authentication और encryption नहीं होती; trusted network तक restrict करें।

SMB Enumeration

Syllabus का “SMP” संभवतः SMB है। Shares, permissions और legacy versions review किए जाते हैं।

  • SMBv1 disable
  • Guest access बंद
  • Permissions audit

IPv6 Enumeration

Neighbor discovery, dual-stack exposure और IPv6 firewall policies review की जाती हैं।

BGP Enumeration

Route advertisements, peer configuration और filtering policies review की जाती हैं।

  • Prefix filtering
  • Peer authentication
  • Route monitoring
  • RPKI validation
