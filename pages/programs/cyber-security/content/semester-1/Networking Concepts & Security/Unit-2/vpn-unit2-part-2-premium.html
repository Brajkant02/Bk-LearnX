IPsec Protocol Suite

IPsec IP communication को secure करने वाले protocols का suite है। यह authentication, integrity, confidentiality और anti-replay protection provide कर सकता है।

Authentication Header (AH)

AH packet integrity, origin authentication और anti-replay protection provide करता है, लेकिन encryption नहीं करता।

  • Integrity
  • Authentication
  • Anti-replay
  • No confidentiality

Encapsulating Security Payload (ESP)

ESP confidentiality के साथ integrity, authentication और anti-replay protection provide कर सकता है।

  • Encryption
  • Integrity
  • Authentication
  • Anti-replay

Security Association

Security Association one-way logical security relationship है जिसमें algorithms, keys, mode और lifetime define होते हैं।

  • Encryption algorithm
  • Integrity algorithm
  • Keys
  • Lifetime
  • Peer identity
