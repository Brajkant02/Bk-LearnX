Introduction to VPN

VPN (Virtual Private Network) public network पर secure private communication channel create करती है। यह data को encapsulate और अक्सर encrypt करके remote users, branches और cloud resources के बीच secure connectivity देती है।

  • Remote access
  • Branch connectivity
  • Data confidentiality
  • Authentication
  • Integrity protection
Remember: VPN public network पर logical secure tunnel बनाती है।
