Introduction to Network Security

Main Objectives

IP Address

IP Address network पर device का logical address है। यह communication और routing में use होता है।

Versions

  • IPv4 – 32-bit address
  • IPv6 – 128-bit address

IP Subnets

Subnetting large network को smaller logical networks में divide करने की process है। इससे traffic control, performance और security improve होती है।

Benefits

  • Broadcast traffic reduce
  • Departments isolate करना
  • Access control आसान
  • Network management improve

Network Address Translation (NAT)

NAT private IP addresses को public IP address से map करता है। इससे internal network addresses hide रहते हैं और public IPv4 addresses conserve होते हैं।

Image Placeholder: Private Network through NAT

Types

  • Static NAT
  • Dynamic NAT
  • PAT / NAT Overload

DHCP Server

DHCP network devices को automatically IP address, subnet mask, gateway और DNS information assign करता है।

Discover → Offer → Request → Acknowledge

Security Concerns

  • Rogue DHCP server
  • Unauthorized device allocation
  • Address pool exhaustion
