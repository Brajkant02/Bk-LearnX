Firewall

Firewall network traffic को predefined security rules के आधार पर allow या deny करता है।

Purposes

  • Unauthorized traffic block करना
  • Network zones separate करना
  • Traffic log करना
  • Policy enforce करना

Access Control Lists (ACL)

ACL rules का set है जो source, destination, protocol या port के आधार पर traffic control करता है।

Types

  • Standard ACL
  • Extended ACL
  • Inbound ACL
  • Outbound ACL
Best Practice:
ACL rules least privilege और clear documentation के साथ configure करनी चाहिए।

Packet Filtering

Packet filtering firewall packet headers inspect करके decision लेता है।

Fields Checked

  • Source IP
  • Destination IP
  • Source port
  • Destination port
  • Protocol

Firewall Alerts and Audit Trails

Firewall alerts suspicious traffic की notification देती हैं, जबकि audit trails past activities का record maintain करते हैं।

Useful Log Fields

  • Timestamp
  • Source/destination IP
  • Port and protocol
  • Action allow/deny
  • Rule matched

Firewall Best Practices

  • Default deny approach
  • Unused rules remove करें
  • Rule review schedule रखें
  • Logs centralized रखें
  • Admin access restrict करें
  • Configuration backup रखें
  • Change management follow करें
Common Mistake:
Firewall होने का अर्थ network automatically secure होना नहीं है; wrong rules बहुत बड़ा risk बन सकती हैं।
