Routers

Router different networks के बीच packets forward करता है। यह Layer 3 device है।

Security Functions

  • Routing control
  • ACLs
  • NAT
  • Traffic filtering
  • VPN termination

Switches

Switch LAN devices को connect करता है और MAC addresses के आधार पर frames forward करता है।

Security Features

  • VLANs
  • Port security
  • DHCP snooping
  • Access control
  • Monitoring

Endpoint Solutions

Endpoint Security laptops, desktops, mobiles और servers को protect करती है।

Solutions

  • Antivirus/anti-malware
  • Endpoint detection and response
  • Host firewall
  • Disk encryption
  • Patch management

Directory Services / Access Directory

Directory service users, groups, devices और permissions का centralized management provide करती है। Syllabus में “Access Directory” को generally directory-based identity and access management के concept के रूप में समझा जा सकता है।

Functions

  • User authentication
  • Group management
  • Central policies
  • Role-based access
  • Account lifecycle management
