Components and Peripheral Devices Connected with Computer

Introduction

A computer system is made up of different physical parts that work together to accept data, process it, store information, and present useful results. These physical parts are commonly known as computer components. Every component performs a particular function, and the combined working of these components allows a computer to perform different tasks.

Some components are installed inside the computer cabinet, while other devices are connected externally. Devices such as a keyboard, mouse, monitor, printer, scanner, speaker, and pen drive help users interact with the computer and extend its usefulness. These connected devices are commonly called peripheral devices.

Computer Components

Computer components are the physical parts or hardware elements that make up a computer system. They are the parts that can be seen and touched, unlike software, which consists of programs and instructions. Each component has a specific responsibility, such as processing instructions, storing data, supplying power, or displaying information.

For example, the CPU processes instructions, RAM temporarily holds the data currently being used, the hard disk stores files for long-term use, and the monitor displays the computer's output. These components depend on one another to make the computer work properly.

Main Computer Components

Component Main Function
CPU Processes instructions and performs calculations required by the computer.
Motherboard Connects the major internal components and allows them to communicate with one another.
RAM Temporarily stores data and instructions that are currently being used by the computer.
Hard Disk Stores the operating system, software, documents, and other files for long-term use.
SMPS Provides the required electrical power to the internal components of the computer.
Monitor Displays text, images, videos, and other visual information produced by the computer.

Importance of Computer Components

  • They work together to perform the basic operations of a computer.
  • They help the computer receive, process, store, and display information.
  • They make it possible to run software and perform different tasks.
  • They provide the hardware support required for the computer to operate.

Peripheral Devices

Peripheral devices are hardware devices connected to a computer to provide additional functions or make interaction with the computer easier. They help users enter data and instructions, receive processed information, or store and transfer data. A peripheral device may be connected through a cable or through a supported wireless connection.

For example, a keyboard allows a user to type text, a mouse helps the user select items on the screen, a printer produces information on paper, and a pen drive provides portable data storage. These devices support the computer's operation but are generally not the main processing unit of the computer.

Need for Peripheral Devices

  • To enter data: Input devices allow users to provide text, numbers, images, and commands to the computer.
  • To receive information: Output devices present the processed results in a form that users can understand.
  • To store and transfer data: Storage devices help users save files and move information between computers.
  • To make work easier: Peripheral devices make common activities such as typing, printing, scanning, and listening to audio more convenient.

Types of Peripheral Devices

Peripheral devices are commonly classified according to the main purpose they perform. The three basic categories covered in this chapter are input devices, output devices, and storage devices.

Category Purpose Examples
Input Devices Used to enter data and instructions into a computer. Keyboard, Mouse, Scanner
Output Devices Used to present the information processed by a computer. Monitor, Printer, Speaker
Storage Devices Used to save data and files so they can be used later. Pen Drive, Hard Disk

Input Devices

Input devices are hardware devices used to enter data, instructions, or commands into a computer. They act as a link between the user and the computer by allowing the user to provide information that the computer can process. The information entered through an input device is converted into a form that the computer can understand.

For example, when a user types a sentence using a keyboard, the keyboard sends the entered characters to the computer. Similarly, a mouse sends movement and click information so that the user can control the pointer and select items on the screen.

Examples of Input Devices

  • Keyboard: A keyboard is used to enter letters, numbers, symbols, and commands into a computer. It is commonly used for typing documents, entering information, and using keyboard shortcuts.
  • Mouse: A mouse is a pointing device used to move the pointer on the screen, select objects, open files, and perform actions such as clicking and dragging.
  • Scanner: A scanner captures printed text, photographs, or documents and converts them into digital form so that they can be viewed or stored on a computer.
Example:
When a student types an assignment using a keyboard, the keyboard works as an input device because it sends the student's text to the computer.

Output Devices

Output devices are hardware devices that receive processed information from a computer and present it to the user. The output may be displayed visually, printed on paper, or produced as sound. Output devices make the results of computer processing understandable and useful to people.

For example, after a user creates a document, the monitor displays the document on the screen. If the user needs a paper copy, a printer can produce the document on paper. A speaker can produce sound when the computer plays music or a video.

Image Placeholder: Output Devices

Examples of Output Devices

  • Monitor: A monitor is a visual output device that displays text, pictures, videos, and other information on a screen.
  • Printer: A printer produces a physical copy of digital information on paper. This printed result is called a hard copy.
  • Speaker: A speaker is an audio output device that converts audio signals from the computer into sound that users can hear.
Example:
When a computer displays the result of a calculation on the monitor, the monitor is performing an output function.

Storage Devices

Storage devices are hardware devices used to save digital data, files, and information for future use. They allow users to keep their documents, photographs, videos, and other files even after the computer is switched off, depending on the type of storage being used. Storage devices are also useful for transferring data from one computer to another.

For example, a hard disk can store a large collection of files inside a computer, while a pen drive can be carried easily and connected to different computers to transfer information.

Examples of Storage Devices

  • Hard Disk: A hard disk is a storage device used to store the operating system, installed software, documents, and other files for long-term use.
  • Pen Drive: A pen drive is a small, portable storage device that uses flash memory and connects to a computer through a USB port. It is commonly used to store and transfer files.
Example:
Saving a project file on a pen drive allows a student to carry that file and open it on another compatible computer.

Difference Between Computer Components and Peripheral Devices

Computer components and peripheral devices are both hardware. However, the terms describe different roles in a computer system. Computer components are the physical parts that make up the system, while peripheral devices are connected devices that provide input, output, or storage functions.

Basis Computer Components Peripheral Devices
Meaning Physical parts that make up the computer system and help it perform its basic operations. Devices connected to a computer to provide input, output, or storage functions.
Main Role Support the internal working and operation of the computer. Help users interact with the computer and use its facilities.
Examples CPU, Motherboard, RAM, Hard Disk, SMPS, Monitor. Keyboard, Mouse, Printer, Scanner, Speaker, Pen Drive.
Connection Many components are installed inside the computer and connected through the motherboard or internal cables. Many peripheral devices are connected externally through suitable ports or wireless connections.
