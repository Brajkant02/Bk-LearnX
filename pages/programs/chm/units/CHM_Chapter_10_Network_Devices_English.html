Network Devices

Introduction

A computer network is a group of computers and other devices connected to share information, resources, and services. Network devices are hardware components that help computers communicate and transfer data within a network or between different networks.

Different network devices perform different functions. A hub sends incoming data to connected devices, a switch forwards data within a local network, and a router connects different networks. Other devices, such as bridges, gateways, and Ethernet cards, also play important roles in network communication.

Hub

A Hub is a basic networking device used to connect multiple computers or network devices in a Local Area Network (LAN). When a hub receives data from one connected device, it sends that data to all other connected ports, except the port from which it was received.

A hub does not examine the destination MAC address of the data. It simply repeats the incoming signal to the other ports. Therefore, all connected devices receive the transmitted data, even when the data is intended for only one device.

Features of a Hub

  • Connects multiple devices in a LAN.
  • Broadcasts incoming data to all other connected ports.
  • Does not maintain a MAC address table.
  • Works at the Physical Layer (Layer 1) of the OSI model.
  • Can create unnecessary network traffic and collisions in traditional shared Ethernet networks.

Types of Hub

  • Passive Hub: Connects devices and passes signals without regenerating or amplifying them.
  • Active Hub: Regenerates or strengthens incoming signals before sending them to connected ports.
  • Intelligent Hub: Provides basic monitoring or management features in addition to connecting devices.

Switch

A Network Switch is a device used to connect computers, printers, servers, and other devices within a Local Area Network. It receives data and forwards it to the appropriate destination port by using MAC addresses.

A switch learns the MAC addresses of connected devices and stores them in a MAC address table. When a frame arrives, the switch checks its destination MAC address and forwards the frame to the correct port when the destination is known.

Features of a Switch

  • Connects multiple devices within a LAN.
  • Uses MAC addresses to forward Ethernet frames.
  • Learns and maintains a MAC address table.
  • Usually provides a separate collision domain for each switch port.
  • Most commonly operates at the Data Link Layer (Layer 2); some advanced switches also perform Layer 3 routing.

Types of Switch

  • Unmanaged Switch: Works with basic default settings and normally does not require configuration.
  • Managed Switch: Allows network administrators to configure and monitor features such as VLANs, port settings, and traffic controls.
  • Layer 3 Switch: Can perform switching and routing functions between supported networks or VLANs.

Router

A Router is a networking device that connects two or more different networks and forwards data packets between them. It examines IP addresses and uses routing information to select a suitable path for data.

A common example is a home router that connects a Local Area Network (LAN) to the Internet. Many home routers also provide Wi-Fi, a built-in network switch, firewall functions, and Network Address Translation (NAT).

Features of a Router

  • Connects different IP networks.
  • Uses IP addresses to forward packets.
  • Maintains routing information to select paths.
  • Can connect a local network to the Internet.
  • May provide additional features such as Wi-Fi, DHCP, NAT, and firewall protection.

A traditional router mainly operates at the Network Layer (Layer 3) of the OSI model.

Bridge

A Network Bridge is a device used to connect two or more LAN segments and control the movement of frames between them. It examines MAC addresses to decide whether a frame should be forwarded to another network segment or kept within the same segment.

Features of a Bridge

  • Connects separate segments of a LAN.
  • Uses MAC addresses to filter and forward frames.
  • Helps reduce unnecessary traffic between network segments.
  • Works at the Data Link Layer (Layer 2) of the OSI model.
  • Can learn device addresses and maintain a forwarding table.

A network switch can be understood as a multiport bridge because it performs similar Layer 2 forwarding functions across multiple ports.

Gateway

A Gateway is a device or system that connects networks that may use different communication protocols or architectures. It acts as an entry and exit point through which data can move from one network to another.

A gateway may perform protocol conversion, data translation, or other communication functions so that different systems can exchange information. In an ordinary IP network, the term default gateway usually refers to the router address that a device uses to send traffic to destinations outside its local network.

Features of a Gateway

  • Connects different networks or systems.
  • May translate between different protocols or data formats.
  • Can act as an entry and exit point for network traffic.
  • May provide security, filtering, or traffic-management functions.
  • Its operation can involve different OSI layers, depending on its purpose.

Ethernet Card (Network Interface Card)

An Ethernet Card, also known as a Network Interface Card (NIC), is a hardware component that allows a computer to connect to a wired Ethernet network. It provides a physical network interface through which the computer can send and receive data.

Many modern computers have Ethernet networking built into the motherboard. A separate Ethernet card can also be installed in a compatible expansion slot, or a USB-to-Ethernet adapter can provide a wired network connection.

Functions of an Ethernet Card

  • Connects a computer to a wired Ethernet network.
  • Sends and receives Ethernet frames.
  • Uses a unique MAC address assigned to the network interface.
  • Converts computer data into signals suitable for the network medium and converts received signals back into data.
  • Supports network communication at the speed and standard supported by the adapter and network equipment.

Common Types

  • Integrated NIC: Built into the computer's motherboard.
  • PCIe Ethernet Card: Installed in a PCI Express expansion slot in a desktop computer.
  • USB-to-Ethernet Adapter: Connects to a USB port and provides an Ethernet port.

Network Cables (CAT-6 and OFC)

Network cables are physical transmission media used to carry data between computers and networking devices. Two important types of wired network media are twisted-pair copper cables, such as CAT-6, and optical fibre cables, such as OFC.

1. CAT-6 Cable

CAT-6 (Category 6) is a type of twisted-pair copper Ethernet cable used in wired computer networks. It contains four pairs of insulated copper wires twisted together to reduce electromagnetic interference and crosstalk.

  • Commonly used to connect computers, switches, routers, and other Ethernet devices.
  • Uses twisted pairs of copper conductors.
  • Normally terminated with an 8P8C modular connector, commonly called an RJ45 connector.
  • Supports Ethernet speeds up to 1 Gbps over 100 metres and can support 10 Gbps over shorter distances, typically up to 55 metres under suitable installation conditions.
  • Has a rated bandwidth of up to 250 MHz.

Image Placeholder: CAT-6 Network Cable

Common CAT-6 Cable Types

  • UTP (Unshielded Twisted Pair): Does not have an additional metallic shield around the cable pairs. It is commonly used in offices and homes.
  • STP/Shielded Cable: Includes shielding to provide additional protection against electromagnetic interference. Proper grounding and installation are important.

2. OFC (Optical Fibre Cable)

OFC (Optical Fibre Cable) carries data in the form of light signals through very thin strands of glass or plastic called optical fibres. It is used for high-speed communication over long distances and in locations where electrical interference may affect copper cables.

Main Parts of an Optical Fibre

  • Core: The central part through which light travels.
  • Cladding: The layer surrounding the core that helps keep light inside the core through total internal reflection.
  • Coating: A protective layer that helps protect the fibre from damage.
  • Outer Jacket: The outer covering that protects the cable during installation and use.

Types of Optical Fibre

  • Single-Mode Fibre: Has a very small core and carries light mainly along a single mode. It is commonly used for long-distance communication.
  • Multi-Mode Fibre: Has a larger core and carries multiple light modes. It is commonly used for shorter-distance links, such as within buildings and data centres.

Advantages of OFC

  • Supports very high data capacity and bandwidth.
  • Can carry data over long distances with low signal loss.
  • Is not affected by electromagnetic interference in the same way as copper cables.
  • Does not carry electrical current through the fibre itself.
  • Is useful for backbone networks and high-speed communication links.

Difference Between CAT-6 and OFC

Basis CAT-6 OFC
Transmission Medium Copper wires. Glass or plastic optical fibres.
Signal Type Electrical signals. Light signals.
Interference Can be affected by electromagnetic interference. Immune to electromagnetic interference in the fibre transmission path.
Distance Common Ethernet channel length is up to 100 metres, depending on the standard and installation. Can support much longer links, depending on fibre type and optical equipment.
Installation Generally easier to terminate with standard Ethernet tools. Requires fibre-specific connectors, tools, and careful handling.
Common Uses Office LANs, homes, and device connections. Network backbones, data centres, and long-distance links.
Note:
CAT-6 and OFC are different cable technologies. The required cable depends on network speed, distance, installation conditions, and the interfaces supported by the devices.

Cabling Tools

Cabling tools are used to prepare, install, terminate, and test network cables. Using the correct tools helps create reliable connections and makes network installation and maintenance easier.

Common Network Cabling Tools

Tool Function
Crimping Tool Attaches an 8P8C modular plug, commonly called an RJ45 plug, to the end of a twisted-pair Ethernet cable.
Wire Stripper Removes the outer jacket or insulation from a cable without damaging the internal conductors.
Cable Cutter Cuts network cables cleanly to the required length.
LAN Cable Tester Checks cable continuity and helps identify open wires, short circuits, and incorrect wire connections.
Punch-Down Tool Pushes and trims individual wires into insulation-displacement terminals on patch panels and network wall jacks.
Network Cable Toner and Probe Helps identify and trace a particular cable among multiple cables.
Measuring Tape Measures the cable route and required cable length.
Fibre Optic Tools Specialized tools such as fibre strippers, cleavers, cleaning tools, and fusion splicers are used for optical fibre preparation and joining.

Basic Steps to Prepare a CAT-6 Ethernet Cable

  1. Measure the required cable length and cut the CAT-6 cable cleanly.
  2. Remove a small section of the outer jacket carefully without damaging the twisted pairs.
  3. Arrange the eight wires according to the selected wiring standard, such as T568A or T568B.
  4. Straighten and trim the wires evenly while keeping the untwisted section as short as practical.
  5. Insert the wires fully into the correct positions in the compatible 8P8C plug.
  6. Use the crimping tool to secure the plug to the cable.
  7. Test the completed cable with a LAN cable tester.

Important:

Network Troubleshooting

Network troubleshooting is the process of finding and resolving problems that prevent devices from communicating correctly. Problems may be caused by loose cables, damaged connectors, incorrect IP settings, faulty network devices, driver issues, or wireless interference.

Common Network Problems and Solutions

Problem Possible Cause Basic Solution
No network connection Loose cable, disabled network adapter, faulty switch port, or router problem. Check cable connections, adapter status, link lights, and network device power. Test with a known-good cable or port.
Limited or no Internet access Router or modem issue, incorrect IP configuration, or service-provider outage. Check the router's status, IP configuration, and Internet connection. Restart network equipment if appropriate.
Slow network speed Damaged cable, network congestion, weak Wi-Fi signal, or device limitation. Check cable condition and link speed, reduce unnecessary traffic, and test the connection from another device.
IP address conflict Two devices are using the same IP address. Check IP settings and use the network's DHCP service or assign a valid unique address according to the network plan.
Network cable tester shows a fault Incorrect wire order, broken conductor, short circuit, or poor termination. Recheck the wiring standard, inspect the connectors, and re-terminate or replace the cable if necessary.
One computer cannot access the LAN Faulty Ethernet adapter, incorrect network settings, or damaged cable. Check the adapter in the operating system, verify IP settings, and test with a known-good cable and switch port.
Frequent disconnections Loose connector, damaged cable, unstable power, or network device fault. Secure the connections, inspect the cable, check device power, and test another port or cable.
Cannot access another device Incorrect IP address, subnet, gateway, firewall rule, or name-resolution issue. Verify network settings, test local connectivity, and check firewall and name-resolution configuration.

Basic Troubleshooting Procedure

  1. Check Physical Connections: Make sure network cables are firmly connected and not visibly damaged.
  2. Check Device Power: Confirm that the hub, switch, router, and other network devices are switched on.
  3. Check Link Indicators: Observe the link or activity LEDs on the Ethernet card and switch or router port.
  4. Check Network Adapter: Ensure the Ethernet or wireless adapter is enabled and working properly.
  5. Verify IP Configuration: Check that the device has a valid IP address, subnet mask, and default gateway.
  6. Test Connectivity: Use a suitable network diagnostic command, such as ping, to test communication with another device or gateway.
  7. Test Cable and Port: Use a cable tester or try a known-good cable and network port.
  8. Restart if Necessary: Restart the affected device or network equipment when appropriate.
  9. Escalate the Problem: If the issue remains, check device logs and configuration or contact the network administrator.

Remember:
Always check physical connections and device power first. Then check the network adapter, IP configuration, cable, and network device settings.
Safety Note:
Do not look directly into the end of an optical fibre or optical connector. Invisible laser light may be present. Use proper fibre inspection and cleaning procedures, and handle glass fibre carefully.
