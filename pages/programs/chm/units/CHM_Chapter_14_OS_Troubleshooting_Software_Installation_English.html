OS Troubleshooting & Software Installation

Introduction

An Operating System (OS) is system software that manages computer hardware and provides services for application programs. Windows and Linux are two widely used operating systems. They manage files, memory, processors, storage devices, users, and connected hardware.

Operating System Troubleshooting is the process of identifying, diagnosing, and resolving problems that prevent an operating system from working correctly. Problems may include slow performance, startup failure, driver errors, application crashes, network issues, or damaged system files.

Software Installation is the process of adding an application program to a computer so that it can be used. Examples include office productivity software and video editing tools.

Troubleshooting Process of an Operating System

Operating system troubleshooting should be performed in a systematic way. A proper process helps identify the actual cause of a problem and reduces the risk of unnecessary changes or data loss.

General Troubleshooting Steps

  1. Identify the Problem: Observe the error message, unusual behaviour, or symptom. Ask when the problem started and whether any hardware, software, or configuration changes were recently made.
  2. Collect Information: Note the operating system version, error codes, affected applications, recent updates, and steps that cause the problem.
  3. Check Basic Connections: Verify power, display, keyboard, mouse, network cables, and external devices where relevant.
  4. Find the Possible Cause: Consider software conflicts, incorrect settings, driver problems, insufficient storage, malware, damaged system files, or hardware faults.
  5. Apply a Suitable Solution: Make one appropriate change at a time, such as restarting a service, updating a driver, removing a conflicting application, or repairing system files.
  6. Test the System: Restart if required and check whether the original problem has been resolved.
  7. Document the Result: Record the cause, solution, and any steps that may help if the same problem occurs again.

Windows Operating System Troubleshooting

Windows is a graphical operating system developed by Microsoft. Common Windows problems can often be investigated using built-in tools such as Task Manager, Device Manager, Disk Management, Windows Update, and Windows Recovery Environment.

Common Windows Problems and Solutions

Problem Possible Cause Basic Solution
Windows is running slowly Too many startup applications, low free storage, insufficient memory, or high background activity. Use Task Manager to check resource usage, disable unnecessary startup apps, free storage space, and restart the computer.
Windows does not start Boot configuration problem, damaged system files, failed update, or storage device issue. Disconnect unnecessary external devices and use Windows Recovery Environment and Startup Repair where available.
Blue Screen error Driver fault, hardware problem, memory issue, or damaged system files. Note the stop code, disconnect recently added hardware, and check recent driver or software changes. Use recovery options if Windows cannot start normally.
No Internet connection Network adapter disabled, incorrect network settings, router problem, or driver issue. Check Wi-Fi or Ethernet, restart the router if appropriate, run the Windows network troubleshooter, and check the adapter in Device Manager.
Sound is not working Incorrect output device, muted volume, audio driver issue, or disconnected speaker. Check volume and output selection, inspect cable connections, and update or reinstall the audio driver if needed.
USB device is not detected Faulty port or cable, driver issue, or device problem. Try another USB port, test the device on another computer, and check Device Manager.
Application is not responding Application error, insufficient resources, or software conflict. Wait briefly, use Task Manager to close the unresponsive application if necessary, and check for application updates.
Windows update fails Insufficient storage, network interruption, update service issue, or incompatible software or drivers. Check Internet access and free space, restart the computer, and use Windows Update troubleshooting options.

Useful Windows Troubleshooting Tools

  • Task Manager: Displays running applications, processes, CPU usage, memory usage, disk activity, and startup applications. It can be opened with Ctrl + Shift + Esc.
  • Device Manager: Shows installed hardware devices and their drivers. It helps identify devices with driver or hardware errors.
  • Disk Management: Displays storage disks, partitions, and drive letters. Use it carefully because changing partitions can affect data.
  • Windows Update: Downloads and installs supported operating system updates and security fixes.
  • System File Checker (SFC): Scans protected Windows system files and attempts to repair damaged files.
  • Startup Repair: A recovery tool that can help fix certain problems preventing Windows from starting.
  • Safe Mode: Starts Windows with a limited set of drivers and services to help diagnose some software and driver problems.

Using System File Checker

If Windows system files are suspected to be damaged, an administrator can use the System File Checker tool.

  1. Open the Start menu and search for Command Prompt.
  2. Select Run as administrator.
  3. Enter the following command and press Enter:
sfc /scannow

Wait for the scan to finish. Windows will report whether it found integrity problems and whether it could repair them. Follow any recommended next steps.

Linux Operating System Troubleshooting

Linux is an open-source operating system kernel used by many distributions, such as Ubuntu, Debian, Fedora, and Linux Mint. Linux distributions provide tools and graphical interfaces for managing hardware, software, users, files, and system services.

Linux troubleshooting can be performed through graphical system tools or the Terminal. Terminal commands are useful for checking system information, storage, network connectivity, running processes, and service status.

Common Linux Problems and Solutions

Problem Possible Cause Basic Solution
Linux system is slow High CPU or memory usage, too many background processes, or low disk space. Use the system monitor or commands such as top to identify resource usage. Close unnecessary applications and check free storage.
Linux does not boot Bootloader issue, incorrect boot settings, damaged file system, or failed update. Check boot settings and use the distribution's recovery options or a live USB to diagnose the problem.
Internet is not working Network adapter disabled, incorrect network configuration, driver issue, or router problem. Check network settings, reconnect to the network, and use suitable diagnostic commands to test connectivity.
Application cannot be installed Incorrect package source, unavailable package, repository issue, or insufficient permissions. Check the package name and repository settings, refresh package information, and use the distribution's supported package manager.
Permission denied The current user does not have permission to access or modify a file or directory. Check file ownership and permissions. Use administrator privileges only when required and understood.
Disk space is full Large files, logs, cached packages, or unnecessary data. Check disk usage, remove unnecessary files safely, and use the distribution's storage-management tools.
Sound or display is not working Incorrect device settings, driver or firmware issue, or hardware connection problem. Check system settings, cable connections, available driver updates, and distribution support information.

Useful Linux Troubleshooting Commands

Command Purpose
pwd Displays the current working directory.
ls Lists files and directories.
df -h Displays file-system disk space usage in a readable format.
free -h Displays memory and swap usage.
top Displays running processes and system resource usage.
ip addr Displays network interface and IP address information.
ping Tests network reachability to another device or host.
systemctl status Displays the status of a specified system service when used with a service name.

Example of checking free disk space:

df -h

Example of checking network connectivity:

ping -c 4 example.com

Package Management in Linux

Linux distributions use package managers to install, update, and remove software. The package manager depends on the distribution.

  • APT: Commonly used in Ubuntu and Debian-based distributions.
  • DNF: Used in Fedora and some related distributions.
  • GUI Software Center: A graphical application that helps users find and install supported software packages.

For example, on Ubuntu or Debian-based systems, package information can be refreshed using:

sudo apt update

Use administrative commands carefully. Install software from trusted repositories and check the command before executing it.

Installation of Popular Application Software

Application software is designed to help users perform specific tasks. Examples include creating documents, preparing spreadsheets, making presentations, editing photographs, and producing videos.

General Steps for Installing Application Software

  1. Check System Requirements: Confirm that the computer meets the application's supported operating system, processor, memory, storage, and graphics requirements.
  2. Choose a Trusted Source: Download the installer from the software developer's official website or use a trusted application store or package repository.
  3. Download the Correct Version: Select the version suitable for the operating system and computer architecture.
  4. Run the Installer: Open the downloaded installation file or use the operating system's package manager.
  5. Follow the Setup Instructions: Review the licence terms, installation location, and available options.
  6. Complete Installation: Wait until the setup process finishes successfully.
  7. Launch and Test: Open the application and check that it works correctly.
  8. Activate or Update if Required: Complete any legitimate activation and install supported updates.
Safety Note:
Avoid unknown download websites, unofficial modified installers, and suspicious activation tools. They may contain malware or unwanted software.

MS Office Installation

Microsoft Office is a productivity software suite developed by Microsoft. Its applications are used for creating documents, spreadsheets, presentations, and other office work. Depending on the licence and edition, the suite may include applications such as Word, Excel, PowerPoint, and Outlook.

Uses of Common MS Office Applications

  • Microsoft Word: Used to create and edit text documents, letters, reports, and assignments.
  • Microsoft Excel: Used to organize data, perform calculations, and create charts and tables.
  • Microsoft PowerPoint: Used to create slide-based presentations.
  • Microsoft Outlook: Used to manage email, calendars, contacts, and tasks in supported editions.

General Installation Process

  1. Check that the computer meets the system requirements for the selected Microsoft 365 or Office edition.
  2. Obtain a valid licence, subscription, or product entitlement for the edition being installed.
  3. Sign in to the official Microsoft account or organization portal associated with the licence.
  4. Choose the available Office installation option and download the installer.
  5. Run the downloaded setup file and allow the installation process to complete.
  6. Open an Office application, such as Word or Excel.
  7. Sign in or complete activation when prompted, using the account or product method supported by the licence.
  8. Check for available updates and open a sample document to test the installation.

LibreOffice Installation

LibreOffice is a free and open-source office productivity suite. It is available for supported Windows, Linux, and macOS systems. It provides tools for word processing, spreadsheets, presentations, drawing, and database-related work.

Important LibreOffice Applications

  • Writer: Used to create and edit text documents.
  • Calc: Used to work with spreadsheets, formulas, and charts.
  • Impress: Used to create presentations.
  • Draw: Used to create diagrams and vector drawings.
  • Base: Used to work with databases.
  • Math: Used to create and edit mathematical formulas.

Installation on Windows

  1. Visit the official LibreOffice website and open its download section.
  2. Select the current stable version for Windows that matches the computer's requirements.
  3. Download the installation file.
  4. Open the downloaded installer.
  5. Follow the setup wizard and select the installation type and options.
  6. Start the installation and wait for it to finish.
  7. Open LibreOffice Writer or another application to confirm that it works.

Installation on Ubuntu or Debian-Based Linux

LibreOffice may be available through the distribution's software centre. On systems that use APT, the package manager can also be used. Package names and available versions may vary by distribution release.

sudo apt update
sudo apt install libreoffice

Enter the administrator password when requested and follow the package manager's instructions.

Advantages of LibreOffice

  • Free to use and open-source.
  • Includes word processing, spreadsheet, and presentation applications.
  • Supports many common document file formats.
  • Available for multiple operating systems.

Installation of Video Editing Tools

Video Editing Software is application software used to create, edit, arrange, and produce video content. It allows users to combine video clips, add titles, insert transitions, adjust audio, apply effects, and export the final video.

Examples of Video Editing Tools

  • Shotcut: A free, open-source video editor available for supported desktop operating systems.
  • OpenShot: A free, open-source video editor designed for common editing tasks.
  • DaVinci Resolve: A professional video editing and post-production application with editing, colour correction, visual effects, and audio tools. Its system requirements are higher than those of many basic editors.
  • Microsoft Clipchamp: A video editing application from Microsoft, available through supported Windows and web experiences depending on the version and account.

General Installation Process

  1. Choose a video editor according to the computer's hardware and the editing work required.
  2. Check the official system requirements, including operating system version, RAM, processor, graphics support, and free storage.
  3. Visit the software developer's official website or a trusted application store.
  4. Download the installer that matches the operating system.
  5. Run the installer and follow the setup instructions.
  6. Choose the installation location and optional components where available.
  7. Complete the installation and restart the computer if the setup requests it.
  8. Open the video editor and create a test project.
  9. Import a sample video, check playback, and export a short test file.

Basic Functions of Video Editing Software

  • Import Media: Adds video, audio, and image files to a project.
  • Timeline Editing: Arranges clips and audio in the required order.
  • Trimming and Splitting: Removes unwanted parts or divides a clip into smaller sections.
  • Transitions: Creates visual changes between clips.
  • Titles and Text: Adds headings, captions, and credits.
  • Audio Editing: Adjusts volume and combines music, voice, and other audio.
  • Export: Produces the completed video in a selected format and quality.

Basic Software Maintenance

  • Keep the operating system and installed applications updated.
  • Install applications only from trusted and official sources.
  • Remove applications that are no longer required using the operating system's uninstall method.
  • Keep sufficient free storage space for temporary files, updates, and projects.
  • Use reliable security software and scan suspicious downloaded files.
  • Back up important documents and video projects regularly.
  • Check application permissions and avoid granting unnecessary administrator access.
  • Restart the computer when required to complete updates or installation tasks.

Common Installation Problems and Solutions

Problem Possible Cause Basic Solution
Installer does not open Incomplete download, unsupported file, or security restriction. Download again from the official source and confirm that the installer supports the operating system.
Not enough disk space Insufficient free storage on the installation drive. Free up space safely or select another supported installation location.
Installation is blocked Insufficient permissions, security policy, or incompatible software. Check the error message and user permissions. Use administrator access only when appropriate.
Application crashes after installation Unsupported system requirements, missing components, driver issue, or corrupted installation. Check system requirements, install updates, and use the application's repair or reinstall option if available.
Video editor runs slowly Insufficient RAM, unsupported graphics hardware, high-resolution media, or background applications. Close unnecessary applications, check hardware requirements, and use suitable preview or project settings.
Remember:
Before installing any application, check system requirements and download it from an official or trusted source. Test the application after installation.
