Detailed Description of CMOS Setup & CMOS Password Setting

CMOS Setup • BIOS/UEFI • System Settings • Boot Priority • Hardware Configuration • Security Password

1. CMOS Setup का परिचय

CMOS Setup एक firmware configuration interface है जिसका उपयोग computer के hardware और startup से संबंधित विभिन्न settings को configure करने के लिए किया जाता है। पुराने PC systems में इन settings को अक्सर CMOS memory में store किया जाता था, इसलिए इसे commonly CMOS Setup कहा जाता है। Modern computers में configuration data सामान्यतः non-volatile firmware storage में रखा जाता है, फिर भी “CMOS Setup” नाम आज भी widely used है।

Exam Definition: CMOS Setup एक system configuration utility है जिसके माध्यम से computer के hardware, boot sequence, date/time, storage devices, security और power management जैसी settings को configure किया जाता है।

CMOS का Meaning

CMOS का traditional full form Complementary Metal-Oxide-Semiconductor है। पुराने personal computers में CMOS technology पर आधारित low-power memory area का उपयोग BIOS configuration settings को store करने के लिए किया जाता था। Motherboard की छोटी battery इस memory/real-time clock को power maintain करने में सहायता करती थी।

CMOS Battery का कार्य

  • Traditional systems में BIOS/CMOS settings को retain करने में सहायता करना।
  • Real-Time Clock (RTC) को power provide करना।
  • Computer बंद होने पर भी date और time maintain करने में सहायता करना।

2. BIOS, CMOS और UEFI का संबंध

CMOS Setup को समझने के लिए BIOS और UEFI का concept समझना आवश्यक है।

BIOS

BIOS (Basic Input/Output System) traditional firmware है जो system startup पर hardware initialization, POST और boot process में महत्वपूर्ण भूमिका निभाता है।

UEFI

UEFI (Unified Extensible Firmware Interface) modern firmware interface है जो traditional BIOS के स्थान पर modern computers में commonly उपयोग होता है और advanced configuration तथा secure boot जैसी सुविधाएँ प्रदान कर सकता है।

TermMeaning / Role
CMOSTraditional term for low-power configuration storage technology/area associated with PC settings.
BIOSTraditional firmware responsible for hardware initialization and boot process.
UEFIModern firmware interface that replaces traditional BIOS on many systems.
CMOS SetupFirmware configuration interface through which hardware/system settings are changed.

3. CMOS Setup में प्रवेश करने की प्रक्रिया

CMOS Setup खोलने के लिए computer start या restart करते समय manufacturer-specific key press की जाती है। Exact key motherboard/laptop manufacturer पर depend करती है। Common keys में Delete, F2, F10, F12, Esc आदि शामिल हो सकती हैं।

Step-by-Step Process

Step 1: Computer को completely shut down या restart करें।
Step 2: Power ON करते समय screen पर दिखाई देने वाले firmware setup instruction को देखें।
Step 3: Manufacturer द्वारा बताई गई key, जैसे F2 या Delete, repeatedly press करें।
Step 4: Firmware Setup Utility / UEFI Setup screen open होगी।
Step 5: Keyboard या graphical interface से required settings configure करें।
Power ON ↓ POST / Hardware Initialization ↓ Press Setup Key (F2 / DEL / F10 / etc.) ↓ BIOS / UEFI Setup ↓ Change Settings ↓ Save & Exit ↓ System Restart
Note: Setup key universal नहीं है। अलग-अलग motherboard, laptop और firmware versions में key अलग हो सकती है।

4. CMOS Setup की Main Settings

4.1 Date and Time

System date और time को configure करने के लिए Date/Time setting का उपयोग किया जाता है। Operating system और applications सही timestamps के लिए system clock पर depend कर सकते हैं।

4.2 Storage / Drive Information

Setup में installed storage devices जैसे HDD, SSD या अन्य supported drives की information दिखाई जा सकती है। कुछ firmware versions में storage controller modes और related options भी उपलब्ध होते हैं।

4.3 Boot Sequence / Boot Priority

Boot order यह निर्धारित करता है कि computer startup पर किस device से operating system खोजेगा। उदाहरण के लिए SSD/HDD, USB drive या network boot device को priority दी जा सकती है।

Example Boot Priority: 1. SSD / HDD 2. USB Storage 3. DVD / Optical Drive 4. Network Boot

4.4 Memory Information

Firmware setup installed RAM की capacity और कुछ systems में memory-related configuration information display कर सकता है। Advanced systems में memory profile या frequency-related settings भी उपलब्ध हो सकती हैं।

4.5 CPU Information

Processor model, speed और supported configuration information firmware interface में दिखाई दे सकती है। Advanced settings में CPU-related options भी हो सकते हैं, लेकिन इन्हें बिना knowledge के बदलना उचित नहीं है।

6. Power Management Settings

Firmware setup में power management options computer के power behavior को configure करने के लिए दिए जा सकते हैं। Modern systems में ACPI-based power management महत्वपूर्ण भूमिका निभाता है।

  • Power on after AC loss: Power वापस आने पर system automatically start हो या नहीं।
  • Wake on LAN: Network signal के माध्यम से system wake करने की सुविधा, supported hardware/configuration में।
  • Wake by USB/Keyboard: Supported systems में USB device से wake-up behavior configure करना।
  • Sleep/Power states: System power states से संबंधित options, firmware/OS support के अनुसार।

7. Security Settings

Firmware security settings का उपयोग unauthorized users को firmware configuration बदलने से रोकने और supported systems में boot security improve करने के लिए किया जा सकता है।

Common Security Options

  • Setup/Administrator password
  • User password
  • Boot password, supported firmware में
  • Secure Boot
  • TPM/Security Device configuration
Difference: Firmware/Setup password का मुख्य उद्देश्य setup configuration को protect करना है। यह जरूरी नहीं कि operating system के Windows login password के समान हो।

8. CMOS Password Setting

CMOS Password या firmware password का उपयोग BIOS/UEFI Setup को unauthorized access से protect करने के लिए किया जा सकता है। Password set होने के बाद firmware setup खोलते समय authentication मांगी जा सकती है। कुछ systems में अलग boot password option भी उपलब्ध होता है।

Password Set करने की General Process

Step 1: Computer restart करें और firmware setup में प्रवेश करें।
Step 2: Security या Password section खोलें।
Step 3: Administrator/Supervisor Password या similar option select करें।
Step 4: Strong password enter करें।
Step 5: Password दोबारा enter करके confirm करें।
Step 6: Changes को Save & Exit करें।
Step 7: System restart होने पर configured security behavior को verify करें।
Firmware Setup │ ▼ Security │ ▼ Administrator / Supervisor Password │ ▼ Enter Password │ ▼ Confirm Password │ ▼ Save Changes │ ▼ Restart

Password Types

Password TypePurpose
Administrator / Supervisor PasswordFirmware setup settings को unauthorized modification से protect करना।
User Passwordकुछ firmware में limited user access या authentication के लिए।
Boot / Power-on Passwordकुछ systems में operating system boot से पहले authentication require करना।

Password Setting में सावधानियाँ

  • Password को सुरक्षित स्थान पर रखें।
  • ऐसा password चुनें जिसे authorized user याद रख सके लेकिन दूसरे आसानी से guess न कर सकें।
  • Password भूलने पर motherboard/laptop manufacturer की official recovery procedure follow करें।
  • CMOS battery निकालने या hardware reset जैसे उपायों से पहले manufacturer documentation देखें; modern systems में firmware security settings अलग तरीके से protected हो सकती हैं।
Exam Point: CMOS/firmware password operating system login password से अलग security layer हो सकता है। इसका उपयोग firmware settings या boot access को protect करने के लिए किया जाता है, system design पर depend करते हुए।

9. Save & Exit Options

CMOS/UEFI Setup में changes करने के बाद उन्हें सही तरीके से save करना आवश्यक है। सामान्यतः firmware में निम्न प्रकार के options दिखाई दे सकते हैं:

OptionMeaning
Save Changes and ExitChanges save करके setup से बाहर निकलना।
Discard Changes and ExitCurrent changes को discard करके बाहर निकलना।
Load Optimized/Setup DefaultsFirmware द्वारा दिए गए default settings load करना।
Save ChangesChanges save करना और setup में बने रहना, यदि supported हो।
CHANGE SETTING ↓ REVIEW SETTING ↓ SAVE CHANGES ↓ EXIT ↓ RESTART
