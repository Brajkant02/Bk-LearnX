1. Steps in the Booting Process

Booting वह process है जिसमें computer को power on या restart करने के बाद system hardware initialize होता है और operating system को memory में load करके computer को usable state में लाया जाता है। DOS environment के संदर्भ में boot process में system files, configuration और startup commands का विशेष महत्व था।

Exam Definition: Booting वह प्रक्रिया है जिसमें computer start होने पर firmware द्वारा hardware initialization के बाद operating system की आवश्यक files को memory में load किया जाता है ताकि system user commands accept कर सके।

DOS Booting Process – Step by Step

Step 1 – Power ON: Computer को power supply मिलती है और processor startup sequence शुरू करता है।
Step 2 – BIOS/ROM Firmware: Traditional PC में BIOS basic hardware initialization और startup checks perform करता है।
Step 3 – Boot Device Search: Firmware configured boot sequence के अनुसार bootable storage device खोजता है।
Step 4 – Boot Sector: Bootable disk का boot sector execute होता है और DOS startup process आगे बढ़ता है।
Step 5 – IO.SYS: Traditional MS-DOS systems में IO.SYS essential DOS startup components और basic I/O initialization में भूमिका निभाता है।
Step 6 – MSDOS.SYS: Traditional DOS में MSDOS.SYS DOS kernel/system services से संबंधित core functionality provide करता है।
Step 7 – CONFIG.SYS: यदि मौजूद हो तो DOS configuration file process की जाती है। इसमें device drivers और system configuration commands हो सकते हैं।
Step 8 – COMMAND.COM: DOS command interpreter load होता है और user commands process करने की सुविधा देता है।
Step 9 – AUTOEXEC.BAT: यदि मौजूद हो तो startup batch commands automatically execute होती हैं।
Step 10 – DOS Prompt: System command prompt display करता है, जैसे C:\>, और user commands के लिए ready हो जाता है।
POWER ON │ ▼ BIOS / FIRMWARE │ ▼ BOOTABLE DISK FOUND │ ▼ BOOT SECTOR │ ▼ IO.SYS │ ▼ MSDOS.SYS │ ▼ CONFIG.SYS │ ▼ COMMAND.COM │ ▼ AUTOEXEC.BAT │ ▼ DOS PROMPT C:\>
Historical Note: ऊपर दिया गया flow traditional MS-DOS style boot process को समझाने के लिए है। Modern Windows systems का boot architecture इससे अलग है।

2. CONFIG.SYS और AUTOEXEC.BAT Files

Traditional DOS में CONFIG.SYS और AUTOEXEC.BAT important startup files थीं। इनका उपयोग system configuration और automatic startup commands के लिए किया जाता था।

CONFIG.SYS

CONFIG.SYS एक configuration file थी जिसमें DOS startup के समय system configuration से संबंधित commands और device-driver loading instructions रखे जा सकते थे।

Common examples: DEVICE=, FILES=, BUFFERS=, LASTDRIVE= आदि।

AUTOEXEC.BAT

AUTOEXEC.BAT एक batch file थी जिसमें ऐसे commands रखे जाते थे जिन्हें DOS startup के बाद automatically execute करना होता था।

Examples: PATH सेट करना, environment variables set करना, startup programs/commands run करना आदि।

CONFIG.SYS Example

DEVICE=HIMEM.SYS FILES=40 BUFFERS=20 LASTDRIVE=Z

AUTOEXEC.BAT Example

@ECHO OFF PATH C:\DOS;C:\UTIL SET TEMP=C:\TEMP PROMPT $P$G

3. Memory Usage in the DOS Environment

Traditional DOS systems में memory management आज के modern operating systems से काफी अलग था। Classic DOS environment में 640 KB conventional memory का concept बहुत महत्वपूर्ण था। DOS और applications के लिए conventional memory के साथ upper memory और extended/expanded memory technologies भी उपयोग की जाती थीं।

Conventional Memory

Traditional IBM PC memory map में lower 1 MB address space के पहले 640 KB को conventional memory कहा जाता था। DOS operating system, device drivers और applications इसी area का उपयोग करते थे। उपलब्ध conventional memory limited होने के कारण memory optimization important थी।

Upper Memory Area (UMA)

640 KB से 1 MB के बीच का address space Upper Memory Area कहलाता है। इसमें hardware-related reserved areas के साथ कुछ memory regions ऐसे हो सकते थे जिनका उपयोग memory management techniques के माध्यम से किया जा सकता था।

Extended Memory

1 MB से ऊपर की physical memory को extended memory कहा जाता था। विशेष memory managers और processor modes की सहायता से DOS applications इस memory का उपयोग कर सकती थीं। HIMEM.SYS extended memory access में महत्वपूर्ण था।

Expanded Memory

Expanded Memory एक अलग memory expansion technique थी जिसमें EMS specification के माध्यम से applications को additional memory access उपलब्ध कराया जाता था।

TRADITIONAL PC MEMORY CONCEPT ┌─────────────────────────────┐ │ Extended Memory │ │ > 1 MB │ ├─────────────────────────────┤ │ Upper Memory Area │ │ 640 KB – 1 MB │ ├─────────────────────────────┤ │ Conventional Memory │ │ 0 – 640 KB │ │ DOS + Drivers + Apps │ └─────────────────────────────┘
Exam Point: DOS environment में conventional memory की limitation एक major issue थी। इसलिए memory managers, device-driver optimization और upper/extended memory techniques का उपयोग memory availability improve करने के लिए किया जाता था।

4. Basic DOS Commands

DOS commands वे instructions हैं जिन्हें user command prompt पर type करके files, directories, disks और system environment से संबंधित operations perform कर सकता है।

Internal Commands

ये commands command interpreter, traditionally COMMAND.COM, के साथ available रहती थीं और सामान्यतः अलग executable file की आवश्यकता नहीं होती थी।

External Commands

ये अलग program files के रूप में disk पर stored होती थीं और आवश्यकता के अनुसार load होकर execute होती थीं।

6. External DOS Commands

External commands अलग executable files के रूप में disk पर stored होती थीं। Traditional DOS में इनमें कई .EXE या .COM programs शामिल हो सकते थे। Exact command availability DOS version पर depend कर सकती है।

CommandPurposeExample

CHKDSKDisk और file-system related information/errors check करने के लिए।CHKDSK C:

Note: External command की availability और exact syntax DOS version के अनुसार बदल सकती है।

7. Basic File Commands

DOS में file management के लिए कई basic commands उपयोग होती थीं। इन commands से file list देखना, copy करना, rename करना, delete करना और text content display करना संभव था।

DIR – Files की List

C:\>DIR

यह current directory की files और directories display करता है।

COPY – File Copy करना

C:\>COPY REPORT.TXT BACKUP.TXT

यह REPORT.TXT की एक copy BACKUP.TXT नाम से बनाता है।

REN – File Rename करना

C:\>REN OLD.TXT NEW.TXT

File का नाम OLD.TXT से NEW.TXT हो जाएगा।

DEL – File Delete करना

C:\>DEL TEMP.TXT

यह TEMP.TXT को delete करने का command है। Wildcards के साथ delete करते समय विशेष सावधानी आवश्यक है।

TYPE – File Content देखना

C:\>TYPE NOTES.TXT

Text file का content command screen पर display करता है।

ATTRIB – File Attributes

C:\>ATTRIB NOTES.TXT

File के attributes display किए जा सकते हैं। Traditional DOS attributes में Read-only, Archive, System और Hidden जैसे flags शामिल थे।
