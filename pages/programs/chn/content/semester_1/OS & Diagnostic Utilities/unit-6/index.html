1. Linux Introduction & Structure

Linux एक open-source, Unix-like operating system kernel है। Linux-based operating systems में kernel के साथ system utilities, libraries, package managers, desktop environments और applications मिलकर complete operating system environment बनाते हैं। Ubuntu, Fedora, Debian और कई अन्य distributions Linux kernel पर आधारित हैं।

Exam Definition: Linux एक open-source, Unix-like operating system environment है जिसमें Linux kernel hardware resources को manage करता है और users/applications को system services उपलब्ध कराता है।

Linux की प्रमुख विशेषताएँ

  • Open Source: इसका source code उपलब्ध होता है और license के अनुसार modify तथा distribute किया जा सकता है।
  • Multiuser: एक system पर multiple user accounts बनाए और manage किए जा सकते हैं।
  • Multitasking: एक समय में कई processes/tasks run कर सकता है।
  • Security: Users, groups और permissions के माध्यम से access control उपलब्ध होता है।
  • Stability: Servers और लंबे समय तक चलने वाले systems में widely used है।
  • Portability: विभिन्न hardware platforms के लिए Linux-based systems उपलब्ध हैं।

2. Kernel and Shell

Kernel क्या है?

Kernel operating system का core component है। यह applications और hardware के बीच interface की तरह काम करता है। Kernel CPU, memory, processes, devices और file systems जैसे resources को manage करता है।

Kernel FunctionDescription
Process ManagementProcesses create, schedule और terminate करने में सहायता।
Memory ManagementRAM allocation और memory usage manage करना।
Device ManagementHardware devices और drivers के साथ communication।
File System ManagementFiles और directories की access/management।
Security & AccessPermissions और resource access controls में सहायता।

Shell क्या है?

Shell

USER ↓ SHELL ↓ KERNEL ↓ HARDWARE
Difference: Kernel system का core है, जबकि Shell user द्वारा दिए गए commands को interpret/execute करने के लिए interface प्रदान करता है।

3. Basic Linux Commands

Linux में command-line interface बहुत powerful है। Commands के द्वारा files, directories, users, processes और system information को efficiently manage किया जा सकता है।

CommandPurposeExample
pwdCurrent working directory दिखाता है।pwd
lsFiles/directories की list दिखाता है।ls -l
cdDirectory change करता है।cd Documents
mkdirनई directory बनाता है।mkdir notes
rmdirEmpty directory हटाता है।rmdir notes
touchनई empty file create/update करता है।touch file.txt
cpFile/directory copy करता है।cp a.txt b.txt
mvFile move या rename करता है।mv old.txt new.txt
rmFile remove करता है।rm test.txt
catFile content display करता है।cat notes.txt
clearTerminal screen साफ करता है।clear
whoamiCurrent user name दिखाता है।whoami
dateSystem date/time display करता है।date
manCommand का manual/help खोलता है।man ls

Basic Practical Example

$ mkdir PGDCA $ cd PGDCA $ touch notes.txt $ ls notes.txt $ mv notes.txt linux.txt $ ls linux.txt $ cat linux.txt $ pwd
Tip: Linux commands case-sensitive होते हैं। LS और ls को same command नहीं माना जाता।

5. Linux File System & Structure

Linux file system एक hierarchical structure follow करता है। इसकी सबसे ऊपर की directory root directory (/) होती है। सभी files और directories किसी न किसी रूप में root hierarchy के अंतर्गत आती हैं।

/ ├── bin ├── boot ├── dev ├── etc ├── home ├── lib ├── media ├── mnt ├── opt ├── proc ├── root ├── run ├── sbin ├── tmp ├── usr └── var

File System का महत्व

  • Files को logical hierarchy में organize करता है।
  • Users और applications को data access करने का structured तरीका देता है।
  • System files और user files को अलग locations में organize करने में सहायता करता है।
  • Permissions के माध्यम से access control लागू किया जा सकता है।

7. VI Editor

vi Unix/Linux का एक प्रसिद्ध text editor है। यह terminal में text files create और edit करने के लिए उपयोग किया जाता है। इसका मुख्य feature इसका mode-based operation है। Modern Linux systems में अक्सर Vim उपलब्ध होता है, जो vi का enhanced version है।

VI के मुख्य Modes

Command / Normal Mode

Navigation, deletion, copying, searching आदि operations के लिए।

Insert Mode

Text type/edit करने के लिए। i या अन्य insert commands से enter किया जा सकता है।

Command-line Mode

: दबाकर save, quit और अन्य commands चलाने के लिए।

VI खोलना

$ vi notes.txt

Basic VI Commands

CommandPurpose
iInsert mode में जाना।
EscInsert mode से normal mode में वापस।
:wFile save करना।
:qEditor से exit करना।
:wqSave करके exit करना।
:q!Changes discard करके exit करना।
ddCurrent line delete करना।
yyCurrent line copy/yank करना।
pCopied/yanked text paste करना।
/wordWord search करना।

VI Practical Flow

$ vi linux.txt # Press i Linux is an open-source operating system. This is a practical note. # Press Esc :wq

8. Linux Installation

Linux installation के दौरान operating system files disk पर install की जाती हैं, boot configuration बनाई जाती है और आवश्यक user accounts तथा settings configure की जाती हैं। Exact screens distribution जैसे Ubuntu, Fedora, Debian आदि के अनुसार अलग हो सकती हैं।

Basic Requirements

  • Compatible computer/virtual machine
  • Linux installation ISO/image
  • Bootable USB/DVD या virtual ISO
  • Required disk space
  • Backup of important data
  • Stable power supply

Installation Steps

Step 1: Required Linux distribution की installation image प्राप्त करें।
Step 2: Bootable USB तैयार करें या virtual machine में ISO attach करें।
Step 3: System को installation media से boot करें।
Step 4: Language, keyboard और regional settings चुनें।
Step 5: Installation type और disk partitioning option select करें।
Step 6: User account और password create करें।
Step 7: Bootloader installation/configuration complete होने दें।
Step 8: Installation finish होने पर restart करें और installation media remove करें।
Warning: Manual partitioning करते समय गलत partition चुनने से existing data loss हो सकता है। Important data का backup पहले लेना चाहिए।

Common Linux Partitions / Mount Points

Mount PointPurpose
/Main/root filesystem।
/homeUser data और personal files के लिए।
/bootBoot-related files के लिए, setup पर depend करता है।
SwapDisk space का उपयोग memory pressure के समय virtual memory mechanism में।

9. Shell Scripting

Shell Script

Basic Shell Script

#!/bin/bash echo "Hello, Linux" echo "Welcome to Shell Scripting"

Output

Hello, Linux Welcome to Shell Scripting

Variables

#!/bin/bash name="Student" echo "Hello $name"

User Input

#!/bin/bash echo "Enter your name:" read name echo "Welcome $name"

IF-ELSE

#!/bin/bash read -p "Enter a number: " n if [ "$n" -gt 0 ] then echo "Positive number" else echo "Zero or negative number" fi

For Loop

#!/bin/bash for i in 1 2 3 4 5 do echo "Number: $i" done

Script Run करने की Basic Process

$ nano test.sh $ chmod +x test.sh $ ./test.sh
Shebang: #!/bin/bash script के लिए interpreter specify करने वाली commonly used first line है।

11. User and Group Management

Linux एक multiuser operating system है। इसलिए system में अलग-अलग users और groups बनाए जा सकते हैं। User account के साथ identity और permissions associated होती हैं, जबकि groups users को logically organize करने में सहायता करते हैं।

User Management Commands

CommandPurposeExample
whoamiCurrent user देखना।whoami
idUser और group IDs देखना।id student
useraddNew user create करना।sudo useradd student
passwdUser password set/change करना।sudo passwd student
usermodUser account modify करना।sudo usermod ...
userdelUser account delete करना।sudo userdel student

Group Management

sudo groupadd developers sudo usermod -aG developers student id student
Important: User/group management commands के लिए administrative privileges की आवश्यकता हो सकती है। Exact command options distribution पर depend कर सकते हैं।

12. Super User / Root User

Root Linux का privileged administrative account है। Root को system की बहुत सी files, services, users और configurations पर unrestricted administrative access प्राप्त होता है। इसी कारण root privileges का उपयोग carefully किया जाना चाहिए।

sudo क्या है?

sudo command authorized users को किसी command को elevated privileges के साथ execute करने की सुविधा देती है, बिना सीधे root account में login किए।

$ sudo apt update $ sudo systemctl status ssh

13. File Permissions

Linux file permissions determine करते हैं कि कौन file को read, write या execute कर सकता है। Permissions तीन main categories के लिए define होती हैं: User/Owner, Group और Others।

Permission Symbols

SymbolMeaningFile पर Meaning
rReadFile content पढ़ना
wWriteFile modify करना
xExecuteExecutable file run करना
-No permissionउस permission का access नहीं

Permission Format

-rwxr-xr-- Owner → rwx Group → r-x Others → r--

Permission Numeric Values

PermissionValue
Read (r)4
Write (w)2
Execute (x)1

इन values को जोड़कर permission numbers बनाए जाते हैं। उदाहरण के लिए rwx = 4+2+1 = 7, r-x = 4+0+1 = 5 और r-- = 4।

chmod Command

chmod file permissions change करने के लिए उपयोग किया जाता है।

$ chmod 755 script.sh # Result concept: Owner = 7 = rwx Group = 5 = r-x Others = 5 = r-x

Symbolic Permission Example

$ chmod u+x script.sh $ chmod g-w notes.txt $ chmod o+r notes.txt

Ownership Commands

$ chown student notes.txt $ chgrp developers notes.txt
Remember: chmod permissions बदलता है, chown ownership बदलता है और chgrp group ownership बदलता है।

Permissions का Practical Importance

  • Unauthorized users को files modify करने से रोकना।
  • Important system files को protect करना।
  • Shared projects में controlled access देना।
  • Executable scripts और programs के access को manage करना।
