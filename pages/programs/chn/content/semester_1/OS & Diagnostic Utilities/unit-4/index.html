1. Making and Accessing Directory from Windows Console

Windows Console से command-line interface को समझा जा सकता है, जहाँ commands type करके files, directories और system resources पर operations perform किए जाते हैं। Traditional Windows/DOS environments में यह काम DOS prompt से किया जाता था; modern Windows में Command Prompt और अन्य shells उपलब्ध हैं।

Directory क्या है?

Directory एक logical container है जिसमें files और अन्य directories को organize करके रखा जाता है। Windows में इसे सामान्यतः folder कहा जाता है। Directory structure की सहायता से files को category और hierarchy के अनुसार manage किया जा सकता है।

Directory Create करना – MD / MKDIR

C:\>MD STUDY

यह current location में STUDY नाम की directory create करता है। MKDIR भी इसी purpose के लिए उपयोग किया जा सकता है।

Directory Access करना – CD

C:\>CD STUDY C:\STUDY>

CD (Change Directory) command current directory बदलने के लिए उपयोग होती है।

Parent Directory पर जाना

C:\STUDY>CD .. C:\>

Root Directory पर जाना

C:\STUDY\NOTES>CD \

Directory की Contents देखना – DIR

C:\STUDY>DIR
C:\ │ ├── STUDY │ ├── NOTES │ ├── ASSIGNMENT │ └── PRACTICAL │ └── BACKUP └── DATA

2. Directory Operations – Step by Step

Step 1: Command Prompt / Windows Console खोलें।
Step 2: DIR command से current directory की contents देखें।
Step 3: MD STUDY से नई directory बनाएं।
Step 4: CD STUDY से नई directory में जाएँ।
Step 5: MD NOTES से subdirectory बनाएं।
Step 6: CD NOTES से subdirectory access करें।
Step 7: CD .. से parent directory में वापस आएँ।
Step 8: Empty directory हटाने के लिए traditional DOS में RD/RMDIR का उपयोग किया जा सकता है।
C:\>MD STUDY C:\>CD STUDY C:\STUDY>MD NOTES C:\STUDY>CD NOTES C:\STUDY\NOTES>CD .. C:\STUDY>DIR

3. Operations Performed on Files

File operations का अर्थ files पर किए जाने वाले basic management tasks से है। इनमें file create करना, copy करना, move करना, rename करना, display करना और delete करना प्रमुख हैं।

OperationCommand / MethodPurpose
ListDIRFiles और directories की list देखना
CopyCOPYएक location से दूसरी location पर file की copy बनाना
RenameRENFile का नाम बदलना
DeleteDELFile delete करना
DisplayTYPEText file का content देखना
AttributesATTRIBFile attributes देखना/बदलना

Examples

C:\>COPY NOTES.TXT D:\BACKUP\NOTES.TXT C:\>REN OLD.TXT NEW.TXT C:\>TYPE NOTES.TXT C:\>DEL TEMP.TXT C:\>ATTRIB NOTES.TXT
Important: Delete, format या partition-related commands का उपयोग करते समय target drive/path verify करना आवश्यक है क्योंकि गलत command से data loss हो सकता है।

4. FDISK

FDISK traditional DOS/Windows environments में hard disk की partitioning के लिए उपयोग किया जाने वाला disk utility program था। Partitioning का अर्थ physical disk को logical partitions में divide करना है, जैसे traditional systems में C:, D: आदि logical drive structures।

FDISK के प्रमुख कार्य

  • Primary partition create करना
  • Extended partition create करना
  • Logical drives create करना
  • Partition information देखना
  • Partition को active mark करना, supported configuration में
  • Existing partitions को delete करना

Traditional FDISK Workflow

1. Important data का backup लें।
2. FDISK utility start करें।
3. Existing partition information carefully check करें।
4. आवश्यकता अनुसार partition create/delete करें।
5. Required partition को active set करें, जहाँ applicable हो।
6. Changes apply करके system restart करें।
Historical Note: FDISK traditional BIOS/MBR-era partitioning environments से associated utility है। Modern Windows systems में Disk Management और अन्य tools commonly used होते हैं।

5. FORMAT Command

FORMAT command किसी disk/partition को filesystem के लिए तैयार करने के लिए उपयोग की जाती थी। Formatting में file-system structures बनाए जाते हैं ताकि storage medium पर files store और manage की जा सकें।

Basic Syntax

FORMAT drive:

Example

C:\>FORMAT A:

Traditional systems में floppy disk जैसे removable media को format करने के लिए FORMAT command commonly used थी। Modern systems में formatting tools और filesystem options environment के अनुसार अलग हो सकते हैं।

Warning: Formatting existing data को inaccessible या erased कर सकती है। इसलिए किसी drive को format करने से पहले drive letter और backup को verify करना बहुत जरूरी है।

6. DEFRAG

Disk Defragmentation का उद्देश्य fragmented files के data blocks को अधिक व्यवस्थित तरीके से arrange करना है। Traditional magnetic hard disks में repeated file creation, modification और deletion के कारण file fragments अलग-अलग disk locations पर spread हो सकते थे।

Fragmentation क्या है?

जब किसी file का data disk पर एक continuous area में न रहकर अलग-अलग locations पर fragments के रूप में store हो जाता है, तो इसे fragmentation कहा जाता है।

BEFORE DEFRAGMENTATION [File A][Free][A][File B][A][Free][B][Free][B] ↓ DEFRAG AFTER DEFRAGMENTATION [File A A A][File B B B][Free Free Free]

DEFRAG के Benefits

  • Traditional HDD पर sequential file access improve हो सकता है।
  • File fragments को व्यवस्थित करने में सहायता करता है।
  • Disk access efficiency improve हो सकती है।
Important: Defragmentation का concept mainly traditional magnetic HDDs के लिए महत्वपूर्ण है। SSDs के लिए traditional defragmentation strategy लागू नहीं करनी चाहिए; modern operating systems SSDs के लिए अलग optimization mechanisms use करते हैं।

7. SCANDISK

SCANDISK traditional DOS/Windows systems में disk और filesystem की problems detect करने के लिए उपयोग की जाने वाली utility थी। यह logical file-system errors और कुछ disk-related problems की जांच कर सकती थी।

SCANDISK के प्रमुख उद्देश्य

  • File-system errors detect करना
  • Directory structure की consistency check करना
  • Disk surface-related problems की जांच करना, supported modes में
  • कुछ errors को repair करने में सहायता करना

Example

C:\>SCANDISK
Concept: SCANDISK का मुख्य उद्देश्य disk checking and error detection था, जबकि DEFRAG का मुख्य उद्देश्य fragmentation management था।

8. EMM386 / Memory Optimization

Syllabus में दिया गया EMMAKER term traditional DOS memory-management context में commonly discussed EMM386 utility से related माना जाता है। EMM386 एक DOS memory manager था जो processor के memory-management capabilities का उपयोग करके upper memory area और expanded-memory related services उपलब्ध कराने में सहायता करता था।

Note: यदि आपके official syllabus/notes में exact utility का नाम “EMMAKER” दिया है, तो exam में वही terminology लिखें। Technical context में EMM386 एक well-known DOS memory manager था।

EMM386 का उद्देश्य

  • Expanded Memory Specification (EMS) support provide करना, configured system में।
  • Upper Memory Blocks (UMBs) का उपयोग संभव बनाना।
  • कुछ DOS components/device drivers को conventional memory से बाहर shift करने में सहायता करना।
  • Available conventional memory को applications के लिए बढ़ाने में सहायता करना।

Example CONFIG.SYS Entry

DEVICE=C:\DOS\EMM386.EXE RAM

यह traditional DOS configuration में EMM386 को load करने का एक example है। Actual syntax और options system configuration तथा DOS version पर depend कर सकते हैं।

Memory Optimization Concept

CONVENTIONAL MEMORY │ │ Move suitable drivers/components ▼ UPPER MEMORY / UMB │ ▼ More Conventional Memory available for DOS Applications

9. Understanding .INI Files in Windows

.INI का अर्थ सामान्यतः Initialization file से है। Traditional Windows applications और system components में INI files configuration information store करने के लिए widely used थीं। इनमें program startup और settings से संबंधित values रखी जा सकती थीं।

INI File का Basic Structure

एक typical INI file में sections, keys और values होते हैं। Section square brackets में लिखा जाता है और setting सामान्यतः key=value format में होती है।

[Application] Name=MyProgram Mode=Normal [Display] Width=800 Height=600 FullScreen=No

Components

Section

[Display] जैसे heading से related settings का group define होता है।

Key

Width या FullScreen जैसे setting names को key कहा जाता है।

Value

800, 600 या No जैसे data setting का value होता है।

Comment

Traditional INI formats में comments के लिए अक्सर semicolon ; का उपयोग किया जाता था, application support पर depend करता है।

INI File का Example

; Application configuration [General] Language=English AutoStart=Yes [Window] Width=1024 Height=768 Maximized=No

INI Files के Uses

  • Application settings store करना
  • Startup/configuration preferences रखना
  • Display और interface settings store करना
  • Default options define करना
  • कुछ traditional Windows components की configuration रखना
Modern Windows Note: Modern Windows applications में configuration के लिए Registry, XML, JSON, YAML और application-specific configuration systems भी commonly used होते हैं। इसलिए .INI files को मुख्यतः historical/traditional Windows configuration concept के रूप में समझना उपयोगी है।
