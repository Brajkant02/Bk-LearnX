1. Troubleshooting क्या है?

Troubleshooting computer system में आने वाली समस्या का systematic तरीके से पता लगाने, उसके possible causes को test करने और appropriate solution लागू करने की प्रक्रिया है। इसमें केवल component बदलना ही शामिल नहीं है; technician पहले symptoms observe करता है, फिर simplest और safest checks से शुरुआत करता है और धीरे-धीरे detailed diagnosis करता है।

Exam Definition: Troubleshooting वह systematic process है जिसमें computer hardware या operating system की समस्या को identify, diagnose और correct किया जाता है ताकि system normal working condition में वापस आ सके।

Troubleshooting के Objectives

  • Problem का actual cause identify करना।
  • Hardware और software fault को अलग-अलग करना।
  • Data को सुरक्षित रखते हुए fault resolve करना।
  • Unnecessary component replacement से बचना।
  • System को stable और reliable condition में वापस लाना।
  • Future में same problem repeat होने की संभावना कम करना।

Hardware Troubleshooting

RAM, CPU, motherboard, PSU, storage, display, keyboard, mouse, printer आदि physical components की problems का diagnosis।

O/S Troubleshooting

Operating system boot, drivers, updates, system files, applications, services और configuration से जुड़ी problems का diagnosis।

2. Basic Troubleshooting Method

Good troubleshooting हमेशा logical sequence में की जाती है। सबसे पहले obvious और low-risk causes check किए जाते हैं। उसके बाद ही advanced repair steps लिए जाते हैं।

Step 1 — Identify: User से symptoms पूछें और problem को clearly define करें।
Step 2 — Observe: Error message, beep, LED, unusual sound, smell, overheating या system behavior note करें।
Step 3 — Check Basics: Power, cables, connections, switches और external devices check करें।
Step 4 — Reproduce: यदि safe हो तो problem को reproduce करके conditions note करें।
Step 5 — Isolate: Hardware और software causes को अलग-अलग test करें।
Step 6 — Correct: Appropriate repair/configuration/update/part replacement करें।
Step 7 — Test: System को restart और normal workload के साथ test करें।
Step 8 — Document: Problem, cause और solution को record करें।
Golden Rule: पहले simple checks → फिर software checks → फिर component-level diagnosis। बिना diagnosis के random parts replace करना troubleshooting नहीं है।

Basic Power Check

1. Power outlet और UPS को check करें।
2. Power cable properly connected है या नहीं देखें।
3. Desktop PSU का rear switch सही position में है या नहीं देखें।
4. Internal connectors केवल power disconnected होने पर check करें।
5. System start करके POST behavior observe करें।

4. Display / Monitor Problems

Display problem में पहले यह determine करना चाहिए कि computer वास्तव में boot हो रहा है या पूरी machine ही start नहीं हो रही। Monitor का black screen होना हमेशा monitor fault का मतलब नहीं होता।

SymptomPossible CauseSolution/Check
No displayMonitor power, video cable, GPU, RAM, input sourceMonitor power/input, cable और correct display output check करें।
Display flickeringCable, refresh setting, monitor/GPU issueCable replace/test और display settings check करें।
Wrong resolutionDriver/settingsDisplay driver और recommended resolution check करें।
Artifacts/linesGPU, cable या monitorDifferent cable/display से isolate करें।
Practical Tip: No-display case में एक-एक करके monitor, cable, RAM और graphics output को isolate करना useful होता है।

5. RAM Troubleshooting

RAM fault से system boot failure, random crashes, freezes, application errors और unexpected restarts हो सकते हैं। RAM troubleshooting में physical connection और memory testing दोनों important हैं।

Step 1: System shutdown करके power disconnect करें।
Step 2: RAM modules की seating और slot condition inspect करें।
Step 3: यदि multiple modules हैं तो controlled testing से एक-एक module test करें।
Step 4: Operating system का memory diagnostic tool run करें।
Step 5: Repeated errors मिलने पर compatible replacement/test module से confirm करें।
Windows Memory Diagnostic Run dialog / Start menu: mdsched.exe
Safety: RAM को handle करने से पहले power completely disconnect करें और ESD precautions अपनाएँ।

6. HDD / SSD Troubleshooting

Storage problems के कारण slow performance, boot failure, missing files, file-system errors और data-access issues हो सकते हैं। Storage diagnosis में backup और data safety को priority देनी चाहिए।

System बहुत slowFull storage, background activity, drive health issueFree space, Task Manager और storage health check करें।
File-system errorsImproper shutdown/corruptionBackup first; suitable disk-check tools use करें।
Boot device not foundDrive detection/boot order/OS problemBIOS/UEFI boot settings और OS recovery options check करें।
:: Windows disk checking example chkdsk C: /scan :: System file check sfc /scannow
Important: यदि drive physical failure के संकेत दे रही हो या valuable data inaccessible हो, repeated repair attempts से पहले backup/data recovery priority होनी चाहिए।

7. CPU & Overheating Problems

CPU को proper cooling की आवश्यकता होती है। Overheating से system performance reduce हो सकती है, crashes/restarts हो सकते हैं और long-term hardware reliability प्रभावित हो सकती है।

Overheating के कारण

  • CPU fan failure
  • Dust-clogged heatsink/air vents
  • Poor cabinet airflow
  • Improper thermal interface
  • High ambient temperature
  • Heavy sustained workload

Overheating Troubleshooting

1. System shutdown करके cooling fans और vents inspect करें।
2. Dust buildup clean करें।
3. CPU fan और other cooling fans functioning check करें।
4. Cabinet airflow और cable arrangement improve करें।
5. Software monitoring tools से temperature behavior observe करें।
6. Persistent overheating में qualified technician से cooling assembly inspect करवाएँ।

11. Windows Diagnostic Tools & Commands

1. Task Manager

Task Manager CPU, memory, disk, network usage, running processes और startup applications की जानकारी देता है। Slow computer की initial diagnosis में यह बहुत useful है।

2. Device Manager

Device Manager hardware devices की list, driver status और device errors देखने में सहायता करता है। Yellow warning icon driver/device problem का संकेत हो सकता है।

3. Event Viewer

Windows Event Viewer system, application और security events को record करता है। Repeated errors और system failures की diagnosis में logs useful हो सकते हैं।

4. System File Checker

sfc /scannow

यह command protected Windows system files की integrity check करती है और supported cases में corrupted files को repair करने का प्रयास करती है।

5. DISM

DISM /Online /Cleanup-Image /RestoreHealth

Windows component store/image से संबंधित corruption को repair करने में सहायता कर सकता है।

6. CHKDSK

chkdsk C: /scan

File-system और disk-related issues की checking के लिए उपयोग किया जा सकता है। Repair options use करने से पहले important data backup रखना बेहतर है।

7. Safe Mode

Safe Mode Windows को limited drivers/services के साथ start करता है। यदि problem Safe Mode में नहीं आती, तो third-party driver, startup software या service के involved होने की संभावना investigate की जा सकती है।

12. Complete Troubleshooting Flowchart

USER REPORTS PROBLEM │ ▼ OBSERVE SYMPTOMS / ERROR │ ▼ IS POWER AVAILABLE? ┌────┴────┐ NO YES │ │ CHECK CHECK POST / POWER DISPLAY │ ▼ HARDWARE OR O/S? ┌─────┴─────┐ HARDWARE O/S │ │ ▼ ▼ CHECK RAM/CPU/ CHECK BOOT, STORAGE/PSU DRIVERS, FILES, DISPLAY/PORTS UPDATES, LOGS │ │ └──────┬──────┘ ▼ APPLY SAFE FIX │ ▼ TEST SYSTEM │ ┌──────┴──────┐ PASS FAIL │ │ DOCUMENT DEEPER DIAGNOSIS / SOLUTION PROFESSIONAL REPAIR

Important Troubleshooting Principles

  • Start simple: Power और cable checks पहले करें।
  • One change at a time: एक साथ कई changes न करें, वरना root cause identify करना कठिन हो सकता है।
  • Protect data: Repair से पहले important data का backup consider करें।
  • Use logs: Error messages और event logs को ignore न करें।
  • Test after repair: Fix के बाद complete functionality verify करें।
  • Document: Future reference के लिए solution record करें।
