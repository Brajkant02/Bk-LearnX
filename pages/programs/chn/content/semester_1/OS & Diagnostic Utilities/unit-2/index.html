1. Operating System – Introduction

Operating System (OS) computer system का सबसे important system software है। यह user, application programs और computer hardware के बीच एक interface के रूप में काम करता है। Computer के processor, memory, storage, input/output devices और अन्य resources को manage करने का प्रमुख कार्य operating system करता है।

जब हम किसी computer या mobile device पर कोई application चलाते हैं, file create करते हैं, keyboard से input देते हैं या printer से document print करते हैं, तो इन activities के पीछे operating system विभिन्न hardware और software resources को coordinate करता है।

Exam Definition: Operating System एक system software है जो computer hardware और user/application software के बीच interface प्रदान करता है तथा CPU, memory, files, storage और I/O devices जैसे system resources को manage करता है।

2. Operating System की Definition

Operating System को केवल एक interface मानना पर्याप्त नहीं है। यह एक resource manager और control program भी है। यह decide करता है कि कौन-सा program कब CPU का उपयोग करेगा, कितनी memory allocate होगी, files कहाँ store होंगी और input/output devices किस process को service देंगे।

Interface

OS user और applications को computer hardware के साथ interact करने का convenient environment देता है।

Resource Manager

CPU, RAM, storage और I/O devices जैसे resources का allocation और management करता है।

Control Program

System activities को control करता है और programs के execution को coordinate करता है।

System Software

Operating System application software के नीचे system level पर कार्य करता है और applications को required services देता है।

3. Need and Importance of Operating System

यदि computer में operating system न हो, तो user के लिए hardware resources को directly control करना बहुत difficult होगा। OS hardware की complexity को hide करके applications को standardized services प्रदान करता है।

  • Hardware Management: CPU, memory, storage और peripheral devices manage करता है।
  • Program Execution: Applications को load और execute करने में सहायता करता है।
  • File Management: Files और directories को organize, store और access करने की सुविधा देता है।
  • Memory Management: Processes को memory allocate और release करता है।
  • Device Management: Keyboard, mouse, display, printer, disk आदि devices के साथ communication coordinate करता है।
  • Security: Authentication, permissions और access control जैसी facilities provide कर सकता है।
  • User Interface: GUI या command-line interface के माध्यम से interaction provide करता है।
  • Error Handling: Hardware/software errors को detect और handle करने में सहायता करता है।

5. Batch Processing Operating System

Batch Processing में similar या related jobs को collect करके एक batch के रूप में process किया जाता है। User सामान्यतः हर job के execution के दौरान system के साथ continuously interact नहीं करता। Jobs को पहले submit किया जाता है और OS उन्हें निर्धारित order/policy के अनुसार execute करता है।

Working

Step 1: Users अपनी jobs/programs और required input prepare करते हैं।
Step 2: Similar jobs को एक batch में collect किया जाता है।
Step 3: Jobs को processing system में submit किया जाता है।
Step 4: OS/monitor program jobs को क्रम से execute करता है।
Step 5: Processing complete होने के बाद output/results उपलब्ध होते हैं।
Example: Large-scale payroll processing, billing या periodic report generation जैसे workloads batch-oriented processing के लिए suitable हो सकते हैं।

Advantages

  • Large number of similar jobs efficiently process हो सकती हैं।
  • Repeated jobs के लिए automation useful होता है।
  • Operator intervention कम हो सकती है।

Limitations

  • Immediate user interaction कम या unavailable होती है।
  • Output प्राप्त करने में waiting time हो सकता है।
  • एक problematic job के कारण processing flow प्रभावित हो सकता है, implementation पर depend करता है।

6. Time Sharing Operating System

Time Sharing system में CPU time को छोटे-छोटे time slices या quanta में divide करके multiple users/processes को दिया जाता है। इससे users को ऐसा अनुभव होता है कि system एक साथ सभी users के commands पर respond कर रहा है।

Time-sharing systems interactive computing के लिए designed होते हैं। OS rapid context switching के द्वारा different processes/users को CPU service देता है।

CPU │ ┌───────┼────────┐ ▼ ▼ ▼ User A User B User C │ │ │ Time 1 Time 2 Time 3 │ │ │ └───────┴────────┘ Rapid Switching

Advantages

  • Interactive response प्रदान करता है।
  • Multiple users को system resources share करने की सुविधा देता है।
  • CPU utilization improve हो सकता है।

Limitation

बहुत अधिक users/processes होने पर response time बढ़ सकता है। System को efficient scheduling और resource management की आवश्यकता होती है।

7. Real-Time Operating System (RTOS)

Real-Time Operating System ऐसा operating system है जिसे ऐसे applications के लिए design किया जाता है जहाँ tasks को specified timing constraints के भीतर execute करना महत्वपूर्ण होता है। यहाँ correctness केवल result पर नहीं बल्कि result कब उपलब्ध हुआ इस पर भी depend कर सकती है।

Types of Real-Time Systems

Hard Real-Time

Critical deadline miss होना unacceptable या potentially serious consequence वाला हो सकता है। Example: कुछ industrial control और safety-critical systems.

Soft Real-Time

Deadline important होती है लेकिन occasional delay system को necessarily fail नहीं करता। Multimedia और interactive systems में real-time characteristics मिल सकती हैं।

Characteristics

  • Predictable response time
  • Priority-based scheduling का उपयोग
  • Low and controlled latency
  • Timing constraints को importance
  • Reliable interrupt and task handling

8. Multitasking Operating System

Multitasking का अर्थ है कि operating system एक समय में multiple tasks/processes को manage और execute करता है। Single-core CPU में processes वास्तव में rapidly switch हो सकती हैं, जबकि multi-core systems में multiple tasks parallel cores पर simultaneously execute भी हो सकती हैं।

MULTITASKING │ ┌────────┼────────┐ ▼ ▼ ▼ Browser Music Editor │ │ │ └────────┼────────┘ ▼ OPERATING SYSTEM │ ▼ CPU / CPU CORES

Examples

एक user browser में webpage देख रहा हो, साथ में music चल रही हो और background में file download हो रही हो—OS इन tasks को manage करता है।

Types

  • Preemptive Multitasking: OS आवश्यकता अनुसार running process से CPU control लेकर दूसरे process को दे सकता है।
  • Cooperative Multitasking: Tasks स्वयं control relinquish करती हैं; इसका behavior implementation पर depend करता है।

9. Multiprogramming Operating System

Multiprogramming में main memory में multiple programs/jobs रखे जाते हैं ताकि CPU को idle रहने से बचाया जा सके। जब एक program I/O operation के कारण wait करता है, OS CPU को किसी दूसरे ready program को दे सकता है।

MAIN MEMORY ┌────────────────────────┐ │ Program A │ ├────────────────────────┤ │ Program B │ ├────────────────────────┤ │ Program C │ └────────────────────────┘ │ ▼ CPU │ A waits for I/O │ ▼ CPU executes Program B │ ▼ CPU utilization ↑

Main Objective

Multiprogramming का मुख्य उद्देश्य CPU utilization बढ़ाना है। CPU को idle रहने के बजाय ready queue में उपलब्ध दूसरे program को execute कराया जा सकता है।

Important Difference: Multiprogramming का primary focus CPU को busy रखना है, जबकि time sharing का primary focus interactive users/processes को responsive CPU time देना है।
