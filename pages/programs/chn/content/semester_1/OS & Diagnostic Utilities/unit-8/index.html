1. Introduction to Diagnostic Tools & PC Maintenance

Computer Diagnostics वह प्रक्रिया है जिसमें computer system में मौजूद hardware, software, operating system, storage, memory, network या security से संबंधित problems को identify, test और troubleshoot किया जाता है। Diagnostic tools technician को problem का कारण पता लगाने और suitable corrective action लेने में सहायता करते हैं।

PC Maintenance computer hardware और software को अच्छी working condition में रखने के लिए की जाने वाली नियमित activities का समूह है। इसमें cleaning, software updates, security checks, storage management, backup, hardware inspection और power protection जैसी activities शामिल होती हैं।

Diagnostic

Problem को identify और analyze करना।

Maintenance

Problem आने से पहले system को healthy condition में रखना।

Corrective Maintenance

Existing fault को repair या correct करना।

Preventive Maintenance

Future failures की संभावना कम करने के लिए regular care करना।

Exam Definition: Diagnostic Tools वे hardware या software utilities हैं जिनका उपयोग computer system की समस्या को detect, test, analyze और troubleshoot करने के लिए किया जाता है।

2. Computer Virus क्या है?

Computer Virus एक प्रकार का malicious software/code है जो किसी computer file या program के साथ जुड़कर अपनी copies बना सकता है और system में फैल सकता है। Virus सामान्यतः user की activity या किसी infected file/program को execute करने के माध्यम से सक्रिय हो सकता है।

Virus की मुख्य विशेषताएँ

  • यह malicious code होता है।
  • यह files/programs को infect कर सकता है।
  • यह अपनी copies बनाने और फैलने की क्षमता रख सकता है।
  • कुछ viruses files या system behavior को modify कर सकते हैं।
  • इसके effects हल्के performance issues से लेकर serious data loss तक हो सकते हैं।
Virus और Malware: Malware एक broad term है जिसमें virus के अलावा worms, trojans, ransomware, spyware आदि भी आते हैं। इसलिए हर malware virus नहीं होता।

3. Types of Computer Virus

Virus TypeExplanationPossible Impact
Boot Sector VirusStorage device के boot-related area को target करता है।Boot problems या startup failure हो सकता है।
File/Program VirusExecutable/program files को infect करता है।Program behavior बदल सकता है या files corrupt हो सकती हैं।
Macro VirusMacro-enabled documents के macros के माध्यम से फैल सकता है।Documents और related applications प्रभावित हो सकते हैं।
Resident VirusMemory में active रहकर files/processes को affect कर सकता है।System operations में लगातार interference हो सकता है।
Multipartite Virusएक से अधिक system areas, जैसे boot और files, को target कर सकता है।Detection और recovery अधिक कठिन हो सकती है।
Polymorphic Virusअपना code/signature बदलने की techniques use कर सकता है।Traditional signature-based detection को चुनौती दे सकता है।
Overwrite VirusInfected files के content को overwrite कर सकता है।Original file data का loss हो सकता है।

4. Effect of Virus on Computer System

Virus infection का effect system configuration, infected files और malware के behavior पर depend करता है। कुछ infections केवल performance को affect करते हैं जबकि कुछ serious data damage कर सकते हैं।

Performance

Computer unusually slow हो सकता है, applications देर से open हो सकती हैं या CPU/memory usage बढ़ सकता है।

Files

Files modify, corrupt, hide या delete हो सकती हैं।

Boot Problems

System startup में errors या boot failure हो सकता है।

Applications

Programs crash कर सकते हैं या unexpected behavior दिखा सकते हैं।

Security

Malicious software system security को कमजोर कर सकता है और unauthorized activity का risk बढ़ा सकता है।

Network

Unusual network traffic या connectivity-related behavior दिखाई दे सकता है।

Possible Warning Signs

  • Unexpected pop-ups या advertisements
  • Unknown programs/processes
  • Browser settings में unexpected changes
  • Files का अचानक disappear या rename होना
  • System का बार-बार crash होना
  • Antivirus/security settings में unexpected changes
  • Unusual CPU, memory या disk activity

5. Scanning and Antivirus Removal Tools

Antivirus Software ऐसा security software है जो malicious software को detect, block, quarantine या remove करने में सहायता करता है। Antivirus के साथ operating system updates और safe computing practices भी जरूरी हैं।

Virus Scanning के Types

ScanMeaning
Quick ScanSystem के common/important locations को comparatively जल्दी check करता है।
Full ScanSystem की अधिक व्यापक scanning करता है; इसमें अधिक time लग सकता है।
Custom ScanUser selected drive, folder या location को scan करता है।
Real-Time ProtectionFiles/programs के use/access के दौरान suspicious activity को detect/block करने में मदद करता है।
Offline Scanकुछ persistent threats के लिए operating environment से बाहर/विशेष recovery environment में scanning की सुविधा देता है।

General Antivirus Scanning Procedure

Step 1: Antivirus/security software की definitions और application को updated रखें।
Step 2: Important work save करें।
Step 3: Quick/Full/Custom scan में से appropriate option चुनें।
Step 4: Scan पूरा होने दें।
Step 5: Detected threats की details review करें।
Step 6: Recommended action—जैसे quarantine या removal—security software की guidance के अनुसार करें।
Step 7: आवश्यकता होने पर system restart करके दोबारा scan करें और affected files/recovery स्थिति verify करें।
Safety: Unknown websites से random “virus remover” utilities download करना risk पैदा कर सकता है। Security software trusted/official source से ही install/update करें।

6. Antivirus Utilities for Diagnostic

Antivirus utilities केवल infection remove करने के लिए नहीं, बल्कि security-related diagnosis में भी useful हैं। ये suspicious files/processes identify करने, scan results देखने और potentially harmful objects को quarantine करने में सहायता कर सकती हैं।

Real-Time Monitor

Running activity और accessed files को continuously monitor करने में मदद करता है।

Quarantine

Suspicious object को isolated area में रखता है ताकि वह सामान्य रूप से execute न हो।

Scan History

Previous scans और detected threats की information review करने में सहायता करता है।

Scheduled Scan

Regular security checking automatically perform करने में उपयोगी है।

Windows में Useful Diagnostic Commands

:: System File Checker sfc /scannow :: Deployment Image Servicing and Management DISM /Online /Cleanup-Image /RestoreHealth :: Check disk chkdsk

ये commands antivirus नहीं हैं। इनका उपयोग अलग-अलग system/file-system problems की diagnosis और repair में किया जाता है।

7. Safety and Preventive Maintenance Tools

Preventive maintenance का उद्देश्य system failure, overheating, data loss, security problems और unnecessary downtime की संभावना कम करना है।

Hardware Maintenance Tools

ToolUse
Compressed Air / Air BlowerDust हटाने के लिए।
Soft Anti-static BrushComponents की surface cleaning में सहायता।
Microfiber ClothExternal surfaces और displays की cleaning के लिए suitable।
Screwdriver SetPC components खोलने/fit करने में उपयोगी।
Anti-static Wrist StrapESD risk को कम करने के लिए component handling में उपयोगी।
MultimeterElectrical voltage/resistance आदि की measurement के लिए।
UPSPower interruption/voltage issues से system को protection और short backup दे सकता है।

Software Preventive Maintenance

  • Operating system और applications को updated रखें।
  • Reliable antivirus/security protection use करें।
  • Regular backups maintain करें।
  • Unused applications/files को manage करें।
  • Storage में पर्याप्त free space रखें।
  • Important data को केवल एक location पर depend न रखें।
  • Unknown links, attachments और unauthorized software से बचें।
ESD Safety: PC खोलने से पहले power disconnect करें और components handle करते समय electrostatic discharge से protection रखें।

8. Data Recovery

Data Recovery damaged, deleted, corrupted या inaccessible storage से data को वापस प्राप्त करने की प्रक्रिया है। Recovery की सफलता इस बात पर depend करती है कि data किस कारण से lost हुआ और storage device की physical/logical condition क्या है।

Data Loss के Common Causes

  • Accidental deletion
  • Formatting
  • File-system corruption
  • Storage device failure
  • Malware/ransomware
  • Power failure या improper shutdown
  • Physical damage

Basic Data Recovery Procedure

Step 1: Data loss notice होते ही unnecessary writes को minimize करें, खासकर यदि deleted files recover करनी हों।
Step 2: Check Recycle Bin/Trash और available backups।
Step 3: Backup से restore करने की संभावना check करें।
Step 4: Logical issue होने पर suitable recovery utility का उपयोग करें।
Step 5: Recovered data को उसी failed/source drive पर save न करें।
Step 6: Physical failure होने पर professional data-recovery service की आवश्यकता हो सकती है।
Important: गंभीर physical disk failure में drive को बार-बार खोलना, repair करना या experimental actions करना recovery को और कठिन बना सकता है।

9. PC Care and Maintenance

Daily / Regular Care

Clean Environment

PC को dust, moisture और excessive heat से दूर रखें।

Airflow

Air vents और cooling fans को blocked न होने दें।

Software Updates

OS और applications के security/maintenance updates install करें।

Backup

Important documents और project data की regular backup copy रखें।

PC Cleaning Procedure

1. Computer shut down करें और power cable disconnect करें।
2. External cables और peripherals को safely disconnect करें।
3. Ventilation openings और external surfaces clean करें।
4. Internal cleaning की आवश्यकता हो तो proper ESD precautions अपनाएँ।
5. Fans/vents में excessive dust जमा न होने दें।
6. Components properly reconnect करके system test करें।

Maintenance Checklist

AreaCheck
HardwareDust, cables, fans, overheating और physical damage।
StorageFree space, health indicators और backup availability।
SecurityAntivirus status, updates और suspicious activity।
OSUpdates, errors और startup behavior।
PowerUPS, surge protection, cables और stable power।
BackupRecent backup और restore test।

10. Electrical Power Issues

Electrical power problems computer hardware को unstable बना सकते हैं और कुछ परिस्थितियों में components को damage भी कर सकते हैं। इसलिए stable power और appropriate protection important है।

Power IssueMeaning / EffectPreventive Measure
Power FailureSupply पूरी तरह चली जाना; unsaved data loss हो सकता है।UPS और regular backup।
Voltage SagVoltage का short period के लिए कम होना।Suitable UPS/power conditioning।
SurgeVoltage का अचानक बढ़ जाना।Surge protection और suitable UPS।
Spikeबहुत short duration का high-voltage event।Surge protection।
BrownoutVoltage का relatively लंबे समय तक lower level पर रहना।UPS/regulated power।
OverheatingPower/cooling problems के साथ component temperature बढ़ सकता है।Proper ventilation और cooling maintenance।

UPS का उपयोग

UPS (Uninterruptible Power Supply) computer को power interruption के दौरान limited backup power प्रदान करता है और कुछ models power-quality fluctuations से भी protection देते हैं। इससे user को system safely shut down करने या short interruption handle करने का समय मिल सकता है।

Electrical Safety: PSU या mains electrical circuitry को खोलकर repair करने का काम trained technician द्वारा appropriate safety procedures के साथ किया जाना चाहिए। केवल software-level troubleshooting के आधार पर live electrical components को touch न करें।
