1. BIOS – Introduction

BIOS का full form Basic Input/Output System है। Traditional PC architecture में BIOS motherboard पर stored firmware होता है जो computer को power-on होने के बाद शुरुआती hardware initialization और boot process शुरू करने में सहायता करता है।

BIOS computer के hardware और operating system के बीच शुरुआती software-level interface की भूमिका निभाता है। यह processor, memory, storage और basic input/output devices जैसी hardware components को initialize और check करने में सहायता करता है तथा available boot device से operating system loader को शुरू करने की प्रक्रिया initiate करता है।

Exam Definition: BIOS एक firmware program है जो computer start होने पर basic hardware initialization करता है, POST run करता है और boot device से operating system को load करने की प्रक्रिया शुरू करता है।

BIOS कहाँ Stored होता है?

Traditional systems में BIOS firmware motherboard पर non-volatile memory chip में stored रहता है, इसलिए computer बंद होने पर भी firmware information बनी रहती है। Modern PCs में traditional BIOS की जगह अक्सर UEFI firmware उपयोग होता है, लेकिन basic startup/firmware initialization concepts को समझने के लिए BIOS terminology अभी भी commonly पढ़ाई जाती है।

2. Functions of BIOS

1. Hardware Initialization

Power-on के बाद essential hardware components को initialize करने में सहायता करता है।

2. POST

Power-On Self-Test शुरू करता है ताकि basic hardware की startup condition check की जा सके।

3. Boot Support

Bootable device खोजने और operating system loader को start करने की प्रक्रिया में सहायता करता है।

4. BIOS Setup

System configuration settings जैसे boot order और hardware-related options को configure करने का interface provide कर सकता है।

5. Basic I/O Services

Traditional BIOS environment में basic input/output services उपलब्ध कराता है।

6. Error Reporting

Startup hardware problems की स्थिति में screen messages, beep patterns या अन्य diagnostic indicators के माध्यम से information दे सकता है।

3. POST – Power-On Self-Test

POST का full form Power-On Self-Test है। यह startup के दौरान firmware द्वारा performed diagnostic checks का एक sequence है। इसका उद्देश्य यह verify करना है कि computer के आवश्यक hardware components initialization के लिए पर्याप्त रूप से available और functional हैं।

POST में memory, processor-related initialization, display initialization और अन्य essential hardware checks शामिल हो सकते हैं। Exact tests system firmware और motherboard manufacturer के अनुसार अलग हो सकते हैं।

Simple Meaning: POST को ऐसे समझ सकते हैं जैसे computer start होते समय अपना basic hardware check करता है और problem मिलने पर diagnostic signal देता है।

4. POST Process – Step by Step

Step 1 – Power ON: Computer को power मिलती है और processor startup/reset state से firmware execution शुरू करता है।
Step 2 – Firmware Execution: BIOS/UEFI firmware का startup code execute होता है।
Step 3 – CPU Initialization: Processor और जरूरी system-level initialization perform होता है।
Step 4 – Memory Check: System memory को initialize/check किया जाता है।
Step 5 – Basic Hardware Detection: Display, keyboard, storage/controller और अन्य required hardware components detect/initialize किए जा सकते हैं।
Step 6 – Error Reporting: यदि critical problem मिलती है तो firmware diagnostic message, beep pattern या code के माध्यम से संकेत दे सकता है।
Step 7 – Boot Device Selection: यदि POST/startup checks सफल हों, firmware configured boot order के अनुसार bootable device खोजता है।
Step 8 – Operating System Start: Bootloader/OS startup process को control transfer किया जाता है।

5. POST Error Codes

POST error reporting के कई forms हो सकते हैं। System के firmware implementation के अनुसार errors को screen messages, numeric/hexadecimal POST codes, beep patterns, diagnostic LEDs या motherboard displays के द्वारा report किया जा सकता है।

POST Code क्या है?

POST code एक diagnostic value है जो startup के दौरान firmware द्वारा किसी particular initialization/test stage को indicate कर सकती है। कुछ motherboards पर dedicated two-digit या multi-digit diagnostic display के माध्यम से code दिखाई देता है।

Important: POST codes universal नहीं होते। एक ही code का अर्थ अलग BIOS/UEFI firmware, motherboard manufacturer या diagnostic implementation में अलग हो सकता है। इसलिए exact interpretation के लिए motherboard/firmware manual को प्राथमिक reference माना जाना चाहिए।

Common Diagnostic Categories

Symptom / CategoryPossible Area to Check
Memory initialization failureRAM module seating, compatible memory, memory slot और motherboard.
Display initialization failureGraphics card, display connection, GPU seating और display hardware.
CPU initialization problemProcessor seating, power connection, CPU compatibility और motherboard.
Keyboard/Input initialization problemKeyboard connection, port/device और firmware settings.
Storage/Boot device problemDrive connection, storage device, boot order और bootable media.
Firmware/CMOS configuration issueFirmware settings, CMOS-related configuration और supported reset procedure.

6. POST Beep Codes

कुछ systems में display successfully initialize होने से पहले भी firmware speaker/buzzer के माध्यम से beep pattern दे सकता है। Beep pattern को सुनकर technician hardware problem की category identify करने का प्रयास कर सकता है।

Beep PatternInterpretationTypical Area to Check
Single short beepकई traditional PC systems में successful POST का indication हो सकता है।यदि system normally boots, सामान्य startup माना जा सकता है।
Repeated beepsHardware initialization problem का संकेत हो सकता है।RAM, power या motherboard documentation check करें।
Continuous beepHardware fault का संकेत हो सकता है; exact meaning firmware-specific है।RAM, power, motherboard और component seating check करें।
Long/short combinationSpecific hardware diagnostic condition indicate कर सकती है।Motherboard/BIOS manual के beep-code table से exact meaning देखें।
Note: ऊपर दिए गए patterns केवल general interpretation हैं। Beep codes को universal मानना सही नहीं है। Exact beep-code meaning motherboard के BIOS/UEFI vendor और model पर depend करता है।

7. Error Code Interpretation

POST error code की interpretation करते समय केवल code को देखकर component replace नहीं करना चाहिए। पहले यह identify करना जरूरी है कि code किस firmware और motherboard model से संबंधित है।

Step 1: Motherboard का manufacturer और exact model identify करें।
Step 2: BIOS/UEFI manufacturer और firmware version check करें, यदि available हो।
Step 3: Motherboard manual में दिए गए POST code/beep-code table को देखें।
Step 4: Code किस startup stage से related है, यह identify करें।
Step 5: Related hardware connections और component seating check करें।
Step 6: Minimal hardware configuration के साथ startup test किया जा सकता है, यदि technician procedure इसकी अनुमति देता हो।
Step 7: समस्या isolate होने के बाद manufacturer-recommended repair/replacement procedure follow करें।

8. Basic POST Troubleshooting

RAM Problem

System power off करके RAM modules की proper seating और supported configuration check करें।

Display Problem

Monitor connection, display cable और graphics hardware की seating check करें।

Power Problem

Power supply connections और motherboard/CPU power connectors की स्थिति check करें।

Boot Device Problem

Storage drive connection, boot order और bootable device की availability check करें।

CMOS/Firmware Settings

Incorrect firmware settings की स्थिति में manufacturer-supported default/reset procedure उपयोग किया जा सकता है।

Motherboard Diagnostic LEDs

यदि motherboard पर CPU/DRAM/VGA/BOOT जैसी diagnostic LEDs उपलब्ध हों, तो उनकी indication को manual के अनुसार interpret करें।

Safety: Hardware reseating या internal inspection से पहले computer को completely power off करें और appropriate electrical/static precautions follow करें।
