1. Introduction to Network Media and Connectors

Computer network में दो या दो से अधिक devices के बीच data transfer करने के लिए communication path की आवश्यकता होती है। इस communication path को Transmission Media कहा जाता है। Network media data को electrical signals, light signals या wireless radio signals के रूप में एक location से दूसरी location तक carry कर सकता है।

इस unit में मुख्यतः wired LAN media का अध्ययन किया जाता है, जैसे UTP, STP, Coaxial Cable और Optical Fibre। इनके साथ cable termination, connectors, jacks और patch panels भी network installation का महत्वपूर्ण हिस्सा हैं।

Exam Definition: Transmission Media वह physical path या communication channel है जिसके माध्यम से network में data signals एक device से दूसरे device तक travel करते हैं।

Network Media की आवश्यकता

  • Network devices के बीच communication path उपलब्ध कराना।
  • Data signals को source से destination तक carry करना।
  • LAN infrastructure को establish करना।
  • Reliable और organized cabling प्रदान करना।
  • Network expansion और structured cabling में सहायता करना।

3. UTP – Unshielded Twisted Pair

UTP (Unshielded Twisted Pair) cable में insulated copper conductors के pairs को आपस में twist किया जाता है। प्रत्येक pair की twisting unwanted electromagnetic interference और crosstalk को कम करने में मदद करती है। इसमें individual metallic shield नहीं होता, इसलिए इसे unshielded twisted pair कहा जाता है।

UTP की Construction

UTP CABLE ┌─────────────────────────────────────┐ │ Outer Jacket │ │ ┌──── Pair 1 ────┐ │ │ ├──── Pair 2 ────┤ │ │ ├──── Pair 3 ────┤ │ │ └──── Pair 4 ────┘ │ │ Twisted Copper Conductors │ └─────────────────────────────────────┘

UTP के Advantages

  • Generally inexpensive और widely available।
  • Installation और termination relatively आसान।
  • LAN/Ethernet cabling में extensively used।
  • Lightweight और flexible होने के कारण cable management आसान।
  • Suitable category के अनुसार different network speeds support कर सकता है।

UTP के Limitations

  • External electromagnetic interference से protection shielded cable की तुलना में कम होता है।
  • Maximum supported distance और performance cable category तथा network standard पर depend करती है।
  • Improper termination से crosstalk और connectivity problems हो सकती हैं।
Full Form: UTP = Unshielded Twisted Pair

4. STP – Shielded Twisted Pair

STP (Shielded Twisted Pair) twisted-pair copper cable का shielded form है। इसमें conductive shielding का उपयोग external electromagnetic interference को reduce करने के लिए किया जाता है। Shield की exact construction cable type के अनुसार अलग हो सकती है।

STP CABLE ┌──────────────────────────────────────┐ │ Outer Jacket │ │ ┌──────────────────────────────────┐ │ │ │ Metallic Shield │ │ │ │ Twisted Copper Pairs │ │ │ │ Pair 1 Pair 2 Pair 3 Pair4│ │ │ └──────────────────────────────────┘ │ └──────────────────────────────────────┘

STP के Advantages

  • Shielding के कारण EMI/noise से protection बेहतर हो सकती है।
  • Electrically noisy environments में useful हो सकता है।
  • Twisted-pair construction के साथ interference reduction में सहायता करता है।

STP के Disadvantages

  • UTP की तुलना में generally अधिक costly हो सकता है।
  • Cable installation और termination comparatively more demanding हो सकती है।
  • Shielding को correctly implement/ground करना आवश्यक हो सकता है, depending on cable system.
Full Form: STP = Shielded Twisted Pair

5. Coaxial Cable

Coaxial Cable एक copper-based cable है जिसमें central conductor के चारों ओर insulating dielectric, metallic shielding और outer protective jacket होती है। इसका नाम “coaxial” इसलिए है क्योंकि central conductor और shield एक common axis share करते हैं।

COAXIAL CABLE CROSS-SECTION ┌──────────────────────────┐ │ Outer Jacket │ │ ┌────────────────────┐ │ │ │ Metallic Shield │ │ │ │ ┌────────────────┐ │ │ │ │ │ Dielectric │ │ │ │ │ │ ┌──────┐ │ │ │ │ │ │ │Core │ │ │ │ │ │ │ └──────┘ │ │ │ │ │ └────────────────┘ │ │ │ └────────────────────┘ │ └──────────────────────────┘

Coaxial Cable के Components

  1. Central Conductor: Electrical signal carry करता है।
  2. Dielectric Insulator: Conductor और shield को electrically separate रखता है।
  3. Metallic Shield: Interference reduction और return path में भूमिका निभा सकता है।
  4. Outer Jacket: Cable को physical protection देता है।

Advantages

  • Shielding के कारण interference resistance अच्छी हो सकती है।
  • Strong construction।
  • Different communication applications में historically widely used रहा है।

Limitations

  • Modern structured Ethernet LANs में twisted-pair और fibre का उपयोग अधिक common है।
  • Termination के लिए suitable coaxial connectors की आवश्यकता होती है।

6. Optical Fibre

Optical Fibre एक transmission medium है जिसमें data electrical signal की जगह light pulses के रूप में transmit किया जाता है। Fibre का मुख्य transmission region core होता है और उसके चारों ओर lower-refractive-index cladding होती है। Protective coating/jacket fibre को mechanical protection देती है।

OPTICAL FIBRE ┌──────────────────────────────────────────┐ │ Protective Jacket │ │ ┌────────────────────────────────────┐ │ │ │ Cladding │ │ │ │ ┌────────────────────────────┐ │ │ │ │ │ Core │ │ │ │ │ │ LIGHT ───────────────► │ │ │ │ │ └────────────────────────────┘ │ │ │ └────────────────────────────────────┘ │ └──────────────────────────────────────────┘

Working Principle

Optical fibre में information को light signals में convert करके fibre core के through transmit किया जाता है। Core और cladding की optical properties light को fibre के अंदर guide करने में सहायता करती हैं। Receiver side पर optical signal को वापस electrical/data representation में convert किया जाता है।

Optical Fibre के Advantages

  • High bandwidth capability।
  • Long-distance communication के लिए highly suitable।
  • Electromagnetic interference से immune होता है क्योंकि transmission light से होता है।
  • Electrical isolation प्रदान करता है।
  • High-speed backbone और inter-building links में useful।

Limitations

  • Installation और splicing के लिए specialized tools/skills की आवश्यकता हो सकती है।
  • Fibre handling में bending और physical damage से बचना आवश्यक है।
  • Transceivers/connectors की आवश्यकता होती है।
Key Point: Optical Fibre में data light के रूप में travel करता है, electrical current के रूप में नहीं।

7. TIA/EIA Standards

TIA/EIA telecommunications और cabling standards से जुड़ा terminology है। Structured cabling में standards का उद्देश्य consistent cabling design, component performance, termination और installation practices के लिए guidelines उपलब्ध कराना है।

Ethernet twisted-pair cabling में commonly referenced wiring schemes T568A और T568B हैं। ये RJ-45/8P8C style termination में conductor positions का color order define करते हैं।

T568A Color Order

Pin 1 → White/Green Pin 2 → Green Pin 3 → White/Orange Pin 4 → Blue Pin 5 → White/Blue Pin 6 → Orange Pin 7 → White/Brown Pin 8 → Brown

T568B Color Order

Pin 1 → White/Orange Pin 2 → Orange Pin 3 → White/Green Pin 4 → Blue Pin 5 → White/Blue Pin 6 → Green Pin 7 → White/Brown Pin 8 → Brown
Exam Tip: T568A और T568B में मुख्य difference orange और green pairs की position में है। Blue और brown pairs की positions same रहती हैं।

Basic Cable Making Procedure

Step 1: Required cable length measure करके cable cut करें।
Step 2: Outer jacket को carefully strip करें।
Step 3: Twisted pairs को separate करें और conductor sequence arrange करें।
Step 4: Selected T568A या T568B wiring scheme के अनुसार wires arrange करें।
Step 5: Conductors को equal length में trim करें।
Step 6: Wires को RJ-45/8P8C plug में correct order और full insertion के साथ place करें।
Step 7: Crimping tool से plug terminate करें।
Step 8: Cable के दूसरे end को required wiring type के अनुसार terminate करें।
Step 9: Cable tester से continuity और pin mapping verify करें।

9. Straight-through Cable

Straight-through cable में दोनों ends पर same wiring standard लगाया जाता है। उदाहरण के लिए T568B–T568B या T568A–T568A।

STRAIGHT-THROUGH End A: T568B End B: T568B 1 W/O ─────────────── W/O 1 2 O ─────────────── O 2 3 W/G ─────────────── W/G 3 4 B ─────────────── B 4 5 W/B ─────────────── W/B 5 6 G ─────────────── G 6 7 W/Br─────────────── W/Br 7 8 Br ─────────────── Br 8

Use

Traditional Ethernet teaching examples में straight-through cable को different device types, जैसे computer-to-switch, connect करने के लिए बताया जाता है। Modern Ethernet equipment में auto-negotiation/auto-MDI-X के कारण कई devices cable type को automatically accommodate कर सकते हैं।

Rule: Straight-through = Same standard on both ends.

10. Crossover Cable

Crossover cable में एक end पर T568A और दूसरे end पर T568B wiring scheme लगाई जाती है। इससे relevant transmit और receive pairs cross होते हैं।

CROSSOVER End A: T568A End B: T568B 1 W/G ─────────────── W/O 1 2 G ─────────────── O 2 3 W/O ─────────────── W/G 3 4 B ─────────────── B 4 5 W/B ─────────────── W/B 5 6 O ─────────────── G 6 7 W/Br─────────────── W/Br 7 8 Br ─────────────── Br 8

Traditional Use

Traditional Ethernet implementations में crossover cables similar device types को directly connect करने के लिए use किए जाते थे, जैसे computer-to-computer या switch-to-switch। लेकिन modern network interfaces में Auto-MDI/MDI-X support होने के कारण dedicated crossover cable की आवश्यकता कई situations में नहीं रहती।

Rule: Crossover = T568A on one end + T568B on the other end.

11. Cable Testing

Cable testing का उद्देश्य यह verify करना है कि cable सही तरीके से terminated है और सभी conductors सही pin mapping के साथ connected हैं।

Cable Tester से Basic Testing

Step 1: Cable के दोनों ends को tester के main और remote units में connect करें।
Step 2: Tester को power on करें।
Step 3: LED/display sequence observe करें।
Step 4: Pin-to-pin continuity और correct pair mapping verify करें।
Step 5: Open, short, miswire या crossed pair indication हो तो termination दोबारा check करें।
FaultMeaning
Openकिसी conductor में electrical continuity नहीं है।
Shortदो conductors unintended तरीके से electrically connected हैं।
MiswireConductor गलत pin पर terminated है।
Reversed Pair / Pair Mapping IssuePair arrangement expected wiring से match नहीं करता।
CorrectExpected pin mapping और continuity प्राप्त होती है।

Network Jack / Keystone Jack

Network jack एक fixed termination point होता है जहाँ horizontal cable terminate की जाती है और patch cable के माध्यम से end device या patch panel से connection बनाया जाता है। Structured cabling में keystone-style jacks common हैं।

13. Patch Panels

Patch Panel structured cabling system में एक centralized termination और cable-management component है। Building/office की permanent network cables को patch panel के rear side पर terminate किया जा सकता है और front side से short patch cords के माध्यम से switch या अन्य networking equipment से connections किए जाते हैं।

PERMANENT CABLING │ ▼ ┌──────────────────┐ │ PATCH PANEL │ │ 01 02 03 04 ... │ └──────────────────┘ │ │ │ │ Patch Cords │ │ │ │ ▼ ▼ ▼ ▼ ┌──────────────────┐ │ SWITCH │ └──────────────────┘

Patch Panel के Advantages

  • Cabling को organized और structured रखने में सहायता।
  • Network changes और troubleshooting को easier बनाता है।
  • Permanent cable और active network equipment के बीच manageable interface देता है।
  • Cable labeling और port identification को आसान बनाता है।
  • Rack-based network installations में cable management improve करता है।

Patch Panel का Basic Working

1. Room/outlet से आने वाली permanent cable patch panel के पीछे terminate होती है।
2. Front ports को labels दिए जाते हैं।
3. Short patch cable से required patch-panel port को switch port से connect किया जाता है।
4. आवश्यकता के अनुसार patch cord बदलकर logical connection बदला जा सकता है, बिना permanent cable को दोबारा terminate किए।
