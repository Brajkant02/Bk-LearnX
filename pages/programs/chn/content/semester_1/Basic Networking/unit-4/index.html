1. Network Model का Introduction

Computer network में अलग-अलग computers, servers, mobile devices और networking devices को आपस में communicate करना होता है। यदि communication के लिए कोई common structure या standard approach न हो, तो अलग-अलग manufacturers और technologies के devices के बीच communication difficult हो सकता है। इसी समस्या को व्यवस्थित करने के लिए Network Models का उपयोग किया जाता है।

Network model communication process को अलग-अलग layers में divide करता है। प्रत्येक layer का अपना specific काम होता है और वह ऊपर तथा नीचे वाली layer के साथ interaction करती है। Layered approach से networking concepts को समझना, design करना, troubleshoot करना और standardize करना आसान होता है।

Definition: Network Model एक conceptual framework है जो network communication की विभिन्न activities और functions को अलग-अलग layers में व्यवस्थित करता है।

इस Chapter के मुख्य Models

OSI Model

Open Systems Interconnection model में 7 layers होती हैं। यह networking concepts को समझने और standardize करने के लिए reference model के रूप में बहुत महत्वपूर्ण है।

TCP/IP Model

Internet communication में widely used protocol architecture है। इसमें commonly 4 layers का model बताया जाता है।

2. OSI Model – Open Systems Interconnection

OSI (Open Systems Interconnection) model को networking communication को सात अलग-अलग layers में समझाने के लिए बनाया गया था। प्रत्येक layer communication process के एक specific aspect को handle करती है। OSI model को एक reference model के रूप में समझना सबसे उचित है; यह स्वयं Internet पर चलने वाला single protocol नहीं है।

OSI की 7 Layers

┌─────────────────────────┐ 7 │ APPLICATION │ ├─────────────────────────┤ 6 │ PRESENTATION │ ├─────────────────────────┤ 5 │ SESSION │ ├─────────────────────────┤ 4 │ TRANSPORT │ ├─────────────────────────┤ 3 │ NETWORK │ ├─────────────────────────┤ 2 │ DATA LINK │ ├─────────────────────────┤ 1 │ PHYSICAL │ └─────────────────────────┘ Data Flow: Application → Presentation → Session → Transport → Network → Data Link → Physical
Memory Trick: ऊपर से नीचे: All People Seem To Need Data Processing — Application, Presentation, Session, Transport, Network, Data Link, Physical.

7Application Layer

Application Layer OSI model की सबसे ऊपर वाली layer है। यह network services के सबसे करीब होती है और applications को network communication के लिए required services उपलब्ध कराती है। यह सीधे user application को network से connect करने वाली layer के रूप में समझी जाती है, हालांकि actual application स्वयं layer का हिस्सा नहीं होती।

मुख्य कार्य

  • Network services को applications के लिए उपलब्ध कराना।
  • Network resource या remote service access में सहायता करना।
  • Web, email, file transfer और name/service related communication के लिए application-level protocols provide करना।
  • User-level network communication के लिए interface प्रदान करना।

Examples

HTTP/HTTPS, FTP, SMTP, DNS आदि application-level protocols के examples हैं।

Exam Point: Application Layer user-facing network services से सबसे अधिक संबंधित OSI layer है।

6Presentation Layer

Presentation Layer का काम data को एक suitable format में represent करना है ताकि sender और receiver systems data को सही तरीके से interpret कर सकें। इसे data representation, translation और formatting से associated layer माना जाता है।

मुख्य कार्य

  • Data format/translation में सहायता।
  • Character encoding और data representation का handling।
  • Encryption और decryption जैसे presentation-related functions की conceptual responsibility।
  • Compression और decompression में सहायता।

उदाहरण के लिए अलग-अलग systems में character representation या data encoding अलग हो सकती है; presentation functions communication के लिए compatible representation में सहायता करते हैं।

5Session Layer

Session Layer दो communicating applications के बीच session को establish, manage और terminate करने की concept से संबंधित है। यह communication dialog को organize करने और session के दौरान synchronization में सहायता करती है।

मुख्य कार्य

  • Session establishment.
  • Session management.
  • Session termination.
  • Dialog control में सहायता।
  • Long communication में synchronization/checkpointing की conceptual सुविधा।
Easy Meaning: Session Layer को याद रखें — “Communication session को start, manage और end करना.”

4Transport Layer

Transport Layer end-to-end communication के लिए responsible होती है। यह source application से destination application तक data delivery के लिए transport services provide करती है। यह reliability, flow control और segmentation जैसे functions की concept से जुड़ी है।

मुख्य कार्य

  • Data को smaller segments में divide करना।
  • Destination पर data reassembly में सहायता।
  • End-to-end delivery।
  • Flow control।
  • Reliable delivery के लिए error recovery mechanisms, protocol पर depend करते हुए।
  • Port numbers के माध्यम से applications/processes की पहचान।

Important Protocols

ProtocolBasic Characteristic
TCPConnection-oriented, reliable and ordered transport service प्रदान करता है।
UDPConnectionless, lightweight datagram transport service प्रदान करता है; reliability application पर depend कर सकती है।
PDU: Transport layer पर commonly Segment (TCP) या Datagram (UDP) terminology का उपयोग किया जाता है।

3Network Layer

Network Layer logical addressing और routing से संबंधित है। यह packets को source network से destination network तक पहुँचाने के लिए route selection और forwarding की concept provide करती है।

मुख्य कार्य

  • Logical addressing, जैसे IP addressing।
  • Routing और path selection।
  • Packets को different networks के बीच forward करना।
  • Internetwork communication में सहायता।

Important Device

Router Network Layer का प्रमुख example है। यह destination IP address और routing information का उपयोग करके packet forwarding करता है।

PDU: Network Layer पर data को सामान्यतः Packet कहा जाता है।

2Data Link Layer

Data Link Layer directly connected network nodes के बीच reliable frame delivery के लिए functions provide करती है। यह physical medium पर transmitted bits को frames में organize करती है और local network communication में addressing तथा error detection जैसी facilities देती है।

मुख्य कार्य

  • Framing.
  • MAC addressing.
  • Error detection.
  • Medium access control.
  • Local link पर frame delivery में सहायता।

Sub-layers

IEEE 802 networking context में Data Link Layer को commonly दो sublayers में describe किया जाता है:

LLC – Logical Link Control
Logical link control से संबंधित functions provide करता है।
MAC – Media Access Control
Media access और MAC addressing से संबंधित functions handle करता है।

Switch और Bridge को सामान्यतः Data Link Layer devices के examples के रूप में पढ़ाया जाता है।

PDU: Data Link Layer पर data को Frame कहा जाता है।

1Physical Layer

Physical Layer OSI model की सबसे नीचे वाली layer है। यह raw bits को physical medium के माध्यम से transmit करने से संबंधित है। इसमें electrical, optical या radio signals और physical characteristics शामिल होते हैं।

मुख्य कार्य

  • Bits का physical transmission।
  • Electrical/optical/radio signaling।
  • Cables, connectors और interfaces की physical characteristics।
  • Data rate और signal characteristics से संबंधित specifications।
  • Physical network topology के implementation में सहायता।

Examples

Twisted-pair cable, coaxial cable, optical fibre, connectors और physical signaling technologies Physical Layer concepts से associated हैं।

PDU: Physical Layer पर data को Bits के रूप में देखा जाता है।

3. TCP/IP Model

TCP/IP (Transmission Control Protocol/Internet Protocol) architecture Internet और interconnected networks की communication technologies का foundation है। TCP/IP model को commonly 4-layer model के रूप में पढ़ाया जाता है। कुछ books में इसकी layers को अलग naming या 5-layer teaching model के साथ भी दिखाया जाता है, लेकिन इस syllabus में OSI से comparison के लिए 4-layer TCP/IP model उपयोगी है।

TCP/IP MODEL ┌─────────────────────────┐ │ 4. APPLICATION │ ├─────────────────────────┤ │ 3. TRANSPORT │ ├─────────────────────────┤ │ 2. INTERNET │ ├─────────────────────────┤ │ 1. NETWORK ACCESS │ └─────────────────────────┘

TCP/IP की Layers

4. Application Layer

यह OSI की Application, Presentation और Session layers के functions को broadly cover करती है। HTTP/HTTPS, DNS, FTP, SMTP जैसे application-level protocols इसी broad layer में रखे जाते हैं।

3. Transport Layer

End-to-end process communication provide करती है। TCP और UDP इसके प्रमुख protocols हैं।

2. Internet Layer

Logical addressing, packet forwarding और routing से संबंधित है। IP इसका मुख्य protocol family member है। ICMP भी Internet-layer functions से associated है।

1. Network Access Layer

Local network communication और physical transmission से संबंधित functions को cover करती है। यह OSI की Data Link और Physical layers के functions को broadly combine करती है। Ethernet और Wi-Fi जैसी technologies इस level पर relevant हैं।

TCP/IP Memory Trick: Application → Transport → Internet → Network Access

मुख्य Similarities

  • दोनों layered architecture का उपयोग करते हैं।
  • दोनों communication functions को अलग-अलग responsibilities में divide करते हैं।
  • दोनों में Transport और Network/Internet related layers मौजूद हैं।
  • दोनों network communication को समझने और organize करने में सहायता करते हैं।

मुख्य Differences

  • OSI में 7 layers हैं, जबकि common TCP/IP model में 4 layers हैं।
  • OSI में Presentation और Session अलग layers हैं; TCP/IP में ये functions Application layer में broadly शामिल होते हैं।
  • OSI में Data Link और Physical अलग layers हैं; TCP/IP में इन्हें Network Access layer में broadly combine किया जाता है।
  • TCP/IP practical Internet protocols के साथ directly associated architecture है, जबकि OSI मुख्यतः reference model के रूप में उपयोगी है।

5. Data Encapsulation और Decapsulation

जब sender computer application data भेजता है, data नीचे की ओर layers से गुजरते समय प्रत्येक relevant layer पर control information जोड़ सकता है। इस process को Encapsulation कहते हैं। Receiver side पर reverse process होता है, जिसे Decapsulation कहा जाता है।
