3. Networking Devices

NIC • Repeater • Hub • Bridge • Switch • Router

1. Introduction to Networking Devices

Computer network में केवल cables या wireless media ही पर्याप्त नहीं होते। Different devices को connect करने, signals को regenerate करने, frames को forward करने, network segments को separate करने और different networks के बीच packets को route करने के लिए Networking Devices का उपयोग किया जाता है।

Networking device का काम उसके operating layer, addressing method और forwarding technique पर depend करता है। उदाहरण के लिए NIC किसी computer को network से जोड़ता है, Repeater signal को regenerate करता है, Hub incoming signal को multiple ports पर repeat करता है, Bridge network segments को MAC address के आधार पर connect/filter करता है, Switch frames को specific port की ओर forward करता है और Router different IP networks के बीच packets को route करता है।

Definition: Networking Devices वे hardware components हैं जो computers, network segments या different networks के बीच communication को establish, control, extend या manage करने में सहायता करते हैं।
Typical Network PC ── NIC ── Switch ── Router ── Internet │ ├── PC ├── Printer └── Access/Other Network

2. NIC – Network Interface Card

NIC (Network Interface Card) एक hardware interface है जो computer या अन्य host device को network medium से connect करता है। NIC motherboard में integrated हो सकता है या expansion/adapter के रूप में लगाया जा सकता है। Wired Ethernet NIC cable के माध्यम से network से जुड़ता है, जबकि wireless NIC radio communication का उपयोग कर सकता है।

NIC के मुख्य कार्य

  • Computer को network connectivity प्रदान करना।
  • Data को network transmission के suitable signals/frames में interface करना।
  • Ethernet जैसे LAN technologies के साथ communication करना।
  • MAC address के माध्यम से network interface की पहचान में सहायता करना।
  • Frame transmission और reception में सहायता करना।
  • Network driver/software के साथ hardware communication उपलब्ध कराना।

NIC का Basic Diagram

COMPUTER / HOST ┌───────────────────────────┐ │ CPU / Memory / OS │ │ │ │ │ ▼ │ │ ┌─────────┐ │ │ │ NIC │ │ │ └────┬────┘ │ └───────────┼───────────────┘ │ Network Cable │ ▼ Switch / Network

NIC के प्रकार

Wireless NICWi-Fi जैसे wireless standards के माध्यम से network से connect करता है।
Integrated NICMotherboard पर built-in network interface।

Key Point: NIC host/device और network के बीच interface का काम करता है।

3. Repeater

Repeater एक network device है जो कमजोर या degraded signal को receive करके उसे regenerate/reshape करके आगे transmit करता है। इसका primary purpose communication distance को extend करने में सहायता करना है। यह सामान्यतः physical layer concept से associated device है।

Signal becomes weak Source ──────── weak signal ────────► Repeater │ ▼ Regenerated Signal │ ▼ ───────────────► Destination

Repeater के Functions

  • Weak signal को receive करना।
  • Signal को regenerate करना।
  • Transmission distance extend करने में सहायता करना।
  • Physical layer level पर signal propagation में सहायता करना।

Advantages

  • Network segment की effective reach बढ़ाने में मदद करता है।
  • Signal degradation के प्रभाव को कम करने में सहायता करता है।
  • Simple network extension scenarios में useful है।

Limitations

  • यह normally traffic filtering या intelligent forwarding नहीं करता।
  • Network congestion को solve करने के लिए designed नहीं है।
  • Modern LANs में switches ने कई traditional repeater/hub use cases को replace कर दिया है।

4. Hub

Hub एक multi-port networking device है जो incoming signal/data को receive करके उसे अपने दूसरे ports पर repeat करता है। Traditional Ethernet hubs physical layer devices माने जाते हैं और destination के आधार पर intelligent frame forwarding नहीं करते।

┌──── PC 1 │ ├──── PC 2 ┌───┴───┐ │ HUB │ └───┬───┘ │ ├──── PC 3 │ └──── PC 4 Incoming transmission → shared to other ports

Hub कैसे काम करता है?

जब किसी connected device से signal hub पर आता है, hub उसे receive करके अन्य relevant ports पर repeat करता है। Hub destination MAC address देखकर specific port choose नहीं करता। इसलिए traditional hub-based Ethernet में multiple devices shared collision domain में operate करते थे।

Hub के Types

TypeDescription
Passive HubSignal को amplify/regenerate किए बिना simple connection/distribution function प्रदान करने की traditional concept।
Active HubIncoming signal को regenerate करके आगे distribute करता है; repeater hub के रूप में भी describe किया जाता है।
Intelligent HubManagement/monitoring capabilities वाली hub category की historical concept।

Hub के Disadvantages

  • Intelligent MAC-based forwarding नहीं करता।
  • Unnecessary traffic multiple ports पर भेजता है।
  • Traditional shared Ethernet में collisions अधिक हो सकती हैं।
  • Modern switched Ethernet में सामान्य LAN access के लिए largely obsolete है।
Exam Point: Hub को simple multi-port repeater के रूप में याद किया जा सकता है।

5. Bridge

Bridge एक networking device है जो two or more LAN segments को connect करता है और frames को MAC addresses के आधार पर forward या filter कर सकता है। Traditional bridges data-link layer (Layer 2) concept से associated हैं।

LAN Segment A LAN Segment B ┌──────────────┐ ┌──────────────┐ │ PC PC PC │ │ PC PC PC │ └──────┬───────┘ └──────┬───────┘ │ │ └───────────┌────────┐─────────────┘ │ BRIDGE │ └────────┘ MAC Filtering

Bridge के Functions

  • LAN segments को connect करना।
  • MAC address information के आधार पर frames forward/filter करना।
  • Unnecessary traffic को दूसरे segment तक जाने से रोकने में सहायता करना।
  • Network segmentation में सहायता करना।

Bridges के Types

TypeMeaning
Transparent BridgeEnd devices को bridge की presence की विशेष configuration आवश्यकता नहीं होती; bridge forwarding decisions transparently करता है।
Source Routing BridgeSource station route information specify करती है; यह concept विशेष रूप से Token Ring environments से associated था।
Translational BridgeDifferent LAN technologies के बीच frame format/operation translation में सहायता करने के लिए historical design।
Key Point: Bridge MAC addresses का उपयोग करके traffic को filter/forward करता है, जबकि repeater signal level पर काम करता है।

6. Switch

Switch एक multi-port network device है जो generally data-link layer पर Ethernet frames को MAC address के आधार पर appropriate port की ओर forward करता है। Modern switches कई advanced features जैसे VLAN, STP, link aggregation, QoS और management capabilities भी provide कर सकते हैं, model पर depend करता है।

┌───────────┐ PC 1 ─────────────│ │──────────── PC 3 PC 2 ─────────────│ SWITCH │──────────── PC 4 Printer ──────────│ │──────────── Server └───────────┘ Switch learns MAC addresses and forwards frames to the appropriate port.

Switch कैसे काम करता है?

Step 1: Switch incoming Ethernet frame receive करता है।
Step 2: Source MAC address और incoming port को MAC address table में learn कर सकता है।
Step 3: Destination MAC address को table में search किया जाता है।
Step 4: Destination known होने पर frame संबंधित port की ओर forward किया जाता है।
Step 5: Destination unknown होने पर frame को appropriate flooding behavior के अनुसार अन्य ports पर भेजा जा सकता है, source port को छोड़कर।

Switch के Types

TypeDescription
Unmanaged SwitchBasic plug-and-play switching; manual configuration options बहुत limited होते हैं।
Managed SwitchConfiguration और monitoring features जैसे VLAN, STP, QoS आदि उपलब्ध हो सकते हैं।
Layer 2 SwitchPrimarily MAC addresses और Layer 2 frames पर forwarding करता है।
Layer 3 SwitchSwitching के साथ IP routing capabilities भी प्रदान कर सकता है।

Switch के Advantages

  • Frames को destination port की ओर intelligently forward करता है।
  • Unnecessary traffic को कम करने में सहायता करता है।
  • Modern Ethernet LANs में high-performance connectivity प्रदान करता है।
  • Full-duplex Ethernet और VLAN जैसी technologies support कर सकता है, device पर depend करता है।

7. Router

Router एक Layer 3 networking device है जो different IP networks या subnets के बीच packets को forward करता है। Router destination IP address और routing table के आधार पर best available route select करता है।

LAN A Router LAN B 192.168.1.0/24 ┌───────────┐ 192.168.2.0/24 PC ────────────────► │ ROUTER │ ───────────────► PC │ │ └─────┬─────┘ │ Routing Table │ ▼ Next-hop / Interface

Router के मुख्य कार्य

  • Different networks के बीच packet forwarding।
  • Destination IP address के आधार पर route selection।
  • Routing table maintain/use करना।
  • Network-to-network communication enable करना।
  • Broadcast domains को separate करना।
  • कुछ routers NAT, DHCP, firewall/VPN जैसी additional services भी provide कर सकते हैं।

Routing के Basic Concepts

Router के पास connected और learned routes की information होती है। जब packet आता है, router destination IP को routing table में match करता है और सबसे specific applicable route के आधार पर next hop/interface चुनता है। अगर suitable route available नहीं है, packet drop हो सकता है या default route के अनुसार आगे भेजा जा सकता है।

Router के Types

TypeDescription
Wired RouterEthernet interfaces के माध्यम से networks connect करता है।
Wireless RouterRouting के साथ wireless LAN access भी provide कर सकता है।
Core/Enterprise RouterLarge network environments में high-capacity routing के लिए design किया जाता है।
SOHO RouterSmall Office/Home Office environments के लिए integrated networking functions वाला router।
Exam Definition: Router वह Layer 3 device है जो IP address के आधार पर packets को एक network से दूसरे network तक forward करता है।

9. कौन-सा Networking Device कब Use करें?

NIC

जब किसी computer/device को network connection देना हो।

Repeater

जब physical signal reach extend/regenerate करनी हो।

Hub

Historical/simple shared LAN environments में signal distribution के लिए; modern LANs में switch preferred है।

Bridge

LAN segments को Layer 2 MAC filtering के साथ connect करने के लिए।

Switch

Modern LAN में multiple devices को efficiently connect करने के लिए।

Router

Different IP networks/subnets के बीच communication और route selection के लिए।

Easy Memory Trick NIC → Connects Host Repeater→ Regenerates Signal Hub → Repeats to Ports Bridge → Filters by MAC Switch → Forwards by MAC Router → Routes by IP
