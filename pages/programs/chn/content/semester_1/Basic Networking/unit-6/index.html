1. Introduction

Computer network में data को source device से destination device तक पहुँचाने के लिए कई networking layers मिलकर काम करती हैं। Network Layer मुख्य रूप से different networks के बीच packets को पहुँचाने, logical addressing और routing से संबंधित होती है। इसके ऊपर Transport Layer end-to-end communication और applications/processes के बीच data delivery की services प्रदान करती है।

इस chapter में हम Network Layer के role, packet और datagram, virtual circuit, routing के types, ICMP, IP addressing, IP address classes, subnetting तथा subnet masking के साथ Transport Layer, TCP और UDP protocols को detail में समझेंगे।

Exam Definition: Network Layer logical addressing और routing के माध्यम से packets को source network से destination network तक पहुँचाने में सहायता करती है, जबकि Transport Layer end-to-end process communication के लिए transport services प्रदान करती है।

2. Network Layer

Network Layer OSI Model की Layer 3 है। इसका primary purpose packets को एक network से दूसरे network तक पहुँचाने के लिए logical addressing और routing का उपयोग करना है। यह local link तक सीमित Data Link Layer से आगे जाकर internetwork communication को support करती है।

मुख्य Functions

Logical Addressing

Devices/interfaces को IP addresses के माध्यम से logically identify करना।

Routing

Source से destination तक suitable path select करने में सहायता।

Packet Forwarding

Router द्वारा packets को appropriate next hop की ओर भेजना।

Internetworking

Multiple interconnected networks के बीच communication enable करना।

PDU: Network Layer पर data को सामान्यतः Packet कहा जाता है।

3. Role of Network Layer

Network Layer का सबसे important role है कि वह packets को logical network addresses के आधार पर destination network की दिशा में आगे भेजने में सहायता करे। Internet जैसे large network में sender और receiver अक्सर एक ही local network में नहीं होते। इसलिए packet को कई routers से होकर गुजरना पड़ सकता है।

Network Layer के प्रमुख roles

  • Addressing: IP address के माध्यम से logical identification।
  • Routing: Destination तक जाने वाले path का determination।
  • Forwarding: Router के द्वारा packet को next hop की ओर भेजना।
  • Internetwork Communication: Different networks के बीच packet communication।
  • Fragmentation/handling: कुछ IP versions और परिस्थितियों में packet size से related handling।
  • Error/Diagnostic Messaging: ICMP जैसे protocols के माध्यम से network-related diagnostic information।

4. Packet और Datagram

Packet

Packet Network Layer पर data unit है। इसमें upper-layer data के साथ network-layer header information होती है, जिसमें source और destination IP addresses जैसी information शामिल होती है।

Datagram

Datagram एक self-contained packet को refer करता है जिसे independently route किया जा सकता है। IP networking में IP datagrams connectionless packet delivery concept से closely associated हैं। हर datagram में destination information होती है, इसलिए network इसे independently forward कर सकता है।

PointPacketDatagram
MeaningNetwork Layer का general data unitIndependent, connectionless packet
RoutingNetwork routing के through forwardedप्रत्येक datagram independently route हो सकता है
ExampleIP packetIP datagram
Exam Tip: “Packet” broad term है, जबकि “datagram” connectionless communication में independently handled packet को emphasize करता है।

5. Virtual Circuit

Virtual Circuit (VC) packet-switched network में logical communication path का concept है। इसमें data transfer से पहले logical path establish किया जा सकता है। Packets उस established logical connection से associated state/context के अनुसार आगे भेजे जाते हैं।

Virtual Circuit की Working

Step 1 – Setup: Source और destination के बीच logical path establish किया जाता है।
Step 2 – Data Transfer: Data packets established virtual circuit के अनुसार forward होते हैं।
Step 3 – Termination: Communication complete होने पर virtual circuit release किया जा सकता है।

6. Types of Routing

Routing वह process है जिसमें network traffic/packets के लिए source से destination तक suitable path determine किया जाता है। Routers routing information का उपयोग करके packets को next hop की ओर forward करते हैं।

1. Static Routing

Static routing में routes administrator द्वारा manually configure किए जाते हैं। Network topology stable और small होने पर यह useful हो सकता है। इसका advantage यह है कि route behavior predictable रहता है, लेकिन topology change होने पर manual modification की आवश्यकता पड़ सकती है।

2. Dynamic Routing

Dynamic routing में routing protocols routers को network routes discover और update करने में सहायता करते हैं। Network changes के अनुसार routing information automatically adapt हो सकती है।

Distance Vector

Routers destination तक distance/metric और direction/next hop जैसी information exchange करते हैं। RIP इसका classic example है।

Link State

Routers network topology की information build करते हैं और shortest-path calculation करते हैं। OSPF इसका प्रमुख example है।

Path Vector

Route के साथ path information maintain करने की approach। BGP इसका प्रमुख example है।

Default Route

जब कोई more-specific route available न हो, traffic को default next hop की ओर भेजा जा सकता है।

Routing TypeMain IdeaExample
StaticManually configuredAdministrator-defined route
Dynamic – Distance VectorDistance/metric based route exchangeRIP
Dynamic – Link StateTopology information + shortest pathOSPF

7. IP Address

IP Address एक logical network-layer address है जिसका उपयोग network interfaces/hosts की identification और packet delivery में किया जाता है। IPv4 और IPv6 दो प्रमुख Internet Protocol versions हैं। इस syllabus के IP classes और subnetting topics मुख्यतः IPv4 से संबंधित हैं।

IPv4 Address

IPv4 address 32 bits का होता है। इसे 4 octets में divide करके dotted-decimal notation में लिखा जाता है। प्रत्येक octet 8 bits का होता है और सामान्यतः 0 से 255 तक value रख सकता है।

IPv4 = 32 bits = 4 × 8 bits 11000000 . 10101000 . 00000001 . 00001010 │ │ │ │ 192 168 1 10 Dotted Decimal: 192.168.1.10

Network Part और Host Part

IPv4 address में कुछ bits network को identify करती हैं और बाकी bits host/interface को identify करती हैं। यह division subnet mask या prefix length से determine होता है।

Example: 192.168.1.10/24 में /24 का अर्थ है कि first 24 bits network prefix के लिए हैं और remaining 8 bits host portion के लिए हैं।

8. IP Address Classes

Traditional IPv4 classful addressing में addresses को Class A, B, C, D और E में divide किया गया था। Modern networks में CIDR/classless addressing अधिक practical है, लेकिन IP classes examination के लिए महत्वपूर्ण concept हैं।

ClassFirst Octet RangeDefault MaskTraditional Use

B128 – 191255.255.0.0 (/16)Medium-size networks
C192 – 223255.255.255.0 (/24)Smaller networks
D224 – 239Not a normal host classMulticast
E240 – 255Not a normal host classExperimental/reserved

Class A

Class A में first octet network identification के लिए और remaining three octets traditional classful host addressing के लिए उपयोग होते थे। Default mask /8 है।

Class B

Class B में first two octets network part और remaining two octets host part के लिए होते थे। Default mask /16 है।

Class C

Class C में first three octets network part और last octet host part के लिए होता था। Default mask /24 है।

Class D और E

Class D multicast addressing के लिए और Class E historically experimental/reserved purposes के लिए defined किया गया था।

Important: 127.0.0.0/8 range traditional Class A range में होने के बावजूद loopback के लिए reserved है; इसे सामान्य host network assignment की तरह नहीं माना जाता।

9. Basics of Subnetting

Subnetting एक IP network को smaller logical subnetworks में divide करने की technique है। इसमें host portion की कुछ bits को borrow करके additional network/subnet bits बनाई जाती हैं। इससे address space को organized तरीके से allocate करना और network management improve करना संभव होता है।

Subnetting की आवश्यकता

  • Large network को smaller networks में divide करना।
  • Network management को improve करना।
  • Broadcast domain size को reduce करने में सहायता।
  • Address space को organization की requirement के अनुसार allocate करना।
  • Different departments/locations के लिए separate subnets बनाना।

Basic Formula

Borrowed bits = n

Traditional subnet calculation में number of subnets = 2n

Remaining host bits = h

Traditional usable hosts per subnet = 2h − 2

Example: /24 को /26 में Subnet करना

मान लें network है 192.168.1.0/24 और हमें इसे /26 करना है। /24 से /26 करने पर 2 host bits borrow होती हैं।

Original: 192.168.1.0/24 Network bits = 24 Host bits = 8 New: 192.168.1.0/26 Network bits = 26 Host bits = 6 Number of subnets = 2² = 4 Addresses/subnet = 2⁶ = 64 Traditional usable hosts = 64 - 2 = 62

11. ICMP

ICMP (Internet Control Message Protocol) IP networks में error reporting, diagnostics और control-related messaging के लिए उपयोग होता है। यह सामान्य application data transport करने के लिए TCP या UDP का replacement नहीं है।

ICMP के Uses

  • Destination unreachable जैसी error information report करना।
  • Network diagnostic और troubleshooting में सहायता।
  • Echo Request और Echo Reply messages के माध्यम से reachability testing।
  • Network conditions से संबंधित control/diagnostic messages।

Ping और ICMP

Ping सामान्यतः ICMP Echo Request भेजकर destination host की reachability test करता है। Destination available होने पर ICMP Echo Reply प्राप्त हो सकता है।

Computer A Computer B │ │ │ ---- ICMP Echo Request --------► │ │ │ │ ◄---- ICMP Echo Reply ---------- │ │ │ "Is the host reachable?"

Traceroute/Tracert Concept

Network path troubleshooting में traceroute/tracert techniques routers/hops की information identify करने के लिए IP/ICMP related responses और TTL behavior का उपयोग कर सकती हैं।

Important: ICMP का primary role diagnostic और error/control messaging है।

12. Transport Layer

Transport Layer OSI Model की Layer 4 है। इसका मुख्य focus end-to-end communication और applications/processes के बीच transport services provide करना है। Network Layer packet को destination host तक पहुँचाने पर focus करती है, जबकि Transport Layer destination host के अंदर appropriate application/process तक communication को support करती है।

मुख्य Functions

  • End-to-end delivery।
  • Process-to-process communication।
  • Segmentation और reassembly।
  • Port numbers के माध्यम से application/process identification।
  • Flow control और reliability, protocol के अनुसार।
  • Connection management, protocol के अनुसार।

Major Transport Protocols

TCP

Reliable, connection-oriented, ordered byte-stream transport service।

Connectionless, lightweight datagram transport service।

13. TCP – Transmission Control Protocol

TCP (Transmission Control Protocol) एक connection-oriented transport protocol है। यह applications को reliable और ordered byte-stream communication प्रदान करता है। TCP connection establish करके data exchange करता है और acknowledgements, sequencing तथा retransmission जैसी mechanisms के माध्यम से reliable delivery support करता है।

TCP की मुख्य विशेषताएँ

  • Connection-oriented: Data transfer से पहले connection establish किया जाता है।
  • Reliable: Lost/corrupted data के recovery के लिए mechanisms।
  • Ordered: Data को sequence के अनुसार deliver करने में सहायता।
  • Flow Control: Receiver की capacity के अनुसार sending rate manage करता है।
  • Congestion Control: Network congestion के अनुसार transmission behavior adjust करता है।
  • Full-duplex: दोनों directions में communication support करता है।
  • Port Numbers: Source और destination applications/processes identify करने में सहायता।

TCP Three-Way Handshake

TCP connection establishment के लिए commonly three-way handshake use किया जाता है:

Client Server │ -------- SYN -----------> │ │ <----- SYN + ACK -------- │ │ -------- ACK -----------> │ │ │ │ TCP Connection Ready │
1. SYN: Client connection initiate करने के लिए SYN भेजता है।
2. SYN-ACK: Server SYN को acknowledge करके SYN-ACK भेजता है।
3. ACK: Client final ACK भेजता है और connection establish हो जाता है।

TCP के Uses

जहाँ reliable and ordered delivery important है वहाँ TCP useful है, जैसे web traffic के कई traditional applications, file transfer और email-related protocols।

14. UDP – User Datagram Protocol

UDP (User Datagram Protocol) एक connectionless transport protocol है। यह lightweight datagram service प्रदान करता है और TCP की तरह connection establishment, acknowledgements और retransmission की built-in reliability provide नहीं करता।

UDP की मुख्य विशेषताएँ

  • Connectionless communication।
  • Low protocol overhead।
  • Fast/simple transmission model।
  • Delivery, ordering और duplicate protection की reliability application को implement करनी पड़ सकती है।
  • Real-time या latency-sensitive applications में useful हो सकता है, जहाँ application अपनी requirements के अनुसार loss handling कर सकती है।

UDP Header का Basic Concept

┌─────────────────────┬─────────────────────┐ │ Source Port │ Destination Port │ ├─────────────────────┼─────────────────────┤ │ Length │ Checksum │ ├─────────────────────┴─────────────────────┤ │ DATA │ └───────────────────────────────────────────┘

UDP के Uses

  • DNS queries जैसे request/response applications।
  • Streaming और real-time communication scenarios में।
  • Online gaming और latency-sensitive traffic के कुछ cases में।
  • ऐसे applications जहाँ application-level protocol स्वयं reliability/control implement कर सकता है।
