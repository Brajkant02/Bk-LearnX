1. Internet

Internet एक worldwide interconnected network of networks है, जिसमें computers, mobile devices, servers, routers और अन्य network devices standard communication protocols के माध्यम से आपस में communicate करते हैं। Internet किसी एक company या एक single network का नाम नहीं है; यह अलग-अलग networks और organizations का interconnected system है।

Internet की प्रमुख विशेषताएँ

Global Connectivity

दुनिया के अलग-अलग locations में स्थित networks और users को connect करता है।

Resource Sharing

Websites, files, applications, databases और अन्य services access की जा सकती हैं।

Communication

E-mail, messaging, voice/video communication आदि संभव बनाता है।

Information Access

WWW और अन्य Internet services के माध्यम से information उपलब्ध कराता है।

Internet और WWW में अंतर

InternetWWW
Global network infrastructure है।Internet पर चलने वाली information service है।
Multiple services को support करता है।Web pages/resources पर मुख्य focus है।

2. Internet Connection Types

Internet connection type उस technology को बताता है जिसके द्वारा user device या local network ISP के network से connect होता है।

1. Dial-up

Traditional telephone line का उपयोग करके Internet access किया जाता था। इसकी speed कम और connection establishment relatively slow होता था।

2. DSL

Digital Subscriber Line telephone infrastructure का उपयोग करके broadband connectivity प्रदान करती है।

3. Cable Broadband

Cable television infrastructure के माध्यम से Internet access प्रदान किया जा सकता है।

4. Fiber Optic

Optical fibre के माध्यम से high-speed Internet connectivity मिलती है। FTTH में fibre सीधे premises तक आ सकती है।

5. Fixed Wireless

Wireless radio link के माध्यम से fixed location को ISP network से connect किया जाता है।

6. Mobile Internet

Cellular networks जैसे 4G/5G के माध्यम से mobile devices और routers Internet से connect हो सकते हैं।

7. Satellite

Satellite communication के माध्यम से Internet connectivity दी जा सकती है, विशेषकर remote areas में।

8. Leased Line

Organizations के लिए dedicated connectivity प्रदान करने वाला business-oriented connection type।

Exam Point: Connection type और ISP अलग concepts हैं। Connection type technology/method है, जबकि ISP वह organization/provider है जो Internet access service देता है।

3. Internet Service Provider (ISP)

ISP (Internet Service Provider) वह organization/company है जो individuals, homes, businesses या institutions को Internet connectivity और related services provide करती है। ISP customer को network access देने के साथ कई additional services भी provide कर सकता है।

ISP की Services

  • Internet connectivity
  • IP address assignment
  • DNS-related services
  • Business connectivity और leased connections
  • Web hosting / e-mail जैसी additional services
  • Customer support और network maintenance

ISP के Examples

India में consumer/business Internet services अलग-अलग providers द्वारा उपलब्ध कराई जाती हैं। उदाहरण के रूप में Jio, Airtel, BSNL और अन्य regional/service providers अलग-अलग connectivity technologies और plans offer करते हैं।

4. Web Hosting

Web Hosting वह service है जिसमें website की files, databases और related resources को Internet-connected server infrastructure पर store किया जाता है ताकि users browser के माध्यम से website access कर सकें।

Website को Online करने के लिए क्या चाहिए?

1. Domain Name: Website का human-readable address, जैसे example.com.
2. Hosting: Website files/app को server infrastructure पर रखने की service.
3. DNS: Domain को appropriate server/IP information से connect करने में सहायता।
4. Website/Application: HTML, CSS, JavaScript, backend code, database आदि।

Types of Web Hosting

Cloud HostingMultiple interconnected computing resources पर scalable hosting infrastructure।
Managed HostingProvider server management, updates, monitoring आदि में additional support देता है।

6. IANA

IANA (Internet Assigned Numbers Authority) Internet के globally unique identifiers की coordination से संबंधित functions का नाम है। IANA functions DNS Root, IP addressing, Autonomous System Numbers और protocol registries जैसे resources की global coordination में महत्वपूर्ण भूमिका निभाते हैं। citeturn0search3turn0search4

IANA के प्रमुख क्षेत्र

DNS Root Zone

Top-level domains की root-zone delegation information coordinate करना।

Number Resources

IPv4, IPv6 और Autonomous System Numbers के global coordination से संबंधित registries maintain करना।

Protocol Registries

Internet protocols में उपयोग होने वाले कई protocol names/numbers की central registry maintain करना।

Global Coordination

Internet के globally unique identifiers की coordinated administration में भूमिका।

Important: IANA आम users को सीधे सामान्य IP addresses allocate नहीं करता। Large IP address blocks RIRs को allocate किए जाते हैं और आगे hierarchical system के माध्यम से distribute होते हैं। citeturn0search4

7. IANA Root Zone Database

IANA Root Zone Database top-level domains की delegation details का authoritative record है। इसमें gTLDs और country-code TLDs सहित TLD managers तथा technical delegation information से संबंधित data मिलता है। citeturn0search0turn0search2

Root Zone क्या है?

DNS hierarchy में Root Zone सबसे ऊपर का level है। इसके नीचे .com, .org, .in, .edu आदि top-level domains आते हैं। IANA root zone management में TLD managers की delegation और related technical information coordinate करती है। citeturn0search2

8. IANA Number Resources

IANA Internet number resources की global coordination में IPv4, IPv6 और Autonomous System Numbers (ASN) से संबंधित registries maintain करती है। citeturn0search1turn0search4

ResourceDescription
IPv4 Address SpaceIPv4 address space की top-level coordination/delegation information.
IPv6 Address SpaceIPv6 address space की global coordination.

IPv4 addresses 32-bit और IPv6 addresses 128-bit होते हैं। IANA large address pools primarily RIRs को allocate करती है; RIRs अपने regions में network operators/ISPs को resources allocate करते हैं। citeturn0search4turn0search16

9. LIR, NIR और RIR

LIR – Local Internet Registry

LIR एक organization/registry arrangement है जो अपने local service area में Internet number resources के allocation/assignment से संबंधित कार्य कर सकती है। कई मामलों में ISPs और network operators LIR framework के माध्यम से IP resources प्राप्त करते हैं।

NIR – National Internet Registry

NIR किसी देश या national framework के अंतर्गत Internet number resources को manage/distribute करने वाली registry होती है। IANA के अनुसार users को IP addresses hierarchical system के माध्यम से ISP/LIR/NIR/RIR structures से प्राप्त हो सकते हैं। citeturn0search4

RIR – Regional Internet Registry

RIR एक regional organization है जो अपने geographic region में Internet number resources की allocation/registration policy और distribution का कार्य करती है। IANA वर्तमान में पाँच RIRs को global IPv4/IPv6/ASN resource system में recognize करती है। citeturn0search4turn0search16

11. Registration of a Domain

Domain Registration में user/organization किसी available domain name को किसी accredited registrar के माध्यम से register करता है। .IN Registry के अनुसार registry स्वयं सामान्य registrant से direct registration नहीं करती; registrations accredited registrars के माध्यम से किए जाते हैं। citeturn0search12

General Domain Registration Steps

Step 1 – Choose Name: Desired domain name select करें, जैसे mysite.in.
Step 2 – Availability Check: Registrar के search tool से check करें कि domain available है या नहीं।
Step 3 – Select Extension: .com, .in, .org आदि appropriate extension चुनें।
Step 4 – Provide Details: Registrant/contact details और required information provide करें।
Step 5 – Payment: Registration fee pay करें।
Step 6 – DNS/Nameservers: Domain को hosting/server की ओर point करने के लिए nameservers या DNS records configure करें।
Step 7 – Renewal: Registration validity maintain करने के लिए समय पर renewal करें।
