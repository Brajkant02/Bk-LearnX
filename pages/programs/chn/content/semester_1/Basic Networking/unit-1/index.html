1. Introduction to Computer Networks

Computer Network computers और अन्य digital devices का ऐसा interconnected system है जिसमें devices communication links और networking protocols की सहायता से आपस में data, information और resources का आदान-प्रदान करते हैं। Network में connected devices एक-दूसरे से communicate कर सकते हैं और आवश्यकता के अनुसार files, printers, applications, Internet connection तथा अन्य resources share कर सकते हैं।

Exam Definition: Computer Network दो या दो से अधिक computers/devices का ऐसा समूह है जो communication medium और suitable protocols के माध्यम से connected होकर data तथा resources को share करता है।

Network के मुख्य उद्देश्य

  • एक computer से दूसरे computer तक data transfer करना।
  • Files और information को share करना।
  • Printers और अन्य hardware resources को share करना।
  • Internet या अन्य network services को multiple users तक पहुँचाना।
  • Communication को fast, reliable और organized बनाना।
  • Centralized या distributed applications को support करना।

Data Sharing

Network users एक-दूसरे के साथ documents, images, databases और अन्य digital data exchange कर सकते हैं।

Resource Sharing

Printer, storage और network services जैसे resources को multiple users share कर सकते हैं।

Communication

Email, messaging, video conferencing और अन्य communication applications networks पर काम करते हैं।

Centralized Management

Organization में users, devices, data और security policies को centrally manage किया जा सकता है।

2. Need & Uses of Computer Networks

आज के computing environment में individual computers के साथ-साथ connected systems की आवश्यकता होती है। Network users और organizations को information तथा resources तक controlled और efficient access प्रदान करता है।

UseExplanation
File Sharingएक system पर उपलब्ध files को authorized network users के साथ share किया जा सकता है।
Hardware Sharingएक printer या अन्य network device को multiple computers से use किया जा सकता है।
CommunicationEmail, chat, voice और video communication network connectivity पर निर्भर करते हैं।
Internet Accessएक network connection को कई devices तक distribute किया जा सकता है।
Data ManagementServers और databases के माध्यम से organizational information को manage किया जा सकता है।
Remote AccessAuthorized users network के माध्यम से दूर स्थित resources तक access कर सकते हैं।

3. Elements of a Computer Network

एक network केवल computers को cable से जोड़ने का नाम नहीं है। Effective communication के लिए hardware, software, communication media और protocols सभी की आवश्यकता होती है।

1. Sender / Source

Sender वह device है जो data या message को network पर भेजता है। उदाहरण: computer, smartphone या server।

2. Receiver / Destination

Receiver वह device है जो transmitted data को प्राप्त करता है।

3. Network Devices

Network communication को connect और manage करने के लिए switches, routers, access points, modems आदि devices उपयोग किए जाते हैं।

4. Transmission Medium

Data जिस path से travel करता है उसे transmission medium कहते हैं। यह wired या wireless हो सकता है। Wired examples में twisted-pair और fiber-optic cable आते हैं; wireless में radio-based communication शामिल है।

5. Network Interface

Network Interface Card/NIC या built-in network interface device को computer को network से connect करने में उपयोग किया जाता है।

6. Protocols

Protocols communication के rules और conventions होते हैं जो यह निर्धारित करते हैं कि devices data को कैसे format, address, transmit और interpret करेंगे।

7. Network Software

Operating system networking components और network applications communication, resource access तथा network management में सहायता करते हैं।

4. Types of Computer Networks

Networks को उनके geographical coverage, size और purpose के आधार पर अलग-अलग categories में classify किया जा सकता है।

TypeFull FormCoverage / DescriptionExample
PANPersonal Area Networkएक व्यक्ति के आसपास बहुत छोटी range का network।Phone + Bluetooth earbuds
LANLocal Area NetworkLimited area जैसे room, office, lab या building।Computer lab network
MANMetropolitan Area Networkएक city/metropolitan area के स्तर पर बड़ा network।City-wide institutional network
WANWide Area NetworkLarge geographical area, cities/countries तक।Internet / enterprise WAN

LAN

LAN relatively small geographical area में computers और devices को connect करता है। Offices, schools, laboratories और homes में LAN commonly used होता है।

WAN

WAN large geographical distance पर networks को interconnect करता है। WAN में अलग-अलग locations के networks communication links के माध्यम से connect हो सकते हैं।

Exam Tip: Basic classification याद रखने के लिए: PAN → Personal, LAN → Local, MAN → Metropolitan, WAN → Wide.

5. Network Topology

Network Topology network में computers, network devices और communication links की physical या logical arrangement को कहा जाता है। दूसरे शब्दों में, topology यह बताती है कि network nodes किस प्रकार एक-दूसरे से connected और arranged हैं।

Important: इस syllabus में मुख्य topologies हैं — Bus, Star, Mesh और Ring.

Topology के आधार पर विचार

  • Nodes के बीच connection pattern
  • Communication path
  • Network expansion की सुविधा
  • Failure का effect
  • Cost और cabling requirement
  • Maintenance और troubleshooting

6. Bus Topology

Bus Topology में सभी network devices एक common backbone cable से connected होते हैं। Data इस shared communication medium पर travel करता है और appropriate destination device उसे receive/process करता है। Traditional bus networks में backbone के ends पर termination का उपयोग किया जाता था।

[Terminator]══════ Backbone Cable ═══════════[Terminator] │ │ │ PC1 PC2 PC3 │ │ │ PC4 PC5 PC6

Bus Topology के Advantages

  • Simple network layout।
  • कम cable की आवश्यकता हो सकती है।
  • Small/simple networks के लिए initial installation comparatively simple हो सकती है।
  • एक common communication backbone का उपयोग होता है।

Bus Topology के Disadvantages

  • Backbone failure network communication को प्रभावित कर सकता है।
  • Network में devices बढ़ने पर performance और troubleshooting complexity बढ़ सकती है।
  • Fault location identify करना difficult हो सकता है।
  • Shared medium होने के कारण simultaneous communication manage करना पड़ता है।
Key Point: Bus topology का सबसे important concept है single shared backbone cable.

7. Star Topology

Star Topology में प्रत्येक node एक central networking device से separately connected होता है। Modern Ethernet LANs में central device के रूप में switch commonly used होता है।

PC1 │ │ PC2 ─── [ SWITCH ] ─── PC3 │ │ PC4 │ PC5

Working

जब एक computer data भेजता है, तो वह data central switch/device तक जाता है। Central device network rules और destination information के अनुसार frame को appropriate port/device की ओर forward करता है।

Advantages

  • Individual node connection को manage करना comparatively आसान होता है।
  • एक cable/device link fail होने पर सामान्यतः बाकी nodes connected रह सकते हैं।
  • Fault isolation आसान होता है।
  • Network को expand करना comparatively convenient है।
  • Modern switched Ethernet networks के लिए suitable topology है।

Disadvantages

  • Central device की आवश्यकता होती है।
  • Central switch/device failure से उससे जुड़े पूरे network segment की connectivity प्रभावित हो सकती है।
  • Bus की तुलना में अधिक individual cable runs की आवश्यकता हो सकती है।
Key Point: Star topology की पहचान है central connecting device.

8. Mesh Topology

Mesh Topology में nodes के बीच multiple direct links हो सकते हैं। Full Mesh में प्रत्येक node बाकी सभी nodes से directly connected होता है। Mesh topology का major advantage redundancy और alternate communication paths हैं।

A / | \ / | \ B---|---C \ | / \ | / D Full Mesh concept: हर node → बाकी सभी nodes से direct link

Types of Mesh

Full Mesh

हर node प्रत्येक दूसरे node से directly connected होता है।

Partial Mesh

कुछ important nodes multiple connections रखते हैं, जबकि सभी nodes fully interconnected नहीं होते।

Advantages

  • Multiple communication paths उपलब्ध हो सकते हैं।
  • Link failure की स्थिति में alternate path उपलब्ध हो सकता है।
  • High redundancy और reliability प्रदान कर सकती है।

Disadvantages

  • Full mesh में बहुत अधिक links/cabling की आवश्यकता होती है।
  • Installation और maintenance complex हो सकते हैं।
  • Cost अन्य simple topologies की तुलना में अधिक हो सकती है।
Key Point: Mesh topology का main concept है multiple interconnections and redundancy.

9. Ring Topology

Ring Topology में network nodes circular arrangement में connected होते हैं, जिससे प्रत्येक node अपने neighboring nodes से जुड़ा रहता है। इस arrangement से एक logical ring path बनता है।

[PC1] / \ [PC2] [PC5] | | [PC3]──────[PC4] Circular / Ring Arrangement

Working

Ring-based systems में data communication ring के path के अनुसार आगे बढ़ सकती है। Particular implementation में transmission direction और access method अलग हो सकते हैं। इसलिए ring topology की working को केवल एक fixed direction से define नहीं करना चाहिए।

Advantages

  • Organized circular communication path।
  • Network access को controlled तरीके से manage किया जा सकता है, depending on implementation।
  • कुछ implementations में predictable access behavior मिल सकता है।

Disadvantages

  • एक link/node failure network communication को प्रभावित कर सकता है यदि alternate path/redundancy मौजूद न हो।
  • Adding/removing nodes network design पर प्रभाव डाल सकता है।
  • Fault isolation simple star network की तुलना में difficult हो सकती है।
Key Point: Ring topology की पहचान है circular connection of nodes.
