1. Introduction to Application Layer

Application Layer OSI model की सबसे ऊपर वाली Layer 7 है। यह end-user applications और network services के बीच interface provide करती है। इसका उद्देश्य applications को network पर communication और different network services का उपयोग करने की सुविधा देना है।

जब हम web browser से website खोलते हैं, e-mail भेजते हैं, किसी FTP server से file transfer करते हैं, domain name को IP address में resolve करते हैं या network से automatically IP configuration प्राप्त करते हैं, तब अलग-अलग application-layer protocols की आवश्यकता होती है।

OSI MODEL 7 APPLICATION ← User/Application Network Services 6 PRESENTATION 5 SESSION 4 TRANSPORT 3 NETWORK 2 DATA LINK 1 PHYSICAL
Exam Definition: Application Layer OSI model की Layer 7 है जो network applications को communication और network services उपलब्ध कराने के लिए application-level protocols का उपयोग करती है।

2. Role of Application Layer

Application Layer स्वयं कोई single application नहीं है। यह विभिन्न network applications के लिए protocols और services का framework provide करती है। Different applications के लिए अलग-अलग protocols designed होते हैं।

1. Network Services

Web browsing, e-mail, file transfer, remote access और name resolution जैसी services के लिए protocols provide करती है।

2. User Interaction

End-user applications को network communication capabilities उपलब्ध कराने में सहायता करती है।

3. Resource Access

Remote files, websites, mail servers और अन्य network resources access करने में मदद करती है।

4. Application Communication

Applications के बीच messages और requests/responses के exchange के लिए rules define करती है।

Application Layer Protocol क्या है?

Application Layer Protocol ऐसे rules और message formats का set है जो network applications के बीच communication को define करता है। उदाहरण के लिए HTTP web communication के लिए, FTP file transfer के लिए और DNS name resolution के लिए उपयोग होता है।

4. Domain Name System (DNS)

DNS (Domain Name System) एक distributed naming system है जो human-readable domain names को corresponding IP addresses में resolve करने की सुविधा देता है। Humans के लिए example.com जैसा नाम याद रखना आसान है, जबकि network communication के लिए IP address आवश्यक होता है।

DNS की आवश्यकता

  • Domain names को याद रखना IP addresses की तुलना में आसान है।
  • Users को numeric IP address manually याद रखने की आवश्यकता नहीं होती।
  • DNS distributed और hierarchical naming system provide करता है।
  • एक domain की service infrastructure change होने पर users वही domain name use कर सकते हैं।

DNS Working

User enters: www.example.com │ ▼ DNS Resolver │ ▼ DNS Server hierarchy │ ▼ IP Address found │ ▼ Browser connects │ ▼ Web Server

DNS Hierarchy

DNS hierarchical structure follow करता है। इसके top level पर Root, उसके नीचे Top-Level Domains (TLDs) जैसे .com, .org, .in आदि और उसके नीचे authoritative domain information होती है।

Important DNS Terms

Domain Name:
Human-readable network name, जैसे example.com.
DNS Resolver:
Client की ओर से DNS lookup perform करने वाला component/service.
Root Server:
DNS hierarchy के root level पर queries को appropriate TLD की ओर direct करने में सहायता करता है।
Authoritative DNS Server:
किसी domain के लिए authoritative DNS records provide करता है।
Remember: DNS का main काम name resolution है — Domain Name → IP Address.

5. Electronic Mail (E-Mail)

Electronic Mail internet/network के माध्यम से electronic messages भेजने और प्राप्त करने की service है। E-mail system में sender, recipient, mail client और mail servers शामिल हो सकते हैं।

E-Mail के Major Components

  • Mail User Agent (MUA): User द्वारा mail compose, send और read करने के लिए application.
  • Mail Server: E-mail messages को receive, store और forward करने वाला server.
  • SMTP: Mail भेजने/relay करने के लिए commonly used protocol.
  • POP3: Mailbox से messages download/retrieve करने के लिए protocol.
  • IMAP: Server-side mailbox को access और synchronize करने के लिए protocol.

E-Mail Working

Sender │ ▼ Mail Client │ │ SMTP ▼ Sender Mail Server │ │ SMTP / Mail Routing ▼ Receiver Mail Server │ │ IMAP / POP3 ▼ Receiver Mail Client

SMTP vs POP3 vs IMAP

ProtocolPurpose
SMTPMail submission/transfer
POP3Mail retrieve/download करने के लिए
IMAPServer पर stored mail को access और synchronize करने के लिए

6. World Wide Web (WWW)

World Wide Web interconnected web resources का system है जिन्हें Internet के माध्यम से access किया जाता है। Web pages और resources generally URLs द्वारा identified होते हैं और browsers HTTP/HTTPS जैसे protocols के माध्यम से servers से resources request करते हैं।

WWW के Main Components

Web Browser

User की तरफ से web resources request और display करता है।

Web Server

Web pages और अन्य web resources provide करता है।

URL

Web resource का address/location identify करता है।

HTTP/HTTPS

Browser और web server के बीच web communication के लिए protocol.

Web Browsing Flow

User enters URL │ ▼ DNS resolves domain │ ▼ Browser connects to server │ ▼ HTTP Request │ ▼ Web Server │ ▼ HTTP Response │ ▼ Browser renders webpage
Important: Internet और WWW same नहीं हैं। Internet एक global network infrastructure है, जबकि WWW उस infrastructure पर चलने वाली प्रमुख information service है।

7. File Transfer Protocol (FTP)

FTP का पूरा नाम File Transfer Protocol है। इसका उपयोग client और server के बीच files को upload और download करने के लिए किया जाता है। FTP traditional client-server architecture पर आधारित है।

FTP के प्रमुख Operations

  • File upload करना
  • File download करना
  • Remote directory listing देखना
  • Directories में navigation
  • File management operations, server permissions के अनुसार

FTP Connections

Traditional FTP में control और data communication के लिए अलग logical connections का concept होता है। Control connection सामान्यतः TCP port 21 से associated होती है। Data transfer के लिए FTP active/passive modes का उपयोग कर सकता है।

FTP Client │ ├──────── Control Connection ───────► FTP Server │ Port 21 │ └────────── Data Transfer ──────────► FTP Server
Exam Point: FTP का main purpose file transfer है। यह सामान्य web browsing protocol नहीं है।

8. Telnet

Telnet एक network protocol है जिसका उपयोग remote computer/server पर terminal-like access के लिए historically किया जाता रहा है। इसमें user remote machine पर commands execute करने जैसी activities कर सकता है, provided appropriate account and permissions available हों।

Telnet की Working

Local Computer │ │ Telnet connection │ TCP Port 23 ▼ Remote Computer │ ▼ Remote Terminal Session

Telnet की Limitation

Traditional Telnet communication में credentials और data secure encryption के बिना transmit हो सकते हैं। इसलिए modern secure remote administration में SSH को prefer किया जाता है।

Remember: Telnet = Remote terminal access. Common port = 23.

9. HTTP

HTTP (Hypertext Transfer Protocol) Web के लिए fundamental application-layer protocol है। Browser और web server के बीच request और response messages के exchange के लिए HTTP का उपयोग होता है।

HTTP Request-Response Model

Client / Browser │ │ HTTP Request │ GET /index.html ▼ Web Server │ │ HTTP Response │ 200 OK + Content ▼ Client / Browser

HTTP और HTTPS

HTTPS HTTP को TLS-based security के साथ use करता है, जिससे communication में encryption और server authentication जैसी security properties उपलब्ध हो सकती हैं।

Common Port: HTTP → 80, HTTPS → 443.

10. DHCP

DHCP (Dynamic Host Configuration Protocol) network devices को automatically IP configuration provide करने के लिए उपयोग किया जाता है। इससे administrator को हर client machine पर IP address manually configure करने की आवश्यकता कम हो जाती है।

DHCP से मिलने वाली Information

  • IP Address
  • Subnet Mask
  • Default Gateway
  • DNS Server information
  • Lease-related configuration

DORA Process

DHCP का सबसे important exam topic DORA process है:

D = DISCOVER Client ─────────────► DHCP Server(s) O = OFFER Client ◄───────────── DHCP Server R = REQUEST Client ─────────────► Selected DHCP Server A = ACKNOWLEDGEMENT Client ◄───────────── DHCP Server
1. DHCP Discover: Client available DHCP server को खोजने के लिए message भेजता है।
2. DHCP Offer: Server client को IP configuration offer करता है।
3. DHCP Request: Client offered configuration को request करता है।
4. DHCP ACK: Server configuration को acknowledge और assign करता है।

DHCP Ports

DHCP commonly UDP port 67 (server) और UDP port 68 (client) use करता है।

Easy Trick: DORA = Discover → Offer → Request → Acknowledge
