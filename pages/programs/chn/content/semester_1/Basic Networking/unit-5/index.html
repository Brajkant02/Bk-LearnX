1. Introduction

Computer network में data को एक device से दूसरे device तक पहुँचाने के लिए अलग-अलग layers काम करती हैं। OSI Model में Physical Layer सबसे नीचे और Data Link Layer उसके ऊपर होती है। Physical Layer का मुख्य focus raw bits को physical medium पर transmit करना है, जबकि Data Link Layer directly connected nodes के बीच frames की delivery, MAC addressing, error detection और medium access जैसी responsibilities संभालती है।

Exam Definition: Physical Layer physical medium पर bits और signals के transmission से संबंधित होती है, जबकि Data Link Layer local link पर frames की delivery, addressing, error control और flow/medium access functions से संबंधित होती है।

2. Physical Layer

Physical Layer OSI Model की Layer 1 है। यह data को raw bits के रूप में physical medium के माध्यम से transmit करने से संबंधित है। यह layer logical meaning of data को नहीं समझती; इसका focus signals, transmission medium और physical characteristics पर होता है।

मुख्य कार्य

  • Bits को electrical, optical या radio signals में represent/transmit करना।
  • Physical transmission medium की characteristics define करना।
  • Cables, connectors और physical interfaces से संबंधित specifications।
  • Signal levels और timing जैसी physical characteristics को support करना।
  • Transmission rate और bit transmission से संबंधित specifications में सहायता।

Physical Media के Examples

Twisted Pair

UTP और STP जैसे copper cables LANs में commonly use होते हैं।

Coaxial Cable

Central conductor और shielding वाला cable type।

Optical Fibre

Light pulses के माध्यम से data transmit करता है।

Wireless Medium

Radio waves आदि के माध्यम से transmission करता है।

PDU: Physical Layer पर data को commonly Bits के रूप में represent किया जाता है।

3. Data Link Layer

Data Link Layer OSI Model की Layer 2 है। इसका primary purpose directly connected network nodes के बीच data transfer को organize करना है। यह network layer से प्राप्त packets को frames में encapsulate करती है और local link पर frame delivery के लिए आवश्यक functions provide करती है।

Data Link Layer के प्रमुख कार्य

  • Framing: Network layer packets को frames में organize करना।
  • MAC Addressing: Local network interfaces की पहचान के लिए MAC addresses का उपयोग।
  • Error Control: Transmission errors को detect करने और कुछ protocols में recovery support करने की mechanisms।
  • Flow Control: Sender और receiver की speed के बीच coordination।
  • Medium Access Control: Shared medium पर transmission access को coordinate करना।

4. MAC Sub-layer

MAC (Media Access Control) Data Link Layer का lower sub-layer है। यह local network medium तक access और frame transmission से संबंधित functions को handle करता है। विशेष रूप से shared communication medium में यह तय करने में सहायता करता है कि कौन-सा device कब transmit कर सकता है।

MAC Sub-layer के Functions

  • MAC addressing से संबंधित functions।
  • Frame transmission और reception में सहायता।
  • Shared medium access को control करना।
  • Network technology के अनुसार access method लागू करना।
  • Ethernet और अन्य LAN technologies के frame handling में भूमिका।
Easy Memory: MAC = Media Access Control → “Medium पर किस device को access मिलेगा और frame कैसे handle होगा।”

5. LLC – Logical Link Control

LLC (Logical Link Control) Data Link Layer का upper sub-layer है। IEEE 802 architecture में LLC, network layer protocols और underlying MAC mechanisms के बीच logical link control functions provide करता है।

LLC के Functions

  • Network layer protocols के लिए logical interface provide करना।
  • Data link communication को logically organize करना।
  • Upper-layer protocols के multiplexing/identification में सहायता करना।
  • कुछ implementations में flow और error-related link services provide करना।

6. MAC Addressing

MAC Address (Media Access Control Address) network interface की hardware-level identifier है। Ethernet और अन्य IEEE 802 networks में MAC address local network communication के लिए frame destination/source identification में उपयोग होता है।

MAC Address का सामान्य Format

Ethernet MAC address सामान्यतः 48 bits (6 bytes) का होता है और hexadecimal notation में लिखा जाता है। उदाहरण:

00:1A:2B:3C:4D:5E 48 bits = 6 bytes Each byte = 8 bits 6 × 8 = 48 bits

MAC Address के मुख्य Concepts

  • MAC address network interface को identify करने में सहायता करता है।
  • Frame में source और destination MAC addresses हो सकते हैं।
  • Ethernet switches MAC address table के आधार पर forwarding decisions लेते हैं।
  • MAC addressing local/link-level communication से संबंधित है।
MAC vs IP: MAC address Layer 2/link-level identification से संबंधित है, जबकि IP address Layer 3 logical addressing और routing के लिए उपयोग होता है।

7. Framing

Framing Data Link Layer का important function है। Network Layer से प्राप्त packet को Data Link Layer एक frame के रूप में organize करती है। Frame में control information, addresses और error-detection information जैसी fields हो सकती हैं, जो particular data-link technology पर depend करती हैं।

Generic Data Link Frame ┌─────────┬──────────────┬─────────────┬────────────┐ │ Header │ Payload │ Error Check │ Trailer* │ └─────────┴──────────────┴─────────────┴────────────┘ ▲ ▲ ▲ │ │ │ Addresses Data Error detection * Exact fields technology पर depend करती हैं।

Framing की आवश्यकता

  • Continuous bit stream को manageable data units में divide करना।
  • Frame boundaries identify करना।
  • Source/destination link-level addressing carry करना।
  • Error detection information attach करना।

Framing के Common Approaches

MethodBasic Idea
Character/Byte CountFrame length/count information के आधार पर frame boundary determine करना।
Byte StuffingSpecial delimiter bytes को data में appear होने पर escape/stuff करना।
Bit StuffingSpecial bit pattern को preserve करने के लिए extra bits insert करना।

8. Error Control

Data transmission के दौरान noise, interference, signal distortion या other physical conditions के कारण bits बदल सकते हैं। Error Control का उद्देश्य transmission errors को detect करना और protocol के अनुसार correction या retransmission में सहायता करना है।

Error Detection

Data Link Layer में error detection के लिए विभिन्न techniques use हो सकती हैं:

Parity

Additional parity bit के द्वारा simple error detection।

Checksum

Data values से calculated checking value का उपयोग।

CRC

Polynomial-based cyclic redundancy check; Ethernet frames में CRC/FCS आधारित error detection widely used है।

Error Control की Basic Process

1. Sender data/frame transmit करता है।
2. Receiver received frame को check करता है।
3. Error detected होने पर protocol के अनुसार frame discard, notification या retransmission mechanism हो सकता है।
4. Reliable protocols में corrupted/lost data को पुनः भेजा जा सकता है।
Note: Error detection और error correction अलग concepts हैं। हर Data Link protocol स्वयं corrupted frame को correct नहीं करता; कई systems detection के बाद retransmission का उपयोग करते हैं।

9. Flow Control

Flow Control sender की transmission rate और receiver की processing/buffering capacity के बीच coordination करने की technique है। इसका उद्देश्य receiver को ऐसी speed से data receive करने से बचाना है जिससे उसके buffers overflow हो जाएँ।

मुख्य Techniques

TechniqueExplanation
Stop-and-WaitSender एक frame भेजकर acknowledgement या required response का wait करता है, फिर next frame भेजता है।
Sliding WindowSender acknowledgement का wait किए बिना allowed window के अंदर multiple frames भेज सकता है। इससे link utilization improve हो सकता है।
Stop-and-Wait Sender Receiver │ -------- Frame 1 --------► │ │ ◄------- ACK 1 ----------- │ │ -------- Frame 2 --------► │ │ ◄------- ACK 2 ----------- │
Easy Difference: Flow Control = speed/manage receiver capacity; Error Control = transmission errors detect/recover.

10. Token Ring

Token Ring एक LAN technology थी जिसमें devices logical ring arrangement में communicate करते थे और transmission permission के लिए एक special frame जिसे token कहा जाता था, circulate करता था। जिस station के पास token होता था, उसे data transmit करने का अवसर मिलता था।

┌──────────┐ │ Station 1│ └────┬─────┘ │ ┌─────────┘ ▼ ┌─────────────┐ ┌─────────────┐ │ Station 4 │ ◄──── │ Station 2 │ └──────┬──────┘ └──────┬──────┘ │ │ └──────► Station 3 ◄─┘ TOKEN circulates around ring

Token Ring की विशेषताएँ

  • Logical ring based access mechanism।
  • Token possession transmission permission देता था।
  • Controlled access के कारण collisions को avoid करने का उद्देश्य।
  • IEEE 802.5 से historically associated।

Advantages

  • Controlled access mechanism।
  • Heavy traffic में predictable access behavior का advantage हो सकता था।
  • Collision-based contention से अलग access approach।

Limitation

Modern Ethernet switching के widespread adoption के कारण Token Ring आज सामान्य enterprise LAN technology नहीं है; यह networking history और concepts समझने के लिए महत्वपूर्ण है।

11. Ethernet

Ethernet IEEE 802.3 family से associated LAN technology है। यह wired local area networking में सबसे widely deployed technologies में से एक है। Traditional shared Ethernet में CSMA/CD mechanism relevant था, जबकि modern switched full-duplex Ethernet में collisions सामान्य operation का हिस्सा नहीं हैं और CSMA/CD की आवश्यकता नहीं होती।

Modern Ethernet LAN PC ───┐ PC ───┼──── SWITCH ───── Router ───── Other Network PC ───┤ Server┘ Ethernet Frame ┌──────┬────────┬──────────┬───────┐ │ MAC │ MAC │ Payload │ FCS │ │ Dest │ Source │ Data │ │ └──────┴────────┴──────────┴───────┘

Ethernet की प्रमुख विशेषताएँ

  • IEEE 802.3 standards family से संबंधित।
  • MAC addressing का उपयोग।
  • Ethernet frames में source और destination MAC addresses।
  • Modern Ethernet में switches का widespread use।
  • Different speeds और physical media के लिए अनेक standards उपलब्ध हैं।

Traditional CSMA/CD

CSMA/CD (Carrier Sense Multiple Access with Collision Detection) traditional shared, half-duplex Ethernet networks में used access method था। Device transmit करने से पहले medium sense करता था और collision होने पर transmission को detect करके retry mechanism use किया जाता था।

Exam Point: CSMA/CD को traditional shared Ethernet से associate करें; modern full-duplex switched Ethernet में collisions नहीं होते, इसलिए CSMA/CD operational requirement नहीं है।

12. FDDI

FDDI (Fiber Distributed Data Interface) एक high-speed LAN technology थी जो primarily optical fibre और token-passing ring architecture का उपयोग करती थी। यह backbone और high-speed networking applications में historically important रही है।

FDDI Dual Ring Concept ┌─────────────────────────┐ │ Primary Ring │ ▼ │ [Node A] → [Node B] → [Node C] ▲ │ └─────────────────────────┘ Secondary Ring ◄──────────────────────── Used for redundancy/fault tolerance

FDDI की विशेषताएँ

  • Fiber optic medium का उपयोग।
  • Token-passing based ring architecture।
  • Dual-ring design redundancy और fault tolerance के लिए उपयोग किया जा सकता था।
  • Historically high-speed LAN/backbone environments में important।

FDDI के फायदे

  • Optical fibre के कारण high bandwidth और long-distance capability।
  • Dual ring architecture से resilience में सहायता।
  • Electromagnetic interference के प्रति fibre की immunity का benefit।

13. Address Resolution Protocol (ARP)

ARP (Address Resolution Protocol) IPv4 networks में किसी known IP address के corresponding local network MAC address को determine करने के लिए उपयोग किया जाता है। यह तब useful होता है जब host को local Ethernet frame बनाने के लिए destination interface का MAC address चाहिए।

Host A IP: 192.168.1.10 MAC: AA:AA:AA:AA:AA:AA ARP Request "Who has 192.168.1.20?" │ ▼ ┌─────────────────┐ │ Local LAN │ └─────────────────┘ │ ▼ Host B IP: 192.168.1.20 MAC: BB:BB:BB:BB:BB:BB ARP Reply "192.168.1.20 is BB:BB:BB:BB:BB:BB"

ARP की Working

Step 1: Sender के पास destination का IPv4 address होता है, लेकिन local destination का MAC address available नहीं होता।
Step 2: Sender local network पर ARP Request broadcast करता है।
Step 3: जिस host का IP address request में match करता है, वह ARP Reply के माध्यम से अपना MAC address बताता है।
Step 4: Sender प्राप्त mapping को ARP cache में temporarily store कर सकता है।
Step 5: Sender destination MAC address के साथ Ethernet frame भेज सकता है।

ARP का महत्व

  • IPv4 logical address को local link-layer address से map करने में सहायता।
  • Ethernet जैसे LANs पर packet delivery के लिए MAC address determination।
  • ARP cache repeated requests को कम करने में सहायता करती है।
Important: ARP का basic purpose IPv4 Address → MAC Address mapping है। इसे IP-to-MAC resolution के रूप में याद करें।
