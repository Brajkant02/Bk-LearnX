1. Introduction

एक personal computer कई hardware components का combination होता है। इन components में processor, motherboard, memory, storage, power supply, input/output devices और firmware प्रमुख हैं। Computer के अंदर सभी components independently काम नहीं करते; motherboard और उसके associated controllers/chipset communication और coordination में महत्वपूर्ण भूमिका निभाते हैं।

PC hardware को समझने के लिए केवल individual parts के नाम जानना पर्याप्त नहीं है। यह समझना भी जरूरी है कि processor instructions कैसे execute करता है, CPU clock timing कैसे निर्धारित करती है, motherboard components को कैसे connect करता है, chipset/controllers data movement को कैसे support करते हैं और BIOS/firmware computer को startup पर operating system तक कैसे पहुँचाता है।

Exam Point: PC system का basic startup sequence broadly Power ON → Firmware initialization → Hardware checks → Boot device selection → Bootloader → Operating System loading होता है।

2. PC-AT और PC-ATX System

2.1 PC-AT क्या है?

PC-AT (Advanced Technology) IBM PC/AT family से जुड़ा एक historical PC hardware design/form factor concept है। इस architecture ने earlier PC design की तुलना में अधिक capable processor, memory expansion और hardware features को support किया। आज “AT” शब्द अक्सर पुराने motherboard/case/power-supply standards के संदर्भ में दिखाई देता है।

AT-based systems में motherboard layout, power connectors और cabinet design modern ATX systems से अलग थे। इसलिए पुराने PC hardware को समझने के लिए AT architecture important historical concept है।

2.2 PC-ATX क्या है?

ATX (Advanced Technology eXtended) Intel द्वारा विकसित motherboard और computer-case design specification है। इसका उद्देश्य motherboard layout, component placement, expansion slots, I/O arrangement और power connections को बेहतर बनाना था। Modern desktop PCs में ATX family के standards और उनके derivatives widely used रहे हैं।

AT System

  • Older PC design.
  • Older motherboard/power arrangement.
  • Modern ATX से अलग connector/layout.
  • Historical importance अधिक।

ATX System

  • Improved motherboard layout.
  • Standardized rear I/O arrangement.
  • Modern power/connectivity design.
  • Better component placement और expandability.

3. Basics of Processor

Processor या CPU (Central Processing Unit) computer का मुख्य processing component है। यह program instructions को fetch, decode और execute करता है तथा arithmetic, logical और control operations perform करता है। CPU को अक्सर computer का “brain” कहा जाता है, हालांकि modern systems में processing कई specialized units में distributed भी हो सकती है।

CPU के Major Parts

ALU – Arithmetic Logic Unit

Addition, subtraction, comparison और logical operations जैसे calculations perform करता है।

Control Unit

Instructions की execution sequence को control करती है और CPU के different parts को coordinate करती है।

Registers

CPU के अंदर मौजूद बहुत fast small storage locations हैं जो temporary data, instructions और addresses hold करते हैं।

Cache

Frequently required data/instructions को processor के करीब रखकर access latency कम करने में सहायता करती है।

Instruction Cycle

4. CPU Clock

CPU Clock processor के operations के लिए timing reference प्रदान करने वाली periodic electronic signal है। Clock cycles में processor की activities synchronize होती हैं। Clock frequency को सामान्यतः Hertz (Hz) में measure किया जाता है; modern CPUs में MHz/GHz units common हैं।

यदि किसी processor की clock frequency 3 GHz है, तो इसका अर्थ लगभग 3 billion clock cycles per second की nominal clock rate है। लेकिन इसका यह अर्थ नहीं कि processor हर cycle में exactly एक instruction execute करता है। Modern CPU performance architecture, instruction complexity, cores, cache, pipeline, memory और कई अन्य factors पर depend करती है।

Clock Speed के Important Terms

  • Clock Cycle: Clock signal का एक basic timing interval.
  • Frequency: प्रति second clock cycles की संख्या।
  • MHz: Million cycles per second.
  • GHz: Billion cycles per second.
  • Core: CPU का independent processing unit जो instructions execute कर सकता है।
  • Multicore CPU: एक processor package में multiple processing cores.
Important: केवल GHz देखकर दो processors की performance decide नहीं करनी चाहिए। Architecture, IPC, core count, cache, workload और power/thermal limits भी performance को प्रभावित करते हैं।

5. Motherboard

Motherboard computer का मुख्य printed circuit board (PCB) है जिस पर CPU socket, memory slots, expansion slots, firmware chip, connectors और अन्य system interfaces मौजूद होते हैं। यह अलग-अलग components को electrical और logical communication paths provide करता है।

Motherboard के Major Components

CPU Socket

Processor को motherboard पर install करने का स्थान।

RAM Slots

Memory modules install करने के लिए slots.

Expansion Slots

Graphics/network/specialized expansion cards के लिए interfaces.

Storage Interfaces

SATA और अन्य storage interfaces के माध्यम से drives connect की जाती हैं।

Firmware

BIOS/UEFI firmware system startup और hardware initialization में महत्वपूर्ण है।

Power Connectors

Power supply से motherboard और processor को required power पहुँचाते हैं।

Rear I/O

USB, audio, networking, display और अन्य external ports provide कर सकता है।

Chipset/Platform Controllers

CPU, memory, storage, USB और अन्य devices के communication को support करते हैं।

6. Chipset & Controllers

Chipset

Chipset motherboard/platform पर मौजूद controller logic का collection है जो processor और different system components के बीच communication और control functions provide करता है। Older PC architectures में chipset को commonly Northbridge और Southbridge जैसे parts में describe किया जाता था। Modern systems में कई traditional northbridge functions processor के अंदर integrate हो चुके हैं और platform controller hub जैसे designs use होते हैं।

Northbridge – Historical Concept

Traditional architecture में Northbridge high-speed components जैसे CPU, main memory और graphics interface के बीच communication handle करता था। यह modern systems में largely integrated functionality के रूप में बदल चुका है।

Southbridge – Historical Concept

Southbridge traditional architecture में comparatively slower I/O devices जैसे USB, storage interfaces, audio और other peripherals को manage करने से संबंधित था।

Controllers

Controller hardware logic/device interface है जो किसी particular device या function को manage करने और system bus/CPU तथा peripheral के बीच communication support करने का काम करता है। Examples में storage controller, USB controller, network controller और display controller शामिल हो सकते हैं।

7. BIOS

BIOS (Basic Input/Output System) traditional PC firmware है जो system के power-on/startup के समय hardware initialization और basic boot services provide करता है। BIOS motherboard के non-volatile firmware storage में रखा जाता है। Modern computers में traditional BIOS की जगह UEFI (Unified Extensible Firmware Interface) widely used है, लेकिन “BIOS” शब्द सामान्य conversation में firmware के लिए भी इस्तेमाल होता है।

BIOS के प्रमुख Functions

  • Power-on के बाद basic hardware initialization करना।
  • System components की basic checking/diagnostics में सहायता करना।
  • Hardware configuration information maintain करना।
  • Boot device identify/select करने में सहायता करना।
  • Bootloader/operating system loading process को initiate करना।
  • Basic firmware-level setup interface provide करना।

BIOS Setup में Common Settings

  • Boot order
  • Date and time
  • Storage/device configuration
  • CPU और memory related settings
  • Security/password settings
  • Peripheral enable/disable options
BIOS vs Operating System: BIOS/UEFI firmware startup stage पर hardware initialize करके boot process शुरू करता है, जबकि Windows/Linux जैसे operating systems computer को normal runtime environment में manage करते हैं।

8. Boot Process

Booting वह process है जिसमें computer power-on/reset के बाद hardware initialize करता है और अंततः operating system को memory में load करके उसे execution के लिए start करता है।

Boot Process – Step by Step

Power On: Power supply system को electrical power देती है और CPU reset/start state से operation begin करता है।
Firmware Starts: BIOS या UEFI firmware execute होता है और basic hardware initialization करता है।
Hardware Check: Firmware available hardware और required startup conditions की जांच करता है। Traditional systems में POST (Power-On Self-Test) इस stage से associated है।
Hardware Initialization: Memory, storage interfaces, display और अन्य essential devices initialize/configure किए जाते हैं।
Boot Device Selection: Firmware configured boot order के आधार पर bootable device तलाशता है।
Bootloader: Selected device से bootloader का code load और execute किया जाता है।
Operating System Loading: Bootloader operating system के required components/kernel को memory में load करता है।
OS Initialization: Operating system drivers, services, user interface और other runtime components initialize करता है।
Login/Desktop: System user interaction के लिए ready हो जाता है।
POWER ON ↓ BIOS / UEFI ↓ POST / HARDWARE INITIALIZATION ↓ BOOT DEVICE SELECTION ↓ BOOTLOADER ↓ OPERATING SYSTEM KERNEL ↓ DRIVERS + SERVICES ↓ LOGIN / DESKTOP

Cold Boot और Warm Boot

Cold Boot

System को powered-off state से power on करके start करना।

Warm Boot

Already running system को restart/reboot करना, बिना complete power-off state से शुरू किए।
