1. Keyboard Introduction

Keyboard एक input device है जिसका उपयोग computer में alphabets, numbers, symbols, commands और अन्य control information enter करने के लिए किया जाता है। Keyboard पर उपस्थित keys को press करने पर keyboard का internal electronic circuit उस key press को detect करता है और उसका corresponding signal computer तक भेजता है।

Modern keyboards में individual keys सामान्यतः एक key matrix के रूप में electrically arranged होती हैं। Keyboard controller लगातार इस matrix को scan करता है। जब कोई key press होती है, controller उसके row और column की पहचान करके उस key का corresponding code तैयार करता है और interface के माध्यम से computer को भेजता है।

Exam Definition: Keyboard एक electronic input device है जो key press को detect करके उसे electrical/digital signals में convert करता है और computer को भेजता है।

2. Keyboard Circuit

Keyboard circuit का मुख्य उद्देश्य किसी key के दबने की स्थिति को electrically detect करना और उसे पहचान योग्य digital information में convert करना है। इसके लिए keyboard में key switches, matrix lines, controller/processor, firmware और communication interface जैसे मुख्य parts होते हैं।

Key Switches

जब user किसी key को press करता है तो उसका switch circuit की corresponding row और column lines के बीच electrical connection बनाता या बदलता है।

Key Matrix

Keys को rows और columns के arrangement में organize किया जाता है। इससे प्रत्येक key को कम number of electrical lines के द्वारा identify किया जा सकता है।

Keyboard Controller

Controller matrix को scan करता है, key press/release detect करता है, debounce तथा key identification जैसे tasks संभालता है और output code generate करता है।

Firmware

Controller में चलने वाला firmware key mapping, scanning और communication के rules को manage करता है।

Interface Circuit

Controller से प्राप्त information को computer तक suitable communication protocol/interface के माध्यम से भेजता है।

Connector/Cable

Wired keyboard में USB जैसे interface के माध्यम से keyboard और computer के बीच power तथा communication connection provide किया जाता है।

4. Key Matrix

Key Matrix keyboard circuit का important हिस्सा है। इसमें keys को rows और columns के intersection पर arrange किया जाता है। प्रत्येक key press एक particular row और column combination को identify करने में सहायता करता है।

COLUMN LINES C1 C2 C3 C4 │ │ │ │ R1 ───┼────●────┼────●─── R2 ───●────┼────●────┼─── R3 ───┼────●────┼────●─── R4 ───●────┼────●────┼─── │ │ │ │ ● = Key switch position R = Row line C = Column line

Controller rows और columns को scan करके पता लगाता है कि कौन-सा switch active हुआ है। इस method से keyboard को प्रत्येक key के लिए अलग wire की आवश्यकता नहीं होती।

Matrix Scanning

1. Controller एक या अधिक matrix lines को scan/drive करता है।
2. दूसरी lines की state read की जाती है।
3. यदि key press से electrical path change हुआ है, controller active row और column identify करता है।
4. Row-column combination को corresponding key position से map किया जाता है।

5. Keyboard Controller

Keyboard controller keyboard का central electronic control unit है। यह key matrix और computer interface के बीच मुख्य bridge का काम करता है।

FunctionDescription
Matrix ScanningRows और columns को scan करके pressed/released keys detect करना।
DebouncingMechanical switch के contact bounce से आने वाले unwanted multiple transitions को filter करना।
Key IdentificationDetected row-column position को specific key से associate करना।
Key MappingPhysical key position को firmware-defined key code/action से map करना।
CommunicationGenerated keyboard information को host computer तक भेजना।
LED/Status Controlकुछ keyboards में Caps Lock, Num Lock आदि indicator LEDs को control करना।
Note: Keyboard controller का exact architecture keyboard model और protocol के अनुसार अलग हो सकता है।

6. Keyboard Working — Step by Step

जब user keyboard की कोई key press करता है, तब keyboard circuit में कई electronic steps होते हैं।

Step 1 – Key Press: User किसी key को press करता है और उसका switch electrical state change करता है।
Step 2 – Matrix Detection: Key matrix में corresponding row और column के बीच connection detect होता है।
Step 3 – Scanning: Keyboard controller matrix को scan करके active row-column position identify करता है।
Step 4 – Debouncing: Controller short-duration unwanted switch transitions को filter करता है ताकि एक press को कई presses न माना जाए।
Step 5 – Key Mapping: Controller detected position को corresponding key identity/code से map करता है।
Step 6 – Communication: Keyboard generated information को USB, PS/2 या wireless mechanism के माध्यम से host तक भेजता है।
Step 7 – OS Processing: Operating system keyboard input को receive करके driver/input subsystem के माध्यम से application तक पहुंचाता है।
Step 8 – Result: Application उस input के अनुसार character, command या action perform करती है।

7. Keyboard Interface

Keyboard controller द्वारा तैयार information host computer तक एक communication interface के माध्यम से भेजी जाती है। Wired keyboards में USB बहुत common है; older systems में PS/2 interface भी widely used था। Wireless keyboards radio-based communication के माध्यम से receiver/host से communicate कर सकते हैं।

USB Keyboard

Modern computers में common wired interface। यह data communication के साथ keyboard को power भी provide कर सकता है।

PS/2 Keyboard

एक legacy keyboard interface है जो पुराने PCs और motherboards में common था।

Wireless Keyboard

Physical data cable की जगह wireless radio communication और receiver/Bluetooth जैसी technology का उपयोग कर सकता है।

9. Basic Keyboard Troubleshooting

Keyboard not detected: USB connection, port, wireless receiver/battery और system settings check करें।
Some keys not working: Key mechanism, dirt/debris, matrix line या controller-related issue हो सकता है।
Repeated characters: Key switch issue, debounce problem या software/input setting check करें।
Wrong characters: Operating system का keyboard layout/language setting verify करें।
Wireless keyboard not responding: Battery/charging, receiver pairing और wireless connection check करें।
