1. Introduction to Computer System

Computer एक electronic programmable machine है जो user द्वारा दिए गए data और instructions को accept करता है, उन्हें process करता है, required information produce करता है और data/results को आवश्यकता के अनुसार store भी कर सकता है। Computer system का basic working pattern Input → Processing → Output है, जबकि storage और control पूरी प्रक्रिया को support करते हैं।

एक complete computer system में केवल CPU ही नहीं होता। इसमें input devices, output devices, memory/storage और communication paths भी महत्वपूर्ण होते हैं। Modern computer architecture में CPU memory और I/O devices के साथ मिलकर instructions execute करता है और data को process करता है।

Computer fundamentals के अनुसार मुख्य functional activities हैं: input लेना, data store करना, data process करना, output देना और पूरे workflow को control करना। citeturn0search3turn0search5

Input

User या external device से raw data और instructions computer में enter किए जाते हैं।

Processing

CPU instructions के अनुसार data पर arithmetic और logical operations perform करता है।

Storage

Data, instructions, intermediate results और final results को temporary या permanently store किया जाता है।

Output

Processed result को monitor, printer, speaker आदि के माध्यम से user तक पहुँचाया जाता है।

Exam Definition: A computer system is an electronic system consisting of input, processing, storage and output components that works together under the control of instructions to convert data into useful information.

3. Input Unit & Input Devices

Input Unit computer system का वह functional part है जिसके द्वारा user data और instructions computer को देता है। Input device user की information को ऐसे signals/data representation में convert करता है जिसे computer system process कर सके। Keyboard, mouse, scanner, microphone और barcode reader इसके common examples हैं। citeturn0search3turn0search10

Functions of Input Unit

  • User से data और instructions accept करना।
  • Input data को computer के लिए suitable form में convert करना।
  • Data/instructions को processing system तक भेजना।
  • Input और computer processing के बीच communication link बनाना।

4. Output Unit & Output Devices

Output Unit computer system के processed result को user के लिए understandable form में प्रस्तुत करती है। Output visual, printed या audio form में हो सकता है। Monitor, printer, speaker और projector common output devices हैं। citeturn0search3turn0search9

Functions

  • CPU/processing system से result receive करना।
  • Computer-readable result को suitable human-readable form में convert/present करना।
  • Information को display, print या play करना।

Soft Copy vs Hard Copy

Soft Copy electronic form में दिखाई देने वाली information है, जैसे monitor पर document। Hard Copy physical printed form है, जैसे printer से निकला document।

5. Central Processing Unit (CPU)

CPU (Central Processing Unit) computer का primary processing component है। इसे सामान्यतः computer का “brain” कहा जाता है क्योंकि यह instructions execute करता है, calculations करता है और system के विभिन्न components के operations को coordinate करता है। citeturn0search2turn0search8

जब कोई program run होता है, CPU memory से instructions fetch करता है, उन्हें decode करता है और फिर required operation execute करता है। Processing के दौरान CPU memory तथा input/output devices के साथ data exchange करता है। यह basic fetch → decode → execute cycle के द्वारा instructions process करता है। citeturn0search6

CPU के Main Components

Control Unit (CU)

Instructions को fetch/decode करके computer components की activities को coordinate और control करती है।

ALU

Arithmetic calculations और logical/comparison operations perform करता है।

Registers

CPU के अंदर बहुत fast temporary storage locations हैं जिनमें processing के दौरान data/instructions/addresses रखे जा सकते हैं।

Cache

High-speed memory layer जो frequently needed data/instructions तक CPU की access को तेज करने में मदद करती है।

Exam Point: CPU अकेले केवल calculation unit नहीं है; इसमें control, execution और fast temporary data handling के लिए अलग-अलग functional components होते हैं।

6. Control Unit (CU)

Control Unit CPU का वह component है जो computer system में instructions और data movement को coordinate करता है। यह memory से instructions प्राप्त करता है, उन्हें interpret/decode करता है और appropriate control signals के माध्यम से required operations करवाता है। citeturn0search2turn0search24

Functions of Control Unit

  • Memory से instruction fetch करना।
  • Fetched instruction को decode/interpret करना।
  • ALU को required operation perform करने के लिए control करना।
  • Registers और memory के बीच data movement coordinate करना।
  • Input/output devices के साथ data transfer को manage करना।
  • Computer system के different units के बीच timing और control signals coordinate करना।

Fetch–Decode–Execute Cycle

FETCH ↓ Memory से Instruction प्राप्त ↓ DECODE ↓ Instruction का अर्थ/operation determine ↓ EXECUTE ↓ ALU / Registers / Memory / I-O required action ↓ RESULT ↓ Next Instruction

7. Arithmetic & Logic Unit (ALU)

ALU (Arithmetic Logic Unit) CPU का वह component है जो arithmetic तथा logical operations perform करता है। Arithmetic section addition, subtraction, multiplication और division जैसे calculations करता है; logic section comparison और logical decision operations करता है। citeturn0search12turn0search3

A. Arithmetic Operations

  • Addition (+)
  • Subtraction (−)
  • Multiplication (×)
  • Division (÷)
  • Increment और decrement जैसे operations, architecture के अनुसार।

B. Logical / Comparison Operations

  • Equal to (=)
  • Greater than (>)
  • Less than (<)
  • AND, OR, NOT, XOR जैसे logical operations
  • Bit shifting जैसी operations, architecture के अनुसार।

ALU Example

यदि computer को 25 + 15 calculate करना है, तो required operands processing path के माध्यम से ALU तक पहुँचते हैं। ALU addition operation perform करता है और result 40 तैयार होता है। इसी तरह यदि 75 > 50 check करना है, तो ALU comparison करके logical result produce कर सकता है।

Important: ALU का मुख्य काम data पर arithmetic और logical processing करना है; instructions की overall control/coordination की responsibility Control Unit की होती है।

8. Memory Unit

Memory computer system का वह hardware component है जिसका उपयोग data, program instructions और processing results को store करने के लिए किया जाता है। Processing के दौरान CPU को instructions और data तक fast access चाहिए, इसलिए memory system computer performance का अत्यंत महत्वपूर्ण हिस्सा है। citeturn0search2turn0search3

Memory को broadly Primary Memory और Secondary Memory/Storage के रूप में समझा जाता है। Primary memory CPU के active processing environment के बहुत करीब होती है, जबकि secondary storage large-capacity, long-term data storage के लिए उपयोग होती है।

Memory के Main Functions

  • Program instructions store करना।
  • Input data को processing के लिए hold करना।
  • Intermediate results store करना।
  • Final results को temporarily hold करना।
  • CPU को required data/instructions उपलब्ध कराना।

9. Primary Memory

Primary Memory या main memory वह memory है जिसका उपयोग CPU के active processing के दौरान instructions और data को readily accessible form में रखने के लिए किया जाता है। RAM और ROM इसके important examples हैं। citeturn0search2turn0search3

9.1 RAM (Random Access Memory)

RAM computer की मुख्य volatile working memory है। Programs और data जब actively use हो रहे होते हैं, तब RAM में रखा जा सकता है। Power बंद होने पर सामान्य RAM का stored content retain नहीं रहता। citeturn0search2

RAM की Characteristics

  • Volatile memory.
  • Read/write operations support करती है।
  • Active programs के execution में महत्वपूर्ण भूमिका।
  • CPU के लिए frequently accessed working data रखने में उपयोगी।

RAM के Common Types

TypeGeneral Description
SRAMStatic RAM; fast और comparatively expensive, cache-related applications में commonly used.
DRAMDynamic RAM; comparatively high density और main memory में widely used.

9.2 ROM (Read Only Memory)

ROM non-volatile memory category है जिसका data power off होने के बाद भी retain रहता है। इसका उपयोग firmware या relatively permanent instructions रखने के लिए किया जा सकता है।

ROM TypeMeaning / Feature
PROMProgrammable Read-Only Memory; सामान्यतः एक बार program करने के लिए।
EPROMErasable Programmable ROM; suitable process के द्वारा erase/reprogram किया जा सकता है।
EEPROMElectrically Erasable Programmable ROM; electrical method से erase/reprogram किया जा सकता है।

9.3 Cache Memory

Cache एक high-speed memory layer है जो CPU और main memory के बीच access latency कम करने में सहायता करती है। Frequently used instructions/data के लिए cache useful होती है। CPU architecture में अलग-अलग cache levels जैसे L1, L2 और L3 हो सकते हैं।

10. Secondary Memory / Storage

Secondary storage का उपयोग data और files को long-term/permanent storage के लिए किया जाता है। Primary memory की तुलना में यह generally large capacity प्रदान करती है और non-volatile होती है। Common examples में HDD, SSD, USB flash drive और memory card शामिल हैं।

Difference: RAM active working data के लिए fast temporary memory है, जबकि SSD/HDD जैसे secondary storage devices files और programs को long-term रखने के लिए उपयोग किए जाते हैं।

11. Memory Hierarchy

Computer में सभी memories की speed, cost और capacity समान नहीं होती। इसलिए memories को hierarchy में समझा जाता है। सामान्यतः CPU के सबसे पास वाली memory तेज और छोटी होती है, जबकि large-capacity storage comparatively slower होती है।

FASTEST / SMALLEST ▲ │ CPU REGISTERS │ CACHE │ MAIN MEMORY (RAM) │ SECONDARY STORAGE SSD / HDD │ LARGE ARCHIVAL STORAGE ▼ SLOWER / LARGER

यह hierarchy performance और cost के बीच balance बनाने में मदद करती है। CPU registers और cache बहुत fast access provide करते हैं, जबकि secondary storage अधिक data capacity provide करता है।

12. Working of a Computer System

Computer का working process एक continuous cycle की तरह समझा जा सकता है जिसमें user input देता है, system data को memory में रखता है, CPU instructions execute करता है और result output के रूप में मिलता है।

USER ↓ INPUT DEVICE ↓ INPUT DATA / INSTRUCTIONS ↓ MEMORY ↓ CONTROL UNIT → Instruction Fetch & Decode ↓ ALU / CPU REGISTERS → Processing ↓ MEMORY ↓ OUTPUT UNIT ↓ USER

Step-by-Step Explanation

Input: User keyboard, mouse, scanner आदि से data/instructions देता है।
Storage: Required data/instructions memory में available होते हैं।
Fetch: CPU memory से instruction प्राप्त करता है।
Decode: Control Unit instruction को interpret करती है।
Execute: Required arithmetic/logical operation ALU और अन्य CPU components perform करते हैं।
Store: Result temporary memory या required storage location में रखा जा सकता है।
Output: Result monitor, printer, speaker आदि output device के माध्यम से user तक पहुँचता है।

13. Real-Life Example: Student Marks Calculation

मान लीजिए student के तीन marks हैं: 70, 80 और 90 और computer को total तथा average निकालना है।

Input: Keyboard से 70, 80 और 90 enter किए जाते हैं।
Memory: Entered values और required program instructions memory में available रहते हैं।
Control: Control Unit required instructions को fetch और coordinate करती है।
ALU: ALU addition करके 70 + 80 + 90 = 240 calculate करता है।
ALU: Average के लिए 240 ÷ 3 = 80 calculate किया जाता है।
Output: Monitor पर Total = 240 और Average = 80 display किया जाता है।
Concept: इस example में Keyboard = Input, RAM = working memory, CPU/CU = control, ALU = calculation और Monitor = Output का role समझा जा सकता है।
