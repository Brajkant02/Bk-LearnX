Network Administration

Network Administration

Network Administration वह process है जिसमें किसी computer network को plan, configure, monitor, secure और troubleshoot किया जाता है। Network administrator का काम यह ensure करना होता है कि network properly काम करे, users को सही access मिले, devices को IP address मिले, internet और local resources available रहें और unauthorized access से network secure रहे।

एक organization, college, office या computer lab में कई computers, servers, printers, routers और switches connected होते हैं। इन सभी devices को manage करने के लिए network administration की जरूरत होती है। इसमें security policies बनाना, DHCP server configure करना, network problems find करना, secure protocols use करना और users को workgroup या domain environment में manage करना शामिल है।

Need of Network Administration

  • Network को secure, reliable और fast बनाए रखने के लिए।
  • Users और computers को proper IP address और access देने के लिए।
  • Network problems को जल्दी troubleshoot करने के लिए।
  • Servers, routers, switches और clients को centrally manage करने के लिए।
  • Data protection, authentication और resource sharing को control करने के लिए।
Real Life Example:
College computer lab में network administrator सभी computers को network से connect रखता है, internet access manage करता है, DHCP से IP assign करवाता है और network slow होने पर PING, IPCONFIG, NETSTAT जैसे tools से problem check करता है।

Network Security

Network Security का मतलब network, data, devices और services को unauthorized access, misuse, modification, attack और damage से protect करना है। Network security में hardware, software, policies और procedures use किए जाते हैं ताकि network safe रहे। इसमें firewall, antivirus, encryption, authentication, access control, secure protocols और monitoring tools important role play करते हैं।

Network security का main goal यह होता है कि सही user को सही resource मिले और गलत user या attacker network में enter न कर सके। अगर network secure नहीं है, तो data चोरी हो सकता है, password leak हो सकते हैं, system hack हो सकता है और organization का important work रुक सकता है।

CIA Principle

Principle Meaning Example
Confidentiality Data केवल authorized users को ही visible होना चाहिए। Password, encryption और access control.
Integrity Data unauthorized तरीके से change नहीं होना चाहिए। Hashing, checksum और digital signature.
Availability Network services जरूरत के समय available होनी चाहिए। Backup server, UPS और DDoS protection.

Main Network Security Principles

  • Authentication: User की identity verify करना, जैसे username-password, OTP, biometric.
  • Authorization: Verified user को कौन-कौन से resources access करने हैं, यह decide करना।
  • Access Control: Users और devices के access को rules के according control करना।
  • Encryption: Data को unreadable form में convert करना ताकि चोरी होने पर भी data समझ न आए।
  • Firewall Protection: Incoming और outgoing traffic को filter करना।
  • Auditing and Logging: Network activities का record रखना ताकि suspicious activity पता चल सके।
  • Backup and Recovery: Data loss होने पर data वापस प्राप्त करने के लिए backup रखना।
Remember:
Network Security का base concept CIA है: Confidentiality, Integrity और Availability.

Cryptography

Cryptography वह technique है जिसके द्वारा data को secure form में convert किया जाता है ताकि unauthorized person उसे read न कर सके। इसमें original message को Plain Text कहा जाता है और encrypted message को Cipher Text कहा जाता है। Cipher text को वापस plain text में convert करने की process Decryption कहलाती है।

Plain Text → Encryption Algorithm + Key → Cipher Text
Cipher Text → Decryption Algorithm + Key → Plain Text

Important Terms

Term Explanation
Plain Text Original readable message.
Cipher Text Encrypted unreadable message.
Encryption Plain text को cipher text में बदलना।
Decryption Cipher text को वापस plain text में बदलना।
Key Secret value जिसके द्वारा encryption/decryption होती है।

Types of Cryptography

1. Symmetric Key Cryptography

Symmetric cryptography में encryption और decryption दोनों के लिए same key use होती है। Sender और receiver दोनों के पास वही secret key होनी चाहिए। यह method fast होती है, लेकिन key को safely share करना difficult हो सकता है।

Example: AES, DES. Real life में file encryption और VPN में symmetric encryption use हो सकती है।

2. Asymmetric Key Cryptography

Asymmetric cryptography में दो keys use होती हैं: Public Key और Private Key। Public key सबके साथ share की जा सकती है, लेकिन private key secret रखी जाती है। जो data public key से encrypt होता है, उसे private key से decrypt किया जा सकता है।

Example: RSA. HTTPS और digital certificates में asymmetric cryptography important role play करती है।

3. Hashing

Hashing में data को fixed length hash value में convert किया जाता है। Hashing one-way process है, यानी hash से original data वापस प्राप्त नहीं किया जा सकता। यह password storage, data integrity check और digital signature में use होती है।

Example: अगर file download के बाद उसका hash match करता है, तो file सही और unchanged मानी जाती है।

Secure Protocols

Secure Protocols वे communication rules होते हैं जो network पर data transfer करते समय security provide करते हैं। Secure protocols data को encrypt करते हैं, user/server authentication provide करते हैं और data integrity maintain करते हैं। पुराने insecure protocols जैसे HTTP, FTP और Telnet में data plain text में जा सकता है, इसलिए attacker password या data read कर सकता है।

Secure Protocol Full Form / Meaning Use
HTTPS Hyper Text Transfer Protocol Secure Secure website browsing.
SSL/TLS Secure Sockets Layer / Transport Layer Security Encrypted communication provide करना।
SSH Secure Shell Remote server login securely.
SFTP Secure File Transfer Protocol Secure file transfer.
FTPS FTP Secure FTP को SSL/TLS के साथ secure करना।
VPN Virtual Private Network Public internet पर secure private tunnel बनाना।
IPsec Internet Protocol Security IP packets को secure करना।
Exam Tip:
Telnet की जगह SSH, HTTP की जगह HTTPS और FTP की जगह SFTP/FTPS use करना ज्यादा secure माना जाता है।

PING

PING एक basic network troubleshooting command है जिसका use यह check करने के लिए किया जाता है कि कोई device या server reachable है या नहीं। PING ICMP Echo Request भेजता है और destination से ICMP Echo Reply receive करता है। इससे पता चलता है कि network connectivity working है या नहीं।

Syntax

ping destination_address

Example

ping google.com
ping 192.168.1.1

Output Meaning

  • Reply from: Destination reachable है।
  • Request timed out: Reply नहीं मिला, connection या firewall problem हो सकती है।
  • TTL: Time To Live value packet की lifetime indicate करती है।
  • Time: Response आने में कितना समय लगा।
Real Life Example:
अगर internet नहीं चल रहा, तो पहले ping 192.168.1.1 से router check करें और फिर ping google.com से internet/DNS check करें।

IPCONFIG

IPCONFIG Windows command है जिसके द्वारा computer का IP address, subnet mask, default gateway और DNS information check की जाती है। यह command DHCP related problems solve करने में भी useful है।

Common Commands

ipconfig
ipconfig /all
ipconfig /release
ipconfig /renew
ipconfig /flushdns
Command Use
ipconfig Basic IP configuration show करता है।
ipconfig /all Detailed IP, MAC, DNS और DHCP information show करता है।
ipconfig /release Current DHCP IP release करता है।
ipconfig /renew DHCP server से नया IP प्राप्त करता है।
ipconfig /flushdns DNS cache clear करता है।

IFCONFIG

IFCONFIG Linux/Unix based systems में network interfaces की configuration देखने और manage करने के लिए use होता है। इससे IP address, MAC address, subnet mask और interface status check किया जा सकता है। Modern Linux systems में ip addr command भी use होती है।

Examples

ifconfig
ifconfig eth0
ifconfig wlan0
ip addr show
Real Life Example:
Linux server में कौन सा IP assign है, यह check करने के लिए administrator ifconfig या ip addr command use करता है।

NETSTAT

NETSTAT का full form Network Statistics है। यह command active network connections, listening ports, routing table और protocol statistics show करती है। इससे पता चलता है कि computer किन IP addresses से connected है और कौन से ports open हैं।

Common Commands

netstat
netstat -a
netstat -n
netstat -ano
Command Use
netstat -a All connections and listening ports show करता है।
netstat -n Addresses और ports को numeric form में show करता है।
netstat -ano PID के साथ active connections show करता है।

TRACERT / TRACEROOT

TRACERT Windows command है और TRACEROUTE Linux/Unix command है। यह command यह बताती है कि packet source से destination तक किन-किन routers या hops से होकर जा रहा है। Syllabus में TRACEROOT लिखा है, लेकिन commonly command का name traceroute होता है।

Syntax

tracert google.com (Windows)
traceroute google.com (Linux)

Use

  • Internet route path check करने के लिए।
  • किस hop पर delay या packet loss है, यह identify करने के लिए।
  • Routing problem troubleshoot करने के लिए।

Wireshark

Wireshark एक graphical packet analyzer tool है जिसका use network packets को capture और analyze करने के लिए किया जाता है। इससे administrator यह देख सकता है कि network में कौन सा data packet जा रहा है, कौन सा protocol use हो रहा है, source/destination IP क्या है और packet में error या delay कहाँ है।

Uses

  • Packet capture और analysis.
  • Protocol level troubleshooting.
  • Suspicious traffic detect करना।
  • DNS, TCP, HTTP, ICMP traffic check करना।
Important:
Wireshark को केवल अपने authorized network पर learning और troubleshooting purpose के लिए use करना चाहिए।

Nmap Network Scanner

Nmap का full form Network Mapper है। यह एक network scanning tool है जो network में active hosts, open ports, running services और operating system information identify करने में help करता है। Network administrator इसका use security auditing और inventory के लिए करता है।

Examples

nmap 192.168.1.1
nmap 192.168.1.0/24

Uses

  • Network में active devices check करना।
  • Open ports और running services identify करना।
  • Security audit और vulnerability checking में help करना।
Legal Reminder:
Nmap scanning केवल अपने network या authorized system पर करें। किसी दूसरे network को बिना permission scan करना गलत हो सकता है।

TCPDUMP

TCPDUMP Linux/Unix command-line packet capture tool है। यह network interface पर आने-जाने वाले packets को capture और display करता है। Wireshark GUI based है, जबकि TCPDUMP command line based है। Server environment में TCPDUMP बहुत useful होता है क्योंकि वहाँ GUI available नहीं होता।

Examples

tcpdump
tcpdump -i eth0
tcpdump host 192.168.1.10
tcpdump port 80

Uses

  • Server traffic capture करना।
  • Specific host या port traffic analyze करना।
  • Network delay, packet loss और suspicious packets identify करना।

DHCP Server

DHCP का full form Dynamic Host Configuration Protocol है। DHCP Server network devices को automatically IP address, subnet mask, default gateway और DNS server information assign करता है। अगर DHCP नहीं हो, तो administrator को हर computer में manually IP address set करना पड़ेगा।

DHCP server network administration को आसान बनाता है क्योंकि यह IP address management automatically करता है। Home router में भी DHCP server होता है, जो mobile, laptop और computer को automatic IP देता है।

DORA Process

D - Discover : Client network में DHCP server खोजता है।
O - Offer : DHCP server IP address offer करता है।
R - Request : Client offered IP address request करता है।
A - Acknowledge : Server IP address confirm करके lease देता है।

Important DHCP Terms

Term Explanation
Scope IP addresses की range जो DHCP server assign कर सकता है।
Lease Time IP address कितने time के लिए client को दिया गया है।
Reservation किसी specific device को हमेशा same IP देना।
DHCP Relay Different network में DHCP request forward करना।
Default Gateway Network से बाहर जाने के लिए router IP.

Advantages of DHCP

  • IP address automatic assign होता है।
  • Manual configuration की जरूरत कम होती है।
  • IP conflict की possibility कम होती है।
  • Large network में IP management easy होता है।
  • DNS और gateway information भी automatically मिल जाती है।

Disadvantages of DHCP

  • DHCP server down होने पर new devices को IP नहीं मिलेगा।
  • Security के लिए rogue DHCP server problem create कर सकता है।
  • कुछ servers/printers को static IP या reservation की जरूरत होती है।
Real Life Example:
जब आप mobile को Wi-Fi से connect करते हैं, तो router का DHCP server mobile को automatic IP देता है, जैसे 192.168.1.5।

Workgroup / Domain Networking

Workgroup एक peer-to-peer network model है जिसमें सभी computers लगभग equal होते हैं। इसमें कोई central server या central user management नहीं होता। हर computer अपने local users, files और permissions को खुद manage करता है। छोटे home network या small office में workgroup use किया जा सकता है।

Features of Workgroup

  • Small network के लिए suitable है।
  • Central server की जरूरत नहीं होती।
  • हर computer अपने users और resources खुद manage करता है।
  • Setup simple होता है।
  • Security और centralized control limited होता है।
Real Life Example:
घर में 2 laptop और 1 printer connected हैं और वे files/printer share कर रहे हैं, तो यह simple workgroup network हो सकता है।

Domain Networking

Domain एक client-server based network model है जिसमें users, computers और resources को centrally manage किया जाता है। Domain में एक special server होता है जिसे Domain Controller कहा जाता है। Domain controller user authentication, policies, permissions और security settings को manage करता है।

Important Domain Terms

Term Explanation
Domain Controller Central server जो users, computers और authentication manage करता है।
Active Directory Microsoft directory service जिसमें users, groups, computers और policies store होते हैं।
Client Domain से joined computer.
Group Policy Central rules जिनसे user/computer settings control होती हैं।
Authentication User identity verify करने की process.

Features of Domain

  • Centralized user management.
  • Better security and access control.
  • Group Policy से settings centrally apply होती हैं।
  • Large organization और college network के लिए suitable है।
  • Administrator एक जगह से users और computers manage कर सकता है।
Real Life Example:
किसी college में सभी lab computers domain से joined हैं। Student अपने username-password से किसी भी lab computer में login कर सकता है। Administrator password policy, desktop restrictions और software access centrally control कर सकता है।
