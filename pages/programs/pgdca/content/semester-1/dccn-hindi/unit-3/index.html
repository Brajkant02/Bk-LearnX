Concept of Network

Introduction

Computer Network का Basic Idea

आज के समय में computer अकेले काम करने के बजाय network में connect होकर ज्यादा useful बन जाता है। जब दो या दो से अधिक computers, laptops, mobiles, printers, servers या other devices किसी communication medium के through आपस में connect होते हैं, तो वे एक Computer Network बनाते हैं। Network का main purpose data sharing, resource sharing, communication और centralized management को आसान बनाना होता है।

Example के लिए college lab में कई computers एक switch से connected होते हैं। सभी computers एक printer share कर सकते हैं, internet use कर सकते हैं और server से files access कर सकते हैं। इसी तरह office में employees email, file server, database server और internet को network के through use करते हैं। इसलिए computer network modern computing का बहुत important part है।

Real Life Example:
Cyber cafe, school computer lab, bank branch, railway reservation system और office LAN computer network के practical examples हैं।

Concept of Network

Network की Definition

Network दो या दो से अधिक devices का ऐसा group होता है जो communication medium के through connected होते हैं और data, information, hardware resources तथा software services को share कर सकते हैं। Network में connected हर device को node कहा जाता है। Node computer, printer, server, router, switch या mobile device हो सकता है।

Network में communication wired medium जैसे twisted pair cable, coaxial cable, fiber optic cable या wireless medium जैसे Wi-Fi, Bluetooth, radio waves और infrared के through हो सकता है। Network का size छोटा भी हो सकता है, जैसे home network, और बहुत बड़ा भी हो सकता है, जैसे internet। Internet दुनिया का सबसे बड़ा computer network माना जाता है।

Need of Network

  • Data Sharing: एक computer से दूसरे computer तक files और information transfer करने के लिए।
  • Resource Sharing: Printer, scanner, storage और internet connection को multiple users में share करने के लिए।
  • Communication: Email, chat, video call और online meeting के लिए।
  • Centralized Control: Users, data और security को एक central place से manage करने के लिए।
  • Cost Saving: हर computer के लिए अलग printer या storage लेने की जरूरत कम हो जाती है।

Models of Network Computing

Network Computing Models

Network Computing Model यह बताता है कि network में processing, storage, applications और services किस तरह organize और use की जाती हैं। अलग-अलग organizations अपनी need के according different computing models use करती हैं। इन models से यह decide होता है कि data कहाँ store होगा, processing कहाँ होगी और users services को कैसे access करेंगे।

1. Centralized Computing

Centralized computing में main processing और data storage एक central computer या server पर होता है। Users terminals या clients के through central system को access करते हैं। इस model में data control और security manage करना आसान होता है क्योंकि resources एक जगह होते हैं। लेकिन अगर central system fail हो जाए, तो entire network affected हो सकता है।

2. Distributed Computing

Distributed computing में processing और data multiple computers में distribute होते हैं। सभी computers network के through connected रहते हैं और मिलकर एक बड़ा task complete कर सकते हैं। इसमें performance और reliability better हो सकती है क्योंकि work एक ही machine पर dependent नहीं होता।

3. Client-Server Computing

Client-server computing में server services provide करता है और client उन services को request करता है। Server पर data, application, authentication या database हो सकता है। Client server से request भेजता है और server response देता है। यह model offices, websites, banking और online applications में बहुत common है।

4. Peer-to-Peer Computing

Peer-to-peer computing में सभी computers लगभग equal role रखते हैं। कोई dedicated central server जरूरी नहीं होता। हर computer अपनी files या resources directly दूसरे computers के साथ share कर सकता है। छोटे home networks में यह model useful हो सकता है।

5. Cloud Computing

Cloud computing में storage, applications और computing power internet के through access की जाती है। User को local machine पर heavy setup रखने की जरूरत नहीं होती। Google Drive, Gmail, Microsoft OneDrive और online learning platforms cloud computing के common examples हैं।

Model Main Idea Example
Centralized Processing और storage central system पर। Mainframe system
Distributed Work multiple systems में divide होता है। Distributed database
Client-Server Client request करता है, server service देता है। Website, Bank server
Peer-to-Peer All computers equal role में resource share करते हैं। Small file sharing network
Cloud Internet based computing services। Google Drive, Gmail

Networking Models

Networking Model एक conceptual framework होता है जो बताता है कि network communication किस तरह step-by-step perform होती है। जब एक computer दूसरे computer को data send करता है, तो data directly simple form में नहीं जाता। Data को कई layers से pass किया जाता है, जहाँ हर layer अपना specific काम करती है। Networking models इस layered communication process को समझने में help करते हैं।

Networking models का सबसे important benefit यह है कि वे complex communication process को छोटे-छोटे logical parts में divide कर देते हैं। इससे designing, troubleshooting, protocol development और learning आसान हो जाती है। सबसे common networking models हैं OSI Model और TCP/IP Model।

OSI Model

OSI का full form Open Systems Interconnection है। यह एक reference model है जिसमें 7 layers होती हैं। यह model बताता है कि data sender से receiver तक पहुँचने के लिए किन layers से होकर जाता है। OSI model practical implementation से ज्यादा learning और understanding के लिए important माना जाता है।

Layer No. Layer Name Main Work
7 Application User applications को network services provide करना।
6 Presentation Data format, encryption और compression manage करना।
5 Session Communication session establish, maintain और terminate करना।
4 Transport End-to-end delivery, reliability और flow control।
3 Network IP addressing और routing।
2 Data Link MAC addressing और frame delivery।
1 Physical Bits को physical medium पर transmit करना।

TCP/IP Model

TCP/IP Model internet communication का practical model है। यह model actual internet और modern networks में use होता है। TCP/IP model में usually 4 layers मानी जाती हैं: Application Layer, Transport Layer, Internet Layer और Network Access Layer।

TCP/IP Layer Main Work Protocols
Application Layer User-level network services। HTTP, FTP, SMTP, DNS
Transport Layer Data delivery और reliability। TCP, UDP
Internet Layer IP addressing और routing। IP, ICMP
Network Access Layer Physical network access और frame transmission। Ethernet, Wi-Fi
Exam Point: OSI model theoretical/reference model है, जबकि TCP/IP model practical internet communication में use होता है।

Peer-to-Peer Network

Peer to Peer Model एक network architecture है, जिसमें नेटवर्क का प्रत्येक node (computer) एक साथ Client और Server दोनों की भूमिका निभाता है। इस मॉडल में किसी central server की आवश्यकता नहीं होती। सभी computers आपस में सीधे (directly) data, files, resources तथा services को साझा (share) कर सकते हैं।

P2P Model में प्रत्येक node के अधिकार और कार्य समान होते हैं। कोई भी computer दूसरे computer से data प्राप्त भी कर सकता है और उसे data उपलब्ध भी करा सकता है। इस कारण network load सभी nodes में समान रूप से विभाजित हो जाता है और प्रत्येक computer स्वतंत्र रूप से कार्य करता है।

Example: छोटे office में 4 computers हैं। एक computer में printer connected है और बाकी computers उस printer का use network से करते हैं। यह simple P2P network हो सकता है।

Advantages

  • Low Cost:
    इस मॉडल में किसी dedicated server की आवश्यकता नहीं होती, इसलिए installation और maintenance cost कम होती है।
  • Easy Setup:
    P2P Network को install और configure करना बहुत आसान होता है। छोटे network को बिना किसी जटिल प्रक्रिया के बनाया जा सकता है।
  • Resource Sharing:
    सभी computers आपस में सीधे files, folders, printers तथा अन्य resources को share कर सकते हैं। इसके लिए central server की आवश्यकता नहीं होती।
  • No Single Point of Failure:
    यदि कोई एक computer (node) बंद हो जाए, तो बाकी computers सामान्य रूप से कार्य करते रहते हैं। इससे पूरा network बंद नहीं होता।
  • Equal Role for Every Node:
    इस मॉडल में प्रत्येक node एक साथ Client और Server दोनों की भूमिका निभाता है। इसलिए सभी computers समान अधिकारों के साथ data और resources का आदान-प्रदान कर सकते हैं.

Disadvantages

  • Less Security: इस मॉडल में कोई central server नहीं होता, इसलिए data security और access control कमज़ोर होते हैं। अनधिकृत (unauthorized) users के लिए data तक पहुँचने का खतरा अधिक रहता है।
  • Difficult Backup: सभी computers अपना-अपना data अलग-अलग store करते हैं, इसलिए data management और backup करना कठिन हो जाता है।
  • Not Suitable for Large Network: यह मॉडल छोटे network के लिए उपयुक्त होता है। Users की संख्या बढ़ने पर network performance प्रभावित हो सकती है।
  • Performance Issue: यदि किसी computer (node) को बंद कर दिया जाए या उसमें समस्या आ जाए, तो उस computer पर उपलब्ध files और resources अन्य users के लिए उपलब्ध नहीं रहेंगे। इससे resource sharing प्रभावित हो सकती है।

Client-Server Network

Client Server Model एक network architecture है, जिसमें Client और Server के बीच communication के माध्यम से data तथा services का आदान-प्रदान होता है। इस मॉडल में Client किसी resource या service की request भेजता है, जबकि Server उस request को process करके आवश्यक response वापस भेजता है।

Client
Client वह computer, device या application होता है, जो Server से किसी service, resource या data की request करता है और Server से प्राप्त response का उपयोग करता है।

Server
Server एक शक्तिशाली computer या software होता है, जो Client द्वारा भेजी गई request को process करता है और आवश्यक data, resources या services को response के रूप में वापस भेजता है।

Working Example

जब user browser में www.example.com open करता है, तो browser client की तरह web server को request भेजता है। Server requested webpage send करता है और browser उसे user को display करता है।

Advantages

  • Centralized Management:
    इस मॉडल में सभी data और services एक central server पर store होती हैं। इससे data management, updates और backup करना आसान हो जाता है।
  • Better Security:
    Server पर authentication और access control लागू किए जा सकते हैं, जिससे केवल अधिकृत (authorized) users ही data और resources का उपयोग कर सकते हैं। इससे network security बेहतर होती है।
  • Supports Multiple Clients:
    एक Server एक ही समय में कई clients की requests को process कर सकता है। इसलिए अनेक users एक साथ एक ही service का उपयोग कर सकते हैं।
  • Easy Data Sharing:
    सभी clients को data एक ही central server से प्राप्त होता है, जिससे सभी users को समान (consistent) और updated information मिलती है।
  • Easy Maintenance:
    इस मॉडल में यदि किसी software या service में बदलाव करना हो, तो केवल Server पर update करना पड़ता है। सभी clients को अलग-अलग update करने की आवश्यकता नहीं होती, जिससे maintenance आसान और समय की बचत होती है।

Disadvantages

  • Server Failure:
    यदि Server खराब हो जाए या बंद हो जाए, तो सभी clients उसकी services और resources का उपयोग नहीं कर पाएँगे। इससे पूरा network प्रभावित हो सकता है।
  • High cost:
    एक शक्तिशाली Server, network devices तथा maintenance की आवश्यकता होने के कारण इस मॉडल की installation और maintenance cost अधिक होती है।
  • Network Dependency:
    यह मॉडल पूरी तरह network connection पर निर्भर करता है। यदि network या Internet connection में समस्या आ जाए, तो clients Server की services और data तक पहुँच नहीं सकते।
  • Server Overload:
    जब बहुत अधिक clients एक साथ requests भेजते हैं, तो Server पर अधिक load पड़ता है। इससे performance धीमी हो सकती है।

LAN, MAN and WAN

LAN(Local Area Network)
एक network है, जो सीमित क्षेत्र जैसे room, office, school, college या building के अंदर कई computers और devices को आपस में जोड़ता है, ताकि वे data और resources को साझा (share) कर सकें।

Example: किसी school computer lab में 30 computers एक Switch के माध्यम से आपस में जुड़े होते हैं, ताकि सभी students एक ही printer, Internet connection और files का उपयोग कर सकें। यह LAN का सबसे सामान्य उदाहरण है। इसी प्रकार किसी office के सभी computers का एक-दूसरे से जुड़ा होना भी LAN कहलाता है।

MAN(Metropolitan Area Network)
एक ऐसा computer network है, जो किसी city या बड़े metropolitan area में स्थित कई LANs (Local Area Networks) को आपस में जोड़ता है। इसका क्षेत्रफल LAN से बड़ा और WAN से छोटा होता है। MAN का उपयोग किसी शहर के विभिन्न offices, colleges, universities, government departments तथा business organizations को जोड़ने के लिए किया जाता है।

Example: मान लीजिए किसी university के अलग-अलग campuses पूरे शहर में स्थित हैं। यदि इन सभी campuses के computer networks को आपस में जोड़ दिया जाए, तो वह MAN कहलाता है। इसी प्रकार किसी bank की शहरभर में स्थित सभी branches का एक network से जुड़ा होना भी MAN का उदाहरण है।

WAN(Wide Area Network)
एक ऐसा computer network है, जो बहुत बड़े geographical area जैसे country, continent या पूरी world में स्थित कई LANs और MANs को आपस में जोड़ता है। WAN का उपयोग लंबी दूरी तक data communication तथा resource sharing के लिए किया जाता है। इसमें leased lines, fiber optic cables, satellites तथा Internet जैसी communication technologies का उपयोग किया जाता है।

Example: किसी bank की अलग-अलग cities में स्थित सभी branches यदि एक ही network से जुड़ी हों, तो वह WAN का उदाहरण है। इसी प्रकार Internet दुनिया का सबसे बड़ा WAN है, जो लाखों networks और करोड़ों devices को आपस में जोड़ता है।
Network Type Full Form Coverage Area Example
LAN Local Area Network Room, building, lab, office Computer Lab
MAN Metropolitan Area Network City or large campus City cable network
WAN Wide Area Network Country, continent, world Internet

  • Security, authentication और access control को improve करती हैं।
Real Life Example:

Switching Techniques

Switching Technique वह method है जिसके द्वारा data को source से destination तक network के through forward किया जाता है। बड़े networks में sender और receiver directly connected नहीं होते। Data कई intermediate devices से होकर destination तक पहुँचता है। Switching technique यह decide करती है कि data किस path से और किस form में travel करेगा।

Main switching techniques तीन प्रकार की होती हैं: Circuit Switching, Message Switching और Packet Switching। इन techniques का use different communication systems में किया जाता है।

1. Circuit Switching

Circuit switching में communication start होने से पहले sender और receiver के बीच एक dedicated path establish किया जाता है। जब तक communication complete नहीं होता, तब तक वही path reserved रहता है। Traditional telephone system circuit switching का common example है। इसमें delay कम होता है लेकिन resource utilization कम efficient हो सकता है क्योंकि path reserved रहता है।

Advantages of Circuit Switching

  • Dedicated path available होता है।
  • Continuous communication के लिए suitable है।
  • Voice call जैसी real-time communication में useful है।

Disadvantages of Circuit Switching

  • Path reserved रहने के कारण resources waste हो सकते हैं।
  • Connection establish करने में initial time लग सकता है।
  • Data communication के लिए हमेशा efficient नहीं है।

2. Message Switching

Message switching में पूरा message एक unit के रूप में send किया जाता है। Intermediate nodes message को store करते हैं और फिर आगे forward करते हैं। इसे store-and-forward technique भी कहा जाता है। इसमें dedicated path की जरूरत नहीं होती, लेकिन large message होने पर delay ज्यादा हो सकता है।

3. Packet Switching

Packet switching में data को छोटे-छोटे parts में divide किया जाता है जिन्हें packets कहा जाता है। हर packet में source address, destination address और sequence information हो सकती है। Packets अलग-अलग paths से destination तक जा सकते हैं और destination पर फिर से original data में arrange किए जाते हैं। Internet में packet switching technique use होती है।

Advantages of Packet Switching

  • Network resources का efficient use होता है।
  • Different packets different paths से travel कर सकते हैं।
  • Internet communication के लिए suitable है।
  • Failure होने पर alternate path possible हो सकता है।

Disadvantages of Packet Switching

  • Packets out of order arrive हो सकते हैं।
  • Congestion होने पर delay हो सकता है।
  • Real-time traffic के लिए proper quality control चाहिए।
Technique Main Idea Example
Circuit Switching Dedicated path पहले establish होता है। Traditional telephone call
Message Switching Complete message store-and-forward होता है। Old telegraph/email-like systems
Packet Switching Data छोटे packets में divide होकर travel करता है। Internet
