Network Architecture: Ethernet Specification and Standardization

Network Architecture

Network Architecture का मतलब किसी computer network की complete design, structure और working arrangement से होता है। इसमें यह define किया जाता है कि devices किस तरह connected होंगी, data किस path से travel करेगा, कौन-से protocols use होंगे, कौन-से networking devices जैसे switch, router, hub या access point लगाए जाएंगे और communication किस standard के अनुसार होगा। Network Architecture किसी building के blueprint की तरह होती है, जिसमें पहले से plan किया जाता है कि network reliable, scalable, secure और efficient कैसे बनेगा।

Ethernet network architecture का बहुत important part है क्योंकि local area networks यानी LAN में सबसे ज्यादा use होने वाली technology Ethernet ही है। School lab, office network, computer center, data center और home broadband connection में Ethernet का use बहुत common है। Ethernet devices को cable और switch की help से connect करता है और data को frames के रूप में transmit करता है।

Need of Network Architecture

  • Network को proper design और structure देने के लिए।
  • Devices के बीच reliable data communication provide करने के लिए।
  • Future expansion यानी scalability को support करने के लिए।
  • Network troubleshooting और maintenance को आसान बनाने के लिए।
  • Standard protocols और technologies के through interoperability provide करने के लिए।
Real Life Example:
College computer lab में 40 computers एक switch से connected होते हैं। Switch router से connect होता है और router internet से। यह पूरा arrangement network architecture का example है।

Network Architecture Concept

Network Architecture यह describe करती है कि network के different components कैसे arranged होंगे और data communication कैसे perform होगा। इसमें physical architecture और logical architecture दोनों शामिल हो सकते हैं। Physical architecture बताती है कि cables, switches, routers, servers और computers physically कैसे connected हैं। Logical architecture बताती है कि data flow, addressing, protocols और services किस तरह work करेंगे।

Main Components of Network Architecture

Component Explanation Example
End Devices वे devices जो data send या receive करते हैं। Computer, Laptop, Mobile, Printer
Networking Devices वे devices जो data forwarding और connectivity provide करते हैं। Switch, Router, Hub, Access Point
Transmission Media Data travel करने का path। Ethernet Cable, Fiber, Wi-Fi
Protocols Communication rules का set। Ethernet, TCP/IP, HTTP
Services Network द्वारा provide की जाने वाली facilities। File Sharing, Internet, Printing
Important:
Ethernet mainly LAN architecture में use होता है। यह Data Link Layer और Physical Layer से related technology है।

Ethernet

Ethernet एक widely used Local Area Network technology है जिसका use computers और other network devices को wired LAN में connect करने के लिए किया जाता है। Ethernet data को frames के रूप में transmit करता है और devices की पहचान के लिए MAC Address का use करता है। Ethernet technology IEEE 802.3 standard के under standardized है। यह आज offices, schools, homes, data centers और enterprise networks में सबसे common wired networking technology है।

Ethernet पहले shared medium और hub-based networks में use होता था जहाँ CSMA/CD method collisions handle करने के लिए use होता था। Modern Ethernet networks में switches use होते हैं, जहाँ हर device का separate collision domain होता है और full-duplex communication possible होता है। Ethernet की speed समय के साथ 10 Mbps से 100 Mbps, 1000 Mbps और उससे भी आगे 10 Gbps, 40 Gbps और 100 Gbps तक develop हो चुकी है।

Features of Ethernet

  • LAN में सबसे commonly used wired networking technology है।
  • Data को frames के रूप में transmit करता है।
  • MAC Address का use device identification के लिए करता है।
  • IEEE 802.3 standard के under defined है।
  • Twisted pair cable, coaxial cable और fiber optic cable पर काम कर सकता है।
  • Switch-based Ethernet में better performance और full-duplex communication possible होता है।
Real Life Example:
जब आप laptop को LAN cable से Wi-Fi router या switch में connect करते हैं, तो आपका device Ethernet technology के through network से communicate करता है।

Ethernet Specification and Standardization

Ethernet Standardization का मतलब Ethernet technology के rules, frame format, speed, cable type, signaling method और working mechanism को common standard के रूप में define करना है। Standardization की वजह से अलग-अलग companies के network cards, switches, routers और cables एक-दूसरे के साथ properly work कर पाते हैं। अगर standardization न हो, तो हर company अपनी अलग technology बनाती, जिससे devices compatible नहीं होते।

Ethernet को initially Xerox PARC में develop किया गया था, बाद में DEC, Intel और Xerox ने मिलकर Ethernet specification को आगे बढ़ाया। इसके बाद IEEE ने Ethernet को IEEE 802.3 standard के रूप में standardized किया। आज Ethernet की कई versions available हैं, जैसे Traditional Ethernet, Fast Ethernet, Gigabit Ethernet और higher-speed Ethernet standards।

Why Standardization is Needed

  • Different vendors के devices को compatible बनाने के लिए।
  • Frame format और signaling rules common रखने के लिए।
  • Speed, cable length और media type define करने के लिए।
  • Network design और troubleshooting को आसान बनाने के लिए।
  • Technology evolution को organized तरीके से आगे बढ़ाने के लिए।
Real Life Example:
अगर आपके laptop का network adapter Intel का है और switch Cisco या TP-Link का है, फिर भी दोनों Ethernet standard follow करते हैं, इसलिए वे आपस में communicate कर पाते हैं।

IEEE 802.3 Standard

IEEE 802.3 Ethernet networks के लिए standard है। यह define करता है कि Ethernet frame कैसा होगा, MAC addressing कैसे work करेगी, data transmission किस speed पर होगा, कौन-सा cable/media use होगा और physical/data link layer पर communication कैसे perform होगा। IEEE 802.3 primarily wired LAN technology को standardize करता है।

Ethernet Frame

Ethernet Frame वह data unit है जिसे Ethernet network में transmit किया जाता है। जब Network Layer से packet आता है, तो Data Link Layer उसे Ethernet frame में encapsulate करती है। Frame में destination MAC address, source MAC address, type/length field, data और error checking के लिए FCS जैसे fields होते हैं। Switch destination MAC address को read करके frame को correct port पर forward करता है।

Main Fields of Ethernet Frame

Field Function
Preamble Receiver को synchronization में help करता है।
Destination MAC Address Frame किस device को जाना है, यह बताता है।
Source MAC Address Frame भेजने वाले device का MAC address बताता है।
Type / Length Upper layer protocol या data length indicate करता है।
Data / Payload Actual data होता है जो transmit किया जा रहा है।
FCS Frame Check Sequence, error detection के लिए use होता है।
Real Life Example:
Ethernet frame को courier packet की तरह समझिए। Destination MAC address receiver का address है और source MAC address sender का address है।

Working of Ethernet

How Ethernet Works

Working:
Ethernet network में devices network interface card यानी NIC के through connect होती हैं। हर NIC का unique MAC address होता है। जब एक device दूसरे device को data send करता है, तो data Ethernet frame में convert होता है। Frame में source और destination MAC address add होते हैं। अगर network switch-based है, तो switch अपने MAC address table की help से यह decide करता है कि frame को किस port पर forward करना है।

पुराने hub-based Ethernet में सभी devices same collision domain share करती थीं और CSMA/CD method use होता था। इसमें device पहले medium को listen करती थी और फिर data send करती थी। अगर collision होती थी, तो devices थोड़ी देर wait करके data फिर से send करती थीं। Modern switched Ethernet में collision बहुत कम या practically eliminate हो जाती है क्योंकि each device का switch से dedicated link होता है।

Simple Ethernet Communication Steps

  1. Sender device data create करता है।
  2. Data Ethernet frame में encapsulate होता है।
  3. Frame में source और destination MAC address add होते हैं।
  4. Frame cable के through switch तक जाता है।
  5. Switch MAC table देखकर frame को correct port पर forward करता है।
  6. Destination device frame receive करके data extract करता है।
Computer A → Ethernet Frame → Switch → Correct Port → Computer B
Frame forwarding mainly MAC Address के basis पर होती है।

Traditional Ethernet - 10 Mbps

Traditional Ethernet Ethernet की early generation है जिसकी speed normally 10 Mbps होती थी। इसमें data 10 megabits per second की rate से transmit होता था। Traditional Ethernet initially coaxial cable और bus topology के साथ use होता था, बाद में twisted pair cable और star topology के साथ भी use हुआ। यह LAN communication की foundation technology मानी जाती है।

10 Mbps Ethernet में old networks में hub-based architecture common थी। Hub incoming data को सभी ports पर broadcast करता था, जिससे collision की possibility रहती थी। इसलिए CSMA/CD method collision handling के लिए use किया जाता था। आज 10 Mbps Ethernet mostly outdated माना जाता है, लेकिन networking history और basic Ethernet concepts समझने के लिए यह बहुत important है।

Features of Traditional Ethernet

  • Speed 10 Mbps होती है।
  • Early LANs में widely use होता था।
  • Coaxial cable और twisted pair दोनों versions available थे।
  • Hub-based networks में CSMA/CD use होता था।
  • Modern networks में इसे mostly Fast/Gigabit Ethernet ने replace कर दिया है।

Common 10 Mbps Standards

Standard Media Meaning
10BASE5 Thick Coaxial Cable Thick Ethernet, older bus network
10BASE2 Thin Coaxial Cable Thin Ethernet, cheaper coaxial version
10BASE-T Twisted Pair Cable Star topology with hub/switch
Real Life Example:
पुराने computer labs में 10 Mbps hub-based Ethernet networks use होते थे, जहाँ सभी computers एक hub से connected होते थे।

Fast Ethernet - 100 Mbps

Fast Ethernet Ethernet का improved version है जिसकी speed 100 Mbps होती है। यह Traditional Ethernet से 10 times faster है। Fast Ethernet को IEEE 802.3u standard के under define किया गया। इसका purpose existing Ethernet networks को ज्यादा speed provide करना था, ताकि users file sharing, internet access और client-server applications को better performance के साथ use कर सकें।

Fast Ethernet mainly twisted pair cable और fiber optic cable पर work कर सकता है। इसमें common standard 100BASE-TX है जो Cat5 या better twisted pair cable पर use होता है। Fast Ethernet ने old 10 Mbps networks को बहुत तेजी से replace किया क्योंकि यह existing Ethernet frame format और network concepts के साथ compatible था।

Features of Fast Ethernet

  • Speed 100 Mbps होती है।
  • Traditional Ethernet से 10 times faster है।
  • IEEE 802.3u standard से related है।
  • Twisted pair और fiber optic media support करता है।
  • Star topology और switch-based LAN में commonly use होता है।
  • Half-duplex और full-duplex दोनों modes support कर सकता है।

Common Fast Ethernet Standards

Standard Media Use
100BASE-TX Twisted Pair Cable Most common Fast Ethernet LAN
100BASE-FX Fiber Optic Cable Longer distance links
Real Life Example:
अगर किसी small office में 100 Mbps switch लगा है और computers LAN cable से connected हैं, तो वह Fast Ethernet network का example हो सकता है।

Gigabit Ethernet - 1000 Mbps

Gigabit Ethernet Ethernet का high-speed version है जिसकी speed 1000 Mbps यानी 1 Gbps होती है। यह Fast Ethernet से 10 times faster और Traditional Ethernet से 100 times faster है। Gigabit Ethernet को high-performance LANs, servers, backbone links, data centers और modern home/office networks में use किया जाता है।

Gigabit Ethernet twisted pair cable और fiber optic cable दोनों पर work कर सकता है। 1000BASE-T standard copper twisted pair cable पर 1 Gbps speed provide करता है, जबकि 1000BASE-SX और 1000BASE-LX fiber optic cable पर use होते हैं। Modern switches और network interface cards usually Gigabit Ethernet support करते हैं।

Features of Gigabit Ethernet

  • Speed 1000 Mbps यानी 1 Gbps होती है।
  • Fast Ethernet से 10 times faster है।
  • Large file transfer, server access और high-speed LAN के लिए suitable है।
  • Copper और fiber दोनों media support करता है।
  • Modern LANs में common standard बन चुका है।
  • Full-duplex switch-based networks में बहुत efficient performance देता है।

Common Gigabit Ethernet Standards

Standard Media Use
1000BASE-T Cat5e / Cat6 Twisted Pair Cable Common office/home gigabit LAN
1000BASE-SX Multimode Fiber Short-distance fiber links
1000BASE-LX Single-mode / Multimode Fiber Longer-distance fiber links
Real Life Example:
Modern Wi-Fi routers में अक्सर 1 Gbps LAN ports होते हैं। जब laptop Cat6 cable से ऐसे router से connect होता है, तो Gigabit Ethernet speed support हो सकती है।

Ethernet Transmission Media

Ethernet different transmission media पर काम कर सकता है। पुराने Ethernet networks में coaxial cable use होती थी। बाद में twisted pair cable जैसे Cat5, Cat5e और Cat6 widely use होने लगे। High-speed और long-distance links के लिए fiber optic cable use होती है। Media selection network speed, distance, cost और environment पर depend करता है।

Media Explanation Used In
Coaxial Cable पुराने bus topology Ethernet networks में use होती थी। 10BASE5, 10BASE2
Twisted Pair Cable आज LAN में सबसे common cable type है। RJ-45 connector use होता है। 10BASE-T, 100BASE-TX, 1000BASE-T
Fiber Optic Cable Light signals के through high speed और long distance communication provide करती है। 100BASE-FX, 1000BASE-SX/LX
Real Life Example:
Office के अंदर computers को connect करने के लिए twisted pair LAN cable use होती है, जबकि building-to-building link के लिए fiber optic cable use की जा सकती है।
