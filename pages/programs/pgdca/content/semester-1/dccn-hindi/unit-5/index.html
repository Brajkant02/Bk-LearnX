TCP/IP Addressing

TCP/IP Addressing

TCP/IP Addressing वह addressing system है जिसके द्वारा network में connected devices को uniquely identify किया जाता है। जब कोई computer, mobile, server या router network में communicate करता है, तो data को सही destination तक पहुँचाने के लिए address की जरूरत होती है। TCP/IP network में mainly दो important addresses use होते हैं: Physical Address और Logical Address। Physical address local network में device को identify करता है, जबकि logical address different networks और internet पर device की पहचान करता है।

Internet पर करोड़ों devices connected होते हैं। अगर addressing system न हो, तो sender द्वारा भेजा गया data सही receiver तक नहीं पहुँच पाएगा। IP addressing packets को route करने में help करता है। Router destination IP address देखकर decide करता है कि packet को किस direction में forward करना है। इसी कारण TCP/IP addressing computer networking का fundamental concept है।

Real Life Example:
जैसे courier deliver करने के लिए घर का address चाहिए होता है, वैसे ही network packet को destination device तक पहुँचाने के लिए IP address चाहिए होता है।

Concept of Physical and Logical Addressing

Physical Address को commonly MAC Address कहा जाता है। यह Network Interface Card यानी NIC का hardware address होता है। MAC address manufacturer द्वारा assign किया जाता है और local network में device को identify करने के लिए use होता है। दूसरी तरफ Logical Address यानी IP Address software-based address होता है, जो device को network या internet पर identify करता है। IP address network configuration के अनुसार change हो सकता है, लेकिन MAC address normally fixed रहता है।

Working Concept

जब data same local network में travel करता है, तो Data Link Layer MAC address का use करती है। जब data different network या internet पर travel करता है, तो Network Layer IP address का use करती है। Router IP address देखकर packet को आगे forward करता है, जबकि switch MAC address देखकर local delivery करता है।

Basis Physical Address Logical Address
Name MAC Address IP Address
Layer Data Link Layer Network Layer
Nature Hardware address Software/logical address
Change Usually fixed Can change according to network
Example 00:1A:2B:3C:4D:5E 192.168.1.10
Real Life Example:
IP address घर के current address जैसा है, जो बदल सकता है। MAC address व्यक्ति के permanent ID जैसा है, जो device hardware से जुड़ा होता है।

IPv4 Addresses

Definition:
IPv4 का full form Internet Protocol version 4 है। यह 32-bit logical addressing system है, जिसका use devices को network पर uniquely identify करने के लिए किया जाता है। IPv4 address को normally dotted decimal notation में लिखा जाता है, जिसमें चार parts होते हैं और प्रत्येक part को octet कहा जाता है। हर octet 8 bits का होता है, इसलिए total 4 × 8 = 32 bits होते हैं।

IPv4 address का example है 192.168.1.1। इसमें 192, 168, 1 और 1 चार octets हैं। प्रत्येक octet की range 0 से 255 तक होती है। IPv4 internet की शुरुआत से लेकर आज तक बहुत widely use होता आया है। लेकिन IPv4 में address space limited है, इसलिए IPv6 को develop किया गया।

IPv4 Features

  • IPv4 address 32-bit का होता है।
  • यह dotted decimal notation में लिखा जाता है।
  • इसमें 4 octets होते हैं।
  • प्रत्येक octet की value 0 से 255 तक हो सकती है।
  • IPv4 routing और packet delivery के लिए use होता है।
Example: 192.168.1.10
Binary concept: 11000000.10101000.00000001.00001010

IPv4 Address Space

Address Space

Address Space किसी addressing system में possible total addresses की संख्या को कहा जाता है। IPv4 32-bit address use करता है, इसलिए इसमें total possible addresses 232 होते हैं। इसका मतलब लगभग 4.3 billion addresses theoretically possible हैं। लेकिन इन सभी addresses को public use में directly assign नहीं किया जा सकता, क्योंकि कुछ addresses private networks, loopback, multicast, broadcast और special purposes के लिए reserved होते हैं।

Important Points

  • IPv4 address length = 32 bits
  • Total address space = 232
  • Approx total addresses = 4.3 billion
  • कुछ addresses special purpose के लिए reserved होते हैं।
  • Limited address space के कारण IPv4 address depletion problem हुई।
Real Life Example:
जैसे किसी city में limited house numbers होते हैं, वैसे ही IPv4 में limited IP addresses होते हैं। Internet devices बढ़ने से addresses कम पड़ने लगे।

IPv4 Notations

IPv4 Notation का मतलब IPv4 address को लिखने के तरीके से है। Computer internally IPv4 address को binary form में understand करता है, लेकिन humans के लिए binary address याद रखना कठिन होता है। इसलिए IPv4 address को dotted decimal notation में लिखा जाता है। Dotted decimal notation में address को चार decimal numbers में divide किया जाता है और प्रत्येक number dot से separate होता है।

Notation Example Explanation
Binary Notation 11000000.10101000.00000001.00000001 Computer-friendly form, 32 bits.
Dotted Decimal Notation 192.168.1.1 Human-friendly form, four decimal octets.

Octet Concept

IPv4 address में प्रत्येक decimal part 8-bit binary octet को represent करता है। जैसे 192 का binary form 11000000 होता है। इसी तरह चार octets मिलकर complete IPv4 address बनाते हैं।

Classful Addressing

Definition:
Classful Addressing IPv4 addressing की पुरानी method है जिसमें IP addresses को fixed classes में divide किया गया था। इन classes को Class A, Class B, Class C, Class D और Class E कहा जाता है। Class A बड़े networks के लिए, Class B medium-size networks के लिए और Class C small networks के लिए use होती थी। Class D multicast के लिए reserved है और Class E experimental purpose के लिए reserved है।

Classful addressing में network part और host part fixed होते थे। यह method शुरू में simple थी, लेकिन बाद में inefficient साबित हुई क्योंकि कई organizations को requirement से ज्यादा addresses मिल जाते थे और बहुत सारे addresses waste होते थे। इसी address wastage के कारण classless addressing यानी CIDR introduce किया गया।

Classes Overview

Class First Octet Range Default Mask Purpose
Class A 1 - 126 255.0.0.0 /8 Very large networks
Class B 128 - 191 255.255.0.0 /16 Medium networks
Class C 192 - 223 255.255.255.0 /24 Small networks
Class D 224 - 239 Not applicable Multicast
Class E 240 - 255 Not applicable Experimental

Different IP Address Classes, Classes & Blocks

Definition:
IP address classes address space को अलग-अलग blocks में divide करती हैं। Class A addresses में first bit 0 होता है, Class B में starting bits 10, Class C में 110, Class D में 1110 और Class E में 1111 होते हैं। इन bit patterns की help से IP address की class identify की जाती थी। Class A सबसे बड़े host space के लिए, Class B medium और Class C छोटे host networks के लिए use होती थी।

Class Starting Bits Network/Host Structure Approx Hosts per Network
A 0 N.H.H.H 16 million+
B 10 N.N.H.H 65,000+
C 110 N.N.N.H 254
D 1110 Multicast Not for normal hosts
E 1111 Experimental Not for normal use
Real Life Example:
Small office network में Class C style private address जैसे 192.168.1.0/24 commonly use होता है।

Net-id and Host-id

IPv4 address दो parts से मिलकर बनता है: Net-id और Host-id। Net-id network को identify करता है और Host-id उस network के अंदर particular device को identify करता है। Router mainly Net-id का use करके packet को correct network तक पहुँचाता है। जब packet destination network में पहुँच जाता है, तब host part की help से specific device तक delivery होती है।

Classful Net-id and Host-id

Class Default Mask Network Part Host Part
A /8 First octet Last 3 octets
B /16 First 2 octets Last 2 octets
C /24 First 3 octets Last octet
Example: 192.168.1.25 /24
Net-id = 192.168.1.0
Host-id = 25

Masks

Subnet Mask

Mask या Subnet Mask वह 32-bit value है जो IP address में network part और host part को identify करती है। Mask में binary 1s network portion को represent करते हैं और binary 0s host portion को represent करते हैं। Subnet mask की help से device determine करता है कि destination same network में है या different network में।

Common Default Masks

Class Default Mask CIDR
Class A 255.0.0.0 /8
Class B 255.255.0.0 /16
Class C 255.255.255.0 /24

Working Concept

Device IP address और subnet mask को compare करके network address निकालता है। अगर source और destination का network address same है, तो packet local network में भेजा जाता है। अगर network address different है, तो packet default gateway/router को send किया जाता है।

Address Depletion

IPv4 Address Depletion

Address Depletion का मतलब available IP addresses का कम पड़ जाना है। IPv4 में केवल 32-bit address space है, जिससे लगभग 4.3 billion addresses possible हैं। शुरुआत में यह बहुत बड़ा लगा, लेकिन internet, smartphones, IoT devices, servers और networks के तेजी से बढ़ने के कारण IPv4 addresses कम पड़ने लगे।

Causes

  • Internet users और devices की संख्या तेजी से बढ़ना।
  • Classful addressing में address wastage।
  • Large organizations को बहुत बड़े address blocks मिलना।
  • Mobile devices और IoT devices का expansion।

Solutions

  • CIDR: Classless addressing से address allocation efficient हुआ।
  • NAT: Private IPs को public IP के through internet access मिला।
  • Private Addresses: Internal networks में reusable address ranges use हुईं।
  • IPv6: बहुत बड़ा 128-bit address space provide किया गया।

Classless Addressing

Classless Addressing IPv4 addressing की modern method है जिसमें fixed Class A, B और C boundaries पर depend नहीं किया जाता। इसे CIDR यानी Classless Inter-Domain Routing भी कहा जाता है। CIDR में IP address के साथ prefix length लिखी जाती है, जैसे 192.168.1.0/24। यहाँ /24 बताता है कि first 24 bits network part हैं और remaining bits host part हैं।

Classless addressing address allocation को flexible और efficient बनाती है। Organizations को exactly जरूरत के अनुसार address blocks दिए जा सकते हैं, जिससे IPv4 address wastage कम होता है।

Features

  • Fixed class boundary पर depend नहीं करता।
  • Prefix notation जैसे /24, /27, /30 use करता है।
  • Address wastage कम करता है।
  • Route aggregation और supernetting support करता है।
Real Life Example:
अगर किसी office को केवल 30 usable IP addresses चाहिए, तो उसे पूरा Class C block देने के बजाय /27 block दिया जा सकता है।

Address Blocks and Masks in Classless Addressing

Definition:
Address Block continuous IP addresses का group होता है जिसे किसी organization या network को assign किया जाता है। CIDR notation में block को base address और prefix length से represent किया जाता है। जैसे 192.168.10.0/26 एक address block है जिसमें first 26 bits network part हैं।

Home Wi-Fi routers usually devices को 192.168.1.x जैसे private IP addresses assign करते हैं।

Subnetting

Subnetting वह process है जिसमें एक large network को कई छोटे logical networks यानी subnets में divide किया जाता है। Subnetting से network management आसान होता है, security improve होती है और broadcast traffic reduce होता है। Subnetting में host bits में से कुछ bits borrow करके subnet bits बनाई जाती हैं।

Need of Subnetting

  • Large network को छोटे manageable parts में divide करने के लिए।
  • Broadcast traffic कम करने के लिए।
  • Different departments को separate network देने के लिए।
  • IP address utilization improve करने के लिए।
  • Security और control improve करने के लिए।

Simple Example

Suppose एक company के पास 192.168.1.0/24 network है। Company इसे Admin, Accounts, Lab और Library जैसे departments में divide कर सकती है। हर department को अलग subnet मिल सकता है।

Original Network: 192.168.1.0/24
Possible Subnets: 192.168.1.0/26, 192.168.1.64/26, 192.168.1.128/26, 192.168.1.192/26

Supernetting

Definition:
Supernetting वह process है जिसमें कई छोटे networks को combine करके एक बड़ा network block बनाया जाता है। इसे route aggregation या route summarization भी कहा जाता है। Supernetting का main purpose routing table को छोटा और efficient बनाना है। जब multiple continuous network blocks को एक single summarized route में represent किया जाता है, तो routers को fewer routes maintain करने पड़ते हैं।

Need of Supernetting

  • Routing table size कम करने के लिए।
  • Route aggregation करने के लिए।
  • Internet routing को efficient बनाने के लिए।
  • Multiple continuous networks को एक route में summarize करने के लिए।
Real Life Example:
अगर ISP के पास कई continuous network blocks हैं, तो वह उन्हें एक large summarized route के रूप में advertise कर सकता है। इससे internet routers की routing table छोटी रहती है।

Loopback Concept

Loopback concept में device खुद को ही network request send करता है। IPv4 में loopback address commonly 127.0.0.1 होता है, जिसे localhost भी कहा जाता है। इसका use local machine की TCP/IP stack testing, server testing और development में किया जाता है। Loopback request physical network card से बाहर नहीं जाती; यह same computer के अंदर ही process होती है।

Uses of Loopback

  • Local TCP/IP configuration test करने के लिए।
  • Local web server test करने के लिए।
  • Application development में localhost testing के लिए।
  • Network troubleshooting में basic connectivity verify करने के लिए।

Real Life Example:
Web developer अपने computer पर local server run करके browser में localhost open करता है। यह loopback concept का practical example है।

Network Address Translation (NAT)

Definition:
NAT का full form Network Address Translation है। NAT एक technique है जिसके द्वारा private IP addresses को public IP address में translate किया जाता है ताकि private network के devices internet access कर सकें। Home router NAT का common example है। घर के अंदर multiple devices private IP addresses use करते हैं, लेकिन internet पर जाते समय router उन्हें एक public IP address के through represent करता है।

Working of NAT

जब private network का कोई device internet पर request भेजता है, तो router source private IP को public IP में translate करता है। Router translation table maintain करता है ताकि response वापस आने पर उसे सही internal device तक deliver किया जा सके।

Types of NAT

Type Explanation
Static NAT One private IP को fixed public IP से map करता है।
Dynamic NAT Private IPs को public IP pool से dynamically map करता है।
PAT / NAT Overload Multiple private devices एक public IP share करते हैं, port numbers की help से।
Real Life Example:
घर में mobile, laptop और smart TV सभी internet चलाते हैं, लेकिन ISP से usually एक public IP मिलता है। Router NAT की help से सभी devices को internet access देता है।

IPv4 Header

Definition:
IPv4 Header वह control information होती है जो IPv4 packet के beginning में add की जाती है। Header में source IP, destination IP, version, header length, TTL, protocol, checksum और fragmentation information जैसी details होती हैं। Router इसी header information को read करके packet को correct destination की ओर forward करता है।

Important IPv4 Header Fields

Field Function

IHL Header length बताता है।
Total Length Complete packet की length बताता है।
Identification Fragmented packets को identify करने में help करता है।
Flags Fragmentation control करता है।
Fragment Offset Fragment की position बताता है।
TTL Packet की lifetime limit करता है।
Protocol Upper layer protocol बताता है, जैसे TCP या UDP।
Header Checksum Header error detection के लिए।

Real Life Example:
IP packet का header envelope पर लिखे address जैसा है। Router header पढ़कर packet को next route पर forward करता है।

IPv6 Header

IPv6 Header IPv6 packet के beginning में present control information है। IPv6 header IPv4 header की तुलना में simpler और fixed length का होता है। IPv6 address 128-bit का होता है, इसलिए source और destination addresses बड़े होते हैं। IPv6 header में Version, Traffic Class, Flow Label, Payload Length, Next Header, Hop Limit, Source Address और Destination Address जैसे fields होते हैं।

Important IPv6 Header Fields

Field Function
Version IP version बताता है; IPv6 के लिए value 6 होती है।
Traffic Class Packet priority और traffic handling में help करता है।
Flow Label Special flow identification के लिए।
Payload Length Header के बाद data length बताता है।
Next Header Next protocol या extension header बताता है।
Hop Limit IPv4 TTL जैसा function करता है।
Source Address Sender का 128-bit IPv6 address।
Destination Address Receiver का 128-bit IPv6 address।
Real Life Example:
IPv6 header large address space और improved routing support करता है, इसलिए modern internet growth के लिए important है।
