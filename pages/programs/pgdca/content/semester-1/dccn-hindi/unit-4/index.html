Networking Models

Introduction to Networking Models

Networking Model

Networking Model एक conceptual framework होता है जो यह समझाता है कि network में data sender से receiver तक किस process के through travel करता है। जब दो computers या devices आपस में communicate करते हैं, तो data directly एक जगह से दूसरी जगह नहीं चला जाता। उसके पीछे कई छोटे-छोटे काम होते हैं, जैसे data को packets में divide करना, address add करना, error check करना, signal में convert करना, medium से transmit करना और receiver side पर वापस original form में convert करना। Networking Model इन सभी tasks को अलग-अलग layers में organize करता है।

Networking models students और engineers को यह समझने में help करते हैं कि network communication के अलग-अलग parts कैसे काम करते हैं। अगर network में कोई problem आती है, तो layered model की help से यह पता लगाया जा सकता है कि problem physical cable में है, IP addressing में है, transport connection में है या application service में है। इसलिए networking models communication को systematic, modular और easy to troubleshoot बनाते हैं।

Why Networking Models are Needed

  • Network communication process को छोटे logical parts में divide करने के लिए।
  • Different manufacturers के devices को common standards पर communicate करवाने के लिए।
  • Network troubleshooting को easy बनाने के लिए।
  • Protocols और services को layer-wise organize करने के लिए।
  • Students को complex communication process easily समझाने के लिए।
Real Life Example:
जैसे postal system में letter लिखना, envelope में रखना, address लिखना, sorting, transport और final delivery अलग-अलग stages में होता है, वैसे ही computer network में data communication layer-wise stages से होकर complete होता है।

Layered Architecture

Layered Architecture का मतलब है किसी बड़े और complex communication process को कई small, manageable और independent layers में divide करना। प्रत्येक layer का अपना specific काम होता है। एक layer अपनी ऊपर वाली layer को service देती है और अपनी नीचे वाली layer से service लेती है। इससे पूरे network system का design, development और maintenance आसान हो जाता है।

Layered architecture में हर layer दूसरे layer के internal details को जाने बिना अपना काम कर सकती है। इसे abstraction कहते हैं। उदाहरण के लिए, Application Layer को यह जानने की जरूरत नहीं होती कि data cable से जा रहा है या Wi-Fi से। उसी तरह Physical Layer को यह जानने की जरूरत नहीं होती कि user website open कर रहा है या email send कर रहा है। इस separation के कारण network protocols को easily design और update किया जा सकता है।

Benefits of Layered Architecture

  • Modularity: पूरे communication process को छोटे parts में divide किया जाता है।
  • Easy Troubleshooting: Problem किस layer में है, यह identify करना आसान होता है।
  • Interoperability: Different vendors के devices common protocols के through communicate कर सकते हैं।
  • Flexibility: एक layer में changes करने से बाकी layers पर कम effect पड़ता है।
  • Learning Friendly: Complex networking concepts को step-by-step समझा जा सकता है।
Real Life Example:
Restaurant में order लेने वाला, kitchen staff, billing counter और delivery person अलग-अलग roles perform करते हैं। Customer को kitchen की internal working जानने की जरूरत नहीं होती। इसी तरह networking में हर layer अपना काम करती है।

OSI Model

OSI Model का full form Open Systems Interconnection Model है। यह एक reference model है जिसे ISO यानी International Organization for Standardization ने develop किया था। इसका main purpose यह था कि different companies और manufacturers के computer systems आपस में standard way में communicate कर सकें। OSI Model network communication को सात layers में divide करता है। ये layers bottom से top तक हैं: Physical, Data Link, Network, Transport, Session, Presentation और Application।

OSI Model mostly conceptual और educational model है। Real internet communication directly OSI model पर implement नहीं होता, लेकिन OSI model networking concepts समझने के लिए बहुत powerful framework है। जब कोई data sender side से receiver side तक जाता है, तो sender side पर data top layer से bottom layer तक जाता है। हर layer data में अपना control information add करती है। Receiver side पर data bottom layer से top layer तक जाता है और हर layer अपना added information remove करके data को आगे pass करती है।

Purpose of OSI Model

  • Network communication को standard format में explain करना।
  • Different systems के बीच communication को possible बनाना।
  • Protocols और network functions को layer-wise organize करना।
  • Network troubleshooting और learning को आसान बनाना।
  • Complex communication को simple steps में divide करना।
Remember:
OSI Model एक reference model है, practical protocol suite नहीं। यह बताता है कि network communication को logically कैसे organize किया जा सकता है।

OSI Layered Architecture

OSI Model की architecture 7 layers पर based होती है। Sender side पर data Application Layer से start होकर Physical Layer तक जाता है। इस process को Encapsulation कहा जाता है, क्योंकि हर layer data के साथ अपना header या control information add करती है। Receiver side पर data Physical Layer से start होकर Application Layer तक पहुँचता है। इस process को Decapsulation कहा जाता है, क्योंकि हर layer अपना header remove करती है और data को next upper layer को दे देती है।

OSI Layers from Top to Bottom

  2. Presentation Layer
  3. Session Layer

  7. Physical Layer

OSI Layers from Bottom to Top

Sender Side: Application → Presentation → Session → Transport → Network → Data Link → Physical
Receiver Side: Physical → Data Link → Network → Transport → Session → Presentation → Application
Real Life Example:
जब आप browser में website open करते हैं, तो user request application level से start होती है, फिर transport, network और physical level से होकर internet पर जाती है। Server से response वापस reverse order में आता है।

OSI Layers

1.Physical Layer

Physical Layer OSI Model की सबसे नीचे वाली layer है। इसका main काम raw bits को physical medium के through transmit करना है। यह data को 0 और 1 के form में electrical signals, optical signals या radio signals में convert करके sender से receiver तक भेजती है। Physical Layer यह define करती है कि cable कौन-सी होगी, connector कैसा होगा, signal voltage level क्या होगा, transmission speed कितनी होगी, और data किस physical path से travel करेगा।

यह layer actual data के meaning को नहीं समझती। इसका काम सिर्फ bits को signal के रूप में send और receive करना है। अगर communication wired है, तो copper cable या fiber optic cable use हो सकती है। अगर communication wireless है, तो radio waves या microwaves use हो सकती हैं। Physical Layer network की foundation है, क्योंकि बिना physical transmission के upper layers का data receiver तक पहुँच ही नहीं सकता।

Functions of Physical Layer

  • Bits को electrical, optical या radio signals में convert करना।
  • Transmission medium define करना, जैसे cable या wireless channel।
  • Data transmission rate यानी speed define करना।
  • Connectors, cables और physical devices का standard define करना।
  • Signal synchronization और bit timing handle करना।

Real Life Example:
जब LAN cable से दो computers connect होते हैं, तो data electrical signals के रूप में cable से travel करता है। यह Physical Layer का काम है।

2. Data Link Layer

Data Link Layer OSI Model की second layer है। इसका काम directly connected devices के बीच reliable data transfer करवाना है। यह raw bits को organized form यानी frames में arrange करती है। Data Link Layer physical network में devices की पहचान करने के लिए MAC Address का use करती है। यह layer error detection, flow control और media access control जैसे functions perform करती है।

Data Link Layer local network communication में बहुत important होती है। जब एक computer उसी LAN में दूसरे computer को data send करता है, तो Data Link Layer destination device का MAC address use करती है। यह layer यह भी check कर सकती है कि received frame में error है या नहीं। Switches इसी layer पर काम करते हैं और MAC address table की help से data को correct port पर forward करते हैं।

Functions of Data Link Layer

  • Network layer से आए packets को frames में convert करना।
  • Source और destination MAC address add करना।
  • Error detection करना, जैसे corrupted frame identify करना।
  • Flow control maintain करना ताकि fast sender slow receiver को overload न करे।
  • Media access control करना कि shared medium पर कौन device कब data send करेगी।

Sub-layers of Data Link Layer

Sub-layer Function

Real Life Example:
School computer lab में switch MAC address देखकर data को सही computer तक भेजता है। यह Data Link Layer का practical example है।

3. Network Layer

Network Layer OSI Model की third layer है। इसका main काम data packets को source network से destination network तक पहुँचाना है। यह logical addressing और routing handle करती है। Network Layer में IP Address use होता है, जिससे different networks पर devices को identify किया जाता है। यह layer decide करती है कि packet किस route से destination तक जाएगा।

जब data local network से बाहर internet या दूसरे network में जाता है, तो Network Layer important role निभाती है। Router इसी layer पर काम करता है। Router packet के destination IP address को देखकर best path choose करता है। Network Layer packet forwarding, path selection, fragmentation और logical addressing जैसे tasks perform करती है।

Functions of Network Layer

  • Logical addressing यानी IP address assign और use करना।
  • Packet routing करना।
  • Different networks के बीच data forwarding करना।
  • Large packets को छोटे fragments में divide करना, यदि required हो।
  • Best path selection करना।

Protocols and Devices

Real Life Example:
जब आप India से किसी US-based website को open करते हैं, तो आपका request packet कई routers से होकर destination server तक पहुँचता है। यह Network Layer routing का example है।

4. Transport Layer

Transport Layer OSI Model की fourth layer है। इसका main काम source और destination devices के बीच end-to-end communication provide करना है। यह data को smaller parts यानी segments में divide करती है और receiver side पर उन्हें फिर से सही order में combine करती है। Transport Layer reliability, flow control, error recovery और port addressing जैसे functions perform करती है।

Transport Layer यह ensure करती है कि data सही application तक पहुँचे। इसके लिए port numbers use किए जाते हैं। उदाहरण के लिए web traffic usually port 80 या 443 पर चलता है। Transport Layer के दो important protocols हैं: TCP और UDP। TCP reliable, connection-oriented protocol है, जबकि UDP faster but connectionless protocol है।

Functions of Transport Layer

  • Data को segments में divide करना।
  • End-to-end delivery provide करना।
  • Flow control और error recovery करना।
  • Lost segments को retransmit करवाना, अगर TCP use हो रहा है।
  • Port numbers के through correct application तक data पहुँचाना।

Protocols

Protocol Explanation
TCP Reliable, connection-oriented protocol; data delivery confirm करता है।
UDP Fast, connectionless protocol; video streaming और gaming में useful।

5. Session Layer

Session Layer OSI Model की fifth layer है। इसका main काम दो devices या applications के बीच communication session को establish, maintain और terminate करना है। Session का मतलब communication relationship या connection state से है। यह layer ensure करती है कि दो systems के बीच conversation properly start हो, बीच में manage हो और काम पूरा होने के बाद close हो जाए।

Session Layer dialog control भी provide करती है। इसका मतलब यह decide करना कि communication एक समय पर one-way होगा या both-way। कुछ systems में यह checkpoints भी maintain कर सकती है, ताकि communication interrupt होने पर पूरा data फिर से start करने की जरूरत न पड़े। हालांकि practical TCP/IP model में Session Layer का काम mostly Application Layer protocols में include हो जाता है।

Functions of Session Layer

  • Session establish करना।
  • Session maintain करना।
  • Session terminate करना।
  • Dialog control manage करना।
  • Synchronization points या checkpoints provide करना।

Examples

Item Examples

Real Life Example:
जब आप किसी website में login करते हैं और कुछ समय तक logged-in रहते हैं, तो session management की concept काम कर रही होती है।

6. Presentation Layer

Presentation Layer OSI Model की sixth layer है। इसे data translator layer भी कहा जाता है। इसका main काम data को ऐसे format में convert करना है जिसे receiver system समझ सके। Different systems अलग data formats use कर सकते हैं, इसलिए Presentation Layer data translation, encryption, decryption, compression और decompression जैसे functions perform करती है।

Presentation Layer ensure करती है कि sender side का data receiver side पर readable और usable form में मिले। अगर data encrypted है, तो receiver side पर decrypt किया जाता है। अगर data compressed है, तो उसे decompress किया जाता है। Images, videos, text encoding और secure communication में Presentation Layer की concept important होती है।

Functions of Presentation Layer

  • Data translation करना, जैसे different character encoding formats handle करना।
  • Data encryption और decryption करना।
  • Data compression और decompression करना।
  • Data को application-readable format में present करना।

Examples

Function Examples

Real Life Example:
जब आप HTTPS website open करते हैं, तो data encrypted form में travel करता है। Encryption और decryption Presentation Layer concept से related हैं।

7. Application Layer

Application Layer OSI Model की topmost यानी seventh layer है। यह user applications को network services provide करती है। इसका मतलब यह नहीं है कि Chrome, WhatsApp या MS Outlook खुद Application Layer हैं; बल्कि वे applications Application Layer protocols का use करती हैं। Application Layer user के सबसे पास होती है और web browsing, email, file transfer, remote login और domain name resolution जैसी services provide करती है।

जब user browser में URL type करता है, तो Application Layer protocol HTTP या HTTPS request create करता है। जब user email send करता है, तो SMTP जैसे protocols use होते हैं। जब website name को IP address में convert करना होता है, तो DNS use होता है। इसलिए Application Layer network services को directly user-level applications तक पहुँचाती है।

Functions of Application Layer

  • User applications को network services provide करना।
  • Web browsing, email, file transfer और remote access support करना।
  • Application protocols के through data exchange करना।
  • Resource sharing और network services access करवाना।

TCP/IP Model

TCP/IP Model

TCP/IP Model का full form Transmission Control Protocol / Internet Protocol Model है। यह practical networking model है जिस पर modern Internet based है। TCP/IP model communication को 4 layers में divide करता है: Application Layer, Transport Layer, Internet Layer और Network Access Layer। यह model OSI की तुलना में ज्यादा practical है क्योंकि actual internet protocols TCP/IP suite पर काम करते हैं।

TCP/IP Model originally ARPANET और Department of Defense network से related development में use हुआ। आज web browsing, email, file transfer, video streaming, online gaming और cloud computing जैसे लगभग सभी internet services TCP/IP protocols पर depend करती हैं। TCP reliable data delivery provide करता है और IP data packets को correct destination network तक पहुँचाने में help करता है।

Purpose of TCP/IP Model

  • Real-world internet communication को support करना।
  • Different networks को interconnect करना।
  • Data को packets में divide करके route करना।
  • Reliable और unreliable दोनों types की communication support करना।
  • Application services को practical protocol suite provide करना।
Real Life Example:
जब आप YouTube video देखते हैं, तो application protocols, TCP/UDP, IP और network access technologies मिलकर TCP/IP model के according data deliver करते हैं।

1. Network Access Layer

Network Access Layer TCP/IP Model की lowest layer है। यह OSI Model की Physical Layer और Data Link Layer के functions को combine करती है। इसका काम data को local network medium पर transmit करना है। यह layer physical transmission, MAC addressing, framing और local network access handle करती है। Ethernet, Wi-Fi और other LAN technologies इसी layer से related हैं।

Functions

  • Data को frames में organize करना।
  • MAC address के through local delivery करना।
  • Physical medium पर bits transmit करना।
  • Ethernet और Wi-Fi जैसे network technologies support करना।
Real Life Example:
आपके laptop का Wi-Fi adapter router से connect होकर data frames transmit और receive करता है। यह Network Access Layer का काम है।

2. Internet Layer

Definition:
Internet Layer TCP/IP Model की वह layer है जो packets को source से destination network तक पहुँचाने का काम करती है। इसका main protocol IP है। यह layer logical addressing, packet forwarding और routing perform करती है। Internet Layer packets को अलग-अलग networks के through destination तक भेजती है।

Functions

  • IP addressing provide करना।
  • Packets को route करना।
  • Different networks को interconnect करना।
  • Packet forwarding और fragmentation handle करना।

Protocols

Protocol Use
IP Packets को address और route करना।
ICMP Error reporting और diagnostics, जैसे ping।
ARP IP address से MAC address find करना।
Real Life Example:
जब आप किसी website को open करते हैं, तो IP packets कई routers से होकर destination server तक पहुँचते हैं।

3. Transport Layer in TCP/IP

Transport Layer TCP/IP Model में application processes के बीच end-to-end communication provide करती है। यह source और destination devices पर running applications को port numbers के through identify करती है। इस layer के main protocols TCP और UDP हैं।

Application Layer TCP/IP Model की top layer है। यह user applications को network services provide करती है। OSI Model की Application, Presentation और Session layers के functions TCP/IP में mostly इसी layer में combine हो जाते हैं। Web browsing, email, file transfer, domain name resolution और remote login जैसी services इसी layer से related हैं।

Complete Communication Example

Website Open करने पर Layers कैसे काम करती हैं?

जब user browser में किसी website का URL type करता है, तो कई layers मिलकर communication complete करती हैं। यह process user को simple दिखती है, लेकिन background में protocols और layers step-by-step काम करते हैं।

User types URL in Browser
↓
Application Layer: HTTP/HTTPS request create होती है
↓
DNS domain name को IP address में convert करता है
↓
Transport Layer: TCP connection establish करता है और data segments बनाता है
↓
Internet/Network Layer: IP address add होता है और routing होती है
↓
Data Link/Network Access Layer: MAC address और frames बनते हैं
↓
Physical Layer: Bits signals बनकर cable/Wi-Fi से travel करते हैं
↓
Router → Internet → Destination Server
↓
Server response वापस same process के reverse order में browser तक आता है

Step-by-Step Explanation

  1. User browser में URL enter करता है।
  2. DNS domain name को IP address में convert करता है।
  3. HTTP/HTTPS request create होती है।
  4. Transport Layer request को segments में divide करती है।
  5. Network/Internet Layer IP packet बनाकर destination address add करती है।
  6. Data Link Layer frame बनाकर MAC address add करती है।
  7. Physical Layer bits को signals में convert करके transmit करती है।
  8. Server request receive करके response generate करता है।
  9. Response वापस user browser तक पहुँचता है और webpage display हो जाता है।
Real Life Example:
आपको सिर्फ website open होती दिखती है, लेकिन वास्तव में HTTP, DNS, TCP, IP, Ethernet/Wi-Fi और Physical signals मिलकर पूरी communication complete करते हैं।
