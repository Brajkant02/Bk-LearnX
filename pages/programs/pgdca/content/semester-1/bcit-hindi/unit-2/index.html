Data Representation

Data Representation

Data Representation का अर्थ है Computer के अंदर Data को किस form में store, process और display किया जाता है। Computer एक digital electronic machine है, इसलिए यह हमारी भाषा, numbers, images, audio या video को सीधे नहीं समझता। Computer केवल electric signals के रूप में 0 और 1 को समझता है। इसी कारण सभी प्रकार के data को Binary form में convert करके memory में रखा जाता है।

जब हम keyboard से कोई letter type करते हैं, photo open करते हैं या कोई calculation करते हैं, तो computer उस information को internally binary digits में represent करता है। Data Representation computer system का बहुत important concept है क्योंकि इसी के आधार पर memory storage, processing speed, coding systems और communication work करते हैं।

Data

Data ऐसे raw facts, figures, symbols या characters का संग्रह होता है, जिनका अपने आप में कोई स्पष्ट अर्थ नहीं होता। जब तक इनका processing नहीं किया जाता, तब तक ये केवल Data कहलाते हैं।

Information

Information वह processed data होता है जो meaningful, useful और decision making में helpful होता है। Data अपने आप में raw facts होता है, लेकिन जब data को process करके useful meaning दिया जाता है, तब वह Information बन जाता है।

Example
“85, 90, 78” केवल data है। लेकिन अगर हम कहें कि “Brajkant ने Computer exam में 85, English में 90 और Math में 78 marks प्राप्त किए”, तो यह Information है क्योंकि इसका clear meaning है। Information user को सही decision लेने में सहायता करती है।

Difference between Data and Information

Data Information
Data raw facts, figures, symbols या values का संग्रह होता है, जिनका अपने आप में कोई स्पष्ट अर्थ नहीं होता। Information processed और meaningful data होता है, जिससे उपयोगी जानकारी प्राप्त होती है।
Data को समझने के लिए पहले processing की आवश्यकता होती है। Information पहले से processed होती है, इसलिए इसे सीधे समझा जा सकता है।
Data का उपयोग input के रूप में किया जाता है। Information, data की processing के बाद प्राप्त output होती है।
Data निर्णय (decision making) लेने के लिए पर्याप्त नहीं होता। Information का उपयोग decision making और planning में किया जाता है।
Data का उदाहरण: 85, 92, 78, Rahul, Delhi Information का उदाहरण: Rahul scored 92 marks and secured first position.
Data अव्यवस्थित (unorganized) हो सकता है। Information हमेशा व्यवस्थित (organized) होती है।
Data अकेले उपयोगी नहीं होता। Information उपयोगी होती है और किसी उद्देश्य के लिए प्रयोग की जाती है।

Number System

Number System symbols और rules का एक set होता है जिसके द्वारा numbers को represent किया जाता है। Computer Science में number systems बहुत important हैं क्योंकि अलग-अलग systems अलग-अलग purposes के लिए use होते हैं।

Human beings normally Decimal Number System use करते हैं, जिसमें 0 से 9 तक digits होते हैं। Computer Binary Number System use करता है, जिसमें केवल 0 और 1 होते हैं। Programming और memory representation में Octal और Hexadecimal systems भी use होते हैं।

Binary Number System

Binary Number System computer की सबसे basic language है। Computer के electronic circuits केवल दो states को represent करते हैं: ON और OFF। ON को 1 और OFF को 0 से represent किया जाता है। इसी कारण computer सारी processing Binary Number System के आधार पर करता है।

Binary system memory addressing, arithmetic operations, logical operations, data storage और communication में use होता है। अगर binary system न हो तो computer hardware और software के बीच proper communication possible नहीं होगा।

Decimal Number System

Decimal Number System सबसे अधिक उपयोग की जाने वाली संख्या पद्धति है। इसमें 0 से 9 तक कुल 10 अंक (Digits) होते हैं। प्रत्येक अंक का मान उसके स्थान (Place Value) पर निर्भर करता है।

Octal Number System

Octal Number System एक Base-8 संख्या पद्धति है। इसमें 0 से 7 तक कुल 8 अंक (Digits) का उपयोग किया जाता है। इसका उपयोग मुख्य रूप से Computer Programming और Digital Systems में किया जाता है।

Hexadecimal Number System

Hexadecimal Number System एक Base-16 संख्या पद्धति है। इसमें 0–9 तथा A–F (जहाँ A=10, B=11, C=12, D=13, E=14 और F=15) का उपयोग किया जाता है। इसका उपयोग Computer Programming, Memory Addressing और Web Development में किया जाता है।

Memory

Memory Addressing वह process है जिसके द्वारा computer memory के हर location को एक unique address दिया जाता है। जैसे किसी घर को पहचानने के लिए address होता है, उसी प्रकार memory में stored data को access करने के लिए memory address होता है।

Memory Addressing CPU को यह बताती है कि data कहाँ store है और कहाँ से fetch करना है। यह program execution, data storage, instruction processing और fast access के लिए बहुत important है। Without memory addressing, CPU correct data को locate नहीं कर पाएगा।

Example: मान लीजिए एक Apartment Building में 100 फ्लैट हैं। हर फ्लैट का अपना एक Flat Number जैसे 101, 102, 103 आदि होता है। यदि किसी व्यक्ति से फ्लैट नंबर 105 पर मिलने जाना हो, तो आप सीधे उसी फ्लैट तक पहुँच जाते हैं। इसी प्रकार, Computer Memory (RAM) में भी प्रत्येक Memory Location का एक Unique Address होता है। जब CPU को कोई Data या Instruction चाहिए होती है, तो वह उसके Memory Address का उपयोग करके सीधे उसी स्थान से Data प्राप्त कर लेता है। इसे ही Memory Addressing कहते हैं।

ASCII Coding System

ASCII का full form American Standard Code for Information Interchange है। यह एक character coding system है जिसका use computer में letters, digits, symbols और control characters को represent करने के लिए किया जाता है।

ASCII में हर character को एक unique numeric code दिया जाता है। Example के लिए capital letter A का ASCII code 65 होता है। ASCII system keyboard input, text files, programming और data communication में बहुत commonly use होता है।

EBCDIC Coding System

EBCDIC का full form Extended Binary Coded Decimal Interchange Code है। यह character coding system mainly IBM mainframe computers में use होता था। इसमें characters को represent करने के लिए 8-bit code का use किया जाता है।

EBCDIC ASCII की तरह characters को numeric code में convert करता है, लेकिन इसके code values अलग होते हैं। Modern personal computers में ASCII और Unicode ज्यादा common हैं, जबकि EBCDIC mostly पुराने IBM systems में पाया जाता है।
