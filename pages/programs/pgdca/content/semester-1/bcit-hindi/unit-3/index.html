DOS & Windows Operating Systems

Hardware and Software

Hardware

Hardware computer के physical parts को कहा जाता है जिन्हें हम देख और छू सकते हैं। जैसे CPU, Monitor, Keyboard, Mouse, Hard Disk, RAM, Printer, Scanner आदि। Hardware अपने आप काम नहीं करता; उसे instructions की जरूरत होती है। ये instructions software द्वारा दिए जाते हैं। Computer system में hardware body की तरह होता है और software mind की तरह काम करता है।

Software

Software programs और instructions का collection होता है जो computer hardware को बताता है कि कौन-सा काम कैसे करना है। Software को छुआ नहीं जा सकता, लेकिन उसके result को screen पर देखा जा सकता है। Operating System, MS Word, Browser, Antivirus, Compiler और Games software के examples हैं।

Types of Software

  1. System Software

    2. System Software वह software होता है, जो सीधे computer hardware को नियंत्रित (control) करता है और Computer के सभी hardware components को सही प्रकार से कार्य करने योग्य बनाता है। यह users तथा अन्य application software को आवश्यक services प्रदान करता है, जिससे पूरा Computer System सुचारु (smoothly) रूप से कार्य कर सके।

    System Software Computer के आंतरिक (internal) कार्यों को नियंत्रित करता है तथा CPU, Memory, Monitor, Printer, Keyboard, Mouse, Hard Disk और अन्य hardware devices का प्रबंधन (manage) करता है। यह hardware और application software के बीच एक interface का कार्य करता है। Hardware केवल machine language (0 और 1) को समझता है, जबकि users और application software human-readable languages जैसे English, Hindi आदि का उपयोग करते हैं। System Software इन दोनों के बीच communication स्थापित करता है, जिससे Computer उपयोगकर्ता के commands को समझकर सही output प्रदान कर सके।

    मान लीजिए Operating System (Windows, Linux) आपके Computer में System Software के रूप में कार्य कर रहा है। जब आप MS Word खोलते हैं, तो Operating System CPU, Memory और Hard Disk का उपयोग करके उस application को चलाता है। यदि System Software न हो, तो Computer Hardware और Application Software एक-दूसरे से communicate नहीं कर पाएँगे।

    Types of System Software
      Operating System

      Operating System (OS) एक महत्वपूर्ण System Software है, जो Computer Hardware और User के बीच interface का कार्य करता है। यह Computer के सभी hardware resources जैसे CPU, Memory, Input Devices, Output Devices तथा Storage Devices का प्रबंधन (manage) करता है और Application Software को चलाने के लिए आवश्यक environment प्रदान करता है।
      Example: Linux, MacOS, Android, iOS, UNIX, MicroSoft Windows

      Langauage Processor

      Language Processor एक System Software है, जो high-level language या assembly language में लिखे गए source program को machine language (0 और 1) में परिवर्तित करता है, ताकि Computer उस program को समझकर execute कर सके। क्योंकि Computer केवल machine language को समझता है, इसलिए किसी भी program को चलाने के लिए Language Processor की आवश्यकता होती है।
      Example: Compiler, Assembler, Interpreter

      Device Driver

      Device Driver एक System Software है, जो Operating System और hardware device के बीच interface का कार्य करता है। यह Operating System को किसी विशेष hardware device जैसे Printer, Scanner, Keyboard, Mouse, Monitor या Graphics Card से communication करने में सहायता करता है। प्रत्येक hardware device के सही तरीके से कार्य करने के लिए उसका Device Driver Computer में install होना आवश्यक होता है।
      Example: Printer Driver, Scanner Driver, Mouse Driver, Keyboard Driver etc

  2. Application Software

    3. Application Software वह software होता है, जिसे user के विशेष (specific) कार्यों को पूरा करने के लिए बनाया जाता है। यह System Software के ऊपर कार्य करता है और users को document writing, calculations, presentations, web browsing, gaming तथा अन्य दैनिक कार्य करने की सुविधा प्रदान करता है। Application Software सीधे user की आवश्यकताओं को पूरा करता है और Operating System की सहायता से कार्य करता है।

    मान लीजिए किसी student को project report बनानी है। वह Microsoft Word का उपयोग करेगा। यदि उसे presentation तैयार करनी है, तो वह Microsoft PowerPoint का उपयोग करेगा। इसी प्रकार Google Chrome की सहायता से वह Internet पर information खोज सकता है। ये सभी Application Software के उदाहरण हैं।
    Type of Application software
      General Purpose Software

      General Purpose Software वह Application Software होता है, जिसे सामान्य (general) कार्यों को करने के लिए बनाया जाता है। इसका उपयोग विभिन्न प्रकार के users अपनी दैनिक (day-to-day) आवश्यकताओं जैसे document writing, calculations, presentations, database management तथा Internet browsing के लिए करते हैं। यह किसी एक विशेष कार्य के लिए नहीं, बल्कि अनेक सामान्य कार्यों के लिए उपयोग किया जाता है।
      Example: MS Excel, MS Word, MOzilla Firebox, Chrome

      Customized Software

      Customized Software वह Application Software होता है, जिसे किसी विशेष organization, company, business या user की आवश्यकताओं (requirements) के अनुसार design और develop किया जाता है। यह केवल एक विशेष कार्य (specific task) या किसी विशेष organization की जरूरतों को पूरा करने के लिए बनाया जाता है। इसलिए इसे Tailor-Made Software या Custom Software भी कहा जाता है।
      Example: Hospital Management System, School Management System, Banking Software, Bk Learnx

      Utility Software

      Utility Software एक प्रकार का System Software है, जिसे Computer System की performance, security तथा maintenance को बेहतर बनाने के लिए बनाया जाता है। यह Operating System की सहायता करता है और Computer को तेज़, सुरक्षित तथा सुचारु (efficiently) रूप से कार्य करने योग्य बनाता है। Utility Software files, disks, memory तथा अन्य system resources का प्रबंधन (manage) करके Computer की कार्यक्षमता को बढ़ाता है।
      Example: Antivirus Software, Backup Software, File Compression Software

Operating System

Operating System (OS) एक महत्वपूर्ण System Software है, जो Computer Hardware और User के बीच interface का कार्य करता है। यह Computer के सभी hardware resources जैसे CPU, Memory, Input Devices, Output Devices तथा Storage Devices का प्रबंधन (manage) करता है और Application Software को चलाने के लिए आवश्यक environment प्रदान करता है।

Operating System Computer के सभी आंतरिक (internal) कार्यों को नियंत्रित करता है। जब user कोई command देता है, तो Operating System उस command को hardware तक पहुँचाता है और प्राप्त result को user तक वापस पहुँचाता है। यह process management, memory management, file management, device management तथा security जैसे महत्वपूर्ण कार्यों को भी नियंत्रित करता है। यदि Operating System न हो, तो Computer Hardware और Application Software एक-दूसरे से communication नहीं कर पाएँगे और Computer सही प्रकार से कार्य नहीं करेगा।

Example: Microsoft Windows, Linux, macOS, Android, iO

Uses of Operating System
  1. Computer Hardware को manage और control करना।
  2. User और Hardware के बीच interface प्रदान करना।
  3. Application Software को चलाने के लिए platform उपलब्ध कराना।
  4. Memory, CPU, Files तथा Input/Output Devices का प्रबंधन करना।
  5. Computer System की security, stability और overall performance को बनाए रखना।

Need of Operating System

Operating System की जरूरत इसलिए होती है क्योंकि computer hardware बहुत complex होता है। Normal user directly CPU, RAM, Disk या Printer को control नहीं कर सकता। OS user को easy interface देता है और सभी resources को automatically manage करता है।

  • User Interface: OS user को GUI या CUI interface देता है, जिससे computer use करना आसान होता है।
  • Program Execution: OS programs को load, run और close करने में help करता है।
  • Resource Management: CPU, Memory, I/O devices और Storage को efficiently allocate करता है।
  • File Management: Files और folders को create, delete, rename, copy और organize करने की सुविधा देता है।
  • Security: User accounts, passwords और permissions के through system को protect करता है।

Types of Operating System

Batch Operating System

Batch Operating System एक ऐसा Operating System है, जिसमें एक जैसे jobs को पहले एक batch में एकत्र किया जाता है और फिर उन्हें queue में रखकर एक-एक करके execute किया जाता है। इसमें user का Computer से सीधा संपर्क नहीं होता। Operating System सभी jobs को स्वतः process करता है और प्रत्येक job के पूरा होने के बाद अगली job को execute करता है।

Example:

  • Insurance Claim Processing
  • Library Book Records
  • Stock Market Reports

किसी Bank में दिनभर के सभी transactions का रात में एक साथ processing करना तथा किसी College में हजारों छात्रों की marksheets एक साथ तैयार करना Batch Operating System का उदाहरण है।

Multi-Programming Operating System

Multi-Programming Operating System एक ऐसा Operating System है, जिसमें एक ही समय पर कई programs memory (RAM) में load रहते हैं। जब कोई एक program Input/Output (I/O) कार्य के कारण प्रतीक्षा करता है, तब CPU दूसरे program को execute करना शुरू कर देता है। इससे CPU utilization बढ़ता है और system performance बेहतर होती है।

Example:

  • Billing Machines
  • Railway Server
  • Banking Stystem

Computer पर Google Chrome में browsing करते समय MS Word में typing करना और साथ में Music Player चलाना Multi-Programming Operating System का उदाहरण है।

Multi-Processing Operating System

Multi-Processing Operating System एक ऐसा Operating System है, जिसमें एक से अधिक CPU या Processor का उपयोग processes को execute करने के लिए किया जाता है। सभी processors मिलकर एक साथ अलग-अलग processes पर कार्य करते हैं, जिससे system performance, processing speed तथा throughput में वृद्धि होती है।

Example:

  • UNIX
  • Linux(Ubuntu, Red Hat, Debian)
  • MacOS

बड़े Database Servers, Cloud Servers तथा Scientific Research Computers में कई processors का उपयोग करके एक साथ अनेक tasks पूरे किए जाते हैं।

Multitasking/Time Sharing Operating System

Multitasking Operating System एक ऐसा Operating System है, जो एक ही समय पर कई tasks या applications को चलाने की सुविधा देता है। इसमें प्रत्येक task को CPU का निश्चित time slice (Quantum) दिया जाता है। समय समाप्त होने पर Operating System अगले task को CPU प्रदान करता है, जिससे सभी tasks एक साथ चलते हुए दिखाई देते हैं।

Example:

  • IBM VM/CMS
  • TSO (Time Sharing Option)
  • Windows Terminal Services

Laptop पर MS Word में typing करना, Google Chrome में Internet चलाना तथा साथ में Music Player में गाने सुनना Multitasking Operating System का उदाहरण है।

Network Operating System (NOS)

Network Operating System (NOS) एक ऐसा Operating System है, जो server पर install किया जाता है और पूरे network के users, data, security, applications तथा shared resources का प्रबंधन करता है। यह सभी users को files, printers तथा अन्य network resources तक सुरक्षित पहुँच प्रदान करता है।

Example:

  • Microsoft Windows Server 2003
  • UNIX, Linux
  • Mac OS X

किसी School, College या Office में सभी Computers यदि एक Server से जुड़े हों और सभी users उसी printer, files तथा Internet का उपयोग करें, तो यह Network Operating System का उदाहरण है।

Distributed Operating System

Distributed Operating System एक ऐसा Operating System है, जो कई स्वतंत्र Computers को communication network के माध्यम से जोड़ता है। प्रत्येक Computer का अपना CPU और Memory होता है, लेकिन सभी Computers मिलकर एक ही system की तरह कार्य करते हैं। इसमें users दूसरे Computers पर उपलब्ध files, software तथा resources का भी उपयोग कर सकते हैं।

Example:

  • LOCUS
  • MICROS
  • Amoeba

किसी University के अलग-अलग Computer Labs यदि एक network से जुड़े हों और सभी students किसी भी Computer से साझा files तथा software का उपयोग कर सकें, तो यह Distributed Operating System का उदाहरण है।

Real-Time Operating System (RTOS)

Real-Time Operating System (RTOS) एक ऐसा Operating System है, जो input प्राप्त होते ही बहुत कम समय में response प्रदान करता है। Input मिलने और response देने के बीच का समय Response Time कहलाता है। इसका उपयोग उन systems में किया जाता है, जहाँ समय पर response देना अत्यंत आवश्यक होता है।

Example:

  • Scientific experiments
  • Medical imaging systems
  • Robots

Airbag System, Missile Control System, Air Traffic Control System, Industrial Robots तथा Medical Equipment में Real-Time Operating System का उपयोग किया जाता है।

DOS (Disk Operating System)

DOS का full form Disk Operating System है। यह command-line based operating system है जो disk files, directories और basic hardware resources को manage करता है। MS-DOS Microsoft द्वारा personal computers के लिए develop किया गया था। DOS में user commands type करके काम करता है, इसलिए इसे CUI based operating system कहा जाता है।

DOS single-user और mostly single-tasking operating system था। इसमें mouse-based GUI नहीं होता था; user को commands जैसे DIR, COPY, DEL, MD, CD आदि याद रखने पड़ते थे।

Note:
window Screen पर window + R click → cmd type करें → enter दबाएँ

Types of DOS Commands

DOS Commands वे instructions हैं जिन्हें user command prompt में type करके DOS से काम करवाता है। DOS commands दो types की होती हैं: Internal Commands और External Commands।

Internal Commands

Internal commands DOS command interpreter COMMAND.COM के अंदर stored होती हैं। इन्हें execute करने के लिए अलग program file की जरूरत नहीं होती। ये memory में available रहती हैं।

Command Full Form Use

CD Change Directory Directory change करने के लिए।
mkdir Make Directory New directory create करने के लिए।

CLS Clear Screen Screen clear करने के लिए।

External Commands

External commands अलग executable files के रूप में disk पर stored होती हैं। इन्हें run करने के लिए उनकी program file available होनी चाहिए।

Command Full Form Use

TREE -- Directory structure tree format में दिखाने के लिए।

Operating System as a Resource Manager

Operating System को Resource Manager इसलिए कहा जाता है क्योंकि यह computer के सभी important resources जैसे CPU, Memory, Storage, Files और I/O Devices को manage करता है। जब multiple programs run होते हैं, तो OS decide करता है कि किस program को CPU कब मिलेगा, कितनी memory मिलेगी और कौन-सा device कैसे use होगा।

  • CPU Management: Processes को CPU time allocate करता है।
  • Memory Management: Programs को RAM allocate और free करता है।
  • Device Management: Keyboard, mouse, printer, disk जैसे devices को control करता है।
  • File Management: Files को store, access और protect करता है।
  • Security Management: User permissions और access control maintain करता है।

BIOS

strong>BIOS का full form Basic Input Output System है। यह firmware होता है जो motherboard की ROM/Flash memory में stored रहता है। जब computer start होता है, तो BIOS सबसे पहले run होता है। यह hardware components को check करता है, POST perform करता है और bootable device से operating system को load करने की process start करता है।

Functions of BIOS

  • Computer start होते ही hardware checking करता है।
  • POST यानी Power On Self Test perform करता है।
  • Boot device जैसे hard disk, SSD या USB को identify करता है।
  • Operating System boot loader को load करने में help करता है।
  • Basic hardware settings जैसे date, time, boot order manage करता है।

जब आप laptop on करते हैं और company logo दिखता है, उस time BIOS/UEFI hardware check और boot process start कर रहा होता है।

GUI and CUI Standards

GUI

GUI का full form Graphical User Interface है। इसमें user icons, windows, menus, buttons और mouse pointer की help से computer operate करता है। GUI user-friendly होता है और beginners के लिए आसान माना जाता है।

CUI

CUI का full form Character User Interface या Command User Interface है। इसमें user commands type करके computer से काम करवाता है। DOS इसका common example है। CUI fast और powerful हो सकता है, लेकिन commands याद रखनी पड़ती हैं।

Beginners के लिए easy होता है। Commands याद होना जरूरी है।

File

File data या information का named collection होता है जो storage device में save रहता है। File text, image, audio, video, program या document हो सकती है। हर file का एक name और extension होता है, जैसे notes.txt, photo.jpg, index.html।

Directory

Directory या folder files और sub-directories को organize करने के लिए use होता है। Directory की help से data को category-wise store किया जाता है, जिससे files ढूँढना और manage करना आसान होता है।

Wild Cards

Definition:
Wild Cards special characters होते हैं जिनका use multiple files को एक साथ search या select करने के लिए किया जाता है। DOS और Windows में commonly * और ? wildcards use होते हैं।

Wildcard Meaning Example
* किसी भी number of characters को represent करता है। *.txt सभी text files select करेगा।
? किसी single character को represent करता है। file?.txt file1.txt, file2.txt जैसे names match करेगा।
Example:
DIR *.DOC command current directory में सभी DOC files show करेगी।

AUTOEXEC.BAT and CONFIG.SYS

AUTOEXEC.BAT

AUTOEXEC.BAT DOS की batch file होती है जो system boot होने के समय automatically execute होती थी। इसमें ऐसी commands लिखी जाती थीं जिन्हें user हर startup पर automatically run कराना चाहता था, जैसे path set करना, prompt change करना या किसी program को start करना।

Example:
PATH=C:\DOS;C:\WINDOWS जैसी command AUTOEXEC.BAT में लिखी जा सकती थी।

CONFIG.SYS

CONFIG.SYS DOS की configuration file होती थी जिसका use device drivers और system settings load करने के लिए किया जाता था। यह file boot process के दौरान read होती थी और memory, device, buffers आदि settings configure कर सकती थी।

Example:
DEVICE=C:\DOS\HIMEM.SYS जैसी line CONFIG.SYS में device driver load करने के लिए use हो सकती थी।

Disk Defragmentation

Disk Defragmentation एक system utility process है जिसमें hard disk पर scattered file fragments को rearrange करके continuous blocks में रखा जाता है। इससे hard disk को files read करने में कम समय लगता है और system performance improve हो सकती है। यह process mainly HDD के लिए useful है; SSD में defragmentation की जरूरत generally नहीं होती।

Steps for Disk Defragmentation

  1. Start Menu open करें और Defragment and Optimize Drives search करें।
  2. Required drive select करें।
  3. Analyze option से fragmentation check करें।
  4. Optimize या Defragment पर click करें।
  5. Process complete होने तक wait करें।
Important:
Modern Windows SSD को defrag नहीं करता, बल्कि optimize/TRIM operation perform करता है।

Booting Process

Booting Process वह process है जिसके द्वारा computer power on होने के बाद hardware को check करता है और Operating System को main memory में load करता है। जब computer बंद अवस्था से start होता है, तो सबसे पहले BIOS/UEFI execute होता है। BIOS hardware components जैसे RAM, keyboard, storage device और display को check करता है। इसके बाद bootable device को identify किया जाता है और वहाँ से boot loader load होता है। Boot loader Operating System kernel को memory में load करता है, जिसके बाद OS user interface और system services start करता है।

Working of Booting Process

  1. Computer power on होता है।
  2. BIOS/UEFI सबसे पहले execute होता है।
  3. POST यानी Power On Self Test perform होता है।
  4. Bootable device जैसे HDD, SSD या USB identify किया जाता है।
  5. Boot Loader load होता है।
  6. Operating System kernel memory में load होता है।
  7. Login screen या desktop show होता है।

Types of Booting

Type Explanation Example
Cold Booting जब computer completely off state से power button दबाकर start किया जाता है। Morning में laptop को shutdown state से start करना।
Warm Booting जब computer पहले से on हो और उसे restart किया जाए। Windows में Restart option click करना।
Real Life Example:
जब आप laptop का power button दबाते हैं और कुछ seconds बाद Windows login screen आती है, तो इस पूरे background process को Booting Process कहा जाता है।

2. Boot Loader

Definition:
Boot Loader एक छोटा system program होता है जो booting process के दौरान Operating System को storage device से main memory में load करने में help करता है। BIOS/UEFI bootable device को locate करने के बाद boot loader को control देता है। Boot loader यह decide करता है कि कौन-सा Operating System load करना है। Dual boot system में boot loader user को Windows या Linux जैसे OS options दिखा सकता है।

Working of Boot Loader

Boot Loader storage device के boot sector या EFI partition से load होता है। यह Operating System kernel की location find करता है और उसे RAM में load करता है। Kernel load होने के बाद system services start होती हैं और फिर user login screen या desktop तक पहुँचता है।

Common Boot Loader Examples

  • Windows Boot Manager: Windows Operating System को load करने के लिए use होता है।
  • GRUB: Linux systems में commonly use होने वाला boot loader है।
  • LILO: Linux का पुराना boot loader था।
Real Life Example:
अगर किसी computer में Windows और Linux दोनों installed हैं, तो GRUB boot loader start में option देता है कि user कौन-सा OS open करना चाहता है।

Command Prompt

Command Prompt Windows का command-line interface है जहाँ user text commands type करके system से अलग-अलग काम करवा सकता है। CMD में user files list कर सकता है, directories change कर सकता है, network information देख सकता है, disk commands run कर सकता है और system utilities open कर सकता है। यह DOS जैसी command environment provide करता है, लेकिन modern Windows के अंदर run होता है।

Methods to Open Command Prompt

Common CMD Uses

  • System troubleshooting करना।
  • Disk और path related commands run करना।

OS File Extensions

File Extension file name के end में dot के बाद आने वाला part होता है, जो बताता है कि file किस type की है। DOS और Windows में file extension की help से system पहचानता है कि file executable है, batch file है, system file है या normal data file है। DOS में कई important extensions use होती थीं, जैसे .EXE, .COM, .BAT और .SYS।

Extension Meaning Use
.EXE Executable File Program run करने के लिए use होती है।
.COM Command File Small executable command programs के लिए use होती थी।
.BAT Batch File Multiple commands को sequence में automatically run करने के लिए।
.SYS System File Device drivers और system configuration files के लिए।

Recycle Bin Windows का special storage area है जहाँ deleted files और folders temporarily store होते हैं। जब user किसी file को delete करता है, तो वह तुरंत permanent delete नहीं होती, बल्कि Recycle Bin में चली जाती है। इससे user गलती से delete हुई file को वापस restore कर सकता है। Recycle Bin system safety feature की तरह काम करता है।

Uses of Recycle Bin

  • Deleted files को temporary store करना।
  • गलती से delete हुई files को restore करना।
  • Unwanted files को permanently delete करना।

Restore Process

  1. Recycle Bin open करें।
  2. Required file या folder select करें।
  3. Right-click करके Restore option choose करें।
  4. File अपनी original location पर वापस चली जाएगी।

Task Manager

Definition:
Task Manager Windows का system monitoring tool है जिसकी help से user running applications, background processes, CPU usage, memory usage, disk activity, network usage और startup programs को देख और manage कर सकता है। अगर कोई application hang हो जाए या system slow हो रहा हो, तो Task Manager troubleshooting में बहुत useful होता है।

Working of Task Manager

Task Manager system में चल रहे processes और resources की real-time information show करता है। User किसी unresponsive program को select करके End Task कर सकता है। इसके अलावा startup apps disable करके boot speed improve की जा सकती है।

Main Tabs of Task Manager

  • Processes: Running apps और background processes show करता है।
  • Performance: CPU, Memory, Disk, Wi-Fi और GPU usage दिखाता है।
  • Startup: Startup apps enable/disable करने के लिए।
  • Users: Current users और उनके resource usage को show करता है।
  • Details: Processes की detailed technical information दिखाता है।
  • Services: Windows services status show करता है।
