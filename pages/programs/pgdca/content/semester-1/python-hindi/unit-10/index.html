Regular Expressions in Python

Introduction

Regular Expression को short में Regex या RegEx कहा जाता है। यह एक special pattern होता है जिसका use text में किसी specific format या sequence को search, match, validate, extract, split या replace करने के लिए किया जाता है। जब normal string methods जैसे find(), replace() या split() complex pattern को handle नहीं कर पाते, तब regular expressions बहुत useful होते हैं।

Python में regular expressions use करने के लिए re module available है। यह Python का standard module है, इसलिए इसे अलग से install करने की जरूरत नहीं होती। हमें केवल import re लिखकर इसे program में use करना होता है।

Regex का use email validation, mobile number checking, password pattern checking, log file analysis, text cleaning, data extraction और web scraping जैसे कामों में किया जाता है। Regex powerful होता है, लेकिन शुरुआत में थोड़ा difficult लग सकता है क्योंकि इसमें special symbols और patterns use होते हैं।

Importing re Module

import re

Simple Search Example

import re

text = "Python is easy to learn"

result = re.search("easy", text)

if result:
    print("Match found")
else:
    print("Match not found")
Output:
Match found

Common re Module Functions

Function Use
re.search() String में pattern search करता है।
re.match() String के beginning से pattern match करता है।
re.findall() सभी matches की list return करता है।
re.finditer() सभी matches के match objects return करता है।
re.sub() Pattern को replace करता है।
re.split() Pattern के basis पर string split करता है।
re.compile() Pattern को reusable regex object में compile करता है।

Why Regex is Needed

  • Complex text patterns search करने के लिए।
  • Email, mobile number और password validation के लिए।
  • Text से required data extract करने के लिए।
  • Unwanted characters remove करने के लिए।
  • Large text files और logs analyze करने के लिए।
Real Life Example:
अगर website form में user का email check करना है कि उसमें @ और proper domain format है या नहीं, तो regex का use किया जा सकता है।
Remember:
Regex text pattern matching की powerful technique है और Python में इसे re module से use किया जाता है।

Simple Character Matches

Simple character match का मतलब है किसी string में normal characters को exactly search करना। अगर pattern में कोई special regex symbol नहीं है, तो regex उस text को normally match करता है। For example, pattern Python string में exactly “Python” word को search करेगा।

Regex matching case-sensitive होती है। इसका मतलब है कि python और Python दोनों अलग माने जाते हैं। अगर case-insensitive matching करनी हो, तो flags का use किया जाता है।

Using re.search()

import re

text = "Python is a powerful language"

result = re.search("Python", text)

if result:
    print("Pattern found")
else:
    print("Pattern not found")
Output:
Pattern found

Case-Sensitive Match

import re

text = "Python is easy"

result = re.search("python", text)

print(result)
Output:
None

यहाँ output None इसलिए आया क्योंकि string में Python capital P के साथ है, लेकिन pattern में python small p के साथ है।

Using re.findall()

findall() function string में pattern के सभी matches की list return करता है।

import re

text = "python-is-easy-python-is-popular."

result = re.findall("Python", text)

print(result)
Output:
['Python', 'Python']

Matching Digits as Simple Text

import re

text = "My roll number is 102"

result = re.search("102", text)

if result:
    print("Roll number found")
Output:
Roll number found

Important Points

  • Normal characters exact text को match करते हैं।
  • Regex default रूप से case-sensitive होती है।
  • search() first match find करता है।
  • findall() सभी matches की list देता है।
Real Life Example:
Large text में “Python” word कितनी बार आया है, यह जानने के लिए simple character match use किया जा सकता है।

Special Characters

Regex में कुछ characters special meaning रखते हैं। इन्हें metacharacters कहा जाता है। ये normal characters की तरह match नहीं होते, बल्कि pattern matching में special role play करते हैं। जैसे . किसी भी character को match कर सकता है, ^ beginning को represent करता है और $ end को represent करता है।

अगर हमें special character को normal character की तरह match करना हो, तो उसके पहले backslash \ लगाया जाता है। इसे escaping कहा जाता है।

Character Meaning

$ String का end।
* Zero या more repetitions।
+ One या more repetitions।
? Zero या one repetition।
[] Character class।

| OR condition।
\ Escape character।

Raw String

Regex patterns में Python raw string r"pattern" use करना अच्छा माना जाता है। Raw string में backslash को specially escape करने की जरूरत कम हो जाती है।

pattern = r"/d"

Common Mistakes

  • Special character को normal character समझ लेना।
  • Dot . को actual dot समझकर use करना।
  • Backslash escaping भूल जाना।
  • Raw string का use न करना।
Remember:
Regex में special characters pattern को powerful बनाते हैं, लेकिन actual character match करने के लिए escape करना पड़ता है।

Character Classes

Character class का use characters के group में से किसी एक character को match करने के लिए किया जाता है। Character class square brackets [ ] के अंदर लिखी जाती है। For example, [abc] का मतलब है कि string में a, b या c में से कोई एक character match हो सकता है।

Character classes validation और pattern matching में बहुत useful होती हैं। इनसे हम digits, alphabets, vowels, special range और unwanted characters को easily identify कर सकते हैं।

Simple Character Class

import re

text = "cat bat rat"

result = re.findall("[cr]at", text)

print(result)
Output:
['cat', 'rat']

Range in Character Class

import re

text = "abc 123 XYZ"

print(re.findall("[a-z]", text))
print(re.findall("[A-Z]", text))
print(re.findall("[0-9]", text))
Output:
['a', 'b', 'c']
['X', 'Y', 'Z']
['1', '2', '3']

Negated Character Class

अगर character class के beginning में ^ लगाया जाए, तो इसका मतलब होता है “इन characters को छोड़कर बाकी match करो”.

import re

text = "abc123"

result = re.findall("[^0-9]", text)

print(result)
Output:
['a', 'b', 'c']

Predefined Character Classes

\W Non-word character

\S Non-whitespace character

Quantifiers

Quantifiers regex में यह बताते हैं कि कोई character या group कितनी बार repeat हो सकता है। अगर हमें pattern में exact count, minimum count या variable count check करना हो, तो quantifiers use होते हैं।

For example, mobile number में exactly 10 digits चाहिए, password में कम से कम कुछ characters चाहिए या किसी word में repeated letters हो सकते हैं। ऐसे cases में quantifiers बहुत helpful होते हैं।

Common Quantifiers

Quantifier Meaning
* Zero या more times
+ One या more times
? Zero या one time
{n} Exactly n times
{n,} At least n times
{n,m} Minimum n और maximum m times

Using + Quantifier

import re

text = "a ab abb abbb"

result = re.findall(r"ab+", text)

print(result)
Output:
['ab', 'abb', 'abbb']

Using * Quantifier

import re

text = "a ab abb abbb"

result = re.findall(r"ab*", text)

print(result)
Output:
['a', 'ab', 'abb', 'abbb']

Using ? Quantifier

import re

text = "color colour"

result = re.findall(r"colou?r", text)

print(result)
Output:
['color', 'colour']

Exact Count

import re

text = "123 1234 12345"

result = re.findall(r"/d-4", text)

print(result)
Output:
['1234', '1234']

Last number 12345 में first four digits भी match हो गए। Exact complete word match के लिए boundaries या fullmatch use किया जा सकता है।

Mobile Number Validation

import re

mobile = "9876543210"

result = re.fullmatch(r"/d-10", mobile)

if result:
    print("Valid")
else:
    print("Invalid")
Output:
Valid

Minimum and Maximum Count

text = "ab abb abbb abbbb"

['abb', 'abbb', 'abbb']

Quantifiers pattern repetition को control करते हैं। Validation में {n} बहुत useful होता है।

The Dot Character

Regex में dot character . एक special character है। यह newline को छोड़कर किसी भी single character को match करता है। इसका use तब किया जाता है जब exact character important न हो, केवल position या pattern structure important हो।

Dot powerful है, लेकिन इसे carefully use करना चाहिए क्योंकि यह बहुत broad match कर सकता है। अगर actual dot यानी period symbol match करना हो, तो \. लिखना पड़ता है।

Simple Dot Example

import re

text = "cat cot cut c9t"

result = re.findall(r"c.t", text)

print(result)
Output:
['cat', 'cot', 'cut', 'c9t']

Dot Does Not Match Newline by Default

import re

text = "a/nb"

result = re.search(r"a.b", text)

print(result)
Output:
None

Matching Dot Literally

import re

text = "price-is-99.50"

result = re.search(r"/.", text)

if result:
    print("Actual dot found")
Output:
Actual dot found

Dot with Quantifier

import re

text = "Start Python End"

result = re.findall(r"start.*end", text)

print(result)
Output:
['Start Python End']

Important Points

  • . किसी भी single character को match करता है।
  • By default newline को match नहीं करता।
  • Actual dot match करने के लिए \. use करें।
  • Dot को quantifiers के साथ use करने पर match बहुत बड़ा हो सकता है।
Real Life Example:
अगर हमें ऐसे words search करने हैं जिनमें first और last character fixed हों लेकिन middle character कोई भी हो सकता है, तो dot character useful होता है।

Greedy Matches

Regex quantifiers by default greedy होते हैं। Greedy का मतलब है कि regex engine जितना possible हो उतना ज्यादा text match करने की कोशिश करता है। Quantifiers जैसे *, +, {n,m} normally greedy behavior दिखाते हैं।

कई बार greedy matching unexpected result दे सकती है क्योंकि pattern expected से ज्यादा text match कर लेता है। ऐसी situation में non-greedy या lazy matching use की जाती है। Lazy matching के लिए quantifier के बाद question mark ? लगाया जाता है, जैसे *?, +?.

Greedy Match Example

import re

text = "lt-b-gt-python-lt/b-gt-and-lt-b-gt-java-lt/b-gt"

result = re.findall(r"lt-b-gt.*</b-gt", text)

print(result)
Output:
['lt-b-gt-python-lt/b-gt-and-lt-b-gt-java-lt/b-gt']

यहाँ regex ने first <b> से last </b> तक पूरा text match कर लिया क्योंकि .* greedy है।

Non-Greedy Match Example

import re

text = "lt-b-gt-python-lt/b-gt-and-lt-b-gt-java-lt/b-gt"

result = re.findall(r"lt-b-gt.*?</b>", text)

print(result)
Output:
['lt-b-gt-python-lt/b-gt', 'lt-b-gt-java-lt/b-gt']

Greedy vs Non-Greedy

Type Pattern Behavior
Greedy .* Maximum possible text match करता है।
Non-Greedy .*? Minimum possible text match करता है।
Greedy .+ One or more maximum characters।
Non-Greedy .+? One or more minimum characters।

Common Mistakes

  • .* का use करके expected से ज्यादा text match कर लेना।
  • HTML/XML जैसी strings में greedy matching को ignore करना।
  • Lazy quantifier ? का role न समझना।
Remember:
Greedy matching ज्यादा से ज्यादा text match करती है, जबकि non-greedy matching कम से कम text match करती है।

Grouping

Regex में grouping के लिए parentheses ( ) का use किया जाता है। Grouping से pattern के किसी part को एक unit की तरह treat किया जा सकता है। Groups का use repeated pattern, extraction, alternation और match object से specific data निकालने के लिए किया जाता है।

जब pattern में groups बनाए जाते हैं, तो match object की help से उन groups को अलग-अलग access किया जा सकता है। Groups data extraction में बहुत useful होते हैं, जैसे email से username और domain अलग निकालना।

Simple Group Example

import re

text = "My number is 9876543210"

result = re.search(r"item/d-10", text)

print(result.group(1))
Output:
9876543210

Multiple Groups

import re

text = "Date: 10-07-2026"

result = re.search(r"item/d-2/d-2/d-4", text)

print(result.group(1))
print(result.group(2))
print(result.group(3))
Output:
10
07
2026

Using groups()

import re

text = "Date: 10-07-2026"

result = re.search(r"item/d-2/d-2/d-4", text)

print(result.groups())
Output:
('10', '07', '2026')

Grouping with OR

import re

text = "I like Python"

result = re.search(r"python-java-c/item/item", text)

print(result.group())
Output:
Python

Non-Capturing Group

अगर group केवल pattern grouping के लिए चाहिए और उसे capture नहीं करना है, तो (?: ) use किया जाता है।

import re

text = "PythonPython"

result = re.search(r"(?:Python)+", text)

print(result.group())
Output:
PythonPython

Email Group Example

import re

email = "student-example.com"

result = re.search(r"item/w/w/./w", email)

print("Username:", result.group(1))
print("Domain:", result.group(2))
Output:
Username: student
Domain: example.com
Real Life Example:
Date string से day, month और year अलग निकालने के लिए grouping बहुत useful होती है।
Remember:
Parentheses pattern को group करते हैं और captured data को group() से access किया जा सकता है।

Matching at Beginning or End

Regex में beginning और end matching के लिए anchors का use किया जाता है। Anchor actual character को match नहीं करता, बल्कि position को match करता है। String की शुरुआत check करने के लिए ^ और string के end को check करने के लिए $ use होता है।

Anchors validation में बहुत useful होते हैं। अगर हमें ensure करना है कि पूरी string एक particular pattern follow करे, तो beginning और ending anchors का use किया जाता है।

Beginning Match with ^

import re

text = "Python is easy"

result = re.search(r"^Python", text)

if result:
    print("String starts with Python")
Output:
String starts with Python

End Match with $

import re

text = "I am learning Python"

result = re.search(r"Python$", text)

if result:
    print("String ends with Python")
Output:
String ends with Python

Full Pattern Validation

import re

mobile = "9876543210"

result = re.search(r"item/d-10", mobile)

if result:
    print("Valid mobile number")
else:
    print("Invalid mobile number")
Output:
Valid mobile number

Using re.match()

re.match() string के beginning से pattern match करता है। यह पूरी string में search नहीं करता, बल्कि शुरुआत से matching check करता है।

import re

text = "Python is easy"

result = re.match("Python", text)

print(result.group())
Output:
Python

Using re.fullmatch()

fullmatch() check करता है कि पूरी string pattern से match हो रही है या नहीं। Validation के लिए यह बहुत useful है।

import re

pin = "209625"

result = re.fullmatch(r"/d-6", pin)

if result:
    print("Valid PIN code")
Output:
Valid PIN code

^ beginning के लिए और $ ending के लिए use होता है। Validation में दोनों साथ use करना common है।

Match Objects

जब re.search(), re.match() या re.fullmatch() को pattern match मिलता है, तो वह match object return करता है। अगर match नहीं मिलता, तो None return होता है। Match object में matched text, start position, end position और groups जैसी information होती है।

Match object regex result को detail में analyze करने के लिए useful होता है। इससे हम matched text, index positions और captured groups प्राप्त कर सकते हैं।

Creating Match Object

import re

text = "Python is easy"

result = re.search("easy", text)

print(result)
Output:
<re.Match object; span=(10, 14), match='easy'>

group()

group() matched text return करता है।

import re

text = "Python is easy"

result = re.search("easy", text)

print(result.group())
Output:
easy

start() and end()

start() match की starting index और end() ending index return करता है।

import re

text = "Python is easy"

result = re.search("easy", text)

print(result.start())
print(result.end())
Output:
10
14

span()

span() start और end position को tuple के रूप में return करता है।

import re

text = "Python is easy"

result = re.search("easy", text)

print(result.span())
Output:
(10, 14)

Using Match Object Safely

Match object use करने से पहले check करना चाहिए कि result None तो नहीं है। अगर None पर group() call करेंगे, तो error आएगा।

import re

text = "Python is easy"

result = re.search("Java", text)

if result:
    print(result.group())
else:
    print("No match found")
Output:
No match found

Match Object Methods

Method Use
group() Matched text return करता है।
groups() All captured groups return करता है।
start() Match की start index return करता है।
end() Match की end index return करता है।
span() Start और end index tuple में return करता है।
Real Life Example:
Text editor में search feature match object की position से बता सकता है कि searched word किस index पर मिला है।

Substituting

Substituting का मतलब text में किसी pattern को दूसरे text से replace करना होता है। Python regex में इसके लिए re.sub() function use होता है। यह normal replace() method से ज्यादा powerful है क्योंकि यह exact text की जगह pattern के basis पर replacement कर सकता है।

Substitution text cleaning, data formatting, unwanted characters remove करने और sensitive information mask करने में बहुत useful होता है।

Basic Syntax

re.sub(pattern, replacement, string)

Simple Replacement

import re

text = "I like Java"

new_text = re.sub("Java", "Python", text)

print(new_text)
Output:
I like Python

Replacing Digits

import re

text = "My number is 9876543210"

new_text = re.sub(r"/d", "*", text)

print(new_text)
Output:
My number is **********

Removing Extra Spaces

import re

text = "Python    is     easy"

new_text = re.sub(r"/s", " ", text)

print(new_text)
Output:
Python is easy

Using count Parameter

count parameter बताता है कि कितनी replacements करनी हैं।

import re

text = "Python Python Python"

new_text = re.sub("Python", "Java", text, count=2)

print(new_text)
Output:
Java Java Python

Substitution with Groups

import re

date = "10-07-2026"

new_date = re.sub(r"item/d-2/d-2/d-4", r"/3//2//1", date)

print(new_date)
Output:
2026/07/10

Common Uses

  • Text cleaning।
  • Multiple spaces को single space में convert करना।
  • Digits या sensitive data mask करना।
  • Date format change करना।
  • Unwanted symbols remove करना।
Remember:
re.sub() pattern-based replacement के लिए use होता है।

Splitting a String

Splitting का मतलब string को छोटे parts में divide करना है। Python string का normal split() method fixed separator पर split करता है, लेकिन regex वाला re.split() pattern के basis पर split कर सकता है।

जब separator simple न हो, जैसे multiple spaces, comma, semicolon, dash या mixed separators हों, तब re.split() बहुत useful होता है।

Basic Syntax

re.split(pattern, string)

Split by Spaces

import re

text = "Python is easy"

result = re.split(r"/s", text)

print(result)
Output:
['Python', 'is', 'easy']

Split by Multiple Spaces

import re

text = "Python    is     easy"

result = re.split(r"/s", text)

print(result)
Output:
['Python', 'is', 'easy']

Split by Multiple Separators

import re

text = "Python,Java;C++ HTML"

result = re.split(r"item/s", text)

print(result)
Output:
['Python', 'Java', 'C++', 'HTML']

Using maxsplit

import re

text = "Python Java C++ HTML"

result = re.split(r"/s", text, maxsplit=2)

print(result)
Output:
['Python', 'Java', 'C++ HTML']

split() vs re.split()

Basis split() re.split()
Separator Fixed separator use करता है। Pattern-based separator use करता है।
Module No module required। re module required।
Use Simple splitting। Complex splitting।
Real Life Example:
CSV-like text में comma, semicolon और spaces मिले हुए हों, तो re.split() से data आसानी से अलग किया जा सकता है।

Compiling Regular Expressions

Python में re.compile() function regex pattern को compile करके pattern object बनाता है। अगर same pattern को program में बार-बार use करना है, तो compile करना useful होता है। इससे code clean होता है और repeated matching easier हो जाती है।

Compiled regex object के साथ search(), match(), findall(), sub() और split() जैसे methods directly use किए जा सकते हैं।

Basic Syntax

pattern = re.compile(r"regex_pattern")

Compiled Pattern Example

import re

pattern = re.compile(r"/d")

text = "Marks are 85 and age is 23"

result = pattern.findall(text)

print(result)
Output:
['85', '23']

Using search() with Compiled Pattern

import re

mobile_pattern = re.compile(r"item/d-10")

mobile = "9876543210"

if mobile_pattern.search(mobile):
    print("Valid mobile number")
else:
    print("Invalid mobile number")
Output:
Valid mobile number

Compiled Pattern with sub()

import re

pattern = re.compile(r"/s")

text = "Python    is     easy"

new_text = pattern.sub(" ", text)

print(new_text)
Output:
Python is easy

Benefits of Compiling

  • Same regex pattern को बार-बार use करना आसान होता है।
  • Code readable और organized बनता है।
  • Pattern object reusable होता है।
  • Large programs में regex management easy हो जाता है।

Without Compile vs With Compile

Without Compile With Compile
re.findall(r"/d", text) pattern.findall(text)
Short one-time use के लिए ठीक। Repeated use के लिए better।
Remember:
Same regex pattern को बार-बार use करना हो तो re.compile() better approach है।

Flags

Regex flags pattern matching behavior को modify करते हैं। Flags की help से case-insensitive matching, multiline matching, dot-all matching और readable regex writing जैसी facilities मिलती हैं। Python में flags को re.search(), re.findall(), re.compile() आदि functions में pass किया जा सकता है।

Common Regex Flags

Flag Short Name Use
re.IGNORECASE re.I Case-insensitive matching।
re.MULTILINE re.M ^ और $ को हर line पर work करवाता है।
re.DOTALL re.S Dot . को newline भी match करवाता है।
re.VERBOSE re.X Regex को readable format में लिखने देता है।

IGNORECASE Example

import re

text = "Python is easy"

result = re.search("python", text, re.IGNORECASE)

if result:
    print("Match found")
Output:
Match found

MULTILINE Example

import re

text = """Python is easy
Java is popular
Python is powerful"""

result = re.findall(r"^Python", text, re.MULTILINE)

print(result)
Output:
['Python', 'Python']

DOTALL Example

import re

text = "start/npython/nend"

result = re.search(r"start.*end", text, re.DOTALL)

if result:
    print("Matched")
Output:
Matched

VERBOSE Example

re.VERBOSE long regex को readable बनाने में help करता है। इसमें spaces और comments use किए जा सकते हैं।

import re

pattern = re.compile(r"""
    ^           # start
    \d{10}      # exactly 10 digits
    $           # end
""", re.VERBOSE)

mobile = "9876543210"

if pattern.search(mobile):
    print("Valid")
Output:
Valid

Combining Multiple Flags

import re

text = """python
Python
PYTHON"""

result = re.findall(r"^python", text, re.IGNORECASE | re.MULTILINE)

print(result)
Output:
['python', 'Python', 'PYTHON']

Important Points

  • Flags regex matching behavior change करते हैं।
  • re.I case-insensitive matching के लिए use होता है।
  • re.M multiline beginning/end matching के लिए use होता है।
  • re.S dot को newline match करने देता है।
  • re.X readable regex लिखने में help करता है।
Real Life Example:
User “python”, “Python” या “PYTHON” किसी भी case में search करे, तो re.IGNORECASE से सभी match किए जा सकते हैं।
Remember:
Flags regex को flexible बनाते हैं। Multiple flags को | operator से combine किया जा सकता है।
