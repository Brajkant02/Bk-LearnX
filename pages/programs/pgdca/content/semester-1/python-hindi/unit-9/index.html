Classes in Python

Classes in Python

Python में class object-oriented programming का basic building block है। Class एक blueprint या template की तरह होती है, जिससे objects create किए जाते हैं। जिस तरह house बनाने से पहले उसका design या map बनाया जाता है, उसी तरह object बनाने से पहले class बनाई जाती है।

Class में data और behavior दोनों को एक साथ रखा जाता है। Data को attributes या variables कहा जाता है और behavior को methods कहा जाता है। Object class का real instance होता है। यानी class plan है और object उस plan से बना actual item है।

Python पूरी तरह object-oriented language है। Python में almost हर चीज object होती है, जैसे integer, string, list, function और module. Classes programmer को अपने custom data types create करने की facility देती हैं।

Class and Object Concept

Term Meaning Example
Class Object बनाने का blueprint। Student
Object Class से बना actual instance। Brajkant नाम का student object
Attribute Object का data/property। name, age, course
Method Object का behavior/function। show_details()

Simple Class Example

class Student:
    name = "Brajkant"
    course = "PGDCA"

s1 = Student()

print(s1.name)
print(s1.course)
Output:
Brajkant
PGDCA

Why Classes Are Needed

  • Real-world entities को program में represent करने के लिए।
  • Data और functions को एक single unit में combine करने के लिए।
  • Large programs को organized और modular बनाने के लिए।
  • Code reuse और maintainability improve करने के लिए।
  • Inheritance और polymorphism जैसे OOP concepts apply करने के लिए।
Real Life Example:
Student Management System में Student class बनाई जा सकती है जिसमें name, roll number, course attributes और display, update, calculate_result methods हो सकते हैं।
Remember:
Class blueprint है और object उस blueprint से बना actual instance है।

Principles of Object Orientation

Object-oriented programming यानी OOP एक programming approach है जिसमें program को objects के form में design किया जाता है। Object real-world entity को represent करता है। OOP का main purpose program को modular, reusable, secure और easy to maintain बनाना है।

OOP के important principles हैं: Encapsulation, Abstraction, Inheritance और Polymorphism. ये principles large software development में बहुत useful होते हैं क्योंकि इनसे code organized रहता है और complexity reduce होती है।

Encapsulation

Encapsulation का मतलब data और methods को एक single unit यानी class में bind करना है। इससे data directly हर जगह से access नहीं होता और object अपने methods के through data को manage करता है।

class Student:
    def __init__(self, name):
        self.name = name

    def show_name(self):
        print("Name:", self.name)

s1 = Student("Brajkant")
s1.show_name()
Output:
Name: Brajkant

Abstraction

Abstraction का मतलब unnecessary details को hide करके only essential features show करना है। User को यह जानने की जरूरत नहीं होती कि अंदर logic कैसे काम कर रहा है।

For example, जब हम mobile में call button press करते हैं, तो हमें internal network processing की detail नहीं पता होती। हमें केवल call feature visible होता है।

Inheritance

Inheritance में एक class दूसरी class की properties और methods को acquire कर सकती है। इससे code reuse होता है और relationship-based classes बनाई जा सकती हैं।

class Person:
    def show(self):
        print("I am a person")

class Student(Person):
    pass

s1 = Student()
s1.show()
Output:
I am a person

Polymorphism

Polymorphism का मतलब है same method name या same operation का different objects के साथ different behavior दिखाना। Python में polymorphism method overriding और duck typing के through commonly दिखता है।

class Dog:
    def sound(self):
        print("Dog barks")

class Cat:
    def sound(self):
        print("Cat meows")

for animal in (Dog(), Cat()):
    animal.sound()
Output:
Dog barks
Cat meows

Remember:
OOP real-world problem को objects और classes के form में solve करने की technique है।

Creating Classes

Python में class create करने के लिए class keyword का use किया जाता है। Class name usually capital letter से start किया जाता है। यह naming convention है, compulsory syntax नहीं। Class के अंदर variables और methods define किए जा सकते हैं।

Object create करने के लिए class name को function की तरह call किया जाता है। Object create होते ही class का constructor method __init__() automatically call हो सकता है। Constructor object की initial values set करने के लिए use होता है।

Basic Syntax

class ClassName:
    statements

Creating Object

class Student:
    pass

s1 = Student()

print(type(s1))
Output:
<class 'main.student'>

Using __init__() Constructor

__init__() special method है जो object create होते समय automatically execute होता है। इसका use object की initial properties set करने के लिए किया जाता है।

class Student:
    def __init__(self, name, course):
        self.name = name
        self.course = course

s1 = Student("Brajkant", "PGDCA")

print(s1.name)
print(s1.course)
Output:
Brajkant
PGDCA

class Student:
    def __init__(self, name):
        self.name = name

    def show(self):

s1 = Student("Brajkant")
s1.show()

  • Class name के बाद colon : लगाना भूल जाना।
  • Method में self parameter लिखना भूल जाना।
  • __init__ spelling गलत लिखना।
  • Object create करते समय required arguments pass न करना।
Real Life Example:
Student class से अलग-अलग student objects बनाए जा सकते हैं, जिनमें हर student का name और course अलग होगा।

Instance Methods

Instance methods वे methods होते हैं जो class के object यानी instance पर काम करते हैं। ये methods object के data को access और modify कर सकते हैं। Instance method का पहला parameter usually self होता है, जो current object को refer करता है।

Instance methods object-specific behavior define करते हैं। For example, Student class में show_details(), update_course() और calculate_result() जैसे methods instance methods हो सकते हैं क्योंकि ये particular student object के data पर काम करेंगे।

Simple Instance Method

class Student:
    def __init__(self, name, course):
        self.name = name
        self.course = course

    def show_details(self):
        print("Name:", self.name)
        print("Course:", self.course)

s1 = Student("Brajkant", "PGDCA")
s1.show_details()
Output:
Name: Brajkant
Course: PGDCA

Method to Update Data

class Student:
    def __init__(self, name, course):
        self.name = name
        self.course = course

    def update_course(self, new_course):
        self.course = new_course

    def show_details(self):
        print(self.name, self.course)

s1 = Student("Brajkant", "PGDCA")
s1.update_course("Python")
s1.show_details()
Output:
Brajkant Python

Method with Return Value

class Marks:
    def __init__(self, m1, m2, m3):
        self.m1 = m1
        self.m2 = m2
        self.m3 = m3

    def total(self):
        return self.m1 + self.m2 + self.m3

student_marks = Marks(80, 75, 90)

print("Total:", student_marks.total())
Output:
Total: 245

Instance Method Features

  • Object के data को access कर सकता है।
  • Object के data को modify कर सकता है।
  • पहला parameter usually self होता है।
  • Object के through call किया जाता है।
  • Object-specific behavior define करता है।
Remember:
Instance method का पहला parameter self होता है और यह current object के data पर काम करता है।

File Organization

Python projects में classes को properly organize करना बहुत important है। Small program में class और main code एक ही file में लिखा जा सकता है, लेकिन large project में classes को अलग modules/files में रखना better होता है। इससे code clean, reusable और maintainable बनता है।

File organization का मतलब है project की files को logical तरीके से arrange करना। Related classes को एक module में रखा जा सकता है। Main program अलग file में हो सकता है। इससे team members अलग-अलग files पर easily काम कर सकते हैं।

Single File Example

# main.py

class Student:
    def __init__(self, name):
        self.name = name

    def show(self):
        print("Name:", self.name)

s1 = Student("Brajkant")
s1.show()
Output:
Name: Brajkant

Separate Class File

मान लो class को student.py file में रखा गया है:

# student.py

class Student:
    def __init__(self, name, course):
        self.name = name
        self.course = course

    def show(self):
        print(self.name, self.course)

अब main file में class import की जा सकती है:

# main.py

from student import Student

s1 = Student("Brajkant", "PGDCA")
s1.show()
Output:
Brajkant PGDCA

Possible Project Structure

project/
│
├── main.py
├── student.py
├── teacher.py
├── course.py
└── utils.py

Benefits of Proper File Organization

  • Code readability improve होती है।
  • Large project manage करना आसान होता है।
  • Classes को reuse करना आसान होता है।
  • Testing और debugging simple होती है।
  • Team work में confusion कम होता है।

Common Mistakes

  • सब code एक ही file में लिख देना।
  • File names को unclear रखना।
  • Standard module names जैसे math.py, time.py रखना।
  • Import path सही न रखना।
Real Life Example:
School management project में Student, Teacher, Course और Fee की classes अलग-अलग files में रखी जा सकती हैं।

Special Methods

Python में special methods वे methods होते हैं जिनके नाम के beginning और ending में double underscore होता है। इन्हें dunder methods भी कहा जाता है। जैसे __init__(), __str__(), __len__(), __add__() आदि।

Special methods Python objects को built-in behavior देने के लिए use होते हैं। इनके through हम object को print करने, compare करने, add करने, length निकालने और other operations perform करने के लिए customize कर सकते हैं।

__init__()

__init__() constructor method है जो object create होने पर automatically call होता है।

class Student:
    def __init__(self, name):
        self.name = name

s1 = Student("Brajkant")
print(s1.name)
Output:
Brajkant

__str__()

__str__() object का user-friendly string representation return करता है। जब object को print किया जाता है, तो यह method automatically call होता है।

class Student:
    def __init__(self, name, course):
        self.name = name
        self.course = course

    def __str__(self):
        return f"self-name-self.course}"

s1 = Student("Brajkant", "PGDCA")

print(s1)
Output:
Brajkant - PGDCA

__len__()

__len__() object पर len() function का behavior define कर सकता है।

class Batch:
    def __init__(self, students):
        self.students = students

    def __len__(self):
        return len(self.students)

b1 = Batch(["Amit", "Ravi", "Brajkant"])

print(len(b1))
Output:
3

__add__()

__add__() method object पर plus operator + का behavior customize करता है।

class Marks:
    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return self.value + other.value

m1 = Marks(80)
m2 = Marks(90)

print(m1 + m2)
Output:
170

Common Special Methods

Method Use
__init__() Object initialization के लिए।
__str__() Readable string output के लिए।
__len__() len() behavior define करने के लिए।
__add__() + operator behavior define करने के लिए।
__eq__() Equality comparison के लिए।
Remember:
Special methods Python objects को built-in functions और operators के साथ काम करने योग्य बनाते हैं।

Class Variables

Class variables वे variables होते हैं जो class के अंदर लेकिन methods के बाहर define किए जाते हैं। ये variables class के सभी objects के लिए common होते हैं। अगर कोई data सभी objects के लिए same होना चाहिए, तो उसे class variable के रूप में define किया जा सकता है।

Instance variables हर object के लिए अलग-अलग values रखते हैं, जबकि class variables सभी objects द्वारा shared होते हैं। Class variables को class name या object name दोनों से access किया जा सकता है, लेकिन best practice class name से access करना है।

Class Variable Example

class Student:
    college = "Government Polytechnic Kanpur"

    def __init__(self, name):
        self.name = name

s1 = Student("Brajkant")
s2 = Student("Amit")

print(s1.name, s1.college)
print(s2.name, s2.college)
Output:
Brajkant Government Polytechnic Kanpur
Amit Government Polytechnic Kanpur

Changing Class Variable

class Student:
    college = "GPK"

Student.college = "Government Polytechnic Kanpur"

print(Student.college)
Output:
Government Polytechnic Kanpur

Class Variable vs Instance Variable

Basis Class Variable Instance Variable
Defined Class के अंदर, methods के बाहर। Usually __init__() में self के साथ।
Shared सभी objects में shared। हर object की अलग value।
Access Class name से access करना best है। Object name से access होता है।
Example college name, age

Counting Objects Using Class Variable

class Student:
    count = 0

    def __init__(self, name):
        self.name = name
        Student.count += 1

s1 = Student("Brajkant")
s2 = Student("Amit")
s3 = Student("Neha")

print("Total Students:", Student.count)
Output:
Total Students: 3
Real Life Example:
College name सभी students के लिए same हो सकता है, इसलिए उसे class variable बनाया जा सकता है। Student name हर object के लिए अलग होगा, इसलिए वह instance variable होगा।
Remember:
Class variable shared होता है, instance variable object-specific होता है।

Inheritance

Inheritance object-oriented programming का important principle है। इसमें एक class दूसरी class की properties और methods को acquire कर सकती है। जिस class से properties ली जाती हैं उसे parent class, base class या superclass कहते हैं। जो class properties receive करती है उसे child class, derived class या subclass कहते हैं।

Inheritance का main benefit code reuse है। अगर common features parent class में define कर दिए जाएँ, तो child classes उन्हें reuse कर सकती हैं। इससे duplicate code कम होता है और program structured बनता है।

Simple Inheritance

class Person:
    def show_person(self):
        print("I am a person")

class Student(Person):
    def show_student(self):
        print("I am a student")

s1 = Student()

s1.show_person()
s1.show_student()
Output:
I am a person
I am a student

Parent Constructor Calling

Child class में parent class का constructor call करने के लिए super() function use किया जाता है।

class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, course):
        super().__init__(name)
        self.course = course

s1 = Student("Brajkant", "PGDCA")

print(s1.name)
print(s1.course)
Output:
Brajkant
PGDCA

Method Overriding

जब child class parent class के same method name को अपनी requirement के according redefine करती है, तो उसे method overriding कहते हैं।

class Person:
    def show(self):
        print("Person details")

class Student(Person):
    def show(self):
        print("Student details")

s1 = Student()
s1.show()
Output:
Student details

Types of Inheritance

Type Meaning
Single Inheritance एक child class एक parent class से inherit करती है।
Multiple Inheritance एक child class multiple parent classes से inherit करती है।
Multilevel Inheritance Inheritance chain बनती है: Grandparent → Parent → Child।
Hierarchical Inheritance एक parent class से multiple child classes inherit करती हैं।

Multilevel Inheritance Example

class GrandParent:
    def grand_parent_method(self):
        print("Grandparent method")

class Parent(GrandParent):
    def parent_method(self):
        print("Parent method")

class Child(Parent):
    def child_method(self):
        print("Child method")

obj = Child()

obj.grand_parent_method()
obj.parent_method()
obj.child_method()
Output:
Grandparent method
Parent method
Child method

Benefits of Inheritance

  • Code reuse possible होता है।
  • Duplicate code कम होता है।
  • Real-world relationship represent करना आसान होता है।
  • Program organized और maintainable बनता है।
  • Method overriding से behavior customize किया जा सकता है।
Real Life Example:
Person parent class हो सकती है और Student, Teacher, Employee child classes हो सकती हैं। सभी में name और age common हो सकते हैं, लेकिन work अलग-अलग होगा।
Remember:
Inheritance का main purpose code reuse और relationship-based class design है।

Polymorphism

Polymorphism object-oriented programming का important principle है। Polymorphism का मतलब है “many forms”. Programming में इसका मतलब है same method name, same function या same operator का different objects के साथ different behavior दिखाना।

Python में polymorphism बहुत natural तरीके से work करता है क्योंकि Python dynamically typed language है। अगर अलग-अलग classes में same method name available है, तो same code उन objects पर अलग-अलग behavior दिखा सकता है।

Method Polymorphism

class Dog:
    def sound(self):
        print("Dog barks")

class Cat:
    def sound(self):
        print("Cat meows")

class Cow:
    def sound(self):
        print("Cow moos")

animals = [Dog(), Cat(), Cow()]

for animal in animals:
    animal.sound()
Output:
Dog barks
Cat meows
Cow moos

Function Polymorphism

Same function different objects को accept करके उनके behavior के according result दे सकता है।

def make_sound(animal):
    animal.sound()

dog = Dog()
cat = Cat()

make_sound(dog)
make_sound(cat)
Output:
Dog barks
Cat meows

Operator Polymorphism

Python में same operator अलग-अलग data types के साथ अलग behavior दिखा सकता है।

print(10 + 20)
print("Hello " + "Python")
print([1, 2] + [3, 4])
Output:
30
Hello Python
[1, 2, 3, 4]

ऊपर + operator numbers के लिए addition कर रहा है, strings के लिए concatenation कर रहा है और lists के लिए merging कर रहा है। यही operator polymorphism है।

Method Overriding as Polymorphism

class Shape:
    def area(self):
        print("Area of shape")

class Circle(Shape):
    def area(self):
        print("Area of circle")

class Rectangle(Shape):
    def area(self):
        print("Area of rectangle")

shapes = [Circle(), Rectangle()]

for shape in shapes:
    shape.area()
Output:
Area of circle
Area of rectangle

Duck Typing

Python में duck typing का मतलब है कि object किस class का है यह कम important है, object required method provide करता है या नहीं यह ज्यादा important है। अगर कोई object sound() method provide करता है, तो उसे sound behavior के लिए use किया जा सकता है।

class Bird:
    def fly(self):
        print("Bird can fly")

class Airplane:
    def fly(self):
        print("Airplane can fly")

def start_flying(obj):
    obj.fly()

start_flying(Bird())
start_flying(Airplane())
Output:
Bird can fly
Airplane can fly

Benefits of Polymorphism

  • Code flexible बनता है।
  • Same interface से different objects handle हो सकते हैं।
  • Code reuse improve होता है।
  • Large applications में extensibility बढ़ती है।
  • Child classes अपनी behavior customize कर सकती हैं।

Inheritance vs Polymorphism

Basis Inheritance Polymorphism
Meaning एक class दूसरी class से properties लेती है। Same method/operator different behavior दिखाता है।
Purpose Code reuse। Flexibility।
Example Student inherits Person। Dog और Cat दोनों sound() differently execute करते हैं।
Real Life Example:
Payment system में CreditCard, UPI और Cash classes में same pay() method हो सकता है, लेकिन हर payment method का process अलग होगा।
Remember:
Polymorphism का मतलब है same name या same interface का multiple forms में behave करना।
