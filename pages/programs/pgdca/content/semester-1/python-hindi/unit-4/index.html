Collections in Python

Introduction

Python में collections का मतलब ऐसे data structures से है जिनमें एक से ज्यादा values को एक ही variable में store किया जा सकता है। Normal variable में usually एक value store होती है, लेकिन collections में multiple values को group form में रखा जाता है। इससे program में data को manage करना, access करना, update करना और process करना आसान हो जाता है।

Python में four commonly used built-in collection types होते हैं: list, tuple, set और dictionary. हर collection का अपना अलग purpose और behavior होता है। कुछ collections ordered होते हैं, कुछ unordered होते हैं, कुछ duplicate values allow करते हैं और कुछ duplicate values allow नहीं करते।

Need of Collections

मान लो किसी class के 50 students के names store करने हैं। अगर normal variables use करेंगे तो name1, name2, name3 जैसे बहुत सारे variables बनाने पड़ेंगे। यह तरीका difficult और unprofessional है। Collection की help से सभी names एक ही variable में store किए जा सकते हैं।

students = ["Amit", "Ravi", "Neha", "Brajkant"]

Types of Collections

Collection Ordered Changeable Duplicates Example
List Yes Yes Allowed [10, 20, 30]
Tuple Yes No Allowed (10, 20, 30)
Set No Yes Not Allowed {10, 20, 30}
Dictionary Yes Yes Duplicate keys not allowed {"name": "Amit"}
Real Life Example:
School management system में students की list, fixed subjects का tuple, unique roll numbers का set और student record का dictionary use किया जा सकता है।
Remember:
Collection choose करते समय यह देखना जरूरी है कि data change होगा या नहीं, order चाहिए या नहीं, और duplicate values allow करनी हैं या नहीं।

Lists

List Python की सबसे commonly used collection type है। List में multiple items को एक single variable में store किया जाता है। List ordered होती है, यानी items जिस order में insert किए जाते हैं, उसी order में store रहते हैं। List changeable होती है, यानी items को add, remove और update किया जा सकता है। List duplicate values भी allow करती है।

List को square brackets [ ] के अंदर लिखा जाता है। List में same type या different type की values store की जा सकती हैं। यानी एक list में numbers, strings और boolean values भी एक साथ रखी जा सकती हैं।

Creating a List

subjects = ["Python", "DCCN", "BCIT", "WDT"]

print(subjects)
Output:
['Python', 'DCCN', 'BCIT', 'WDT']

List with Mixed Data

student = ["Brajkant", 23, "PGDCA", 85.5]

print(student)
Output:
['Brajkant', 23, 'PGDCA', 85.5]

Accessing List Items

List items को index की help से access किया जाता है। Python में indexing 0 से start होती है।

subjects = ["Python", "DCCN", "BCIT", "WDT"]

print(subjects[0])
print(subjects[2])
Output:
Python
BCIT

Negative Indexing

Negative indexing list के last item से counting start करती है। -1 last item को represent करता है।

subjects = ["Python", "DCCN", "BCIT", "WDT"]

print(subjects[-1])
print(subjects[-2])
Output:
WDT
BCIT

Changing List Item

subjects = ["Python", "DCCN", "BCIT"]

subjects[1] = "Networking"

Output:

Shopping cart में products को list में store किया जा सकता है क्योंकि user products add, remove और update कर सकता है।
Remember:
List ordered, changeable और duplicate values allow करने वाली collection है।

Tuples

Tuple Python की एक collection type है जिसमें multiple items store किए जाते हैं। Tuple ordered होती है, यानी items का order fixed रहता है। लेकिन tuple unchangeable होती है, यानी tuple create होने के बाद उसके items को change, add या remove नहीं किया जा सकता। इसी property को immutable कहा जाता है।

Tuple को parentheses ( ) के अंदर लिखा जाता है। Tuple का use ऐसे data के लिए किया जाता है जो program में fixed रहना चाहिए, जैसे days of week, months name, fixed coordinates, RGB color values आदि।

Creating a Tuple

subjects = ("Python", "DCCN", "BCIT")

print(subjects)
Output:
('Python', 'DCCN', 'BCIT')

Accessing Tuple Items

subjects = ("Python", "DCCN", "BCIT")

print(subjects[0])
print(subjects[-1])
Output:
Python
BCIT

Single Item Tuple

अगर tuple में केवल एक item है, तो उसके बाद comma लगाना जरूरी होता है। बिना comma के Python उसे normal value समझ सकता है।

a = ("Python")
b = ("Python",)

print(type(a))
print(type(b))
Output:
<class 'str'>
<class 'tuple'>

Tuple Cannot Be Changed

subjects = ("Python", "DCCN", "BCIT")

subjects[0] = "Java"
Output:
TypeError: 'tuple' object does not support item assignment

Looping Through Tuple

subjects = ("Python", "DCCN", "BCIT")

for subject in subjects:
    print(subject)
Output:
Python
DCCN
BCIT

Tuple Methods

Method Use

Real Life Example:
Week days जैसे Monday, Tuesday, Wednesday आदि fixed data हैं, इसलिए इन्हें tuple में store करना logical choice हो सकता है।
Remember:
Tuple ordered और duplicate values allow करती है, लेकिन changeable नहीं होती।

Sets

Set Python की collection type है जो unique items को store करती है। Set में duplicate values allow नहीं होतीं। Set unordered होती है, यानी items का fixed order नहीं होता। Set changeable होती है, लेकिन set के अंदर रखे items immutable होने चाहिए।

Set को curly braces { } के अंदर लिखा जाता है। Set का use तब किया जाता है जब हमें unique values store करनी हों या mathematical set operations जैसे union, intersection और difference perform करने हों।

Creating a Set

numbers = {10, 20, 30, 40}

print(numbers)
Output:
{40, 10, 20, 30}

Set unordered होता है, इसलिए output का order हर बार same होना जरूरी नहीं है।

Duplicates Are Removed

numbers = {10, 20, 10, 30, 20}

print(numbers)
Output:
{10, 20, 30}

Adding Items

subjects = {"Python", "DCCN"}

subjects.add("BCIT")

print(subjects)
Output:
{'Python', 'BCIT', 'DCCN'}

Removing Items

Method Use
remove() Item remove करता है। Item न मिले तो error देता है।
discard() Item remove करता है। Item न मिले तो error नहीं देता।
pop() Random item remove करता है।
clear() Set के सभी items remove करता है। 
subjects = {"Python", "DCCN", "BCIT"}

subjects.discard("DCCN")

print(subjects)
Output:
{'Python', 'BCIT'}

Set Operations

Operation Method / Operator Meaning
Union union() or | दोनों sets के सभी unique items देता है।
Intersection intersection() or & Common items देता है।
Difference difference() or - पहले set में मौजूद लेकिन दूसरे में absent items देता है।

b = {3, 4, 5, 6}

print(a | b)

print(a - b)

{1, 2, 3, 4, 5, 6}
{3, 4}
{1, 2}

Looping Through Set

subjects = {"Python", "DCCN", "BCIT"}

for subject in subjects:
    print(subject)
Output:
Python
DCCN
BCIT
Real Life Example:
अगर किसी website पर duplicate email IDs remove करनी हों, तो emails को set में convert करके unique emails प्राप्त किए जा सकते हैं।
Remember:
Set unordered होता है और duplicate values automatically remove कर देता है।

Dictionaries

Dictionary Python की बहुत powerful collection type है। Dictionary data को key-value pair के रूप में store करती है। इसमें हर value को access करने के लिए एक unique key होती है। List में values index से access होती हैं, लेकिन dictionary में values keys से access होती हैं।

Dictionary ordered और changeable होती है। इसमें duplicate keys allow नहीं होतीं, लेकिन values duplicate हो सकती हैं। Dictionary को curly braces { } के अंदर लिखा जाता है और key-value pair को colon : से separate किया जाता है।

Creating a Dictionary

student = {
    "name": "Brajkant",
    "course": "PGDCA",
    "age": 23
}

print(student)
Output:
{'name': 'Brajkant', 'course': 'PGDCA', 'age': 23}

Accessing Values

student = {
    "name": "Brajkant",
    "course": "PGDCA",
    "age": 23
}

print(student["name"])
print(student.get("course"))
Output:
Brajkant
PGDCA

Changing Values

student = {
    "name": "Brajkant",
    "course": "PGDCA",
    "age": 23
}

student["age"] = 24

print(student)
Output:
{'name': 'Brajkant', 'course': 'PGDCA', 'age': 24}

Adding New Item

student = {
    "name": "Brajkant",
    "course": "PGDCA"
}

student["city"] = "Kanpur"

print(student)
Output:
{'name': 'Brajkant', 'course': 'PGDCA', 'city': 'Kanpur'}

Removing Items

Method Use
pop() Specified key-value pair remove करता है।
popitem() Last inserted item remove करता है।
clear() Dictionary के सभी items remove करता है।

    "name": "Brajkant",
    "course": "PGDCA",
    "age": 23
}

print(student)
Output:

Important Dictionary Methods

Method Use
keys() सभी keys return करता है।
values() सभी values return करता है।

Real Life Example:
Student record, employee details, product information और marksheet data dictionary में store करना बहुत useful होता है क्योंकि हर value को meaningful key से access किया जा सकता है।
Remember:
Dictionary key-value pair पर based होती है। Keys unique होती हैं, लेकिन values repeat हो सकती हैं।

Sorting Dictionaries

Dictionary को sort करने का मतलब dictionary के keys या values के basis पर data को arranged order में show करना होता है। Dictionary में data key-value pair के रूप में stored रहता है, इसलिए sorting normally keys या values पर की जाती है।

Python में dictionary को sort करने के लिए commonly sorted() function का use किया जाता है। Sorting original dictionary को directly change नहीं करती, बल्कि sorted result return करती है। जरूरत के अनुसार हम sorted result से new dictionary बना सकते हैं।

Sorting by Keys

marks = {
    "Ravi": 78,
    "Amit": 92,
    "Neha": 85
}

for key in sorted(marks):
    print(key, ":", marks[key])
Output:
Amit : 92
Neha : 85
Ravi : 78

Creating New Dictionary Sorted by Keys

marks = {
    "Ravi": 78,
    "Amit": 92,
    "Neha": 85
}

sorted_marks = dict(sorted(marks.items()))

print(sorted_marks)
Output:
{'Amit': 92, 'Neha': 85, 'Ravi': 78}

Sorting by Values

Values के basis पर sorting करने के लिए lambda function का use किया जा सकता है।

marks = {
    "Ravi": 78,
    "Amit": 92,
    "Neha": 85
}

sorted_marks = dict(sorted(marks.items(), key=lambda item: item[1]))

print(sorted_marks)
Output:
{'Ravi': 78, 'Neha': 85, 'Amit': 92}

Descending Order Sorting

marks = {
    "Ravi": 78,
    "Amit": 92,
    "Neha": 85
}

sorted_marks = dict(sorted(marks.items(), key=lambda item: item[1], reverse=True))

print(sorted_marks)
Output:
{'Amit': 92, 'Neha': 85, 'Ravi': 78}

Important Points

  • sorted() function sorting के लिए use होता है।
  • Dictionary को keys या values दोनों के basis पर sort किया जा सकता है।
  • items() key-value pair return करता है।
  • lambda item: item[1] value के basis पर sorting करता है।
  • reverse=True descending order के लिए use होता है।
Real Life Example:
Marks dictionary को values के basis पर sort करके toppers की list निकाली जा सकती है।
Remember:
Dictionary sorting में सबसे important बात यह है कि sorting key पर करनी है या value पर, यह पहले decide करना पड़ता है।

Copying Collections

Python में collections को copy करना important concept है। कई बार हमें existing collection का duplicate बनाकर उस पर काम करना होता है, ताकि original collection change न हो। लेकिन Python में assignment operator = use करने पर actual copy नहीं बनती, बल्कि दोनों variables same collection को refer करने लगते हैं।

इसलिए collections की proper copy बनाने के लिए copy(), constructor functions जैसे list(), dict(), set(), और sometimes slicing का use किया जाता है।

Assignment Is Not Real Copy

a = [10, 20, 30]
b = a

b.append(40)

print(a)
print(b)
Output:
[10, 20, 30, 40]
[10, 20, 30, 40]

ऊपर वाले example में b = a से new list नहीं बनी। दोनों variables same list को point कर रहे हैं, इसलिए b में change करने पर a भी changed दिख रही है।

Copying List Using copy()

a = [10, 20, 30]
b = a.copy()

b.append(40)

print(a)
print(b)
Output:
[10, 20, 30]
[10, 20, 30, 40]

Copying List Using Slicing

a = [10, 20, 30]
b = a[:]

b.remove(20)

print(a)
print(b)
Output:
[10, 20, 30]
[10, 30]

Copying Dictionary

student = {
    "name": "Brajkant",
    "course": "PGDCA"
}

new_student = student.copy()
new_student["city"] = "Kanpur"

print(student)
print(new_student)
Output:
{'name': 'Brajkant', 'course': 'PGDCA'}
{'name': 'Brajkant', 'course': 'PGDCA', 'city': 'Kanpur'}

Copying Set

a = {10, 20, 30}
b = a.copy()

b.add(40)

print(a)
print(b)
Output:
{10, 20, 30}
{40, 10, 20, 30}

Shallow Copy and Deep Copy

Normal copy() method shallow copy बनाता है। अगर collection के अंदर nested collection है, तो shallow copy inner collection को अलग से fully copy नहीं करती। Deep copy के लिए Python के copy module का deepcopy() function use किया जाता है।

import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)

b[0][0] = 100

print(a)
print(b)
Output:
[[1, 2], [3, 4]]
[[100, 2], [3, 4]]

Copying Methods Table

Collection Copy Method Example
List copy(), slicing, list() b = a.copy()
Tuple Normally copy needed नहीं होती क्योंकि tuple immutable है। b = tuple(a)
Set copy(), set() b = a.copy()
Dictionary copy(), dict() b = a.copy()
Real Life Example:
अगर original marks list safe रखनी है और duplicate list में grace marks add करके testing करनी है, तो copy बनाकर काम करना सही रहेगा।
Remember:
= operator real copy नहीं बनाता। Proper copy के लिए copy() या suitable constructor use करना चाहिए।

Summary

Python collections multiple values को एक single variable में store करने के लिए use होते हैं। Collection data को organize और manage करने का powerful तरीका provide करते हैं। Python में main collection types List, Tuple, Set और Dictionary हैं।

List ordered, changeable और duplicate values allow करने वाली collection है। Tuple ordered और duplicate values allow करती है, लेकिन changeable नहीं होती। Set unordered होता है और duplicate values remove कर देता है। Dictionary key-value pairs के रूप में data store करती है और keys unique होती हैं।

Dictionary को keys या values के basis पर sort किया जा सकता है। Collections को copy करते समय assignment operator = और actual copy में difference समझना जरूरी है। Proper copy बनाने के लिए copy(), slicing, constructor functions और nested data के लिए deepcopy() use किया जा सकता है।

Collection Best Use
List जब data change करना हो और order important हो।
Tuple जब data fixed रखना हो।
Set जब unique values store करनी हों।
Dictionary जब data key-value pair में store करना हो।
Remember Points:
List = ordered + changeable.
Tuple = ordered + unchangeable.
Set = unordered + unique values.
Dictionary = key-value pairs.
= copy नहीं, reference बनाता है।
