Language Components

Indenting Requirements

Python में indentation language का बहुत important rule है। Indentation का मतलब line की शुरुआत में खाली space देना होता है। दूसरी languages जैसे C, C++ और Java में code blocks को दिखाने के लिए curly braces { } का use किया जाता है, लेकिन Python में code block indentation से बनता है। इसी वजह से Python code clean, readable और structured दिखाई देता है।

जब हम if, else, for, while, function या class जैसे statements लिखते हैं, तो इनके अंदर आने वाले statements को left side से थोड़ा अंदर लिखना पड़ता है। Python interpreter indentation देखकर समझता है कि कौन-सा statement किस block के अंदर belong करता है। इसलिए Python में indentation केवल formatting नहीं है, बल्कि syntax का compulsory part है।

Python में आमतौर पर एक block के लिए 4 spaces use किए जाते हैं। अगर एक ही block के statements अलग-अलग indentation पर लिखे जाएँ, तो program में error आ सकता है। इसलिए same block के सभी statements को same level पर indent करना चाहिए।

Correct Indentation

if 10 > 5:
    print("10 is greater than 5")
    print("This line is inside if block")

print("This line is outside if block")
Output:
10 is greater than 5
This line is inside if block
This line is outside if block

Wrong Indentation

if 10 > 5:
print("10 is greater than 5")
Output:
IndentationError: expected an indented block

How Python Reads Indentation

जब Python को colon : मिलता है, तो वह expect करता है कि अगली line indented होगी। अगर अगली line indentation के बिना लिख दी गई, तो Python समझ नहीं पाएगा कि block कहाँ शुरू हो रहा है। इसी कारण indentation error आता है।

Important Rules

  • Same block के सभी statements की indentation same होनी चाहिए।
  • Generally 4 spaces use करना best practice माना जाता है।
  • Tabs और spaces को mix करने से avoid करना चाहिए।
  • Indentation code को readable और professional बनाता है।
  • Colon : के बाद usually indented block आता है।

Common Mistakes

  • Colon : लगाने के बाद next line indent न करना।
  • एक ही block में कभी 2 spaces और कभी 4 spaces use करना।
  • Tabs और spaces को एक साथ mix करना।
  • Outer block और inner block को same indentation पर लिख देना।
Real Life Example:
जैसे notebook में main heading के अंदर sub-points थोड़ा अंदर से लिखे जाते हैं ताकि structure clear रहे, वैसे ही Python में block के अंदर statements indentation से लिखे जाते हैं।
Remember:
Python में indentation styling नहीं, syntax का part है। गलत indentation से program run नहीं होगा।

The if Statement

if statement Python में decision making के लिए use होता है। Program में कई बार ऐसी situation आती है जहाँ हमें condition के आधार पर decide करना पड़ता है कि कौन-सा code execute होगा। ऐसी condition-based execution के लिए if, if-else, if-elif-else और nested if statements use किए जाते हैं।

if statement में condition check होती है। अगर condition true होती है, तो if block के अंदर लिखा code execute होता है। अगर condition false होती है, तो if block skip हो जाता है। यह concept real life decision जैसा होता है, जैसे “अगर marks 33 या उससे अधिक हैं तो student pass है, नहीं तो fail है।”

Basic Syntax

if condition:
    statement_1
    statement_2

Simple if Example

age = 18

if age >= 18:
    print("You are eligible to vote")
Output:
You are eligible to vote

Working Process

  1. सबसे पहले condition evaluate होती है।
  2. अगर condition True है, तो indented block execute होता है।
  3. अगर condition False है, तो block skip हो जाता है।
  4. Block complete होने के बाद control next statement पर चला जाता है।

if-else Statement

जब condition true होने पर एक block और false होने पर दूसरा block execute करना हो, तब if-else statement use किया जाता है।

marks = 35

if marks >= 33:
    print("Pass")
else:
    print("Fail")
Output:
Pass

if-elif-else Statement

जब program में multiple conditions check करनी हों, तब elif का use किया जाता है। Python conditions को top to bottom check करता है। जो condition सबसे पहले true होती है, उसका block execute हो जाता है और बाकी conditions skip हो जाती हैं।

marks = 75

if marks >= 90:
    print("Grade A+")
elif marks >= 75:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
else:
    print("Grade C")
Output:
Grade A

Nested if

जब एक if statement के अंदर दूसरा if statement लिखा जाता है, तो उसे nested if कहा जाता है। इसका use तब होता है जब एक condition true होने के बाद दूसरी condition check करनी हो।

username = "admin"
password = "1234"

if username == "admin":
    if password == "1234":
        print("Login Successful")
    else:
        print("Wrong Password")
else:
    print("Wrong Username")
Output:
Login Successful

Common Mistakes

  • if condition के बाद colon : लगाना भूल जाना।
  • = और == में confusion करना।
  • if block के statements को indent न करना।
  • Multiple conditions में wrong order रखना।
Real Life Example:
Login system में पहले username check होता है, फिर password check होता है। यह nested if का practical example है।
Remember:
if statement program को intelligent बनाता है क्योंकि program condition के हिसाब से decision ले सकता है।

Relational and Logical Operators

Relational operators और logical operators decision making में बहुत important role निभाते हैं। Relational operators दो values को compare करते हैं और result में True या False देते हैं। Logical operators multiple conditions को combine करके final result decide करते हैं।

जब भी हम if, while या किसी condition-based statement का use करते हैं, तब relational और logical operators बहुत काम आते हैं। जैसे age compare करना, marks check करना, username-password validate करना, या किसी range में value check करना।

Bit Wise Operators

Bitwise operators integer values पर binary level operation perform करते हैं। Computer internally numbers को binary form यानी 0 और 1 में store करता है। Bitwise operators इन्हीं bits पर work करते हैं। ये operators normal arithmetic operators जैसे +, -, * से अलग होते हैं क्योंकि ये number की actual value पर नहीं बल्कि उसके binary representation पर काम करते हैं।

Bitwise operators का use low-level programming, embedded systems, networking, file permissions, flags और performance-based operations में किया जाता है। Beginners के लिए ये topic थोड़ा advanced लग सकता है, लेकिन exam point of view से इसके operators और basic examples समझना जरूरी है।

Binary Concept

Decimal number 5 को binary में 101 लिखा जाता है और decimal number 3 को binary में 011 लिखा जाता है। Bitwise operators इन bits को position-wise compare करते हैं।

~ Bitwise NOT Bits को invert करता है।

Shift Operators

Left shift operator bits को left side shift करता है। यह generally number को 2 से multiply करने जैसा effect देता है। Right shift operator bits को right side shift करता है। यह generally number को 2 से divide करने जैसा effect देता है।

x = 4

print(x << 1)
print(x >> 1)

Common Mistakes

  • Binary values को समझे बिना output याद करने की कोशिश करना।
  • ^ को power operator समझना, जबकि Python में power के लिए ** use होता है।
Real Life Example:
Networking में subnet masks, hardware programming में pins और permission systems में flags को handle करने के लिए bitwise operators useful होते हैं।
Remember:
Bitwise operators binary bits पर काम करते हैं। इन्हें समझने के लिए decimal to binary conversion की basic knowledge helpful होती है।

The while Loop

while loop का use किसी block of code को बार-बार execute करने के लिए किया जाता है। यह loop तब तक चलता है जब तक दी गई condition true रहती है। जैसे ही condition false होती है, loop terminate हो जाता है। while loop condition-based loop होता है, इसलिए इसका use वहाँ ज्यादा होता है जहाँ पहले से पता न हो कि loop कितनी बार चलेगा।

while loop में तीन main parts होते हैं: initialization, condition और update. Initialization में variable की starting value दी जाती है। Condition decide करती है कि loop चलेगा या नहीं। Update statement variable की value change करती है ताकि loop eventually stop हो सके।

Basic Syntax

while condition:
    statements

Simple Example

i = 1

while i <= 5:
    print(i)
    i = i + 1
Output:
1
2
3
4
5

Working Process

  1. सबसे पहले variable initialize होता है।
  2. while condition check होती है।
  3. अगर condition true है तो loop body execute होती है।
  4. Update statement variable की value change करती है।
  5. Control वापस condition पर जाता है।
  6. Condition false होते ही loop stop हो जाता है।

Sum of First Five Numbers

i = 1
total = 0

while i <= 5:
    total = total + i
    i = i + 1

print("Sum =", total)
Output:
Sum = 15

Counting Even Numbers

while i <= 10:
    print(i)
    i = i + 2

while Loop with else

Python में while loop के साथ else block भी use किया जा सकता है। अगर loop normally complete होता है, तो else block execute होता है।

i = 1

i = 1

Common Mistakes

  • Update statement लिखना भूल जाना।
  • Wrong condition लिखना जिससे loop कभी run ही न हो।
  • Condition हमेशा true बना देना।
  • Loop variable को गलत direction में update करना।
Real Life Example:
ATM PIN entry system में user सही PIN enter करे तब तक input लेना while loop का practical example हो सकता है।
Remember:
while loop तब useful है जब repetition condition पर depend करे और iterations की exact संख्या पहले से fixed न हो।

break and continue

break और continue loop control statements हैं। Loop normally अपनी condition या sequence के हिसाब से चलता है, लेकिन कई बार हमें loop के flow को manually control करना पड़ता है। ऐसी situation में break और continue का use किया जाता है।

break loop को पूरी तरह terminate करता है, जबकि continue current iteration को skip करके loop की next iteration पर control भेज देता है। दोनों statements while और for loop में use हो सकते हैं।

break Statement

break statement जैसे ही execute होता है, loop तुरंत stop हो जाता है और control loop के बाहर चला जाता है। इसका use तब किया जाता है जब required value मिल जाए या किसी special condition पर loop को आगे नहीं चलाना हो।

for i in range(1, 6):
    if i == 4:
        break
    print(i)
Output:
1
2
3

break with while Loop

i = 1

    if i == 5:
        break
    print(i)
    i = i + 1

4

continue Statement

continue statement current iteration के बाकी code को skip कर देता है और loop को next iteration पर भेज देता है। इसका use तब किया जाता है जब किसी particular value को ignore करना हो।

for i in range(1, 6):
    if i == 3:
        continue
    print(i)
Output:
1
2
4
5

continue with while Loop

i = 0

while i < 5:
    i = i + 1
    if i == 3:
        continue
    print(i)
Output:
1
2
4
5

Difference Between break and continue

Basis break continue
Work Loop को पूरी तरह stop करता है। Only current iteration skip करता है।
Control Loop के बाहर चला जाता है। Loop की next iteration पर जाता है।
Use Search complete होने पर loop stop करना। Unwanted value को skip करना।
Effect Remaining iterations execute नहीं होतीं। Remaining iterations continue होती हैं।

students = ["Amit", "Ravi", "Brajkant", "Neha"]

for student in students:
    if student == "Brajkant":
        print("Student Found")
        break
Output:
Student Found

Skip Example using continue

numbers = [1, 2, 3, 4, 5]

for num in numbers:
    if num == 3:
        continue
    print(num)
Output:
1
2
4
5
Real Life Example:
अगर list में कोई required student मिल गया, तो break से search stop कर सकते हैं। अगर किसी invalid entry को ignore करना हो, तो continue use कर सकते हैं।
Remember:
break loop को खत्म करता है, लेकिन continue loop को खत्म नहीं करता; वह केवल current round skip करता है।

The for Loop

for loop Python में sequence-based iteration के लिए use होता है। Sequence का मतलब ऐसी collection जिससे एक-एक item निकाला जा सके, जैसे string, list, tuple, dictionary या range. for loop sequence के हर item पर एक बार code execute करता है।

जब हमें पता हो कि loop कितनी बार चलाना है, या हमें किसी collection के सभी items पर काम करना है, तब for loop सबसे useful होता है। Python का for loop C/C++ के traditional for loop से थोड़ा अलग होता है, क्योंकि Python में for loop index-based से ज्यादा item-based होता है।

Basic Syntax

for variable in sequence:
    statements

Using range()

range() function numbers की sequence generate करता है। यह for loop के साथ बहुत commonly use होता है। range(1, 6) numbers 1 से 5 तक generate करता है, यानी stop value include नहीं होती।

for i in range(1, 6):
    print(i)
Output:
1
2
3
4
5

range() Forms

Form Meaning Example
range(stop) 0 से stop-1 तक numbers देता है। range(5) → 0,1,2,3,4
range(start, stop) start से stop-1 तक numbers देता है। range(1, 5) → 1,2,3,4
range(start, stop, step) step के according numbers generate करता है। range(2, 11, 2) → 2,4,6,8,10

for Loop with else

Python में for loop के साथ else block भी use हो सकता है। अगर loop normally complete होता है और break से stop नहीं होता, तो else block execute होता है।

    print(i)

    print("Loop completed")

2
3
Loop completed

Nested for Loop

जब एक for loop के अंदर दूसरा for loop लिखा जाता है, तो उसे nested for loop कहते हैं। इसका use pattern printing, table generation और matrix operations में किया जाता है।

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

while Loop vs for Loop

Basis while Loop for Loop
Use Condition-based repetition के लिए। Sequence-based repetition के लिए।
Iterations जब exact count पहले से clear न हो। जब sequence या range available हो।
Update Manual update required होती है। Sequence से item automatically मिलता है।
Example PIN correct होने तक input लेना। List के सभी names print करना।

Common Mistakes

  • range() की stop value को include समझ लेना।
  • for loop के अंदर statements को indent न करना।
  • Nested loop में inner और outer loop का flow confuse करना।
  • Sequence के item और index में difference न समझना।
Real Life Example:
Students की list में हर student का name print करना, marks list का total निकालना और multiplication table generate करना for loop के common examples हैं।
Remember:
while loop condition based होता है, जबकि for loop mostly sequence या fixed repetition के लिए use होता है।
