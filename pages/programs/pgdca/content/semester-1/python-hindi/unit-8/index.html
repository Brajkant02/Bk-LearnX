Input and Output in Python

इस chapter में Python input-output, data streams, file handling, access modes, pipes और IO exceptions को exam-oriented Hindi-English style में समझाया गया है।

Introduction

Input और Output programming के बहुत basic लेकिन important concepts हैं। Input का मतलब user, file, keyboard, network या किसी external source से data लेना होता है। Output का मतलब processed data को screen, file, printer, console या किसी other destination पर send करना होता है। हर useful program किसी न किसी form में input लेता है, उस data को process करता है और फिर output देता है।

Python में simple input के लिए input() function और output के लिए print() function commonly use होते हैं। लेकिन जब data को permanent रूप से store करना हो, तो files का use किया जाता है। File handling की help से Python program text files, binary files और other data files को read और write कर सकता है।

Input-output operations real applications में बहुत important होते हैं। जैसे student record save करना, result file बनाना, log file maintain करना, report generate करना, user data read करना और program output को file में store करना आदि।

Simple Input Example

name = input("Enter your name: ")

print("Hello", name)
Output:
Enter your name: Brajkant
Hello Brajkant

Simple Output Example

course = "PGDCA"

print("Course:", course)
Output:
Course: PGDCA

File Output Example

file = open("student.txt", "w")
file.write("Name: Brajkant")
file.close()

इस program से current folder में student.txt file create होगी और उसमें data write हो जाएगा।

Why File Handling is Needed

  • Data को permanently store करने के लिए।
  • Program output को future use के लिए save करने के लिए।
  • Large data को file से read करके process करने के लिए।
  • Reports, logs और records create करने के लिए।
  • External files के साथ communication करने के लिए।
Real Life Example:
College management software में student names, roll numbers और marks को file में save किया जा सकता है ताकि program बंद होने के बाद भी data available रहे।
Remember:
Input data को program में लाता है, output processed data को बाहर दिखाता या store करता है।

Data Streams

Data stream का मतलब data का continuous flow होता है। जब data एक source से दूसरे destination तक move करता है, तो उसे stream के रूप में समझा जा सकता है। Python में input और output operations streams के through perform होते हैं। Stream data को एक continuous sequence की तरह handle करता है।

Computer programming में stream एक abstract concept है। Programmer को यह जरूरी नहीं कि data exactly hardware level पर कैसे move हो रहा है। वह stream object की help से read और write operations perform करता है। Data keyboard से program में आए, file से read हो या network से आए, conceptually वह stream के form में process हो सकता है।

Types of Data Streams

Stream Type Meaning Example
Input Stream Program में data आने का flow। Keyboard input, file reading
Output Stream Program से data बाहर जाने का flow। Screen output, file writing
Error Stream Error messages का output flow। Exception message, error log

Standard Streams in Python

Python में standard streams sys module के through available होती हैं। ये streams command line और console based input-output से connected होती हैं।

Stream Use
sys.stdin Standard input stream, usually keyboard से input लेती है।
sys.stdout Standard output stream, usually screen पर output show करती है।
sys.stderr Standard error stream, error messages show करने के लिए।

Using sys.stdin

import sys

print("Enter your name:")
name = sys.stdin.readline()

print("Hello", name)
Output:
User input के according output show होगा।

Using sys.stdout

import sys

sys.stdout.write("Welcome to Python")
Output:
Welcome to Python

Using sys.stderr

import sys

sys.stderr.write("This is an error message")
Output:
Error stream पर message show होगा।

Text Stream and Binary Stream

Text stream human-readable characters को handle करती है, जैसे text file में names, sentences और numbers as text. Binary stream raw bytes को handle करती है, जैसे images, audio files, video files और executable files।

Basis Text Stream Binary Stream
Data Form Characters/string Bytes
Mode r, w, a rb, wb, ab
Example .txt, .csv .jpg, .png, .mp3
Real Life Example:
जब आप keyboard से name type करते हैं, तो data input stream के through program तक जाता है। जब program result screen पर दिखाता है, तो output stream use होती है।
Remember:
Stream data flow को represent करती है। File, keyboard और console सभी stream concept से जुड़े हो सकते हैं।

Creating Your Own Data Streams

Python में हम अपनी data streams create कर सकते हैं। इसका मतलब है कि हम file objects या memory-based stream objects create करके उनके through data read/write कर सकते हैं। जब हम open() function से file open करते हैं, तो Python file object return करता है। यह file object stream की तरह behave करता है।

कई बार हमें actual file की जगह memory में ही data stream बनानी होती है। इसके लिए Python में io module helpful होता है। io.StringIO text data के लिए memory stream बनाता है और io.BytesIO binary data के लिए memory stream बनाता है।

File as Data Stream

file = open("message.txt", "w")

file.write("Hello Python")

file.close()

यहाँ file एक file stream object है जिसके through data file में write किया जा रहा है।

Reading From File Stream

file = open("message.txt", "r")

data = file.read()

print(data)

file.close()
Output:
Hello Python

Using with Statement

with statement file handling का safer तरीका है। इसमें file automatically close हो जाती है, इसलिए programmer को manually close() call करना जरूरी नहीं रहता।

with open("message.txt", "w") as file:
    file.write("Learning file handling")

Creating Memory Stream with StringIO

StringIO memory में text stream create करता है। यह actual disk file create नहीं करता, बल्कि RAM में file-like object बनाता है।

from io import StringIO

stream = StringIO()

stream.write("Hello")
stream.write(" Python")

print(stream.getvalue())
Output:
Hello Python

Reading from StringIO Stream

from io import StringIO

stream = StringIO("python/njava/nc")

print(stream.readline())
print(stream.readline())
Output:
Python
Java

Creating Binary Stream with BytesIO

from io import BytesIO

stream = BytesIO()

stream.write(b"Hello Bytes")

print(stream.getvalue())
Output:
b'Hello Bytes'

Testing में actual file create किए बिना memory stream से file-like operations test किए जा सकते हैं।

Access Modes

Access mode यह बताता है कि file को किस purpose के लिए open किया जा रहा है। File को read करने के लिए अलग mode, write करने के लिए अलग mode और append करने के लिए अलग mode use होता है। Python में open() function file name और mode accept करता है।

अगर mode properly choose नहीं किया गया, तो file का data overwrite हो सकता है या file access error आ सकता है। इसलिए file handling में access modes समझना बहुत जरूरी है।

Basic Syntax

file = open("filename", "mode")

Common Access Modes

Mode Meaning Use
r Read mode Existing file को read करने के लिए। File न हो तो error।
w Write mode File में write करने के लिए। Existing data overwrite हो जाता है।
a Append mode File के end में data add करने के लिए।
x Exclusive creation New file create करता है। File already हो तो error।
r+ Read and write File read और write दोनों के लिए।
w+ Write and read File write और read दोनों के लिए, existing data clear हो जाता है।
a+ Append and read File read और append दोनों के लिए।

Read Mode

file = open("student.txt", "r")
data = file.read()
print(data)
file.close()

Write Mode

file = open("student.txt", "w")
file.write("Name: Brajkant")
file.close()

w mode existing file का old data remove करके new data write करता है।

Append Mode

file = open("student.txt", "a")
file.write("/ncourse-pgdca")
file.close()

a mode file के end में new data add करता है। Old data remove नहीं होता।

Binary Modes

Binary files के लिए mode में b add किया जाता है। जैसे rb read binary, wb write binary और ab append binary।

file = open("image.jpg", "rb")
data = file.read()
file.close()

Mode Selection Table

Requirement Mode
File read करनी है r
New data write करना है और old data हटाना है w
Existing file के end में data add करना है a
Only new file create करनी है x
Binary file read करनी है rb

Common Mistakes

  • w mode use करके accidentally old data overwrite कर देना।
  • Non-existing file को r mode में open करना।
  • Text file और binary file modes में confusion करना।
  • File close करना भूल जाना।
Remember:
w mode old data overwrite करता है, जबकि a mode file के end में data add करता है।

Writing Data to a File

Python में file में data write करने के लिए file को write mode w, append mode a या related modes में open किया जाता है। File write operation का use data को permanent रूप से store करने के लिए किया जाता है।

जब file w mode में open होती है, तो अगर file already exist करती है, उसका old data clear हो जाता है। अगर file exist नहीं करती, तो Python नई file create कर देता है। Append mode में old data safe रहता है और new data end में add होता है।

Using write()

file = open("student.txt", "w")

file.write("Name: Brajkant")
file.write("/ncourse-pgdca")

file.close()

इस code से student.txt file में data write होगा।

Reading Written File

file = open("student.txt", "r")

print(file.read())

file.close()
Output:
Name: Brajkant
Course: PGDCA

Using writelines()

writelines() method list of strings को file में write करने के लिए use होता है। यह automatically new line add नहीं करता, इसलिए \n manually देना पड़ता है।

lines = ["python/n", "dccn/n", "bcit/n"]

file = open("subjects.txt", "w")

file.writelines(lines)

file.close()

Writing with with Statement

with open("student.txt", "w") as file:
    file.write("name-brajkant/n")
    file.write("course-pgdca/n")
    file.write("Learning: Python File Handling")

with statement file को automatically close कर देता है। यह safer और professional approach मानी जाती है।

Appending Data

with open("student.txt", "a") as file:
    file.write("/ncity-kanpur")

Writing Numbers to File

File में data write करते समय data string format में होना चाहिए। अगर number write करना हो, तो उसे str() से string में convert करना पड़ता है।

marks = 85

with open("marks.txt", "w") as file:
    file.write("Marks: " + str(marks))

write() vs writelines()

Method Use

writelines() List of strings write करने के लिए।

Common Mistakes

  • Number को string में convert किए बिना write करना।
  • w mode use करके old data overwrite कर देना।
  • writelines() में new line character लगाना भूल जाना।
  • File close करना भूल जाना।
Real Life Example:
Student admission form का data file में write करके record save किया जा सकता है।
Remember:
File में write करने के लिए data generally string form में होना चाहिए।

Reading Data From a File

Python में file से data read करने के लिए file को read mode r में open किया जाता है। Reading operation का use stored data को program में वापस लाने के लिए किया जाता है। Program file से data read करके उसे process, display या analyze कर सकता है।

File reading के लिए Python कई methods provide करता है जैसे read(), readline() और readlines(). हर method का use अलग situation में किया जाता है।

Using read()

read() method पूरी file का content एक string के रूप में read करता है।

file = open("student.txt", "r")

data = file.read()

print(data)

file.close()
Output:
File का पूरा content show होगा।

Using readline()

readline() method file से एक line read करता है। बार-बार call करने पर next line read होती है।

file = open("student.txt", "r")

print(file.readline())
print(file.readline())

file.close()
Output:
File की पहली और दूसरी line show होगी।

Using readlines()

readlines() method file की सभी lines को list के रूप में return करता है।

file = open("student.txt", "r")

lines = file.readlines()

print(lines)

file.close()
Output:
['name-brajkant/n', 'course-pgdca/n'] जैसे output आ सकता है।

Reading File Using Loop

with open("student.txt", "r") as file:
    for line in file:
        print(line)
Output:
File की lines एक-एक करके print होंगी।

Reading Limited Characters

with open("student.txt", "r") as file:
    data = file.read(10)
    print(data)
Output:
File के first 10 characters show होंगे।

read(), readline(), readlines()

Method Return Use
read() String पूरी file या fixed characters read करने के लिए।
readline() String एक line read करने के लिए।
readlines() List सभी lines को list में read करने के लिए।

Common Mistakes

  • File exist न होने पर read mode में open करना।
  • File read करने के बाद pointer end पर होने के कारण दोबारा read करने पर empty output मिलना।
  • Large file को एक साथ read() से memory में load कर लेना।
  • File close करना भूल जाना।
Real Life Example:
Marks file से students के marks read करके total और percentage calculate की जा सकती है।
Remember:
Large files को line by line read करना better होता है।

Additional File Methods

Python file objects में read और write के अलावा भी कई useful methods और properties होती हैं। ये methods file pointer control करने, file status check करने, file close करने और file position manage करने में help करती हैं।

File handling में file pointer एक important concept है। जब file read या write होती है, तो Python internally pointer maintain करता है कि next operation किस position से होगा। tell() और seek() methods इसी pointer को manage करते हैं।

close()

close() method opened file को close करता है। File close करना important है क्योंकि इससे system resources release होते हैं।

file = open("student.txt", "r")
data = file.read()
file.close()

closed Property

closed property यह बताती है कि file close है या नहीं।

file = open("student.txt", "r")

print(file.closed)

file.close()

print(file.closed)
Output:
False
True

tell()

tell() method current file pointer position return करता है।

with open("student.txt", "r") as file:
    print(file.tell())
    file.read(5)
    print(file.tell())
Output:
0
5

seek()

seek() method file pointer को specified position पर move करता है।

with open("student.txt", "r") as file:
    print(file.read(5))
    file.seek(0)
    print(file.read(5))
Output:
पहले 5 characters
फिर वही पहले 5 characters

flush()

flush() method buffered data को तुरंत file में write करने के लिए use होता है। Normally Python automatically buffer manage करता है, लेकिन कुछ cases में manual flush useful हो सकता है।

file = open("data.txt", "w")

file.write("Hello")
file.flush()

file.close()

File Object Properties

Property / Method Use
file.name File का name return करता है।
file.mode File का access mode return करता है।
file.closed File close है या नहीं बताता है।
file.tell() Current pointer position बताता है।
file.seek() Pointer को specific position पर move करता है।
file.flush() Buffered data को file में forcefully write करता है।

File Name and Mode Example

file = open("student.txt", "r")

print(file.name)
print(file.mode)

file.close()
Output:
student.txt
r
Real Life Example:
अगर file पढ़ते समय pointer end पर चला गया है और हमें फिर से शुरुआत से read करना है, तो seek(0) use किया जा सकता है।
Remember:
tell() current position बताता है और seek() position change करता है।

Using Pipes as Data Streams

Pipe एक mechanism है जिसके through एक program का output दूसरे program के input के रूप में use किया जा सकता है। Operating systems में pipes command line पर बहुत common हैं। Pipe data को stream के form में transfer करता है, इसलिए इसे data stream की तरह समझा जा सकता है।

Python में pipes का use external commands के साथ communication करने, command output read करने और process input/output handle करने के लिए किया जा सकता है। इसके लिए commonly subprocess module use किया जाता है। Older Python में os.popen() भी use होता था, लेकिन modern programs में subprocess ज्यादा recommended है।

Command Line Pipe Concept

command1 | command2

यहाँ command1 का output command2 के input के रूप में जाता है।

Using subprocess to Read Command Output

import subprocess

result = subprocess.run(
    ["echo", "Hello Python"],
    capture_output=True,
    text=True
)

print(result.stdout)
Output:
Hello Python

Using Pipe with subprocess.Popen

import subprocess

process = subprocess.Popen(
    ["echo", "Learning Pipes"],
    stdout=subprocess.PIPE,
    text=True
)

output, error = process.communicate()

print(output)
Output:
Learning Pipes
