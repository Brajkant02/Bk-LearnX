Introduction to Python

Introduction

Python Programming Language

Python एक high-level, interpreted, general-purpose और beginner-friendly programming language है। इसका syntax simple और readable होता है, इसलिए नए students इसे आसानी से सीख सकते हैं। Python का use web development, data analysis, artificial intelligence, machine learning, automation, software development, scripting, cyber security, game development और scientific computing जैसे कई areas में किया जाता है।

Python को ऐसा design किया गया है कि programmer complex logic को कम code में लिख सके। इसमें indentation का use block define करने के लिए होता है, जिससे code clean और readable दिखता है। Python में large standard library और बहुत सारे third-party packages available हैं।

Important Features of Python

  • Simple Syntax: Python का code English-like और readable होता है।
  • Interpreted Language: Python code line-by-line execute होता है।
  • High-Level Language: Programmer को low-level memory details manage नहीं करनी पड़ती।
  • Portable: Python programs Windows, Linux और macOS पर run हो सकते हैं।
  • Large Library: Python में many built-in modules और external packages मिलते हैं।
  • Dynamically Typed: Variable का type runtime पर decide होता है।
Real Life Example:
अगर आपको Excel files को automatically process करना है, website बनानी है या data analysis करना है, तो Python इन सभी कामों के लिए useful language है।

Brief History of Python

Python को Guido van Rossum ने late 1980s में design करना शुरू किया और इसका first public release 1991 में आया। Python का goal ऐसी programming language बनाना था जो simple, readable और powerful हो। Python का name snake से नहीं, बल्कि British comedy group Monty Python से inspired है।

Python ने शुरुआत से ही readability और simplicity पर focus किया। इसकी philosophy यह है कि code ऐसा होना चाहिए जिसे दूसरे programmers आसानी से read और understand कर सकें। समय के साथ Python बहुत popular language बन गई क्योंकि इसे beginners भी सीख सकते हैं और professionals भी बड़े projects में use कर सकते हैं।

Real Life Example:
Python आज school/college programming से लेकर Google, NASA, Netflix और AI research तक अलग-अलग areas में use होता है।

Python Versions

Python के अलग-अलग versions समय के साथ release हुए हैं। Python के दो major version families बहुत important हैं: Python 2 और Python 3। Python 2 पुराने projects में use होता था, लेकिन अब उसका official support खत्म हो चुका है। Python 3 current और recommended version है। नए students और developers को Python 3 ही सीखना और use करना चाहिए।

Python 3 में कई improvements किए गए, जैसे better Unicode support, cleaner syntax, improved libraries और more consistent behavior। Python 2 और Python 3 पूरी तरह compatible नहीं हैं।

Python 2 vs Python 3

Basis Python 2 Python 3

Remember:
New learning और new projects के लिए हमेशा Python 3 use करना चाहिए।

Installing Python

Installing Python का मतलब computer में Python interpreter और related tools install करना है, ताकि user Python programs लिख और run कर सके। Python install करने के बाद system में Python command available हो जाती है। Windows, Linux और macOS पर Python install किया जा सकता है।

Installing Python on Windows

  1. Official Python website से latest Python 3 installer download करें।
  2. Installer open करें।
  3. Add Python to PATH option tick करें।
  4. Install Now पर click करें।
  5. Installation complete होने के बाद Command Prompt open करें।
  6. python --version या py --version command run करके version check करें।

Installing Python on Linux

Linux में कई distributions में Python पहले से installed होता है। Version check करने के लिए terminal में command run कर सकते हैं:

python3 --version

Installing Python on macOS

macOS में Python installer official website से download किया जा सकता है या Homebrew जैसे package manager से install किया जा सकता है।

Real Life Example:
अगर आप VS Code में Python program run करना चाहते हैं, तो पहले system में Python install होना चाहिए।

Environment Variables

Environment Variables

Environment Variables operating system की ऐसी settings होती हैं जो programs को system paths, configuration values और runtime information provide करती हैं। Python के context में सबसे important environment variable PATH होता है। PATH system को बताता है कि executable programs कहाँ search करने हैं।

अगर Python PATH में correctly add है, तो user किसी भी folder से Command Prompt या Terminal में python command run कर सकता है। अगर Python PATH में add नहीं है, तो system error दे सकता है जैसे “python is not recognized as an internal or external command”.

Why PATH is Important

  • Command line से Python run करने के लिए।
  • pip commands use करने के लिए।
  • VS Code और other tools को Python locate करवाने के लिए।
  • Python scripts को terminal से execute करने के लिए।
Real Life Example:
अगर आप Command Prompt में python --version लिखते हैं और version show होता है, तो इसका मतलब Python PATH में properly available है।

Executing Python from the Command Line

Command Line Execution

Python programs को Command Line से execute करना बहुत common method है। Command Line Windows में Command Prompt/PowerShell और Linux/macOS में Terminal कहलाता है। User terminal में Python command type करके interactive mode open कर सकता है या saved Python file को run कर सकता है।

Interactive Mode

python
print("Hello Python")
python hello.py
Compiler

Steps to Run Python File

  1. Notepad/VS Code में Python code लिखें।
  2. File को .py extension से save करें।
  3. Command Prompt open करें।
  4. उस folder में जाएँ जहाँ file saved है।
  5. python hello.py command run करें।
Real Life Example:
अगर आपने Desktop पर student.py file बनाई है, तो Command Prompt से Desktop folder में जाकर python student.py run कर सकते हैं।

7. IDLE

Python IDLE

Image Placeholder: Python IDLE window screenshot यहाँ लगाएँ

Definition:
IDLE का full form Integrated Development and Learning Environment है। यह Python के साथ आने वाला simple editor और interpreter environment है। IDLE beginners के लिए useful होता है क्योंकि इसमें Python shell, code editor और run option available होते हैं। Students IDLE में छोटे programs लिखकर quickly output देख सकते हैं।

Parts of IDLE

  • Python Shell: Direct commands type करके output देखा जा सकता है।
  • File Editor: Python program लिखकर save और run किया जा सकता है।
  • Run Module: Program file execute करने के लिए use होता है।
  • Syntax Highlighting: Keywords और strings अलग colors में दिखते हैं।

Steps to Run Program in IDLE

  1. IDLE open करें।
  2. File menu से New File select करें।
  3. Python code लिखें।
  4. File को .py extension से save करें।
  5. Run menu से Run Module या F5 press करें।
Real Life Example:
Beginners IDLE में print("Hello World") लिखकर तुरंत Python output देख सकते हैं।

11. Dynamic Types

Dynamic Typing in Python

Image Placeholder: Variable changing type diagram यहाँ लगाएँ

Definition:
Python एक Dynamically Typed Language है। इसका मतलब है कि Python में variable declare करते समय उसका data type explicitly बताना जरूरी नहीं होता। Python runtime पर value देखकर variable का type automatically decide कर लेता है। उदाहरण के लिए, अगर हम लिखते हैं x = 10, तो Python समझ जाता है कि x integer है। अगर बाद में x = "Hello" लिखते हैं, तो x string बन जाता है।

Dynamic typing Python को flexible बनाती है, लेकिन programmer को careful रहना चाहिए। अगर variable का type unexpected change हो जाए, तो error आ सकता है।

Example of Dynamic Typing

x = 10
print(type(x))

x = "Python"
print(type(x))

x = 25.5
print(type(x))

Features

  • Variable type runtime पर decide होता है।
  • Variable का type value के अनुसार change हो सकता है।
  • Code writing fast और flexible हो जाती है।
  • Type mistakes से runtime error आ सकता है।
Real Life Example:
Python में marks = 80 लिखने पर marks integer होता है, लेकिन marks = "Eighty" लिखने पर वही variable string बन सकता है।

13. Naming Conventions

Python Naming Conventions

Image Placeholder: Python naming conventions examples chart यहाँ लगाएँ

Definition:
Naming Conventions वे rules और best practices हैं जिनके अनुसार variables, functions, classes, constants और files के names लिखे जाते हैं। Good naming convention code को readable, professional और maintainable बनाती है। Python में official style guide PEP 8 के according naming conventions follow करना अच्छा माना जाता है।

Basic Identifier Rules

  • Name letters, digits और underscore से बन सकता है।
  • Name digit से start नहीं हो सकता।
  • Python case-sensitive है, इसलिए Name और name अलग हैं।
  • Reserved words को name के रूप में use नहीं कर सकते।
  • Special symbols जैसे @, #, %, - identifiers में use नहीं किए जाते।

Common Naming Conventions

Item Convention Example
Variable snake_case student_name
Function snake_case calculate_marks()
Class PascalCase StudentRecord
Constant UPPER_CASE MAX_MARKS
Module/File lowercase_with_underscore student_report.py

Good and Bad Examples

Good Name Bad Name Reason
student_name sn Good name meaningful है।
total_marks tm Readable और clear है।
calculate_average() ca() Function का purpose clear है।
Real Life Example:
अगर variable का name student_age है तो तुरंत समझ आ जाता है कि इसमें student की age store है। लेकिन x या a1 देखकर meaning clear नहीं होता।
