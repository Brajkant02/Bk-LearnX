Cascading Style Sheets

Introduction

CSS का full form Cascading Style Sheets है। CSS का use HTML web pages को design और style करने के लिए किया जाता है। HTML webpage का structure बनाता है, जबकि CSS उस structure को attractive look देता है। CSS से हम color, font, size, spacing, border, layout, background, alignment और responsive design control कर सकते हैं।

Web development में HTML और CSS दोनों बहुत important हैं। HTML बिना CSS के simple और plain दिखता है, लेकिन CSS apply करने के बाद वही page professional, colorful और user-friendly बन जाता है। CSS website के presentation layer को control करता है। इसका मतलब है कि webpage browser में कैसा दिखाई देगा, यह CSS decide करता है।

CSS को “Cascading” इसलिए कहा जाता है क्योंकि इसमें styles priority के according apply होते हैं। अगर एक ही element पर multiple styles apply किए गए हैं, तो browser cascade rules, specificity और order के according final style decide करता है।

HTML Without CSS

<h1>Welcome to My Website</h1>
<p>This is a simple paragraph.</p>

HTML With CSS

<h1 style="color: blue; text-align: center;">Welcome to My Website</h1>
<p style="font-size: 18px;">This is a styled paragraph.</p>
Output Feel:
Heading blue color में center align होगी और paragraph बड़ा दिखाई देगा।

CSS का Main Work

  • Text और font styling करना।
  • Colors और backgrounds apply करना।
  • Margins, padding और borders control करना।
  • Page layout बनाना।
  • Website को responsive बनाना।
  • HTML content को attractive और readable बनाना।
Real Life Example:
HTML घर का structure है और CSS उसकी paint, decoration, furniture arrangement और lighting की तरह है। बिना CSS के page simple दिखेगा, लेकिन CSS से वही page premium और professional दिख सकता है।
Remember:
HTML structure देता है, CSS design देता है और JavaScript behavior/interactivity देता है।

CSS code reusability provide करता है। एक ही CSS class को कई HTML elements पर apply किया जा सकता है। इससे बार-बार same styling लिखने की जरूरत नहीं पड़ती। CSS page loading, consistency, responsive design और user experience improve करने में help करता है।

CSS Syntax

CSS syntax selector और declaration block से मिलकर बनता है। Selector बताता है कि किस HTML element पर style apply करनी है। Declaration block curly braces { } के अंदर लिखा जाता है। इसमें property और value होती है। Property बताती है कि कौन-सी style change करनी है और value बताती है कि वह style कैसी होनी चाहिए।

Basic Syntax

selector {
  property: value;
}

Example

p {
  color: blue;
  font-size: 18px;
}

ऊपर code में p selector है, color और font-size properties हैं, और blue तथा 18px values हैं। यह CSS सभी paragraph elements पर apply होगी।

CSS Syntax Parts

Part Meaning

Property Style का नाम बताती है।
Value Property की setting बताती है।
Declaration Property और value का pair।
Declaration Block Curly braces में multiple declarations।

Multiple Declarations

h1 {

CSS comments code explain करने के लिए use होते हैं। Browser comments को ignore करता है।

/* This is a CSS comment */

  • Property और value के बीच colon : लगाना भूल जाना।

  • Curly braces close करना भूल जाना।
  • Property name गलत लिखना।
  • Selector name गलत लिखना।
Remember:
CSS syntax में selector element select करता है और declaration block उसकी styling define करता है।

CSS Implementation

CSS को HTML document में तीन ways से apply किया जा सकता है: inline CSS, internal CSS और external CSS. हर method का अपना use case होता है। Small testing के लिए inline CSS use हो सकती है, single page styling के लिए internal CSS और complete website design के लिए external CSS सबसे अच्छा method माना जाता है।

Inline CSS

Inline CSS directly HTML element के style attribute में लिखी जाती है। यह सिर्फ उसी element पर apply होती है।

<p style="color: blue; font-size: 18px;">
  This is inline styled paragraph.
</p>

Internal CSS

Internal CSS HTML document के <head> section में <style> tag के अंदर लिखी जाती है। यह same page के elements पर apply होती है।

<head>
  <style>
    p {
      color: green;
      font-size: 18px;
    }
  </style>
</head>

External CSS

External CSS अलग .css file में लिखी जाती है और HTML page में <link> tag से connect की जाती है। यह large websites के लिए best method है।

/* style.css */
h1 {
  color: purple;
  text-align: center;
}
<head>
  <link rel="stylesheet" href="style.css">
</head>

Comparison Table

Type Location Best Use Limitation
Inline CSS Element के style attribute में। Quick testing या one element styling। Code repeated और messy हो सकता है।
Internal CSS HTML head में style tag के अंदर। Single page design। Multiple pages में reuse difficult।
External CSS Separate .css file में। Complete website design। CSS file properly link करनी पड़ती है।

Priority Order

अगर same element पर multiple CSS methods apply हों, तो generally inline CSS की priority internal/external CSS से ज्यादा होती है। Specificity और order भी final result decide करते हैं।

Inline CSS  >  Internal CSS / External CSS  >  Browser Default
Real Life Example:
BK LearnX जैसे multi-page project में external CSS best रहेगी क्योंकि एक ही CSS file सभी chapter pages पर apply की जा सकती है।
Remember:
Professional websites में external CSS सबसे ज्यादा use होती है।

CSS Selectors

CSS selectors का use HTML elements को select करने के लिए किया जाता है। जब किसी element पर style apply करनी होती है, तो सबसे पहले CSS selector से उस element को target किया जाता है। CSS में कई types के selectors होते हैं जैसे element selector, id selector, class selector, grouping selector, universal selector और pseudo-class selector।

Element Selector

Element selector HTML tag name के basis पर elements को select करता है।

p {
  color: blue;
}

यह CSS सभी <p> paragraphs पर apply होगी।

Selector Types Overview

Selector Type Symbol / Syntax Use
Element Selector p, h1 Tag name से select करता है।
ID Selector #idname Unique element select करता है।
Class Selector .classname Multiple elements को group style करता है।
Grouping Selector h1, p, div Multiple selectors पर same style apply करता है।
Universal Selector * All elements select करता है।
Pseudo-class a:hover Element की special state select करता है।
Remember:
Selector यह decide करता है कि CSS किस HTML element पर apply होगी।

ID Selectors

ID selector किसी unique HTML element को select करने के लिए use होता है। HTML में id attribute का value एक page में unique होना चाहिए। CSS में ID selector लिखने के लिए hash symbol # का use किया जाता है।

HTML Code

<h1 id="main-heading">Welcome to CSS</h1>

CSS Code

#main-heading {
  color: blue;
  text-align: center;
}

Use of ID Selector

  • Unique section को style करने के लिए।
  • JavaScript में element access करने के लिए।
  • Same page linking के लिए।
  • Specific element पर special styling देने के लिए।

ID Selector Example

<p id="intro">This is introduction paragraph.</p>

<style>
  #intro {
    color: green;
    font-size: 20px;
  }
</style>
Output Feel:
Introduction paragraph green color और 20px font-size में show होगा।
Remember:
ID unique होता है और CSS में ID selector # से start होता है।

Class Selectors

Class selector multiple HTML elements को same style देने के लिए use होता है। HTML में class attribute दिया जाता है और CSS में class selector dot . से लिखा जाता है। Class selector CSS में सबसे ज्यादा useful और common selectors में से एक है।

HTML Code

<p class="highlight">Important paragraph</p>
<h2 class="highlight">Important heading</h2>

CSS Code

.highlight {
  background-color: yellow;
  color: black;
  padding: 10px;
}

Multiple Classes

एक element पर multiple classes भी apply की जा सकती हैं।

<p class="box warning">This is warning message</p>
.box {
  padding: 15px;
  border: 1px solid black;
}

.warning {
  background-color: orange;
}

Real Life Example:
Website में सभी cards को same design देना हो तो .card class बनाकर हर card पर apply किया जा सकता है।
Remember:
Class reusable होती है और CSS में dot . से लिखी जाती है।

Grouping Selectors

Grouping selector का use multiple selectors पर same CSS properties apply करने के लिए किया जाता है। अगर कई elements को same styling देनी हो, तो हर selector के लिए अलग CSS लिखने की जरूरत नहीं होती। Selectors को comma , से separate करके group किया जाता है।

Without Grouping

h1 {
  color: blue;
}

h2 {
  color: blue;
}

p {
  color: blue;
}

With Grouping

h1, h2, p {
  color: blue;
}

ऊपर grouping selector से code short और clean हो गया।

Grouping Example

h1, h2, h3 {
  font-family: Arial;
  color: darkblue;
}

Benefits

  • CSS code छोटा हो जाता है।
  • Repeated code कम होता है।
  • Maintenance आसान होती है।
  • Same design multiple elements पर apply हो जाता है।
Remember:
Grouping selector में selectors को comma से separate किया जाता है।

Universal Selectors

Universal selector CSS में सभी HTML elements को select करने के लिए use होता है। इसे star symbol * से लिखा जाता है। इसका use commonly default margin, padding remove करने या global box-sizing set करने के लिए किया जाता है।

Universal Selector Example

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

यह CSS सभी elements पर apply होगी। Web development में page reset करने के लिए यह बहुत common है।

Use Cases

  • Default margin और padding reset करने के लिए।
  • Global font family set करने के लिए।
  • Box sizing globally apply करने के लिए।
  • Basic layout consistency maintain करने के लिए।

Example with Font

* {
  font-family: Arial, sans-serif;
}

Careful Use

Universal selector powerful होता है क्योंकि यह पूरे page के सभी elements पर apply होता है। इसलिए इसे carefully use करना चाहिए। बहुत heavy properties universal selector में देने से performance पर effect पड़ सकता है।

Remember:
Universal selector * सभी elements को select करता है।

CSS Pseudo-classes

CSS pseudo-classes का use किसी element की special state को style करने के लिए किया जाता है। Pseudo-class selector में colon : का use होता है। For example, जब user किसी link पर mouse ले जाता है, तो :hover state apply होती है।

Common Pseudo-classes

Pseudo-class Use
:hover Mouse element पर आने पर style apply करता है।
:active Element click होते समय style apply करता है।
:visited Visited link को style करता है।
:focus Input field focus होने पर style apply करता है।
:first-child Parent का first child select करता है।
:nth-child() Specific child number select करता है।

Hover Example

a {
  color: blue;
}

a:hover {
  color: red;
}

Button Hover Example

button {
  background-color: blue;
  color: white;
}

button:hover {
  background-color: darkblue;
}

Focus Example

input:focus {
  border: 2px solid blue;
  outline: none;
}

nth-child Example

li:nth-child(2) {
  color: red;
}

यह CSS list के second item को red color देगी।

Real Life Example:
Navbar link पर mouse ले जाने पर उसका color change होना :hover pseudo-class का practical use है।
Remember:
Pseudo-classes element की state या position के basis पर styling apply करती हैं।

Box Model in CSS

CSS box model web design का बहुत important concept है। Browser हर HTML element को एक rectangular box की तरह treat करता है। इस box में content, padding, border और margin शामिल होते हैं। Box model समझना layout, spacing और element size control करने के लिए जरूरी है।

Box Model Parts

Part Meaning
Content Actual text, image या content area।
Padding Content और border के बीच की space।
Border Padding/content के बाहर की boundary line।
Margin Element के बाहर की space, दूसरे elements से distance।

|  |  |  | Content   |  |  |  |
|  |  |  +-----------+  |  |  |

|  +-----------------------+  |
+-----------------------------+

Box Model Example

  width: 300px;
  padding: 20px;

Padding content और border के बीच की internal space होती है।

Margin vs Padding

Basis Margin Padding
Location Border के बाहर होती है। Content और border के बीच होती है।
Purpose Elements के बीच gap बनाती है। Content के अंदर space देती है।
Background Effect Background color margin area पर apply नहीं होता। Background color padding area पर apply होता है।

box-sizing

By default CSS में width केवल content area पर apply होती है। Padding और border add होने पर actual element size बढ़ सकता है। इस problem को avoid करने के लिए box-sizing: border-box; use किया जाता है।

* {
  box-sizing: border-box;
}

Without border-box

.box {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}

Actual width = 300 + 40 padding + 10 border = 350px

With border-box

.box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}

Actual width 300px के अंदर ही padding और border include हो जाएंगे।

Real Life Example:
एक gift box में gift content है, अंदर की thermocol padding है, बाहर की box boundary border है और दूसरे boxes से दूरी margin है।
Remember:
Box model = Content + Padding + Border + Margin. CSS layout समझने के लिए box model सबसे important concept है।
