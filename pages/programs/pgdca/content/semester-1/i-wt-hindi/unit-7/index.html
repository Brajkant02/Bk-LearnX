XML & JSON

Introduction and Use of XML

XML का full form Extensible Markup Language है। XML एक markup language है जिसका use data को store और transport करने के लिए किया जाता है। XML का main purpose data को structured, readable और platform-independent form में represent करना है। XML में user अपने tags खुद define कर सकता है, इसलिए इसे extensible कहा जाता है।

HTML mainly data को browser में display करने के लिए use होती है, जबकि XML data को describe और carry करने के लिए use होती है। XML में predefined tags नहीं होते। Programmer data के according meaningful tags create करता है, जैसे <student>, <name>, <course> आदि।

XML human-readable भी है और machine-readable भी। इसका मतलब है कि इसे इंसान पढ़कर समझ सकता है और software programs भी इसे process कर सकते हैं। XML का use configuration files, data exchange, web services, RSS feeds, document storage और application settings में किया जाता है।

Simple XML Example

<student>
  <name>Brajkant</name>
  <course>PGDCA</course>
  <city>Kanpur</city>
</student>

Why XML is Used

  • Data को structured form में store करने के लिए।
  • Different applications के बीच data exchange करने के लिए।
  • Platform-independent data representation के लिए।
  • Configuration files create करने के लिए।
  • RSS feed और web services में data transfer करने के लिए।
  • Custom tags की help से meaningful data define करने के लिए।

Features of XML

Feature Explanation
Extensible User अपने tags define कर सकता है।
Self-descriptive Tags data का meaning clear करते हैं।
Platform Independent Different systems पर use हो सकती है।
Human Readable XML text form में होती है, इसलिए पढ़ना आसान है।
Hierarchical Data tree structure में arranged होता है।

XML Data Example for Book

<book>
  <title>Web Development</title>
  <author>Rahul Sharma</author>
  <price>350</price>
</book>
Real Life Example:
College software से student data किसी दूसरे system को भेजना हो, तो XML format में name, roll number, course और marks को structured form में send किया जा सकता है।
Remember:
XML data को display करने के लिए नहीं, बल्कि data को store और transport करने के लिए use होती है।

Difference between XML and HTML

XML और HTML दोनों markup languages हैं, लेकिन दोनों का purpose अलग है। HTML का use web pages को display करने के लिए किया जाता है, जबकि XML का use data को store और transport करने के लिए किया जाता है। HTML में predefined tags होते हैं, जैसे <h1>, <p>, <table>. XML में tags user खुद define करता है।

HTML browser को बताता है कि content कैसे show करना है, जबकि XML data का meaning और structure बताता है। XML strict syntax follow करती है। XML में tags properly closed और nested होने चाहिए। HTML browsers कई बार छोटी mistakes को ignore कर देते हैं, लेकिन XML parser strict होता है।

Focus Presentation पर focus। Data structure पर focus।
Syntax Relatively flexible। Strict syntax rules।
Closing Tags कुछ tags बिना closing के भी work कर सकते हैं। Every tag properly closed होना चाहिए।

Example <p>Hello</p> <name>Brajkant</name>

Real Life Example:
HTML report card को browser में सुंदर तरीके से दिखा सकती है, जबकि XML उसी report card data को another software को transfer करने के लिए useful हो सकती है।
Remember:
HTML दिखाने के लिए है और XML data carry करने के लिए है।

XML Elements

XML element XML document का basic building block होता है। एक XML element opening tag, content और closing tag से मिलकर बनता है। XML element data को meaningful form में represent करता है। For example, <name>Brajkant</name> में name element है और उसका content Brajkant है।

Basic Element Syntax

<elementName>Content</elementName>

Example

<name>Brajkant</name>

Nested Elements

XML में elements के अंदर other elements हो सकते हैं। इसे nested elements कहा जाता है।

<student>
  <name>Brajkant</name>
  <course>PGDCA</course>
  <marks>85</marks>
</student>

Root Element

हर XML document में एक single root element होना चाहिए। Root element बाकी सभी elements को contain करता है।

<students>
  <student>
    <name>Brajkant</name>
  </student>

  <student>
    <name>Amit</name>
  </student>
</students>

ऊपर <students> root element है।

Empty Element

अगर element में content नहीं है, तो उसे empty element की तरह लिखा जा सकता है।

<middleName></middleName>

<middleName />

XML Element Naming Rules

  • Element names case-sensitive होते हैं।
  • Element name letter या underscore से start हो सकता है।
  • Element name number से start नहीं होना चाहिए।
  • Element name में spaces नहीं होने चाहिए।
  • Element name meaningful होना चाहिए।
  • Opening और closing tag names exactly same होने चाहिए।

Correct and Wrong Element Examples

Correct Wrong
<studentName>Brajkant</studentName> <student name>Brajkant</student name>
<course>PGDCA</course> <course>PGDCA</Course>
<marks>85</marks> <1marks>85</1marks>
Remember:
XML document में one root element जरूरी होता है और XML tags case-sensitive होते हैं।

XML Attribute

XML attributes elements को extra information provide करते हैं। Attribute हमेशा opening tag के अंदर लिखा जाता है और name-value pair के रूप में होता है। Attribute value quotes में लिखी जाती है। XML में data element के अंदर भी रखा जा सकता है और attribute में भी, लेकिन main data normally element में रखना better माना जाता है।

Attribute Syntax

<element attribute="value">Content</element>

Example

<student roll="101">
  <name>Brajkant</name>
  <course>PGDCA</course>
</student>

यहाँ roll="101" attribute है।

Multiple Attributes

<student roll="101" batch="2026">
  <name>Brajkant</name>
</student>

Element vs Attribute

Basis Element Attribute
Location Opening और closing tag के बीच। Opening tag के अंदर।
Use Main data store करने के लिए। Extra information देने के लिए।
Example <name>Brajkant</name> roll="101"

Same Data as Element

<student>
  <roll>101</roll>
  <name>Brajkant</name>
</student>

Same Data as Attribute

<student roll="101">
  <name>Brajkant</name>
</student>

Attribute Rules

  • Attribute values quotes में होनी चाहिए।
  • Same element में same attribute दो बार नहीं होना चाहिए।
  • Attributes extra information के लिए use करें।
  • Main structured data elements में रखना better है।
Real Life Example:
Student का roll number attribute में और name/course elements में रखा जा सकता है। लेकिन अगर roll number पर processing करनी है, तो उसे element के रूप में रखना ज्यादा clear हो सकता है।
Remember:
XML attributes extra information देते हैं, जबकि elements main data represent करते हैं।

Name Space

XML namespace का use element और attribute names के conflict को avoid करने के लिए किया जाता है। जब अलग-अलग XML documents या vocabularies को combine किया जाता है, तो same element name का meaning अलग हो सकता है। Namespace unique identifier provide करके names को अलग करता है।

Namespace define करने के लिए xmlns attribute use होता है। Namespace usually URI के रूप में लिखा जाता है। यह जरूरी नहीं कि URI actual webpage open करे; इसका main purpose unique name provide करना होता है।

Problem Without Namespace

<table>
  <tr>
    <td>HTML Table</td>
  </tr>
</table>

<table>
  <name>Wooden Table</name>
  <price>5000</price>
</table>

यहाँ दोनों जगह <table> tag है, लेकिन first HTML table को represent कर सकता है और second furniture table को। इससे confusion हो सकता है।

Using Namespace

<root
  xmlns:h="http://www.w3.org/TR/html4/"
  xmlns:f="https://example.com/furniture">

  <h:table>
    <h:tr>
      <h:td>HTML Table</h:td>
    </h:tr>
  </h:table>

  <f:table>
    <f:name>Wooden Table</f:name>
    <f:price>5000</f:price>
  </f:table>

</root>

यहाँ h: और f: prefixes अलग namespaces को represent कर रहे हैं।

Default Namespace

<student xmlns="https://example.com/student">
  <name>Brajkant</name>
  <course>PGDCA</course>
</student>

Namespace Parts

Part Meaning
xmlns Namespace define करने के लिए attribute।
Prefix Short name, जैसे h या f।
URI Unique namespace identifier।
Qualified Name Prefix के साथ element name, जैसे h:table।
Real Life Example:
अगर दो departments अपने XML में <code> element use करते हैं, लेकिन one course code और दूसरा employee code के लिए, तो namespace confusion avoid करता है।
Remember:
Namespace same tag names के conflict को avoid करने के लिए use होता है।

Syntax Rules

XML syntax HTML से ज्यादा strict होती है। XML document properly structured होना चाहिए। अगर XML syntax rules follow नहीं किए गए, तो parser error दे सकता है। Proper syntax वाले XML document को well-formed XML कहा जाता है।

Important XML Syntax Rules

Rule Explanation
One Root Element XML document में only one root element होना चाहिए।
Closing Tags Required Every opening tag का closing tag होना चाहिए।
Case Sensitive <Name> और <name> अलग हैं।
Proper Nesting Tags सही order में nested और closed होने चाहिए।
Attribute Values in Quotes Attribute values हमेशा quotes में होनी चाहिए।
Special Characters Escaped Special characters के लिए entities use करनी चाहिए।

Correct XML

<student>
  <name>Brajkant</name>
  <course>PGDCA</course>
</student>

Wrong XML: Missing Closing Tag

<student>
  <name>Brajkant
  <course>PGDCA</course>
</student>

Wrong XML: Case Mismatch

<name>Brajkant</Name>

Wrong XML: Multiple Root Elements

<student>Brajkant</student>
<course>PGDCA</course>

Correct XML with One Root

<record>
  <student>Brajkant</student>
  <course>PGDCA</course>
</record>

Special Characters in XML

Character Entity
< &lt;
> &gt;
& &amp;
" &quot;
' &apos;
Remember:
Well-formed XML में one root element, proper closing tags, proper nesting और quoted attributes जरूरी हैं।

XML DTD and XML Schema

XML document की structure और rules define करने के लिए DTD और XML Schema use किए जाते हैं। XML file well-formed हो सकती है, लेकिन यह जरूरी नहीं कि वह required structure follow कर रही हो। DTD या Schema document को validate करने में help करते हैं। Valid XML वह XML होती है जो defined rules के according हो।

DTD

DTD का full form Document Type Definition है। DTD XML document की legal structure define करता है। इसमें कौन-कौन से elements होंगे, उनका order क्या होगा और कौन से attributes allowed होंगे, यह define किया जा सकता है।

Internal DTD Example

<!DOCTYPE student [
  <!ELEMENT student (name, course)>
  <!ELEMENT name (#PCDATA)>
  <!ELEMENT course (#PCDATA)>
]>

<student>
  <name>Brajkant</name>
  <course>PGDCA</course>
</student>

External DTD

<!DOCTYPE student SYSTEM "student.dtd">

student.dtd

<!ELEMENT student (name, course)>
<!ELEMENT name (#PCDATA)>
<!ELEMENT course (#PCDATA)>

XML Schema

XML Schema या XSD XML document की structure define करने का advanced और powerful way है। XML Schema XML syntax में लिखा जाता है और data types support करता है। DTD की comparison में XML Schema ज्यादा powerful है क्योंकि इसमें string, integer, date आदि data types define किए जा सकते हैं।

XML Schema Example

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">

  <xs:element name="student">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="name" type="xs:string"/>
        <xs:element name="course" type="xs:string"/>
        <xs:element name="marks" type="xs:integer"/>
      </xs:sequence>
    </xs:complexType>
  </xs:element>

</xs:schema>

DTD vs XML Schema

Basis DTD XML Schema
Full Form Document Type Definition XML Schema Definition
Syntax XML syntax नहीं होती। XML syntax में लिखा जाता है।
Data Types Limited support। Strong data type support।
Namespace Support Limited। Better namespace support।
Power Simple validation। Advanced validation।

Use of DTD and Schema

  • XML document की structure define करने के लिए।
  • XML data validation के लिए।
  • Elements और attributes rules define करने के लिए।
  • Data exchange में format consistency maintain करने के लिए।
Real Life Example:
अगर college को student XML file में name, roll और marks compulsory चाहिए, तो XML Schema से rules define करके invalid files reject की जा सकती हैं।
Remember:
DTD और XML Schema XML document की rules और structure define करते हैं। XML Schema DTD से ज्यादा powerful है।

RSS FEED

RSS का full form Really Simple Syndication है। RSS feed XML based format है जिसका use frequently updated content share करने के लिए किया जाता है। News websites, blogs, educational websites और podcast platforms RSS feeds use कर सकते हैं ताकि users या applications latest updates automatically receive कर सकें।

RSS feed एक XML document होती है जिसमें website की latest posts, titles, links, descriptions और publish dates stored होते हैं। RSS reader या feed reader application इस feed को read करके user को latest updates दिखाता है।

Simple RSS Feed Example

<rss version="2.0">
  <channel>
    <title>BK LearnX Updates</title>
    <link>https://example.com</link>
    <description>Latest study material updates</description>

    <item>
      <title>New HTML Chapter Added</title>
      <link>https://example.com/html</link>
      <description>HTML notes are now available.</description>
      <pubDate>Fri, 10 Jul 2026 10:00:00 GMT</pubDate>
    </item>

  </channel>
</rss>

RSS Feed Components

Element Use
<rss> RSS document का root element।
<channel> Website/feed information contain करता है।
<title> Feed या item का title।
<link> Website या item का URL।
<description> Short description।
<item> Individual update/post।
<pubDate> Publishing date।

Uses of RSS Feed

  • Latest news updates share करने के लिए।
  • Blog posts automatically distribute करने के लिए।
  • Podcast updates provide करने के लिए।
  • Educational content updates send करने के लिए।
  • Users को website visit किए बिना updates देने के लिए।
Real Life Example:
BK LearnX में नया chapter upload होते ही RSS feed में update add हो सकता है, जिससे students को latest material का पता चल सके।
Remember:
RSS feed XML based होती है और latest updates automatically share करने के लिए use होती है।

JSON Introduction and Uses

JSON का full form JavaScript Object Notation है। JSON एक lightweight data format है जिसका use data को store और exchange करने के लिए किया जाता है। JSON human-readable और machine-readable दोनों है। यह especially web APIs में बहुत popular है क्योंकि इसका structure simple और compact होता है।

JSON JavaScript object syntax से inspired है, लेकिन यह language-independent data format है। इसका मतलब है कि JSON को JavaScript, Python, PHP, Java, C#, Ruby और many other languages में use किया जा सकता है। Modern web development में client और server के बीच data exchange के लिए JSON बहुत common है।

Simple JSON Example

{
  "name": "Brajkant",
  "course": "PGDCA",
  "city": "Kanpur"
}

JSON Uses

  • Client और server के बीच data exchange करने के लिए।
  • Web APIs में response data भेजने के लिए।
  • Configuration files में settings store करने के लिए।
  • Database-like structured data represent करने के लिए।
  • Mobile apps और web apps में data transfer करने के लिए।
  • JavaScript applications में object data handle करने के लिए।

JSON Data with Array

{
  "students": [
    {
      "name": "Brajkant",
      "course": "PGDCA"
    },
    {
      "name": "Amit",
      "course": "DCCN"
    }
  ]
}

Features of JSON

Feature Explanation
Lightweight XML की comparison में छोटा और simple होता है।
Readable Human और machine दोनों आसानी से read कर सकते हैं।
Language Independent Many programming languages में use हो सकता है।
API Friendly Web APIs में commonly use होता है।
Structured Key-value pairs और arrays support करता है।

JSON in JavaScript

let student = {
  "name": "Brajkant",
  "course": "PGDCA"
};

console.log(student.name);
Output:
Brajkant
Real Life Example:
Weather app server से JSON data receive कर सकता है जैसे city, temperature और condition. App उस JSON data को read करके screen पर weather show करता है।
Remember:
JSON modern web APIs में data exchange का सबसे common lightweight format है।

JSON v/s XML

JSON और XML दोनों data exchange formats हैं। दोनों का use structured data को store और transfer करने के लिए किया जाता है, लेकिन JSON lightweight और simple होता है, जबकि XML ज्यादा verbose और tag-based होता है। Modern web APIs में JSON ज्यादा popular है क्योंकि यह compact, fast और JavaScript friendly है।

JSON Example

{
  "student": {
    "name": "Brajkant",
    "course": "PGDCA",
    "marks": 85
  }
}

XML Example

<student>
  <name>Brajkant</name>
  <course>PGDCA</course>
  <marks>85</marks>
</student>

Basis JSON XML

Size Less verbose, compact। More verbose due to tags।
Readability Simple और easy to read। Readable but longer।

Array Support Direct array support। Arrays को repeated elements से represent करते हैं।
Comments Comments allowed नहीं हैं। Comments allowed हैं।

When to Use JSON

  • Web APIs में data send/receive करना हो।
  • Lightweight data format चाहिए।
  • JavaScript application के साथ काम करना हो।
  • Fast parsing और compact response चाहिए।

When to Use XML

  • Strict document structure चाहिए।
  • DTD या Schema validation चाहिए।
  • RSS feeds या old enterprise systems के साथ काम करना हो।
  • Document-oriented data store करना हो।
Real Life Example:
Modern mobile app server से JSON data लेना पसंद करता है, जबकि पुराने banking या enterprise systems XML format use कर सकते हैं।
Remember:
JSON compact और API-friendly है, XML strict और document-oriented है।

JSON Syntax

JSON syntax simple होती है, लेकिन इसके rules strict होते हैं। JSON data key-value pairs में लिखा जाता है। Keys हमेशा double quotes में होती हैं। Values string, number, boolean, null, object या array हो सकती हैं। JSON में comments allowed नहीं होते।

Basic JSON Syntax

{
  "key": "value"
}

JSON Object

{
  "name": "Brajkant",
  "age": 23,
  "course": "PGDCA"
}

JSON Array

{
  "subjects": ["HTML", "CSS", "JavaScript", "Bootstrap"]
}

Nested JSON

{
  "student": {
    "name": "Brajkant",
    "course": "PGDCA",
    "address": {
      "city": "Kanpur",
      "state": "Uttar Pradesh"
    }
  }
}

JSON Data Types

Data Type Example
String "Brajkant"
Number 23, 85.5
Boolean true, false
Null null
Object {"name": "Amit"}
Array ["HTML", "CSS"]

JSON Syntax Rules

  • Data key-value pairs में होता है।
  • Keys double quotes में लिखी जाती हैं।
  • String values भी double quotes में होती हैं।
  • Data pairs comma से separate होते हैं।
  • Objects curly braces { } में लिखे जाते हैं।
  • Arrays square brackets [ ] में लिखी जाती हैं।
  • JSON में comments allowed नहीं हैं।
  • Last item के बाद extra comma नहीं लगाना चाहिए।

Correct JSON

{
  "name": "Brajkant",
  "course": "PGDCA",
  "age": 23
}

Wrong JSON: Single Quotes

{
  'name': 'Brajkant'
}

Wrong JSON: Extra Comma

{
  "name": "Brajkant",
  "course": "PGDCA",
}

JSON.parse() and JSON.stringify()

JavaScript में JSON string को object में convert करने के लिए JSON.parse() और object को JSON string में convert करने के लिए JSON.stringify() use होता है।

let jsonText = '{"name":"Brajkant","course":"PGDCA"}';

let obj = JSON.parse(jsonText);

console.log(obj.name);
Output:
Brajkant
let student = {
  name: "Brajkant",
  course: "PGDCA"
};

let jsonString = JSON.stringify(student);

console.log(jsonString);
Output:
{"name":"Brajkant","course":"PGDCA"}
Real Life Example:
Server से आया JSON text browser में JavaScript object में convert करके webpage पर student details display की जा सकती हैं।
Remember:
JSON में keys double quotes में होती हैं और extra comma allowed नहीं होता।
