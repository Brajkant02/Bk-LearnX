Bootstrap

Bootstrap Introduction

Bootstrap एक popular front-end framework है जिसका use responsive और mobile-first websites बनाने के लिए किया जाता है। Bootstrap में ready-made CSS classes और JavaScript components available होते हैं, जिनकी help से developer जल्दी और professional design बना सकता है। Bootstrap HTML, CSS और JavaScript पर based है।

Bootstrap का main purpose web development को fast, consistent और responsive बनाना है। अगर developer को button, navbar, form, table, alert, card, modal, dropdown या grid layout बनाना है, तो उसे scratch से पूरा CSS लिखने की जरूरत नहीं होती। Bootstrap की predefined classes use करके design जल्दी बन जाता है।

Responsive design Bootstrap की सबसे important feature है। Bootstrap grid system screen size के according layout adjust कर देता है। इसी कारण एक ही website mobile, tablet, laptop और desktop पर properly दिखाई दे सकती है।

Why Bootstrap is Used

  • Responsive websites जल्दी बनाने के लिए।
  • Ready-made components use करने के लिए।
  • Consistent design maintain करने के लिए।
  • Less custom CSS लिखने के लिए।
  • Mobile-first layout बनाने के लिए।
  • Forms, buttons, navbar और tables को professional look देने के लिए।

Bootstrap Features

Feature Explanation
Responsive Grid 12-column grid system से layout responsive बनता है।
Predefined Classes Design के लिए ready CSS classes मिलती हैं।
Components Navbar, dropdown, alert, buttons, forms आदि ready components।
Utilities Spacing, color, display, text alignment जैसी utility classes।
Cross Browser Support Modern browsers में consistent behavior देता है।
Real Life Example:
अगर आपको BK LearnX website का responsive navbar, subject cards और forms जल्दी बनाने हैं, तो Bootstrap classes use करके design fast तैयार किया जा सकता है।
Remember:
Bootstrap ready-made CSS और JavaScript components का framework है, जिससे responsive website जल्दी बनती है।

Adding Bootstrap

Bootstrap use करने के लिए उसे HTML page में add करना जरूरी है। Bootstrap को CDN link से या local downloaded files से add किया जा सकता है। CDN method quick और easy है, जबकि local files offline use के लिए helpful होती हैं।

Bootstrap CDN

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Complete Basic Template

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bootstrap Page</title>

  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>

  <div class="container">
    <h1 class="text-primary">Hello Bootstrap</h1>
    <button class="btn btn-success">Click Me</button>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
Output:
Page में primary color heading और green success button दिखाई देगा।

Why meta viewport is Important

Bootstrap responsive design के लिए viewport meta tag important है। यह mobile devices पर page width को device width के according set करता है।

<meta name="viewport" content="width=device-width, initial-scale=1.0">

CDN vs Local Files

Basis CDN Local File
Source Internet server से load होता है। Project folder से load होता है।
Setup Easy और fast। Files download करनी पड़ती हैं।
Internet Required हो सकता है। Offline work कर सकता है।
Use Quick projects/testing। Offline lab/practical।
Remember:
Bootstrap CSS को head में और Bootstrap JS bundle को body के end में add करना अच्छा रहता है।

Grid

Bootstrap grid system responsive layout बनाने के लिए use होता है। Bootstrap grid 12 columns पर based होता है। Page को rows और columns में divide करके content arrange किया जाता है। Grid system की help से same design different screen sizes पर automatically adjust हो सकता है।

Grid में container, row और col classes important होती हैं। Content हमेशा columns के अंदर रखा जाता है, columns rows के अंदर और rows container के अंदर रखी जाती हैं।

Basic Grid Structure

<div class="container">
  <div class="row">
    <div class="col">Column 1</div>
    <div class="col">Column 2</div>
    <div class="col">Column 3</div>
  </div>
</div>

12 Column System

<div class="container">
  <div class="row">
    <div class="col-4">4 Columns</div>
    <div class="col-4">4 Columns</div>
    <div class="col-4">4 Columns</div>
  </div>
</div>

तीनों columns 4+4+4 = 12 columns cover करेंगे।

Responsive Grid

<div class="container">
  <div class="row">
    <div class="col-12 col-md-6 col-lg-4">Card 1</div>
    <div class="col-12 col-md-6 col-lg-4">Card 2</div>

  </div>
</div>

इस example में mobile पर column full width, medium screen पर half width और large screen पर one-third width होगा।

Utilities & Filters

Bootstrap utilities small helper classes होती हैं जिनसे जल्दी styling apply की जा सकती है। Utilities से margin, padding, display, flex, text alignment, colors, border, shadow, width, height और visibility जैसी styling बिना custom CSS लिखे apply की जा सकती है।

Filters Bootstrap में direct core component की तरह नहीं होते, लेकिन utility classes और CSS filter properties की help से images या elements पर visual effects apply किए जा सकते हैं। Bootstrap utilities design को fast और consistent बनाती हैं।

Spacing Utilities

Bootstrap में margin और padding के लिए short classes use होती हैं।

m-3   = margin
p-3   = padding
mt-2  = margin-top
mb-4  = margin-bottom
ms-3  = margin-start
me-3  = margin-end
px-4  = padding-left and right
py-4  = padding-top and bottom

Spacing Example

<div class="p-4 m-3 bg-light">
  This box has padding and margin.
</div>

Filter Example with CSS

Image पर filter effects apply करने के लिए CSS filter property use की जा सकती है। Bootstrap classes के साथ custom CSS combine किया जा सकता है।

<img src="photo.jpg" class="img-fluid custom-filter">

<style>
.custom-filter {
  filter: grayscale(100%);
}
</style>

Common CSS Filters

Filter Use
grayscale() Image को black and white बनाता है।
blur() Image blur करता है।
brightness() Brightness control करता है।
contrast() Contrast control करता है।
opacity() Transparency control करता है।
