HTML

HTML Document

HTML का full form HyperText Markup Language है। यह web pages बनाने के लिए use होने वाली standard markup language है। HTML किसी webpage का structure बनाता है। Browser HTML code को read करता है और उसे user के सामने formatted webpage के रूप में display करता है।

HTML programming language की तरह logic execute नहीं करती, बल्कि यह page के elements को describe करती है। इसमें headings, paragraphs, images, links, lists, tables, forms और sections जैसे elements बनाए जाते हैं। HTML document एक text file होती है जिसकी extension usually .html या .htm होती है।

Simple HTML Document

<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Welcome to HTML</h1>
  <p>This is my first web page.</p>
</body>
</html>

Output

Browser Output:
Welcome to HTML
This is my first web page.

Important Points

  • HTML webpage का structure create करता है।
  • HTML document browser में open होता है।
  • HTML file की extension .html होती है।
  • HTML tags angle brackets < > में लिखे जाते हैं।
  • HTML के साथ CSS और JavaScript मिलकर complete web page बनाते हैं।
Real Life Example:
अगर webpage एक घर है, तो HTML उस घर की दीवार, कमरे और structure की तरह है। CSS decoration की तरह और JavaScript electric switches/interactivity की तरह काम करता है।
Remember:
HTML web page का skeleton यानी structure बनाता है।

Basic Structure of HTML

HTML document की एक fixed basic structure होती है। इस structure में <!DOCTYPE html>, <html>, <head>, <title> और <body> tags शामिल होते हैं। हर tag का अपना specific role होता है।

Basic Structure

<!DOCTYPE html>
<html>
<head>
  <title>Page Title</title>
</head>
<body>
  Page content goes here
</body>
</html>

Structure Parts

Part Work
<!DOCTYPE html> Browser को बताता है कि document HTML5 है।
<html> पूरे HTML document का root element है।
<head> Page की information, title, meta और links रखता है।
<title> Browser tab में page का title show करता है।
<body> Visible webpage content रखता है।

Head and Body Difference

Head Body
Page की information store करता है। Visible content store करता है।
Mostly user को directly visible नहीं होता। User को browser में visible होता है।
Title, meta, CSS links आदि रखता है। Headings, paragraphs, images, links आदि रखता है।
Remember:
HTML page में visible content हमेशा <body> tag के अंदर लिखा जाता है।

Syntax

HTML syntax का मतलब HTML code लिखने के rules से है। HTML में content को tags के अंदर लिखा जाता है। Most HTML tags opening tag और closing tag के pair में आते हैं। Opening tag start बताता है और closing tag end बताता है।

Basic Syntax

<tagname>Content</tagname>

Example

<p>This is a paragraph.</p>
Output:
This is a paragraph.

Element Structure

<h1>Welcome</h1>
Part Meaning
<h1> Opening tag
Welcome Content
</h1> Closing tag

Case Sensitivity

HTML tags case-sensitive नहीं होते, लेकिन modern HTML में lowercase tags लिखना best practice माना जाता है।

<P>Hello</P>
<p>Hello</p>

दोनों काम कर सकते हैं, लेकिन <p> lowercase format professional और recommended है।

Common Syntax Rules

  • Tags angle brackets में लिखे जाते हैं।
  • Most tags का opening और closing pair होता है।
  • Closing tag में slash / होता है।
  • Tags properly nested होने चाहिए।
  • Attribute values को quotes में लिखना चाहिए।
Remember:
HTML syntax simple है, लेकिन correct nesting और proper closing tags important हैं।

HTML Tags and Attributes

HTML tags webpage के elements define करते हैं। Tags browser को बताते हैं कि content heading है, paragraph है, image है, link है या table है। Tags angle brackets के अंदर लिखे जाते हैं।

Attributes HTML elements को extra information provide करते हैं। Attributes हमेशा opening tag में लिखे जाते हैं और generally name-value pair में होते हैं। जैसे image tag में src image location बताता है और alt image का alternate text बताता है।

Tag Example

<h1>HTML Tutorial</h1>
<p>HTML is used to create web pages.</p>

Attribute Example

<img src="computer.jpg" alt="Computer Image">

<a href="https://example.com">Visit Website</a>

Attribute Use

Real Life Example:
जैसे किसी student के name के साथ roll number, course और class extra details होते हैं, वैसे ही HTML tag के साथ attributes extra information देते हैं।
Remember:
Tag element बनाता है और attribute उस element की extra information देता है।

Types of HTML Tags

HTML tags को उनके behavior और structure के basis पर अलग-अलग types में divide किया जा सकता है। कुछ tags opening और closing pair में आते हैं, जबकि कुछ tags self-closing या empty होते हैं। कुछ tags block-level होते हैं और कुछ inline होते हैं।

Paired Tags

Paired tags में opening और closing दोनों tags होते हैं। Content इन दोनों tags के बीच लिखा जाता है।

<p>This is paragraph</p>
<h1>Main Heading</h1>

Empty Tags

Empty tags में closing tag नहीं होता क्योंकि इनमें content नहीं होता।

<br>
<hr>
<img src="photo.jpg" alt="Photo">

Block-Level Tags

Block-level tags new line से start होते हैं और available width पूरी ले लेते हैं।

<div>This is div</div>
<p>This is paragraph</p>

Inline Tags

Inline tags same line में रहते हैं और केवल required width लेते हैं।

<span>Text</span>
<b>Bold</b>
<a href="#">Link</a>

Comparison Table

Type Meaning Example
Paired Tag Opening और closing tag होते हैं। <p></p>
Empty Tag Closing tag नहीं होता। <br>
Block Tag New line से start होता है। <div>
Inline Tag Same line में रहता है। <span>
Remember:
Block elements full width लेते हैं, जबकि inline elements content जितनी width लेते हैं।

Rules of Nesting

Nesting का मतलब एक HTML element के अंदर दूसरा HTML element लिखना है। HTML में nesting बहुत common है, लेकिन nested tags properly close होने चाहिए। जो tag बाद में open हुआ है, उसे पहले close करना चाहिए।

Correct Nesting

<p>This is <b>bold text</b> in paragraph.</p>

Wrong Nesting

<p>This is <b>bold text</p></b>

Wrong nesting से browser output unpredictable हो सकता है और page structure खराब हो सकता है।

Nesting Example with List

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Important Rules

  • Tags को proper order में close करें।
  • Parent element के अंदर child element properly रखा जाए।
  • List items हमेशा list tag के अंदर रखें।
  • Table rows table के अंदर और table cells rows के अंदर रखें।
  • Readable code के लिए indentation use करें।
Real Life Example:
जैसे file folder के अंदर sub-folder proper structure में होता है, वैसे ही HTML elements proper nesting में होने चाहिए।

Basic Tags

HTML के basic tags हर webpage में commonly use होते हैं। इनमें HTML tag, head tag, title tag और body tag सबसे important हैं। ये tags HTML document का foundation बनाते हैं।

HTML Tag

<html> tag पूरे HTML document का root tag होता है। बाकी सभी main tags इसके अंदर आते हैं।

<html>
  ...
</html>

Head Tag

<head> tag document की information रखता है जैसे title, meta tags, CSS links आदि।

<head>
  <title>My Website</title>
</head>

Title Tag

<title> tag browser tab में page title show करता है। यह SEO और user identification के लिए भी useful है।

<title>Home Page</title>

Body Tag

<body> tag webpage का visible content रखता है। User को browser में जो content दिखाई देता है, वह body tag के अंदर लिखा जाता है।

<body>
  <h1>Welcome</h1>
  <p>This is my page.</p>

Visible webpage content हमेशा body tag के अंदर लिखा जाता है।

Page Formatting

Page formatting का मतलब webpage के content को readable और properly arranged बनाना है। HTML में paragraph, line break, blank space, background color, div और span जैसे elements page formatting में help करते हैं।

Adding a New Paragraph

<p> tag paragraph बनाने के लिए use होता है। Browser paragraph के पहले और बाद में automatically spacing देता है।

<p>This is first paragraph.</p>
<p>This is second paragraph.</p>
Output:
This is first paragraph.

This is second paragraph.

Adding a Line Break

<br> tag line break के लिए use होता है। यह empty tag है।

First Line<br>
Second Line
Output:
First Line
Second Line

Inserting a Blank Space

HTML normal multiple spaces को single space की तरह treat करता है। Extra blank space के लिए &nbsp; use किया जा सकता है।

Hello&nbsp;&nbsp;&nbsp;World
Output:
Hello   World

Changing Page Background

Modern HTML में background change करने के लिए CSS use किया जाता है।

<body style="background-color: lightblue;">
  <h1>Welcome</h1>
</body>

Div Tag

<div> block-level container होता है। इसका use content को sections में divide करने और CSS styling apply करने के लिए किया जाता है।

<div>
  <h2>About Us</h2>
  <p>This is about section.</p>
</div>

Span Tag

<span> inline container होता है। इसका use text के छोटे part पर styling apply करने के लिए किया जाता है।

<p>This is <span style="color:red;">important</span> text.</p>

Div vs Span

Basis Div Span
Type Block-level element। Inline element।
Use Large sections/grouping के लिए। Small inline text styling के लिए।
New Line New line से start होता है। Same line में रहता है।
Remember:
div section/container के लिए और span inline text styling के लिए use होता है।

Text Formatting

HTML text formatting elements text को meaningful और visually different बनाने के लिए use होते हैं। इन tags से text को bold, italic, important, emphasized, marked, deleted, inserted, subscript और superscript form में दिखाया जा सकता है।

HTML Headings

HTML में heading tags <h1> से <h6> तक होते हैं। <h1> सबसे important और largest heading होती है, जबकि <h6> सबसे smallest heading होती है।

<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>

Horizontal Lines

Remember:
<strong> और <em> semantic importance बताते हैं, जबकि <b> और <i> mainly visual formatting करते हैं।

Creating Lists

HTML lists का use related items को organized तरीके से show करने के लिए किया जाता है। HTML में mainly तीन types की lists होती हैं: ordered list, unordered list और definition list।

Ordered List

Ordered list numbered list होती है। इसे <ol> tag से बनाया जाता है और items <li> tag में लिखे जाते हैं।

<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>
Output:
1. HTML
2. CSS
3. JavaScript

Unordered List

Unordered list bullet list होती है। इसे <ul> tag से बनाया जाता है।

<ul>
  <li>Python</li>
  <li>Java</li>
  <li>C++</li>
</ul>
Output:
• Python
• Java
• C++

Definition List

Definition list terms और उनकी description show करने के लिए use होती है। इसमें <dl>, <dt> और <dd> tags use होते हैं।

<dl>
  <dt>HTML</dt>
  <dd>HTML is used to create web pages.</dd>

  <dt>CSS</dt>
  <dd>CSS is used for styling web pages.</dd>
</dl>

List Tags

Tag Use
<ol> Ordered list बनाता है।
<ul> Unordered list बनाता है।
<li> List item define करता है।
<dl> Definition list बनाता है।
<dt> Definition term define करता है।
<dd> Definition description define करता है।
Real Life Example:
Syllabus topics को ordered list में और features को unordered list में show किया जा सकता है।

Images

Linking to an Area of Same Page

HTML में same page के किसी specific section पर जाने के लिए internal linking या anchor linking का use किया जाता है। इसके लिए target section को id दिया जाता है और link में #id use किया जाता है।

Same Page Link Example

<a href="#contact">Go to Contact Section</a>

<h2 id="contact">Contact Us</h2>
<p>This is contact section.</p>

Uses

  • Long webpage में quick navigation के लिए।
  • Table of contents बनाने के लिए।
  • FAQ page में questions से answers तक jump करने के लिए।
  • Single page website में section navigation के लिए।
Real Life Example:
BK LearnX notes page के left sidebar में topics पर click करने से same page के अलग-अलग sections open होते हैं। यह same page linking का example है।

Introduction to Table Tags

HTML tables का use data को rows और columns के form में display करने के लिए किया जाता है। Table tabular data जैसे marksheet, timetable, price list, comparison chart और student records show करने के लिए useful है।

Basic Table Example

<table border="1">
  <tr>
    <th>Name</th>
    <th>Course</th>
  </tr>
  <tr>
    <td>Brajkant</td>
    <td>PGDCA</td>
  </tr>
</table>

Table Tags

Tag Use
<table> Table create करता है।
<tr> Table row create करता है।
<th> Table heading cell create करता है।
<td> Table data cell create करता है।
<caption> Table title/caption देता है।

Rowspan and Colspan

rowspan multiple rows merge करता है और colspan multiple columns merge करता है।

<td colspan="2">Total Marks</td>
<td rowspan="2">Result</td>

Advantages of Tables

  • Data को organized form में show करते हैं।
  • Comparison easy हो जाता है।
  • Rows और columns में data readable दिखता है।
  • Marksheet, timetable और reports के लिए useful हैं।

Limitations of Tables

  • Layout design के लिए tables use करना old practice है।
  • Mobile responsive बनाना difficult हो सकता है।
  • Complex tables small screens पर overflow कर सकते हैं।
  • Accessibility issues आ सकते हैं अगर table structure सही न हो।
Remember:
Tables का use tabular data के लिए करें, page layout बनाने के लिए नहीं।

Frames and IFrame

HTML frames पुराने समय में एक browser window को multiple sections में divide करने के लिए use होते थे। HTML5 में traditional frames और frameset obsolete हो चुके हैं। Modern HTML में external page या content embed करने के लिए <iframe> tag use किया जाता है।

IFrame

<iframe> का full form inline frame है। यह current webpage के अंदर another webpage या resource display कर सकता है।

<iframe src="chapter.html" width="100%" height="400"></iframe>

Common IFrame Attributes

Attribute Use
src Embedded page का address।
width IFrame की width।
height IFrame की height।
title Accessibility के लिए iframe title।
loading Lazy loading enable कर सकता है।

Responsive IFrame Example

<div style="width:100%; height:100vh;">
  <iframe src="chapter.html" style="width:100%; height:100%; border:none;"></iframe>
</div>

Uses of IFrame

  • Another HTML page embed करने के लिए।
  • Map embed करने के लिए।
  • YouTube video embed करने के लिए।
  • PDF या external content show करने के लिए।
Real Life Example:
BK LearnX project में chapter HTML files को main page में iframe के through show किया जा सकता है।
Remember:
Frames obsolete हैं, modern HTML में iframe use होता है।

XHTML

XHTML का full form Extensible HyperText Markup Language है। यह HTML और XML का combination है। XHTML HTML की तरह web pages create करने के लिए use होता है, लेकिन इसमें XML जैसी strict rules follow करनी पड़ती हैं।

XHTML में tags properly closed होने चाहिए, tags lowercase में होने चाहिए, attributes quoted होने चाहिए और nesting correct होनी चाहिए। XHTML का purpose cleaner, stricter और well-formed HTML documents बनाना था।

XHTML Rules

  • All tags properly closed होने चाहिए।
  • Tags lowercase में लिखे जाने चाहिए।
  • Attributes values quotes में होनी चाहिए।
  • Tags properly nested होने चाहिए।
  • Empty tags भी closed format में लिखे जाते हैं।

Advantages of XHTML

  • Code clean और strict होता है।
  • Parsing और validation easy होती है।
  • XML tools के साथ compatible हो सकता है।
  • Properly structured documents बनते हैं।

Limitations of XHTML

  • Rules ज्यादा strict होते हैं।
  • Small mistake से document error दे सकता है।
  • Modern HTML5 ने कई practical cases में XHTML को replace कर दिया।
Real Life Example:
XHTML को ऐसे समझो जैसे HTML का strict discipline वाला version, जिसमें हर tag properly closed और formatted होना जरूरी है।
Remember:
XHTML HTML जैसा है, लेकिन XML-style strict rules follow करता है।
