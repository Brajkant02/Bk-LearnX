jQuery Concept

jQuery एक popular और lightweight JavaScript Library है, जिसका उपयोग Web Pages को अधिक Interactive, Dynamic और User-Friendly बनाने के लिए किया जाता है। jQuery JavaScript के कई Common Tasks को आसान बनाती है, जैसे HTML Elements को Select करना, DOM को Manipulate करना, Events Handle करना, Effects Apply करना और AJAX के माध्यम से Server के साथ Communication करना।

JavaScript में किसी HTML Element को Select करने और उसके ऊपर कोई Action Perform करने के लिए कई Lines of Code लिखनी पड़ सकती हैं। jQuery इन्हीं Tasks को कम और सरल Code के माध्यम से पूरा करने की सुविधा देती है। इसी कारण jQuery को JavaScript की Fast, Concise और Easy-to-Use Library माना जाता है।

jQuery का मुख्य उद्देश्य JavaScript को Replace करना नहीं है, बल्कि JavaScript के साथ काम करना आसान बनाना है। jQuery के द्वारा DOM Manipulation, Event Handling, Animation तथा अन्य Client-Side Operations को Simple Syntax में Perform किया जा सकता है।

Exam Point:
jQuery एक lightweight JavaScript Library है, जिसका उपयोग HTML Elements को Select और Manipulate करने, Events Handle करने तथा Web Page पर Effects और Animations Apply करने के लिए किया जाता है।

Definition of jQuery

Definition:
"jQuery एक fast, lightweight और feature-rich JavaScript Library है, जो HTML Document Traversal, DOM Manipulation, Event Handling और Animation जैसे JavaScript Tasks को सरल बनाती है।"

Why jQuery is Used?

Web Development में केवल HTML और CSS का उपयोग करने पर Web Page का Structure और Design तैयार किया जा सकता है, लेकिन Interactive Behaviour के लिए JavaScript की आवश्यकता होती है। JavaScript के साथ होने वाले कई repetitive Tasks को jQuery सरल Syntax में उपलब्ध कराती है।

उदाहरण के लिए यदि किसी HTML Element को Hide करना हो, तो jQuery में केवल एक simple Method का उपयोग किया जा सकता है। 

$("#box").hide();

इसी प्रकार किसी Element को Show करने के लिए: 

$("#box").show();

इससे पता चलता है कि jQuery कई Common JavaScript Operations को छोटे और readable Syntax में Perform करने की सुविधा देती है।

Main Features of jQuery

  • Simple Syntax: jQuery का Syntax JavaScript की तुलना में कई Common Tasks के लिए छोटा और आसान होता है।
  • DOM Manipulation: HTML Elements को Select, Modify, Add और Remove किया जा सकता है।
  • Event Handling: Click, Mouse, Keyboard तथा Form Events को आसानी से Handle किया जा सकता है।
  • Animation and Effects: Hide, Show, Fade और Slide जैसे Effects आसानी से Apply किए जा सकते हैं।
  • Cross-Browser Support: jQuery को अलग-अलग Browsers के साथ काम करने के लिए बनाया गया था, जिससे पुराने समय में Browser Differences को Handle करना आसान हुआ।
  • AJAX Support: Server के साथ Asynchronous Communication के लिए jQuery में AJAX सुविधाएँ उपलब्ध हैं।
  • Chaining: एक ही Element पर कई jQuery Methods को Chain किया जा सकता है।
  • Large Ecosystem: jQuery के लिए Plugins उपलब्ध हैं, जिनका उपयोग अतिरिक्त Features के लिए किया जा सकता है।

Basic Syntax of jQuery

jQuery में किसी HTML Element को Select करके उस पर कोई Method Apply करने के लिए सामान्यतः निम्न Syntax का उपयोग किया जाता है: 

$(selector).method();

यहाँ $ jQuery का मुख्य Function है, selector उस HTML Element को Select करता है जिस पर Action Perform करना है और method() वह Operation है जिसे Element पर Apply किया जाएगा।

Example of Basic jQuery Syntax

$("#heading").hide();

इस Example में #heading एक ID Selector है। jQuery उस ID वाले HTML Element को Select करेगी और hide() Method की सहायता से उसे Hide कर देगी।

The $ Symbol in jQuery

jQuery में $ Symbol बहुत महत्वपूर्ण है। यह jQuery Function का short form है। इसके माध्यम से HTML Elements को Select किया जा सकता है और उन पर jQuery Methods Apply किए जा सकते हैं। 

$("#box");

ऊपर दिया गया Code उस HTML Element को Select करता है जिसकी id="box" है।

$ के स्थान पर jQuery नाम भी लिखा जा सकता है। 

jQuery("#box");

दोनों Statements का उद्देश्य समान है: 

$("#box");

jQuery("#box");

DOM Manipulation using jQuery

jQuery का एक प्रमुख उपयोग DOM Manipulation है। इसकी सहायता से HTML Elements के Text, HTML Content, Attributes और CSS को Dynamically Change किया जा सकता है।

Example

यहाँ text() Method का उपयोग करके Selected Element का Text Change किया गया है।

jQuery में User Actions को Handle करने के लिए विभिन्न Event Methods उपलब्ध हैं। उदाहरण के लिए click(), dblclick(), mouseenter(), mouseleave() और submit() आदि। 

$("#btn").click(function() {

    alert("Button Clicked");

});

  • Hide
  • Show
  • Fade
  • Slide
  • Toggle

Example

$("#box").hide();

$("#box").slideUp();

jQuery Chaining

jQuery की एक महत्वपूर्ण सुविधा Method Chaining है। इसमें एक ही Selected Element पर कई Methods को एक के बाद एक Apply किया जा सकता है। 

$("#box")
    .css("color", "blue")
    .slideUp()
    .slideDown();

यहाँ एक ही Element पर कई Methods को Chain किया गया है। इससे Code को Compact और Readable बनाया जा सकता है।

Adding jQuery to Web Page

jQuery एक JavaScript Library है, इसलिए इसका उपयोग करने से पहले jQuery Library को अपने HTML Web Page में Include करना आवश्यक होता है। jQuery को Web Page में Add करने के बाद ही हम इसके Selectors, Event Methods, Effects तथा अन्य Functions का उपयोग कर सकते हैं।

jQuery को HTML Page में Add करने के लिए सामान्यतः <script> Tag का उपयोग किया जाता है। jQuery Library को दो मुख्य तरीकों से Web Page में Include किया जा सकता है:

  1. Download करके Local File के रूप में Add करना
  2. CDN (Content Delivery Network) का उपयोग करना
Exam Point:
jQuery को HTML Web Page में Include करने के लिए <script> Tag का उपयोग किया जाता है। इसे Local File या CDN के माध्यम से Web Page में Add किया जा सकता है।

Why jQuery Library is Added?

jQuery के Functions और Methods Browser में अपने आप Available नहीं होते। Browser JavaScript को Directly समझता है, लेकिन jQuery के $(), hide(), show(), fadeIn() जैसे jQuery-specific Methods का उपयोग करने के लिए jQuery Library को पहले Load करना पड़ता है।

जब jQuery Library HTML Document में Successfully Load हो जाती है, तब JavaScript Code में jQuery के विभिन्न Methods और Selectors का उपयोग किया जा सकता है।

Method 1: Adding jQuery using CDN

CDN (Content Delivery Network) एक Network of Servers है, जिसकी सहायता से jQuery जैसी Libraries को Internet के माध्यम से सीधे Web Page में Load किया जा सकता है।

CDN Method में jQuery की File को अपने Computer में Download करने की आवश्यकता नहीं होती। HTML Page में jQuery CDN का URL <script> Tag के अंदर दिया जाता है।

Example using CDN

<!DOCTYPE html>

<html>

<head>

    <title>jQuery Example</title>

    <script
        src="https://code.jquery.com/jquery-3.7.1.min.js">
    </script>

</head>

<body>

    <h1>Hello jQuery</h1>

</body>

</html>

इस Example में src Attribute के अंदर jQuery CDN का URL दिया गया है। Browser इस URL से jQuery Library को Load करेगा।

Important:
CDN का उपयोग करने पर jQuery Library Internet से Load होती है। इसलिए यदि CDN उपलब्ध नहीं है या Internet Connection नहीं है, तो External CDN से jQuery Load होने में समस्या हो सकती है।

Method 2: Adding jQuery using Downloaded File

jQuery को Official Source से Download करके अपने Project Folder में भी रखा जा सकता है। इसके बाद HTML Page में उस Local JavaScript File का Path दिया जाता है।

Adding Local jQuery File

<script src="js/jquery.min.js"></script>

Browser इस Path से Local jQuery File को Load करेगा। इसके बाद Page में jQuery के Methods का उपयोग किया जा सकता है।

jQuery Document Ready

jQuery में एक महत्वपूर्ण Concept Document Ready है। इसका उपयोग यह सुनिश्चित करने के लिए किया जाता है कि jQuery Code HTML Document के आवश्यक Elements Load होने के बाद Execute हो।

Syntax

$(document).ready(function() {

    // jQuery Code

});

Example

$(document).ready(function() {

    $("#heading").hide();

});

यहाँ jQuery Code Document Ready होने के बाद Execute होगा।

Short Form of Document Ready

jQuery में Document Ready लिखने का Short Syntax भी उपलब्ध है। 

$(function() {

    $("#heading").hide();

});

यह भी Document Ready Handler के रूप में कार्य करता है।

Position of jQuery Script

jQuery Library को HTML Page में सही स्थान पर Include करना महत्वपूर्ण है। यदि jQuery Code को jQuery Library से पहले Execute किया गया, तो jQuery उपलब्ध न होने के कारण Error आ सकता है।

Correct Order

<script src="jquery.min.js"></script>

<script>

    // jQuery Code

</script>

यहाँ पहले jQuery Library Load हो रही है और उसके बाद jQuery Code Execute हो रहा है।

Incorrect Order

<script>

    $("#heading").hide();

</script>

<script src="jquery.min.js"></script>

इस स्थिति में jQuery Code Library Load होने से पहले Execute हो सकता है, जिससे $ is not defined जैसी समस्या आ सकती है।

Adding jQuery in HTML Head

jQuery Library को HTML Document के <head> Section में भी Include किया जा सकता है। 

<head>

    <script src="jquery.min.js"></script>

</head>

Adding jQuery before Closing Body Tag

jQuery Library को </body> Tag से ठीक पहले भी Include किया जा सकता है। कई Web Pages में JavaScript Files को Body के अंत में Load करने का तरीका अपनाया जाता है ताकि HTML Content पहले Parse हो सके।

    <h1>My Web Page</h1>

    <button id="btn">Click Me</button>

    <script src="jquery.min.js"></script>

    <script src="script.js"></script>

console.log($);

Common Errors while Adding jQuery

  1. jQuery File का गलत Path
    यदि Local jQuery File का Path गलत है, तो Browser File Load नहीं कर पाएगा।
  2. jQuery Library Include नहीं करना
    jQuery Library के बिना $() और अन्य jQuery Methods काम नहीं करेंगे।
  3. Wrong Loading Order
    Custom jQuery Code को Library से पहले Load करने पर Error आ सकता है।
  4. Internet / CDN Problem
    External CDN उपलब्ध न होने पर CDN से jQuery Load नहीं हो पाएगी।
  5. Version Compatibility
    किसी पुराने Project में प्रयुक्त jQuery Version और Plugins के बीच Compatibility समस्या हो सकती है।

jQuery Selectors

jQuery Selectors का उपयोग HTML Web Page के किसी एक या अनेक HTML Elements को Select करने के लिए किया जाता है। jQuery Selector की सहायता से हम किसी Element को उसकी id, class, tag, attribute या अन्य conditions के आधार पर Select कर सकते हैं।

किसी HTML Element पर jQuery का कोई Method जैसे hide(), show(), css(), text(), html() या Event Method Apply करने से पहले उस Element को Select करना आवश्यक होता है। इसलिए jQuery Selectors को jQuery Programming का एक महत्वपूर्ण Fundamental Concept माना जाता है।

jQuery Selectors का Syntax काफी हद तक CSS Selectors जैसा होता है। इसके कारण यदि किसी Student को CSS Selectors की जानकारी है, तो jQuery Selectors को समझना comparatively आसान होता है।

Exam Point:

Definition of jQuery Selector

Definition:
"jQuery Selector वह तरीका है जिसके द्वारा jQuery HTML Document के किसी Element या Elements को उनकी ID, Class, Tag, Attribute या अन्य Selector Conditions के आधार पर Select करती है।"

$(selector);

Example

$("p");

यह Statement सभी matching <p> Elements को Select करता है।

$("tag");

ID Selector किसी specific HTML Element को उसकी unique id के आधार पर Select करता है। jQuery में ID Selector के लिए # Symbol का उपयोग होता है।

Syntax

$("#id");

Example

<h1 id="heading">

    Hello World

</h1>

3. Class Selector

Class Selector का उपयोग उन सभी HTML Elements को Select करने के लिए किया जाता है जिनमें कोई specific class मौजूद हो। jQuery में Class Selector के लिए . Dot Symbol का उपयोग किया जाता है।

Syntax

$(".classname");

Example

4. Universal Selector

Universal Selector का उपयोग HTML Document के सभी Elements को Select करने के लिए किया जाता है। इसके लिए * Symbol का उपयोग होता है।

Example

$("*").css("margin", "0");

यह सभी matching HTML Elements पर दिए गए CSS Style को Apply करेगा।

5. Multiple Selector

Multiple Selector की सहायता से एक ही Statement में कई अलग-अलग Selectors को Select किया जा सकता है। Selectors को Comma , से Separate किया जाता है।

Example

यहाँ सभी h1, h2 और p Elements Select किए जाएंगे।

6. Attribute Selector

Attribute Selector का उपयोग किसी HTML Element को उसके Attribute के आधार पर Select करने के लिए किया जाता है।

Example

$("input[type='text']");

यह उन सभी input Elements को Select करेगा जिनका type="text" है।

यह उन सभी Anchor Elements को Select करेगा जिनमें href Attribute मौजूद है।

7. Descendant Selector

Descendant Selector का उपयोग किसी Parent Element के अंदर मौजूद Descendant Elements को Select करने के लिए किया जाता है।

Example HTML

        <p>Paragraph 2</p>

jQuery

$("#box p").css("color", "blue");

यहाँ #box के अंदर मौजूद सभी p Descendants Select होंगे।

8. Child Selector

Child Selector का उपयोग किसी Parent के Direct Child को Select करने के लिए किया जाता है। इसके लिए > Symbol का उपयोग होता है। 

$("#box > p").css("color", "green");

यह केवल #box के Direct Child <p> Elements को Select करेगा।

9. :first Selector

:first Selector किसी selected collection के पहले matching Element को Select करने के लिए उपयोग किया जाता है। 

$("p:first").css("color", "red");

यहाँ पहला matching Paragraph Select किया जाएगा।

10. :last Selector

:last Selector selected Elements में से अंतिम matching Element को Select करता है। 

$("p:last").css("color", "blue");

11. :even Selector

:even Selector collection में even-indexed Elements को Select करने के लिए उपयोग किया जाता है। jQuery में indexing सामान्यतः 0 से शुरू होती है। 

$("tr:even").css("background", "#eee");

इसका उपयोग Tables में alternate rows को Style करने के लिए किया जा सकता है।

12. :odd Selector

:odd Selector collection में odd-indexed Elements को Select करता है। 

$("tr:odd").css("background", "#f5f5f5");

13. :first-child Selector

$("li:first-child").css("font-weight", "bold");

14. :last-child Selector

:last-child उस Element को Select करता है जो अपने Parent का Last Child है। 

$("li:last-child").css("font-weight", "bold");

15. :contains() Selector

:contains() Selector उन Elements को Select करता है जिनके Text Content में दी गई String मौजूद होती है। 

$("p:contains('JavaScript')");

यह उन Paragraphs को Select करेगा जिनके Text में JavaScript शब्द मौजूद है।

jQuery Event Methods

jQuery Event Methods का उपयोग Web Page पर होने वाले विभिन्न User Actions और Browser Events को Handle करने के लिए किया जाता है। जब User किसी Button पर Click करता है, Mouse को किसी Element पर ले जाता है, Keyboard से Key Press करता है या Form Submit करता है, तब इन Actions को jQuery Event Methods की सहायता से Detect और Handle किया जा सकता है।

jQuery में Event Handling को सरल बनाने के लिए विभिन्न Methods उपलब्ध हैं, जैसे click(), dblclick(), mouseenter(), mouseleave(), mousedown(), mouseup(), keydown(), keyup(), change(), submit(), focus() और blur()।

Event Method के साथ सामान्यतः एक Function दिया जाता है। जब संबंधित Event होता है, तो वह Function Automatically Execute हो जाता है। इस प्रकार jQuery की सहायता से Web Page को Interactive बनाया जा सकता है।

Exam Point:
jQuery Event Methods का उपयोग User या Browser द्वारा किए गए Actions को Detect करके उनके अनुसार JavaScript Function Execute करने के लिए किया जाता है।

Definition of jQuery Event Methods

Definition:
"jQuery Event Methods वे Methods हैं जिनका उपयोग HTML Elements पर होने वाले विभिन्न Events जैसे Click, Mouse Movement, Keyboard Input तथा Form Submission को Handle करने के लिए किया जाता है।"

Basic Syntax of jQuery Event Method

$(selector).event(function() {

    // Code to execute

});

यहाँ selector उस HTML Element को Select करता है जिस पर Event Apply करना है, जबकि event() के स्थान पर संबंधित Event Method लिखा जाता है।

1. click() Event Method

click() Event Method तब Execute होता है जब User किसी HTML Element पर Mouse से Click करता है। यह jQuery में सबसे अधिक उपयोग किए जाने वाले Event Methods में से एक है।

Syntax

$("#btn").click(function() {

    alert("Button Clicked");

});

Example

<button id="btn">

    Click Me

</button>

<script>

$("#btn").click(function() {

    alert("Hello User");

});

</script>

जब User Button पर Click करेगा, तो alert() Function Execute होगा।

2. dblclick() Event Method

dblclick() Method तब Execute होता है जब User किसी HTML Element पर Double Click करता है। 

$("#box").dblclick(function() {

    alert("Double Click Detected");

});

3. mouseenter() Event Method

mouseenter() Method तब Execute होता है जब Mouse Pointer किसी HTML Element के अंदर Enter करता है। 

$("#box").mouseenter(function() {

    $(this).css("background", "lightblue");

});

यहाँ this उस Element को Represent करता है जिस पर Mouse Enter हुआ है।

4. mouseleave() Event Method

mouseleave() Method तब Execute होता है जब Mouse Pointer किसी Element से बाहर चला जाता है। 

$("#box").mouseleave(function() {

    $(this).css("background", "white");

});

5. mousedown() Event Method

mousedown() Method तब Execute होता है जब User किसी HTML Element पर Mouse Button को Press करता है। 

$("#btn").mousedown(function() {

    console.log("Mouse Button Pressed");

});

6. mouseup() Event Method

mouseup() Method तब Execute होता है जब User Mouse Button को Release करता है। 

$("#btn").mouseup(function() {

    console.log("Mouse Button Released");

});

7. mousemove() Event Method

mousemove() Method तब Trigger होता है जब Mouse Pointer किसी Element के अंदर Move करता है। 

$("#box").mousemove(function() {

    console.log("Mouse is Moving");

});

यह Event बार-बार Trigger हो सकता है क्योंकि Mouse की Position लगातार Change होती रहती है।

8. hover() Event Method

hover() Method का उपयोग किसी Element पर Mouse Enter और Mouse Leave दोनों Actions को Handle करने के लिए किया जा सकता है। 

$("#box").hover(

    function() {

        $(this).css("background", "lightblue");

    },

    function() {

        $(this).css("background", "white");

    }

);

पहला Function Mouse के Element पर आने पर Execute होगा, जबकि दूसरा Function Mouse के Element से बाहर जाने पर Execute होगा।

9. keydown() Event Method

keydown() Method तब Execute होता है जब User Keyboard की कोई Key Press करता है। 

$("#username").keydown(function() {

    console.log("Key Pressed");

});

10. keyup() Event Method

keyup() Method तब Execute होता है जब User Keyboard की Pressed Key को Release करता है। 

$("#username").keyup(function() {

    console.log("Key Released");

});

11. keypress() Event Method

पुराने jQuery Code में keypress() Method का उपयोग Keyboard Input को Handle करने के लिए किया जाता था। Modern Web Development में Keyboard Events के लिए keydown() और keyup() को सामान्यतः अधिक उपयुक्त माना जाता है। 

$("#username").keypress(function() {

    console.log("Key Pressed");

});

12. focus() Event Method

focus() Method तब Execute होता है जब User किसी Input Field या Form Element पर Focus करता है। उदाहरण के लिए User जब किसी Text Box में Click करके Typing शुरू करने के लिए उसे Active करता है। 

$("#username").focus(function() {

    $(this).css("background", "lightyellow");

});

13. blur() Event Method

blur() Method तब Execute होता है जब किसी Input Element का Focus समाप्त हो जाता है। यानी User उस Input Field से बाहर चला जाता है। 

$("#username").blur(function() {

    $(this).css("background", "white");

});

14. change() Event Method

change() Method का उपयोग Form Element की Value Change होने पर Action Perform करने के लिए किया जाता है। इसका उपयोग विशेष रूप से Select Box, Checkbox और Input Fields के साथ किया जा सकता है। 

$("#course").change(function() {

    alert("Course Changed");

});

15. submit() Event Method

submit() Method तब Execute होता है जब कोई HTML Form Submit किया जाता है। इसका उपयोग Form Validation और Form Submission को Handle करने के लिए किया जाता है। 

$("#loginForm").submit(function(event) {

    event.preventDefault();

    alert("Form Submitted");

});

यहाँ event.preventDefault() का उपयोग Browser के Default Form Submission को रोकने के लिए किया गया है।

16. focusin() Event Method

focusin() Method तब Trigger होता है जब कोई Element या उसके अंदर मौजूद Element Focus प्राप्त करता है। 

$("#form").focusin(function() {

    console.log("Form Element Focused");

});

17. focusout() Event Method

focusout() Method तब Trigger होता है जब किसी Element या उसके अंदर मौजूद Element का Focus समाप्त होता है। 

$("#form").focusout(function() {

    console.log("Focus Removed");

jQuery Fade Effects

jQuery Fade Effects का उपयोग HTML Elements को धीरे-धीरे Show या Hide करने के लिए किया जाता है। Fade Effect में किसी Element की Opacity धीरे-धीरे Change होती है, जिससे Element अचानक दिखाई देने या गायब होने के बजाय Smooth तरीके से Visible या Invisible होता है।

jQuery में Fade Effects का उपयोग Websites को अधिक Interactive और User-Friendly बनाने के लिए किया जाता है। इसका उपयोग Images, Messages, Notifications, Menus, Product Information, Login Forms तथा अन्य Web Elements में किया जा सकता है।

jQuery में मुख्य रूप से चार Fade Methods उपलब्ध हैं: fadeIn(), fadeOut(), fadeToggle() और fadeTo()। इन सभी Methods का कार्य Element की Opacity को धीरे-धीरे Change करना है, लेकिन प्रत्येक Method का उपयोग अलग परिस्थिति में किया जाता है।

jQuery Slide Effects

jQuery Slide Effects का उपयोग HTML Elements को Vertical Direction में धीरे-धीरे Show या Hide करने के लिए किया जाता है। इसमें Element एक Sliding Animation के साथ दिखाई देता है या छिप जाता है।

Slide Effects विशेष रूप से Navigation Menu, Dropdown Menu, FAQ Sections, Accordion, Sidebar तथा अन्य Interactive Web Components में उपयोग किए जाते हैं। jQuery में Slide Effect के लिए मुख्य रूप से slideDown(), slideUp() और slideToggle() Methods उपलब्ध हैं।

Exam Point:
jQuery Slide Effects का उपयोग HTML Elements को Sliding Animation के साथ Show और Hide करने के लिए किया जाता है। इसके मुख्य Methods slideDown(), slideUp() और slideToggle() हैं।

Definition of Slide Effects

Definition:
"jQuery Slide Effects वे Built-in Effects हैं जिनकी सहायता से HTML Elements को Vertical Sliding Animation के माध्यम से धीरे-धीरे Show या Hide किया जाता है।"

Types of jQuery Slide Effects

  1. slideDown() – Hidden Element को Slide करके Show करता है।
  2. slideUp() – Visible Element को Slide करके Hide करता है।
  3. slideToggle() – slideUp() और slideDown() दोनों को Toggle करता है।

1. slideDown() Method

slideDown() Method का उपयोग किसी Hidden HTML Element को ऊपर से नीचे की ओर Sliding Animation के साथ Show करने के लिए किया जाता है।

जब कोई Element पहले से Hidden होता है, तो slideDown() उसे धीरे-धीरे नीचे की दिशा में Expand करते हुए Visible करता है।

Syntax

$(selector).slideDown();

Speed और Callback के साथ: 

$(selector).slideDown(speed, callback);

Simple Example

$("#box").slideDown();

यहाँ #box ID वाले Hidden Element को Sliding Animation के साथ Show किया जाएगा।

slideDown() with Speed

slideDown() Method में Speed Parameter देकर Animation की Duration को Control किया जा सकता है। 

$("#box").slideDown(1000);

यहाँ 1000 milliseconds अर्थात लगभग 1 second में Element Slide होकर दिखाई देगा।

Predefined Speed Values भी उपयोग की जा सकती हैं: 

$("#box").slideDown("slow");

$("#box").slideDown("fast");

Practical Example

<button id="openBtn">

    Open Content

</button>

    This is sliding content.

</div>

<script>

$("#openBtn").click(function() {

});

</script>

जब User Open Content Button पर Click करेगा, तो Hidden Content नीचे की ओर Slide होकर दिखाई देगा।

2. slideUp() Method

slideUp() Method का उपयोग किसी Visible HTML Element को नीचे से ऊपर की ओर Sliding Animation के साथ Hide करने के लिए किया जाता है।

इस Method में Element धीरे-धीरे अपनी Height को कम करता है और अंत में Hidden हो जाता है।

Syntax

$(selector).slideUp();

Speed और Callback के साथ: 

$(selector).slideUp(speed, callback);

Simple Example

$("#box").slideUp();

यहाँ #box Element Sliding Animation के साथ Hide हो जाएगा।

slideUp() with Speed

यहाँ Element लगभग 1 second में Slide होकर Hide होगा।

Practical Example

Button पर Click करने के बाद Content ऊपर की दिशा में Slide होकर Hide हो जाएगा।

3. slideToggle() Method

slideToggle() Method का उपयोग slideDown() और slideUp() दोनों Operations को एक ही Method के माध्यम से Perform करने के लिए किया जाता है।

यदि Element Hidden है, तो slideToggle() उसे Slide Down करके Show करेगा। यदि Element पहले से Visible है, तो यही Method उसे Slide Up करके Hide करेगा।

Syntax

$(selector).slideToggle();

Speed के साथ: 

$(selector).slideToggle(speed);

Simple Example

$("#box").slideToggle();

Practical Example

    Open / Close

</button>

<div id="box">

Button पर प्रत्येक Click के साथ Box Slide होकर Open और Close होगा।

9. Using Callback with load()

jQuery load() Method के साथ Callback Function का उपयोग भी किया जा सकता है। Callback Function तब Execute होता है जब Loading Process Complete हो जाता है। 

$("#header").load("header.html", function() {

    console.log("Header Loaded Successfully");

});

इस Example में header.html Load होने के बाद Callback Function Execute होगा।

10. Loading Header and Footer with Error Handling

यदि External File उपलब्ध नहीं है या उसका Path गलत है, तो Loading में Problem आ सकती है। ऐसी Situation को Handle करने के लिए Callback के साथ Response Status Check किया जा सकता है। 

$("#header").load("header.html", function(response, status) {

    if (status === "success") {

        console.log("Header Loaded");

    } else {

        console.log("Unable to Load Header");

    }

});

यहाँ status के द्वारा यह Check किया जा सकता है कि File Successfully Load हुई है या नहीं।

11. Loading Header and Footer on Multiple Pages

यदि Website में कई Pages हैं, तो प्रत्येक Page में केवल Header और Footer के Containers तथा Loading Script रखा जा सकता है। इससे Common Header और Footer सभी Pages पर Reuse हो जाते हैं। 

index.html
about.html
services.html
contact.html
courses.html

इन सभी Pages में समान Code का उपयोग करके: 

$("#header").load("header.html");

$("#footer").load("footer.html");

Header और Footer को Dynamically Insert किया जा सकता है।

12. Using Header and Footer from a Folder

बड़े Projects में Header और Footer को अलग Folder में रखा जा सकता है। उदाहरण: 

project/
│
├── pages/
│   ├── index.html
│   └── about.html
│
├── components/
│   ├── header.html
│   └── footer.html
│
└── js/
    └── script.js

यदि HTML Page pages Folder के अंदर है और Header तथा Footer components Folder में हैं, तो Relative Path का सही उपयोग करना आवश्यक होगा। 

$("#header").load("../components/header.html");

$("#footer").load("../components/footer.html");

यहाँ ../ का उपयोग एक Directory पीछे जाने के लिए किया गया है।

13. Reusable Header and Footer

Header और Footer को अलग Files में रखने का सबसे बड़ा लाभ Reusability है। एक ही Header File को Website के कई Pages में उपयोग किया जा सकता है।

उदाहरण के लिए यदि Header में Navigation Menu में Home, About, Courses और Contact Links हैं, तो इन Links को केवल header.html में Maintain करना होगा।

यदि भविष्य में कोई नया Navigation Link Add करना हो, तो केवल Header File को Update करने से सभी संबंधित Pages पर नया Link उपलब्ध कराया जा सकता है।

14. Advantages of Header/Footer Insertion using jQuery

  1. Code Reusability
    Header और Footer को कई HTML Pages पर Reuse किया जा सकता है।
  2. Less Code Duplication
    एक ही Header और Footer को हर Page पर दोबारा लिखने की आवश्यकता नहीं होती।
  3. Easy Maintenance
    Common Content में Change करने के लिए केवल एक File Update करनी पड़ती है।
  4. Consistent Layout
    सभी Pages पर समान Header और Footer दिखाई देता है।
  5. Modular Structure
    Website को छोटे और Reusable Components में Divide किया जा सकता है।
  6. Development Time Saving
    बार-बार समान HTML Code लिखने की आवश्यकता कम हो जाती है।

15. Limitations of jQuery Header/Footer Loading

  1. jQuery Dependency
    इस Method के लिए jQuery Library की आवश्यकता होती है।
  2. Path Problem
    External HTML File का गलत Path होने पर Content Load नहीं होगा।
  3. Server Environment
    कुछ परिस्थितियों में Local File System से External File Load करते समय Browser Security Restrictions आ सकती हैं।
  4. Loading Dependency
    Header और Footer के लिए अलग Files Load होने के कारण Page Rendering में अतिरिक्त Request हो सकती है।
  5. JavaScript Required
    यदि JavaScript Disabled है, तो Dynamically Loaded Header और Footer दिखाई नहीं दे सकते।
