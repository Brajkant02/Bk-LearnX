Web Development Introduction

Internet

Internet दुनिया भर के computers, servers, mobile devices और networks का एक बहुत बड़ा global network है। Internet की help से एक device दूसरे device से data exchange कर सकता है। यह communication TCP/IP protocols के through होता है। Internet को “network of networks” भी कहा जाता है क्योंकि यह कई छोटे-बड़े networks को आपस में connect करता है।

Internet केवल websites देखने तक limited नहीं है। इसका use email, online classes, video calling, online banking, social media, cloud storage, online shopping, gaming, file sharing और many digital services के लिए किया जाता है। जब user browser में कोई website open करता है, तो उसका device internet के through server से data request करता है और server response के रूप में webpage भेजता है।

Main Features

  • यह worldwide communication system provide करता है।
  • Data को fast transfer करने में help करता है।
  • Information sharing को easy बनाता है।
  • Online services जैसे email, banking, education और business को support करता है।
  • Different devices और networks को connect करता है।

Common Uses

Use Example
Communication Email, WhatsApp, video call
Education Online classes, e-learning websites
Business E-commerce, online payment
Entertainment YouTube, OTT, online games
Information Search engines, news websites
Real Life Example:
जब आप Google पर कोई topic search करते हैं, तो आपका mobile internet के through Google server से connect होता है और result screen पर दिखता है।
Remember:
Internet एक global network है, जबकि website internet पर available एक service या collection of web pages हो सकती है।

WWW

WWW का full form World Wide Web है। यह internet पर available web pages और websites का interconnected system है। WWW की help से user web browser में URLs type करके web pages access कर सकता है। Web pages आपस में hyperlinks के through connected होते हैं।

WWW internet का एक service part है। Internet physical और logical network है, जबकि WWW उस network पर चलने वाली information system है। WWW में HTML documents, images, videos, CSS files, JavaScript files और other resources शामिल हो सकते हैं। User browser की help से इन resources को view करता है।

WWW कैसे काम करता है

  1. User browser में URL type करता है।
  2. Browser server को request भेजता है।
  3. Server requested webpage या resource browser को send करता है।
  4. Browser HTML, CSS और JavaScript को process करके webpage display करता है।

WWW के Components

Component Work
Web Browser Web pages display करता है।
Web Server Web pages store और deliver करता है।
URL Web resource का address बताता है।
HTTP/HTTPS Browser और server के बीच communication protocol है।
HTML Web page structure बनाता है।

Internet vs WWW

Basis Internet WWW
Meaning Global network of networks। Internet पर web pages का system।
Scope Broad concept। Internet की एक service।
Use Email, FTP, WWW, chat आदि। Websites और web pages access करना।
Real Life Example:
Internet road की तरह है और WWW उस road पर चलने वाली web information service की तरह है।
Remember:
WWW और Internet same नहीं हैं। WWW internet पर चलने वाली एक major service है।

Browser

Browser एक software application है जिसकी help से user websites और web pages access कर सकता है। Browser URL के through server से webpage request करता है और received HTML, CSS, JavaScript, images और other resources को process करके user को visual form में दिखाता है।

Browser user और web server के बीच interface की तरह काम करता है। जब user कोई website open करता है, तो browser HTTP/HTTPS protocol के through server से communication करता है। फिर browser page का layout render करता है, CSS apply करता है और JavaScript execute करता है।

Popular Browsers

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Browser के Main Functions

Function Work
URL Processing User द्वारा entered web address को process करता है।
Rendering HTML और CSS को visual webpage में convert करता है।
JavaScript Execution Page की interactivity run करता है।
Security HTTPS, certificates और privacy features handle करता है।
Developer Tools Developers को debugging और inspection tools देता है।

Browser Rendering Process

  1. Browser server से HTML receive करता है।
  2. HTML structure को DOM में convert करता है।
  3. CSS styles apply करता है।
  4. JavaScript execute करता है।
  5. Final webpage screen पर display करता है।
Real Life Example:
जब आप google.com browser में type करते हैं, तो browser Google server से page मांगता है और search page screen पर दिखाता है।
Remember:
Browser web pages को download करके readable और visual form में show करता है।

Search Engine

Search Engine एक web-based service है जो internet पर available information को search करने में help करती है। User search box में keyword type करता है और search engine related websites, images, videos, news और other results show करता है।

Search engine websites को crawl, index और rank करता है। Crawling में search engine bots web pages visit करते हैं। Indexing में pages की information database में store की जाती है। Ranking में user query के according सबसे relevant results ऊपर दिखाए जाते हैं।

Popular Search Engines

  • Google
  • Bing
  • Yahoo
  • DuckDuckGo
  • Yandex

Working Process

Step Meaning
Crawling Bots web pages visit करते हैं।
Indexing Web page data search engine database में store होता है।
Ranking Relevant pages को order में show किया जाता है।
Result Display User को search results दिखते हैं।

Browser vs Search Engine

Basis Browser Search Engine
Type Software application। Web-based service।
Use Website open करने के लिए। Websites/information search करने के लिए।
Example Chrome, Firefox, Edge। Google, Bing, Yahoo।
Real Life Example:
Chrome browser है, जबकि Google search engine है। Chrome में Google open करके information search की जाती है।
Remember:
Browser और search engine अलग चीजें हैं। Browser website खोलता है, search engine website खोजता है।

Client Server Model

Client Server Model एक network model है जिसमें client request भेजता है और server response देता है। Web development में browser usually client होता है और web server requested web pages या data provide करता है।

जब user browser में URL type करता है, तो browser server को HTTP/HTTPS request भेजता है। Server उस request को process करता है और response के रूप में HTML page, CSS, JavaScript, image या data भेजता है। यह पूरा process client-server communication कहलाता है।

Client

Client वह device या software है जो request send करता है। Web browsing में browser client की तरह काम करता है।

Server

Server वह computer या software system है जो resources store करता है और client की request पर response देता है।

Working Example

  1. User browser में example.com type करता है।
  2. Browser server को request send करता है।
  3. Server requested page find करता है।
  4. Server response browser को send करता है।
  5. Browser page display करता है।

Client vs Server

Basis Client Server
Role Request send करता है। Response send करता है।
Example Browser, mobile app। Web server, database server।
Data Data मांगता है। Data provide करता है।
User Side User device पर होता है। Remote machine पर हो सकता है।

Simple Diagram

Client Browser  ---- Request ---->  Web Server
Client Browser  <--- Response ----  Web Server
Real Life Example:
Restaurant में customer order देता है और kitchen food provide करता है। इसी तरह client request करता है और server response देता है।
Remember:
Web browsing में browser client होता है और website host करने वाला computer server होता है।

URL

URL का full form Uniform Resource Locator है। URL internet पर किसी web resource का address होता है। Browser URL की help से यह पता लगाता है कि कौन-सा resource किस server से access करना है।

URL में protocol, domain name, path, query string और fragment जैसे parts हो सकते हैं। हर URL का purpose specific web page, image, file या service को locate करना होता है।

Example URL

https://www.example.com/course/python.html?id=10#intro

Parts of URL

Part Example Meaning
Protocol https Communication method बताता है।
Domain www.example.com Website/server का name।
Path /course/python.html Server पर resource की location।
Query String ?id=10 Extra data send करने के लिए।
Fragment #intro Page के specific section पर जाने के लिए।

HTTP vs HTTPS

Basis HTTP HTTPS
Security Less secure। Secure, encrypted।
Use Old/simple websites। Banking, login, modern websites।
Full Form HyperText Transfer Protocol HyperText Transfer Protocol Secure

Absolute and Relative URL

Absolute URL complete address होता है, जबकि relative URL current page के relation में resource location बताता है।

Absolute URL:
https://example.com/images/logo.png

Relative URL:
images/logo.png
Real Life Example:
जैसे घर का complete address किसी व्यक्ति को location बताता है, वैसे ही URL browser को web resource की location बताता है।
Remember:
URL web resource का address होता है। HTTPS secure communication के लिए use होता है।

Web Pages

Web Page एक document होता है जो browser में display होता है। Web page usually HTML से बनाया जाता है और उसकी styling CSS से की जाती है। JavaScript का use web page को interactive बनाने के लिए किया जाता है।

Web page में text, images, videos, links, forms, tables, buttons और other elements हो सकते हैं। हर web page का अपना URL हो सकता है। Web pages static भी हो सकते हैं और dynamic भी।

Basic Web Page Structure

<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
</head>
<body>
  <h1>Welcome</h1>
  <p>This is my first web page.</p>
</body>
</html>

Main Technologies

Technology Work
HTML Web page structure बनाता है।
CSS Design और layout बनाता है।
JavaScript Interactivity add करता है।

Types of Web Pages

  • Static Web Page: Same content show करता है।
  • Dynamic Web Page: User, database या server response के according content change कर सकता है।

Web Page Elements

  • Headings
  • Paragraphs
  • Images
  • Links
  • Forms
  • Tables
  • Buttons

BK LearnX website का एक chapter page एक web page है जिसमें heading, notes, examples और navigation links होते हैं।

Website and Web Services

Website related web pages का collection होता है जो एक domain name के under available होता है। Website में home page, about page, contact page, course pages, login page आदि हो सकते हैं। Website का purpose information provide करना, service देना, product sell करना या user interaction कराना हो सकता है।

Web Service ऐसी service होती है जो internet के through applications को data या functionality provide करती है। Web services usually APIs के रूप में काम करती हैं। वे user को direct visual page न भी दिखाएँ, लेकिन applications के बीच data exchange कराती हैं।

Website Example

  • E-commerce website
  • News website
  • Portfolio website
  • Government website

Web Service Example

  • Payment gateway API
  • Login authentication service

Types of Websites

Websites को उनके behavior और design के basis पर अलग-अलग types में divide किया जा सकता है। इस chapter में मुख्य रूप से static, dynamic और responsive websites important हैं।

Static Website

Static website में content fixed होता है। हर user को same content show होता है। Static websites mostly HTML, CSS और basic JavaScript से बनाई जाती हैं। इनमें server-side processing या database connection usually नहीं होता।

Example:
College notice page
Portfolio page
Simple company information page

Dynamic Website

Dynamic website में content user, database, login status या server logic के according change हो सकता है। इसमें backend technologies और database का use होता है। Dynamic websites user interaction और real-time data handle कर सकती हैं।

Example:
Facebook
Online banking website
E-commerce website
Student login portal

Responsive Website

Responsive website ऐसी website होती है जो different screen sizes पर properly adjust हो जाती है। यानी mobile, tablet, laptop और desktop सभी devices पर layout readable और usable रहता है। Responsive design के लिए CSS media queries, flexible layout, percentage width, grid और flexbox का use किया जाता है।

Comparison Table

Type Meaning Technology Example
Static Website Fixed content show करती है। HTML, CSS Portfolio, notice page
Dynamic Website Content database/user के according change होता है। Backend + Database Login portal, e-commerce
Responsive Website Different screen sizes पर adjust होती है। CSS media queries, flexbox, grid Modern websites

Responsive CSS Example

@media (max-width: 768px) {
  .container {
    width: 100%;
    padding: 10px;
  }
}

Static vs Dynamic Website

Basis Static Dynamic

Database Usually नहीं होता। Usually होता है।
Speed Generally fast। Processing के कारण थोड़ा complex।
Example Simple info website। Shopping website।
Real Life Example:
आपका BK LearnX frontend notes page static हो सकता है, लेकिन login, progress tracking और dashboard add करने पर website dynamic बन जाएगी।
Remember:
Responsive website device के हिसाब से layout adjust करती है। आजकल almost हर modern website responsive होनी चाहिए।

Developer Options of Browser

Browser developer options या developer tools web developers के लिए बहुत useful tools होते हैं। इनकी help से developer web page का HTML, CSS, JavaScript, network requests, console errors, responsive design और performance inspect कर सकता है।

Developer tools usually browser में right click करके Inspect option से open किए जाते हैं। Keyboard shortcut भी use किया जा सकता है, जैसे Chrome और Edge में F12 या Ctrl + Shift + I.

View Page Source

View Page Source option webpage का original HTML source code show करता है जो server से browser को मिला होता है। इससे user page का raw HTML देख सकता है।

Shortcut:
Ctrl + U

Inspect Element

Inspect Element से किसी specific element का HTML और CSS inspect किया जा सकता है। Developer live CSS changes test कर सकता है, element size देख सकता है और layout issue debug कर सकता है।

Developer Tools Panels

Panel Use
Elements HTML और CSS inspect/edit करने के लिए।
Console JavaScript errors और logs देखने के लिए।
Network Requests, responses और loading files देखने के लिए।
Sources JavaScript files debug करने के लिए।
Application Storage, cookies, localStorage check करने के लिए।
Lighthouse Performance, accessibility और SEO report के लिए।

Inspect Element Steps

  1. Webpage open करें।
  2. किसी element पर right click करें।
  3. Inspect option select करें।
  4. Elements panel में HTML और CSS देखें।
  5. CSS temporarily edit करके design test करें।

Console Example

Console में JavaScript code directly test किया जा सकता है।

console.log("Hello Developer Tools");

Responsive Mode

Developer tools में device toolbar से website को mobile, tablet और desktop screen sizes पर test किया जा सकता है। इससे responsive design check करने में help मिलती है।

Shortcut:
Ctrl + Shift + M

View Page Source vs Inspect Element

Basis View Page Source Inspect Element
Content Original HTML source show करता है। Current DOM और CSS show करता है।
Edit Edit नहीं कर सकते। Temporary edit कर सकते हैं।
Use Raw HTML देखने के लिए। Debugging और design testing के लिए।

Important Uses for Developers

  • HTML structure check करना।
  • CSS design problem debug करना।
  • JavaScript errors देखना।
  • Network request और file loading check करना।
  • Responsive design test करना।
  • Website performance और accessibility check करना।
Real Life Example:
अगर किसी webpage में button सही position पर नहीं दिख रहा, तो Inspect Element से उसकी CSS properties check करके problem find की जा सकती है।
Remember:
Developer Tools browser के अंदर built-in debugging lab की तरह हैं। Web development सीखने वाले हर student को Inspect, Console और Network panel जरूर समझना चाहिए।
