1. Introduction to MS PowerPoint

MS PowerPoint एक presentation software है जिसका उपयोग information, ideas और data को slides के रूप में visually present करने के लिए किया जाता है। इसमें text, pictures, shapes, charts, audio, video, transitions और animations को शामिल करके प्रभावी presentation बनाई जा सकती है।

Presentation

Related slides का organized collection, जिसे किसी topic या idea को audience के सामने प्रस्तुत करने के लिए बनाया जाता है।

Slide

Presentation का एक individual page/screen, जिस पर text, images, objects और media रखे जाते हैं।

Template

Pre-designed presentation layout जिसमें design, colors, fonts और formatting पहले से निर्धारित हो सकती है।

Slide Show

Presentation को full-screen sequence में audience के सामने चलाने की प्रक्रिया।

Exam Definition: MS PowerPoint is a presentation program used to create, format and deliver slide-based presentations containing text, graphics, multimedia and visual effects.

2. Creating a Presentation

नई presentation blank presentation या available template/theme से बनाई जा सकती है।

  1. MS PowerPoint open करें।
  2. New option चुनें।
  3. Blank Presentation या required template select करें।
  4. Title slide पर presentation title और subtitle enter करें।
  5. New Slide से additional slides add करें।
  6. Required text, images, shapes और other objects insert करें।
PowerPoint → New → Blank/Template → Title Slide → New Slides → Content → Design → Save

3. Opening and Saving Presentations

Opening an Existing Presentation

  1. PowerPoint open करें।
  2. File → Open चुनें या Ctrl + O दबाएँ।
  3. Presentation file location पर जाएँ।
  4. File select करके Open करें।

Saving a Presentation

  1. File → Save या Ctrl + S दबाएँ।
  2. Location select करें।
  3. File name enter करें।
  4. Save करें।
Save As: Presentation की अलग copy, नया name, location या supported format में save करने के लिए Save As उपयोग किया जाता है।

5. Working with Slides

Slides presentation की basic units हैं। उन्हें insert, duplicate, delete, move और rearrange किया जा सकता है।

New Slide

  1. Home → New Slide चुनें।
  2. Required layout select करें।

Duplicate Slide

  1. Slide select करें।
  2. Duplicate option use करें या suitable shortcut/menu command चुनें।

Delete Slide

  1. Slide thumbnail select करें।
  2. Delete command use करें।

Rearrange Slides

Slide Sorter या thumbnail pane में slide को drag करके उसका order बदला जा सकता है।

6. Adding and Formatting Text

PowerPoint में text को placeholders, text boxes और other text-containing objects में add किया जा सकता है।

Adding Text

  1. Text placeholder या Text Box select करें।
  2. Required text type करें।
  3. Text select करके formatting apply करें।

Text Formatting

  • Font family और font size बदलना।
  • Bold, Italic और Underline apply करना।
  • Font color बदलना।
  • Text alignment set करना।
  • Text box का size और position adjust करना।

8. Checking Spelling and Correcting Typing Mistakes

PowerPoint में spelling mistakes identify और correct करने के लिए spelling checker का उपयोग किया जा सकता है।

  1. Presentation open करें।
  2. Review tab पर जाएँ।
  3. Spelling command select करें।
  4. Suggested correction को review करें।
  5. Correct/change/ignore option आवश्यकता के अनुसार चुनें।

Manual Correction

Typing mistake को directly select करके correct text type किया जा सकता है।

Notes Pages

Notes Pages में presenter के लिए additional information, explanation, speaking points या reminders लिखे जा सकते हैं। ये notes audience को दिखाने के बजाय presenter की सहायता के लिए होते हैं।

Handouts

Handouts presentation की slides को audience के लिए printed/reference material के रूप में उपलब्ध कराने में उपयोगी होते हैं।

Slide Content → Handout → Audience Reference

11. Adding Clip Art and Other Pictures

Images presentation को visually attractive और understandable बनाने में मदद करती हैं। PowerPoint में pictures को computer/device से insert किया जा सकता है और उपलब्ध graphic resources का उपयोग किया जा सकता है।

  1. Insert → Pictures option खोलें।
  2. Image source/location select करें।
  3. Required picture choose करें।
  4. Insert करें।
  5. Picture को resize, crop, position और format करें।
Images को slide के topic से relevant रखें और बहुत अधिक images से slide को cluttered न करें।

12. Designing Slide Shows Using Templates

Template एक pre-designed presentation structure है जो presentation के visual design को consistent बनाने में मदद करता है।

Template/Theme Apply करने के Steps

  1. Presentation open करें।
  2. Design tab पर जाएँ।
  3. Available theme/template select करें।
  4. Variants या design options से suitable appearance choose करें।
  5. Slides को review करें।

Advantages

  • Designing time कम होता है।
  • Slides में consistency रहती है।
  • Professional appearance बनाने में मदद मिलती है।
  • Colors और typography को organized रखने में सहायता मिलती है।

13. Rehearse Timing

Rehearse Timing presentation practice करते समय प्रत्येक slide पर कितना समय लग रहा है, इसे record करने के लिए उपयोग किया जाता है। इससे presentation की total timing manage की जा सकती है।

  1. Slide Show/related presentation tools में rehearsal timing option open करें।
  2. Presentation को practice mode में चलाएँ।
  3. हर slide पर बोलने/समझाने के लिए required time लें।
  4. Timing record/save करें।
  5. Recorded timings का उपयोग automatic slide progression के लिए किया जा सकता है।

14. Narration

Narration presentation slides के साथ recorded voice/speaker explanation जोड़ने की प्रक्रिया है। यह self-running presentations, training material और instructional presentations में उपयोगी हो सकती है।

General Process

  1. Presentation और required slide open करें।
  2. Recording/Narration option start करें।
  3. Microphone से explanation record करें।
  4. Recording review करें।
  5. Required होने पर re-record करें और save करें।

15. Applying Transitions Between Slides

Transition वह visual effect है जो एक slide से दूसरी slide पर जाते समय दिखाई देता है। यह slide-level effect होता है।

Steps

  1. Required slide select करें।
  2. Transitions tab open करें।
  3. Transition effect select करें।
  4. Duration जैसी timing settings adjust करें।
  5. यदि सभी slides पर same transition चाहिए तो appropriate apply-to-all option use करें।
Transition vs Animation: Transition slides के बीच होता है, जबकि Animation slide के अंदर मौजूद object/content पर apply किया जाता है।

16. Animating Slide Content

Animation slide के अंदर text, picture, shape या अन्य object पर लगाया जाने वाला visual effect है।

Types of Animation Effects

TypePurpose
EntranceObject को slide पर आने का effect देना।
EmphasisExisting object को highlight/move आदि effect देना।
ExitObject को slide से बाहर जाने का effect देना।
Motion PathObject को defined path पर move करना।

Steps

  1. Object select करें।
  2. Animations tab open करें।
  3. Required animation choose करें।
  4. Effect options और timing adjust करें।
  5. Preview करके result check करें।

17. Set Timing for Transitions and Animations

Timing settings यह निर्धारित करती हैं कि transition या animation कब start होगा और कितनी देर चलेगा।

SettingMeaning
DurationEffect कितने समय में complete होगा।
StartAnimation कब शुरू होगी, जैसे click के साथ या previous effect के बाद।
DelayEffect शुरू होने से पहले wait time.
Select Effect → Set Start → Set Delay → Set Duration → Preview → Adjust

18. Insert and Format Media

Multimedia effects presentation को अधिक engaging बना सकते हैं। PowerPoint में audio और video जैसे media elements add किए जा सकते हैं।

Media Insertion

  1. Required slide select करें।
  2. Insert tab में media options open करें।
  3. Audio या Video source select करें।
  4. Media file choose करके insert करें।
  5. Playback और formatting options adjust करें।

Media Formatting

  • Size और position change करना।
  • Video/audio playback settings adjust करना।
  • Required section को trim/edit करना, यदि supported हो।
  • Start behavior और presentation playback behavior set करना।

19. Encrypting Presentations with a Password

Password protection presentation को unauthorized access से बचाने में सहायता करती है।

  1. File menu open करें।
  2. Presentation information/protection options open करें।
  3. Password protection/encryption option select करें।
  4. Strong password enter करें।
  5. Password confirm करें।
  6. Presentation save करें।
Important: Password को सुरक्षित रखें। Password भूल जाने पर protected file तक access प्रभावित हो सकता है।

20. Running and Controlling a Slide Show

Presentation को audience के सामने display करने के लिए Slide Show mode का उपयोग किया जाता है।

Run Slide Show

  1. Presentation open करें।
  2. Slide Show option select करें।
  3. From Beginning या appropriate starting slide चुनें।
  4. Slides को click/keyboard/automatic timing के अनुसार आगे बढ़ाएँ।

Controlling the Slide Show

  • Next slide पर जाना।
  • Previous slide पर वापस जाना।
  • Specific slide पर jump करना।
  • Pointer/annotation tools का उपयोग करना, जहाँ उपलब्ध हों।
  • Slide show को exit करना।
Common keyboard controls: Arrow keys से navigation, Esc से slide show exit किया जा सकता है।

21. Printing Presentations

PowerPoint presentation को print करते समय slides, notes pages या handouts जैसे output formats उपयोग किए जा सकते हैं, उपलब्ध print settings के अनुसार।

  1. File → Print या Ctrl + P दबाएँ।
  2. Printer select करें।
  3. Copies और required pages select करें।
  4. Print layout में required output type choose करें।
  5. Color/grayscale और page settings check करें।
  6. Print Preview में output review करें।
  7. Print click करें।
