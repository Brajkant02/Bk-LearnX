Introduction to Word Processing

Word Processing computer software की सहायता से text documents को create, edit, format, store और print करने की प्रक्रिया है। MS Word एक popular word processing application है जिसका उपयोग letters, applications, reports, assignments, resumes और अन्य documents बनाने के लिए किया जाता है।

Text Editing

Text add, delete, copy, move और modify किया जा सकता है।

Formatting

Font, size, color, alignment और spacing बदल सकते हैं।

Tables

Information को rows और columns में organize किया जा सकता है।

Graphics

Pictures, shapes और charts insert किए जा सकते हैं।

Exam Definition: Word Processing is the process of creating, editing, formatting, storing and printing text documents using computer software.

Creating a Document

MS Word में नया document blank document या template की सहायता से बनाया जा सकता है।

  1. Microsoft Word open करें।
  2. File → New पर जाएँ।
  3. Blank Document select करें।
  4. Text type करें।
  5. Required formatting apply करें।
  6. Document save करें।
MS Word → File → New → Blank Document → Type → Format → Save

Saving a Document

Save command document को storage में file के रूप में सुरक्षित करती है। पहली बार save करते समय file name और location चुननी होती है।

  1. File → Save या Ctrl + S दबाएँ।
  2. Location select करें।
  3. File name enter करें।
  4. Required format select करें, यदि आवश्यक हो।
  5. Save click करें।
SaveSave As
Current document के changes save करता है।Document को नए name/location/format में अलग copy के रूप में save करने के लिए।

Opening and Closing an Existing Document

Open

  1. File → Open या Ctrl + O दबाएँ।
  2. File location पर जाएँ।
  3. Required document select करें।
  4. Open click करें।

Close

  1. Pending changes हों तो save करें।
  2. File → Close select करें।

Using Featured Word Templates

Template एक pre-designed document format है जिसमें layout, styles और placeholders पहले से configured हो सकते हैं। इससे document बनाने का समय कम होता है।

  • Resume/CV
  • Letter
  • Report
  • Certificate
  • Business documents
  • Planner/Calendar
  1. File → New open करें।
  2. Featured templates browse/search करें।
  3. Template select करें।
  4. Create click करें।
  5. Placeholder text replace करके document save करें।

Exploring Templates and Formatting of Documents

Template को अपने requirement के अनुसार modify किया जा सकता है। Document formatting का उद्देश्य content को readable, consistent और professional बनाना है।

Text Formatting

Paragraph Formatting

Alignment, indentation और spacing।

Page Formatting

Margins, size, orientation और columns।

Object Formatting

Paragraph Formatting

Paragraph formatting पूरे paragraph की layout और spacing को control करती है।

  • Alignment: Left, Center, Right, Justify.

  • Line Spacing: Lines के बीच distance।
  • Paragraph Spacing: Paragraphs के before/after space।
  • Bullets & Numbering: Lists को organized बनाना।

Automatic Formatting and Styles

Styles predefined formatting sets हैं। इनका उपयोग headings और paragraphs में consistent formatting maintain करने के लिए किया जाता है।

Working With Tables

Table information को rows और columns में organize करने की structure है। इसका उपयोग schedules, marksheets, comparisons, lists और structured data के लिए किया जाता है।

  • Row: Horizontal arrangement.
  • Column: Vertical arrangement.
  • Cell: Row और column का intersection.
Table → Rows + Columns → Cells → Structured Information

Insert Table

Table Grid

  1. Insert → Table select करें।
  2. Grid से required rows/columns select करें।

Insert Table Dialog

  1. Insert → Table → Insert Table चुनें।
  2. Columns और Rows की संख्या दें।
  3. OK करें।

Delete Cells

Unwanted cells, rows या columns delete किए जा सकते हैं।

  1. Required cell/row/column select करें।
  2. Table Layout में Delete option खोलें।
  3. Delete Cells / Rows / Columns में appropriate option चुनें।
  4. यदि cells delete कर रहे हैं तो cell-shifting option choose करें।
पूरी row/column delete करने से उसका data भी हट सकता है।

Merge Cells

Merge Cells दो या अधिक adjacent cells को एक single larger cell में combine करता है। इसका उपयोग table headings और grouped information में होता है।

  1. Adjacent cells select करें।
  2. Table Layout में Merge Cells select करें।
Cell A + Cell B + Cell C → One Merged Cell

Creating and Printing Merged Documents – Mail Merge

Mail Merge main document और data source को combine करके multiple personalized documents बनाने की सुविधा है। इसका उपयोग letters, certificates, invitations, labels आदि में किया जाता है।

Main Document

Common format और content.

Data Source

Names, addresses और recipient information.

Merge Fields

Variable information के placeholders.

Merged Output

Personalized final documents.

Mail Merge Steps

  1. Main document तैयार करें।
  2. Mailings → Start Mail Merge चुनें।
  3. Document type select करें।
  4. Recipients/data source select या create करें।
  5. Merge fields insert करें।
  6. Preview Results से check करें।
  7. Finish & Merge select करें।
  8. Documents edit/print करें।
Main Document + Recipient Data → Merge Fields → Preview → Finish & Merge → Personalized Documents
Example: 100 students को अलग-अलग names और addresses के साथ same format letter भेजना हो तो Mail Merge उपयोगी है।

Encrypting Document with a Password

Important documents को unauthorized access से protect करने के लिए password/encryption features का उपयोग किया जा सकता है। Exact options Word version के अनुसार बदल सकते हैं।

  1. Document open करें।
  2. File → Info में जाएँ।
  3. Protect Document select करें।
  4. Available password/encryption option चुनें।
  5. Password enter और confirm करें।
  6. Document save करें।
Important: Password भूलने पर document access/recovery difficult हो सकती है।
