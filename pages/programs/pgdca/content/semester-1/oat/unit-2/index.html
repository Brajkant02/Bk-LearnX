1. Introduction to Spreadsheet

Spreadsheet एक electronic worksheet है जिसमें data को rows और columns के रूप में व्यवस्थित करके store, calculate, analyze और present किया जाता है। MS Excel Microsoft का spreadsheet application है। इसका उपयोग numerical calculations, data organization, reports, tables, charts और financial calculations के लिए किया जाता है।

Workbook

Excel की पूरी file को Workbook कहा जाता है। इसमें एक या अधिक worksheets हो सकती हैं।

Worksheet

Workbook के अंदर working sheet होती है जिसमें rows, columns और cells होते हैं।

Cell

Row और column का intersection cell कहलाता है, जैसे A1, B5.

Formula

Calculation करने के लिए expression, जो सामान्यतः = से शुरू होता है।

Exam Definition: MS Excel is a spreadsheet application used to enter, organize, calculate, analyze and present data in tabular form.

2. Creating a Workbook

Workbook Excel की primary file structure है। नया workbook blank workbook या template से बनाया जा सकता है।

3. Saving and Closing a Workbook

Saving

Workbook को permanent storage में रखने के लिए Save command का उपयोग किया जाता है।

  1. File → Save या Ctrl + S दबाएँ।
  2. File location select करें।
  3. Workbook का name enter करें।
  4. Required Excel format चुनें, यदि आवश्यक हो।
  5. Save click करें।

Closing

  1. Pending changes save करें।
  2. File → Close चुनें या window close करें।
Save vs Save As: Save current workbook के changes store करता है, जबकि Save As नई file name/location/format में copy save करने के लिए उपयोग होता है।

11. Logical Functions

Logical functions conditions test करने और condition के आधार पर result देने के लिए उपयोग होती हैं।

IF Function

=IF(A1>=40,"Pass","Fail")

यदि A1 की value 40 या उससे अधिक है तो Pass, अन्यथा Fail result मिलेगा।

AND

=AND(A1>=40,B1>=40)

सभी specified conditions TRUE होने पर TRUE देता है।

OR

=OR(A1>=40,B1>=40)

कम-से-कम एक condition TRUE होने पर TRUE देता है।

23. LOOKUP / VLOOKUP

LOOKUP और VLOOKUP functions table से related information खोजने के लिए उपयोग होती हैं। VLOOKUP का उपयोग विशेष रूप से तब किया जाता है जब lookup value table की first column में हो और required result किसी दूसरी column से लेना हो।

VLOOKUP Syntax

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
ArgumentMeaning
lookup_valueजिस value को search करना है।
table_arrayवह table/range जिसमें search और result data है।
col_index_numResult वाली column की position.
range_lookupApproximate या exact matching specify करता है।

Example

मान लें table में Student ID, Name और Marks हैं:

A: IDB: NameC: Marks
101Ravi78
102Neha85
103Aman91

यदि E2 में 102 है और उसका Name निकालना है:

=VLOOKUP(E2,A2:C4,2,FALSE)

Result: Neha

यदि उसी ID के Marks निकालने हैं:

=VLOOKUP(E2,A2:C4,3,FALSE)

Result: 85

Important: Exact match के लिए सामान्यतः FALSE या 0 use किया जाता है। VLOOKUP में lookup column selected table range की first column होती है।

VLOOKUP के Uses

  • Student record search करना।
  • Employee information निकालना।
  • Product price lookup करना।
  • Inventory data से details प्राप्त करना।
  • Large tables में matching records find करना।

LOOKUP और VLOOKUP में Basic Difference

LOOKUPVLOOKUP
Lookup operation के लिए general function.Vertical table lookup के लिए specific function.
Lookup/vector या array approach में use हो सकता है।Table की first column में value खोजकर specified column से result देता है।
