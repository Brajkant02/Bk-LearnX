1. Introduction to MS Access

Microsoft Access एक database management application है जिसका उपयोग structured data को store, organize, manage, retrieve और present करने के लिए किया जाता है। इसमें tables में data store किया जाता है तथा queries, forms और reports की सहायता से data के साथ काम किया जाता है।

Tables

Tables database में actual records/data store करने के लिए उपयोग होती हैं।

Queries

Queries का उपयोग required records को search, filter, sort और analyze करने के लिए किया जाता है।

Forms

Forms data entry और user-friendly interaction के लिए interface provide करते हैं।

Reports

Reports database information को organized और printable format में present करने के लिए उपयोग होती हैं।

Exam Definition: MS Access is a database management application used to create and manage databases, tables, queries, forms and reports.

2. Database

Database related data का एक organized collection है जिसे इस प्रकार व्यवस्थित किया जाता है कि data को आसानी से store, access, update और manage किया जा सके।

Example

एक college student database में students की ID, Name, Course, Semester, Marks और Contact information store की जा सकती है।

Student_IDNameCourseSemesterMarks
101RaviPGDCA178
102NehaPGDCA185
103AmanPGDCA291

Database की आवश्यकता

  • Large amount of data को व्यवस्थित रखने के लिए।
  • Data को जल्दी search और retrieve करने के लिए।
  • Records को update और delete करने के लिए।
  • Duplicate और inconsistent data को कम करने के लिए।
  • Reports और useful information तैयार करने के लिए।
Simple Idea: Database को एक organized digital storage system की तरह समझ सकते हैं जिसमें related information structured form में रखी जाती है।

3. Relational Database

Relational Database वह database है जिसमें data को tables के रूप में organize किया जाता है और tables के बीच relationships establish की जा सकती हैं। प्रत्येक table में rows और columns होते हैं।

Important Terms

TermMeaning
TableRelated records का collection.
Row / Recordएक complete data entry.
Column / Fieldकिसी specific attribute की information.
Primary Keyऐसा field जो प्रत्येक record को uniquely identify करता है।
Foreign Keyऐसा field जो दूसरी table की key से relationship establish करने में सहायता करता है।

Example of Relationship

मान लें दो tables हैं:

  • Students: Student_ID, Student_Name, Course_ID
  • Courses: Course_ID, Course_Name

यहाँ Course_ID के माध्यम से Students और Courses tables के बीच relationship बनाया जा सकता है।

Students Table ─── Course_ID ───► Courses Table
Exam Point: Relational database का मुख्य लाभ यह है कि related data को separate tables में रखकर relationships के माध्यम से meaningful information प्राप्त की जा सकती है।

4. Data Integrity

Data Integrity का अर्थ database में stored data की accuracy, consistency, validity और reliability को बनाए रखना है। Database में data सही और logically valid होना चाहिए।

Types / Examples of Integrity

Entity Integrity

Primary key की value unique और valid होनी चाहिए तथा सामान्यतः NULL नहीं होनी चाहिए।

Referential Integrity

Related tables के बीच foreign key references valid होने चाहिए।

Domain Integrity

Field में allowed data type, range और format के अनुसार valid data होना चाहिए।

Validation

Input data को defined rules के अनुसार check किया जाता है।

Example

यदि Student_ID primary key है तो दो students का same Student_ID नहीं होना चाहिए। इसी प्रकार यदि Course_ID किसी दूसरे table को reference करता है तो वह valid course से संबंधित होना चाहिए।

5. MS Access Interface and Main Objects

MS Access में database के साथ काम करने के लिए कई database objects होते हैं। इनके माध्यम से data storage से लेकर reporting तक का काम किया जाता है।

ObjectMain Purpose
TableData store करना।
QueryData search, filter, sort और retrieve करना।
FormData entry और user interaction.
ReportData को formatted/printable output में present करना।

Database Navigation

Access database में created objects को navigation area के माध्यम से देखा और open किया जा सकता है। इससे tables, queries, forms और reports को manage करना आसान होता है।

6. Creating a Database

Database create करना MS Access में database development का पहला major step है।

Step-by-Step Procedure

  1. MS Access open करें।
  2. Blank Database option select करें।
  3. Database का suitable name enter करें।
  4. Storage location select करें।
  5. Create button click करें।
  6. नई database file open हो जाएगी।
  7. अब tables और अन्य database objects create किए जा सकते हैं।
MS Access → Blank Database → Database Name → Location → Create → Tables/Queries/Forms/Reports
Good Practice: Database का name ऐसा रखें जिससे उसके purpose की पहचान आसानी से हो सके, जैसे College_Student_DB या Library_DB.

7. Creating Tables

Table database का मुख्य data-storage object है। इसमें fields columns के रूप में और records rows के रूप में stored होते हैं।

Table Design करते समय

  • Table का purpose determine करें।
  • Required fields identify करें।
  • हर field के लिए suitable data type choose करें।
  • Primary key decide करें।
  • Required validation/constraints apply करें।

Example: Student Table

Field NamePossible Data TypePurpose
Student_IDNumber / suitable identifier typeUnique student identification
Student_NameShort TextStudent name
CourseShort TextCourse name
SemesterNumberSemester number
MarksNumberMarks obtained

Steps

  1. Database open करें।
  2. Table creation/design option choose करें।
  3. Field names enter करें।
  4. Data types select करें।
  5. Primary key set करें, यदि required हो।
  6. Table save करें।

8. Table Structure

Table Structure यह बताता है कि table में कौन-कौन से fields हैं, उनका data type क्या है और उनके rules/constraints क्या हैं।

ComponentDescription
Field NameColumn का नाम।
Data TypeField में किस प्रकार का data रखा जाएगा।
Field PropertiesSize, format, default value, validation आदि settings.
Primary KeyUnique record identification.
RequiredField में value required है या नहीं।
Example: Marks field को numeric data type देना अधिक appropriate है, जबकि Student_Name के लिए text type suitable है।

9. Dropping / Deleting Tables

Database में किसी table की आवश्यकता न रहने पर उसे delete किया जा सकता है। Database terminology में table को permanently remove करने की प्रक्रिया को dropping/deleting a table कहा जा सकता है।

MS Access में General Steps

  1. Database open करें।
  2. Navigation area में required table select करें।
  3. Right-click करें।
  4. Delete option select करें।
  5. Confirmation आने पर carefully confirm करें।
Warning: Table delete करने से उसमें stored records भी हट सकते हैं। इसलिए deletion से पहले backup या data requirement verify करना चाहिए। Related objects भी प्रभावित हो सकते हैं।

10. Manipulating Table Structure

Table structure manipulation का अर्थ existing table के design को आवश्यकता के अनुसार बदलना है।

Common Operations

  • New field add करना।
  • Existing field delete करना।
  • Field name बदलना।
  • Data type बदलना।
  • Field size या properties modify करना।
  • Primary key set/change करना।
  • Validation rules define करना।

Procedure

  1. Required table select/open करें।
  2. Design View में जाएँ।
  3. Required field add या modify करें।
  4. Data type और properties adjust करें।
  5. Required key/constraint set करें।
  6. Changes save करें।
Open Table → Design View → Add/Modify Field → Set Data Type/Properties → Set Key → Save

11. Manipulation of Data

Data Manipulation का अर्थ database में stored records के साथ operations करना है। इसमें records को add, edit, delete और retrieve करना शामिल हो सकता है।

OperationMeaning
Insert / AddNew record database में enter करना।
Update / EditExisting record की information बदलना।
DeleteUnwanted record remove करना।
RetrieveRequired records को search करके प्राप्त करना।

Example

Student table में नए student का record add करना Insert है, marks बदलना Update है और withdrawn student का record remove करना Delete है।

12. Query

Query database से specific information प्राप्त करने या data पर operation करने के लिए दिया गया request/instruction है। Queries large data collections में से required records को quickly identify करने में मदद करती हैं।

Query के मुख्य Uses

  • Specific records search करना।
  • Conditions के आधार पर records filter करना।
  • Data को sort करना।
  • Selected fields display करना।
  • Calculated/summary information प्राप्त करना।
  • कुछ query types के माध्यम से data modify करना।

Simple Example

यदि Student table में बहुत सारे records हैं और केवल ऐसे students चाहिए जिनके marks 80 से अधिक हैं, तो query में marks की condition लगाई जा सकती है।

Student Table ↓ Query Condition: Marks > 80 ↓ Only matching student records

Query बनाने के General Steps

  1. Database open करें।
  2. Query creation option choose करें।
  3. Required table/table(s) select करें।
  4. Required fields add करें।
  5. Criteria/conditions define करें।
  6. Query run करें।
  7. Result check करें।
  8. Query को meaningful name से save करें।

13. Types of Queries

MS Access में अलग-अलग requirements के लिए अलग प्रकार की queries उपयोग की जा सकती हैं।

Query TypePurpose
Select QueryRequired records को display/retrieve करने के लिए।
Parameter QueryUser से input लेकर उसके आधार पर result देने के लिए।
Action QueryData में changes करने वाले operations के लिए, जैसे update/delete आदि।
Totals QuerySummary और aggregate calculations के लिए।
Crosstab QueryData को summarized row-column format में analyze करने के लिए।

Select Query Example

मान लें Student table में Student_ID, Name और Marks हैं। यदि केवल Name और Marks display करने हैं, तो query में उन्हीं fields को select किया जा सकता है।

Student Table → Select Query → Choose Fields → Set Criteria → Run → Result

14. Data Entry Form

Data Entry Form database में records enter और edit करने के लिए बनाया गया user-friendly interface है। सीधे table में data भरने की तुलना में form structured input experience दे सकता है।

Forms की आवश्यकता

  • User-friendly data entry.
  • Required fields को organized layout में दिखाना।
  • Data entry errors को कम करने में सहायता।
  • Existing records को view/edit करना।
  • Database users के लिए सरल interface provide करना।

Data Entry Form बनाने के Steps

  1. Database open करें।
  2. Required table/query select करें।
  3. Form creation option choose करें।
  4. Available fields select करें।
  5. Form layout/design adjust करें।
  6. Form save करें।
  7. Form open करके records enter करें।

Example

Form FieldSample Entry

NameRahul

Semester2

Form vs Table: Table data को directly store करती है, जबकि Form data entry और interaction के लिए user-friendly interface provide करता है।

15. Reports

Report database information को organized, formatted और often printable form में प्रस्तुत करने के लिए उपयोग किया जाने वाला object है।

Reports के Uses

  • Data का formatted presentation.
  • Summary information दिखाना।
  • Records को print-ready form में प्रस्तुत करना।
  • Management/academic reports बनाना।
  • Categories या groups के अनुसार information organize करना।

Report बनाने के General Steps

  1. Database open करें।
  2. Required table या query select करें।
  3. Report creation option choose करें।
  4. Required fields select करें।
  5. Grouping/sorting की आवश्यकता हो तो set करें।
  6. Report layout और formatting adjust करें।
  7. Preview करें।
  8. Report save करें।

Example

College database से सभी students के नाम, course और marks को formatted pages में दिखाने वाली output एक Student Marks Report हो सकती है।

Database → Table/Query → Report → Group/Sort → Format → Preview → Print

16. Table Relationships

जब database में multiple tables हों, तो related information को connect करने के लिए relationships का उपयोग किया जाता है। इससे duplicate data को कम करने और related records के साथ काम करने में मदद मिलती है।

Common Relationship Types

TypeMeaningExample
One-to-Oneएक record का एक related record.Person ↔ Passport
One-to-Manyएक record के कई related records.One Course → Many Students
Many-to-Manyदोनों sides पर multiple relationships; अक्सर intermediate/junction table की आवश्यकता होती है।Students ↔ Subjects
Exam Connection: Relational database में relationships establish करने के लिए primary key और foreign key concepts महत्वपूर्ण होते हैं।

18. Advantages of MS Access

  • Database create और manage करना आसान है।
  • Tables के माध्यम से structured data storage मिलता है।
  • Queries से required information quickly retrieve की जा सकती है।
  • Forms user-friendly data entry provide करते हैं।
  • Reports formatted output बनाने में मदद करती हैं।
  • Small और medium-scale database applications के लिए उपयोगी हो सकता है।
  • Data organization और basic analysis को आसान बनाता है।
  • Multiple database objects को एक database file में organize किया जा सकता है।
Short Conclusion: MS Access database को create, organize, manipulate और present करने के लिए tables, queries, forms और reports जैसे integrated objects provide करता है।
