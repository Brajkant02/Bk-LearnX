1. Introduction to Google Office Tools

Google Office Tools से सामान्यतः Google के cloud-based productivity applications का संदर्भ लिया जाता है। इनके माध्यम से users documents, spreadsheets, forms और presentations create, edit, store, share और collaborate कर सकते हैं। इनके files को Google Drive के माध्यम से organize किया जा सकता है।

Google Drive

Files और folders को cloud में store, organize और share करने के लिए।

Google Docs

Online text documents create और edit करने के लिए।

Google Sheets

Spreadsheet, calculations और tabular data के लिए।

Google Forms

Online forms और responses collect करने के लिए।

Google Slides

Presentations create और present करने के लिए।

Exam Definition: Google Office Tools are cloud-based productivity tools used to create, store, edit, share and collaborate on documents, spreadsheets, forms and presentations.

2. Google Drive

Google Drive एक cloud storage service है जिसका उपयोग digital files और folders को online store तथा organize करने के लिए किया जाता है। इसमें stored files को compatible Google applications के साथ work किया जा सकता है।

Major Uses

  • Files को online store करना।
  • Folders बनाकर files organize करना।
  • Files और folders share करना।
  • Shared files पर collaborative work करना।
  • Files को download करना।
  • Google Docs, Sheets और Slides files manage करना।

Google Drive खोलने के General Steps

Browser खोलें और Google account में sign in करें।
Google Drive खोलें।
Drive का main interface दिखाई देगा।
My Drive में folders और files को manage करें।

3. Creating, Saving, Downloading Files/Folders

New Folder Create करना

New option select करें।
New Folder choose करें।
Folder का suitable name enter करें।
Create करके folder को open करें।

File Upload करना

Drive में required folder open करें।
New → File upload choose करें।
Computer से required file select करें।
Upload complete होने तक wait करें।

Folder Upload

New → Folder upload के माध्यम से computer से पूरा folder Drive में upload किया जा सकता है, जहाँ supported environment में उसका internal structure maintain रहता है।

Download करना

Required file या folder पर right-click करें।
Download option select करें।
File download process complete होने दें।
Important: Google Drive में files cloud में stored रहती हैं, इसलिए उन्हें अलग-अलग devices से access और share किया जा सकता है, provided account/access permissions available हों।

4. Sharing Files/Folders

Google Drive की sharing facility से किसी file या folder को specific people के साथ या configured link access के माध्यम से share किया जा सकता है। Access level आवश्यकता के अनुसार तय किया जाता है।

Common Permission Levels

PermissionMeaning
ViewerContent को देख सकता है।
CommenterContent देख सकता है और comments दे सकता है, जहाँ supported हो।
EditorContent में changes कर सकता है।

Sharing Procedure

File/folder select करें।
Share option choose करें।
Person का email address enter करें या available general access option choose करें।
Required permission select करें।
Share/Send action complete करें।
Security Point: Sensitive files को share करते समय सही users और सही permission level चुनना चाहिए।

5. Google Docs

Google Docs एक online word-processing tool है। इसका उपयोग text documents create, edit, format, share और collaborate करने के लिए किया जाता है।

Google Docs में Basic Work

  • Text type और edit करना।
  • Fonts, size, alignment और paragraph formatting.
  • Headings और lists का उपयोग।
  • Tables और other supported elements insert करना।
  • Document को share करना।
  • Document की copy/download बनाना।
  • Multiple users के साथ collaborative editing.

Document Create करने के Steps

Google Drive या Google Docs खोलें।
New/Blank document option choose करें।
Document का title set करें।
Required text type और format करें।
Document automatically cloud में save होता रहता है।

6. Creating and Sharing Google Docs

Google Docs का एक प्रमुख advantage real-time collaboration है। एक document को authorized users के साथ share करके वे permissions के अनुसार document देख, comment या edit कर सकते हैं।

Sharing Steps

Google Docs document open करें।
ऊपर Share button select करें।
Required email addresses enter करें।
Viewer, Commenter या Editor permission choose करें।
Share/Send करें।
Example: Teacher assignment document share कर सकता है और students को required access देकर उसमें work submit/collaborate कराया जा सकता है।

7. Import and Export Google Docs

Import का अर्थ external document/file को Google Docs environment में लाकर उसके साथ work करना है। Export/Download का अर्थ Google document की copy को available file formats में computer पर save करना है।

Import

Google Drive में file upload करें या supported document open करें।
File को Google Docs-compatible editing environment में open करें।
Content को review और edit करें।

Export / Download

Google Docs document open करें।
File menu खोलें।
Download option choose करें।
Required available format select करें।
File local computer पर save हो जाएगी।

12. Google Forms and Form Responses

जब users Google Form submit करते हैं, तो उनके responses को form के response section में review किया जा सकता है। Responses को spreadsheet के साथ connect करके tabular analysis भी किया जा सकता है, जहाँ available functionality इसका support करती हो।

Responses देखने के Steps

Google Form open करें।
Responses section open करें।
Submitted responses review करें।
Available response summary/data view को analyze करें।

Create Form → Share Form → User Submits Response → Responses Collected → Review / Analyze
Example: College feedback form में students अपने responses submit करते हैं। Faculty responses को review करके common feedback identify कर सकती है।

13. Google Slides

Google Slides एक online presentation tool है जिसका उपयोग slides create, edit, design, share और present करने के लिए किया जाता है।

Basic Components

  • Title and content slides.
  • Text formatting.
  • Images and graphics.
  • Shapes and other supported objects.
  • Themes and layouts.
  • Transitions/animations where required.
  • Sharing and collaboration.

Presentation Create करने के Steps

नई slides add करें।

14. Creating Slides to Present Your Ideas

Presentation का उद्देश्य information को logical और visually understandable sequence में present करना होता है। अच्छी presentation में content को छोटे और meaningful sections में divide किया जाता है।

Recommended Slide Structure

SlideContent
1. TitleTopic name, presenter details.
2. IntroductionTopic का short introduction.
3. Main ConceptImportant definition/concept.
4. DetailsKey points, examples, data.
5. VisualsImages, charts या diagrams जहाँ useful हों।
6. ConclusionMain findings/summary.
7. Thank YouClosing slide.

Presentation Tips

  • एक slide पर बहुत ज्यादा text avoid करें।
  • Clear headings और readable fonts रखें।
  • Important information को bullets में रखें।
  • Relevant visuals का उपयोग करें।
  • Slides का sequence logical रखें।
  • Presentation से पहले slideshow preview करें।

15. Complete Google Office Workflow

Google Drive ↓ Create Folder ↓ Create / Upload File ↓ Docs / Sheets / Forms / Slides ↓ Edit & Format ↓ Share ↓ Collaborate ↓ Download / Export / Present

Example: College Project

  1. Drive में College Project folder create करें।
  2. Project report के लिए Google Docs create करें।
  3. Data analysis के लिए Google Sheets create करें।
  4. Feedback collection के लिए Google Form create करें।
  5. Final presentation के लिए Google Slides create करें।
  6. Required team members के साथ files/folder share करें।
  7. Final documents को review करके required format में download/export करें।
