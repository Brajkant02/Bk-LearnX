MYSQL / SQL

1. Introduction to MySQL and SQL

SQL (Structured Query Language) एक standard language है जिसका उपयोग relational databases के साथ communicate करने के लिए किया जाता है। SQL की सहायता से database objects create किए जा सकते हैं, data insert/update/delete किया जा सकता है और queries के द्वारा required information retrieve की जा सकती है।

MySQL एक popular relational database management system (RDBMS) है जो SQL का उपयोग करके relational data को manage करता है। MySQL में databases, tables, views, indexes और other database objects create और manage किए जा सकते हैं।

SQL और MySQL में अंतर

SQL MySQL
Database से interact करने की language है। एक RDBMS/database software system है।
Queries और database operations define करता है। SQL commands को execute करके data manage करता है।
यह स्वयं database server software नहीं है। यह database server/RDBMS environment provide करता है।
User / Application ↓ SQL Query ↓ MySQL RDBMS ↓ Database / Tables ↓ Result
Exam Definition: SQL is a language used to define, manipulate, retrieve and control data in relational database systems.

2. Data Definition Language (DDL)

DDL (Data Definition Language) SQL commands का वह group है जिसका उपयोग database schema और database objects की structure को define या modify करने के लिए किया जाता है। इसमें tables, indexes, views और अन्य schema-related objects के structure पर काम किया जाता है। citeturn0search1turn0search5

Important DDL Commands

Command Purpose Example
CREATE New database object create करना। CREATE TABLE Student (...);
ALTER Existing object की structure modify करना। ALTER TABLE Student ADD Email VARCHAR(100);
DROP Database object को remove करना। DROP TABLE Student;
TRUNCATE Table के सभी rows remove करना, structure को बनाए रखना। TRUNCATE TABLE Student;
RENAME Object/table का नाम बदलना। RENAME TABLE Student TO Students;

CREATE TABLE Example

CREATE TABLE Student ( StudentID INT PRIMARY KEY, Name VARCHAR(50), Age INT, Course VARCHAR(50) );

CREATE command database object का structure define करता है और columns के साथ data types तथा constraints specify किए जा सकते हैं। citeturn0search2turn0search10

Remember: DDL → Database Structure को define/modify करता है।

3. Data Manipulation Language (DML)

DML का उपयोग database tables में stored actual data को manipulate करने के लिए किया जाता है। इसके मुख्य commands INSERT, UPDATE और DELETE हैं। कुछ educational classifications में SELECT को DML के साथ discuss किया जाता है, जबकि कई references इसे DQL के रूप में अलग रखते हैं। citeturn0search1turn0search9

INSERT

Table में नया record add करने के लिए INSERT का उपयोग किया जाता है।

INSERT INTO Student (StudentID, Name, Age, Course) VALUES (101, 'Amit', 21, 'PGDCA');

UPDATE

Existing records की values modify करने के लिए UPDATE use होता है।

UPDATE Student SET Age = 22 WHERE StudentID = 101;

DELETE

Specific records remove करने के लिए DELETE use होता है।

DELETE FROM Student WHERE StudentID = 101;
Warning: UPDATE या DELETE में WHERE clause न देने पर unintended rows प्रभावित हो सकती हैं।

4. SQL — Structured Query Language

SQL relational database के साथ interaction की primary language है। SQL commands का उपयोग schema define करने, data manipulate करने, queries run करने और permissions manage करने के लिए किया जाता है।

Common SQL Categories

Category Meaning Examples
DDL Data Definition Language CREATE, ALTER, DROP, TRUNCATE
DML Data Manipulation Language INSERT, UPDATE, DELETE
DQL Data Query Language SELECT
DCL Data Control Language GRANT, REVOKE
TCL Transaction Control Language COMMIT, ROLLBACK

GFG के SQL command reference में DDL, DQL, DML, DCL और TCL categories दी गई हैं, और SELECT को data retrieval के लिए DQL में रखा गया है। citeturn0search1

5. Object Naming Conventions & Guidelines

Database objects में databases, tables, columns, views और indexes जैसे names शामिल हो सकते हैं। Consistent naming conventions database को पढ़ने, maintain करने और queries लिखने में आसान बनाती हैं।

Recommended Guidelines

  1. Names meaningful और descriptive रखें।
  2. एक project में consistent naming style रखें।
  3. Spaces और confusing special characters से बचना practical होता है।
  4. SQL keywords जैसे SELECT, TABLE, ORDER आदि को object names के रूप में avoid करें।
  5. Table और column names short लेकिन understandable रखें।
  6. एक ही concept के लिए पूरे database में एक consistent name रखें।
  7. Names में unnecessary abbreviations कम रखें।
  8. Related objects के लिए predictable naming pattern रखें।

Good vs Poor Naming

Better Less Descriptive
Student st1
StudentID x
CourseName cn
EnrollmentDate dt
StudentPhone p1
Tip: Naming convention team/project की official style guide के अनुसार consistent रखनी चाहिए।

7. Tables — Creating, Inserting, Updating and Deleting

Relational database में Table data को rows और columns के रूप में store करने की primary structure है। प्रत्येक column एक attribute को represent करता है और प्रत्येक row एक record/tuple को represent करती है। citeturn0search10

Creating a Table

CREATE TABLE Student ( StudentID INT PRIMARY KEY, Name VARCHAR(50) NOT NULL, Age INT, Course VARCHAR(50) );

Inserting Records

INSERT INTO Student (StudentID, Name, Age, Course) VALUES (101, 'Amit', 21, 'PGDCA'), (102, 'Neha', 22, 'PGDCA'), (103, 'Rahul', 20, 'BCA');

Updating Records

UPDATE Student SET Course = 'MCA' WHERE StudentID = 103;

Deleting Records

DELETE FROM Student WHERE StudentID = 103;

Altering Table Structure

ALTER TABLE Student ADD Email VARCHAR(100); ALTER TABLE Student MODIFY Age SMALLINT; ALTER TABLE Student DROP COLUMN Email;
Difference: DELETE records/data को remove करता है; DROP पूरे table/object को remove करता है; TRUNCATE table के सभी records remove करता है लेकिन table structure रखता है।

8. Constraints

Constraints database में data integrity और validity maintain करने के लिए rules हैं। इन्हें table creation या alteration के समय columns पर apply किया जा सकता है। Common constraints में NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, CHECK और DEFAULT शामिल हैं। citeturn0search2turn0search6

Constraint Purpose Example
NOT NULL Column को NULL value accept करने से रोकना। Name VARCHAR(50) NOT NULL
UNIQUE Duplicate values को रोकना। Email VARCHAR(100) UNIQUE
PRIMARY KEY हर record को uniquely identify करना। StudentID INT PRIMARY KEY
FOREIGN KEY दो tables के बीच referential relationship establish करना। FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
CHECK Value पर condition enforce करना। Age INT CHECK (Age >= 18)
DEFAULT Value absent होने पर default value देना। Status VARCHAR(20) DEFAULT 'Active'

Complete Example

CREATE TABLE Department ( DeptID INT PRIMARY KEY, DeptName VARCHAR(50) NOT NULL UNIQUE ); CREATE TABLE Employee ( EmpID INT PRIMARY KEY, Name VARCHAR(100) NOT NULL, Email VARCHAR(100) UNIQUE, Age INT CHECK (Age >= 18), DeptID INT, Status VARCHAR(20) DEFAULT 'Active', FOREIGN KEY (DeptID) REFERENCES Department(DeptID) );

9. Views

View एक virtual table-like result representation है जो एक SQL query पर आधारित होती है। View में सामान्यतः actual data की अलग physical copy रखने के बजाय underlying tables से query result expose किया जाता है। Views security, simplification और customized data presentation के लिए useful हैं।

Create a View

CREATE VIEW PGDCA_Students AS SELECT StudentID, Name, Course FROM Student WHERE Course = 'PGDCA';

Use the View

SELECT * FROM PGDCA_Students;

Remove a View

DROP VIEW PGDCA_Students;

Advantages of Views

  • Complex queries को reusable बनाया जा सकता है।
  • Users को customized subset of data दिया जा सकता है।
  • Sensitive columns को direct exposure से बचाने में सहायता मिल सकती है।
  • Query readability improve हो सकती है।

10. Indexes

Index database object/data structure है जो columns पर data retrieval को faster बनाने में सहायता कर सकता है। Index को book के index की तरह समझ सकते हैं: पूरी table scan करने के बजाय DBMS appropriate index का उपयोग करके required rows locate करने में सक्षम हो सकता है।

Create Index

CREATE INDEX idx_student_name ON Student(Name);

Unique Index

CREATE UNIQUE INDEX idx_student_email ON Student(Email);

Drop Index in MySQL

DROP INDEX idx_student_name ON Student;

Advantages

  • Search/query performance improve हो सकती है।
  • WHERE, JOIN और ORDER BY जैसे operations में useful हो सकता है।
  • Large tables में data lookup efficient हो सकता है।

Disadvantages

  • Indexes additional storage लेते हैं।
  • INSERT, UPDATE और DELETE के दौरान indexes भी maintain करने पड़ते हैं।
  • हर column पर index बनाना जरूरी या beneficial नहीं होता।

11. DESCRIBE Command

DESCRIBE या DESC command table की structure देखने के लिए use की जाती है। यह columns, data types, NULL information, keys और related structural information देखने में useful है। citeturn0search3

DESCRIBE Student; -- Short form DESC Student;

12. SELECT Command

SELECT SQL की सबसे important query commands में से एक है। इसका उपयोग database से required rows और columns retrieve करने के लिए किया जाता है। SELECT one or more tables से result set return कर सकता है। citeturn0search7

Select All Columns

SELECT * FROM Student;

Select Specific Columns

SELECT StudentID, Name, Course FROM Student;

Column Alias

SELECT Name AS StudentName, Course AS Program FROM Student;

Basic SELECT Structure

SELECT columns FROM table WHERE condition GROUP BY columns HAVING condition ORDER BY columns;

13. WHERE Clause

WHERE clause result में आने वाली rows को condition के आधार पर filter करता है। यह SELECT के साथ-साथ UPDATE और DELETE में भी specific rows target करने के लिए important है। GFG के SQL command reference में WHERE को row filtering clause बताया गया है। citeturn0search1turn0search11

Examples

SELECT * FROM Student WHERE Age > 20; SELECT Name, Course FROM Student WHERE Course = 'PGDCA'; SELECT * FROM Student WHERE Age BETWEEN 18 AND 25;

LIKE

SELECT * FROM Student WHERE Name LIKE 'A%';

A% का अर्थ है A से start होने वाला text pattern।

14. DISTINCT Clause

DISTINCT result set से duplicate rows/values को remove करके unique results दिखाता है। citeturn0search1turn0search11

SELECT DISTINCT Course FROM Student;

यदि कई students एक ही Course में हैं, तो Course name result में केवल unique values के रूप में दिखाई देगा।

Remember: DISTINCT → Duplicate results हटाता है।

15. ORDER BY Clause

ORDER BY result set को specified column के आधार पर sort करता है। Default ordering ascending होती है; DESC descending ordering के लिए use किया जाता है। citeturn0search1turn0search6

SELECT Name, Age FROM Student ORDER BY Age ASC; SELECT Name, Age FROM Student ORDER BY Age DESC;

Multiple Columns

SELECT * FROM Student ORDER BY Course ASC, Age DESC;

16. HAVING Clause

HAVING grouped/aggregated results को filter करने के लिए use होता है। इसे अक्सर GROUP BY के साथ use किया जाता है। WHERE individual rows को filter करता है, जबकि HAVING groups को filter करता है। citeturn0search1

SELECT Course, COUNT(*) AS TotalStudents FROM Student GROUP BY Course HAVING COUNT(*) > 2;
WHERE HAVING
Rows filter करता है। Groups/aggregated results filter करता है।
GROUP BY से पहले filtering conceptually होती है। Grouping के बाद group condition apply होती है।
Example: Age > 20 Example: COUNT(*) > 2

17. Logical Operations

SQL conditions को combine करने के लिए logical operators use किए जाते हैं। Main logical operators हैं AND, OR और NOT.

AND

दोनों conditions true होनी चाहिए।

SELECT * FROM Student WHERE Age > 20 AND Course = 'PGDCA';

OR

कम से कम एक condition true होनी चाहिए।

SELECT * FROM Student WHERE Course = 'PGDCA' OR Course = 'BCA';

NOT

Condition का logical opposite देता है।

SELECT * FROM Student WHERE NOT Course = 'BCA';

Parentheses

SELECT * FROM Student WHERE (Course = 'PGDCA' OR Course = 'BCA') AND Age >= 20;

Complex conditions में parentheses use करने से intended logic clear रहता है।

19. JOIN

JOIN का उपयोग दो या अधिक related tables से data combine करने के लिए किया जाता है। Tables के बीच relationship आमतौर पर common/key columns के through establish होती है।

Example Tables

Student ---------------------------- StudentID | Name | DeptID Department ---------------------------- DeptID | DeptName

INNER JOIN

केवल matching records return करता है।

SELECT Student.Name, Department.DeptName FROM Student INNER JOIN Department ON Student.DeptID = Department.DeptID;

LEFT JOIN

Left table के सभी records और matching right-table records return करता है।

SELECT Student.Name, Department.DeptName FROM Student LEFT JOIN Department ON Student.DeptID = Department.DeptID;

RIGHT JOIN

Right table के सभी records और matching left-table records return करता है।

SELECT Student.Name, Department.DeptName FROM Student RIGHT JOIN Department ON Student.DeptID = Department.DeptID;

CROSS JOIN

दो tables के rows के combinations produce करता है।

SELECT Student.Name, Department.DeptName FROM Student CROSS JOIN Department;
JOIN Main Result
INNER JOIN Only matching rows
LEFT JOIN All left rows + matching right rows
RIGHT JOIN All right rows + matching left rows
CROSS JOIN Combinations of rows

20. Aggregate Functions

Aggregate functions multiple rows पर calculation करके एक summarized result देती हैं। Common SQL aggregate functions में COUNT, SUM, AVG, MIN और MAX शामिल हैं। citeturn0search4

Function Purpose Example
COUNT() Rows/values count करना COUNT(*)
SUM() Numeric values का total SUM(Salary)
AVG() Average value AVG(Marks)
MIN() Smallest value MIN(Marks)
MAX() Largest value MAX(Marks)

Examples

SELECT COUNT(*) AS TotalStudents FROM Student; SELECT AVG(Age) AS AverageAge FROM Student; SELECT MIN(Age) AS MinimumAge, MAX(Age) AS MaximumAge FROM Student; SELECT Course, COUNT(*) AS Total FROM Student GROUP BY Course;
COUNT(*) सभी rows count करता है, जबकि COUNT(column) उस column की non-NULL values count करता है। NULL handling aggregate functions के behavior को प्रभावित कर सकती है।

21. String Functions

String functions text values को manipulate, format या analyze करने के लिए use होती हैं।

Function Purpose Example
UPPER() Text को uppercase में बदलना UPPER(Name)
LOWER() Text को lowercase में बदलना LOWER(Name)
CONCAT() Strings combine करना CONCAT(FirstName,' ',LastName)
LENGTH() String length निकालना LENGTH(Name)
SUBSTRING() String का portion निकालना SUBSTRING(Name,1,3)
TRIM() Leading/trailing spaces remove करना TRIM(Name)
REPLACE() Text का part replace करना REPLACE(Name,'a','@')

Examples

SELECT UPPER(Name) AS UpperName FROM Student; SELECT LOWER(Name) AS LowerName FROM Student; SELECT CONCAT(Name, ' - ', Course) AS StudentInfo FROM Student; SELECT LENGTH(Name) AS NameLength FROM Student;

22. Date and Time Functions

MySQL date/time functions date और time values को retrieve, format, compare और calculate करने में सहायता करती हैं।

Function Purpose Example
CURDATE() Current date SELECT CURDATE();
CURTIME() Current time SELECT CURTIME();
NOW() Current date and time SELECT NOW();
YEAR() Date से year निकालना YEAR(JoiningDate)
MONTH() Month निकालना MONTH(JoiningDate)

23. NULL Values

NULL का अर्थ generally missing, unknown या not available value होता है। NULL को zero, empty string या ordinary value के बराबर नहीं समझना चाहिए। GFG के MySQL reference के अनुसार NULL को check करने के लिए IS NULL और IS NOT NULL use करना चाहिए; = या != के साथ NULL comparison उचित नहीं है। citeturn0search0turn0search11

Checking NULL

SELECT * FROM Employee WHERE Email IS NULL; SELECT * FROM Employee WHERE Email IS NOT NULL;

Wrong Approach

-- Avoid: WHERE Email = NULL; -- Avoid: WHERE Email != NULL;

COALESCE()

COALESCE() arguments में से पहला non-NULL value return कर सकता है। इससे missing value के लिए fallback value दिखाने में सहायता मिलती है। citeturn0search0

SELECT Name, COALESCE(Email, 'Not Available') AS Email FROM Employee;

NULL and Aggregate Functions

COUNT(column), SUM(column) और AVG(column) जैसे functions सामान्यतः NULL values को ignore करते हैं, जबकि COUNT(*) rows को count करता है। citeturn0search0

Remember: NULL ≠ 0 and NULL ≠ empty string (''). Use IS NULL / IS NOT NULL for NULL checks.

24. Complete SQL Practical Workflow

नीचे एक छोटा end-to-end example है जिसमें database creation से लेकर table, constraints, insertion, query, grouping और ordering तक concepts connect होते हैं।

CREATE DATABASE CollegeDB; USE CollegeDB; CREATE TABLE Department ( DeptID INT PRIMARY KEY, DeptName VARCHAR(50) NOT NULL UNIQUE ); CREATE TABLE Student ( StudentID INT PRIMARY KEY, Name VARCHAR(50) NOT NULL, Age INT CHECK (Age >= 18), DeptID INT, Email VARCHAR(100) UNIQUE, FOREIGN KEY (DeptID) REFERENCES Department(DeptID) ); INSERT INTO Department VALUES (1, 'Computer'), (2, 'Management'); INSERT INTO Student (StudentID, Name, Age, DeptID, Email) VALUES (101, 'Amit', 21, 1, 'amit@example.com'), (102, 'Neha', 22, 1, 'neha@example.com'), (103, 'Rahul', 20, 2, NULL); DESCRIBE Student; SELECT * FROM Student; SELECT DISTINCT Age FROM Student; SELECT Name, Age FROM Student WHERE Age >= 21 ORDER BY Age DESC; SELECT DeptID, COUNT(*) AS TotalStudents FROM Student GROUP BY DeptID HAVING COUNT(*) >= 1; SELECT Student.Name, Department.DeptName FROM Student INNER JOIN Department ON Student.DeptID = Department.DeptID;
CREATE → INSERT → DESCRIBE → SELECT ↓ WHERE / DISTINCT ↓ GROUP BY / HAVING ↓ ORDER BY ↓ JOIN
