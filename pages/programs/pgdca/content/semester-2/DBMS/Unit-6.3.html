Introduction to Triggers

Trigger stored PL/SQL block है जो specified database event होने पर automatically execute होता है। Trigger को user directly call नहीं करता।

Image Placeholder: Trigger Event and Automatic Action

Common Events

  • INSERT
  • UPDATE
  • DELETE
  • Database login or schema events

Types of Triggers

TypeMeaning
BEFORE TriggerEvent से पहले execute।
AFTER TriggerEvent के बाद execute।
INSTEAD OF TriggerOriginal operation की जगह execute।
Row-Level Triggerहर affected row के लिए execute।
Statement-Level TriggerComplete SQL statement के लिए once execute।

Trigger Example

CREATE OR REPLACE TRIGGER student_audit_trigger
AFTER UPDATE OF marks ON student
FOR EACH ROW
BEGIN
    INSERT INTO student_audit
    (
        student_id,
        old_marks,
        new_marks,
        change_date
    )
    VALUES
    (
        :OLD.student_id,
        :OLD.marks,
        :NEW.marks,
        SYSDATE
    );
END;
/

:OLD and :NEW

  • :OLD previous value represent करता है।
  • :NEW new value represent करता है।

Applications and Limitations of Triggers

Applications

  • Audit logging
  • Automatic validation
  • Derived values update करना
  • Security rules
  • Business rule enforcement

Limitations

  • Hidden automatic logic debugging कठिन बना सकती है।
  • Too many triggers performance reduce कर सकते हैं।
  • Recursive or conflicting behavior हो सकता है।

Explicit Cursor

Explicit cursor programmer manually declare करता है जब query multiple rows return करती है।

Cursor Life Cycle

  1. DECLARE
  2. OPEN
  3. FETCH
  4. CLOSE
DECLARE
    CURSOR student_cursor IS
        SELECT student_id, name
        FROM student;

    v_id   student.student_id%TYPE;
    v_name student.name%TYPE;

BEGIN
    OPEN student_cursor;

    LOOP
        FETCH student_cursor INTO v_id, v_name;
        EXIT WHEN student_cursor%NOTFOUND;

        DBMS_OUTPUT.PUT_LINE(v_id || ' ' || v_name);
    END LOOP;

    CLOSE student_cursor;
END;
/

Cursor FOR Loop

Cursor FOR loop OPEN, FETCH और CLOSE automatically manage करता है।

BEGIN
    FOR student_record IN
    (
        SELECT student_id, name
        FROM student
    )
    LOOP
        DBMS_OUTPUT.PUT_LINE(
            student_record.student_id || ' ' ||
            student_record.name
        );
    END LOOP;
END;
/

Parameterized Cursor

DECLARE
    CURSOR student_cursor(p_city VARCHAR2) IS
        SELECT student_id, name
        FROM student
        WHERE city = p_city;

BEGIN
    FOR record_item IN student_cursor('Kanpur')
    LOOP
        DBMS_OUTPUT.PUT_LINE(record_item.name);
    END LOOP;
END;
/

GRANT Statement

GRANT user या role को database privileges देता है।

GRANT SELECT ON student TO teacher_user;
GRANT INSERT, UPDATE ON student TO clerk_user;
GRANT EXECUTE ON update_student_marks TO admin_user;

Common Privileges

  • SELECT
  • INSERT
  • UPDATE
  • DELETE
  • EXECUTE
  • CREATE SESSION

REVOKE Statement

REVOKE previously granted privilege remove करता है।

REVOKE UPDATE ON student FROM clerk_user;
REVOKE EXECUTE ON update_student_marks FROM admin_user;
Security Principle:
User को केवल उतनी permissions दें जितनी उसके work के लिए required हों। इसे principle of least privilege कहते हैं।

Roles and Privilege Management

Role privileges का named collection होता है। Multiple users को same privileges देने के लिए role useful है।

CREATE ROLE teacher_role;

GRANT SELECT ON student TO teacher_role;
GRANT SELECT ON course TO teacher_role;

GRANT teacher_role TO teacher_user;

Advantages

  • Permission management simple।
  • Consistency maintain होती है।
  • Security administration आसान।

PL/SQL Best Practices

  • Meaningful variable और object names use करें।
  • Specific exceptions handle करें।
  • Transactions को unnecessary long न रखें।
  • Row-by-row cursor के बजाय set-based SQL prefer करें जहाँ possible हो।
  • Triggers में complex hidden logic avoid करें।
  • Functions और procedures को single clear responsibility दें।
  • Privileges least privilege principle के अनुसार assign करें।
  • Production changes से पहले backup और testing करें।
Remember:
PL/SQL का purpose database logic को reusable, secure और manageable बनाना है।
