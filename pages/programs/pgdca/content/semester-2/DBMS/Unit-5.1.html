Introduction to SQL and MySQL

SQL का full form Structured Query Language है। इसका use relational database में data create, store, retrieve, update, delete और control करने के लिए किया जाता है। MySQL एक popular relational database management system है जो SQL language support करता है।

Main Uses

  • Database create करना
  • Tables बनाना
  • Records insert/update/delete करना
  • Data search और filter करना
  • Security और transactions manage करना

SQL Language Categories

CategoryPurposeCommands
DDLDatabase objects define करनाCREATE, ALTER, DROP, TRUNCATE
DMLData modify करनाINSERT, UPDATE, DELETE
DQLData retrieve करनाSELECT
DCLPermissions control करनाGRANT, REVOKE
TCLTransactions manage करनाCOMMIT, ROLLBACK, SAVEPOINT

Data Definition Language

DDL database structure create और modify करने के लिए use होती है।

CREATE DATABASE college;
ALTER TABLE student ADD email VARCHAR(100);
DROP TABLE old_student;
TRUNCATE TABLE temp_data;

Data Manipulation Language

DML table के records को insert, update और delete करने के लिए use होती है।

INSERT INTO student VALUES (1, 'Aman');
UPDATE student SET name='Ravi' WHERE id=1;
DELETE FROM student WHERE id=1;

DCL and TCL

DCL

GRANT SELECT ON college.* TO user1;
REVOKE INSERT ON college.* FROM user1;

TCL

START TRANSACTION;
UPDATE account SET balance=balance-500 WHERE id=1;
COMMIT;

Object Naming Conventions

  • Names meaningful रखें।
  • Spaces avoid करें।
  • Reserved keywords use न करें।
  • Consistent lowercase naming use करें।
  • Primary key के लिए id या table_id pattern रखें।
  • Foreign key का नाम referenced key से match करें।
