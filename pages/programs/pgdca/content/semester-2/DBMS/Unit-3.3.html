Introduction to Relational Algebra

Relational Algebra procedural query language है जिसमें relations पर operations perform करके new relation generate किया जाता है। यह SQL की theoretical foundation है।

Image Placeholder: Relational Algebra Overview

Basic Principle

हर relational algebra operation का input relation होता है और output भी relation होता है। इसे closure property कहा जाता है।

Union Operation

Union दो union-compatible relations के सभी tuples combine करता है और duplicates remove करता है।

R ∪ S

Conditions

  • Same number of attributes।
  • Corresponding attributes compatible domains के हों।

Image Placeholder: Relational Algebra Union

Intersection Operation

Intersection केवल वे tuples return करता है जो दोनों relations में common हों।

R ∩ S

Difference Operation

Difference R के वे tuples return करता है जो S में नहीं हैं।

R − S

Important

R − S और S − R generally different results देते हैं।

Cartesian Product

Cartesian Product R की हर row को S की हर row के साथ combine करता है।

R × S

यदि R में m tuples और S में n tuples हैं, तो result में m × n tuples होंगे।

Image Placeholder: Cartesian Product

Selection Operation

Selection condition के आधार पर rows select करता है। इसे horizontal subset भी कहा जाता है।

σ Marks > 60 (STUDENT)

यह उन students को select करेगा जिनके marks 60 से अधिक हैं।

Projection Operation

Projection required columns select करता है। इसे vertical subset कहा जाता है। Duplicate rows remove हो सकती हैं।

π Name, Course (STUDENT)

Rename Operation

Rename relation या attributes का temporary name change करता है।

ρ S(Student_ID, Student_Name) (STUDENT)

Complex expressions और self-join में rename useful है।

Join Operation

Join related attributes के आधार पर two relations combine करता है।

Division Operation

Division उन entities को find करने के लिए use होता है जो related set की सभी values से related हों।

Example

उन students को find करना जिन्होंने सभी compulsory courses complete किए हैं।

Remember:
Division “for all” type queries के लिए useful है।

Converting ER Model to Relational Model

ER model को relational tables में convert करने के लिए entities, attributes और relationships को systematic rules के अनुसार map किया जाता है।

Image Placeholder: ER Model to Relational Tables

Strong Entity

Each strong entity के लिए separate table बनाएं और key attribute को primary key बनाएं।

Weak Entity

Weak entity table में owner entity की primary key include करें। Owner key + partial key composite primary key बन सकती है।

One-to-One Relationship

Foreign key किसी एक suitable table में add करें।

One-to-Many Relationship

One-side की primary key many-side table में foreign key बनती है।

Many-to-Many Relationship

Separate relationship table बनाएं जिसमें दोनों entities की keys foreign keys हों।

Mapping Attributes

Attribute TypeRelational Conversion

DerivedUsually calculate, store only if needed

Common Mistakes and Best Practices

Common Mistakes

  • Union compatibility ignore करना।
  • Selection और projection confuse करना।
  • Join condition miss करना जिससे unwanted Cartesian product बन जाए।
  • Many-to-many relationship के लिए separate table न बनाना।
  • Foreign key constraints ignore करना।

Best Practices

  • Relations और attributes के clear names रखें।
  • Primary keys carefully select करें।
  • Relational algebra expression step-by-step solve करें।
  • ER conversion के बाद redundancy और constraints verify करें।
Remember:
Relational Algebra query logic समझाती है और ER-to-Relational conversion database implementation की foundation बनाती है।
