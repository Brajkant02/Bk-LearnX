User Defined Function

User Defined Function named PL/SQL block होती है जो एक value return करती है। इसका use calculation, validation और reusable business logic के लिए किया जाता है।

Image Placeholder: Function Input, Processing and Return Value

General Syntax

CREATE OR REPLACE FUNCTION function_name
(parameter_name datatype)
RETURN datatype
IS
BEGIN
    -- Statements
    RETURN value;
END;
/

Function Example

CREATE OR REPLACE FUNCTION calculate_grade
(
    p_marks NUMBER
)
RETURN VARCHAR2
IS
    v_grade VARCHAR2(10);
BEGIN
    IF p_marks >= 75 THEN
        v_grade := 'A';
    ELSIF p_marks >= 60 THEN
        v_grade := 'B';
    ELSIF p_marks >= 40 THEN
        v_grade := 'C';
    ELSE
        v_grade := 'F';
    END IF;

    RETURN v_grade;
END;
/

Calling the Function

SELECT calculate_grade(82) FROM dual;

Function Characteristics

  • Function return type declare करना mandatory है।
  • At least one RETURN statement होना चाहिए।
  • Parameters optional हो सकते हैं।
  • Function SQL statements में call की जा सकती है, यदि suitable हो।
  • Function business logic reuse करती है।

Stored Procedure

Stored Procedure database में saved named PL/SQL block होती है। यह task perform करती है, लेकिन function की तरह direct return value mandatory नहीं होती।

Image Placeholder: Stored Procedure Execution

General Syntax

CREATE OR REPLACE PROCEDURE procedure_name
(parameter_name mode datatype)
IS
BEGIN
    -- Statements
END;
/

Procedure Example

CREATE OR REPLACE PROCEDURE update_student_marks
(
    p_student_id IN NUMBER,
    p_new_marks  IN NUMBER
)
IS
BEGIN
    UPDATE student
    SET marks = p_new_marks
    WHERE student_id = p_student_id;

    COMMIT;
END;
/

Calling Procedure

BEGIN
    update_student_marks(101, 88);
END;
/

Procedure Parameter Modes

ModeMeaning
INValue procedure को input के रूप में दी जाती है।
OUTProcedure result caller को return करती है।
IN OUTValue input भी होती है और modified output भी बनती है।
CREATE OR REPLACE PROCEDURE increase_salary
(
    p_salary IN OUT NUMBER
)
IS
BEGIN
    p_salary := p_salary * 1.10;
END;
/

Transaction Concept

Transaction database operations का logical unit है। Transaction में सभी operations successful होने चाहिए या failure पर सभी changes undo होने चाहिए।

Image Placeholder: Transaction Flow

Bank Transfer Example

START TRANSACTION;

UPDATE account
SET balance = balance - 500
WHERE account_id = 1;

UPDATE account
SET balance = balance + 500
WHERE account_id = 2;

COMMIT;

ACID Properties

PropertyMeaning
AtomicityAll operations complete हों या none।
ConsistencyDatabase valid state में रहे।
IsolationConcurrent transactions एक-दूसरे को incorrectly affect न करें।
DurabilityCommitted changes permanently save रहें।

Transaction Control Statements

COMMIT

Changes permanently save करता है।

ROLLBACK

Uncommitted changes undo करता है।

SAVEPOINT

Transaction के बीच recovery point create करता है।

UPDATE account SET balance=balance-500 WHERE id=1;
SAVEPOINT after_debit;

UPDATE account SET balance=balance+500 WHERE id=2;

ROLLBACK TO after_debit;
COMMIT;

Transaction Error Handling

BEGIN
    UPDATE account
    SET balance = balance - 500
    WHERE account_id = 1;

    UPDATE account
    SET balance = balance + 500
    WHERE account_id = 2;

    COMMIT;

EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE;
END;
/
