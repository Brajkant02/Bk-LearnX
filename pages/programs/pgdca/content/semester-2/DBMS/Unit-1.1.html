Database System Concept & Data Modeling (Part-1)

1. Basic Concepts of DBMS

Database is an organized collection of related data. DBMS (Database Management System) is software used to create, store, retrieve, update and manage data efficiently.

Image Placeholder: DBMS Overview Diagram

Examples: MySQL, PostgreSQL, Oracle Database, SQL Server, SQLite.

Real Life Example: Bank, Hospital, School and E-commerce websites all use DBMS to manage large amounts of data.

3. Data Abstraction

Data abstraction hides unnecessary implementation details and shows only the required information to users.

  • Physical Level: How data is stored.
  • Logical Level: What data is stored and relationships.
  • View Level: Only required data shown to users.

8. Three-Level Architecture

DBMS follows External → Conceptual → Internal architecture to achieve data abstraction and independence.

9. Data Independence

  • Physical Data Independence: Storage changes without affecting logical structure.
  • Logical Data Independence: Logical changes without affecting user views.

10. Client-Server Architecture

In Client-Server Architecture, client sends requests and the database server processes queries and returns results.
