NULL Values

NULL का मतलब missing, unknown या unavailable value है। यह zero या empty string नहीं है।

SELECT * FROM student WHERE email IS NULL;
SELECT * FROM student WHERE email IS NOT NULL;
Remember:
NULL compare करने के लिए = NULL नहीं, IS NULL use करें।

Handling NULL

SELECT name, IFNULL(email,'Not Available')
FROM student;

SELECT COALESCE(phone,email,'No Contact')
FROM student;

Combined Practical Query

SELECT city,
       COUNT(*) AS total_students,
       AVG(marks) AS average_marks
FROM student
WHERE marks IS NOT NULL
GROUP BY city
HAVING AVG(marks) > 70
ORDER BY average_marks DESC;

Common Mistakes

  • UPDATE/DELETE में WHERE भूलना।
  • NULL के साथ = use करना।
  • Wrong data type select करना।
  • JOIN condition miss करना।
  • GROUP BY के बिना aggregate misuse करना।
  • Reserved words को object name बनाना।

Best Practices

  • Meaningful naming conventions use करें।
  • Primary key हर important table में रखें।
  • Foreign keys से referential integrity maintain करें।
  • Transactions use करें।
  • Queries test करके run करें।
  • Frequently searched columns पर index use करें।
  • Backup रखें।
