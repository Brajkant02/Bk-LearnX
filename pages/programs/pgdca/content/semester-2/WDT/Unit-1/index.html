1. Image Editing Tools

1. Introduction to Image Editing Tools

Image Editing Tools ऐसे software applications हैं जिनकी सहायता से digital images को create, open, modify, enhance, organize और export किया जा सकता है। इनका उपयोग photographs, graphics, posters, banners, web images, advertisements और digital artwork तैयार करने के लिए किया जाता है।

Image editing software में अलग-अलग tools और panels उपलब्ध होते हैं जिनकी सहायता से image को crop, resize, select, paint, adjust, organize और visually modify किया जा सकता है। Software के अनुसार interface और exact tool names अलग हो सकते हैं, लेकिन basic concepts काफी similar होते हैं।

Common Image Editing Operations

Crop

Image के unwanted हिस्से को हटाना।

Resize

Image की dimensions बदलना।

Color Adjustment

Brightness, contrast और colors को adjust करना।

Selection

Image के किसी specific area को select करके उस पर operation करना।

Layers

Image elements को अलग-अलग editable layers में organize करना।

Transparency

Image या layer के कुछ हिस्सों को transparent बनाना।

Exam Definition: Image editing tools are software tools used to create, modify, enhance, organize and export digital images.

2. File Formats

Image file format यह निर्धारित करता है कि digital image किस प्रकार store और represent की जाएगी। अलग-अलग formats के compression, quality, transparency और editing capabilities अलग हो सकते हैं।

Format Type / Feature Common Use
JPEG / JPG Raster, lossy compression Photographs, web images
PNG Raster, lossless compression, transparency support Web graphics, logos, transparent images
GIF Raster, limited color palette, animation support Simple animations and web graphics
TIFF High-quality raster format Printing, scanning and image workflows
BMP Raster bitmap format Basic bitmap storage
SVG Vector format Logos, icons and scalable graphics
PSD Layered editing format associated with Adobe Photoshop Editable Photoshop projects

Lossy vs Lossless Compression

Lossy compression file size reduce करने के लिए कुछ image information discard कर सकती है। JPEG इसका common example है।

Lossless compression image information को इस प्रकार compress करती है कि decompression के बाद original data को preserve किया जा सके। PNG इसका common example है।

Exam Tip: JPEG → photographs, PNG → transparency/web graphics, SVG → vector graphics, PSD → layered editing project.

3. Raster vs Vector Images

Digital graphics को broadly Raster और Vector categories में समझा जाता है।

Raster Images

Raster image छोटे-छोटे pixels से बनी होती है। प्रत्येक pixel में color information होती है। Photographs सामान्यतः raster images होती हैं।

Raster Image ┌───┬───┬───┬───┐ │ ■ │ ■ │ ■ │ ■ │ ├───┼───┼───┼───┤ │ ■ │ ■ │ ■ │ ■ │ ├───┼───┼───┼───┤ │ ■ │ ■ │ ■ │ ■ │ └───┴───┴───┴───┘ Pixels

Vector Images

Vector graphics mathematical paths, points, lines, curves और shapes के आधार पर बनी होती हैं। इन्हें size बढ़ाने या घटाने पर quality सामान्यतः raster की तरह pixelate नहीं होती।

Raster Vector
Pixels पर आधारित। Paths और mathematical shapes पर आधारित।
Photographs के लिए suitable। Logos, icons और illustrations के लिए suitable।
बहुत ज्यादा enlarge करने पर pixelation हो सकती है। Scale करने पर sharpness maintain रहती है।
JPEG, PNG, TIFF आदि common formats। SVG जैसे formats common हैं।
Important: Photo editing में raster graphics important हैं, जबकि logos और scalable illustrations के लिए vector graphics useful होती हैं।

6. Starting and Opening a Document

New Document Create करना

General steps:

  1. Image editing software open करें।
  2. File → New command select करें।
  3. Required width और height set करें।
  4. Resolution आवश्यकता के अनुसार choose करें।
  5. Color mode और background settings select करें।
  6. Create/New button select करें।
File → New ↓ Width / Height ↓ Resolution ↓ Color Mode ↓ Background ↓ Create

Existing Document Open करना

  1. File → Open select करें।
  2. Computer में required image file locate करें।
  3. File select करें।
  4. Open button click करें।
  5. Image work area में दिखाई देगी।

Open Shortcut

Many applications में Ctrl + O Open command के लिए commonly used shortcut है।

7. Getting / Importing an Image

Image editing workflow में image कई sources से प्राप्त की जा सकती है, जैसे local storage, scanner, camera, screenshot या अन्य application/document।

Local File से Image लेना

  1. File → Open पर जाएँ।
  2. Image file locate करें।
  3. Open करें।

Import Concept

कुछ applications में external image को current document में import/place किया जा सकता है। इससे image को existing project में एक अलग layer/object के रूप में add करना possible हो सकता है।

Scanner / Camera

कुछ image editing environments scanners या cameras जैसे external sources से image acquire करने की सुविधा provide कर सकते हैं। Actual procedure software और device support पर depend करता है।

Best Practice: Original image की backup copy रखें और editing के लिए duplicate/project copy पर काम करें।

Example

यदि Layers panel में किसी layer पर right-click किया जाए, तो software के अनुसार Duplicate, Delete, Rename, Merge आदि options दिखाई दे सकते हैं।

10. Rulers and Guidelines

Rulers

Rulers work area में horizontal और vertical measurement references provide करते हैं। इनकी सहायता से object/image placement और approximate dimensions को understand किया जा सकता है।

Guidelines

Guidelines non-printing visual reference lines होती हैं जिनका उपयोग objects को align करने और layout accurately arrange करने के लिए किया जाता है।

Horizontal Ruler ───────────────────────────── │ │ │ Image │ │ │ ────────┼───────┼───────────── │ │ Vertical Guide

Rulers के Uses

  • Object positioning।
  • Layout alignment।
  • Approximate measurement।
  • Document structure समझना।

Guidelines के Uses

  • Text और images align करना।
  • Margins और layout planning।
  • Multiple objects को consistent position पर रखना।
  • Design में visual accuracy improve करना।
Important: Guidelines सामान्यतः final image में दिखाई देने वाली printed content नहीं होतीं; वे editing सहायता के लिए होती हैं।

12. Color Modes of Images

Color Mode यह define करता है कि image में colors किस प्रकार represent और store किए जाएंगे। अलग-अलग output requirements के लिए अलग color modes use किए जा सकते हैं।

RGB

RGB = Red, Green, Blue. यह screen-based graphics, websites, mobile devices और digital displays के लिए commonly used color model है।

RGB ├── Red ├── Green └── Blue

CMYK

CMYK = Cyan, Magenta, Yellow, Key (Black). यह printing workflows में commonly used color model है।

CMYK ├── Cyan ├── Magenta ├── Yellow └── Key / Black

Grayscale

Grayscale images में colors की जगह shades of gray use किए जाते हैं। यह black, white और intermediate gray tones को represent कर सकता है।

Bitmap / Indexed Color

कुछ software environments limited color palettes या indexed-color modes भी support करते हैं। Exact features software पर depend करती हैं।

Color Mode Common Use
RGB Digital screens, web, mobile and general digital graphics
CMYK Printing
Grayscale Black-and-white / gray-tone images
Indexed Color Limited-color graphics and specific file/workflow requirements
Exam Tip: Screen → RGB | Print → CMYK | Black & White → Grayscale.

13. Working with Layers

Layer image project का एक separate editable level है। Layers की सहायता से image के अलग-अलग elements को independently edit, move, hide, duplicate और organize किया जा सकता है।

Layer 3 → Text Layer 2 → Logo Layer 1 → Photo Layer 0 → Background

Layer Operations

Operation Purpose
New Layer New editable layer create करना।
Duplicate Existing layer की copy बनाना।
Rename Layer को meaningful name देना।
Hide/Show Layer को temporarily visible या invisible करना।
Reorder Layer stacking order बदलना।
Delete Unwanted layer remove करना।
Merge Selected layers को combine करना, software support के अनुसार।

Layer Order

Layers का order यह determine करता है कि कौन-सा element दूसरे element के ऊपर दिखेगा। ऊपर वाली layer सामान्यतः नीचे वाली layer के content को cover कर सकती है, जब तक transparency या blending behavior उसे अलग न बनाए।

Advantages of Layers

  • Non-destructive और organized editing workflow में सहायता।
  • एक element को दूसरे elements को disturb किए बिना edit किया जा सकता है।
  • Design के अलग-अलग components को manage करना आसान।
  • Complex projects को logically organize किया जा सकता है।
Exam Definition: A layer is an independent editable level in an image document used to organize and modify individual elements of a design.

14. Transparency

Transparency का अर्थ image या layer के किसी area में background या underlying content को दिखाई देने देना है। Transparent area में कोई solid color present नहीं होता।

Transparency के Uses

  • Logo को background के बिना use करना।
  • Web graphics में transparent background बनाना।
  • Different layers को combine करना।
  • Design elements के आसपास unwanted background remove करना।
  • Overlay और compositing effects create करना।

Alpha Channel

कई image formats और editing systems में transparency information को alpha channel के माध्यम से represent किया जा सकता है।

Image Pixel ↓ Color Information + Alpha Information ↓ Opacity / Transparency

Opacity vs Transparency

Term Meaning
Opacity किसी layer/object की visibility/solidness की degree।
Transparency Underlying background/content कितना दिखाई दे रहा है।

Example

यदि किसी logo layer की opacity कम की जाती है, तो उसके नीचे का background अधिक visible हो सकता है। इसी concept का उपयोग overlays और visual effects में किया जाता है।

Format Tip: Transparency की आवश्यकता होने पर ऐसा file format/workflow चुनें जो required transparency information preserve कर सके, जैसे PNG में transparent backgrounds commonly supported होते हैं।
