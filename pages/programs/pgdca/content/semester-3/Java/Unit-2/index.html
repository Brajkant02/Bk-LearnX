Language Constructs

Variables

Variable Java program में data store करने के लिए memory location का named container होता है। Program में जब हमें कोई value बार-बार use करनी होती है, जैसे age, marks, name, price या total, तो हम उसे variable में store करते हैं। Variable का नाम programmer define करता है और उसका type बताता है कि उसमें किस प्रकार की value store होगी।

Java strongly typed language है। इसका मतलब है कि variable declare करते समय उसका data type बताना जरूरी होता है। अगर variable int type का है, तो उसमें integer value store होगी। अगर variable String type का है, तो उसमें text value store होगी।

Image Placeholder: Variable Memory Diagram

Variable Declaration Syntax

dataType variableName;

Variable Initialization Syntax

dataType variableName = value;

Example

public class Main {
    public static void main(String[] args) {
        int age = 23;
        double marks = 85.5;
        String name = "Brajkant";

        System.out.println(age);
        System.out.println(marks);
        System.out.println(name);
    }
}
Output:
23
85.5
Brajkant

Rules for Naming Variables

  • Variable name letter, underscore _ या dollar sign $ से start हो सकता है।
  • Variable name number से start नहीं हो सकता।
  • Java variable names case-sensitive होते हैं।
  • Reserved keywords variable name नहीं हो सकते।
  • Meaningful variable names use करना best practice है।

Valid and Invalid Variable Names

if then else Clause

if-else statement Java में decision making के लिए use होता है। Program condition के according different code blocks execute कर सकता है। अगर condition true है, तो if block run होता है, otherwise else block run होता है।

if Statement

int age = 20;

if (age >= 18) {
    System.out.println("Eligible to vote");
}

if-else Statement

int marks = 30;

if (marks >= 33) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}
Output:
Fail

else-if Ladder

int marks = 78;

if (marks >= 90) {
    System.out.println("Grade A+");
} else if (marks >= 75) {
    System.out.println("Grade A");
} else if (marks >= 60) {
    System.out.println("Grade B");
} else {
    System.out.println("Grade C");
}
Output:
Grade A

Nested if

String username = "admin";
String password = "1234";

if (username.equals("admin")) {
    if (password.equals("1234")) {
        System.out.println("Login successful");
    } else {
        System.out.println("Wrong password");
    }
} else {
    System.out.println("Wrong username");
}
Real Life Example:

Conditional Expressions

Conditional expression Java में decision को short form में लिखने का तरीका है। इसे ternary operator भी कहा जाता है क्योंकि इसमें three operands होते हैं: condition, true expression और false expression।

Syntax

condition ? valueIfTrue : valueIfFalse;

Example

System.out.println(result);
Output:
Pass

Even or Odd

String answer = (num % 2 == 0) ? "Even" : "Odd";

Even

Iteration and Jump Statement

Iteration statements loops को represent करते हैं। Java में for, while और do-while iteration statements हैं। Jump statements program control को एक place से दूसरे place पर transfer करते हैं। Java में important jump statements break, continue और return हैं।

return Statement

return method से control वापस भेजता है। अगर method value return करता है, तो return के साथ value दी जाती है।

break vs continue

Basis break continue
Work Loop को stop करता है। Only current iteration skip करता है।
Control Loop के बाहर जाता है। Next iteration पर जाता है।
Use Search complete होने पर loop रोकना। कुछ values skip करना।
Real Life Example:
Array में required roll number मिलते ही search रोकने के लिए break use किया जा सकता है। Invalid value skip करने के लिए continue use हो सकता है।

switch Case

switch statement multiple choices में से एक block execute करने के लिए use होता है। जब एक variable की value के basis पर कई possible cases handle करने हों, तो switch case if-else ladder का better alternative हो सकता है।

Syntax

switch (expression) {
    case value1:
        statements;
        break;

    case value2:
        statements;
        break;

    default:
        statements;
}

Example

int day = 3;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    case 3:
        System.out.println("Wednesday");
        break;
    default:
        System.out.println("Invalid day");
}
Output:
Wednesday

Calculator Example

char operator = '+';
int a = 10;
int b = 5;

switch (operator) {
    case '+':
        System.out.println(a + b);
        break;
    case '-':
        System.out.println(a - b);
        break;
    case '*':
        System.out.println(a * b);
        break;
    case '/':
        System.out.println(a / b);
        break;
    default:
        System.out.println("Invalid operator");
}
Output:
15

Role of break

break switch block से बाहर निकलने के लिए use होता है। अगर break नहीं लगाया गया, तो next cases भी execute हो सकते हैं। इसे fall-through कहा जाता है।

switch vs if-else

Basis switch if-else
Use Single expression के multiple fixed values। Complex conditions।
Readability Menu-based programs में clean। Range और logical conditions के लिए better।
Operators Relational conditions directly नहीं। Relational/logical conditions possible।
Remember:
switch case में break लगाना important है ताकि unwanted fall-through न हो।

Methods

Method Java में statements का reusable block होता है जो किसी specific task को perform करता है। Method program को modular बनाता है। अगर same task बार-बार करना हो, तो method बनाकर उसे multiple times call किया जा सकता है।

Java में method class के अंदर define होता है। Method input values ले सकता है जिन्हें parameters कहते हैं और result return कर सकता है। Method code readability, reusability और debugging को improve करता है।
