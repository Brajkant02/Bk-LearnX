Inheritance

Definition of Inheritance

Inheritance object-oriented programming का एक important concept है जिसमें एक class दूसरी class की properties और methods को acquire कर सकती है। जिस class से features inherit किए जाते हैं उसे parent class, base class या superclass कहा जाता है। जो class features receive करती है उसे child class, derived class या subclass कहा जाता है।

Java में inheritance का use code reusability, method overriding और class relationship represent करने के लिए किया जाता है। अगर कई classes में कुछ common data और methods हैं, तो उन्हें parent class में define करके child classes में reuse किया जा सकता है। इससे duplicate code कम होता है और program maintain करना आसान होता है।

Image Placeholder: Basic Inheritance Diagram

Basic Syntax

class Parent {
    // parent class members
}

class Child extends Parent {
    // child class members
}

Simple Example

class Animal {
    void eat() {
        System.out.println("Animal eats food");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }

    public static void main(String[] args) {
        Dog d = new Dog();

        d.eat();
        d.bark();
    }
}
Output:
Animal eats food
Dog barks

Important Terms

Term Meaning
Superclass जिस class से members inherit होते हैं।
Subclass जो class members inherit करती है।
extends Java keyword जो inheritance define करता है।
Reusability Existing code को new class में use करना।

Need of Inheritance

  • Common code को बार-बार लिखने से बचने के लिए।
  • Class relationship represent करने के लिए।
  • Program को organized और maintainable बनाने के लिए।
  • Method overriding के through runtime polymorphism achieve करने के लिए।
  • Large projects में code reuse बढ़ाने के लिए।
Real Life Example:
Person class में name और age common properties हो सकती हैं। Student और Teacher classes Person class से इन्हें inherit कर सकती हैं।
Remember:
Java में inheritance implement करने के लिए extends keyword use किया जाता है।

Protected Data

protected access modifier Java में data और methods को same class, same package और subclasses में accessible बनाता है। Protected data inheritance में useful होता है क्योंकि child class parent class के protected members को directly access कर सकती है, even अगर child class different package में हो, लेकिन access inheritance relation के through होना चाहिए।

Protected data private से ज्यादा accessible और public से कम accessible होता है। इसे तब use किया जाता है जब parent class अपने members child classes को access देना चाहती है, लेकिन पूरी दुनिया को direct access नहीं देना चाहती।

Image Placeholder: Protected Access in Inheritance

Example

class Animal {
    protected String name = "Dog";
}

class Dog extends Animal {
    void display() {
        System.out.println("Name: " + name);
    }

    public static void main(String[] args) {
        Dog d = new Dog();
        d.display();
    }
}
Output:
Name: Dog

Why Protected is Useful

  • Child class को parent data access करने की permission देता है।
  • Data को completely public नहीं बनाना पड़ता।
  • Inheritance-based design में controlled access देता है।
  • Same package classes भी protected members access कर सकती हैं।

Protected Access Scope

Location Access Allowed?
Same class Yes
Same package Yes
Subclass in same package Yes
Subclass in different package Yes, through inheritance
Non-subclass in different package No
Remember:
Protected members inheritance में child class को controlled access देने के लिए useful होते हैं।

Private Data

private access modifier Java में सबसे restrictive access देता है। Private data केवल उसी class के अंदर accessible होता है जिसमें वह declared है। Private members child class में inherit तो technically class structure का part नहीं बनते जिस तरह directly access हो सकें; child class उन्हें direct access नहीं कर सकती।

Private data encapsulation और data hiding के लिए use होता है। अगर किसी variable को direct modification से protect करना हो, तो उसे private बनाया जाता है और public getter तथा setter methods के through controlled access दिया जाता है।

Image Placeholder: Private Data and Encapsulation

Private Data Example

class Student {
    private int marks = 85;

    void displayMarks() {
        System.out.println("Marks: " + marks);
    }
}

class Main {
    public static void main(String[] args) {
        Student s = new Student();

        // System.out.println(s.marks); // Error
        s.displayMarks();
    }
}
Output:
Marks: 85

Accessing Private Data using Getter and Setter

class Student {
    private int marks;

    public void setMarks(int m) {
        marks = m;
    }

    public int getMarks() {
        return marks;
    }
}

class Main {
    public static void main(String[] args) {
        Student s = new Student();

        s.setMarks(90);
        System.out.println(s.getMarks());
    }
}
Output:
90

Benefits of Private Data

  • Data hiding provide करता है।
  • Direct unauthorized access रोकता है।
  • Encapsulation implement करने में help करता है।
  • Getter/setter से validation apply की जा सकती है।
  • Class internal implementation को safe रखता है।
Real Life Example:
Bank account balance को private रखना चाहिए। User direct balance change न करे, बल्कि deposit और withdraw methods से controlled change हो।
Remember:
Private members same class के बाहर direct access नहीं होते, child class में भी नहीं।

Public Data

public access modifier Java में सबसे open access देता है। Public data, methods या classes को same class, same package, different package और subclasses सभी जगह से access किया जा सकता है। Public members inheritance में child class के अंदर भी directly accessible होते हैं।

Public access easy होता है, लेकिन data variables को public बनाना हमेशा good practice नहीं माना जाता, क्योंकि कोई भी class उन्हें direct modify कर सकती है। Normally methods को public रखा जाता है और data को private/protected रखा जाता है।

Image Placeholder: Public Access Modifier Diagram

Public Method Example

class Student {
    public void display() {
        System.out.println("Public method can be accessed");
    }
}

class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}
Output:
Public method can be accessed

Public Data Example

class Student {
    public String name = "Brajkant";
}

class Main {
    public static void main(String[] args) {
        Student s = new Student();
        System.out.println(s.name);
    }
}
Output:
Brajkant

When to Use Public

  • जब method को other classes से access कराना जरूरी हो।
  • API methods या service methods expose करने के लिए।
  • Main class को outside package से accessible बनाना हो।
  • Constants को public static final के रूप में expose करना हो।

Careful Use

Public variables को avoid करना चाहिए क्योंकि वे direct modification allow करते हैं। Better practice यह है कि variables private रखें और public getter/setter methods दें।

Remember:
Public members हर जगह accessible होते हैं, इसलिए public data का use carefully करना चाहिए।

Constructor Chaining

Constructor chaining का मतलब है एक constructor से दूसरे constructor को call करना। Java में constructor chaining same class के अंदर this() से और parent class के constructor को call करने के लिए super() से की जाती है। Inheritance में constructor chaining बहुत important है क्योंकि child class का constructor parent class के constructor को call करता है।

जब child class object create होता है, तो सबसे पहले parent class constructor execute होता है, फिर child class constructor execute होता है। इससे parent part पहले initialize होता है और फिर child part initialize होता है।

Image Placeholder: Constructor Chaining with super()

Constructor Chaining in Same Class using this()

class Student {
    String name;
    int roll;

    Student() {
        this("Unknown", 0);
    }

    Student(String name, int roll) {
        this.name = name;
        this.roll = roll;
    }

    void display() {
        System.out.println(name + " " + roll);
    }

    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}
Output:
Unknown 0

Constructor Chaining in Inheritance using super()

class Animal {
    Animal() {
        System.out.println("Animal constructor");
    }
}

class Dog extends Animal {
    Dog() {
        super();
        System.out.println("Dog constructor");
    }

    public static void main(String[] args) {
        Dog d = new Dog();
    }
}
Output:
Animal constructor
Dog constructor

Important Rules

  • this() same class के constructor को call करता है।
  • super() parent class के constructor को call करता है।
  • this() या super() constructor की first statement होनी चाहिए।
  • एक constructor में this() और super() दोनों एक साथ first statement नहीं हो सकते।
  • अगर super() नहीं लिखा, तो compiler automatically no-argument super() insert कर सकता है।

Parameterized Parent Constructor

class Person {
    String name;

    Person(String name) {
        this.name = name;
    }
}

class Student extends Person {
    int roll;

    Student(String name, int roll) {
        super(name);
        this.roll = roll;
    }

    void display() {
        System.out.println(name + " " + roll);
    }

    public static void main(String[] args) {
        Student s = new Student("Brajkant", 101);
        s.display();
    }
}
Output:
Brajkant 101
Remember:
Inheritance में parent constructor पहले execute होता है, child constructor बाद में।

Order of Invocation

Inheritance में जब child class का object create होता है, तो constructors का execution एक specific order में होता है। Java पहले topmost parent class constructor को call करता है, फिर next child और अंत में actual child class constructor execute करता है। इसे order of invocation कहा जाता है।

Constructor invocation order इसलिए important है क्योंकि child object में parent class का part भी होता है। Parent part initialize हुए बिना child part properly initialize नहीं माना जाता।

Image Placeholder: Order of Invocation in Inheritance

Example

class A {
    A() {
        System.out.println("Constructor of A");
    }
}

class B extends A {
    B() {
        System.out.println("Constructor of B");
    }
}

class C extends B {
    C() {
        System.out.println("Constructor of C");
    }

    public static void main(String[] args) {
        C obj = new C();
    }
}
Output:
Constructor of A
Constructor of B
Constructor of C

Execution Flow

new C()
  ↓
C constructor calls B constructor
  ↓
B constructor calls A constructor
  ↓
A constructor executes first
  ↓
B constructor executes
  ↓
C constructor executes

Why Parent Constructor Executes First

  • Child object में parent class का inherited part भी होता है।
  • Parent data members को पहले initialize करना जरूरी होता है।
  • Child class parent members पर depend कर सकती है।
  • Object construction top-to-bottom hierarchy में complete होता है।

Initialization Order in Java

Order Process
1 Parent class static members load होते हैं।
2 Child class static members load होते हैं।
3 Parent instance variables और constructor execute होते हैं।
4 Child instance variables और constructor execute होते हैं।
Real Life Example:
Building में पहले foundation बनती है, फिर floors बनते हैं। इसी तरह object creation में parent class पहले initialize होती है, फिर child class।
Remember:
Constructor invocation order parent से child की direction में होता है।

Types of Inheritance

Inheritance के different types class relationships को represent करते हैं। Java में class-based inheritance के through single, multilevel और hierarchical inheritance directly supported हैं। Multiple और hybrid inheritance classes के through directly supported नहीं हैं, लेकिन interfaces के through similar behavior achieve किया जा सकता है।

Image Placeholder: Types of Inheritance Diagram

Types Overview

Type Meaning Java Class Support
Single Inheritance One child class one parent class से inherit करती है। Supported
Multilevel Inheritance Inheritance chain बनती है। Supported
Hierarchical Inheritance Multiple child classes same parent से inherit करती हैं। Supported
Multiple Inheritance One child multiple parents से inherit करती है। Classes के through not supported
Hybrid Inheritance Multiple inheritance types का combination। Classes के through directly not supported

Why Java Does Not Support Multiple Inheritance with Classes

Java classes के through multiple inheritance support नहीं करती क्योंकि इससे ambiguity problem हो सकती है। अगर two parent classes में same method हो और child class दोनों को inherit करे, तो compiler confuse हो सकता है कि कौन-सा method call हो। इसे diamond problem भी कहा जाता है।

Remember:
Java classes से single, multilevel और hierarchical inheritance support करती है। Multiple inheritance interfaces से achieve किया जाता है।

Single Inheritance

Single inheritance में एक child class एक parent class से inherit करती है। यह inheritance का simplest form है। इसमें child class parent class के accessible members को reuse कर सकती है और अपने additional members भी add कर सकती है।

Image Placeholder: Single Inheritance Diagram

Syntax

class Parent {
    // parent members
}

class Child extends Parent {
    // child members
}

Example

class Vehicle {
    void start() {
        System.out.println("Vehicle starts");
    }
}

class Bike extends Vehicle {
    void ride() {
        System.out.println("Bike is riding");
    }

    public static void main(String[] args) {
        Bike b = new Bike();

        b.start();
        b.ride();
    }
}
Output:
Vehicle starts
Bike is riding

Explanation

इस example में Bike class Vehicle class से inherit कर रही है। इसलिए Bike object start() method भी call कर सकता है और अपना ride() method भी call कर सकता है।

Uses

  • Simple parent-child relationship represent करने के लिए।
  • Common methods को parent class में रखने के लिए।
  • Code reuse करने के लिए।
  • Basic OOP structure समझने के लिए।
Real Life Example:
Vehicle parent class हो सकती है और Bike child class हो सकती है। Bike vehicle की basic properties inherit कर सकती है।

Multilevel Inheritance

Multilevel inheritance में inheritance chain बनती है। एक class दूसरी class से inherit करती है और फिर कोई third class उस second class से inherit करती है। इस तरह grandparent → parent → child relationship बनता है।

Image Placeholder: Multilevel Inheritance Diagram

Example

class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

class Puppy extends Dog {
    void weep() {
        System.out.println("Puppy weeps");
    }

    public static void main(String[] args) {
        Puppy p = new Puppy();

        p.eat();
        p.bark();
        p.weep();
    }
}
Output:
Animal eats
Dog barks
Puppy weeps

Explanation

यहाँ Dog class Animal से inherit कर रही है और Puppy class Dog से inherit कर रही है। इसलिए Puppy object Animal और Dog दोनों के accessible methods use कर सकता है।

Constructor Invocation in Multilevel Inheritance

class A {
    A() {
        System.out.println("A constructor");
    }
}

class B extends A {
    B() {
        System.out.println("B constructor");
    }
}

class C extends B {
    C() {
        System.out.println("C constructor");
    }

    public static void main(String[] args) {
        C obj = new C();
    }
}
Output:
A constructor
B constructor
C constructor
Remember:
Multilevel inheritance में child class अपने parent और grandparent दोनों के accessible members use कर सकती है।

Hierarchical Inheritance

Hierarchical inheritance में multiple child classes same parent class से inherit करती हैं। इसका use तब होता है जब एक common parent class से अलग-अलग specialized classes बनानी हों।

Image Placeholder: Hierarchical Inheritance Diagram

Example

class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Cat meows");
    }
}

class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        Cat c = new Cat();

        d.eat();
        d.bark();

        c.eat();
        c.meow();
    }
}
Output:
Animal eats
Dog barks
Animal eats
Cat meows

Explanation

यहाँ Dog और Cat दोनों Animal class से inherit कर रहे हैं। दोनों child classes parent class का eat() method use कर सकती हैं, लेकिन उनके अपने अलग methods भी हैं।

Uses

  • Common parent से कई related child classes बनाने के लिए।
  • Code duplication reduce करने के लिए।
  • Common behavior parent में और specific behavior child में रखने के लिए।
  • Real-world categories represent करने के लिए।
Real Life Example:
Person parent class हो सकती है और Student, Teacher, Staff child classes हो सकती हैं। Name और age common data parent में रखा जा सकता है।

Hybrid Inheritance

Hybrid inheritance दो या अधिक inheritance types का combination होता है। For example, single + hierarchical या multilevel + hierarchical मिलकर hybrid structure बना सकते हैं। Java में classes के through hybrid inheritance directly support नहीं होती अगर उसमें multiple inheritance शामिल हो। लेकिन interfaces की help से hybrid-like structure achieve किया जा सकता है।

Image Placeholder: Hybrid Inheritance Diagram

Hybrid Structure Concept

        A
       / \
      B   C
       \ /
        D

ऊपर diagram में D class B और C दोनों से inherit करना चाहेगी। Classes के through Java में यह direct possible नहीं है क्योंकि Java multiple inheritance with classes support नहीं करती।

Hybrid Using Interfaces

interface Printable {
    void print();
}

interface Showable {
    void show();
}

class Document implements Printable, Showable {
    public void print() {
        System.out.println("Printing document");
    }

    public void show() {
        System.out.println("Showing document");
    }

    public static void main(String[] args) {
        Document d = new Document();

        d.print();
        d.show();
    }
}
Output:
Printing document
Showing document

Why Interfaces Help

  • Java class multiple interfaces implement कर सकती है।
  • Interface ambiguity problem को reduce करता है।
  • Hybrid-like behavior achieve किया जा सकता है।
  • Flexible design possible होता है।

Important Point

Java में class केवल एक class को extend कर सकती है, लेकिन multiple interfaces implement कर सकती है। इसलिए hybrid inheritance का practical design interfaces के through किया जाता है।

Remember:
Java classes से hybrid inheritance directly support नहीं करती, लेकिन interfaces से hybrid-like design बनाया जा सकता है।

Access Control: Private Vs Public Vs Protected Vs Default

Access control Java में classes, variables, methods और constructors की visibility decide करता है। Java में four main access levels होते हैं: private, default, protected और public. Access modifiers encapsulation और security के लिए important होते हैं।

Image Placeholder: Access Modifiers Scope Diagram

Access Modifiers Overview

Modifier Same Class Same Package Subclass Different Package Other Package
private Yes No No No
Default Yes Yes No No
protected Yes Yes Yes No
public Yes Yes Yes Yes

Private Access

class Student {
    private int marks = 90;

    void show() {
        System.out.println(marks);
    }
}

Private member only same class के अंदर accessible होता है।

Default Access

class Student {
    int roll = 101;
}

अगर कोई modifier नहीं लिखा, तो default access होता है। Default members same package में accessible होते हैं।

Protected Access

class Person {
    protected String name = "Brajkant";
}

class Student extends Person {
    void display() {
        System.out.println(name);
    }
}

Protected members same package और subclasses में accessible होते हैं।

Public Access

public class Student {
    public void display() {
        System.out.println("Public method");
    }
}

Public members हर जगह accessible होते हैं।

Private vs Public vs Protected vs Default

Basis Private Default Protected Public
Keyword private No keyword protected public
Accessibility Only same class Same package Same package + subclass Everywhere
Security Highest Package-level Controlled inheritance access Lowest control
Common Use Data hiding Package internal code Inheritance-based access Public methods/classes

Best Practice

  • Variables को usually private रखें।
  • Getter और setter methods से controlled access दें।
  • Methods को requirement के according public/protected रखें।
  • Inheritance में child class access के लिए protected use किया जा सकता है।
  • हर चीज public बनाना good practice नहीं है।
Real Life Example:
Bank account balance private होना चाहिए, account holder name protected या private हो सकता है और account statement print करने का method public हो सकता है।
Remember:
Private सबसे restricted है और public सबसे open access देता है।
