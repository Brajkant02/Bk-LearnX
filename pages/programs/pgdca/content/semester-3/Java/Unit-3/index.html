Classes and Objects

Class Fundamentals

Class Java में object-oriented programming का सबसे basic और important concept है। Class एक blueprint, template या design की तरह होती है जिससे objects create किए जाते हैं। Class के अंदर data members यानी variables और behavior यानी methods define किए जाते हैं।

Java में हर program कम से कम एक class के अंदर लिखा जाता है। Class real-world entity का structure represent करती है। For example, अगर हमें student information manage करनी है, तो हम Student class बना सकते हैं जिसमें name, roll number और course जैसे variables तथा displayDetails जैसे methods हो सकते हैं।

class ClassName {

Member Meaning Example

Class Naming Convention

  • Class name capital letter से start करना best practice है।
  • Class name meaningful होना चाहिए।
  • एक Java file में public class का name file name से match करना चाहिए।
  • Class के अंदर variables और methods logically related होने चाहिए।
Real Life Example:
Student class एक admission form के format जैसी है। उस format से कई students के records बनाए जा सकते हैं।
Remember:
Class object बनाने का blueprint है, actual data object में store होता है।

Constructors

Constructor special method जैसा block होता है जो object create होने पर automatically call होता है। Constructor का main purpose object को initialize करना होता है। Constructor का name class name के same होता है और इसका कोई return type नहीं होता, even void भी नहीं।

जब हम new keyword से object create करते हैं, तो constructor automatically execute होता है। Constructor की help से object के variables को starting values दी जा सकती हैं।

Constructor Rules

  • Constructor का name class name के same होना चाहिए।
  • Constructor का return type नहीं होता।
  • Object create होते समय constructor automatically call होता है।
  • Constructor overloaded हो सकता है।
  • अगर programmer constructor नहीं बनाता, तो Java default constructor provide करती है।

Default Constructor

class Student {
    Student() {
        System.out.println("Student object created");
    }

    public static void main(String[] args) {

    }

Parameterized Constructor

class Student {
    String name;
    int roll;

    Student(String n, int r) {
        name = n;
        roll = r;
    }

    void display() {
        System.out.println(name + " " + roll);
    }

    public static void main(String[] args) {
        Student s1 = new Student("Brajkant", 101);
        s1.display();
    }
}
Output:
Brajkant 101

Constructor Overloading

एक class में multiple constructors हो सकते हैं, लेकिन उनके parameters अलग होने चाहिए। इसे constructor overloading कहते हैं।

class Student {
    String name;
    int roll;

    Student() {
        name = "Unknown";
        roll = 0;
    }

    Student(String n, int r) {
        name = n;
        roll = r;
    }

    void display() {
        System.out.println(name + " " + roll);
    }

    public static void main(String[] args) {
        Student s1 = new Student();
        Student s2 = new Student("Amit", 102);

        s1.display();
        s2.display();
    }
}
Output:
Unknown 0
Amit 102

Declaring Objects: Object and Object Reference

Object class का real instance होता है। Class केवल blueprint होती है, लेकिन object actual memory में create होता है। Object के पास class में defined variables और methods की copy/access होती है। Object real-world entity को represent करता है।

Object Reference वह variable होता है जो object की memory location को refer करता है। Java में object directly variable में store नहीं होता; reference variable object तक पहुँचने का address-like reference रखता है।

Object Creation

s1 = new Student();

यहाँ new Student() actual object create करता है और उसका reference s1 में store होता है।

Declaration and Creation Together

    String name;

Brajkant 101

Creating and Accessing Variables and Methods

Class के अंदर variables और methods define किए जाते हैं। Object create करने के बाद dot operator . की help से variables और methods access किए जाते हैं। Variables object की state represent करते हैं और methods object का behavior represent करते हैं।

Image Placeholder: Accessing Variables and Methods Using Dot Operator

Dot Operator

objectName.variableName;
objectName.methodName();

Example

class Car {
    String brand;
    int speed;

    void showDetails() {
        System.out.println("Brand: " + brand);
        System.out.println("Speed: " + speed);
    }

    public static void main(String[] args) {
        Car c1 = new Car();

        c1.brand = "Honda";
        c1.speed = 120;

        c1.showDetails();
    }
}
Output:
Brand: Honda
Speed: 120

Method with Parameters

class Calculator {
    void add(int a, int b) {
        System.out.println("Sum: " + (a + b));
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        calc.add(10, 20);
    }
}
Output:
Sum: 30

Method with Return Value

class Calculator {
    int square(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        int result = calc.square(5);

        System.out.println(result);
    }
}
Output:
25

Static and Non Static Variables/Methods

Java में variables और methods static या non-static हो सकते हैं। Static members class से belong करते हैं, जबकि non-static members object से belong करते हैं। Static members को class name से access किया जा सकता है, जबकि non-static members के लिए object create करना पड़ता है।

Image Placeholder: Static vs Non-Static Memory Diagram

Static Variable

Static variable class level variable होता है। यह सभी objects के बीच shared होता है। अगर किसी value को सभी objects के लिए common रखना हो, तो static variable use किया जा सकता है।

class Student {
    String name;
    static String college = "Government Polytechnic Kanpur";

    Student(String n) {
        name = n;
    }

    void display() {
        System.out.println(name + " - " + college);
    }

    public static void main(String[] args) {
        Student s1 = new Student("Brajkant");
        Student s2 = new Student("Amit");

        s1.display();
        s2.display();
    }
}
Output:
Brajkant - Government Polytechnic Kanpur
Amit - Government Polytechnic Kanpur

Static Method

Static method class से belong करता है। इसे object बनाए बिना class name से call किया जा सकता है। main() method भी static होता है क्योंकि program start होते समय object create नहीं होता। 

class MathUtil {
    static int square(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        int result = MathUtil.square(5);
        System.out.println(result);
    }
}
Output:
25

Non-Static Variable and Method

Non-static variables और methods object से belong करते हैं। हर object की अपनी separate copy/value हो सकती है। इन्हें access करने के लिए object की जरूरत होती है।

class Student {
    String name;

    void showName() {
        System.out.println(name);
    }

    public static void main(String[] args) {
        Student s1 = new Student();
        s1.name = "Brajkant";
        s1.showName();
    }
}

Defining Packages

Package Java में related classes और interfaces का group होता है। Package का use code को organize करने, naming conflict avoid करने और access control manage करने के लिए किया जाता है। बड़े projects में classes को अलग-अलग packages में रखना professional practice है।

Java में package दो types के होते हैं: built-in packages और user-defined packages. Built-in packages Java library में already available होते हैं, जैसे java.util, java.io, java.lang. User-defined packages programmer खुद बनाता है।

Image Placeholder: Java Package Folder Structure

Package Declaration Syntax

package packageName;

Example

package mypack;

public class Student {
    public void display() {
        System.out.println("Student class in mypack package");
    }
}

Important Rules

  • Package statement Java file की first statement होनी चाहिए।
  • Package name usually lowercase में लिखा जाता है।
  • Package folder structure से related होता है।
  • Public class को package के बाहर access किया जा सकता है।
  • Same package में related classes रखना best practice है।

Advantages of Packages

Advantage Explanation
Code Organization Related classes को group किया जा सकता है।
Name Conflict Avoid Same class name different packages में use हो सकता है।
Access Control Package-level access control possible होता है।
Reusability Package classes को other programs में use किया जा सकता है।
Maintenance Large project maintain करना easy होता है।

Built-in Package Example

import java.util.Scanner;

यहाँ java.util built-in package है और Scanner class उसी package में available है।

Real Life Example:
College project में student, teacher, fees और result अलग-अलग packages हो सकते हैं।
Remember:
Package classes को organize करने और naming conflicts avoid करने के लिए use होता है।

Creating and Accessing a Package

User-defined package create करने के लिए Java file के top पर package statement लिखी जाती है। Package name के according folder structure भी maintain किया जाता है। Package create करने के बाद उसकी class को दूसरे program से import करके access किया जा सकता है।

Image Placeholder: Creating and Accessing Package Flow

package mypack;

public class Message {
    public void show() {

Step 2: Compile Package Class

javac -d . Message.java

-d . option package folder structure create करने में help करता है।

Step 3: Access Package Class

// File: Test.java
import mypack.Message;

class Test {
    public static void main(String[] args) {

  • Package statement file की first statement न रखना।
  • Class को public न बनाना और दूसरे package से access करने की कोशिश करना।
  • Folder structure package name से match न करना।
  • Compile command में -d option न use करना।

Package class को दूसरे program में access करने के लिए class public होनी चाहिए और package properly import होना चाहिए।

Importing Packages

Java में package की classes use करने के लिए import keyword use किया जाता है। Import statement compiler को बताता है कि required class किस package में available है। Import statement package statement के बाद और class declaration से पहले लिखी जाती है।

Import Single Class

import java.util.Scanner;

Import All Classes from Package

import java.util.*;

यह java.util package की सभी classes को accessible बनाता है। लेकिन sub-packages automatically import नहीं होते।

Scanner Example

import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter name: ");
        String name = sc.nextLine();

        System.out.println("Name: " + name);
    }
}

Using java.util.*

import java.util.*;

class Main {

Understanding CLASSPATH

CLASSPATH Java में वह path होता है जहाँ Java compiler और JVM classes, packages और libraries को search करते हैं। जब हम कोई Java program compile या run करते हैं और उसमें दूसरे package या class का use होता है, तो Java को पता होना चाहिए कि वह class कहाँ available है। यह information CLASSPATH से मिलती है।

Simple words में, CLASSPATH Java को class files की location बताता है। अगर required class CLASSPATH में available नहीं है, तो ClassNotFoundException या compile-time error आ सकता है।

Image Placeholder: CLASSPATH Search Diagram

Why CLASSPATH is Needed

  • Compiler को required classes की location बताने के लिए।
  • JVM को runtime पर classes load करने के लिए।
  • User-defined packages access करने के लिए।
  • External libraries/JAR files use करने के लिए।

Current Directory as Classpath

java -cp . Main

यह command current directory से classes search करती है।

Classpath with Package Folder

javac -cp . Test.java
java -cp . Test

Classpath with JAR File

java -cp mylibrary.jar Main

Classpath with Multiple Locations

java -cp .;mylibrary.jar Main

Windows में multiple paths separate करने के लिए semicolon ; use होता है। Linux/Mac में colon : use होता है।

Common CLASSPATH Problems

Problem Reason
Class not found Class file CLASSPATH में नहीं है।
Package does not exist Package folder या path गलत है।
JAR not found JAR file का path गलत है।
Wrong version class Old class file load हो रही है।

Important Point for Beginners

अगर Java files same folder में हैं और packages use नहीं हो रहे, तो simple compile/run commands enough होते हैं। Packages और external libraries use करते समय CLASSPATH समझना जरूरी हो जाता है।

Real Life Example:
जैसे किसी file को open करने के लिए computer को file की location पता होनी चाहिए, वैसे ही Java को class file की location CLASSPATH से पता चलती है।
Remember:
CLASSPATH Java compiler और JVM को बताता है कि required classes कहाँ search करनी हैं।

Auto Boxing

Autoboxing Java में primitive data type को automatically उसके corresponding wrapper class object में convert करने की process है। For example, int value automatically Integer object में convert हो सकती है। इसके reverse process को Unboxing कहा जाता है।

Wrapper classes primitive types को object form में represent करती हैं। Collections जैसे ArrayList primitive values directly store नहीं करते, वे objects store करते हैं। ऐसे cases में autoboxing बहुत useful है।

Image Placeholder: Autoboxing and Unboxing Diagram

Primitive and Wrapper Classes

Primitive Type Wrapper Class
byte Byte
short Short
int Integer
long Long
float Float
double Double
char Character
boolean Boolean

Autoboxing Example

class Main {
    public static void main(String[] args) {
        int a = 10;

        Integer obj = a;   // Autoboxing

        System.out.println(obj);
    }
}
Output:
10

Unboxing Example

class Main {
    public static void main(String[] args) {
        Integer obj = 25;

        int num = obj;   // Unboxing

        System.out.println(num);
    }
}
Output:
25

Autoboxing in Collection

import java.util.ArrayList;

class Main {
    public static void main(String[] args) {
        ArrayList<Integer> numbers = new ArrayList<>();

        numbers.add(10);   // int automatically Integer में convert
        numbers.add(20);

        System.out.println(numbers);
    }
}
Output:
[10, 20]

Benefits

  • Primitive और object conversion automatic हो जाता है।
  • Code simple और readable बनता है।
  • Collections में primitive values use करना easy हो जाता है।
  • Manual wrapper object creation की जरूरत कम हो जाती है।
Remember:
Autoboxing primitive to wrapper conversion है और unboxing wrapper to primitive conversion है।

String

String Java में characters का sequence होता है। String का use text data store करने के लिए किया जाता है। Java में String class java.lang package में होती है और यह automatically available रहती है। String immutable होती है, यानी once create होने के बाद उसका original content change नहीं होता।

String Buffer

StringBuffer Java में mutable sequence of characters represent करता है। Mutable का मतलब है कि StringBuffer object का content modify किया जा सकता है। अगर किसी text को बार-बार change करना हो, जैसे append, insert, delete या reverse, तो StringBuffer normal String से ज्यादा suitable हो सकता है।

String immutable होती है, इसलिए repeated modifications में multiple new objects बन सकते हैं। StringBuffer existing object को modify करता है। StringBuffer thread-safe भी होता है, यानी synchronized methods provide करता है।

String vs StringBuffer

Basis String StringBuffer
Mutability Immutable Mutable
Modification New object create हो सकता है। Same object modify होता है।
Performance Repeated changes में slower हो सकती है। Repeated changes में better।
Thread Safety Immutable होने से safe nature। Methods synchronized होते हैं।
Use Fixed text data। Frequently changing text data।
Real Life Example:
अगर program में report text धीरे-धीरे add करके बनाना है, तो StringBuffer use करना useful हो सकता है।
Remember:
String immutable है, StringBuffer mutable है। Repeated text modification के लिए StringBuffer better होता है।
