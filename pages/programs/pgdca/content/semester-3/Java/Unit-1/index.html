Introduction and Features

Introduction to Java

Java एक high-level, object-oriented, secure और platform independent programming language है। इसका use desktop applications, web applications, mobile applications, enterprise applications, banking systems, Android apps और server-side software development में किया जाता है। Java का design इस तरह किया गया है कि एक बार लिखा गया program अलग-अलग operating systems पर run हो सके। इसी idea को commonly Write Once, Run Anywhere कहा जाता है।

Java में programs classes और objects के concept पर based होते हैं। इसका मतलब है कि Java real-world entities को program के अंदर represent करने की facility देती है। For example, Student, Book, Account, Employee और Product जैसे real-world objects को Java में class और object की help से represent किया जा सकता है।

Java की सबसे बड़ी strength इसकी platform independence है। Java source code पहले bytecode में convert होता है और फिर JVM यानी Java Virtual Machine उस bytecode को run करती है। इसी वजह से Java program Windows, Linux, Mac जैसे अलग-अलग platforms पर run हो सकता है, अगर वहाँ JVM available है।

Brief History of Java

Java का development 1990s में Sun Microsystems में हुआ था। Java को James Gosling और उनकी team ने develop किया। शुरुआत में इसका नाम Oak रखा गया था, लेकिन बाद में इसका नाम Java कर दिया गया। Java को originally embedded systems और electronic devices के लिए design किया गया था, लेकिन internet और web applications के growth के साथ Java बहुत popular हो गई।

Java का first official version 1995 में release हुआ। उस time Java का platform independent nature बहुत important था क्योंकि internet पर अलग-अलग types के computers और operating systems connected थे। Java ने developers को ऐसा software बनाने की facility दी जो अलग-अलग machines पर run हो सके।

Java Platform

Java platform उन tools और technologies का collection है जिनकी help से Java programs develop और run किए जाते हैं। Java platform में mainly JDK, JRE और JVM आते हैं। इस introduction chapter में इन्हें सिर्फ overview level पर समझना sufficient है। आगे Java installation और programming chapters में इन्हें ज्यादा clearly समझा जा सकता है।

JDK

JDK का full form Java Development Kit है। यह Java programs develop करने के लिए required tools provide करता है। इसमें compiler, debugger और other development tools होते हैं।

JRE

JRE का full form Java Runtime Environment है। यह Java program run करने के लिए environment provide करता है। JRE में JVM और required libraries included होती हैं।

JVM

JVM का full form Java Virtual Machine है। JVM Java bytecode को machine understandable instructions में convert करके execute करती है।

Features of Java

Java की popularity का main reason इसकी powerful features हैं। Java को simple, secure, robust, portable और object-oriented बनाया गया है। नीचे Java के important features को introduction level पर explain किया गया है।

Image Placeholder: Features of Java Diagram

Simple

Java को simple language माना जाता है क्योंकि इसकी syntax C और C++ से inspired है, लेकिन इसमें complex features जैसे pointer और multiple inheritance through classes को avoid किया गया है। Java में memory management भी mostly automatic garbage collection से होता है।

Object-Oriented

Java object-oriented language है। इसमें program classes और objects के around design किया जाता है। OOP approach से code को modular, reusable और maintainable बनाया जा सकता है।

Platform Independent

Java platform independent है क्योंकि Java source code compile होकर bytecode में convert होता है। यह bytecode किसी भी platform पर JVM की help से run हो सकता है।

Secure

Java security features provide करती है। Java में explicit pointer support नहीं होता, जिससे direct memory access की risk कम हो जाती है। JVM bytecode verification करती है।

Robust

Robust का मतलब strong और reliable होता है। Java strong memory management, exception handling और type checking provide करती है। Garbage collector unused objects को memory से remove करता है।

Portable

Java portable language है क्योंकि Java bytecode different platforms पर move किया जा सकता है। Java में data types का size fixed होता है, जिससे behavior consistent रहता है।

Architecture Neutral

Java compiler architecture-independent bytecode generate करता है। यह bytecode किसी specific processor या machine architecture पर dependent नहीं होता।

High Performance

Java में Just-In-Time compiler की help से performance improve होती है। JIT compiler frequently used bytecode को native machine code में convert कर सकता है।

Multithreaded

Java multithreading support करती है। Multithreading की help से program में multiple tasks एक साथ run हो सकते हैं।

Distributed

Java distributed applications बनाने में support करती है। Distributed application में program के parts अलग-अलग systems पर run कर सकते हैं।

Dynamic

Java runtime पर classes load कर सकती है और changing environment में adapt कर सकती है।

Interpreted

Java source code पहले bytecode में compile होता है और फिर JVM उस bytecode को interpret या execute करती है।

Procedure-Oriented Programming

Procedure-Oriented Programming या POP एक programming approach है जिसमें program को procedures या functions के group के रूप में design किया जाता है। इसमें main focus functions पर होता है। Data और functions अलग-अलग हो सकते हैं। Program का execution step-by-step होता है और functions को required order में call किया जाता है।

POP approach छोटे और simple programs के लिए useful हो सकती है। C language procedure-oriented programming का common example मानी जाती है। लेकिन large projects में data security और maintenance की problems आ सकती हैं।

Image Placeholder: POP Working Diagram

Characteristics of POP

  • Program functions या procedures में divide होता है।
  • Main focus functions पर होता है।
  • Data और functions अलग-अलग रखे जा सकते हैं।
  • Top-down approach follow करता है।
  • Small programs के लिए suitable हो सकता है।
Remember:
POP में focus functions/procedures पर होता है, objects पर नहीं।

Object-Oriented Programming

Object-Oriented Programming या OOP एक programming approach है जिसमें program को objects के रूप में design किया जाता है। Object real-world entity को represent करता है। Object में data और behavior दोनों हो सकते हैं। Data को attributes या fields कहा जाता है और behavior को methods कहा जाता है।

OOP large software development के लिए बहुत useful है क्योंकि इसमें program को modular और reusable बनाया जा सकता है। OOP में data और methods को class के अंदर combine किया जाता है।

Characteristics of OOP

  • Program objects के around design होता है।
  • Data और methods class में bind होते हैं।
  • Code reuse possible होता है।
  • Large applications के लिए suitable होता है।
Remember:
OOP में focus objects पर होता है, जो data और behavior दोनों को represent करते हैं।

Abstraction

Abstraction का मतलब unnecessary internal details को hide करके केवल essential features show करना है। OOP में abstraction user को simple interface देता है और complex internal working को hide करता है।

For example, जब हम ATM machine से money withdraw करते हैं, तो हमें internal banking process नहीं दिखती। हमें केवल options दिखते हैं।

Encapsulation

Encapsulation का मतलब data और methods को एक single unit में bind करना है। Java में class encapsulation का basic example है क्योंकि class के अंदर data members और methods दोनों रखे जाते हैं।

Encapsulation से object का data direct access से protect किया जा सकता है। Proper methods के through data access और modify किया जाता है।

Inheritance

Inheritance OOP का concept है जिसमें एक class दूसरी class की properties और methods को acquire कर सकती है। जिस class से features लिए जाते हैं उसे parent class या superclass कहा जाता है और जो class features receive करती है उसे child class या subclass कहा जाता है।

Inheritance का main purpose code reuse है। अगर कुछ features common हैं, तो उन्हें parent class में define करके child classes में reuse किया जा सकता है।

Polymorphism

Polymorphism का मतलब है many forms. OOP में polymorphism का मतलब है कि same method name या same operation अलग-अलग objects के साथ different behavior दिखा सकता है। यह program को flexible बनाता है।

Java में polymorphism method overloading और method overriding जैसे concepts से related होता है। इस introduction chapter में केवल basic idea दिया गया है।

Introduction of Eclipse IDE

Eclipse एक popular IDE यानी Integrated Development Environment है जिसका use Java programs develop करने के लिए किया जाता है। IDE ऐसा software environment होता है जिसमें code लिखने, compile करने, run करने और debug करने की facilities एक ही जगह मिलती हैं।

Eclipse में code editor, project explorer, console, debugger, syntax highlighting, auto-completion और error detection जैसी facilities available होती हैं। Beginner students के लिए Eclipse helpful है क्योंकि इसमें Java project create करना, class बनाना और program run करना easier हो जाता है।
