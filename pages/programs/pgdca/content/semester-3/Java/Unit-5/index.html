Abstract Class and Interface

Abstract Class

Abstract class Java में ऐसी class होती है जिसे directly instantiate नहीं किया जा सकता, यानी उसका object direct create नहीं किया जा सकता। Abstract class का use common structure और partial implementation provide करने के लिए किया जाता है। इसमें abstract methods भी हो सकते हैं और normal methods भी।

Abstract class को define करने के लिए abstract keyword use किया जाता है। अगर किसी class में abstract method है, तो उस class को abstract declare करना जरूरी होता है। Abstract method वह method होता है जिसका केवल declaration होता है, body नहीं होती। उसकी body subclass provide करती है।

Image Placeholder: Abstract Class Diagram

Abstract Class Syntax

abstract class ClassName {
    abstract void methodName();

    void normalMethod() {
        // method body
    }
}

Example

abstract class Animal {
    abstract void sound();

    void eat() {
        System.out.println("Animal eats food");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Dog barks");
    }

    public static void main(String[] args) {
        Dog d = new Dog();

        d.sound();
        d.eat();
    }
}
Output:
Dog barks
Animal eats food

Important Points

  • Abstract class का object directly create नहीं किया जा सकता।
  • Abstract class में abstract और non-abstract दोनों methods हो सकते हैं।
  • Abstract method की body नहीं होती।
  • Subclass abstract methods को override करके body provide करती है।
  • Abstract class constructors रख सकती है।
  • Abstract class variables और methods दोनों contain कर सकती है।

Why Abstract Class is Used

Abstract class तब useful होती है जब parent class में कुछ common implementation देनी हो, लेकिन कुछ methods child classes के according अलग-अलग implement करवाने हों। इससे common code reuse होता है और subclasses को एक fixed structure follow करना पड़ता है।

Real Life Example:
Vehicle abstract class हो सकती है जिसमें fuelType common method हो और start() abstract method हो। Car और Bike अपने हिसाब से start() method implement कर सकती हैं।
Remember:
Abstract class incomplete class होती है जिसे complete करने का काम subclass करती है।

Defining an Interface

Interface Java में एक blueprint होता है जो class को बताता है कि कौन-कौन से methods implement करने हैं। Interface में method declarations होते हैं और implementing class उन methods की body provide करती है। Interface abstraction achieve करने का powerful तरीका है।

Interface define करने के लिए interface keyword use होता है। Class interface को implement करने के लिए implements keyword use करती है। Interface के methods by default public और abstract माने जाते हैं। Interface के variables by default public static final होते हैं।

Image Placeholder: Interface Blueprint Diagram

Interface Syntax

interface InterfaceName {
    void methodName();
}

class ClassName implements InterfaceName {
    public void methodName() {
        // method body
    }
}

Example

interface Printable {
    void print();
}

class Document implements Printable {
    public void print() {
        System.out.println("Printing document");
    }

    public static void main(String[] args) {
        Document d = new Document();
        d.print();
    }
}
Output:
Printing document

Interface with Multiple Methods

interface Shape {
    void draw();
    void area();
}

class Circle implements Shape {
    public void draw() {
        System.out.println("Drawing circle");
    }

    public void area() {
        System.out.println("Calculating circle area");
    }

    public static void main(String[] args) {
        Circle c = new Circle();

        c.draw();
        c.area();
    }
}
Output:
Drawing circle
Calculating circle area

Rules for Interface

  • Interface का object directly create नहीं किया जा सकता।
  • Class interface को implements keyword से use करती है।
  • Implementing class को interface के abstract methods implement करने होते हैं।
  • Interface multiple inheritance achieve करने में help करता है।
  • Interface variables by default constants होते हैं।

Interface Variable Example

interface College {
    String NAME = "Government Polytechnic Kanpur";
}

class Student implements College {
    public static void main(String[] args) {
        System.out.println(NAME);
    }
}
Output:
Government Polytechnic Kanpur
Remember:
Interface method declaration देता है और class उस method की implementation देती है।

Difference between Classes and Interface

Class और interface दोनों Java में object-oriented design के important parts हैं, लेकिन दोनों का purpose अलग है। Class object create करने का blueprint है जिसमें variables, constructors और methods हो सकते हैं। Interface behavior का contract define करता है जिसे implementing class follow करती है।

Class Example

class Student {
    String name;

    void display() {
        System.out.println(name);
    }
}

Interface Example

interface Printable {
    void print();
}

Keyword class interface

Methods Concrete methods और abstract methods हो सकते हैं। Mostly abstract methods; default/static methods भी हो सकते हैं।

When Class is Used

  • जब object create करना हो।
  • जब data और methods दोनों define करने हों।
  • जब common implementation देनी हो।
  • जब constructor की जरूरत हो।

When Interface is Used

  • जब केवल behavior contract define करना हो।
  • जब multiple inheritance जैसी facility चाहिए।
  • जब different classes को same method structure follow करवाना हो।
  • जब full abstraction achieve करनी हो।
Real Life Example:
Class एक actual form design जैसी है, जिससे records बनते हैं। Interface rule book जैसी है, जो बताती है कि कौन-से actions जरूर होने चाहिए।
Remember:
Class object बनाती है, interface behavior का contract define करता है।

Key Points of Abstract Class & Interface

Abstract class और interface दोनों abstraction provide करते हैं, लेकिन इनके use cases अलग होते हैं। Abstract class partial abstraction provide कर सकती है क्योंकि इसमें abstract और concrete दोनों methods हो सकते हैं। Interface generally contract-based abstraction provide करता है।

Image Placeholder: Abstract Class & Interface Key Points Diagram

Key Points of Abstract Class

  • Abstract class abstract keyword से define होती है।
  • Abstract class का object direct create नहीं किया जा सकता।
  • इसमें abstract और non-abstract दोनों methods हो सकते हैं।
  • Abstract class constructors रख सकती है।
  • Abstract class instance variables रख सकती है।
  • Subclass abstract methods को implement करती है।
  • Abstract class partial implementation provide करने के लिए useful है।

Key Points of Interface

  • Interface interface keyword से define होता है।
  • Interface का object direct create नहीं किया जा सकता।
  • Class interface को implements keyword से implement करती है।
  • Interface methods by default public abstract होते हैं।
  • Interface variables by default public static final होते हैं।
  • Class multiple interfaces implement कर सकती है।
  • Interface multiple inheritance achieve करने में help करता है।

Abstract Class with Constructor

abstract class Person {
    Person() {
        System.out.println("Person constructor");
    }

    abstract void work();
}

class Teacher extends Person {
    void work() {
        System.out.println("Teacher teaches");
    }

    public static void main(String[] args) {
        Teacher t = new Teacher();
        t.work();
    }
}
Output:
Person constructor
Teacher teaches

    }
}

Difference between an Abstract Class & Interface

Abstract class और interface दोनों abstraction achieve करने के लिए use होते हैं, लेकिन दोनों में कई practical differences हैं। Abstract class तब use होती है जब related classes में common data और common implementation share करनी हो। Interface तब use होता है जब unrelated classes को same behavior follow करवाना हो या multiple inheritance जैसी facility चाहिए।

Abstract Class Example

abstract class Bank {
    void bankInfo() {
        System.out.println("Bank provides financial services");
    }

    abstract void interestRate();
}

class SBI extends Bank {
    void interestRate() {
        System.out.println("Interest rate: 6%");
    }
}

Interface Example

interface Drawable {
    void draw();
}

class Circle implements Drawable {
    public void draw() {
        System.out.println("Drawing circle");
    }
}

When to Choose Abstract Class

  • जब related classes में common data हो।
  • जब common methods की implementation share करनी हो।
  • जब constructors की need हो।
  • जब partial abstraction चाहिए।

When to Choose Interface

  • जब multiple inheritance जैसा design चाहिए।
  • जब only behavior contract define करना हो।
  • जब unrelated classes को same actions implement करवाने हों।
  • जब full abstraction या loose coupling चाहिए।
Real Life Example:
Vehicle abstract class हो सकती है क्योंकि Car और Bike related हैं। Printable interface हो सकता है क्योंकि Document, Image और Bill सभी printable हो सकते हैं, भले वे unrelated classes हों।
Remember:
Abstract class “is-a base” relation के लिए और interface “can-do behavior” relation के लिए ज्यादा useful है।

Implementation of Multiple Inheritance through Interface

Java classes के through multiple inheritance support नहीं करती। इसका कारण ambiguity problem है। अगर एक child class दो parent classes से same method inherit करे, तो compiler confuse हो सकता है कि कौन-सा method use करना है। इस problem को avoid करने के लिए Java ने classes के साथ multiple inheritance allow नहीं किया।

लेकिन Java interface के through multiple inheritance achieve कर सकती है। एक class multiple interfaces implement कर सकती है। Interfaces केवल method contract provide करते हैं और implementing class actual method body देती है। इससे ambiguity कम होती है और flexible design possible होता है।

Image Placeholder: Multiple Inheritance through Interface Diagram

Multiple Inheritance Problem with Classes

class A {
    void show() {
        System.out.println("A");
    }
}

class B {
    void show() {
        System.out.println("B");
    }
}

// Java does not allow this:
// class C extends A, B { }

Multiple Inheritance using Interfaces

interface Printable {
    void print();
}

interface Showable {
    void show();
}

class Document implements Printable, Showable {
    public void print() {
        System.out.println("Printing document");
    }

    public void show() {
        System.out.println("Showing document");
    }

    public static void main(String[] args) {
        Document d = new Document();

        d.print();
        d.show();
    }
}
Output:
Printing document
Showing document

Example with Same Method Name

अगर two interfaces में same method declaration हो, तो implementing class एक method body provide कर सकती है।

interface A {
    void display();
}

interface B {
    void display();
}

class C implements A, B {
    public void display() {
        System.out.println("Display method implemented");
    }

    public static void main(String[] args) {
        C obj = new C();
        obj.display();
    }
}
Output:
Display method implemented

Interface Extending Multiple Interfaces

interface A {
    void methodA();
}

interface B {
    void methodB();
}

interface C extends A, B {
    void methodC();
}

class Test implements C {
    public void methodA() {
        System.out.println("Method A");
    }

    public void methodB() {
        System.out.println("Method B");
    }

    public void methodC() {
        System.out.println("Method C");
    }
}

Benefits

  • Multiple inheritance जैसी facility मिलती है।
  • Ambiguity problem reduce होती है।
  • Class को multiple behaviors provide किए जा सकते हैं।
  • Loose coupling और flexible design possible होता है।
  • Large applications में contract-based programming easy होती है।

Important Points

Point Explanation
Class Extends Java class only one class extend कर सकती है।
Class Implements Java class multiple interfaces implement कर सकती है।
Keyword Multiple interfaces के लिए implements Interface1, Interface2
Method Body Implementing class methods की body देती है।
Real Life Example:
SmartPhone class Camera, MusicPlayer और InternetDevice interfaces implement कर सकती है। एक phone multiple behaviors perform कर सकता है।
Remember:
Java में multiple inheritance classes से नहीं, interfaces से achieve किया जाता है।

Default and Static Methods in Interface

Modern Java में interfaces केवल abstract methods तक limited नहीं हैं। Interface में default और static methods भी define किए जा सकते हैं। Default method की body interface के अंदर होती है और implementing class उसे override कर सकती है। Static method interface name से call होता है।

Default Method Example

interface Vehicle {
    default void start() {
        System.out.println("Vehicle starts");
    }
}

class Car implements Vehicle {
    public static void main(String[] args) {
        Car c = new Car();
        c.start();
    }
}
Output:
Vehicle starts

Static Method Example

interface MathHelper {
    static int square(int n) {
        return n * n;
    }
}

class Main {
    public static void main(String[] args) {
        System.out.println(MathHelper.square(5));
    }
}
Output:
25

Why Default Methods Were Added

  • Existing interfaces में new methods add करने के लिए।
  • Old implementing classes को break होने से बचाने के लिए।
  • Common behavior interface में provide करने के लिए।
  • Backward compatibility maintain करने के लिए।

Important Points

Method Type Call/Use
Abstract Method Class implement करती है।
Default Method Interface में body होती है, class override कर सकती है।
Static Method Interface name से call होता है।
Remember:
Interface में default method implementation provide कर सकता है, लेकिन object state normally class में रहती है।
