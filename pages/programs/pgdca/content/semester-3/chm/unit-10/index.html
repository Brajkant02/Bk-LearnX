Network Devices

1. Introduction to Network Devices

Network Devices वे hardware devices हैं जो computers, servers, printers और अन्य network-enabled devices को आपस में connect करने, data transmit करने, traffic control करने और अलग-अलग networks के बीच communication कराने में सहायता करते हैं।

एक computer network में केवल computers और cables पर्याप्त नहीं होते। Data को सही destination तक पहुँचाने, network segments को connect करने और communication को manage करने के लिए अलग-अलग network devices की आवश्यकता होती है।

Exam Definition: Network device is a hardware component used to connect network nodes and to transmit, receive, forward, filter or route data within or between networks.

मुख्य Network Devices

Device Main Function
Hub Incoming data को connected ports पर broadly repeat/broadcast करता है।
Switch LAN में frames को destination के अनुसार forward करता है।
Router Different networks के बीच packets को route करता है।
Bridge Network segments को connect और traffic filter करता है।
Gateway Different networks/protocol environments के बीच communication interface प्रदान कर सकता है।
Ethernet Card Computer को Ethernet network से connect करने का network interface।

2. Hub

Hub एक basic network connecting device है जो एक port पर received data को अन्य connected ports पर भेज देता है। Traditional Ethernet hubs OSI model के Physical Layer (Layer 1) पर operate करते हैं।

Hub की Working

  1. एक computer hub को data भेजता है।
  2. Hub incoming electrical signal को receive करता है।
  3. Hub signal को अन्य ports पर repeat करता है।
  4. Connected devices signal receive करते हैं और intended device relevant frame को process करता है।
Computer A → Hub → Port 1, Port 2, Port 3, Port 4 → Connected Devices

Hub की विशेषताएँ

  • Simple और easy to configure।
  • Traditional hub में intelligent destination-based forwarding नहीं होता।
  • All connected ports पर traffic भेजने के कारण unnecessary traffic बढ़ सकता है।
  • Shared bandwidth environment में collisions हो सकती हैं।

Advantages

  • Simple design।
  • Low complexity।
  • Basic network setup के लिए historically useful।

Limitations

  • Traffic सभी ports तक भेजता है।
  • Collisions की संभावना अधिक होती है।
  • Modern LANs में switch से कम efficient है।

3. Switch

Network Switch एक networking device है जो LAN के devices को connect करता है और received Ethernet frames को destination के आधार पर appropriate port की ओर forward करता है। सामान्य Ethernet switches मुख्यतः Data Link Layer (Layer 2) पर operate करते हैं; कुछ advanced switches Layer 3 routing capabilities भी provide कर सकते हैं।

Switch कैसे काम करता है?

  1. Switch Ethernet frame receive करता है।
  2. Frame के source MAC address को देखकर switch अपनी MAC address table को learn/update करता है।
  3. Destination MAC address को table में lookup किया जाता है।
  4. यदि destination ज्ञात है, frame संबंधित port पर forward होता है।
  5. यदि destination unknown है, frame को आवश्यकता के अनुसार अन्य relevant ports पर flood किया जा सकता है।
Device → Switch → MAC Address Table → Correct Port → Destination Device

Switch के Advantages

  • Hub की तुलना में traffic forwarding अधिक efficient।
  • प्रत्येक port को अलग collision domain की तरह operate कराया जा सकता है।
  • Full-duplex Ethernet support वाले networks में collisions का issue बहुत कम/व्यावहारिक रूप से समाप्त होता है।
  • Modern LANs में widely used।

Managed और Unmanaged Switch

Type Description
Unmanaged Switch Basic plug-and-play switching; configuration options limited।
Managed Switch VLAN, monitoring, security और अन्य management features उपलब्ध हो सकते हैं।

4. Router

Router एक network-layer device है जो अलग-अलग IP networks के बीच data packets को forward करता है। Router destination IP address और routing information के आधार पर packet के लिए suitable path/next hop select करता है।

Router के Main Functions

  • Different networks को connect करना।
  • IP packets को route/forward करना।
  • Routing table maintain करना।
  • Network traffic को appropriate interface की ओर भेजना।
  • कई consumer routers में DHCP, NAT, firewall और wireless access जैसी additional services भी हो सकती हैं, model के अनुसार।

Router Working

  1. Router packet receive करता है।
  2. Destination IP address inspect करता है।
  3. Routing table में best matching route खोजता है।
  4. Next-hop/interface select करता है।
  5. Packet को selected interface से forward करता है।
Source Network → Router → Routing Decision → Next Network → Destination

Router के Advantages

  • Different IP networks को connect करता है।
  • Network traffic के लिए routing decisions लेता है।
  • Large networks को logical segments में organize करने में मदद करता है।

5. Bridge

Bridge एक networking device है जो दो या अधिक LAN segments को connect करके उनके बीच Ethernet frames को filter और forward करता है। Traditional bridges Data Link Layer (Layer 2) पर operate करते हैं।

Bridge Working

  1. Bridge incoming frame receive करता है।
  2. Source MAC address से network information learn कर सकता है।
  3. Destination MAC address के आधार पर decide करता है कि frame को दूसरे segment में forward करना है या नहीं।
  4. यदि destination उसी segment में है, unnecessary forwarding को रोका जा सकता है।
  5. यदि destination दूसरे segment में है, frame forward किया जाता है।

Bridge के Uses

  • LAN segments को connect करना।
  • Unnecessary traffic को filter करना।
  • Network segmentation में सहायता करना।
Exam Point: Modern Ethernet switches को multi-port bridging के रूप में समझा जा सकता है; traditional bridge और modern switch की exact capabilities अलग हो सकती हैं।

6. Gateway

Gateway एक network interface/device या software function हो सकता है जो different networks, architectures या protocol environments के बीच communication के लिए entry/exit point या translation mechanism प्रदान करता है। “Default gateway” शब्द सामान्य IP networks में उस router/interface को refer करता है जिसके माध्यम से host अपने local network से बाहर traffic भेजता है।

Gateway के Main Functions

  • Network से बाहर जाने वाले traffic के लिए entry/exit point provide करना।
  • Different environments के बीच protocol/data translation, जहाँ required हो।
  • Complex networks में communication integration में सहायता करना।

Default Gateway Example

यदि किसी PC का IP address 192.168.1.20 है और उसे किसी दूसरे network के server से communicate करना है, तो PC सामान्यतः अपने configured default gateway की ओर packet भेजता है। Router आगे packet को destination network की ओर route करता है।

7. Ethernet Card / Network Interface Card (NIC)

Ethernet Card, जिसे NIC (Network Interface Card) भी कहा जाता है, वह hardware interface है जो computer को Ethernet-based wired network से connect करता है। यह motherboard में integrated हो सकता है या अलग expansion adapter के रूप में लगाया जा सकता है।

Ethernet Card के Main Functions

  • Computer और Ethernet network के बीच data transmission/reception।
  • Ethernet frames को send और receive करना।
  • Network interface को physical cable से connect करना।
  • MAC address के माध्यम से network interface की identification में सहायता करना।

Common Ethernet Connection

Wired Ethernet में आमतौर पर twisted-pair cable और RJ-45 style 8P8C modular connector का उपयोग किया जाता है। Network speed और capabilities NIC, switch, cable और configuration पर depend करती हैं।

8. Network Cables

Network cable वह physical medium है जिसके द्वारा wired network में devices के बीच signals/data transmit किए जाते हैं। Network cables broadly copper-based और fiber-optic categories में मिलते हैं।

Medium Example Signal Medium Typical Strength
Copper Twisted Pair CAT-6 Electrical signals LAN cabling, cost-effective installation
Optical Fiber OFC Light pulses High bandwidth, long-distance links, EMI immunity

9. CAT-6 Cable

CAT-6 (Category 6) एक twisted-pair copper Ethernet cable category है। इसमें multiple insulated copper pairs होते हैं। Pairs के twisting से electromagnetic interference और crosstalk को reduce करने में सहायता मिलती है।

CAT-6 Cable Structure

  • चार twisted copper pairs (कुल 8 conductors) सामान्य CAT-6 construction में होते हैं।
  • Individual conductors insulated होते हैं।
  • Outer jacket पूरे cable को protect करती है।
  • कुछ designs में internal separator/cross filler crosstalk control में सहायता करता है।

CAT-6 के Uses

  • Computer-to-switch Ethernet connections।
  • Office LANs।
  • Home networking।
  • Network patching और structured cabling installations।

CAT-6 की विशेषताएँ

  • Twisted-pair copper technology।
  • Modern Gigabit Ethernet deployments में commonly used।
  • Proper installation के साथ higher-frequency signalling के लिए designed।
  • Actual supported speed और maximum distance cable specification, installation quality और network equipment पर depend करते हैं।

10. OFC – Optical Fiber Cable

OFC (Optical Fiber Cable) ऐसा communication cable है जिसमें information को electrical current के बजाय light pulses के रूप में optical fiber के माध्यम से transmit किया जाता है। Optical fiber में मुख्यतः core और cladding होती है तथा protective layers fiber को mechanical damage से बचाती हैं।

OFC के Main Parts

Part Function
Core Light signal को guide करता है।
Cladding Core के चारों ओर lower refractive index layer, जो light guidance में सहायता करती है।
Coating Fiber को physical/environmental protection देती है।
Strength Member Mechanical pulling/tensile protection में सहायता करता है।
Outer Jacket Complete cable assembly को external protection देता है।

OFC Working Principle

  1. Transmitter electrical data को optical signal में convert करता है।
  2. Light pulses fiber core में travel करती हैं।
  3. Fiber light को guided path में आगे carry करती है।
  4. Receiver optical signal को वापस electrical/data signal में convert करता है।
Electrical Data → Optical Transmitter → Light Pulses → Fiber → Optical Receiver → Electrical/Data Output

OFC Advantages

  • High bandwidth क्षमता।
  • Long-distance communication के लिए suitable।
  • Electromagnetic interference से बहुत कम प्रभावित।
  • High-speed backbone और communication links में useful।

OFC Limitations

  • Installation और termination के लिए specialized tools/skills की आवश्यकता हो सकती है।
  • Fiber को excessive bending और physical damage से बचाना चाहिए।
  • Testing और repair के लिए specialized equipment की आवश्यकता हो सकती है।

11. Cabling Tools

Network cabling में cable को cut, strip, terminate, test और organize करने के लिए विभिन्न cabling tools का उपयोग किया जाता है।

Tool Use
RJ-45 Crimping Tool Twisted-pair cable को modular connector में terminate/crimp करने के लिए।
Wire Stripper Cable की outer insulation हटाने के लिए।
Cable Cutter Cable को clean तरीके से cut करने के लिए।
LAN Cable Tester Continuity, wire mapping और common wiring faults check करने के लिए।
Punch Down Tool Compatible keystone jack/patch panel में conductors terminate करने के लिए।
Fish Tape / Pulling Tool Conduit या difficult pathway में cable pull करने में सहायता।
Fiber Stripper Optical fiber की protective layers remove करने के लिए।
Fiber Cleaver Fiber end को precise cleave करने के लिए।
Optical Power Meter Fiber link की optical power measure करने के लिए।
Visual Fault Locator Fiber में visible-light आधारित fault location में सहायता।

RJ-45 Termination का Basic Process

  1. Required length का cable cut करें।
  2. Outer jacket को carefully strip करें।
  3. Twisted pairs को untwist करके required wiring order में arrange करें।
  4. Conductors को समान length में trim करें।
  5. Conductors को connector में correct position तक insert करें।
  6. Crimping tool से connector terminate करें।
  7. LAN cable tester से wire mapping/continuity test करें।
Important: Ethernet cable termination में केवल connector crimp करना पर्याप्त नहीं है; correct pin order, conductor seating और testing भी reliable network connection के लिए जरूरी हैं।

13. Network Troubleshooting

Network troubleshooting का अर्थ network में communication failure, slow connection, packet loss या connectivity problem के कारण को systematically identify करके उसे resolve करना है। Troubleshooting हमेशा simple physical checks से शुरू करके configuration और advanced diagnosis तक करनी चाहिए।

Common Problems और Solutions

Problem Possible Cause Troubleshooting
No Network Connection Loose cable, disabled NIC, switch/router issue Cable, link LEDs, NIC status और network device power check करें।
Limited/No Internet Gateway/DNS/WAN/ISP configuration issue IP configuration, default gateway, DNS और upstream connectivity check करें।
Network Cable Not Working Broken conductor, wrong termination, bad connector LAN cable tester से wire mapping/continuity test करें।
Slow Network Congestion, poor cable, duplex/speed mismatch, overloaded device Link speed, traffic, cables, switch ports और device load inspect करें।
Intermittent Connection Loose connector, damaged cable, interference, unstable device Cable/connector replace करके port और logs/status check करें।
Cannot Access Local Device Wrong IP/subnet, VLAN or firewall issue IP settings, subnet, VLAN configuration और firewall rules verify करें।
Wi-Fi works but wired does not Ethernet cable/NIC/switch port issue Different cable/port test करें और Ethernet adapter status check करें।
Only One PC has Problem Local NIC, driver, IP configuration Adapter status, driver और TCP/IP configuration check करें।

Basic Troubleshooting Commands

Command Purpose
ipconfig / ipconfig /all Windows में IP address, gateway, DNS और adapter information देखना।
ping Basic IP reachability और response test करना।
tracert Windows में destination तक route/hops देखने में सहायता।
nslookup DNS name resolution test करना।
arp ARP-related address information देखने में सहायता।

Systematic Troubleshooting Steps

  1. Physical Layer: Power, cable, connector, link LED और port check करें।
  2. NIC: Ethernet adapter enabled है या नहीं check करें।
  3. IP Configuration: IP address, subnet mask/prefix, gateway और DNS verify करें।
  4. Local Test: localhost/own interface और local network connectivity test करें।
  5. Gateway Test: Default gateway तक reachability check करें।
  6. DNS Test: Name resolution working है या नहीं check करें।
  7. Remote Test: Required remote host/service तक connectivity verify करें।
  8. Device Configuration: Switch port, VLAN, router interface और firewall rules inspect करें।
  9. Replace/Test: Suspected cable, port या adapter को known-good component से test करें।
Physical Check → NIC → IP Configuration → Gateway → DNS → Remote Host → Switch/Router Configuration

14. Network Cabling Maintenance & Safety

  • Network cables को sharp bends और excessive pulling से बचाएँ।
  • Copper cable को strong electrical interference sources से उचित दूरी पर रखें जहाँ practical हो।
  • Connectors को properly seated रखें।
  • Patch panels और switches में cables को label करें।
  • Cable tester से installation verify करें।
  • Fiber cable को manufacturer की recommended bend radius से अधिक न मोड़ें।
  • Fiber connectors को clean और capped रखें जब वे उपयोग में न हों।
  • Fiber end को आँखों के सामने न रखें; optical light दिखाई न देने पर भी safe handling practices follow करें।
  • Network equipment की ventilation और power connections को unobstructed रखें।
