Components and Peripheral Devices Connected with Computer

Introduction

Computer Components वे physical parts होते हैं जिनसे computer system बनता है। इनमें internal components, external components और peripheral devices शामिल होते हैं। Internal components system unit के अंदर लगे होते हैं, जबकि external और peripheral devices computer के बाहर connect किए जाते हैं।

Peripheral Devices वे devices होते हैं जो computer की functionality बढ़ाते हैं। ये input देने, output प्राप्त करने, data store करने या communication establish करने में help करते हैं। Keyboard, mouse, monitor, printer, scanner, speaker, modem और external storage peripheral devices के examples हैं।

Need of Peripheral Devices

  • User से input लेने के लिए।
  • Processed information को output के रूप में दिखाने के लिए।
  • Data और programs store करने के लिए।
  • Computer को network और internet से connect करने के लिए।
  • Multimedia, printing, scanning और communication जैसी extra facilities देने के लिए।

Peripheral devices computer की basic processing capability को useful input, output, storage और communication facilities में बदलते हैं।

Internal, External and Peripheral Components

Internal components system cabinet या motherboard के अंदर लगे होते हैं। ये computer की processing, memory, power और control operations handle करते हैं। CPU, RAM, ROM, motherboard, SMPS और storage drive internal components हैं।

External components computer के बाहर connect होते हैं। Keyboard, mouse, monitor और printer external devices हैं।

Peripheral devices internal या external दोनों हो सकते हैं, लेकिन generally peripheral शब्द उन devices के लिए use होता है जो computer के input, output, storage या communication function को support करते हैं।

Barcode Reader, OCR, OMR, MICR and Biometric Devices

Barcode Reader

Barcode reader product पर printed barcode scan करके data computer में भेजता है। Shopping malls और inventory systems में common है।

QR Code Scanner

QR scanner two-dimensional code read करता है। Payment, login और information sharing में use होता है।

OCR

OCR का full form Optical Character Recognition है। यह scanned printed text को editable text में convert करता है।

OMR

OMR का full form Optical Mark Recognition है। यह answer sheets पर marked circles/bubbles read करता है।

MICR

MICR का full form Magnetic Ink Character Recognition है। Banking में cheque numbers read करने के लिए use होता है।

Biometric Device

Fingerprint, face, iris या voice के आधार पर identity verify करता है। Attendance और security systems में use होता है।

HDD and SSD

HDD magnetic disk-based storage device है। इसमें rotating platters और read/write head होते हैं।

SSD flash memory-based storage device है। इसमें moving parts नहीं होते, इसलिए यह faster, silent और durable होता है।

Image Placeholder: HDD vs SSD

Basis HDD SSD
Technology Magnetic platters Flash memory
Speed Slower Faster
Noise Mechanical noise Silent
Durability Moving parts की वजह से sensitive More durable
Cost Lower per GB Higher per GB

Communication Devices

Communication devices computer को other computers, networks और internet से connect करते हैं।

Image Placeholder: Modem, Router, Switch, NIC

Modem

Modem digital और analog signals के बीच conversion करता है और internet connection provide कर सकता है।

Router

Router different networks के बीच packets forward करता है और home/office devices को internet से connect करता है।

Switch

Switch LAN में multiple devices को connect करता है और data सही destination port तक भेजता है।

Hub

Hub received data सभी ports पर broadcast करता है। यह switch से कम intelligent होता है।

NIC

Network Interface Card computer को wired या wireless network से connect करता है।

Wi-Fi Adapter

Desktop/laptop को wireless network access देता है।

Bluetooth Adapter

Short-range wireless communication enable करता है।
