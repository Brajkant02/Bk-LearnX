Random Access Memory(RAM)

Definition of RAM

RAM (Random Access Memory) computer की primary memory है जिसमें operating system, running programs और currently used data temporary रूप से store होते हैं। RAM volatile memory होती है, अर्थात power off होते ही इसका data समाप्त हो जाता है। CPU RAM से data को बहुत तेज़ी से access करता है, इसलिए system performance में RAM की महत्वपूर्ण भूमिका होती है।

Image Placeholder: RAM Module and Memory Cells

Working

  1. Program storage device से RAM में load होता है।
  2. CPU RAM से instructions पढ़ता है।
  3. Execution के दौरान temporary data RAM में store होता है।
Real Life Example: Browser में कई tabs खोलने पर उनकी information RAM में रहती है ताकि वे जल्दी open हों।

Types of RAM

RAM को मुख्य रूप से दो categories में divide किया जाता है।

Image Placeholder: SRAM and DRAM

SRAM (Static RAM)

SRAM flip-flops का उपयोग करती है। इसे बार-बार refresh करने की आवश्यकता नहीं होती। यह बहुत fast होती है लेकिन expensive भी होती है। CPU Cache में SRAM का उपयोग किया जाता है।

DRAM (Dynamic RAM)

DRAM capacitors में data store करती है और इसे लगातार refresh करना पड़ता है। यह SRAM से slower लेकिन काफी सस्ती होती है। Main system memory में DRAM का उपयोग किया जाता है।

Advantages of RAM

  • CPU को very fast data access मिलता है।
  • Operating system और applications तेजी से run होते हैं।
  • Multitasking improve होती है।
  • System responsiveness बढ़ती है।
  • Large files और professional software smoothly execute होते हैं।
  • Gaming और video editing performance बेहतर होती है।
Remember: अधिक RAM होने से computer हमेशा faster नहीं होता, लेकिन insufficient RAM होने पर performance काफी कम हो जाती है।

Removable RAM Vs Soldered RAM

Modern computers में RAM removable module या motherboard पर permanently soldered दोनों रूपों में मिल सकती है।

Image Placeholder: Removable RAM vs Soldered RAM

Basis Removable RAM Soldered RAM
Installation RAM slot में install होती है Motherboard पर permanently soldered
Upgrade Easy Generally not possible
Replacement Simple Difficult/Not practical
Repair Cost Lower Higher
Common Use Desktop, Gaming PC Thin laptops, tablets
Flexibility High Limited
Practical Example: Gaming desktop में future upgrade के लिए removable RAM बेहतर रहती है, जबकि ultra-thin laptops space बचाने के लिए soldered RAM use करते हैं।
