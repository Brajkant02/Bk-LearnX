Network Devices

Introduction to Network Devices

Network devices वे hardware components होते हैं जो computers, servers, printers, mobile devices और other systems को network में connect करते हैं। ये devices data को receive, forward, filter, route और convert करते हैं।

Different network devices अलग-अलग OSI layers पर work करते हैं। Hub physical layer पर, switch data link layer पर और router network layer पर काम करता है। Gateway multiple layers पर protocol conversion कर सकता है।

Image Placeholder: Hub, Switch, Router, Bridge and Gateway

Need of Network Devices

  • Multiple devices को connect करने के लिए।
  • Data को सही destination तक भेजने के लिए।
  • Network traffic control करने के लिए।
  • Different networks को connect करने के लिए।
  • Internet access provide करने के लिए।
  • Security और network segmentation improve करने के लिए।
Remember:
हर network device का role अलग है; सभी केवल connection देने का काम नहीं करते।

Hub

Hub एक basic networking device है जो multiple computers को LAN में connect करता है। Hub received data को identify नहीं करता कि destination कौन है। यह incoming data सभी connected ports पर broadcast कर देता है।

Image Placeholder: Hub Broadcasting Data

Working

  1. एक computer data hub को भेजता है।
  2. Hub data receive करता है।
  3. Hub same data सभी ports पर forward करता है।
  4. Destination device data accept करता है।
  5. Other devices data ignore करते हैं।

Types of Hub

Type Feature
Passive Hub Signal केवल forward करता है।
Active Hub Signal regenerate/amplify करता है।
Intelligent Hub Basic monitoring और management support कर सकता है।

Advantages

  • Simple और low cost।
  • Small basic network में easy installation।

Limitations

  • Data सभी ports पर broadcast करता है।
  • Network traffic ज्यादा होता है।
  • Security कम होती है।
  • Collisions की possibility ज्यादा।
  • Modern networks में mostly switch ने replace कर दिया है।
Real Life Example:
Hub को ऐसे समझें जैसे एक व्यक्ति room में loudly message बोले और सभी लोग उसे सुनें।

Switch

Switch LAN में multiple devices को connect करता है और MAC address के आधार पर data सही destination port तक भेजता है। यह hub से अधिक intelligent और efficient होता है।

Image Placeholder: Switch MAC Address Table

Working

  1. Switch frame receive करता है।
  2. Source MAC address learn करता है।
  3. MAC address table update करता है।
  4. Destination MAC address check करता है।
  5. Frame केवल correct port पर forward करता है।

Types of Switch

Type Use
Unmanaged Switch Plug-and-play basic LAN
Managed Switch VLAN, monitoring और configuration
Layer-2 Switch MAC address based forwarding
Layer-3 Switch Switching के साथ routing functions
PoE Switch Data के साथ power provide करता है।

Advantages

  • Traffic reduce करता है।
  • Collision domains separate करता है।
  • Better performance और security।
  • Managed switches VLAN support कर सकते हैं।
Remember:
Switch MAC address के आधार पर frame को correct port तक भेजता है।

Router

Router different networks को connect करता है और IP address के आधार पर data packets को route करता है। Home router local network को internet से connect करता है।

Image Placeholder: Router Connecting LAN and Internet

Main Functions

  • Different networks connect करना।
  • Best path select करना।
  • IP packets forward करना।
  • NAT perform करना।
  • DHCP service provide करना।
  • Firewall और basic security देना।
  • Wi-Fi access provide करना।

Routing Process

Source Device
      ↓
Default Gateway
      ↓
Router checks destination IP
      ↓
Routing table selects path
      ↓
Packet forwarded to next network

Types

Type Use
Wired Router Ethernet-based network
Wireless Router Wi-Fi और LAN दोनों
Core Router Large backbone network
Edge Router Internal network को external network से connect करता है।
Real Life Example:
Router traffic police की तरह packet को सही network path पर भेजता है।

Bridge

Bridge two LAN segments को connect करता है और MAC address के आधार पर frames filter/forward करता है। यह network traffic reduce करने में help करता है।

Image Placeholder: Bridge Connecting Two LAN Segments

Working

  • Frames receive करता है।
  • Source MAC learn करता है।
  • Destination same segment पर हो तो frame forward नहीं करता।
  • Other segment पर हो तो bridge frame forward करता है।

Types

Type Meaning
Transparent Bridge Ethernet LAN में automatically learning करता है।
Source Route Bridge Path source device determine करता है।
Translational Bridge Different LAN technologies connect करता है।
Remember:
Bridge LAN को segments में divide करके unnecessary traffic कम करता है।

Gateway

Gateway different networks या systems के बीच entry/exit point होता है। यह protocol conversion, data format conversion और communication translation कर सकता है।

Image Placeholder: Gateway Protocol Conversion

Functions

  • Different protocols के बीच conversion।
  • Different network architectures connect करना।
  • Security और filtering।
  • Application-level translation।
  • Network entry and exit point।

Default Gateway

Default gateway वह router address होता है जहाँ device local network के बाहर जाने वाले packets भेजता है।

Examples

  • Email gateway
  • VoIP gateway
  • IoT gateway
  • Cloud gateway
  • Protocol gateway
Real Life Example:
Language translator की तरह gateway different protocols बोलने वाले systems के बीच translation करता है।

Hub vs Switch vs Router vs Bridge vs Gateway

Device Main Basis Primary Role OSI Layer
Hub No address intelligence Broadcast data Physical Layer
Switch MAC Address LAN frame forwarding Data Link Layer
Router IP Address Connect different networks Network Layer
Bridge MAC Address Connect LAN segments Data Link Layer
Gateway Protocol/format conversion Connect dissimilar systems Multiple Layers

Ethernet Card / NIC

Ethernet Card या NIC का full form Network Interface Card है। यह computer को wired Ethernet network से connect करता है। हर NIC का unique MAC address होता है।

Image Placeholder: Ethernet Card Components

Main Components

  • RJ-45 port
  • MAC controller
  • PHY transceiver
  • Status LEDs
  • PCIe or onboard interface

Functions

  • Computer data को Ethernet frames में convert करना।
  • Frames receive और process करना।
  • MAC address provide करना।
  • Speed और duplex negotiation करना।

Common Speeds

Gigabit Ethernet 1 Gbps

Remember:
Ethernet card computer और wired network के बीच hardware interface है।

CAT-6 Cable

CAT-6 twisted-pair copper Ethernet cable है। इसका use LAN connections में किया जाता है। इसमें four twisted pairs होते हैं और RJ-45 connectors commonly use किए जाते हैं।

Image Placeholder: CAT-6 Cable and RJ-45 Connector

Features

  • Higher bandwidth than older categories।
  • Gigabit Ethernet support।
  • Shorter distances पर higher speeds possible।
  • Crosstalk reduction के लिए tighter twists।
  • UTP और shielded variants available।

Internal Pairs

Pair Typical Colors

Pair 2 White-Green / Green
Pair 3 White-Blue / Blue
Pair 4 White-Brown / Brown

T568A and T568B Standards

RJ-45 termination में color sequence T568A या T568B standard के अनुसार रखा जाता है। दोनों ends पर same standard हो तो straight-through cable बनती है।

Remember:
CAT-6 cable copper-based twisted-pair Ethernet cable है।

OFC - Optical Fiber Cable

OFC का full form Optical Fiber Cable है। यह data को electrical signal की जगह light pulses के रूप में transmit करती है। Fiber cable high speed, long distance और low interference communication के लिए useful है।

Image Placeholder: Optical Fiber Structure

Structure

Part Function
Core Light signal carry करता है।
Cladding Light को core के अंदर reflect रखती है।
Buffer Coating Fiber को protection देती है।
Outer Jacket Mechanical protection।

Types

Type Use
Single-mode Fiber Long distance और high bandwidth
Multi-mode Fiber Shorter distance LAN/data center

Advantages

  • Very high bandwidth।
  • Long distance transmission।
  • Electromagnetic interference से unaffected।
  • More secure communication।
  • Low signal loss।

Limitations

  • Installation cost higher।
  • Special tools और skills required।
  • Fiber fragile हो सकती है।

RJ-45 Crimping Steps

  1. Cable required length में cut करें।
  2. Outer jacket strip करें।
  3. Twisted pairs untwist करें।
  4. T568A या T568B sequence arrange करें।
  5. Wires equal length में trim करें।
  6. RJ-45 connector में insert करें।
  7. Crimping tool से crimp करें।
  8. LAN tester से cable test करें।
Remember:

Network Troubleshooting

Network troubleshooting systematic process है। पहले physical layer check करें, फिर configuration और higher-layer services inspect करें।

   ↓

   ↓

   ↓

   ↓

   ↓
Ping Internet IP
   ↓

No Link Light

  • Cable loose/damaged हो सकती है।
  • Switch port disabled/faulty हो सकता है।
  • NIC disabled या damaged हो सकती है।
  • Wrong fiber module/connector issue हो सकता है।

Connected but No Internet

  • IP address check करें।
  • Default gateway verify करें।
  • DNS settings check करें।
  • Router internet status check करें।
  • DHCP lease renew करें।

Slow Network

  • Duplex mismatch check करें।
  • Damaged cable or high error rate inspect करें।
  • Switch port utilization check करें।
  • Malware/background downloads check करें।
  • Wi-Fi interference check करें।

Useful Troubleshooting Commands

Command Use
ipconfig Windows IP configuration देखना।
ifconfig / ip addr Linux network configuration।
ping Connectivity test।
tracert / traceroute Packet path check।
nslookup DNS resolution test।
netstat Connections और ports check।
arp -a ARP table देखना।

Ping Test Order

ping 127.0.0.1
ping own_IP
ping default_gateway
ping 8.8.8.8
ping example.com

इस order से TCP/IP stack, NIC, local network, internet और DNS problems अलग-अलग identify की जा सकती हैं।

Network Maintenance and Best Practices

  • Cables label करें।
  • Patch panel और rack organized रखें।
  • Sharp bends avoid करें।
  • Power cables और network cables अलग route करें।
  • Fiber connectors clean रखें।
  • Switch/router configuration backup लें।
  • Firmware updates carefully apply करें।
  • Unused switch ports disable करें।
  • UPS और surge protection use करें।
  • Network diagram और IP records maintain करें।
Professional Tip:
Physical layer check किए बिना software configuration बदलना troubleshooting को और complex बना सकता है।
Remember:
Network troubleshooting हमेशा simplest physical checks से start करनी चाहिए।
