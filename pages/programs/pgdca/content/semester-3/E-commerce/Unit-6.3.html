Configuring UTMs (Custom URLs)

UTM Parameters campaign links में add किए जाने वाले labels हैं जो traffic source, medium और campaign identify करते हैं।

Main UTM Parameters

ParameterPurpose
utm_sourceTraffic source, जैसे facebook
utm_mediumMarketing medium, जैसे social या email
utm_campaignCampaign name
utm_termPaid keyword information
utm_contentDifferent ads/links compare करना

Example URL

https://example.com/course
?utm_source=youtube
&utm_medium=video
&utm_campaign=seo_course
Common Mistake:
UTM names में inconsistent spelling और capitalization reports को अलग-अलग campaigns में divide कर सकती है।

UTM Best Practices

  • Consistent lowercase naming use करें।
  • Spaces की जगह hyphen या underscore use करें।
  • Campaign naming document maintain करें।
  • Sensitive information URL में add न करें।
  • Internal website links पर UTM unnecessarily use न करें।
  • Final URL publish करने से पहले test करें।

Google Tag Manager - Overview

Google Tag Manager (GTM) website और app पर analytics तथा marketing tags manage करने का tag management system है। इसके माध्यम से कई tracking scripts centralized interface से manage किए जा सकते हैं।

Image Placeholder: Google Tag Manager Architecture

Main Components

ComponentMeaning
TagTracking or marketing code
TriggerTag कब fire होगा
VariableDynamic information used by tags/triggers
ContainerTags, triggers और variables का collection

Tag Manager Working Flow

User Action
    ↓
Trigger Condition
    ↓
Tag Fires
    ↓
Data Sent to Analytics / Ads

Example

User “Download Notes” button click करता है → Click Trigger activate होता है → Analytics Event Tag data send करती है।

Advantages of Google Tag Manager

  • Centralized tag management
  • Developer dependency reduce हो सकती है
  • Preview and debug mode
  • Version control
  • Multiple marketing tools integration
  • Event tracking आसान
Important:
Tag Manager tracking plan का replacement नहीं है; सही events, naming और testing फिर भी जरूरी हैं।

Analytics Privacy and Data Quality

Privacy Practices

  • Only required data collect करें।
  • Sensitive personal information avoid करें।
  • User consent requirements follow करें।
  • Access permissions control करें।
  • Data retention settings review करें।

Data Quality Practices

  • Tracking test करें।
  • Duplicate tags avoid करें।
  • Internal traffic filter करें जहाँ needed हो।
  • Consistent event names use करें।
  • Reports regularly validate करें।

Analytics Implementation Checklist

  • Business goals defined
  • Analytics property and stream configured
  • Measurement tag verified
  • Important events identified
  • Conversions configured
  • UTM naming standard created
  • Google Ads integration reviewed
  • Social and SEO traffic monitored
  • ROI metrics defined
  • Tag Manager tested
  • Privacy and access settings reviewed
Remember:
Good analytics setup वही है जो business goals को measurable user actions और reliable reports से connect करे।
