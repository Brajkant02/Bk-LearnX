Brainstorming Keywords

Brainstorming में team या individual target audience, problems, products और questions के आधार पर possible keywords की list बनाता है।

Methods

  • Customer questions लिखें।
  • Product/service categories list करें।
  • Competitor topics observe करें।
  • Synonyms और alternate phrases सोचें।
  • Beginner, advanced और local variants बनाएं।
Example:
“Computer notes” से related keywords: computer fundamentals notes, Hindi computer notes, PGDCA notes, basic computer course।

Google Keyword Planner

Keyword Planner paid advertising planning के लिए बनाया गया tool है, लेकिन keyword ideas और approximate demand समझने में भी useful हो सकता है।

Main Uses

  • Keyword ideas
  • Search volume ranges
  • Competition indication
  • Cost estimates for ads
  • Location and language filtering
Important:
Search volume useful signal है, लेकिन relevance और user intent उससे भी ज्यादा important हैं।

How to Translate Keywords

Keyword translation केवल word-by-word translation नहीं है। Different languages में users अलग phrasing use कर सकते हैं।

Process

  1. Original keyword का intent समझें।
  2. Literal translation बनाएं।
  3. Local users की natural language देखें।
  4. Search suggestions compare करें।
  5. Roman Hindi, Devanagari और English variants evaluate करें।
Example:
“What is computer” के variants: “कंप्यूटर क्या है”, “computer kya hai”, “computer definition in Hindi”.

Writing Headlines and Page Titles

Page title users और search engines को page topic बताता है। Title clear, relevant और attractive होना चाहिए।

Good Title Principles

  • Main topic clearly include करें।
  • User benefit show करें।
  • Misleading clickbait avoid करें।
  • हर page का unique title रखें।
  • Natural language use करें।

Writing Meta Descriptions

Meta Description page का short summary text है जो search result snippet में दिखाई दे सकता है। यह direct ranking guarantee नहीं, लेकिन relevant summary clicks improve कर सकती है।

<meta name="description"
content="SEO के basic concepts, keyword research,
on-page optimization और technical SEO को
Hindi-English में सीखें.">

Good Description Principles

  • Page content accurately summarize करें।
  • Main benefit बताएं।
  • Natural keyword use करें।
  • Unique description लिखें।
  • Misleading promises avoid करें।
