Exception Handling

Definition of Exception Handling

Exception Java program में runtime पर आने वाली abnormal condition होती है जो program के normal flow को disturb कर सकती है। For example, किसी number को zero से divide करना, array के बाहर index access करना, file not found होना या user से wrong input मिलना exception create कर सकता है।

Exception Handling वह mechanism है जिसके द्वारा program runtime errors को handle करता है और program को अचानक बंद होने से बचाता है। Exception handling की help से programmer risky code को अलग block में रखता है और error आने पर proper message या alternate action perform करता है।

Image Placeholder: Exception Handling Flow Diagram

Without Exception Handling

class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 0;

        int result = a / b;

        System.out.println(result);
        System.out.println("Program ends");
    }
}
Output:
Runtime error: ArithmeticException
Program आगे execute नहीं होगा।

With Exception Handling

class Main {
    public static void main(String[] args) {
        try {
            int a = 10;
            int b = 0;

            int result = a / b;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }

        System.out.println("Program ends");
    }
}
Output:
Cannot divide by zero
Program ends

Need of Exception Handling

  • Program को abnormal termination से बचाने के लिए।
  • Runtime errors को controlled तरीके से handle करने के लिए।
  • User को proper error message देने के लिए।
  • Important resources जैसे file, database connection आदि properly close करने के लिए।
  • Live projects में application को reliable और stable बनाने के लिए।

Remember:
Exception handling runtime errors को handle करके program के normal flow को continue रखने में help करता है।

Implementation of try and catch

try और catch exception handling के most important keywords हैं। Risky code को try block में लिखा जाता है और exception handle करने वाला code catch block में लिखा जाता है। अगर try block में exception आती है, तो control matching catch block में चला जाता है।

Image Placeholder: try-catch Working Flow

Syntax

try {
    // risky code
} catch (ExceptionType e) {
    // handling code
}

Example

class Main {
    public static void main(String[] args) {
        try {
            int a = 10;
            int b = 0;

            int result = a / b;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Error: Division by zero is not allowed");
        }
    }
}
Output:
Error: Division by zero is not allowed

Array Exception Example

class Main {
    public static void main(String[] args) {
        try {
            int[] numbers = {10, 20, 30};

            System.out.println(numbers[5]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Invalid array index");
        }
    }
}
Output:
Invalid array index

Exception Object

Catch block में जो variable लिखा जाता है, जैसे e, वह exception object होता है। इससे exception details access की जा सकती हैं।

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println(e.getMessage());
}

Important Points

  • Try block के बिना catch block नहीं लिखा जा सकता।
  • Try block में risky code लिखा जाता है।
  • Catch block exception को handle करता है।
  • Catch block का exception type actual exception से match होना चाहिए।
Remember:
try risky code को contain करता है और catch उस risk से आए exception को handle करता है।

Multiple catch Blocks

Java में एक try block के साथ multiple catch blocks लिखे जा सकते हैं। जब try block में exception आती है, तो Java ऊपर से नीचे तक catch blocks check करती है और जो catch block matching exception type का होता है, वही execute होता है।

Multiple catch blocks तब useful होते हैं जब risky code में अलग-अलग types की exceptions आ सकती हैं और हर exception के लिए अलग handling चाहिए।

Image Placeholder: Multiple catch Blocks Flow

Example

class Main {
    public static void main(String[] args) {
        try {
            int[] arr = {10, 20, 30};

            int result = arr[1] / 0;
            System.out.println(arr[5]);
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error occurred");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Array index error occurred");
        } catch (Exception e) {
            System.out.println("General exception occurred");
        }
    }
}
Output:
Arithmetic error occurred

Order of catch Blocks

Specific exception catch block पहले और general exception catch block बाद में लिखना चाहिए। अगर Exception class का catch block पहले लिख दिया, तो बाद के specific catch blocks unreachable हो जाएंगे।

Wrong Order

try {
    int result = 10 / 0;
} catch (Exception e) {
    System.out.println("General exception");
}
// catch (ArithmeticException e) { } // Error: unreachable catch block

Correct Order

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Arithmetic exception");
} catch (Exception e) {
    System.out.println("General exception");
}

Multi-catch Block

Java में एक catch block में multiple exception types को pipe | symbol से handle किया जा सकता है।

try {
    String s = null;
    System.out.println(s.length());
} catch (ArithmeticException | NullPointerException e) {
    System.out.println("Exception handled");
}
Remember:
Multiple catch blocks में child/specific exceptions पहले और parent/general exception बाद में लिखना चाहिए।

finally Keyword

finally block exception handling में ऐसा block है जो generally हमेशा execute होता है, चाहे exception आए या न आए। इसका use important cleanup work के लिए किया जाता है, जैसे file close करना, database connection close करना, network resource release करना आदि।

Finally block try-catch के बाद लिखा जाता है। अगर exception handle हो जाए या exception न आए, दोनों cases में finally block execute होता है।

Image Placeholder: finally Block Execution Flow

Syntax

try {
    // risky code
} catch (Exception e) {
    // handling code
} finally {
    // cleanup code
}

Example

class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Exception handled");
        } finally {
            System.out.println("Finally block executed");
        }
    }
}
Output:
Exception handled
Finally block executed

finally Without Exception

class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 2;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Exception handled");
        } finally {
            System.out.println("Finally block executed");
        }
    }
}
Output:
5
Finally block executed

Use of finally in Practical Programs

FileReader fr = null;

try {
    fr = new FileReader("data.txt");
} catch (Exception e) {
    System.out.println("File problem");
} finally {
    System.out.println("Close file/resource here");
}

Important Points

  • Finally block cleanup work के लिए use होता है।
  • Finally block usually always execute होता है।
  • Try के साथ finally बिना catch के भी हो सकता है।
  • Finally block में resource closing code रखना best practice है।
Real Life Example:
Hotel room use करने के बाद room key return करना finally जैसा है। काम successful हो या problem आए, key return करनी ही होती है।
Remember:
finally block cleanup code के लिए use होता है और generally exception आए या न आए, execute होता है।

throw Keyword

throw keyword Java में manually exception throw करने के लिए use होता है। जब programmer खुद किसी condition पर exception generate करना चाहता है, तब throw keyword use किया जाता है। Throw usually custom validations में useful होता है।

Throw keyword एक single exception object को throw करता है। इसके बाद current method का normal flow stop हो सकता है और exception nearest matching catch block में handle होती है।

Syntax

throw new ExceptionType("message");

Example

class Main {
    static void checkAge(int age) {
        if (age < 18) {
            throw new ArithmeticException("Age must be 18 or above");
        } else {
            System.out.println("Eligible");
        }
    }

    public static void main(String[] args) {
        checkAge(15);
    }
}
Output:
Exception in thread "main" java.lang.ArithmeticException: Age must be 18 or above

Handling thrown Exception

class Main {
    static void checkAge(int age) {
        if (age < 18) {
            throw new ArithmeticException("Age must be 18 or above");
        } else {
            System.out.println("Eligible");

Use Cases

  • Invalid age validation में।
  • Invalid marks या negative amount check करने में।

throw manually exception object throw करता है।

throws Keyword

throws keyword method declaration के साथ use होता है। यह बताता है कि method किसी exception को handle नहीं कर रहा, बल्कि caller method को pass कर रहा है। Throws mostly checked exceptions के साथ use होता है।

Throw और throws में difference समझना important है। throw actual exception throw करता है, जबकि throws method signature में exception possibility declare करता है।

Image Placeholder: throws Keyword Propagation Diagram

Syntax

returnType methodName() throws ExceptionType {
    // code
}

Example

import java.io.FileReader;
import java.io.IOException;

class Main {
    static void readFile() throws IOException {

    }

    public static void main(String[] args) {
        try {
            readFile();
        } catch (IOException e) {
            System.out.println("File not found or cannot be read");
        }
    }
}

Multiple Exceptions with throws

void process() throws IOException, ArithmeticException {
    // risky code
}

Creating Own Exception Sub Classes

Java में programmer अपनी custom exception class भी बना सकता है। Custom exception तब use होती है जब built-in exceptions किसी business rule या application-specific problem को properly represent नहीं करतीं। Custom exception create करने के लिए class को Exception या RuntimeException class से extend किया जाता है।

Image Placeholder: Custom Exception Class Diagram

Custom Checked Exception

class InvalidAgeException extends Exception {
    InvalidAgeException(String message) {
        super(message);
    }
}

class Main {
    static void checkAge(int age) throws InvalidAgeException {
        if (age < 18) {
            throw new InvalidAgeException("Age is below 18");
        } else {
            System.out.println("Valid age");
        }
    }

    public static void main(String[] args) {
        try {
            checkAge(15);
        } catch (InvalidAgeException e) {
            System.out.println(e.getMessage());
        }
    }
}
Output:
Age is below 18

Custom Unchecked Exception

class InvalidMarksException extends RuntimeException {
    InvalidMarksException(String message) {
        super(message);
    }
}

class Main {
    static void checkMarks(int marks) {
        if (marks < 0 || marks > 100) {
            throw new InvalidMarksException("Marks must be between 0 and 100");
        }

        System.out.println("Valid marks");
    }

    public static void main(String[] args) {
        checkMarks(120);
    }
}

Steps to Create Custom Exception

  1. एक class बनाएं।
  2. उसे Exception या RuntimeException से extend करें।
  3. Constructor बनाकर message receive करें।
  4. super(message) से parent exception class को message pass करें।
  5. Required condition पर throw keyword से custom exception throw करें।
  6. try-catch से exception handle करें।

Checked vs Unchecked Custom Exception

Type Extends Compiler Handling
Checked Custom Exception Exception Handle या declare करना जरूरी।
Unchecked Custom Exception RuntimeException Compiler force नहीं करता।

When to Use Custom Exception

  • Business rules represent करने के लिए।
  • Application-specific errors show करने के लिए।
  • Error messages को meaningful बनाने के लिए।
  • Validation logic को clean रखने के लिए।
Real Life Example:
Banking app में अगर user available balance से ज्यादा amount withdraw करे, तो InsufficientBalanceException custom exception बनाई जा सकती है।
Remember:
Custom exception application-specific problems को meaningful तरीके से represent करती है।

Importance of Exception Handling in Practical Implementation of Live Projects

Live projects में exception handling बहुत important होती है क्योंकि real users हमेशा expected input नहीं देते और real systems में file, database, network, payment gateway, API और server जैसी कई चीजों में failure आ सकता है। अगर exception handling properly न हो, तो application crash हो सकती है, data loss हो सकता है या user को confusing error screen दिख सकती है।

Professional software development में exception handling केवल error रोकने के लिए नहीं, बल्कि application को reliable, secure और user-friendly बनाने के लिए use होती है। Proper exception handling से developer logs maintain कर सकता है, user को clean message दिखा सकता है और system resources को safely close कर सकता है।

Importance in Live Projects

Importance Explanation
Application Stability Exception आने पर भी application पूरी तरह crash नहीं होती।
User Friendly Messages User को technical error की जगह simple message मिलता है।

Example: Login System

Login system में database connection fail हो सकता है, user wrong password डाल सकता है या server response late हो सकता है। Exception handling से application user को proper message दिखा सकती है जैसे “Unable to login, please try again later.”

try {
    // database login code
} catch (Exception e) {
    System.out.println("Login failed. Please try again.");
} finally {
    System.out.println("Close database connection");
}

Example: File Upload

File upload feature में file size ज्यादा हो सकता है, file format wrong हो सकता है या storage path available नहीं हो सकता। Exception handling से इन problems को controlled way में handle किया जा सकता है।

Best Practices

  • Specific exception catch करें, हर जगह general Exception catch न करें।
  • User को simple और safe error message दिखाएँ।
  • Technical details logs में रखें, user screen पर नहीं।
  • Finally या try-with-resources से resources close करें।
  • Custom exceptions से business errors को meaningful बनाएं।
  • Empty catch block avoid करें।

Bad Practice

try {
    int result = 10 / 0;
} catch (Exception e) {
    // nothing here
}

Empty catch block error को hide कर देता है, जिससे debugging difficult हो जाती है।

Better Practice

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Invalid calculation");
    e.printStackTrace();
}
Real Life Example:
Online payment app में payment fail होने पर app crash नहीं होनी चाहिए। User को “Payment failed, amount will be refunded if deducted” जैसा clear message मिलना चाहिए।
Remember:
Live projects में exception handling application को stable, secure और user-friendly बनाती है।

try-with-resources

try-with-resources Java का modern feature है जिसका use resources को automatically close करने के लिए किया जाता है। File, database connection, stream जैसी resources को manually close करना पड़ता है। अगर close करना भूल जाएँ, तो memory leak या resource leak हो सकता है। Try-with-resources इस problem को reduce करता है।

Image Placeholder: try-with-resources Flow

Syntax

try (ResourceType resource = new ResourceType()) {
    // use resource
} catch (Exception e) {
    // handle exception
}

Example

import java.io.FileReader;

class Main {
    public static void main(String[] args) {
        try (FileReader fr = new FileReader("data.txt")) {
            System.out.println("File opened successfully");
        } catch (Exception e) {
            System.out.println("File problem occurred");
        }
    }
}

Benefits

  • Resources automatically close हो जाती हैं।
  • Finally block में close code लिखने की जरूरत कम हो जाती है।
  • Code clean और safe बनता है।
  • Resource leak की possibility कम होती है।
Remember:
File, stream और database connection जैसी resources के लिए try-with-resources professional approach है।
