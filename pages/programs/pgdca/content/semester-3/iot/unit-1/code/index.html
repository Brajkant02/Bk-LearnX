IoT Unit 1 - Sample Code

Agar aapko “Code not found” ya 404 error dikh raha hai, iska reason yeh hai ki is unit ke liye actual code page abhi missing tha. Is page ko fallback ke roop me set kiya gaya hai taaki code section properly open ho sake.

Simple example: LED ko ON/OFF karna aur Serial Monitor me data print karna.

const int ledPin = 13; void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); Serial.println("IoT Unit 1: LED Test Started"); } void loop() { digitalWrite(ledPin, HIGH); Serial.println("LED ON"); delay(1000); digitalWrite(ledPin, LOW); Serial.println("LED OFF"); delay(1000); }

Explanation: Yahan setup() se pin define hota hai aur loop() me LED repeat ON/OFF hota hai. Yeh basic IoT/embedded concept ka easy example hai.
