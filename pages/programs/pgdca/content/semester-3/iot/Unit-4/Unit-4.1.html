Arduino Device Introduction

Arduino एक open-source electronics platform है जिसका उपयोग embedded systems, robotics और Internet of Things (IoT) projects बनाने के लिए किया जाता है। इसमें programmable microcontroller board और Arduino IDE software शामिल होता है। Arduino sensors से data पढ़ सकता है और LEDs, motors, relay तथा अन्य actuators को control कर सकता है। Beginners के लिए यह सबसे लोकप्रिय development platform माना जाता है।

Real Life Example: Smart Home, Smart Irrigation, Weather Monitoring, Line Follower Robot.

Features of Arduino Device

  • Open Source Hardware and Software
  • Easy Programming using Arduino IDE
  • Low Cost Development Board
  • Large Community Support
  • Cross Platform (Windows, Linux, macOS)
  • Digital & Analog Input/Output Pins
  • PWM, UART, SPI, I²C Support
  • USB Programming

Understanding the Arduino IDE

Arduino IDE वह software है जिसमें program लिखा, compile और board पर upload किया जाता है।

  • Menu Bar
  • Toolbar
  • Code Editor
  • Verify Button
  • Upload Button
  • Serial Monitor
  • Board & Port Selection
Steps:
1. Board Select
2. COM Port Select
3. Write Code
4. Verify
5. Upload
6. Open Serial Monitor

Arduino Programming Language (C Language)

Arduino Programming C/C++ आधारित language का simplified version है। प्रत्येक Arduino program में दो मुख्य functions होते हैं:

void setup() {
   // Runs only once
}

void loop() {
   // Runs repeatedly
}

  digitalWrite(13,HIGH);
