Arduino Board Overview

Arduino board एक microcontroller-based development board है जिसका use electronic circuits, automation, robotics और IoT projects बनाने के लिए किया जाता है। Arduino Uno beginners के लिए सबसे popular board है। इसमें ATmega328P microcontroller, digital pins, analog pins, power pins, USB port, reset button, crystal oscillator और communication pins होते हैं।

Arduino board का काम केवल program run करना नहीं है। यह sensors से input read करता है, program logic के अनुसार data process करता है और LEDs, motors, relay, buzzer तथा displays जैसे output devices को control करता है।

Digital Pins

Digital pins Arduino board पर ऐसे pins होते हैं जिन्हें input या output के रूप में use किया जा सकता है। Arduino Uno में digital pins 0 से 13 तक numbered होते हैं। Digital signal के केवल two states होते हैं: HIGH और LOW। HIGH usually 5V और LOW 0V को represent करता है।

Image Placeholder: Arduino Digital Pins 0 to 13

Digital Pin as Output

Digital pin को output बनाकर LED, relay या buzzer control किया जा सकता है।

int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);

  digitalWrite(ledPin, LOW);
  delay(1000);
}

Digital Pin as Input

Digital pin को input बनाकर push button, switch या digital sensor read किया जा सकता है।

int buttonPin = 2;
int buttonState;

void setup() {
  pinMode(buttonPin, INPUT);
}

void loop() {
  buttonState = digitalRead(buttonPin);
}

Important Points

  • Pin 0 और 1 serial communication के लिए use होते हैं।
  • हर pin से high-current device directly operate नहीं करना चाहिए।
  • Pin mode setup() में define करना best practice है।

ADC - Analog to Digital Converter

ADC का full form Analog to Digital Converter है। ADC analog voltage को digital number में convert करता है ताकि microcontroller sensor signal को process कर सके। Arduino Uno में 10-bit ADC होता है।

Image Placeholder: Analog to Digital Conversion

10-bit ADC

10-bit ADC total 1024 levels देता है, जिनकी range 0 से 1023 होती है।

0V   → 0
2.5V → लगभग 512
5V   → 1023

Voltage Calculation

Voltage = sensorValue × (5.0 / 1023.0)

Complete Example

int sensorValue;
float voltage;

void setup() {
  Serial.begin(9600);
}

void loop() {
  sensorValue = analogRead(A0);

  voltage = sensorValue * (5.0 / 1023.0);

  Serial.println(voltage);

  delay(500);
}

ADC Importance

  • Analog sensors को microcontroller से connect करता है।
  • Continuous voltage को readable number में बदलता है।
  • Temperature, light, pressure और gas sensors में useful है।
Remember:
Arduino Uno का 10-bit ADC analog voltage को 0-1023 range में convert करता है।

Crystal Oscillator

Crystal oscillator Arduino microcontroller को clock signal provide करता है। Arduino Uno commonly 16 MHz clock frequency पर work करता है। Clock signal microcontroller के operations की timing control करता है।

Image Placeholder: 16 MHz Crystal Oscillator

Why Clock is Needed

  • Instructions execute करने की timing तय करने के लिए।
  • Timers और delays accurate रखने के लिए।
  • Serial communication speed maintain करने के लिए।
  • Microcontroller operations synchronize करने के लिए।

16 MHz Meaning

16 MHz का मतलब oscillator लगभग 16 million clock cycles per second generate करता है। हर instruction exactly one cycle में execute हो, यह जरूरी नहीं है।

Remember:
Crystal oscillator Arduino के operations के लिए clock/timing signal देता है।

Arduino Memory

Arduino microcontroller में different types की memory होती हैं। हर memory का purpose अलग होता है। Program code, temporary variables और permanent settings अलग-अलग memory में store हो सकते हैं।

Image Placeholder: Flash SRAM EEPROM Diagram

Memory Types

MemoryPurposePower Off Effect
Flash MemoryProgram/sketch store करती है।Data retain रहता है।
SRAMRunning program variables store करती है।Data lost हो जाता है।
EEPROMPermanent small data/settings store करती है।Data retain रहता है।

Flash Memory

Uploaded Arduino program flash memory में store होता है। Board power off होने के बाद भी code delete नहीं होता।

SRAM

Variables और runtime data SRAM में store होते हैं। SRAM limited होती है, इसलिए large arrays और strings memory problem create कर सकते हैं।

EEPROM

EEPROM में settings, calibration values और device configuration store की जा सकती है।
