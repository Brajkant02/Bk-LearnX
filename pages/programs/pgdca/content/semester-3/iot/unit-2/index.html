IoT Devices

IoT Devices का परिचय

IoT Device एक physical electronic device होता है जो आसपास के environment से data collect करता है, उसे process करता है और Internet या किसी network के माध्यम से दूसरे devices अथवा cloud server तक भेजता है।

एक सामान्य IoT device में Sensor, Microcontroller, Communication Module, Power Supply और आवश्यकता के अनुसार Actuator लगा होता है।

Sensor → Microcontroller → Communication Module → Cloud / Mobile App → Actuator
याद रखें: Sensor data collect करता है, Microcontroller decision लेता है और Actuator physical action perform करता है।

Breadboard Internal Connections

Breadboard electronics prototyping के लिए solderless board होता है। इसका use components को temporary connect करके circuit test करने में किया जाता है। IoT practicals में breadboard बहुत important है क्योंकि sensors, LEDs, resistors और microcontroller pins को जल्दी connect करके testing की जा सकती है।

Breadboard के holes randomly connected नहीं होते। इसके अंदर metal strips होती हैं जो specific holes को आपस में connect करती हैं। अगर internal connection समझ में नहीं आया, तो circuit correct दिखने के बाद भी work नहीं करेगा।

Power Rails

Breadboard के side में red और blue lines वाली long rows power rails कहलाती हैं। Red rail generally VCC/positive supply के लिए और blue/black rail GND/negative supply के लिए use होती है। कई breadboards में power rails बीच में break हो सकती हैं, इसलिए continuity check करना जरूरी होता है।

Terminal Strips

Breadboard के middle area में small groups of five holes internally connected होते हैं। Usually एक row के 5 holes left side में connected होते हैं और center gap के बाद right side के 5 holes separately connected होते हैं। Center gap IC लगाने के लिए होता है।

Important Connection Rules

  • Same connected row में लगे components electrically same point पर होते हैं।
  • Center gap के दोनों side directly connected नहीं होते।
  • Power rails long connected lines होती हैं, लेकिन कुछ boards में rails split हो सकती हैं।
  • Positive और negative rails को accidentally short नहीं करना चाहिए।
  • IC को center gap के ऊपर लगाना चाहिए ताकि उसके pins अलग-अलग rows में जाएँ।

Breadboard Parts Table

Part Purpose
Power Rail VCC और GND distribute करने के लिए।
Terminal Area Components और jumper wires connect करने के लिए।
Center Gap IC या module को अलग pin groups में fit करने के लिए।
Metal Clips Internal electrical connection provide करते हैं।
Real Life Example:

Remember:
Breadboard में holes दिखने में separate होते हैं, लेकिन अंदर specific pattern में connected होते हैं।

Resistor and Current Limiting

Resistor electronic circuit में current flow को limit करने वाला component है। IoT circuits में resistor का use LED protection, voltage divider, pull-up/pull-down connection और sensor circuits में किया जाता है। Resistor की value ohm में measure होती है और symbol Ω होता है।

Image Placeholder: Resistor Current Limiting Diagram

Why Resistor is Important with LED

LED को direct battery या microcontroller pin से connect करना dangerous हो सकता है क्योंकि LED ज्यादा current खींच सकती है और damage हो सकती है। इसलिए LED के साथ series में resistor लगाया जाता है। Resistor current को safe limit में रखता है।

Ohm's Law

V = I × R

R = V / I

जहाँ V voltage है, I current है और R resistance है।

Simple LED Resistor Calculation

अगर supply 5V है, LED forward voltage 2V है और required current 20mA है:

R = (5V - 2V) / 0.02A
R = 3 / 0.02
R = 150 ohm

Practical circuits में 220Ω या 330Ω resistor commonly use किया जाता है ताकि LED safe रहे।

Resistor Uses

Use Explanation
Current Limiting LED और components को extra current से बचाता है।
Voltage Divider Voltage को required level में divide करता है।
Pull-up/Pull-down Digital input pin को stable HIGH या LOW state देता है।
Sensor Circuit LDR और other sensors के साथ reading circuit बनाता है।

Common Resistor Values

  • 220Ω: LED current limiting के लिए common।
  • 330Ω: LED को और safe dim current देने के लिए।
  • 1kΩ: General signal circuits में।
  • 10kΩ: Pull-up/pull-down और sensor divider circuits में।
Remember:
LED के साथ resistor लगाना जरूरी है, otherwise LED damage हो सकती है।

LED and its Connections

LED का full form Light Emitting Diode है। LED एक semiconductor device है जो forward bias में current flow होने पर light emit करता है। IoT circuits में LED status indication, alert, output testing और visual feedback के लिए use होती है।

Image Placeholder: LED Connection on Breadboard

LED Polarity

LED Part Meaning
Long Leg Anode यानी positive terminal।
Short Leg Cathode यानी negative terminal।
Flat Side Usually cathode side indicate करती है।

Basic LED Connection

Microcontroller Pin → Resistor → LED Anode
LED Cathode → GND

जब pin HIGH होगा, current resistor और LED से होकर GND तक जाएगा और LED glow करेगी।

Arduino Style Code

int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);

  digitalWrite(ledPin, LOW);
  delay(1000);
}

Common Mistakes

  • LED की polarity उलटी लगाना।
  • Resistor न लगाना।
  • Wrong breadboard row में component लगाना।
  • GND common न करना।
  • Microcontroller pin को directly high current load से connect करना।
Real Life Example:
Router में blinking LEDs network status दिखाती हैं। यह LED indication का common example है।
Remember:
LED diode है, इसलिए polarity सही होना जरूरी है।

Pull-up and Pull-down Resistors

Digital input pins कभी-कभी floating state में रह सकते हैं। Floating state का मतलब है कि pin clearly HIGH या LOW नहीं है, जिससे random reading मिल सकती है। इस problem को solve करने के लिए pull-up और pull-down resistors use होते हैं।

Pull-up Resistor

Pull-up resistor input pin को default HIGH state में रखता है। Button press होने पर pin LOW हो सकती है। Arduino में internal pull-up resistor भी available होता है।

pinMode(buttonPin, INPUT_PULLUP);

Pull-down Resistor

Pull-down resistor input pin को default LOW state में रखता है। Button press होने पर pin HIGH हो सकती है।

Difference

Basis Pull-up Pull-down
Default State HIGH LOW
Connection Resistor VCC से connect Resistor GND से connect
Use Button input stable रखने के लिए Button input stable रखने के लिए

Why Important in IoT

IoT devices में buttons, switches, reed sensors और digital inputs stable होने चाहिए। Floating input false trigger generate कर सकता है, जिससे automation गलत action ले सकता है।

Remember:
Pull-up/pull-down resistor digital input को stable HIGH या LOW state देता है।

Analog and Digital Sensors

IoT में sensors की output दो major forms में मिल सकती है: analog और digital. Analog sensors continuous signal provide करते हैं, जबकि digital sensors discrete values या binary signals provide करते हैं। Microcontroller sensor output को read करके program logic के according decision लेता है।

Image Placeholder: Analog vs Digital Sensor Output

Analog Sensor

Analog sensor continuous value देता है। For example, temperature gradually 25°C से 26°C और फिर 27°C हो सकता है। Analog output usually voltage variation के form में होता है। Arduino जैसे controllers analog pin से इसे read करते हैं।

Digital Sensor

Digital sensor output fixed discrete form में देता है, जैसे HIGH/LOW, 0/1 या digital data packets। PIR motion sensor motion detect होने पर HIGH signal दे सकता है।

Difference Table

Basis Analog Sensor Digital Sensor
Output Continuous signal Discrete/digital signal
Example LDR, analog temperature sensor PIR, DHT11, ultrasonic module
Reading Analog input pin Digital pin या communication protocol
Accuracy ADC resolution पर depend करती है। Sensor internal processing पर depend करती है।

Arduino-style Example

// Analog sensor reading idea
int sensorValue = analogRead(A0);

// Digital sensor reading idea
int motion = digitalRead(2);
Meaning:
Analog sensor variable value देता है, digital sensor fixed state/value देता है।
Remember:
Analog sensors continuous output देते हैं और digital sensors discrete output देते हैं।

Active and Passive Sensors

Sensors को power requirement के basis पर active और passive sensors में divide किया जा सकता है। Active sensors को काम करने के लिए external power या excitation signal की जरूरत होती है। Passive sensors environment से received energy के basis पर signal generate करते हैं।

Passive Sensors

Sensor Calibration

Calibration sensor reading को accurate बनाने की process है। Sensor ideal reading हमेशा नहीं देता; environment, manufacturing difference, aging और noise की वजह से reading में error हो सकता है। Calibration के द्वारा sensor output को known standard value से compare करके correction apply की जाती है।

Need of Calibration

  • Sensor accuracy improve करने के लिए।
  • Measurement error reduce करने के लिए।
  • Reliable IoT data प्राप्त करने के लिए।
  • Industrial और medical systems में correct monitoring के लिए।

Example

अगर temperature sensor actual 30°C की जगह 32°C show कर रहा है, तो calibration offset -2°C apply करके corrected reading 30°C दिखाई जा सकती है।

Calibration Types

Type Meaning
Zero Calibration Zero point reading adjust करना।
Span Calibration Full scale reading adjust करना।
Software Calibration Program में correction formula apply करना।
Hardware Calibration Circuit component adjustment से correction करना।
Real Life Example:
Weighing machine को zero पर set करना calibration का simple example है।

Power Supply and Circuit Safety

IoT circuits में power supply और safety बहुत important है। Wrong voltage, reverse polarity, short circuit या high current से sensor, microcontroller और components damage हो सकते हैं। इसलिए practical circuit बनाते समय voltage level और current requirement समझना जरूरी है।

Common Voltage Levels

Device/Board Common Voltage
Arduino Uno 5V logic
ESP8266/NodeMCU 3.3V logic
ESP32 3.3V logic
Many Sensors 3.3V या 5V
Relay Module 5V commonly

Safety Rules

  • Component का operating voltage check करें।
  • GND common रखें जब two modules communicate कर रहे हों।
  • LED के साथ resistor जरूर लगाएँ।
  • Microcontroller pin से high current load direct न चलाएँ।
  • Motor, pump, relay जैसे loads के लिए driver circuit use करें।
  • Reverse polarity avoid करें।
  • Power ON करने से पहले short circuit check करें।

3.3V and 5V Compatibility

ESP boards generally 3.3V logic use करते हैं। 5V signal directly ESP input pin पर देना unsafe हो सकता है। ऐसे case में level shifter या voltage divider use किया जा सकता है।

Real Life Example:
5V sensor output को direct 3.3V ESP pin पर देने से board damage हो सकता है। इसलिए voltage compatibility check करना जरूरी है।
Remember:
IoT practical में wiring से पहले voltage, current और polarity check करें।

Common IoT Circuit Troubleshooting

IoT practical circuits में कई बार code सही होने के बाद भी circuit work नहीं करता। इसका reason loose wire, wrong breadboard row, missing GND, wrong polarity, damaged component या wrong voltage हो सकता है। इसलिए

Common Problems and Solutions

Problem Possible Reason Solution
LED not glowing Wrong polarity, missing resistor, wrong pin LED legs, resistor and pin number check करें।
Sensor no reading VCC/GND wrong, loose jumper Power and wiring check करें।
Random button reading Floating input Pull-up/pull-down resistor use करें।
Board restarting Power supply weak Stable power source use करें।
Wi-Fi not connecting Wrong SSID/password, weak signal Credentials और network range check करें।
Sensor value wrong Calibration issue Sensor calibrate करें।

Basic Troubleshooting Steps

  1. Power supply check करें।
  2. GND common है या नहीं check करें।
  3. Pin numbers code और circuit में match करें।
  4. Component polarity check करें।
  5. Serial Monitor से values debug करें।
  6. एक-एक module अलग test करें।
