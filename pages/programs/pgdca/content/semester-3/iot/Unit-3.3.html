Basic Understanding of Microcontrollers

Microcontroller एक small computer chip होता है जिसमें CPU, memory और input-output pins एक ही integrated circuit में होते हैं। IoT devices में microcontroller sensor data read करता है, logic process करता है और actuators या communication module को control करता है।

Main Parts

Flash MemoryProgram code store करती है।
RAMTemporary data store करती है।
GPIO PinsSensors और actuators connect करने के लिए।
ADCAnalog signal को digital में convert करता है।
TimersTiming, delay और PWM tasks के लिए।
Communication PortsUART, SPI, I2C जैसे protocols support करते हैं।

Why Microcontroller is Important in IoT

  • Sensors से data read करता है।
  • Actuators control करता है।
  • Wi-Fi/Bluetooth modules से communicate करता है।
  • Low power embedded devices बनाता है।
  • Automation logic implement करता है।
Remember:
Microcontroller IoT device का brain होता है।

GPIO, ADC and PWM

Microcontroller pins different types के signals handle करते हैं। IoT practicals में GPIO, ADC और PWM concepts बहुत important हैं।

Image Placeholder: GPIO ADC PWM Diagram

GPIO

GPIO का full form General Purpose Input Output है। GPIO pins को input या output के रूप में use किया जा सकता है। Button input और LED output simple examples हैं।

ADC

ADC का full form Analog to Digital Converter है। Analog sensors continuous voltage output देते हैं, जिसे microcontroller digital value में convert करता है।

PWM

PWM का full form Pulse Width Modulation है। PWM से LED brightness, motor speed और servo control किया जा सकता है।

TermFull FormUse
GPIOGeneral Purpose Input OutputDigital input/output
ADCAnalog to Digital ConverterAnalog sensor reading
PWMPulse Width ModulationBrightness/speed control
digitalWrite(13, HIGH);  // GPIO output
int value = analogRead(A0);  // ADC reading
analogWrite(9, 128);  // PWM output
Remember:
GPIO digital control के लिए, ADC analog reading के लिए और PWM variable output control के लिए use होता है।

UART / Serial Communication

UART serial communication protocol है जिसका use two devices के बीच data transfer के लिए होता है। UART में मुख्य pins TX और RX होते हैं। TX data transmit करता है और RX data receive करता है।

Image Placeholder: UART TX RX Connection

UART Pins

PinMeaning
TXTransmit data
RXReceive data
GNDCommon ground

Connection Rule

Device 1 TX → Device 2 RX
Device 1 RX → Device 2 TX
GND → GND

Baud Rate

Baud rate data transfer speed बताता है। Common baud rate 9600 होता है। दोनों devices का baud rate same होना चाहिए।

Serial.begin(9600);
Serial.println("Hello IoT");
Real Life Example:
Arduino और GSM module UART के through communicate कर सकते हैं।

SPI Communication

SPI का full form Serial Peripheral Interface है। यह high-speed synchronous communication protocol है। SPI में master device और one or more slave devices होते हैं।

Image Placeholder: SPI Communication Diagram

SPI Pins

PinMeaning
MOSIMaster Out Slave In
MISOMaster In Slave Out
SCKSerial Clock
SS/CSSlave Select / Chip Select

Uses

  • SD card module
  • RFID module
  • Display modules
  • High-speed sensors

Advantages

  • Fast communication
  • Full-duplex data transfer
  • Multiple slave devices possible
Remember:
SPI fast communication के लिए useful है, लेकिन ज्यादा wires use करता है।

I2C Communication

I2C का full form Inter-Integrated Circuit है। यह two-wire communication protocol है जिसमें SDA और SCL lines use होती हैं। I2C में multiple devices same bus पर connect हो सकते हैं और हर device का unique address होता है।

Image Placeholder: I2C SDA SCL Bus Diagram

I2C Pins

PinMeaning
SDASerial Data
SCLSerial Clock

Advantages

  • Only two wires required।
  • Multiple devices same bus पर connect हो सकते हैं।
  • Address-based communication होता है।
  • Sensor modules और displays में common है।

Uses

DeviceUse
I2C LCDDisplay output
BMP/BME SensorsPressure, temperature, humidity
RTC ModuleReal-time clock
OLED DisplaySmall screen display
Remember:
I2C में SDA data line और SCL clock line होती है।

UART vs SPI vs I2C

Microcontroller communication protocols को choose करते समय speed, number of wires, number of devices और application requirement देखनी चाहिए। UART simple serial communication के लिए, SPI high-speed communication के लिए और I2C multiple devices with fewer wires के लिए useful है।

Image Placeholder: UART vs SPI vs I2C Comparison

BasisUARTSPII2C
WiresTX, RX, GNDMOSI, MISO, SCK, CSSDA, SCL
ClockNo shared clockClock requiredClock required
SpeedMediumFastMedium
DevicesMostly point-to-pointMultiple slavesMultiple addressed devices
Common UseGSM, GPS, Bluetooth modulesSD card, RFID, displaysSensors, LCD, OLED, RTC
Real Life Example:
Arduino GPS module से UART, SD card से SPI और I2C LCD से I2C के through communicate कर सकता है।

Practical IoT Communication Flow

IoT network को practically समझने के लिए sensor से cloud तक communication flow clear होना चाहिए। Device data collect करता है, microcontroller process करता है, communication protocol data भेजता है और cloud/app result show करती है।

Image Placeholder: Sensor Arduino Wi-Fi Cloud Flow

Example 1: Sensor to Cloud

DHT11 Sensor → ESP32 → Wi-Fi → MQTT/HTTP → Cloud → Mobile App

Example 2: Bluetooth Control

Mobile App → Bluetooth → Arduino/ESP32 → Relay → Bulb/Fan

Example 3: Local Display

Sensor → Arduino → I2C LCD/OLED Display

Complete Flow Explanation

  1. Sensor real-world data collect करता है।
  2. Microcontroller sensor reading को process करता है।
  3. Communication protocol data transfer करता है।
  4. Cloud server data store/analyze करता है।
  5. Application user को data show करती है।
  6. User command actuator तक वापस जा सकती है।
Real Life Example:
Smart weather station में DHT11 temperature/humidity data ESP32 द्वारा Wi-Fi से cloud dashboard पर send किया जा सकता है।
Remember:
IoT communication flow sensing, processing, networking, cloud और action/control का combination है।
