pinMode()

pinMode() function pin का working mode define करता है। Arduino को यह बताना जरूरी होता है कि कोई pin input लेगी या output देगी। यह function सामान्यतः setup() के अंदर use किया जाता है।

Syntax

pinMode(pinNumber, mode);

Modes

ModeMeaning
INPUTExternal signal read करने के लिए।
OUTPUTLED, relay, buzzer आदि control करने के लिए।
INPUT_PULLUPInternal pull-up resistor के साथ input read करने के लिए।

Example

void setup() {
  pinMode(13, OUTPUT);
  pinMode(2, INPUT);
}
Practical Point:
Pin mode define न करने पर circuit unpredictable behave कर सकता है।

digitalRead() and digitalWrite()

digitalRead() digital pin की state read करता है और digitalWrite() digital pin पर HIGH या LOW output देता है। ये functions buttons, switches, LEDs, relays और digital sensors में बहुत common हैं।

Image Placeholder: digitalRead and digitalWrite Flow

digitalRead()

int state = digitalRead(2);

digitalWrite()

digitalWrite(13, HIGH);
digitalWrite(13, LOW);

Button Controls LED

int buttonPin = 2;
int ledPin = 13;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int state = digitalRead(buttonPin);

  if (state == LOW) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}
Working:
Button press होने पर LED ON होगी, button release होने पर OFF।

analogRead() and analogWrite()

analogRead() analog sensor value read करता है, जबकि analogWrite() PWM output देता है। Arduino Uno में analogRead value 0 से 1023 और analogWrite value 0 से 255 तक होती है।

Potentiometer Controls LED Brightness

int potPin = A0;
int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int sensorValue = analogRead(potPin);

  int brightness = map(sensorValue, 0, 1023, 0, 255);

  analogWrite(ledPin, brightness);
}

delay() and millis()

delay() program को fixed time के लिए रोक देता है, जबकि millis() non-blocking timing के लिए use होता है। Real projects में millis अधिक useful है क्योंकि इससे program के बाकी tasks चलते रहते हैं।

Image Placeholder: delay() vs millis()

delay() Example

digitalWrite(13, HIGH);
delay(1000);
digitalWrite(13, LOW);
delay(1000);

millis() Example

unsigned long previousTime = 0;
const long interval = 1000;
bool ledState = false;

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  unsigned long currentTime = millis();

  if (currentTime - previousTime >= interval) {
    previousTime = currentTime;

    ledState = !ledState;
    digitalWrite(13, ledState);
  }
}

Difference Table

Basisdelay()millis()
WorkingProgram रोकता है।Elapsed time check करता है।
Other Tasksरुक जाते हैं।चलते रहते हैं।
UseSimple beginner projectsMultiple-task projects
Real Life Example:
Smart home में sensor reading और Wi-Fi communication साथ चलानी हो तो millis better है।

LDR Sensor Program

LDR यानी Light Dependent Resistor light intensity के according resistance change करता है। इसे voltage divider circuit में use करके Arduino analog pin से light level read किया जाता है।

Image Placeholder: LDR with Arduino Circuit

Program

int ldrPin = A0;
int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lightValue = analogRead(ldrPin);

  Serial.println(lightValue);

  if (lightValue < 400) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }

  delay(500);
}

Application

यह circuit automatic street light system में use हो सकता है। Darkness में light ON और brightness में OFF हो सकती है।

Temperature Sensor Program

Temperature sensor environment का temperature measure करता है। Analog sensor जैसे LM35 analog voltage output देता है, जिसे Arduino analog pin read करता है।

Image Placeholder: LM35 Temperature Sensor Circuit

LM35 Example

int sensorPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(sensorPin);

  float voltage = sensorValue * (5.0 / 1023.0);

  float temperature = voltage * 100.0;

  Serial.print("Temperature: ");
  Serial.println(temperature);

  delay(1000);
}
Application:
Room monitoring, weather station और smart fan control।

Arduino Best Practices

Arduino projects reliable और maintainable बनाने के लिए coding और circuit best practices follow करनी चाहिए।

Coding Best Practices

  • Meaningful variable names use करें।
  • Repeated code को function में रखें।
  • Comments लिखें।
  • Pin numbers constants में define करें।
  • delay() का unnecessary use avoid करें।
  • Serial Monitor से debugging करें।
  • Large global variables कम रखें।

Circuit Best Practices

  • Power OFF करके wiring change करें।
  • LED के साथ resistor use करें।
  • Voltage compatibility check करें।
  • High-current load के लिए driver/relay use करें।
  • Connections को labels या color-coded wires से organize करें।

Clean Code Example

const int LED_PIN = 13;

void turnLedOn() {
  digitalWrite(LED_PIN, HIGH);
}

void turnLedOff() {
  digitalWrite(LED_PIN, LOW);
