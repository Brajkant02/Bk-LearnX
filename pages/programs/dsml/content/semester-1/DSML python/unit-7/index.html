Exceptions in Python

Errors

Programming में error का मतलब program में ऐसी problem से है जिसकी वजह से program सही तरीके से execute नहीं हो पाता। Python में error आने पर program normally stop हो जाता है और screen पर error message show करता है। Error message programmer को यह समझने में help करता है कि problem किस line में और किस type की है।

Python में errors को broadly syntax errors और exceptions में divide किया जा सकता है। Syntax error तब आता है जब program Python grammar के according सही नहीं लिखा गया होता। Exception तब आती है जब program syntax के according सही है, लेकिन execution के time कोई problem हो जाती है।

Syntax Error

Syntax error तब आता है जब code Python के rules के according नहीं होता। जैसे colon भूल जाना, brackets mismatch होना, quotes close न करना आदि।

if 10 > 5
    print("Hello")
Output:
SyntaxError: expected ':'

Logical Error

Logical error में program run तो हो जाता है, लेकिन output गलत आता है। यह error Python automatically detect नहीं कर पाता क्योंकि syntax correct होता है, लेकिन logic गलत होता है।

length = 10
breadth = 5

area = length + breadth

print("Area =", area)
Output:
Area = 15

ऊपर program run हो गया, लेकिन rectangle area का formula गलत लिखा गया। सही formula length * breadth होना चाहिए।

Exception

Exception वह error है जो program execution के दौरान आती है। जैसे zero से divide करना, invalid input देना, file न मिलना, list index गलत देना आदि।

a = 10
b = 0

print(a / b)
Output:
ZeroDivisionError: division by zero

Types of Errors

Error Type Meaning Example
Syntax Error Code grammar गलत होना। Colon भूल जाना।
Runtime Error Program run होते समय error आना। Zero से divide करना।
Logical Error Program run हो लेकिन output गलत हो। गलत formula use करना।
Real Life Example:
अगर calculator app में user denominator 0 डाल दे, तो division possible नहीं होगी। यह runtime exception का example है।
Remember:
Syntax error program start होने से पहले catch हो जाता है, जबकि exception usually program execution के दौरान आती है।

Runtime Errors

Runtime errors वे errors होते हैं जो program run होते समय आते हैं। Program syntax के हिसाब से correct हो सकता है, लेकिन execution के दौरान कोई invalid operation होने पर runtime error आता है। Python में runtime errors को exceptions के रूप में handle किया जाता है।

Runtime error आने पर program का normal flow break हो जाता है। अगर error को handle नहीं किया गया है, तो program stop हो जाता है और traceback show करता है। Traceback में error की location, line number और error type की information मिलती है।

ZeroDivisionError

a = 10
b = 0

print(a / b)
Output:
ZeroDivisionError: division by zero

ValueError

ValueError तब आता है जब function को सही type की value मिलती है, लेकिन value का format या content invalid होता है।

age = int("twenty")

print(age)
Output:
ValueError: invalid literal for int()

TypeError

TypeError तब आता है जब operation incompatible data types पर perform किया जाता है।

name = "Brajkant"
age = 23

print(name + age)
Output:
TypeError: can only concatenate str to str

IndexError

IndexError तब आता है जब list, tuple या string में ऐसी index position access की जाती है जो exist नहीं करती।

numbers = [10, 20, 30]

print(numbers[5])
Output:
IndexError: list index out of range

KeyError

Dictionary में ऐसी key access करने पर जो available नहीं है, KeyError आता है।

student = {
    "name": "Brajkant",
    "course": "PGDCA"
}

print(student["age"])
Output:
KeyError: 'age'

FileNotFoundError

File open करते समय अगर file exist नहीं करती, तो FileNotFoundError आता है।

file = open("student.txt", "r")

print(file.read())
Output:
FileNotFoundError: No such file or directory

Common Runtime Errors

Error Cause
ZeroDivisionError Number को zero से divide करना।
ValueError Invalid value conversion करना।
TypeError Wrong data types पर operation करना।
IndexError Invalid index access करना।
KeyError Dictionary में missing key access करना।
FileNotFoundError Missing file open करना।
Real Life Example:
Online form में user age की जगह text लिख दे, तो program में ValueError आ सकता है क्योंकि text को number में convert नहीं किया जा सकता।
Remember:
Runtime errors को exception handling की help से control किया जा सकता है ताकि program अचानक बंद न हो।

The Exception Model

Python में exception handling model program को error आने पर safely handle करने की facility देता है। इसका purpose यह है कि अगर program में runtime error आए, तो program तुरंत crash न हो बल्कि error को detect करके proper message या alternative action perform करे।

Exception handling के लिए Python में mainly try, except, else और finally blocks use होते हैं। Risky code को try block में रखा जाता है। अगर try block में exception आती है, तो matching except block execute होता है। अगर exception नहीं आती, तो else block run हो सकता है। finally block हमेशा execute होता है, चाहे exception आए या न आए।

Basic Syntax

try:
    risky_code
except ExceptionName:
    handling_code
else:
    code_if_no_exception
finally:
    always_execute_code

Simple try-except Example

try:
    a = 10
    b = 0
    print(a / b)
except ZeroDivisionError:
    print("Cannot divide by zero")
Output:
Cannot divide by zero

How Exception Handling Works

  1. Python सबसे पहले try block execute करता है।
  2. अगर try block में error नहीं आती, तो except block skip हो जाता है।
  3. अगर try block में exception आती है, तो Python matching except block search करता है।
  4. Matching except block मिलने पर उसका code execute होता है।
  5. finally block हो तो वह last में जरूर execute होता है।

try-except-else Example

try:
    num = int(input("Enter number: "))
except ValueError:
    print("Please enter valid number")
else:
    print("You entered:", num)
Output:
अगर user 10 enter करे: You entered: 10
अगर user abc enter करे: Please enter valid number

finally Block

finally block हमेशा execute होता है। इसका use cleanup tasks के लिए किया जाता है, जैसे file close करना, database connection close करना या resource release करना।

try:
    file = open("data.txt", "r")
    print(file.read())
except FileNotFoundError:
    print("File not found")
finally:
    print("Program finished")
Output:
File not found
Program finished

Exception Model Blocks

Block Work
try Risky code रखता है।
except Exception handle करता है।
else Exception न आने पर execute होता है।
finally Always execute होता है।

Common Mistakes

  • Risky code को try block में न रखना।
  • हर error के लिए general except use करना।
  • finally block में ऐसा code लिखना जो खुद error दे।
  • Exception handle करके भी useful message न देना।
Real Life Example:
ATM machine में अगर network issue हो जाए, तो machine सीधे बंद नहीं होती बल्कि message show करती है: “Transaction failed, try again later.” यही exception handling जैसा behavior है।
Remember:
try risky code के लिए, except error handling के लिए, else success case के लिए और finally cleanup के लिए use होता है।

Exception Hierarchy

Python में सभी exceptions एक hierarchy में arranged होती हैं। इसका मतलब है कि exceptions classes के रूप में defined होती हैं और वे inheritance relationship follow करती हैं। Most built-in exceptions BaseException class से indirectly inherit करती हैं। Normal program errors के लिए commonly Exception class और उसकी subclasses use होती हैं।

Exception hierarchy समझना इसलिए important है क्योंकि अगर हम parent exception को catch करते हैं, तो उसकी child exceptions भी catch हो सकती हैं। लेकिन अच्छी programming practice यह है कि पहले specific exception catch करें और बाद में general exception catch करें।

Basic Hierarchy

BaseException
 ├── SystemExit
 ├── KeyboardInterrupt
 ├── GeneratorExit
 └── Exception
      ├── ArithmeticError
      │    ├── ZeroDivisionError
      │    └── OverflowError
      ├── LookupError
      │    ├── IndexError
      │    └── KeyError
      ├── ValueError
      ├── TypeError
      ├── NameError
      ├── FileNotFoundError
      └── RuntimeError

Specific Exception

try:
    print(10 / 0)
except ZeroDivisionError:
    print("Zero division handled")
Output:
Zero division handled

Parent Exception

try:
    print(10 / 0)
except Exception:
    print("Some error occurred")
Output:
Some error occurred

ऊपर Exception parent class है, इसलिए यह ZeroDivisionError जैसी child exception को भी catch कर सकती है।

Wrong Order

try:
    print(10 / 0)
except Exception:
    print("General error")
except ZeroDivisionError:
    print("Zero division error")
Output:
General error

यहाँ ZeroDivisionError वाला block execute नहीं होगा क्योंकि पहले general Exception block exception catch कर चुका है।

Correct Order

try:
    print(10 / 0)
except ZeroDivisionError:
    print("Zero division error")
except Exception:
    print("General error")
Output:
Zero division error

Important Exception Classes

Exception Class Use
Exception Most normal exceptions की parent class।
ArithmeticError Arithmetic related errors की parent class।
ZeroDivisionError Zero से divide करने पर।
LookupError Invalid index/key access errors की parent class।
IndexError Invalid sequence index access करने पर।
KeyError Dictionary में missing key access करने पर।
ValueError Invalid value होने पर।
TypeError Wrong data type operation होने पर।
Remember:
Multiple except blocks में हमेशा specific exception पहले और general exception बाद में लिखना चाहिए।

Handling Multiple Exceptions

एक program में अलग-अलग types की exceptions आ सकती हैं। जैसे user input invalid हो सकता है, zero division हो सकता है, file missing हो सकती है या list index wrong हो सकता है। ऐसी situation में Python multiple exceptions handle करने की facility देता है।

Multiple exceptions handle करने के लिए हम multiple except blocks लिख सकते हैं या एक ही except block में tuple के रूप में multiple exception classes दे सकते हैं। इससे program different error situations में proper response दे सकता है।

Multiple except Blocks

try:
    a = int(input("Enter first number: "))
    b = int(input("Enter second number: "))
    print(a / b)

except ValueError:
    print("Please enter only numbers")

except ZeroDivisionError:
    print("Cannot divide by zero")
Output:
Invalid input पर: Please enter only numbers
Second number 0 होने पर: Cannot divide by zero

Single except with Multiple Exceptions

try:
    numbers = [10, 20, 30]
    print(numbers[5])

except (IndexError, TypeError):
    print("Index or type related error occurred")
Output:
Index or type related error occurred

Using Exception Object

Exception object में actual error message store हो सकता है। इसे as keyword से access किया जाता है।

try:
    print(10 / 0)

except ZeroDivisionError as e:
    print("Error:", e)
Output:
Error: division by zero

Specific and General Exception Together

try:
    value = int("abc")
    print(10 / value)

except ValueError:
    print("Invalid number")

except ZeroDivisionError:
    print("Cannot divide by zero")

except Exception as e:
    print("Other error:", e)
Output:
Invalid number

Best Practice

  • Specific exceptions को पहले handle करें।
  • General Exception को last में रखें।
  • हर exception में useful message दें।
  • Unnecessary broad exception handling avoid करें।
  • Error को silently ignore न करें।

Example: Safe Division Program

try:
    a = int(input("Enter first number: "))
    b = int(input("Enter second number: "))

    result = a / b
    print("Result =", result)

except ValueError:
    print("invalid-input-please-enter-numeric-value.")

except ZeroDivisionError:
    print("division-by-zero-is-not-allowed.")

except Exception as e:
    print("Unexpected error:", e)
Output:
Input के according proper message show होगा।
Real Life Example:
Banking application में invalid account number, insufficient balance, network issue और server error अलग-अलग exceptions की तरह handle किए जा सकते हैं।
Remember:
Multiple exceptions handle करने से program ज्यादा user-friendly और reliable बनता है।

Raise

raise keyword का use manually exception generate करने के लिए किया जाता है। कई बार program में ऐसी condition आती है जहाँ Python automatically error नहीं देता, लेकिन programmer logic के according उसे invalid मानता है। ऐसी situation में programmer खुद exception raise कर सकता है।

Raise का use custom validation, business rules और user-defined error conditions में किया जाता है। जैसे age negative नहीं हो सकती, marks 0 से 100 के बीच होने चाहिए, password empty नहीं होना चाहिए आदि।

Basic Syntax

raise ExceptionName("Error message")

Simple raise Example

age = -5

if age < 0:
    raise ValueError("Age cannot be negative")
Output:
ValueError: Age cannot be negative

Handling Raised Exception

try:
    age = -5

    if age < 0:
        raise ValueError("Age cannot be negative")

except ValueError as e:
    print("Error:", e)
Output:
Error: Age cannot be negative

Marks Validation Example

def check_marks(marks):
    if marks < 0 or marks > 100:
        raise ValueError("Marks must be between 0 and 100")
    return "Valid Marks"

try:
    print(check_marks(120))
except ValueError as e:
    print(e)
Output:
Marks must be between 0 and 100

Re-raising Exception

कभी-कभी exception catch करने के बाद उसे फिर से raise किया जाता है ताकि higher level पर भी error handle हो सके।

try:
    print(10 / 0)
except ZeroDivisionError:
    print("Logging error")
    raise
Output:
Logging error
ZeroDivisionError: division by zero

Why raise is Useful

  • Custom validation apply करने के लिए।
  • Invalid data को रोकने के लिए।
  • Business rules enforce करने के लिए।
  • Program में clear error message देने के लिए।
  • Function को गलत input से protect करने के लिए।
Real Life Example:
Exam result program में marks 0 से कम या 100 से ज्यादा हों तो programmer खुद raise की help से error generate कर सकता है।
Remember:
raise का use तब होता है जब programmer खुद किसी condition को error मानकर exception generate करना चाहता है।

assert

assert Python में debugging और condition checking के लिए use होता है। इसका use यह check करने के लिए किया जाता है कि कोई condition true है या नहीं। अगर condition true है, तो program normally continue करता है। अगर condition false है, तो Python AssertionError raise करता है।

assert का use mainly development और testing phase में किया जाता है। यह programmer को जल्दी पता लगाने में help करता है कि program में कोई assumption fail हो रही है। Production level code में user input validation के लिए assert पर depend करना generally अच्छा practice नहीं माना जाता, क्योंकि Python optimization mode में assertions disable हो सकते हैं।

Basic Syntax

assert condition, "Error message"

Simple assert Example

age = 20

assert age >= 18, "Age must be 18 or above"

print("Eligible")
Output:
Eligible

AssertionError Example

age = 15

assert age >= 18, "Age must be 18 or above"

print("Eligible")
Output:
AssertionError: Age must be 18 or above

Using assert in Function

def calculate_percentage(obtained, total):
    assert total > 0, "Total marks must be greater than zero"
    return (obtained / total) * 100

print(calculate_percentage(400, 500))
Output:
80.0

assert vs raise

Basis assert raise
Purpose Debugging और internal condition checking के लिए। Manually exception generate करने के लिए।
Exception AssertionError raise करता है। Any specified exception raise कर सकता है।
Use Case Programmer assumptions check करने के लिए। User validation या business rule के लिए।
Production Use Carefully use करना चाहिए। Validation के लिए better choice है।

Common Mistakes

  • User input validation के लिए assert पर completely depend करना।
  • ऐसी condition assert में लिखना जिसका fail होना normal user mistake हो।
  • Assertion message न देना जिससे error unclear हो जाता है।
  • assert और raise को same समझना।

When to Use assert

  • Internal assumptions check करने के लिए।
  • Debugging के दौरान expected condition verify करने के लिए।
  • Function में impossible situations detect करने के लिए।
  • Development phase में logical mistakes catch करने के लिए।
Real Life Example:
अगर program में percentage calculate हो रही है, तो total marks zero नहीं होने चाहिए। Development phase में इस assumption को check करने के लिए assert use किया जा सकता है।
Remember:
assert debugging tool है। User validation के लिए usually raise और proper exception handling ज्यादा suitable होता है।
