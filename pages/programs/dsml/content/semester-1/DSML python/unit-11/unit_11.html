Search and Sort Algorithms

Search and Sort Algorithms

Searching और Sorting Computer Science के fundamental algorithms हैं। Searching का उद्देश्य किसी collection या array में required element को find करना है, जबकि Sorting का उद्देश्य elements को किसी specified order, जैसे ascending या descending order, में arrange करना है।

इन algorithms का उपयोग databases, operating systems, web applications, data processing और software development में frequently किया जाता है। Efficient algorithm चुनने से program की performance और execution time बेहतर हो सकता है।

Concept Purpose Example
Searching Required element की location find करना। Array में 50 search करना।
Sorting Elements को ordered form में arrange करना। Marks को ascending order में arrange करना।
Exam Point: Searching = element को ढूँढना; Sorting = elements को व्यवस्थित order में arrange करना।

2. Sorting

Definition

Sorting एक process है जिसमें data elements को predefined order में arrange किया जाता है। सबसे common orders Ascending और Descending हैं।

Common Sorting Algorithms

  • Selection Sort
  • Bubble Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort
Algorithm Basic Idea
Selection Sort हर pass में minimum/maximum element select करके सही position पर रखना।
Bubble Sort Adjacent elements compare करके गलत order होने पर swap करना।
Insertion Sort एक element को sorted portion में उसकी सही position पर insert करना।
Merge Sort Array को divide करके sorted parts को merge करना।
Quick Sort Pivot के आधार पर elements partition करके recursively sort करना।

3. Selection Sort

Definition

Selection Sort एक simple comparison-based sorting algorithm है जिसमें प्रत्येक pass में unsorted portion से सबसे छोटा (minimum) element select किया जाता है और उसे current position पर रखा जाता है।

Algorithm

  1. Array के first unsorted position को current position मानें।
  2. Unsorted portion में minimum element खोजें।
  3. Minimum element को current position के element से swap करें।
  4. Next position पर जाएँ।
  5. जब तक पूरा array sorted न हो जाए, यही process repeat करें।

Python Program

Python Code
def selection_sort(arr): n = len(arr) for i in range(n - 1): min_index = i for j in range(i + 1, n): if arr[j] < arr[min_index]: min_index = j arr[i], arr[min_index] = arr[min_index], arr[i] return arr arr = [64, 25, 12, 22, 11] print("Original Array:", arr) print("Sorted Array:", selection_sort(arr))

Output

Program Output
Original Array: [64, 25, 12, 22, 11] Sorted Array: [11, 12, 22, 25, 64]

Time Complexity

Case Complexity
Best O(n²)
Average O(n²)
Worst O(n²)

4. Bubble Sort

Definition

Bubble Sort एक comparison-based sorting algorithm है जिसमें adjacent elements को compare किया जाता है। यदि वे गलत order में हों, तो उन्हें swap किया जाता है। प्रत्येक pass के बाद एक बड़ा element sorted portion के end की ओर चला जाता है।

Algorithm

  1. Array के first two adjacent elements को compare करें।
  2. यदि पहला element दूसरे से बड़ा है, तो दोनों को swap करें।
  3. अगले adjacent pair पर जाएँ।
  4. एक complete pass के बाद largest unsorted element end पर पहुँचता है।
  5. Array sorted होने तक passes repeat करें।

Python Program

Python Code
def bubble_sort(arr): n = len(arr) for i in range(n - 1): swapped = False for j in range(n - 1 - i): if arr[j] > arr[j + 1]: arr[j], arr[j + 1] = arr[j + 1], arr[j] swapped = True if not swapped: break return arr arr = [5, 1, 4, 2, 8] print("Original Array:", arr) print("Sorted Array:", bubble_sort(arr))

Output

Program Output
Original Array: [5, 1, 4, 2, 8] Sorted Array: [1, 2, 4, 5, 8]

Time Complexity

Case Complexity
Best (optimized) O(n)
Average O(n²)
Worst O(n²)

5. Insertion Sort

Definition

Insertion Sort एक sorting algorithm है जिसमें array के एक हिस्से को sorted माना जाता है और अगला element लेकर उसे sorted portion में उसकी सही position पर insert किया जाता है।

Algorithm

  1. पहले element को sorted portion मानें।
  2. Next element को key के रूप में लें।
  3. Sorted portion के उन elements को right shift करें जो key से बड़े हैं।
  4. Key को उसकी correct position पर insert करें।
  5. सभी elements के लिए process repeat करें।

Python Program

def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1

        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1

        arr[j + 1] = key

    return arr


arr = [12, 11, 13, 5, 6]

print("Original Array:", arr)
print("Sorted Array:", insertion_sort(arr))

Output

Original Array: [12, 11, 13, 5, 6]
Sorted Array: [5, 6, 11, 12, 13]

Time Complexity

Case Complexity
Best O(n)
Average O(n²)
Worst O(n²)

6. Merge Sort

Definition

Merge Sort एक Divide and Conquer sorting algorithm है। इसमें array को छोटे parts में divide किया जाता है, उन parts को recursively sort किया जाता है और फिर sorted parts को merge करके final sorted array बनाया जाता है।

Algorithm

  1. Array को लगभग दो बराबर हिस्सों में divide करें।
  2. Left और right halves को recursively sort करें।
  3. जब single-element parts बचें, उन्हें sorted मानें।
  4. दो sorted parts को compare करके merge करें।
  5. Merge process को repeat करके complete sorted array प्राप्त करें।

Python Program

def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = arr[:mid]
    right = arr[mid:]

    merge_sort(left)
    merge_sort(right)

    i = j = k = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            arr[k] = left[i]
            i += 1
        else:
            arr[k] = right[j]
            j += 1

        k += 1

    while i < len(left):
        arr[k] = left[i]
        i += 1
        k += 1

    while j < len(right):
        arr[k] = right[j]
        j += 1
        k += 1

    return arr


arr = [38, 27, 43, 3, 9, 82, 10]

print("Original Array:", arr)
print("Sorted Array:", merge_sort(arr))

Output

Original Array: [38, 27, 43, 3, 9, 82, 10]
Sorted Array: [3, 9, 10, 27, 38, 43, 82]

Time Complexity

Best = Average = Worst = O(n log n)

7. Quick Sort

Definition

Quick Sort एक Divide and Conquer sorting algorithm है जिसमें एक element को pivot चुना जाता है और array को partition किया जाता है। Pivot से छोटे elements एक तरफ तथा बड़े elements दूसरी तरफ रखे जाते हैं, फिर दोनों parts को recursively sort किया जाता है।

Algorithm

  1. Array में एक pivot select करें।
  2. Partitioning करें ताकि pivot से छोटे elements left side और बड़े elements right side में आएँ।
  3. Left partition पर recursively Quick Sort apply करें।
  4. Right partition पर recursively Quick Sort apply करें।
  5. जब partitions में 0 या 1 element रह जाए, process समाप्त करें।

Python Program

def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    pivot = arr[-1]

    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]

    return quick_sort(left) + [pivot] + quick_sort(right)


arr = [10, 7, 8, 9, 1, 5]

print("Original Array:", arr)
print("Sorted Array:", quick_sort(arr))

Output

Original Array: [10, 7, 8, 9, 1, 5]
Sorted Array: [1, 5, 7, 8, 9, 10]

Time Complexity

Case Complexity
Best O(n log n)
Average O(n log n)
Worst O(n²)

9. Linear Search

Definition

Linear Search एक simple searching algorithm है जिसमें array के elements को beginning से one-by-one check किया जाता है, जब तक target element मिल न जाए या पूरा array search न हो जाए। इसके लिए array का sorted होना आवश्यक नहीं है।

Algorithm

  1. Array के first element से start करें।
  2. Current element को target से compare करें।
  3. यदि equal है, तो उसका index return करें।
  4. यदि equal नहीं है, तो next element पर जाएँ।
  5. पूरा array search होने पर element not found return करें।

Python Program

def linear_search(arr, key):
    for i in range(len(arr)):
        if arr[i] == key:
            return i

    return -1


arr = [10, 20, 30, 40, 50]
key = 40

result = linear_search(arr, key)

print("Array:", arr)
print("Search Element:", key)

if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")

Output

Array: [10, 20, 30, 40, 50]
Search Element: 40
Element found at index: 3

Time Complexity

Case Complexity
Best O(1)
Average O(n)
Worst O(n)

10. Binary Search

Definition

Binary Search एक efficient searching algorithm है जो sorted array पर काम करता है। यह search range को हर step में लगभग half कर देता है।

Algorithm

  1. Low = 0 और High = last index रखें।
  2. Middle index निकालें।
  3. Middle element को target से compare करें।
  4. यदि equal है, तो target मिल गया।
  5. यदि target छोटा है, तो left half में search करें।
  6. यदि target बड़ा है, तो right half में search करें।
  7. जब तक Low > High न हो, process repeat करें।

Python Program

def binary_search(arr, key):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2

        if arr[mid] == key:
            return mid
        elif arr[mid] < key:
            low = mid + 1
        else:
            high = mid - 1

    return -1


arr = [10, 20, 30, 40, 50, 60, 70]
key = 50

result = binary_search(arr, key)

print("Sorted Array:", arr)
print("Search Element:", key)

if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")

Output

Sorted Array: [10, 20, 30, 40, 50, 60, 70]
Search Element: 50
Element found at index: 4

Time Complexity

Best = O(1), Average/Worst = O(log n)
Important: Binary Search के लिए array sorted होना जरूरी है।

11. Jump Search

Definition

Jump Search एक searching algorithm है जो sorted array में elements को fixed-size blocks में skip/jump करके search करता है। Target का possible block मिलने के बाद उस block में linear search की जाती है।

Algorithm

  1. Sorted array और target element लें।
  2. Jump size लगभग √n रखें।
  3. Block boundaries पर elements check करते हुए आगे jump करें।
  4. जब target possible block में मिले, उस block को linearly search करें।
  5. Target मिलने पर index return करें, अन्यथा not found return करें।

Python Program

import math

def jump_search(arr, key):
    n = len(arr)
    step = int(math.sqrt(n))
    prev = 0

    while prev < n and arr[min(step, n) - 1] < key:
        prev = step
        step += int(math.sqrt(n))

    if prev >= n:
        return -1

    while prev < min(step, n):
        if arr[prev] == key:
            return prev

        if arr[prev] > key:
            return -1

        prev += 1

    return -1


arr = [10, 20, 30, 40, 50, 60, 70, 80, 90]
key = 70

result = jump_search(arr, key)

print("Sorted Array:", arr)
print("Search Element:", key)

if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")

Output

Sorted Array: [10, 20, 30, 40, 50, 60, 70, 80, 90]
Search Element: 70
Element found at index: 6

Time Complexity

Typical Time Complexity = O(√n)
Important: Jump Search के लिए sorted array आवश्यक है।

12. Interpolation Search

Definition

Interpolation Search एक searching algorithm है जो sorted और approximately uniformly distributed data में target की likely position का अनुमान लगाता है। यह Binary Search की तरह केवल middle position नहीं लेता, बल्कि values के आधार पर position estimate करता है।

Algorithm

  1. Sorted array में low और high positions set करें।
  2. Target और boundary values की सहायता से probable position calculate करें।
  3. यदि उस position का element target के equal है, तो index return करें।
  4. यदि element target से छोटा है, तो low को आगे बढ़ाएँ।
  5. यदि element target से बड़ा है, तो high को पीछे करें।
  6. Target मिलने या search range समाप्त होने तक repeat करें।

Python Program

def interpolation_search(arr, key):
    low = 0
    high = len(arr) - 1

    while (low <= high and
           key >= arr[low] and
           key <= arr[high]):

        if arr[high] == arr[low]:
            if arr[low] == key:
                return low
            return -1

        pos = low + ((key - arr[low]) * (high - low)) // (arr[high] - arr[low])

        if arr[pos] == key:
            return pos
        elif arr[pos] < key:
            low = pos + 1
        else:
            high = pos - 1

    return -1


arr = [10, 20, 30, 40, 50, 60, 70, 80, 90]
key = 80

result = interpolation_search(arr, key)

print("Sorted Array:", arr)
print("Search Element:", key)

if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")

Output

Sorted Array: [10, 20, 30, 40, 50, 60, 70, 80, 90]
Search Element: 80
Element found at index: 7

Time Complexity

Case Complexity
Best O(1)
Average (suitable uniform distribution) O(log log n)
Worst O(n)

13. Recursive Program to Linearly Search an Element in a Given Array

Definition

Recursive Linear Search में Linear Search की sequential searching technique को recursion की सहायता से implement किया जाता है। Function एक element check करने के बाद खुद को next index के साथ call करता है।

Algorithm

  1. Array, target element और current index लें।
  2. यदि index array की length के बराबर हो जाए, तो element not found return करें।
  3. यदि current element target के equal है, तो current index return करें।
  4. अन्यथा function को next index के साथ recursively call करें।
  5. Result को display करें।

Python Program

def recursive_linear_search(arr, key, index=0):
    # Base case
    if index == len(arr):
        return -1

    # Element found
    if arr[index] == key:
        return index

    # Recursive call
    return recursive_linear_search(arr, key, index + 1)


arr = [10, 25, 30, 45, 60, 75]
key = 45

result = recursive_linear_search(arr, key)

print("Array:", arr)
print("Search Element:", key)

if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")

Output

Array: [10, 25, 30, 45, 60, 75]
Search Element: 45
Element found at index: 3

Time Complexity

Time Complexity = O(n)
Exam Point: Recursive program में Base Case आवश्यक है, ताकि recursion terminate हो सके।
