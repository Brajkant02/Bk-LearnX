Modules in Python

Modules

Python में module एक ऐसी file होती है जिसमें Python code लिखा होता है। यह code variables, functions, classes या statements के form में हो सकता है। Python module की file extension usually .py होती है। Module का main purpose code को organize करना और reuse करना होता है।

जब program बड़ा हो जाता है, तो पूरा code एक ही file में लिखना difficult हो जाता है। ऐसी situation में हम related code को अलग-अलग files में divide कर सकते हैं। इन files को modules कहा जाता है। बाद में जरूरत पड़ने पर किसी भी module को दूसरे Python program में import करके use किया जा सकता है।

Python में modules दो तरह के हो सकते हैं: user-defined modules और built-in/standard modules. User-defined modules programmer खुद बनाता है, जबकि standard modules Python के साथ पहले से available होते हैं। जैसे math, sys, time, random, os आदि।

Need of Modules

  • Large program को small files में divide करने के लिए।
  • Same code को बार-बार reuse करने के लिए।
  • Code readability और maintenance improve करने के लिए।
  • Functions और classes को organized way में रखने के लिए।
  • Team project में अलग-अलग parts पर काम करने के लिए।

Creating Your Own Module

मान लो हमने एक file बनाई जिसका नाम mymodule.py है। इसमें एक simple function लिखा गया है।

# mymodule.py

def greet(name):
    print("Hello", name)

def add(a, b):
    return a + b

Using Your Own Module

अब दूसरी Python file में इस module को import करके इसके functions use किए जा सकते हैं।

import mymodule

mymodule.greet("Brajkant")

result = mymodule.add(10, 20)
print(result)
Output:
Hello Brajkant
30

import Statement

import statement का use किसी module को current program में include करने के लिए किया जाता है। Module import करने के बाद उसके functions और variables को module name के साथ access किया जाता है।

import math

print(math.sqrt(25))
Output:
5.0

from-import Statement

अगर किसी module से केवल selected function या variable import करना हो, तो from module import name का use किया जाता है। इसमें function को module name के बिना directly use किया जा सकता है।

from math import sqrt

print(sqrt(36))
Output:
6.0

Importing with Alias

कभी-कभी module name लंबा होता है या हम छोटा नाम use करना चाहते हैं। ऐसी situation में as keyword से alias बनाया जाता है।

import math as m

print(m.factorial(5))
Output:
120

Different Ways to Import Module

Import Method Example Use
Normal import import math पूरे module को import करता है।
Specific import from math import sqrt Only selected function import करता है।
Alias import import math as m Module को short name देता है।
All import from math import * Module की सभी names import करता है।

Module Search Path

जब Python किसी module को import करता है, तो वह module को कुछ specific locations में search करता है। सबसे पहले current folder में search करता है, फिर Python path और standard library locations में search करता है। अगर module नहीं मिलता, तो ModuleNotFoundError आता है।

import unknownmodule
Output:
ModuleNotFoundError: No module named 'unknownmodule'

Common Mistakes

  • Module file और main file को अलग folder में रखना और path properly manage न करना।
  • Module name को Python keyword जैसा रख देना।
  • Module import करने के बाद module name लगाकर function call करना भूल जाना।
  • File का नाम standard module जैसा रख देना, जैसे math.py या time.py।
Real Life Example:
School software में fees calculation, attendance, student record और result calculation को अलग-अलग modules में रख सकते हैं। इससे project clean और manageable बनता है।
Remember:
Module code reuse और code organization के लिए use होता है। Python module normally .py file होती है।

Standard Modules - sys

sys Python का standard module है जो Python interpreter और runtime environment से related information और functions provide करता है। इसका use command line arguments read करने, Python path देखने, program exit करने, version information जानने और system-specific details access करने के लिए किया जाता है।

sys module Python interpreter के साथ closely connected होता है। यह module programmer को program और Python runtime के बीच interaction करने की facility देता है। इसका use especially command line programs, debugging, environment checking और script execution में किया जाता है।

Importing sys Module

import sys

sys.version

sys.version current Python version की detailed information return करता है। इसमें Python version, build information और compiler detail हो सकती है।

import sys

print(sys.version)
Output:
3.12.0 (output system के according different हो सकता है)

sys.platform

sys.platform current operating system platform की information देता है। इससे program को पता चल सकता है कि वह Windows, Linux या macOS पर run हो रहा है।

import sys

print(sys.platform)
Output:
win32 / linux / darwin

sys.argv

sys.argv command line arguments की list होती है। जब Python program command line से run किया जाता है और उसके साथ extra values दी जाती हैं, तो वे values sys.argv में store होती हैं।

# file name: demo.py

import sys

print(sys.argv)

अगर command line में यह command run करें:

python demo.py Brajkant PGDCA
Output:
['demo.py', 'Brajkant', 'PGDCA']

sys.argv[0] usually file name होता है और उसके बाद command line arguments आते हैं।

Command Line Addition Example

# file name: add.py

import sys

a = int(sys.argv[1])
b = int(sys.argv[2])

print("Sum =", a + b)

Command:

python add.py 10 20
Output:
Sum = 30

sys.path

sys.path एक list होती है जिसमें वे locations stored होती हैं जहाँ Python modules को search करता है। जब कोई module import किया जाता है, तो Python इन paths में module को search करता है।

import sys

for path in sys.path:
    print(path)
Output:
Current folder और Python library paths show होंगे।

sys.exit()

sys.exit() program को stop करने के लिए use होता है। अगर किसी condition पर program को तुरंत terminate करना हो, तो इसका use किया जा सकता है।

import sys

age = 15

if age < 18:
    print("Not eligible")
    sys.exit()

print("Eligible")
Output:
Not eligible

sys.modules

sys.modules एक dictionary होती है जिसमें currently loaded modules की information होती है। Python loaded modules को cache करता है ताकि same module बार-बार import करने पर फिर से load न करना पड़े।

import sys
import math

print("math" in sys.modules)
Output:
True

Important sys Attributes and Functions

Name Use
sys.version Python version information देता है।
sys.platform Current operating system platform बताता है।
sys.argv Command line arguments की list देता है।
sys.path Module search paths की list देता है।
sys.exit() Program terminate करता है।
sys.modules Loaded modules की dictionary देता है।

Common Mistakes

  • sys.argv values को string समझे बिना directly calculation में use करना।
  • Command line arguments की length check किए बिना index access करना।
  • sys.exit() को loop या condition में बिना reason use करना।
  • sys.path में unnecessary changes करना।
Real Life Example:
अगर कोई Python script command line से student name और marks लेकर result generate करती है, तो command line arguments read करने के लिए sys.argv useful होता है।
Remember:
sys module Python interpreter और system environment से related information provide करता है।

Standard Modules - math

math Python का standard module है जो mathematical functions और constants provide करता है। Normal arithmetic operations जैसे addition, subtraction, multiplication और division Python operators से हो जाते हैं, लेकिन advanced mathematical operations जैसे square root, factorial, trigonometry, logarithm, power और constants के लिए math module useful होता है।

math module mainly numeric calculations के लिए use किया जाता है। इसमें बहुत सारे ready-made functions होते हैं जिनसे complex mathematical calculations आसानी से की जा सकती हैं। यह module scientific computing, engineering calculations, statistics, data analysis और academic programming में useful है।

Importing math Module

import math

math.sqrt()

sqrt() function किसी number का square root return करता है। इसका result usually float में आता है।

import math

print(math.sqrt(25))
print(math.sqrt(10))
Output:
5.0
3.1622776601683795

math.pow()

pow() function किसी number की power calculate करता है। math.pow(a, b) का मतलब a की power b होता है।

import math

print(math.pow(2, 3))
print(math.pow(5, 2))
Output:
8.0
25.0

math.factorial()

factorial() function किसी positive integer का factorial return करता है। Factorial में 1 से लेकर उस number तक सभी numbers multiply होते हैं।

import math

print(math.factorial(5))
print(math.factorial(4))
Output:
120
24

math.ceil() and math.floor()

ceil() function number से greater या equal nearest integer देता है। floor() function number से smaller या equal nearest integer देता है।

import math

print(math.ceil(4.2))
print(math.floor(4.8))
Output:
5
4

math.trunc()

trunc() function decimal part remove करके integer part return करता है। यह rounding नहीं करता, केवल decimal part काट देता है।

import math

print(math.trunc(4.9))
print(math.trunc(7.2))
Output:
4
7

math.gcd()

gcd() function दो numbers का greatest common divisor return करता है।

import math

print(math.gcd(12, 18))
print(math.gcd(20, 30))
Output:
6
10

math.pi and math.e

math.pi और math.e mathematical constants हैं। pi का use circle related calculations में होता है और e natural logarithm का base है।

import math

print(math.pi)
print(math.e)
Output:
3.141592653589793
2.718281828459045

Area of Circle Example

import math

radius = 7
area = math.pi * radius * radius

print("Area =", area)
Output:
Area = 153.93804002589985

Trigonometric Functions

math module trigonometric functions भी provide करता है जैसे sin(), cos(), tan(). ये functions angle को radians में accept करते हैं। अगर degree value है, तो उसे radians में convert करने के लिए math.radians() use किया जाता है।

import math

angle = 90
radian = math.radians(angle)

print(math.sin(radian))
print(math.cos(radian))
Output:
1.0
6.123233995736766e-17

cos(90) mathematically 0 होता है, लेकिन floating point calculation की वजह से बहुत छोटी value show हो सकती है।

Logarithmic Functions

import math

print(math.log(10))
print(math.log10(100))
print(math.log2(8))
Output:
2.302585092994046
2.0
3.0

Important math Functions

Function / Constant Use
math.sqrt(x) Square root return करता है।
math.pow(x, y) x की power y return करता है।
math.factorial(x) Factorial return करता है।

Common Mistakes

  • math module import किए बिना math.sqrt() use करना।
  • Trigonometric functions में degree value directly pass कर देना।
  • math.pow() और ** operator में difference न समझना।
  • Negative number का factorial निकालने की कोशिश करना।
Real Life Example:
Circle का area, distance formula, trigonometry based calculation और scientific formulas में math module useful होता है।
Remember:
math module advanced mathematical functions और constants provide करता है। Trigonometric functions radians में काम करते हैं।

Standard Modules - time

time Python का standard module है जो time-related operations perform करने के लिए use होता है। इसका use current time प्राप्त करने, program execution में delay देने, time formatting करने और timestamps handle करने के लिए किया जाता है।

Computer systems में time अक्सर timestamp के form में represent होता है। Timestamp usually seconds की count होती है जो एक fixed starting point, जिसे epoch कहा जाता है, से calculate की जाती है। Python में time module इस timestamp को read, convert और display करने की facility देता है।

Importing time Module

import time

time.time()

time.time() current time को seconds में return करता है। यह seconds epoch से count होते हैं। इसका use execution time measure करने में भी किया जाता है।

import time

print(time.time())
Output:
Output current timestamp के according अलग होगा।

time.ctime()

ctime() function timestamp को readable date-time string में convert करता है। अगर कोई argument न दिया जाए, तो यह current time return करता है।

import time

print(time.ctime())
Output:
Current date और time readable form में show होगा।

time.sleep()

sleep() function program execution को कुछ seconds के लिए pause करता है। इसका use delay create करने के लिए किया जाता है।

import time

print("Start")
time.sleep(3)
print("End")
Output:
Start
3 seconds बाद
End

Measuring Execution Time

किसी code को run होने में कितना time लगा, यह calculate करने के लिए time.time() का use किया जा सकता है।

import time

start = time.time()

for i in range(1000000):
    pass

end = time.time()

print("Execution Time:", end - start)
Output:
Execution Time system speed के according अलग होगा।

time.localtime()

localtime() timestamp को local time structure में convert करता है। इसमें year, month, day, hour, minute, second जैसी information होती है।

import time

current = time.localtime()

print(current.tm_year)
print(current.tm_mon)
print(current.tm_mday)
Output:
Current year
Current month
Current day

time.strftime()

strftime() function time को custom format में display करने के लिए use होता है। इससे date और time को readable और required format में show किया जा सकता है।

import time

current = time.localtime()

formatted = time.strftime("%d-%m-%Y %H:%M:%S", current)

print(formatted)
Output:
10-07-2026 14:30:25 जैसे format में output आएगा।

Common strftime Codes

Code Meaning
%d Day of month
%m Month number
%Y Year with century
%H Hour in 24-hour format
%M Minutes
%S Seconds
%A Full weekday name
%B Full month name

Display Day and Month Name

import time

current = time.localtime()

print(time.strftime("%A", current))
print(time.strftime("%B", current))
Output:
Current day name
Current month name

Digital Clock Style Example

import time

current = time.localtime()
clock = time.strftime("%H:%M:%S", current)

print("Current Time:", clock)
Output:
Current Time: 14:30:25

Important time Functions

Function Use
time.time() Current timestamp return करता है।
time.ctime() Readable current time return करता है।
time.sleep(seconds) Program को pause करता है।
time.localtime() Local time structure return करता है।
time.strftime() Time को formatted string में convert करता है।

Common Mistakes

  • sleep() में बहुत ज्यादा delay value देना।
  • strftime() format codes गलत लिखना।
  • Timestamp और readable time में difference न समझना।
  • time module को date calculation के लिए use करना, जबकि complex date work के लिए datetime ज्यादा suitable होता है।
Real Life Example:
Exam timer, digital clock, program execution time measurement और automatic delay system में time module use किया जा सकता है।
Remember:
time module current time, delay, timestamp और time formatting के लिए useful है।

The dir Function

dir() Python का built-in function है। इसका use किसी object, module, class या data type के available names, methods और attributes देखने के लिए किया जाता है। जब हमें यह जानना हो कि किसी module या object के अंदर कौन-कौन से functions और variables available हैं, तब dir() function बहुत useful होता है।

Beginners के लिए dir() learning tool की तरह काम करता है। इससे student पता कर सकता है कि string में कौन-कौन से methods हैं, list में कौन-कौन से methods हैं या किसी module जैसे math में कौन-कौन से functions available हैं।

Basic Syntax

dir(object)

Using dir() with Module

import math

print(dir(math))
Output:
math module के सभी available names की list show होगी।

Using dir() with String

text = "Python"

print(dir(text))
Output:
String object के methods और attributes की list show होगी।

Using dir() with List

numbers = [10, 20, 30]

print(dir(numbers))
Output:
List object के methods जैसे append, remove, pop, sort आदि list में show होंगे।

Finding Useful Methods

dir() का output बहुत लंबा हो सकता है। उसमें double underscore वाले names भी होते हैं जिन्हें dunder methods कहा जाता है। Beginners normally normal methods पर focus कर सकते हैं जैसे append, remove, upper, lower आदि।

text = "python"

methods = dir(text)

for method in methods:
    if not method.startswith("__"):
        print(method)
Output:
String के normal methods show होंगे।

dir() Without Argument

अगर dir() function को बिना argument call किया जाए, तो यह current scope में available names की list return करता है।

x = 10
name = "Brajkant"

print(dir())
Output:
Current program में available names की list show होगी।

dir() with User-defined Function

def greet():
    print("Hello")

print(dir(greet))
Output:
Function object के attributes की list show होगी।

dir() and help() Difference

Basis dir() help()
Work Available names/methods की list देता है। Detailed documentation show करता है।
Output Mostly names की list। Explanation, usage और details।
Use Methods discover करने के लिए। Method/function समझने के लिए।
Example dir(str) help(str.upper)

Using dir() and help() Together

print(dir(str))
help(str.upper)
Output:
पहले string methods की list show होगी, फिर upper() method की help show होगी।

Important Points

  • dir() built-in function है।
  • यह object/module के available methods और attributes show करता है।
  • यह beginners को methods discover करने में help करता है।
  • बिना argument के current scope के names show करता है।
  • Detailed explanation के लिए help() function use किया जा सकता है।

Common Mistakes

  • dir() के output को documentation समझ लेना।
  • Double underscore methods को beginner level पर unnecessarily use करना।
  • Method name देखकर बिना syntax समझे use करना।
  • dir को variable name बना देना।
Real Life Example:
अगर student को याद नहीं है कि list में कौन-कौन से methods available हैं, तो वह dir(list) run करके methods देख सकता है।
Remember:
dir() खोजने के लिए है, और help() समझने के लिए है।
