1. Advance Tools for Data Analysis

Advanced Data Analysis Tools ऐसे software platforms और libraries हैं जिनका उपयोग data को collect, manage, transform, integrate, analyze और visualize करने के लिए किया जाता है। ये tools basic spreadsheet operations से आगे जाकर specialized data analysis tasks को आसान बनाते हैं।

इस topic में चार महत्वपूर्ण tools/platforms का अध्ययन किया जाता है: BIGML, Natural Language Toolkit (NLTK), Talend और Tableau। प्रत्येक tool data analysis के अलग-अलग aspect में उपयोगी है।

2. BIGML

Definition

BIGML एक web-based data science और machine learning platform है जो data resources को manage करने तथा machine learning workflow को organize करने के लिए interface और resources उपलब्ध कराता है।

Purpose of BIGML

  • Data resources को manage करना।
  • Resources को organize और inspect करना।
  • Required resources को search करना।
  • Unwanted resources को delete करना।
  • Resource metadata को update/manage करना।
Exam Point: BIGML section में syllabus का मुख्य focus interface और resource management operations पर है।

3. Introduction to the BigML Interface

Definition

BigML Interface वह graphical/web interface है जिसके माध्यम से user platform पर available resources को access, organize और manage कर सकता है।

Interface का Basic Use

  1. BigML platform में sign in/access करें।
  2. Available resources और project-related information देखें।
  3. Required resource को select करें।
  4. Resource details inspect करें।
  5. Search, delete या metadata management जैसे operations perform करें।
Example: यदि project में कई uploaded resources हैं, तो interface की सहायता से उन्हें identify करके required resource को open और manage किया जा सकता है।

7. Searching and Deleting Resources

Searching Resources

Resource Searching का अर्थ available resources में required resource को search करना है। Search सुविधा large number of resources में specific item ढूँढने का समय कम करती है।

Basic Search Process

  1. Resource/list area open करें।
  2. Search field में relevant keyword या resource information enter करें।
  3. Matching resources identify करें।
  4. Required resource select करके उसके details देखें।

Deleting Resources

Deleting का अर्थ unwanted resource को resource collection से remove करना है।

  1. Required resource identify करें।
  2. Resource के available actions/options open करें।
  3. Delete option choose करें।
  4. यदि confirmation मांगा जाए तो confirm करें।
Important: Delete operation करने से पहले resource की आवश्यकता और selected resource की identity carefully verify करनी चाहिए।

11. Tokenizing Text

Definition

Tokenization text को छोटे meaningful units में divide करने की process है। इन units को Tokens कहा जाता है। Tokens words या sentences जैसे units हो सकते हैं।

Types

Word Tokenization

Text को individual words/tokens में divide किया जाता है।

Sentence Tokenization

Text को individual sentences में divide किया जाता है।

Example

Python + NLTK
import nltk from nltk.tokenize import word_tokenize text = "Data science is useful." tokens = word_tokenize(text) print(tokens)
Expected Output
['Data', 'science', 'is', 'useful', '.']
Use: Tokenization आगे होने वाले text analysis tasks के लिए एक basic preprocessing step है।

12. WordNet

Definition

WordNet एक lexical database है जिसमें English words को उनके meanings और semantic relationships के आधार पर organize किया जाता है। NLTK के माध्यम से WordNet resources को access किया जा सकता है।

Important Concepts

  • Synonyms: Similar meaning वाले words।
  • Synsets: एक particular meaning को represent करने वाले related words का group।
  • Semantic Relations: Words के बीच meaning-based relationships।

Example

Python + WordNet
from nltk.corpus import wordnet synsets = wordnet.synsets("computer") for s in synsets[:3]: print(s.name())
Exam Point: WordNet NLTK में lexical/semantic information explore करने के लिए important resource है।

25. Joining Tables

Definition

Joining Tables का अर्थ common field या key के आधार पर दो या दो से अधिक tables के records को combine करना है ताकि related information को एक साथ analyze किया जा सके।

Common Join Types

JoinBasic Meaning
Inner JoinMatching records को combine करता है।
Left JoinLeft table के सभी records और matching right records रखता है।
Right JoinRight table के सभी records और matching left records रखता है।
Full Outer Joinदोनों tables के records को include करता है; matching records combine होते हैं।

General Process in Tableau

  1. Required tables को data source area में add करें।
  2. Common field/key identify करें।
  3. Required join type choose करें।
  4. Join condition verify करें।
  5. Combined data का preview/check करें।
  6. Visualization के लिए resulting data source use करें।
Example: Customer table में Customer_ID और Orders table में Customer_ID common field हो, तो दोनों tables को Customer_ID के आधार पर join करके customer और order information को साथ analyze किया जा सकता है।
