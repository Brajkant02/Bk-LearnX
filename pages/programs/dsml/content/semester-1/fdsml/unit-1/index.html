Introduction to Data and Data Science

Introduction to Data and Data Science

आज के Digital World में लगभग प्रत्येक Activity से किसी न किसी प्रकार का Data Generate होता है। जब कोई व्यक्ति Internet पर Search करता है, Online Shopping करता है, Social Media का उपयोग करता है, Mobile Application चलाता है या किसी Website पर Visit करता है, तो विभिन्न प्रकार का Data Generate और Store होता है।

केवल Data का उपलब्ध होना पर्याप्त नहीं है। Raw Data को Collect, Store, Clean, Process और Analyze करके उसमें से Meaningful Information, Patterns, Trends और Insights प्राप्त करना आवश्यक होता है। इसी कार्य में Data Science महत्वपूर्ण भूमिका निभाती है।

Data Science एक interdisciplinary field है जो Mathematics, Statistics, Computer Science, Programming, Data Analysis, Machine Learning और Domain Knowledge जैसी विभिन्न disciplines को Combine करके Data से useful knowledge और insights निकालने का कार्य करती है। :contentReference[oaicite:2]{index=2}

Exam Point:
Data Science का मुख्य उद्देश्य Raw Data को Process और Analyze करके ऐसी Meaningful Information तथा Insights प्राप्त करना है जो Decision Making, Problem Solving और Future Prediction में सहायता कर सकें।

1. Data Definition

Data किसी Object, Person, Event, Activity या Situation से संबंधित Raw Facts, Figures, Symbols, Values या Observations का Collection होता है।

सरल शब्दों में, ऐसा Raw Material जिसे अभी Process और Interpret नहीं किया गया है, उसे Data कहा जा सकता है। जब इस Data को व्यवस्थित करके Process और Analyze किया जाता है, तब इससे Meaningful Information प्राप्त की जा सकती है।

उदाहरण के लिए किसी Student के Marks 65, 72, 81, 55 और 90 केवल अलग-अलग Values के रूप में दिए गए हों, तो ये Raw Data हैं। जब इन्हीं Marks का Average, Highest Marks, Lowest Marks और Performance तैयार किया जाता है, तब इससे Meaningful Information प्राप्त होती है।

2. Various Forms of Data

Data केवल Numbers के रूप में ही नहीं होता। Computer Systems और Digital Applications में Data कई अलग-अलग Forms में उपलब्ध होता है। Data का Form इस बात पर depend करता है कि Data को किस प्रकार Represent, Store और Process किया गया है।

1. Numerical Data

Numerical Data में Numbers या Quantitative Values शामिल होती हैं। इसका उपयोग ऐसी information को represent करने के लिए किया जाता है जिसे Measure या Calculate किया जा सकता है।

Examples: Age = 23, Salary = 25000, Marks = 85, Temperature = 32°C

2. Textual Data

Textual Data में Characters, Words, Sentences और Documents शामिल होते हैं।

Examples: Student Name, Address, Email, Product Description, Blog Article

3. Image Data

Image Data में Photographs, Graphics, Diagrams, Charts, Scanned Documents और अन्य Visual Information शामिल होती है।

Examples: Profile Photo, Product Image, X-Ray Image, Scanned Document

4. Audio Data

Audio Data में Sound या Voice से संबंधित information होती है।

Examples: Voice Recording, Music, Podcast, Call Recording

5. Video Data

Video Data में Moving Images के साथ Audio या अन्य multimedia information शामिल हो सकती है।

Examples: Movies, CCTV Recording, YouTube Videos, Online Classes

6. Sensor Data

Sensors द्वारा automatically generate किया गया Data Sensor Data कहलाता है।

Examples: Temperature Sensor, GPS Location, Heart Rate Sensor, IoT Devices

7. Geographical / Location Data

किसी Person, Device, Vehicle या Place की Location को represent करने वाला Data Geographical Data कहलाता है।

Examples: GPS Coordinates, City, Country, Map Location

3. Categories of Data

Data को अलग-अलग characteristics के आधार पर विभिन्न Categories में classify किया जा सकता है। Data Science में data की nature, structure और measurement को समझना बहुत important है क्योंकि Analysis Method और Algorithm का Selection Data के Type पर depend करता है।

A. Structured Data

Structured Data ऐसा Data है जो एक predefined structure या fixed format में organized होता है। यह सामान्यतः Rows और Columns के रूप में Database या Spreadsheet में Store किया जाता है।

Structured Data को SQL जैसे Query Languages की सहायता से आसानी से Search, Filter और Analyze किया जा सकता है। GFG के अनुसार Relational Database, Excel Files, CSV Files और Tabular Data Structured Data के examples हैं। :contentReference[oaicite:3]{index=3}

Examples: MySQL Table, Excel Sheet, CSV File, Student Database

B. Unstructured Data

Unstructured Data ऐसा Data है जिसका कोई fixed tabular structure नहीं होता। इसे traditional Rows और Columns में सीधे organize करना आसान नहीं होता।

Examples: Images, Videos, Audio, Social Media Posts, Emails, Documents

C. Semi-Structured Data

Semi-Structured Data में पूरी तरह fixed tabular structure नहीं होता, लेकिन इसमें Tags, Keys या Metadata जैसी structural information मौजूद होती है।

Examples: JSON, XML, HTML Documents

Examples: Gender Category, Product Color, Customer Feedback, Type of Product

4. Data Quality

Data Quality से तात्पर्य Data की Accuracy, Completeness, Consistency, Reliability और Timeliness जैसी characteristics से है।

Data Science में Analysis का Result काफी हद तक Input Data की Quality पर depend करता है। यदि Data गलत, incomplete या inconsistent है, तो Analysis से प्राप्त Result भी गलत हो सकता है। इसे अक्सर "Garbage In, Garbage Out" principle से समझाया जाता है।

Important Characteristics of Good Quality Data

  1. Accuracy
    Data सही और वास्तविक होना चाहिए।
  2. Completeness
    आवश्यक Data Missing नहीं होना चाहिए।
  3. Consistency
    अलग-अलग Sources में Data के Values आपस में conflict नहीं करने चाहिए।
  4. Timeliness
    Data समय के अनुसार Updated होना चाहिए।
  5. Validity
    Data निर्धारित Rules और Format के अनुसार होना चाहिए।
  6. Uniqueness
    Duplicate Records को कम या Remove किया जाना चाहिए।

5. Data Quality Issues

Real-world Data अक्सर Perfect नहीं होता। अलग-अलग Sources से Data Collect करने पर उसमें Missing Values, Duplicate Records, Incorrect Values, Inconsistent Formats और अन्य Problems हो सकती हैं।

GFG के अनुसार Data Preparation में Missing Values, Incorrect Data Types, Duplicates और Data Inconsistency जैसी समस्याओं को Resolve करना महत्वपूर्ण होता है। :contentReference[oaicite:4]{index=4}

Major Data Quality Issues

1. Missing Values

जब किसी Record में कोई required value उपलब्ध नहीं होती, तो उसे Missing Value कहा जाता है।

Example: Student Table में किसी Student का Mobile Number खाली होना।

2. Duplicate Data

जब एक ही Record एक से अधिक बार मौजूद हो, तो उसे Duplicate Data कहा जाता है।

3. Incorrect Data

जब Data में गलत Value Store हो जाए, तो यह Incorrect Data Problem होती है।

4. Inconsistent Data

जब एक ही Data अलग-अलग Systems में अलग Format या Value में Store हो, तो Data Inconsistency होती है।

5. Invalid Data

जब Data निर्धारित Format या Rule को Follow नहीं करता, तो वह Invalid Data हो सकता है।

6. Outdated Data

ऐसा Data जो वर्तमान Situation को accurately represent नहीं करता, Outdated Data कहलाता है।

12. What Do Data Scientists Do?

Data Scientist एक professional होता है जो Data से Meaningful Insights निकालने के लिए Scientific Methods, Statistics, Programming, Machine Learning और Data Analysis Techniques का उपयोग करता है।

Data Scientist का काम केवल Programming करना नहीं है। उसे Business Problem समझना, सही Data Identify करना, Data Clean करना, Analysis करना, Models Develop करना और Results को Business Stakeholders तक Explain करना भी होता है।

Major Responsibilities

  1. Understand Business Problem
    सबसे पहले Problem या Business Requirement को समझना।
  2. Data Collection
    विभिन्न Sources से Required Data Collect करना।
  3. Data Cleaning
    Missing Values, Duplicates, Errors और Inconsistencies को Handle करना।
  4. Exploratory Data Analysis
    Data में Patterns, Trends, Relationships और Outliers को Identify करना।
  5. Statistical Analysis
    Statistics और Mathematical Methods की सहायता से Data को Analyze करना।
  6. Machine Learning
    आवश्यकता के अनुसार Prediction या Classification Models Develop करना।
  7. Data Visualization
    Charts, Graphs और Dashboards के माध्यम से Results को understandable बनाना।
  8. Model Evaluation
    Model की Performance को Test और Evaluate करना।
  9. Communication
    Technical Results को Business Users और Stakeholders को Simple तरीके से Explain करना।

13. Data Science Life Cycle

Data Science Life Cycle उन विभिन्न Steps या Stages का systematic sequence है जिनके माध्यम से किसी Data Science Problem को Identify करने से लेकर Final Solution और Deployment तक पूरा किया जाता है।

Data Science एक single-step process नहीं है। इसमें Problem Definition, Data Collection, Data Preparation, Analysis, Model Building, Evaluation और Communication/Deployment जैसी कई stages शामिल होती हैं। :contentReference[oaicite:11]{index=11}

Data Science Life Cycle Flow

Problem Definition
↓ Data Collection
↓ Data Cleaning & Preparation
↓ Exploratory Data Analysis
↓ Feature Engineering
↓ Model Building
↓ Model Evaluation
↓ Deployment
↓ Monitoring & Improvement

Stage 1: Problem Definition

Data Science Life Cycle का पहला और बहुत महत्वपूर्ण Step Problem Definition है। इसमें यह clearly determine किया जाता है कि किस Problem को Solve करना है, Business Objective क्या है और Expected Result क्या होना चाहिए।

यदि Problem सही तरीके से Define नहीं की गई, तो बाद के सभी Steps का Direction गलत हो सकता है।

Stage 2: Data Collection

Problem Define करने के बाद Required Data को विभिन्न Sources से Collect किया जाता है।

Sources: Databases, APIs, Websites, Surveys, Sensors, Files, Applications और Social Media

Stage 3: Data Cleaning and Preparation

Collected Data में Missing Values, Duplicate Records, Incorrect Values और Inconsistent Formats हो सकते हैं। इसलिए Data को Clean और Prepare किया जाता है।

Stage 4: Exploratory Data Analysis

Exploratory Data Analysis (EDA) में Data की Basic Characteristics, Patterns, Trends, Relationships और Outliers को समझने का प्रयास किया जाता है।

Stage 5: Feature Engineering

Machine Learning Model के लिए useful Features को Select, Transform या Create किया जाता है। इसका उद्देश्य Model के लिए Data को अधिक useful बनाना है।

Stage 6: Model Building

Problem के अनुसार Statistical या Machine Learning Model Select और Train किया जाता है।

Stage 7: Model Evaluation

Developed Model को Test Data पर Evaluate किया जाता है। Accuracy और अन्य appropriate Evaluation Metrics के माध्यम से Model की Performance Check की जाती है।

Stage 8: Deployment

यदि Model satisfactory Performance देता है, तो उसे Real-world Application या Production Environment में Deploy किया जा सकता है।

Stage 9: Monitoring and Improvement

Deployment के बाद Model और System की Performance को Monitor किया जाता है। New Data आने पर Model को Update या Retrain करने की आवश्यकता हो सकती है।

14. Components of Data Science

Data Science एक multidisciplinary field है। इसमें विभिन्न Technical और Analytical Components मिलकर Data से Insights निकालने का कार्य करते हैं।

Major Components

1. Data Collection

सबसे पहले Problem के लिए Required Data को विभिन्न Sources से Collect किया जाता है।

2. Data Engineering

Data Engineering में Data Infrastructure, Data Pipelines, Storage और Processing Systems को Design और Manage किया जाता है।

3. Data Cleaning

Raw Data से Errors, Duplicates, Missing Values और Inconsistencies को Handle किया जाता है।

4. Statistics

Statistics की सहायता से Data के Patterns, Relationships, Probability और Trends को Analyze किया जाता है।

5. Programming

Data Science में Python और R जैसी Programming Languages का उपयोग Data Processing, Analysis और Machine Learning के लिए किया जा सकता है।

6. Data Analysis

Data Analysis के द्वारा Data में मौजूद Important Patterns, Relationships और Trends Identify किए जाते हैं।

7. Machine Learning

Machine Learning Algorithms का उपयोग Data से Patterns Learn करके Prediction, Classification और Automation जैसे tasks Perform करने के लिए किया जाता है।

8. Data Visualization

Charts, Graphs, Dashboards और अन्य Visual Methods की सहायता से Complex Data और Results को आसानी से समझने योग्य बनाया जाता है।

9. Domain Knowledge

जिस Industry या Business Problem पर Data Science लागू की जा रही है, उसके Domain को समझना भी महत्वपूर्ण है। इससे सही Problem Definition और सही Interpretation में सहायता मिलती है।

10. Communication

Data Science के Results को Stakeholders और Decision Makers तक स्पष्ट रूप से Explain करना आवश्यक होता है।
