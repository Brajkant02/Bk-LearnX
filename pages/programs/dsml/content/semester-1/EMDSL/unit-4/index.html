Calculus

The Fundamental Theorem of Calculus

Fundamental Theorem of Calculus (FTC) differentiation और integration के बीच important relationship establish करता है। यह बताता है कि integration और differentiation एक-दूसरे के inverse operations की तरह काम करते हैं।

First Part

यदि F(x)=∫ₐˣ f(t)dt, जहाँ f continuous है, तो:

F′(x) = f(x)

Second Part

यदि F, f का antiderivative है, तो definite integral को endpoints पर F की values से calculate किया जा सकता है:

∫ₐᵇ f(x)dx = F(b) − F(a)
Example: ∫₀² x dx = [x²/2]₀² = 2.
Exam Point: FTC calculus में derivative और definite integral को connect करने वाला fundamental result है।

2. Integration

Integration किसी function का antiderivative find करने या definite integral के case में accumulated quantity/area निकालने की process है।

Basic Rules

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C,   n ≠ −1
∫ k dx = kx + C
∫ eˣ dx = eˣ + C
∫ 1/x dx = ln|x| + C

यहाँ C arbitrary constant है, जो indefinite integration में add किया जाता है।

3. Integration of Products

जब दो functions का product integrate करना हो, तब commonly Integration by Parts का उपयोग किया जाता है। यह product rule of differentiation का reverse form माना जा सकता है।

∫u dv = uv − ∫v du

Steps

  1. Suitable function को u और दूसरे part को dv choose करें।
  2. u का derivative निकालकर du प्राप्त करें।
  3. dv को integrate करके v प्राप्त करें।
  4. Formula में values substitute करें।
  5. Remaining integral solve करें।
Example: ∫x eˣ dx में u=x और dv=eˣdx लेने पर integration by parts apply किया जा सकता है।

4. Integration of Quotients

जब function quotient या fraction form में हो, तो integration की method expression की structure पर depend करती है। कई cases में substitution, algebraic simplification या partial fractions useful होते हैं।

Simple Substitution Idea

यदि numerator denominator के derivative से related हो, तो denominator को substitution के रूप में लिया जा सकता है।

∫ f′(x)/f(x) dx = ln|f(x)| + C
Example: ∫(2x)/(x²+1) dx में u=x²+1 लेने पर du=2x dx और answer ln(x²+1)+C मिलता है।

5. Integration of Chains / Chain-Type Functions

जब function के अंदर दूसरा function मौजूद हो, जैसे f(g(x)), तब substitution method useful होती है। इसे chain-rule related integration भी समझा जा सकता है।

Basic Pattern

∫ f(g(x))g′(x) dx = ∫ f(u) du

जहाँ u=g(x).

Example: ∫2x(x²+1)⁵ dx में u=x²+1 लेने पर integral आसानी से solve किया जा सकता है।

6. Simple Rules for Calculus

Power Rule

d/dx(xⁿ) = nxⁿ⁻¹

Constant Rule

d/dx(c) = 0

Constant Multiple Rule

d/dx[cf(x)] = c f′(x)

Sum / Difference Rule

d/dx[f(x) ± g(x)] = f′(x) ± g′(x)

Product Rule

(fg)′ = f′g + fg′

Quotient Rule

(f/g)′ = (gf′ − fg′)/g²

Chain Rule

d/dx[f(g(x))] = f′(g(x))g′(x)

7. Differential Calculus

Derivative यह बताता है कि independent variable में small change होने पर dependent variable किस rate से change करता है।

Applications

8. Definition of a Derivative

Function f(x) का derivative किसी point पर function के instantaneous rate of change को represent करता है।

f′(x) = limₕ→0 [f(x+h) − f(x)]/h

यह first principle / limit definition of derivative है।

Geometrical Meaning

Graph पर किसी point पर derivative उस point पर curve की tangent line की slope देता है।

Exam Point: Derivative को “rate of change” और “tangent की slope” दोनों रूपों में explain किया जा सकता है।

9. How to Find the Derivative of a Function

Function की derivative निकालने के लिए function की form देखकर appropriate differentiation rule apply किया जाता है।

Example 1 — Polynomial

f(x)=x³+4x²−5x+2
f′(x)=3x²+8x−5

Example 2 — Product

f(x)=x²sin(x)

Product Rule apply करें:

f′(x)=2x sin(x)+x² cos(x)

Example 3 — Chain Rule

f(x)=(3x+1)⁵
f′(x)=5(3x+1)⁴×3 = 15(3x+1)⁴

10. Partial Derivatives

जब function में एक से अधिक independent variables हों, तब किसी एक variable के respect में differentiation करते समय बाकी variables को constant माना जाता है। इसे Partial Differentiation कहते हैं।

Example

f(x,y)=x²y+3xy²

x के respect में:

∂f/∂x = 2xy + 3y²

y के respect में:

∂f/∂y = x² + 6xy

Notation

  • ∂f/∂x — partial derivative with respect to x.
  • ∂f/∂y — partial derivative with respect to y.
  • Higher-order partial derivatives भी निकाले जा सकते हैं।

11. The Jacobian Matrix

Jacobian Matrix multivariable functions के first-order partial derivatives को matrix form में arrange करती है। यह coordinate transformations और multivariable calculus में important है।

For Two Functions

यदि:

u=u(x,y),   v=v(x,y)

तो Jacobian:

J = ∂(u,v)/∂(x,y) = | ∂u/∂x ∂u/∂y ; ∂v/∂x ∂v/∂y |

Uses

  • Variable transformation.
  • Change of coordinates.
  • Multivariable integration.
  • Nonlinear systems और numerical methods.
  • Optimization और machine learning contexts.

12. Introduction to Vector Calculus

Vector Calculus vectors और multivariable functions के differentiation और integration का study है। इसका उपयोग Physics, Engineering, Computer Graphics, Fluid Mechanics और Data Science related mathematical models में किया जाता है।

Important Concepts

  • Scalar Field: प्रत्येक point पर एक scalar value assign करता है।
  • Vector Field: प्रत्येक point पर एक vector assign करता है।
  • Gradient: Scalar field के maximum increase की direction बताता है।
  • Divergence: Vector field के local source/sink behavior को describe करता है।
  • Curl: Vector field की local rotation tendency को describe करता है।

Gradient

∇f = (∂f/∂x)i + (∂f/∂y)j + (∂f/∂z)k
Exam Point: Vector calculus में gradient, divergence और curl basic operators हैं।

13. Lagrange Multipliers

Lagrange Multipliers constrained optimization की एक method है। इसका उपयोग तब किया जाता है जब किसी function का maximum या minimum find करना हो और साथ में कोई constraint दिया गया हो।

Basic Setup

Objective function:

f(x,y)

Constraint:

g(x,y)=c

Lagrangian function:

L(x,y,λ)=f(x,y)−λ[g(x,y)−c]

Conditions

∂L/∂x = 0,   ∂L/∂y = 0,   ∂L/∂λ = 0

इन equations को simultaneously solve करके candidate points प्राप्त किए जाते हैं।

14. Constrained Optimization

Constrained Optimization में objective function को maximize या minimize करना होता है, लेकिन variables पर एक या अधिक restrictions/constraints लागू होते हैं।

Example Structure

Maximize / Minimize: f(x,y)
Subject to: g(x,y)=c

General Steps using Lagrange Multipliers

  1. Objective function identify करें।
  2. Constraint identify करें।
  3. Lagrangian function form करें।
  4. All required partial derivatives zero के बराबर रखें।
  5. Equations solve करके candidate points find करें।
  6. Objective function पर candidate points evaluate करें।
  7. Maximum/minimum condition को interpret करें।
Real-Life Applications: Limited resources में maximum profit, minimum cost, shortest distance और engineering design optimization जैसे problems में constrained optimization useful है।
