1. Introduction to Probability

Probability Mathematics और Statistics की वह branch है जो किसी event के होने की likelihood / संभावना को measure करती है। Probability का value हमेशा 0 और 1 के बीच होता है।

0 ≤ P(A) ≤ 1

यदि किसी event का probability 0 है, तो event impossible है; और probability 1 होने पर event certain है।

Experiment

ऐसी प्रक्रिया जिसका result पहले से निश्चित नहीं होता, उसे Random Experiment कहते हैं। जैसे coin toss, dice roll आदि।

Sample Space

Random experiment के सभी possible outcomes के set को Sample Space (S) कहते हैं।

Event

Sample space का कोई भी subset Event कहलाता है।

P(A) = Number of favourable outcomes / Total number of equally likely outcomes

3. Addition Theorem of Probability

दो events A और B में से कम-से-कम एक event होने की probability को addition theorem से calculate किया जाता है।

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

यहाँ A ∩ B दोनों events के simultaneously होने को represent करता है।

For Mutually Exclusive Events

यदि A और B mutually exclusive हैं, तो दोनों एक साथ नहीं हो सकते। इसलिए:

P(A ∩ B) = 0
P(A ∪ B) = P(A) + P(B)
Example: एक die roll में 2 या 5 आने की probability = 1/6 + 1/6 = 1/3.

4. Multiplication Theorem of Probability

दो events A और B दोनों के होने की probability multiplication theorem से प्राप्त की जा सकती है।

P(A ∩ B) = P(A)P(B|A)

इसी प्रकार:

P(A ∩ B) = P(B)P(A|B)

For Independent Events

यदि A और B independent हैं, तो:

P(B|A) = P(B)
P(A ∩ B) = P(A)P(B)
Example: दो independent coin tosses में दोनों बार Head आने की probability = 1/2 × 1/2 = 1/4.

5. Simple Problems on Probability

Example 1 — Dice

एक fair die को एक बार roll किया गया। Even number आने की probability निकालें।

S = {1,2,3,4,5,6}
Favourable = {2,4,6}
P(E) = 3/6 = 1/2

Example 2 — Coin

एक fair coin को एक बार toss किया गया। Tail आने की probability:

P(T) = 1/2

Example 3 — Addition Theorem

यदि P(A)=0.5, P(B)=0.4 और P(A∩B)=0.2, तो:

P(A∪B)=0.5+0.4−0.2=0.7

6. Random Variable

Random Variable एक function है जो random experiment के outcomes को numerical values assign करता है। इसे सामान्यतः X या Y से denote करते हैं।

Types

  • Discrete Random Variable: Countable values लेता है, जैसे 0,1,2,3...
  • Continuous Random Variable: किसी interval में कोई भी real value ले सकता है।

Example

दो coins toss करने पर X = number of heads. Possible values X = 0,1,2.

Important: Random variable outcome itself नहीं बल्कि outcome को numerical value देने वाला mathematical function है।

7. Continuous Random Variable

Continuous Random Variable किसी continuous interval में infinitely many possible values ले सकता है। उदाहरण: height, weight, temperature, time आदि।

Continuous variable की probability generally Probability Density Function (PDF) से describe की जाती है। किसी exact single point की probability continuous case में 0 होती है।

P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx

जहाँ f(x) probability density function है।

8. Conditional Probability

Conditional Probability किसी event A के होने की probability है, जब हमें पता हो कि event B already occur हो चुका है।

P(A|B) = P(A ∩ B) / P(B),   P(B)>0

इसे “probability of A given B” पढ़ते हैं।

Example

यदि P(A∩B)=0.2 और P(B)=0.5, तो:

P(A|B)=0.2/0.5=0.4

9. Bayes' Theorem

Bayes' Theorem available evidence के आधार पर किसी hypothesis की probability को update करने की method है। यह conditional probability पर आधारित है।

P(A|B) = P(B|A)P(A) / P(B)

General Form

P(Aᵢ|B) = P(B|Aᵢ)P(Aᵢ) / Σ P(B|Aⱼ)P(Aⱼ)

Bayes theorem का use medical diagnosis, spam filtering, classification, machine learning और decision making में होता है।

Terms: P(A) = Prior Probability, P(B|A) = Likelihood, P(A|B) = Posterior Probability.

10. Probability Density Function (PDF)

Probability Density Function continuous random variable की probability distribution को describe करती है।

Properties of PDF

  • f(x) ≥ 0 for all x.
  • पूरे range के ऊपर total area 1 होता है।
  • किसी interval की probability उस interval के नीचे area के बराबर होती है।
∫₋∞^∞ f(x) dx = 1
P(a≤X≤b)=∫ₐᵇ f(x)dx

PDF की height को अकेले probability नहीं माना जाता; interval के नीचे area probability देता है।

11. Normal Distribution

Normal Distribution एक continuous probability distribution है जिसका graph symmetric bell-shaped curve होता है। इसे Gaussian Distribution भी कहा जाता है।

Probability Density Function

f(x)=1/(σ√(2π)) · e^[-(x−μ)²/(2σ²)]

यहाँ μ = mean और σ = standard deviation है।

Characteristics

  • Curve symmetric होता है।
  • Mean = Median = Mode.
  • कुल area under curve = 1.
  • Curve के दोनों tails theoretically x-axis के बहुत करीब जाते हैं।
  • Distribution का shape mean और standard deviation से determine होता है।

12. Central Limit Theorem (CLT)

Central Limit Theorem statistics का एक fundamental theorem है। यह बताता है कि sufficiently large sample size होने पर independent observations के sample mean की sampling distribution approximately normal हो जाती है, चाहे original population distribution normal न भी हो।

Importance

  • Sampling distributions को understand करने में मदद करता है।
  • Statistical inference और confidence intervals में important है।
  • Large samples के लिए normal approximation provide करता है।
Mean of X̄ = μ    |    SE(X̄)=σ/√n
Exam Point: CLT की key idea है — large samples के sample means की distribution approximately normal होती है।

13. Binomial Distribution

Binomial Distribution एक discrete probability distribution है जो fixed number of independent trials में success की संख्या को model करती है।

Conditions

  • Fixed number of trials n.
  • हर trial के केवल two outcomes: Success / Failure.
  • Trials independent हों।
  • हर trial में success probability p constant हो।

Probability Formula

P(X=x)=C(n,x)pˣ(1−p)ⁿ⁻ˣ

जहाँ x = successes, n = trials और p = success probability.

Mean and Variance

Mean = np     Variance = np(1−p)
Example: 3 coin tosses में exactly 2 heads की probability: C(3,2)(1/2)²(1/2)¹ = 3/8.

14. Conjugate Distribution

Conjugate Distribution Bayesian statistics में ऐसा prior distribution है जिसके साथ likelihood combine करने पर posterior distribution उसी family का रहता है। इससे Bayesian calculations comparatively simple हो जाती हैं।

Common Examples

LikelihoodConjugate PriorPosterior Family
Bernoulli / BinomialBetaBeta
PoissonGammaGamma
Normal (known variance)NormalNormal
Key Idea: Conjugacy का उद्देश्य posterior distribution को ऐसी known family में रखना है जिससे calculation और interpretation आसान हो।

15. Poisson Distribution

Poisson Distribution fixed interval में किसी event के कितनी बार होने की probability को model करने वाली discrete distribution है, जब events की average rate known हो और appropriate independence assumptions हों।

Probability Formula

P(X=k)=e⁻λ λᵏ/k!,   k=0,1,2,...

यहाँ λ given interval में expected number of events है।

Mean and Variance

Mean = λ     Variance = λ

Examples

  • एक घंटे में आने वाली calls की संख्या।
  • एक page पर printing errors की संख्या।
  • एक fixed time interval में arrivals की संख्या।

16. Bell Curve

Bell Curve

68–95–99.7 Rule

  • लगभग 68% observations μ ± 1σ के अंदर होते हैं।
  • लगभग 95% observations μ ± 2σ के अंदर होते हैं।
  • लगभग 99.7% observations μ ± 3σ के अंदर होते हैं।
Use: Normal data के spread को quickly समझने और unusual observations identify करने में Bell Curve useful है।

17. Sampling Distribution

Sampling Distribution किसी population से बार-बार samples लेने पर किसी statistic, जैसे sample mean, sample proportion या sample variance, की probability distribution है।

Example

यदि एक population से size n के बहुत सारे samples लिए जाएँ और हर sample का mean calculate किया जाए, तो इन sample means का distribution sampling distribution of sample mean कहलाएगा।

Importance

  • Population parameters का estimation.
  • Confidence intervals.
  • Hypothesis testing.
  • Standard error calculation.
  • Central Limit Theorem की application.
SE(X̄)=σ/√n

18. Discriminant Analysis

Discriminant Analysis एक statistical classification technique है जिसका उद्देश्य observations को predefined groups/classes में classify करना और groups के बीच difference को analyze करना है।

Basic Idea

Input variables/features की सहायता से ऐसी discriminant function बनाई जाती है जो different classes को अलग करने में मदद करती है।

Types

  • Linear Discriminant Analysis (LDA): Classes को linear decision boundary से separate करने की कोशिश करता है।
  • Quadratic Discriminant Analysis (QDA): More flexible quadratic decision boundaries allow करता है।

Applications

  • Classification problems
  • Pattern recognition
  • Customer classification
  • Medical diagnosis
  • Machine Learning
Exam Point: Discriminant Analysis statistical data से class membership predict करने और classes को distinguish करने के लिए use किया जाता है।
